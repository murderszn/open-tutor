# 🖥️ STEM Assignment: Windows Command Prompt vs PowerShell

**Subject:** STEM / Computer Science  
**Grade Level:** 8th Grade (Grade 8)  
**Platform:** Windows PC

---

## 🎯 What You Will Learn

- How to open Command Prompt (cmd.exe)
- Basic `cmd` commands: `dir`, `cd`, `cls`
- How `cmd` differs from PowerShell
- When to use each shell
- How to run the same folder navigation task in both shells


**Core Repo Resource:**
- **[Student Guide: Windows Cli And Shell Fundamentals](../../resources/windows-cli-and-shell-fundamentals.md)**
 — Open Command Prompt

Press `Win + R`, type `cmd`, and press Enter.

---

## 🔬 Part 2 — Basic Commands in cmd

Type:

```cmd
cd
dir
cd Documents
cd ..
dir
```

**Questions:**
1. What does `dir` show?
2. What does `cd` with no arguments do?
3. How does `cd ..` work compared to PowerShell?

---

## 🔬 Part 3 — Clear the Screen

Type:

```cmd
cls
```

**Question:** What does `cls` do?

---

## 🔬 Part 4 — Same Task, Two Shells

Do these steps in **both** PowerShell and Command Prompt. Write the commands you used:

1. Go to your Desktop
2. Make a folder called `shell-comparison`
3. Go into that folder
4. Make a file called `compare.txt`
5. Go back to your home folder

**Questions:**
1. Which shell felt easier?
2. Were any commands different? List them.
3. Which shell gives more detailed output?

---

## 💬 Part 5 — Reflection

1. What is one similarity between `cmd` and PowerShell?
2. What is one difference?
3. Why might a person use PowerShell instead of `cmd` today?
