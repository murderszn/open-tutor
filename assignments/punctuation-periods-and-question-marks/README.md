## 📖 Lesson — Read This First

### Statements and Questions

A **statement** tells something and ends with a **period** (`.`).
A **question** asks something and ends with a **question mark** (`?`).

**Examples**
- Statement: `The cat sleeps on the couch.`
- Question: `Is the cat sleeping on the couch?`

### Rules to Remember
- Always capitalize the first letter of the first word.
- Use a period for statements.
- Use a question mark for questions.
- Do not add a period at the end of a question (the question mark serves that job).
