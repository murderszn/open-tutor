# Using the Teaching Library

## Select one grade track

1. Choose one developed grade folder: currently `curriculum/grade-4`, `grade-5`, `grade-7`, or `grade-8`. The [K–12 expansion plan](curriculum-expansion/README.md) identifies placeholder and planned tracks; these are not ready to assign merely because an issue or grade hub exists.
2. Work only inside that grade folder for that learner. Do not reference, assign, or compare with another grade’s folder.
3. Select a subject overview, then a blank assignment or assessment in that same folder.
4. Preview sources, check prerequisites and safety, and adapt accommodations.
5. Keep responses and progress in an access-controlled private workspace.

## Individual weekly planning template

| Session | Focus | Individual evidence |
|---|---|---|
| 1 | Preview one learning goal and reference | Record a question |
| 2 | Practice a core skill | Show one worked response |
| 3 | Read, investigate, or build | Keep a draft or observation note private |
| 4 | Apply the skill to a practical task | Create an individual product |
| 5 | Review and revise | Explain one improvement |

This is a flexible menu, not a prescribed workload. Adjust schedule and supports for one learner at a time. No sibling, peer, shared-work, or cross-grade comparison is required.

## Assessment

A simple individual rubric can assess accuracy, evidence/reasoning, communication, and revision. Generated questions are not standardized or validated assessments.

## Safety and privacy

Preview external media and supervise hands-on tasks. Do not ask learners to put their name, home address, contact details, school, real timetable, or identifying photos into a public repository. Civic letters and portfolio projects should be reviewed by an adult and completed privately before any external sharing.

Faith-based study is optional and isolated in separately labeled enrichment material; it is not a substitute for evidence-based science teaching.
