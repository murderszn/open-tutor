# Platform marks

GitHub and Discord SVG marks come from [Simple Icons](https://github.com/simple-icons/simple-icons), distributed under [CC0](https://github.com/simple-icons/simple-icons/blob/develop/LICENSE.md). Brand names and marks remain the property of their respective owners.

- [GitHub source](https://github.com/simple-icons/simple-icons/blob/develop/icons/github.svg)
- [Discord source](https://github.com/simple-icons/simple-icons/blob/develop/icons/discord.svg)

The marks are decorative beside readable setup-link labels. Footer icon-only links have accessible names on their anchors. CSS uses black marks on yellow and white marks in the footer.
