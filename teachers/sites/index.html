The OpenTutor Operating System

OpenTutor relies on real-world tech stacks to foster profound independence and digital literacy:

  • GitHub (The Classroom): Public curriculum and assignments live here as Markdown files. Learner submissions, grades, and schedules stay in private storage.
  • Discord (The Help Desk): Real-time, async communication. We use dedicated channels (e.g., `#math-help`, `#stem-projects`) integrated with custom AI "Teacher Bots". When students are stuck, they ping the bots for Socratic guidance—getting hints and analogies, never direct answers.

Program Requirements

Set up these accounts and tools before the first sprint. See Resources for quick links.

  • Accounts: Gmail (email), GitHub, Discord.
  • Software: VS Code editor (with GitHub sign‑in).
  • Hardware: Webcam and microphone (for weekly video reviews and check‑ins).
  • Device: PC, Mac laptop, or Chromebook. On Chromebooks, enable Linux (Beta) or use web IDEs (e.g., Codespaces).

Curriculum Overview

  • Math: Practice 5x/week; weekly quiz on Fridays (see timeline links).
  • Spanish: Duolingo lesson daily (5x/week minimum).
  • Logic / Chess: 1 lesson or reviewed game (5x/week).
  • Music / Piano: 1 focused practice session (5x/week).
  • STEM / Science: Weekly topic with short quiz or build task. This term features a 5‑part Biology thread (water cycle, plant/animal cells, photosynthesis, reproduction) with interactives and a consolidated guide.
  • Language Arts: Reading + grammar, plus a weekly video review saved to the student hub.
  • Social Studies: Weekly reading + comprehension quiz; periodic research projects. Includes a Grade 7 “History of War — Turning Points & Institutions”.
  • Finance / Money: “Credit Scores 101” with an interactive Credit Score Explorer (APR impact, loans, and access).

Submission & Review: Students work from their hub, submit GitHub Pull Requests, and discuss blockers in Discord. Sprints move cards Backlog → In Progress → Done; “Close Sprint” triggers parent notification.
