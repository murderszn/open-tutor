# Answer key — Unit 01: Observing, Describing, and Asking Questions

**For the guiding adult only. Never place beside a student question.**
Every item below was solved independently against the lesson text; where a
task is open-ended, the key gives the acceptance rule plus sample acceptable
answers. "Checkable" means the adult can verify it with their own senses.

## Lesson 01

1. **Guided (one notice):** Any detail actually in the illustration counts:
   ladybug, butterfly, flower, snail, stone, bird, fence, sun, clouds, leaf,
   spots, grass. Sample: "I notice a red bug on the leaf."
2. **Three notices:** Any three distinct checkable details from the
   [text-only alternative](lessons/lesson-01-five-senses-noticing.md#teacher-note).
   Sample set: "a blue butterfly," "a snail on a stone," "two white clouds."
   Not acceptable: stories ("the ladybug is lost"), counts the child cannot
   show, or details not in the picture.
3. **Drawing:** Counts if two recognizable details from the picture appear
   (e.g., red body + black dots for the ladybug; spiral shell + stone for the
   snail). Artistic skill is not judged.
4. **"I notice ___":** Any checkable sentence. Sample: "I notice the flower
   is yellow."
5. **Application (object):** Any checkable detail via any sense. Sample for an
   apple: "It is red," "It feels smooth," "It smells sweet."
6. **Exit check:** Three checkable details + one "I notice" sentence, as above.

## Lesson 02

1. **Guided (eyes, then lens):** Eyes: any true visible feature ("green,"
   "pointy end," "smooth"). Lens: any true new detail ("tiny lines/veins,"
   "bumpy edge," "little spots," "fuzz"). The lens detail must not have been
   named in the eyes-only look.
2. **Two drawings:** First shows the leaf as seen; second shows the new
   detail. Counts if the second drawing adds something the first lacks and
   the detail is real.
3. **"Without the lens… / With the lens…":** Sample: "Without the lens I saw
   a smooth green leaf. With the lens I saw tiny lines on it."
4. **Name something to lens next:** Any answer counts ("my finger," "the
   rug").
5. **Application (second object):** One true new detail. Sample (fabric):
   "I see little threads / tiny holes between threads."
6. **Exit check:** One lens-only detail + the completed sentence pair.

## Lesson 03

1. **Guided description:** Counts if at least two checkable details are
   dictated. Sample (red apple): "It is round and red; it has a brown stem."
2. **Independent description:** Same bar for the second object. The adult must
   be able to pick the object from the description.
3. **Drawing:** Two described details visible in the drawing.
4. **"Pretty" vs. "yellow and bumpy":** Correct choice: "It is yellow and
   bumpy," because the details can be checked with the senses; "pretty" is a
   feeling. Accept any reasoning mentioning checkable vs. feeling.
5. **Description game:** Counts if the adult finds the object from the
   description (two checkable details). If the adult cannot find it, the
   description needs more details — that is the lesson, not a failure.
6. **Exit check:** Adult identifies the object from the learner's description
   alone.

## Lesson 04

1. **Guided sort + rule:** Any observable rule counts: color, size, shape,
   texture ("rough/smooth"), "has holes," "rolls / does not roll." Not
   acceptable: "my favorites," "lucky," "pretty."
2. **Re-sort by a different rule:** The second rule must differ from the
   first AND be observable. Sample: first "color," then "big/little."
3. **Name the adult's rule:** The learner states the rule the adult used.
   Counts if it matches (accept synonyms: "colors" for "color").
4. **Which tray has more:** Any answer with a reason counts ("this one —
   it looks like more"). Counting is welcome; estimating by look is allowed
   at K.
5. **Room sort:** Three things + a stated observable rule. Sample: "pillow,
   blanket, stuffed bear — they are all soft."
6. **Exit check:** One sort with a named observable rule, then a re-sort with
   a different named rule.

## Lesson 05

1. **Guided filing (four sentences):** "I notice the shell is pink inside" →
   NOTICE. "I notice it feels bumpy" → NOTICE. "It is sleepy" → WONDER-side
   (it is a guess; accept filing under "wonder" only if the learner recasts
   it as a question — otherwise it belongs nowhere yet, which is also a
   correct insight). "I wonder if it is from the beach" → WONDER.
2. **Own "I notice…":** One checkable sentence. Sample: "I notice the leaf
   has a pointy end."
3. **Own "I wonder…":** Must be phrased as a question. Sample: "I wonder why
   the leaf has spots." Not acceptable: "I wonder it has spots" (statement).
4. **Error analysis ("I notice this leaf wants to be a kite"):** Correct:
   it does not belong in "I notice" because "wants" cannot be seen — it is a
   guess/story. Accept: "You can't see 'wants'." Recast together: "I wonder
   what the leaf would do in the wind."
5. **Application (two-column page):** One filed notice + one filed wonder,
   correctly separated.
6. **Exit check:** One checkable notice, one real question, two adult
   sentences filed correctly.

## Lesson 06

1. **Guided first stop:** One notice contributed; adult scribes.
2. **Three stops:** Each stop counts if it has: two checkable notices (any
   sense), one closer-look new detail, and one dictated notice/wonder pair.
   Sample stop: "I notice the bark is rough. I notice ants. With the lens I
   see tiny cracks. I notice the bark is brown. I wonder how old the tree is."
3. **Most interesting stop:** Any choice with any reason ("the ants, because
   they were moving").
4. **Sort the walk:** Notices filed into "saw" / "heard-felt" / "questions."
   Counts if each notice lands in a defensible column.
5. **Exit check:** One full stop done independently per the bar in (2).

## Practice sessions

### Practice A
Drawing counts with two verifiable details; the compare step must name one
match and add one missing detail. Sample: draws apple with red fill + brown
stem; adds the leaf after comparing.

### Practice B
Per object: two checkable non-visual details before the reveal. Sample
(pinecone): "It is bumpy. It feels rough / prickly." Wrong guesses are fine
if the observations were true — say so explicitly.

### Practice C
One true new detail per object via lens/close looking, drawn or described;
the tool/object distinction stated in the child's own words ("it helped my
eyes find more" or equivalent).

### Practice D
Adult finds the hidden object from the learner's description (two checkable
details). Error-analysis item: "It is nice" cannot guide a search; the
learner must name at least one needed detail ("What color? What shape?").

### Practice E
Two different observable rules named across two sorts (same bar as
Lesson 04). "Easiest to check" — any answer with a reason ("color, because
I can see it fast").

### Practice F
Sentence set (adult reads; learner files). Correct filing:
- "I notice the block is blue." → NOTICE
- "I wonder if the block will float." → WONDER
- "The block is tired." → neither (guess) — accept "wonder side only if
  recast as a question"
- "I notice the block has six flat sides." → NOTICE
- "I wonder who made this block." → WONDER
- "I notice the block is heavier than the ball." → NOTICE (felt comparison)
5 of 6 correct (counting the "tired" nuance as correct either way the
learner justifies it) + one explained filing = success.

## Project — My Observation Journal

Score with the [project rubric](project.md#rubric). Worked example of a
complete journal:
- **Page 1:** "I notice the shell is white. I notice it has a hole. I notice
  it feels bumpy." + drawing with white color and the hole shown.
- **Page 2:** "Without the lens I saw a smooth shell. With the lens I saw
  tiny ridges." + drawing of ridges.
- **Page 3:** "I wonder what animal lived in this shell." marked "cannot
  explore by looking" (or "could explore" if the learner proposes asking an
  expert / looking in a book — both marks are acceptable with a reason).
- **Page 4:** final portrait including the ridges.
- **Share:** "I noticed the hole. With the lens I found tiny ridges. I wonder
  what animal lived in it. I found the ridges by looking closer."

## Week-04 quiz

1. Three checkable notices (2 = unprompted; 1 = needed "anything else?"; 0 =
   fewer than two checkable).
2. Senses used: any correct pairings named (2 = two or more senses named
   correctly; 1 = one; 0 = none).
3. One true new lens detail (same bar as Lesson 02).
4. Two checkable details in the description (2 = two details; 1 = one; 0 =
   feelings/names only).
5. Sort + named observable rule (2 = rule named unprompted; 1 = named from
   choices; 0 = no observable rule).
6. Filing the adult's sentences: "I notice this object is smooth" = saw;
   "I wonder if it is heavy" = question (2 = both correct; 1 = one; 0 =
   neither).
7. Own notice + wonder (same bar as Lesson 05 exit check).

**Totals:** 14 max. 12–14 secure; 8–11 re-teach missed lessons; 0–7 re-teach
whole lessons (see the [teacher guide](teacher-guide.md#readiness-and-reteaching)).

## Unit assessment

Sample passing performance (score 2 per row):
- **1a:** "It is brown. It has bumpy spots. It smells like wood." (three
  checkable, unprompted)
- **1b:** "With the lens I see tiny holes I could not see before."
- **1c:** "It is brown, bumpy, and smaller than my hand" → adult picks the
  pinecone from three objects.
- **2:** "I sorted by color" → re-sort: "Now I sorted by big and little."
- **3a:** Points correctly; explains: "Brown you can see; 'what made the
  marks' is a question."
- **3b:** "I notice it is rough." + "I wonder how the marks got there."

**Totals:** 12 max. 9–12 ready for Unit 02; 6–8 proceed with weekly
observation warm-ups; 0–5 use flexible catch-up time first. See the
[assessment](assessments/unit-assessment.md#readiness-decision) and
[teacher guide](teacher-guide.md#readiness-and-reteaching).
