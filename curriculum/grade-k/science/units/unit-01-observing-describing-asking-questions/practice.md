# Practice sessions

Named 15–20-minute sessions referenced by the unit pacing. All responses may
be oral, pointing, drawing, or adult-scribed. The adult scribes exact words
the child dictates.

## Session A: journal drawing practice

*(Pacing: Sessions 2, and reused in the project.)*

1. **Adult-guided:** Choose one familiar object together. The adult models:
   "I will draw what I see, not what I imagine." Draws the object with two
   visible details.
2. **Independent drawing:** The learner draws the same object (or their own
   choice) with at least two visible details.
3. **Independent oral:** "Tell me two things in your drawing that are really
   on the object." The adult labels the drawing with the dictated words.
4. **Compare (adult-guided):** Hold the drawing next to the object. "What
   matches? What is missing?" Add one missing detail together.

**Success criterion:** The drawing shows two details the adult can verify on
the object. See [answer-key.md](answer-key.md#practice-a).

## Session B: mystery-bag senses game

*(Pacing: Session 3.)*

1. The adult places one familiar object (spoon, pinecone, sponge, shell) in a
   paper bag without the learner seeing.
2. **Touch only:** The learner reaches in (sight blocked) and describes what
   they feel: "It is bumpy. It is round." No guessing the name yet.
3. **Smell/listen:** "Smell it. Shake it gently. What do you notice?"
4. **Guess, then check:** The learner guesses, then looks. "Were your
   observations right? Which sense helped most?"
5. Repeat with a second object. **Error check:** If the learner guessed
   wrong, celebrate the observations that were still true ("It WAS bumpy —
   good observing!").

**Success criterion:** Two checkable touch/smell/hearing details per object
before the reveal. See [answer-key.md](answer-key.md#practice-b).

**Safety:** Bag objects are adult-chosen, familiar, clean, and safe to touch;
never use sharp, unknown, or allergen-risk items.

## Session C: close-looking practice

*(Pacing: practice woven into Sessions 5–7; also used in the project.)*

1. **Adult-guided:** Pick one object. "First look with eyes: tell me one
   thing. Now look through the lens: tell me one NEW thing."
2. **Independent:** The learner repeats the pair on a second object and
   draws the new detail.
3. **Independent oral:** "Without the lens I saw ___. With the lens I
   saw ___." (Sentence frames provided.)
4. **Compare:** "Did the lens change the object, or change what your eyes
   could find?" Accept: "It helped my eyes find more" — the tool shows what
   was already there.

**Success criterion:** One genuinely new detail per object, drawn or
described. See [answer-key.md](answer-key.md#practice-c).

## Session D: describe-and-draw practice

*(Pacing: Sessions 9–10; also used in the project.)*

1. **Adult-guided:** The adult describes a hidden object ("It is yellow, long,
   and curvy"); the learner finds it among three choices. Discuss which words
   helped.
2. **Independent:** The learner describes one object with two checkable
   details while the adult tries to find it (the Lesson 03 game, repeated).
3. **Independent drawing:** Draw the described object with the two details
   visible.
4. **Error analysis (adult-guided):** The adult gives a weak description
   ("It is nice") and asks: "Can you find it from my words? What details do
   you need?" The learner names at least one needed detail.

**Success criterion:** The adult can identify the object from the learner's
description alone. See [answer-key.md](answer-key.md#practice-d).

## Session E: sorting play

*(Pacing: review sessions and Session 13 warm-up.)*

1. **Independent:** Sort a mixed set by the learner's own rule; name the rule.
2. **Independent:** Re-sort the same set by a different rule; name the new rule.
3. **Adult-guided:** The adult sorts by a rule; the learner names it.
4. **Independent oral:** "Which rule was easiest to check with your eyes? Why?"

**Success criterion:** Two different observable rules named across the two
sorts. See [answer-key.md](answer-key.md#practice-e).

## Session F: notice-wonder card sort

*(Pacing: review sessions; Session 15 warm-up.)*

The adult reads six short sentences about a familiar object (three
observations, three guesses/questions, in mixed order). The learner files each
into the "I notice" or "I wonder" tray or column and explains one filing:
"How did you know?" Sentence sets are in the
[answer key](answer-key.md#practice-f).

**Success criterion:** At least 5 of 6 filed correctly, with one explained.
See [answer-key.md](answer-key.md#practice-f).

## Review circles (Sessions 4, 8)

- Each learner (or the single learner with the adult) shares one journal
  page: one notice, one wonder.
- The adult re-checks the week's exit checks for any learner not yet secure
  and re-teaches with the lesson's guided practice.
- End with: "What is one thing you observed this week that surprised you?"
