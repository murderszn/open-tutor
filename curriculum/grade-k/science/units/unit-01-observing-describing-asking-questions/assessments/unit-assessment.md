# Unit assessment — Unit 01: Observing, Describing, and Asking Questions

**Format:** three performance tasks, adult-observed and scribed; the learner
responds by speaking, pointing, drawing, or manipulating objects. **Time:**
15–20 minutes total (may be split across two short sittings). **Materials:**
two unfamiliar-but-safe objects (e.g., a pinecone and a piece of bark — not
used in lessons), the hand lens, 8–10 mixed sorting objects, paper and
crayons.

This is a **draft classroom check, not a standardized or validated test**.
It measures what this unit taught, nothing more.

## Task 1 — Observe and describe (Objectives 1, 2, 4)

The adult presents Object A (new to the learner).

1. "Use your senses. Tell me **three** things you notice." (Adult scribes.)
2. "Now look closer with the lens. Tell me **one new** thing."
3. "Describe Object A so someone in the next room could pick it out. Give at
   least **two** details." The adult tests the description by picking from
   Object A plus two distractors — the learner watches and confirms.

## Task 2 — Sort and name the rule (Objective 3)

The adult presents the mixed set.

1. "Sort these objects. Then tell me the rule you used."
2. "Now sort them a different way. Tell me the new rule."

## Task 3 — Notice and wonder (Objective 5)

The adult presents Object B (new to the learner).

1. The adult says two sentences: "I notice Object B is brown." / "I wonder
   what made these marks." The learner points to which is the observation
   and which is the question, and says how they knew. (Accept: "You saw
   brown"; "Wonder is a question.")
2. The learner makes **one** "I notice…" about Object B and **one** "I
   wonder…" about Object B.

## Scoring

| Task | 2 — shows skill | 1 — developing | 0 — not yet observed |
|---|---|---|---|
| 1a. Three notices | Three checkable notices, unprompted | Three with a prompt ("anything else?") or one is a guess | Fewer than two checkable notices |
| 1b. Closer look | One genuinely new detail via lens/close looking | New detail with heavy adult help | No new detail |
| 1c. Description | Adult identifies Object A from the description alone | Identifies with one follow-up question | Cannot identify |
| 2. Sorting | Two different observable rules, both named | One rule named; second sort copies the first | No observable rule named |
| 3a. Filing | Correctly files both adult sentences and explains one | Files correctly, explanation unclear | Mis-files |
| 3b. Own notice/wonder | One checkable notice + one real question | Correct with a sentence starter | Missing or mixed up |

**Total: ___ / 12.** The [answer key](../answer-key.md#unit-assessment) gives
acceptable-response criteria and worked scoring examples.

## Readiness decision

- **9–12:** ready for Unit 02 (pushes and pulls). The learner's observation
  skills are secure enough to carry into investigations.
- **6–8:** proceed to Unit 02 but keep a weekly 5-minute observation warm-up
  from this unit's practice sessions; re-check Objective 2 or 5 (whichever
  scored 0–1) during the track's flexible weeks.
- **0–5:** use the track's flexible catch-up time to re-teach the missed
  objectives with the lessons' guided practice before starting Unit 02. See
  the [teacher guide](../teacher-guide.md#readiness-and-reteaching).

Record the score and the re-teach plan privately — never in this repository.
