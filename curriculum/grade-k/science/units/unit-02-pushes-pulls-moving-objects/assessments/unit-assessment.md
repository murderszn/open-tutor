# Unit assessment — Unit 02: Pushes, Pulls, and Moving Objects

**Format:** performance tasks; the adult sets up, the learner does and
tells; the adult scribes. **Time:** 15–20 minutes (may split across two
sittings). Materials: toy car, ball, ramp, string toy, two targets, a block
and a cushion bumper, tape.

**Scoring (for the adult):** each task scores 2 / 1 / 0. The
[answer key](../answer-key.md#unit-assessment) gives acceptable responses
and scoring detail. This assessment is a teaching tool, not a standardized
or validated test.

## Tasks

### Task 1 — Name the moves (Objective 1)

The adult performs six quick actions; the learner says **"push"** or
**"pull"** for each: (a) push a car away, (b) pull the string toy closer,
(c) push a ball, (d) pull a drawer/sleeve, (e) stop a rolling ball with a
flat hand, (f) pull the truck toward a target.

- **2** = 5–6 correct. **1** = 3–4 correct. **0** = 0–2 correct.

### Task 2 — Strength test (Objective 2)

"Show me a **gentle** push and a **strong** push with the same car from
this line. Before you push: which one will go farther? Now test."

- **2** = predicts the strong push, tests, and names strength as the
  reason ("the push was stronger"). **1** = shows the result but cannot say
  why. **0** = cannot complete the comparison.

### Task 3 — Pull it there (Objective 3)

"Pull the toy to the red box." Then: "Now make it go to the blue box
instead. What changed?"

- **2** = pulls to both targets and names the direction change ("I pulled
  it toward the blue box"). **1** = pulls to both with prompting but cannot
  name the change. **0** = cannot direct the pull to a named target.

### Task 4 — Keep it fair (Objective 4)

With the adult, the learner runs the ramp test twice with the same setup.
Then the adult asks: "What did we keep the **same**? What did we
**change**?"

- **2** = names both same-things (same ball, same ramp) and the changed
  push. **1** = names one of the two. **0** = names neither.

### Task 5 — Build the turn (Objective 5)

"Here is the problem: this rolling ball must **turn left**. Build
something that makes it turn. Test it. Did it work the way you wanted? If
not, change one thing and test again."

- **2** = builds a bumper/turn, tests, judges "worked / not yet," and
  improves (or explains why the first build worked). **1** = builds with
  heavy adult direction; tests once. **0** = does not attempt a solution.

## What the results mean

- **9–10:** ready to move on to Unit 03.
- **6–8:** mostly secure — use Session 16's re-teach time on the missed
  tasks, then move on.
- **0–5:** use the track's flexible catch-up time to re-teach the missed
  objectives' lessons before Unit 03. See the
  [teacher guide](../teacher-guide.md#readiness-and-reteaching).
