# Answer key — Unit 02: Pushes, Pulls, and Moving Objects

For the guiding adult only. Learner-facing pages never link here. Every
task below was solved independently against the lesson or assessment text
and reconciled before this unit was marked delivered.

## Lesson 01

1. Guided — push: the child with the red car (it moves **away**). Pull:
   the hand, string, and blue truck (it moves **closer**). Pointing counts.
2. Independent pointing — any pushable (door, chair, toy, ball) and any
   pullable (drawer, wagon, sleeve, string toy) in the room; the learner
   must act or point AND say the word.
3. Independent acting — "push" while the car moves away; "pull" while it
   comes back. Accept the motions even if the words lag a beat.
4. Independent oral — the push made the car **start moving** toward the
   ramp. Accept: "it moved," "it went to the ramp."
5. Error-analysis — the learner must correct the adult: "No — it came
   closer, so it is a **pull**." Any correction naming the pull counts.
6. Application — the **cushion** stopped the ball; it pushed back. Accept:
   "the gray pillow stopped it."
- Exit — one push + one pull, acted out. Accept any correct pair.

## Lesson 02

1. Guided — the **strong** push's mark is farther; reason: "the push was
   stronger." Accept: "you pushed harder."
2. Three gentle pushes — marks all near the start and close together.
   Accept: "they are close / in a bunch."
3. Prediction — must predict **strong** goes farther, then confirm by
   testing. A wrong prediction followed by an honest correction still
   counts (the test is the teacher).
4. Ramp ball — the strong push sends the ball farther; changed: **only the
   push**; same: the ball and the ramp.
5. Error-analysis — the unfair change is the **floor/surface** (bumpy rug
   vs. smooth floor). Accept: "you changed the floor." The conclusion
   "strong pushes go less far" is rejected because the test was unfair.
6. Application — gentle examples: passing a glass, pushing a swing for a
   baby, placing a puzzle piece. Strong examples: pushing a heavy door,
   kicking a ball far. Any reasonable pair counts.
- Exit — gentle and strong pushes shown; strong mark farther; reason named.

## Lesson 03

1. Guided — pulls the toy to the named target and says, e.g., "I pulled it
   toward the red box."
2. Direction change — pulls to the second target; names the change:
   "the direction" (accept pointing between the two targets + "it went
   there instead").
3. Push/pull + direction — toward the door box = **push** (away); back =
   **pull** (toward me). Both labels and both directions required.
4. Sorting game — 3 of 4 correct calls of "push"/"pull" with a direction
   word ("away"/"toward").
5. Drawing — two marks pointing two different ways, matching the two
   targets. Any arrow-like marks count.
6. Application — drawer **open** = pull; drawer **closed** = push.
- Exit — two different targets, both directions named.

## Lesson 04

1. Guided — three marks close together; "yes, they are close."
2. Three strong pushes — the **strong set** is farther from the start.
3. Same — any two of: same ball, same ramp, same kind of push. Accept
   "same hill," "same toy."
4. Changed — **the push** (gentle → strong). Only one change.
5. Error-analysis — the adult **raised the ramp**; that is the unfair
   change. Accept: "you moved the hill." The test must be re-run at the
   original height.
6. Application — any home test plan naming what stays the same, e.g.,
   "roll my ball down the couch three times — same ball, same couch."
- Exit — runs three trials; names same ball/ramp and the changed push.

## Lesson 05

1. Guided — judgment must be "yes, it worked" or "not yet," plus one
   planned change if not yet.
2. Build and test — honest report. A "not yet" with a reason counts as
   much as a "yes."
3. Improve — one deliberate change (tilt/move/swap the bumper) + re-test;
   "better / worse / same" reported.
4. Compare — the **cushion stops** the ball; it does not turn it. Accept:
   "it stopped." (Links to Lesson 01's picture.)
5. Record — a path drawing showing straight-then-turn, with the adult's
   scribed description matching the drawing.
6. Application — any reasoned slide idea (safety, fun, rain). This is
   engineering talk; there is no wrong answer with a reason.
- Exit — "did it work the first time?" + "what did you change?" Both
   answered honestly.

## Lesson 06

2. Course run — all four stations completed with the moves named (push,
   turn, pull, stop). Order may vary with the course layout.
3. Strength control — the ball stops **before** the tape line (a controlled
   gentle push). Near-misses with clear intent count.
4. Direction choice — pulls to the chosen target; names it and gives a
   reason ("closer," "I like the red box").
5. Sort-from-memory — (a) child + red car = **push**; (b) hand + string =
   **pull**; (c) ball + cushion = **a push stopped it** (accept "push" or
   "it stopped").
- Exit — any two distinct moves from: push harder/softer, pull, change
   direction (bumper/turn), stop.

## Practice sessions

- Session A — one push + one pull found and named in the room; 4 of 5 in
  the speed round.
- Session B — ball started with a push, stopped with a push; the two jobs
  named.
- Session C — gentle marks close together and short; strong marks farther;
  "the ball changed" (or "floor changed") spotted as unfair in the error
  check.
- Session D — the week's exit check re-passed; one notice + one wonder
  given.
- Session E — invented station named (push/pull/turn/stop) and demonstrated.

## Project — My Motion Machine

Score each rubric criterion 2 / 1 / 0 as described in
[project.md](project.md#rubric). Guidance on judgment calls:

- **Plan and carry out (2):** a stated or drawn path exists BEFORE building
  (journal page), the course is built, and at least one test roll is
  recorded. (1): the adult had to supply the plan; the learner built and
  tested. (0): no plan and no recorded test.
- **Compare strength (2):** the learner chose a push strength deliberately
  and said why ("gentle so it stays in the box"). (1): used different
  strengths without a reason. (0): strength never considered.
- **Change direction (2):** a bumper is placed and the ball's direction
  visibly changes at it. (1): bumper placed but the turn is accidental or
  unclear. (0): no turn attempted.
- **Test as intended + improve (2):** "worked / not yet" judged after a
  test AND one change made + re-tested. (1): tested but never judged or
  never changed. (0): no test-and-improve cycle.
- **Communicate (2):** the share names the path, the bumper's job, and the
  change made. (1): share needs heavy prompting. (0): does not share.

## Week-04 quiz

1. Push = the car moving **away**; pull = the string toy coming
   **closer**. Both labeled.
2. Start: a push. Stop: "I pushed it" / "my hand pushed it." (A push
   stopped it — the key idea.)
3. Predict **strong** goes farther; test confirms. Honest correction after
   a wrong prediction counts.
4. Truck pulled to the red box, then the blue box; "the direction" changed
   (accept pointing at the new target).
5. Same: the **ball/car** and the **ramp/floor**. Accept "same toy, same
   hill."
6. A built turn (bumper/block); the ball turns; "worked / not yet" judged
   honestly.
7. Any real push + pull from home (push door, pull drawer, etc.).

Bands: 12–14 secure; 8–11 re-teach missed lessons' guided practice, then
assess; 0–7 re-teach whole lessons, consider flexible catch-up.

## Unit assessment

Scoring detail per task is in
[assessments/unit-assessment.md](assessments/unit-assessment.md#tasks);
this key records the expected content:

1. **Name the moves** — (a) push, (b) pull, (c) push, (d) pull, (e) push
   (stopping is a push), (f) pull. 5–6 correct = 2; 3–4 = 1; 0–2 = 0.
2. **Strength test** — predicts **strong** goes farther; reason: "the push
   was stronger/harder." Result shown but no reason = 1.
3. **Pull it there** — both targets reached; direction change named. Needs
   prompting but reaches both = 1.
4. **Keep it fair** — same: **ball** and **ramp**; changed: **the push**.
   Both same-things + the change = 2; one of the two parts = 1.
5. **Build the turn** — bumper built, ball turns, "worked / not yet"
   judged, one improvement tested (or a clear explanation of why the first
   build worked). Heavy adult direction = 1.

Bands: 9–10 ready for Unit 03; 6–8 re-teach missed tasks in Session 16,
then move on; 0–5 flexible catch-up before Unit 03.
