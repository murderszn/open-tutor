# Lesson 03 — Pulls in different directions

**Goal (read to the learner):** "Pulls can go different ways. Pull one way
and a toy goes one way; pull another way and it goes a different way. You
will change where a toy goes by changing your pull."

**Time:** 15–20 minutes. **Materials:** a toy truck or car with a string
tied to it, two targets (shoeboxes, cushions, or taped squares on the
floor), open floor space.

## Readiness check (2 minutes)

"Hold the string. Pull the toy toward you." Adult: "The toy came *toward
you*. **Direction** means *the way something goes*." Say the word together:
"di-REC-tion."

## Teach and model

Explain in your own words: *A pull brings something toward the person
pulling. Stand somewhere else, and the same pull sends the toy a different
way — pulls have **directions**. Pushes and pulls can **change the
direction** something moves.*

**Modeled example 1 — pull toward me.** Adult pulls the toy toward
themselves: "I pull toward **me**. The toy comes to **me**. The direction
is 'toward me.'" (Modeled reasoning: name the puller, name the direction,
name the result.)

**Modeled example 2 — pull toward the door.** Same toy, same string; the
adult walks to the other side and pulls toward a target box: "Now I pull
toward the **box**. The toy goes to the **box**. Same string, same toy —
*different direction*, different place. The pull changed the direction."

## Guided practice (adult-guided)

1. **Guided:** The adult names a target ("the red box"). The learner pulls
   the toy toward it and says, "I pulled it toward the red box." Repeat for
   the second target.

## Independent practice

2. **Independent direction change:** "Pull the toy to the door box. Now —
   make it go to the window box instead." The learner says what changed:
   "The direction."
3. **Independent push/pull + direction:** "Push the toy toward the door
   box. Now pull it back to you." Then: "Was each move a push or a pull?
   Which way did it go?" (Push — away, toward the box. Pull — toward me.)
4. **Independent sorting game:** The adult does four quick moves — push a
   car, pull the string, push a ball, pull a wagon or sleeve. The learner
   calls out "push" or "pull" for each and names the direction ("away from
   you" / "toward you"). Aim for 3 of 4.
5. **Independent drawing (adult may scribe):** "Draw two arrows on paper —
   one arrow for the pull toward the red box, one for the pull toward the
   window box. Arrows show directions." (Accept any marks that point two
   different ways.)

## Application

6. **Real-life transfer:** "Think of a door. Push it — it swings away.
   Pull it — it swings toward you. Open this drawer: is that a push or a
   pull?" (Pull — it comes toward you.) "Close it?" (Push.)

## Exit check

The learner pulls the toy toward a named target and names the direction
("toward the red box"), then pulls it toward a different target and names
that direction. The adult records the two directions.

## Supports and extension

- **Reading/language access:** "Direction" is taught with pointing first;
   pair with home-language words and the two hand motions (away = push,
   toward = pull).
- **Alternate response mode:** Pointing toward the target counts as naming
  the direction; the adult scribes. The drawing task may be done entirely
  with finger-pointing on the floor.
- **Extension:** "Can you pull the toy *around* the box?" (A curved path —
  previews Lesson 05 turns.) Or: two learners pull two toys toward the
  same box at the same time — "What happens when they meet?" (They bump;
  a preview of pushes changing motion.)
- **Table and floor variants:** Table-top with a small truck and two cup
  targets, or the full floor course; both work.

## Teacher note

**Common misconception:** "Pulls always come toward *me*." Redirect: "Toward
*the puller*. Watch me stand over here and pull — now toward goes that
way." Let the learner pull from three different spots.

**Common misconception:** "Direction means fast or slow." Redirect: "Speed
is how fast; direction is *which way*. The toy can go toward the box fast
or slow — the direction is still 'toward the box.'"

**Answer-key reference:** [`../answer-key.md`](../answer-key.md#lesson-03) —
pulling toward different targets sends the toy to different places; each
answer must name the direction (toward the box / toward the window), not
just "over there."
