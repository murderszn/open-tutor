# Answer Key — Unit 03: Letter Recognition and Sound Correspondences

Adult-facing. Keep separate from learner materials. Every answer below
was solved independently from the lesson, practice, quiz, and
assessment items and reconciled against them. Where two answers are
correct (C or K for /k/), both are listed and either is accepted.

## Lesson 01 — The whole uppercase alphabet

- **Guided 1:** second half in order: N, O, P, Q, R, S, T, U, V, W,
  X, Y, Z.
- **Guided 2:** whole alphabet in order: A–Z.
- **Guided 3:** R, B, W, E, X (names are the letters themselves).
- **Guided 4:** Q — second half (N–Z); C — first half (A–M);
  Z — second half; H — first half; U — second half.
- **Guided 5:** find M, Z, G, T, A.
- **Independent 1:** N, O, P, Q, R.
- **Independent 2:** Z, S, K, V, D.
- **Independent 3:** point to W, B, Y, J, R.
- **Independent 4:** A–Z in order.
- **Independent 5:** any three cards, named and returned to the
  correct arc positions.
- **Exit 1:** P, A, X, L, U. **Exit 2:** 26 letters. **Exit 3:** last
  letter Z; before Z is Y.

## Lesson 02 — The lowercase alphabet

- **Guided 1:** A → a; M → m; S → s; T → t; G → g.
- **Guided 2:** a, b, c, d, e. **Guided 3:** m, s, g, k, z.
- **Guided 4:** b = stick first, belly second; d = belly first,
  stick second (four rounds each, random order).
- **Guided 5:** looks-like-partner pile: c, o, s; looks-different
  pile: a, g, y.
- **Independent 1:** N–Z lowercase matched to N–Z uppercase.
- **Independent 2:** r, p, q, f, j, w.
- **Independent 3:** point to e, h, t, n, x.
- **Independent 4:** d, b, q, p, b, d.
- **Independent 5:** a–z in order.
- **Exit 1:** a, m, g, s, q, z. **Exit 2:** b's tricky partner is d.
  **Exit 3:** big R's partner is r.

## Lesson 03 — Consonant sounds, A to M

- **Guided 1:** B, /b/, ball; C, /k/, cat; D, /d/, dog; F, /f/,
  fish.
- **Guided 2:** G, /g/, goat; H, /h/, hat; J, /j/, jam; K, /k/,
  kite.
- **Guided 3:** L, /l/, lion; M, /m/, moon; then all ten in order.
- **Guided 4:** /l/ → L; /g/ → G; /j/ → J; /m/ → M; /k/ → C or K
  (either accepted; *cat* uses C, *kite* uses K).
- **Guided 5:** *fish* — /f/ — F; *moon* — /m/ — M; *ball* — /b/ —
  B; *goat* — /g/ — G; *kite* — /k/ — K (or C).
- **Independent 1:** B, /b/, ball; C, /k/, cat; D, /d/, dog;
  F, /f/, fish; G, /g/, goat.
- **Independent 2:** H, /h/, hat; J, /j/, jam; K, /k/, kite;
  L, /l/, lion; M, /m/, moon.
- **Independent 3:** K → /k/; B → /b/; M → /m/; D → /d/; J → /j/.
- **Independent 4:** /f/ → F; /l/ → L; /g/ → G; /h/ → H; /k/ → C
  or K.
- **Independent 5:** ball → B; cat → C; fish → F; lion → L;
  moon → M.
- **Exit 1:** B → /b/; G → /g/; K → /k/; M → /m/; F → /f/.
  **Exit 2:** /j/ → J; /l/ → L. **Exit 3:** *dog* — /d/ — D.

## Lesson 04 — Consonant sounds, N to Z

- **Guided 1:** N, /n/, nose; P, /p/, pig; Q, /kw/, queen; R, /r/,
  rabbit.
- **Guided 2:** S, /s/, sun; T, /t/, turtle; V, /v/, violin; W,
  /w/, web.
- **Guided 3:** X, /ks/, fox; Y, /y/, yes; Z, /z/, zebra; then all
  eleven in order.
- **Guided 4 (throat check):** /p/ — still (voiceless), P;
  /b/ — buzz (voiced), B; /t/ — still, T; /d/ — buzz, D; /s/ —
  still, S; /z/ — buzz, Z.
- **Guided 5:** *sun* — /s/ — S; *zebra* — /z/ — Z; *web* — /w/ —
  W; *nose* — /n/ — N; *turtle* — /t/ — T.
- **Independent 1:** N, /n/, nose; P, /p/, pig; Q, /kw/, queen;
  R, /r/, rabbit; S, /s/, sun.
- **Independent 2:** T, /t/, turtle; V, /v/, violin; W, /w/, web;
  X, /ks/, fox; Y, /y/, yes; Z, /z/, zebra.
- **Independent 3:** Z → /z/; Q → /kw/; S → /s/; V → /v/;
  R → /r/.
- **Independent 4:** /w/ → W; /ks/ → X; /n/ → N; /y/ → Y;
  /t/ → T.
- **Independent 5:** pig → P; sun → S; fox → X (X is at the end of
  *fox*); zebra → Z; web → W.
- **Exit 1:** S → /s/; Q → /kw/; Z → /z/; N → /n/; X → /ks/.
  **Exit 2:** /kw/ → Q (with U); /r/ → R. **Exit 3:** *web* —
  /w/ — W.

## Lesson 05 — Short vowel sounds

- **Guided 1:** A, /a/, apple; E, /e/, egg; I, /i/, igloo; O, /o/,
  octopus; U, /u/, umbrella.
- **Guided 2:** /a/ → A; /o/ → O; /u/ → U; /e/ → E; /i/ → I.
- **Guided 3:** *ant* — /a/ — A; *pen* — /e/ — E; *pin* — /i/ —
  I; *mop* — /o/ — O; *cup* — /u/ — U.
- **Guided 4:** apple → A; egg → E; igloo → I; octopus → O;
  umbrella → U.
- **Guided 5:** c-__-t → /a/ (*cat*); b-__-d → /e/ (*bed*);
  p-__-n → /i/ (*pin*); h-__-t → /o/ (*hot*); c-__-p → /u/
  (*cup*).
- **Independent 1:** as Guided 1, each vowel in turn.
- **Independent 2:** O → /o/; A → /a/; U → /u/; E → /e/;
  I → /i/.
- **Independent 3:** *hat* — /a/; *bed* — /e/; *sit* — /i/;
  *dog* — /o/; *bug* — /u/.
- **Independent 4:** ant → A; pen → E; pin → I; mop → O;
  cup → U.
- **Independent 5:** any vowel, drawn and spoken (name, short sound,
  word).
- **Application (vowel doctor):** *cat* → A; *bed* → E; *pig* → I;
  *dog* → O; *sun* → U.
- **Exit 1:** short sounds A → /a/, E → /e/, I → /i/, O → /o/,
  U → /u/. **Exit 2:** *bed* — /e/ — E. **Exit 3:** *cup* —
  /u/ — U.

## Lesson 06 — Long vowel sounds and letter–sound match

- **Guided 1:** A, /ā/, cake; E, /ē/, bee; I, /ī/, bike; O, /ō/,
  rope; U, /ū/, unicorn.
- **Guided 2:** *apple* — short, A; *cake* — long, A; *egg* —
  short, E; *bee* — long, E; *igloo* — short, I; *bike* — long, I;
  *octopus* — short, O; *rope* — long, O; *umbrella* — short, U;
  *unicorn* — long, U.
- **Guided 3:** B → /b/; R → /r/; O (long) → /ō/; U (short) →
  /u/; Z → /z/.
- **Guided 4:** /v/ → V; /ā/ (long A) → A; /g/ → G; /u/ (short
  U) → U; /ks/ → X.
- **Guided 5 (writing):** /m/ → M; /s/ → S; /a/ (short) → A.
- **Independent 1:** as Guided 1, each vowel in turn.
- **Independent 2:** short pile: apple, egg, igloo, octopus,
  umbrella; long pile: cake, bee, bike, rope, unicorn.
- **Independent 3:** K → /k/; E (long) → /ē/; P → /p/;
  I (short) → /i/; W → /w/.
- **Independent 4:** /d/ → D; /ō/ (long O) → O; /f/ → F;
  /e/ (short E) → E; /y/ → Y.
- **Independent 5 (writing):** /b/ → B; /t/ → T; /o/ (short) → O;
  /n/ → N; /i/ (short) → I.
- **Application (race):** any called sound → its letter card and
  a picture card starting with that sound (e.g., /s/ — S — sun).
- **Exit 1:** long sounds A → /ā/, E → /ē/, I → /ī/, O → /ō/,
  U → /ū/. **Exit 2:** *cake* — long — A. **Exit 3:** /z/ → Z
  ("Z, /z/").

## Practice sessions

- **Session A:** arc A–Z; removed cards D, J, Q, T, W named and
  replaced; speed round B, R, Z, E, M, X; before/after M → L, N;
  before/after S → R, T; before/after Z → Y, and "nothing — Z is
  last."
- **Session B:** hunts F, A, Z, K, P, U; then M, S, G; adult-hunt
  check (learner verifies); missing letter round 1 → Q, round 2
  → H; three favorite letters with a word each (any sensible word).
- **Session C:** mixed naming P, A, X, L, U, R, Z, C; 26 letters;
  first A; last Z; re-drill of missed letters only.
- **Session D:** A–M then N–Z partners matched; mixed g → G,
  r → R, y → Y, e → E, t → T; hold-ups B → b, K → k, W → w,
  D → d, H → h; fixes: b pairs with B (not D), k pairs with K
  (not T).
- **Session E:** b/d drill (stick first — b; belly first — d);
  p/q drill (four rounds each); sort 3 each of b, d, p, q into
  four piles; circle task: circle only the b's among the adult's
  written b, d, p, q (the count depends on the adult's written
  order — the adult circles the key first and checks against it);
  story with a b word and a d word (any sensible sentence).
- **Session F:** lowercase a, m, g, s, q, z, r, w; uppercase C,
  U, Y, F, N, J; partners R → r, L → l, E → e, V → v;
  tricky-pair check d, b, q, p, b, d.
- **Session G:** animals left to right: cat, dog, pig, frog;
  first sounds /k/, /d/, /p/, /f/; letters cat → C (K also says
  /k/; C is the answer because *cat* is spelled with C), dog → D,
  pig → P, frog → F; lip-sound find → pig only (/p/);
  extra words: cat — cake, dog — door, pig — pie, frog — fish
  (any sensible word with the same first sound counts).
- **Session H:** re-teach per the teacher guide's triggers; no
  fixed key — the adult re-tests only the items missed that week.
- **Session I:** uppercase sprint A, C, F, J, M, P, R, U, W, Z;
  lowercase sprint b, e, g, k, n, q, s, t, x, y; sound sprint
  B → /b/, S → /s/, Q → /kw/, Z → /z/, V → /v/, R → /r/,
  N → /n/, X → /ks/; vowel sprint (short and long for A, E, I,
  O, U as named by the adult); writing sprint /m/ → M,
  /a/ (short) → A, /t/ → T, /o/ (short) → O, /s/ → S.

## Formative quiz (assessments/week-04_quiz.md)

1. T, A, Z, M, Q (names are the letters themselves).
2. g, s, q, a, w.
3. d, b, b, d.
4. B → /b/; S → /s/; G → /g/; Z → /z/.
5. M → /m/; Q → /kw/; X → /ks/; V → /v/.
6. Short: A → /a/; E → /e/; I → /i/; O → /o/; U → /u/.
7. Long: A → /ā/; E → /ē/; I → /ī/; O → /ō/; U → /ū/.
8. /r/ → R; /k/ → C (K also says /k/; either accepted);
   /n/ → N; /y/ → Y.
9. *sun* — /s/ — S; *pig* — /p/ — P; *web* — /w/ — W;
   *fox* — /ks/ — X (at the **end** of the word).
10. Writing: /m/ → M; /a/ (short) → A; /t/ → T; /s/ → S;
    /o/ (short) → O.

## Unit assessment (assessments/unit-assessment.md)

- **Task 1:** all 26 uppercase names, in order and shuffled
  (scoring bands in the assessment).
- **Task 2:** all 26 lowercase names, in order and shuffled, plus
  b, d, p, q twice each in random order (the adult's order is the
  key for that sitting).
- **Task 3:** consonant sounds: B → /b/, C → /k/, D → /d/,
  F → /f/, G → /g/, H → /h/, J → /j/, K → /k/, L → /l/,
  M → /m/, N → /n/, P → /p/, Q → /kw/, R → /r/, S → /s/,
  T → /t/, V → /v/, W → /w/, X → /ks/, Y → /y/, Z → /z/.
- **Task 4:** short: A → /a/, E → /e/, I → /i/, O → /o/,
  U → /u/; long: A → /ā/, E → /ē/, I → /ī/, O → /ō/,
  U → /ū/.
- **Task 5A (sound → letter):** /b/ → B; /f/ → F; /l/ → L;
  /n/ → N; /s/ → S; /w/ → W; /z/ → Z; /a/ (short) → A;
  /o/ (short) → O; /ā/ (long A) → A.
- **Task 5B (letter → sound):** D → /d/; H → /h/; J → /j/;
  K → /k/; P → /p/; R → /r/; T → /t/; V → /v/; Y → /y/;
  E (long) → /ē/.
- **Task 5C (writing):** /b/ → B; /d/ → D; /g/ → G; /m/ → M;
  /p/ → P; /r/ → R; /e/ (short) → E; /u/ (short) → U.
