# Teacher Guide — Unit 03: Letter Recognition and Sound Correspondences

Adult-facing. Learner materials never link here with answers visible; keep
this file and [answer-key.md](answer-key.md) out of the learner's reach.

## How this unit runs

Four 15–20-minute sessions per week. Every session opens with the same
30-second ritual — the adult holds up one letter and the learner says
its name and its sound ("M, /m/") — and closes with one sentence of
specific praise tied to the objective ("You found every lowercase
partner all by yourself"). This unit is **eyes and ears together** for
the first time: Unit 01 taught letter names, Unit 02 taught sounds in
speech, and now each letter earns its sound.

**Pacing judgment:** the [16-session pacing](README.md#16-session-pacing-4-weeks--4-sessions-15-20-minutes-each)
puts Lesson 04 and Lesson 05 together in Session 13. That works only
if Lesson 04 is taught briskly — the name–sound–word routine is already
familiar from Lesson 03, so the second-half chant can move fast — and
Lesson 05 contributes only its five action chants and one sort in that
session. If the learner tires, move Lesson 05's sort to the Session 12
re-teach slot and use Session 13 for Lesson 04 alone; the unit's design
survives the swap, and Lesson 06 in Session 14 carries the full vowel
work.

## Session-by-session guidance

- **Sessions 1–4 (uppercase):** the song is a scaffold, not the skill.
  Always follow singing with mixed-up cards. Drill L–M–N slowly; the
  song blurs them into "elemeno."
- **Sessions 5–8 (lowercase):** keep the belly/stick rule worded
  identically every time ("stick first — b; belly first — d").
  Changing the wording resets the learning. Check the tricky pairs
  before any quiz, not after.
- **Sessions 9–10 (consonants A–M + sound sort):** use the mirror for
  every new sound in the first week. The throat check (buzz = voiced)
  is your best tool for P/B, T/D, and later V/F, S/Z.
- **Session 11/14 (project):** scribe the learner's dictated
  name/sound/word lines verbatim, large print. The learner's letter
  attempts count even when shaky — correct formation by modeling,
  not by erasing the child's work.
- **Session 13 (consonants N–Z + short vowels):** teach Q as "Q with
  U, /kw/" and X as an ending sound (*fox*) from the first minute;
  both stall if introduced vaguely. Accept a /w/-like /r/ without
  comment beyond modeling the adult form.
- **Sessions 15–16 (check + assess):** do the quiz in the morning
  slot and the project share after a break. Split the unit assessment
  across two sittings if the learner tires.

## Misconceptions — quick reference

| You see | It usually means | Do this |
|---|---|---|
| Sings the alphabet, cannot name Q alone | Song memorized, letters not recognized | Mixed-up cards, not more singing |
| Says "bee" when asked for B's sound | Letter name given for sound | "That is the name. The sound is /b/ — a little pop." |
| Calls lowercase a a "different letter" | Shape change read as identity change | "Same name, different shape — partners." |
| Reverses b/d (or p/q) repeatedly | Normal visual confusion at age five | Same belly/stick rule every session; watch item, not verdict |
| Insists only one letter can say /k/ | One-to-one assumption | "Sounds can have more than one letter. C and K are both /k/." |
| Hunts for a word starting with /ks/ | X taught as an initial sound | Teach X as an ending sound (*fox*, *box*) |
| Says /ay/ for A's short sound | Alphabet-song habit | "That is A's name-song. The short sound is /a/ — bite the apple." |
| Calls every vowel long after Lesson 06 | Name rule overgeneralized | Keep the short/long picture sort in daily review |
| Matches letters → sounds but not sounds → letters | Chant memorized, correspondence half-built | Sound → letter games; quiz tests both directions on purpose |
| Pronounces /r/ as /w/ | Developmental, common at five | Accept, model /r/, never drill to frustration |

## Re-teach triggers

- **Uppercase naming below 18/26 shuffled:** repeat Sessions A–C
  with only the missed letters, in groups of three, for one flexible
  week before Unit 04.
- **Lowercase naming below 18/26 shuffled, or tricky pairs below
  4/8:** repeat Sessions D–E with only the missed pairs; keep the
  belly/stick rule wording identical.
- **Consonant sounds below 15/21:** repeat Lessons 03–04 guided
  practice with the mirror and throat check, five letters at a time.
- **Vowel sounds below 7/10:** repeat the Lesson 05 action chant and
  the Lesson 06 short/long sort daily for a week; check /a/ vs. /o/
  with the mirror.
- **Matching one-directional:** run sound → letter games only (the
  missing direction) for a week; do not re-drill the direction that
  already works.
- **Writing below 5/8:** dictate only three sounds per session and
  let the learner trace the adult's model first, then write alone.
- **b/d reversals still frequent after Session 8:** note as a watch
  item for Unit 04 (where letter shapes matter for word-building),
  not as a failure; keep the rule in every review.

## Readiness for Unit 04

The learner is ready for Unit 04 (blending, segmenting, regular CVC
words) when the unit assessment shows Tasks 1–2 at "secure" and Tasks
3–5 at "secure" or "nearly there." A "re-teach" result on any task
means a flexible week on that objective first — Unit 04 assumes every
letter's name and primary sound are available on demand, and blending
without them is frustration, not teaching. If the learner is secure on
letters but shaky on short vowels, Unit 04's first week will still be
hard: short vowels are the middle of every CVC word, so prioritize
vowel re-teaching over speed.
