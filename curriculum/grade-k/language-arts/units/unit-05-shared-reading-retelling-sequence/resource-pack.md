# Resource Pack — Unit 05: Shared Reading, Retelling, and Sequence

## Summary

**Goal:** give the guiding adult free, no-account routes to support
kindergarten shared reading, retelling with key details, sequencing
with *first / next / last*, picture talk, author/illustrator roles,
comparing two stories, and answering questions from information.
**Age fit:** kindergarten (about 5–6); all items are read-aloud,
oral, picture-based, or adult-facing routines, with no reading
required of the learner beyond pointing at pictures and word cards
the adult reads aloud.

## Web references

Checked 2026-11-04 unless noted (all reachable in a text or live
browser; noted where a page could not fully render).

1. **Understood — "Retelling: An evidence-based literacy strategy"**
   `https://www.understood.org/en/articles/how-to-teach-retelling`
   *Why:* an adult-facing routine for retelling fiction and
   nonfiction — pre-read for key details, first retell unaided,
   re-read, then retell with supports (five-finger retell, picture /
   props retell, sequence retell with *first / then / next /
   last*). It names the kindergarten standards directly (RL.K.2,
   RI.K.2) and its differentiation table matches this unit's
   supports. Verified live 2026-11-04. Free, no account.
2. **KnowItAll (South Carolina ETV) — "Retelling" lesson**
   `https://www.knowitall.org/lessons/retelling`
   *Why:* a K–2 lesson plan built on one idea this unit uses
   throughout: retell a text beginning, middle, and end using key
   details, with a beginning/middle/end chart filled in together
   after the read-aloud, then a modeled retell. Verified live
   2026-11-04. Free, no account.
3. **Colorín Colorado — "Getting Ready to Read: Using Storytelling,
   Rhymes, and More!"**
   `https://www.colorincolorado.org/article/getting-ready-read-using-storytelling-rhymes-and-more`
   *Why:* family-facing guidance on storytelling at every age —
   listening and responding, reading together, asking and
   answering questions, sharing family stories, and acting stories
   out with props — the home version of this unit's shared-reading
   routine. Verified live 2026-11-04. Free, no account; also
   available in Spanish.
4. **Byram Hills Central School District — "Bobcat-Ready for
   Kindergarten: Retelling a Story" (PDF)**
   `https://www.byramhills.org/uploaded/CH/Bobcat_Ready_Docs/Bobcat-Ready_for_Kindergarten_Retelling_a_Story.pdf`
   *Why:* a kindergarten-readiness handout that mirrors this unit's
   method step for step: choose a familiar story, read aloud, ask
   "What happened first / next / last?", retell together taking
   turns, and use props or three-scene drawings. Found via search
   2026-11-04; adult previews before printing. Free, no account.
5. **Common Core State Standards for English Language Arts —
   kindergarten reading standards (framework reference)**
   `https://www.thecorestandards.org/ELA-Literacy/`
   *Why:* the official text behind this unit's standards table
   (RL.K.1–3, RL.K.6–7, RL.K.9, SL.K.2, W.K.8), verified during the
   track audit 2026-10-02; this unit claims no state adoption or
   accreditation. Free, no account.
6. **Internal — track scope and sequence, Unit 05 section**
