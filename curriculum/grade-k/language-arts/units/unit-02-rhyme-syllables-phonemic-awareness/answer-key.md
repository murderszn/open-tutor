# Answer Key — Unit 02: Rhyme, Syllables, and Phonemic Awareness

Adult-facing. Keep separate from all learner materials. Every item below
was solved independently against its lesson/practice/quiz/assessment;
where a response is open-ended, the key gives the acceptable range and
sample reasoning.

## Lesson 01

**Guided practice:** 1. Yes — *pig/wig* rhyme (-ig). 2. Yes — *bed/red*
(-ed). 3. Yes — *fish/dish* (-ish). 4. No — *ball/dog* differ at the end
(-all vs. -og). 5. Yes — *cake/snake* (-ake).
**Independent practice:** 1. Yes (*bee/tree*). 2. Yes (*mop/top*).
3. No (*pan/moon*: -an vs. -oon). 4. Yes (*box/fox*). 5. No (*sun/cup*:
same /s/ beginning, different endings — the key discrimination item).
**Application:** learner teaches the stuffed animal with the clap (rhyme)
or shake (no rhyme) and states the reason — accept "same at the end" /
"different ends" in any wording.
**Exit check:** 1. Yes. 2. No. 3. Words rhyme when they sound the same
at the end.

## Lesson 02

**Guided practice:** 1. Any -at word: hat, bat, sat, mat, rat, pat, or a
silly rhyme like *zat*. 2. Any -un word: sun, run, bun, or silly *dun*.
3. *log* → dog family (-og). 4. *tree* → bee family (-ee). 5. *cow* →
none (waits on the bench).
**Independent practice:** 1. Any -ed word: red, fed, or silly *med*
("said" pronounced /sed/ accepted). 2. Any -ake word: snake, bake, lake,
take, or silly *zake*. 3. *wig* → pig family. 4. *fish* → none on the
mat (the real *fish/dish* family has no *dish* card today, so "none here"
is the secure answer; accept "fish needs dish" as advanced reasoning).
5. Any -op word: top, hop, pop, cop, or silly *lop*.
**Application:** family of 3+ cards with a correct shared ending, named
("the -at family"); recipe stated as "keep the ending, change the
beginning" in any wording.
**Exit check:** 1. Any -all word: tall, fall, call, wall, or silly rhyme.
2. Dog family. 3. Keep the ending, change the beginning.

## Lesson 03

**Guided practice:** 1. *dog* — 1. 2. *puppy* — 2 (*pup-py*). 3. *window*
— 2 (*win-dow*). 4. Learner's name — count the natural spoken syllables
together (verify against the name; e.g., 2 for most two-beat names).
5. *butterfly* — 3 (*but-ter-fly*).
**Independent practice:** 1. *sun* — 1. 2. *apple* — 2 (*ap-ple*).
3. *tiger* — 2 (*ti-ger*). 4. *banana* — 3 (*ba-na-na*; accept 2 only if
the learner's natural pronunciation is "b'nana," then model the 3-beat
version). 5. *basket* — 2 (*bas-ket*).
**Application:** learner's chosen word clapped and counted; scribed with
hyphens exactly as clapped (e.g., *di-no-saur* — 3).
**Exit check:** 1. *monkey* — 2 (*mon-key*). 2. *egg* — 1. 3. *tomato* —
3 (*to-ma-to*).

## Lesson 04

**Guided practice:** 1. *apple*. 2. *basket*. 3. *turtle*. 4. *puppy*.
5. *banana*.
**Independent practice:** 1. *table*. 2. *monkey*. 3. *rabbit*.
4. *tiger*. 5. *socket* (accept the blended pronunciation even if the
word is new; pre-teach with the picture if the learner has never heard
it).
**Application:** learner-as-robot says a word in parts; the adult blends
(slowly first, then correctly); roles swap. Scribed: hyphenated parts +
blended word (e.g., "cup-cake → cupcake").
**Exit check:** 1. *window*. 2. *elephant*. 3. Say the parts, then say
them fast (any wording).

## Lesson 05

**Guided practice:** 1. *dog*. 2. *mop*. 3. *cat*. 4. *pig* → /p/ + -ig.
5. *fish* → /f/ + -ish. 6. *sun* → /s/ + -un.
**Independent practice:** 1. *bat*. 2. *log*. 3. *top*. 4. *dog* → /d/
+ -og. 5. *mop* → /m/ + -op. 6. *frog* → /f/ + -rog OR /fr/ + -og —
both accepted; note which the learner hears.
**Application:** learner takes a card's word apart (e.g., *cat* → /c/ +
-at); adult-as-animal blends it wrong once ("cut?"); learner corrects
("No — *cat!* The rest is *-at*"). Scribed: the split and the correction.
**Exit check:** 1. *sun*. 2. /f/ + -ish. 3. The rest — *-at* ("the
ending" accepted).

## Lesson 06

**Guided practice:** 1. *table* → ta-ble. 2. *monkey* → mon-key.
3. *rabbit* → rab-bit. 4. *basket* → bas-ket. 5. *apple* → ap-ple.
(Each followed by blending back to prove the parts.)
**Independent practice:** 1. *pencil* → pen-cil. 2. *window* → win-dow.
3. *turtle* → tur-tle. 4. *candle* → can-dle. 5. *banana* → ba-na-na
(3 parts).
**Application:** learner takes a card apart with blocks; adult-as-animal
blends it back (wrong once, e.g., "pen-sill?"); learner corrects with
the blocks ("pen-cil ... pencil!"). Scribed with hyphens as the learner
split it.
**Exit check:** 1. *pup-py*. 2. *tur-tle*. 3. Count/clap, blend
together, take apart (any wording).

## Practice sessions

**Session A (Rhyme song basket):** rhymes caught in the original verse:
*tree/glee*, *sups/cups*. In "Hickory Dickory Dock": *dock/clock*;
accept *mouse/house* if the adult sings the full rhyme.
**Session B (Rhyme detective):** 1. *dog*. 2. *pig*. 3. *ball*.
4. *cup*, then *fish*. Report explains one catch via the ending.
**Session C (Picture sort relay):** frog→DOG, log→DOG, fun→SUN, run→SUN,
tree→BEE; pig, moon, cow on the bench. 4 of 5 family cards correct =
success.
**Session D (Robot says):** *table, apple, window, basket, turtle,
banana*. "Broken robot" word: *dog* (one part).
**Session F (Rhyme round-up):** detector pairs — yes, no, yes, no, yes
(*pig/wig* yes; *bed/sun* no; *cake/snake* yes; *mop/moon* no;
*ball/tall* yes).
**Session G (Beat review):** 1-clap pile: *cat, sun*; 2-clap: *pencil,
window*; 3-clap: *banana, elephant*. Robot blends: *monkey, rabbit,
socket*. Lightning rhymes: *bed→red*, *cake→snake* (any end-match
accepted).

## Formative quiz (Week 4)

1. *cat/hat* — yes; *cat/dog* — no.
2. Any -ee rhyme: *tree, see, me, knee,* silly rhyme.
3. *pencil* — 2 claps; *banana* — 3 claps.
4. *table*.
5. *dog*.
6. /s/ + -un (gestures optional).
7. *win-dow*.
8. One talk rule (listen / take turns / stay on the topic); one correct
   rhyme pair (e.g., *cat/hat*).

Scoring: 7–8 secure → unit assessment; 5–6 → re-teach missed items in
Session 16; fewer than 5 → flexible week re-teach.

## Unit assessment

**Task 1 — Rhyme judge:** 1. yes (*bed/red*). 2. no (*cake/moon*).
3. yes (*mop/top*). 4. yes (*fish/dish*). Produced rhyme for *ball*:
tall, fall, call, wall, or silly rhyme. Secure = 3 of 4 judgments + one
produced rhyme.
**Task 2 — Family sort:** 1. They rhyme — same at the end (-at).
2. *frog* joins the dog family. 3. New -at rhyme: sat, mat, rat, pat, or
silly rhyme.
**Task 3 — Beat counter:** 1. 2 claps (*tur-tle*). 2. 3 claps
(*el-e-phant*). 3. *monkey*. 4. *bas-ket*.
**Task 4 — Beginning and rest:** 1. *fish*. 2. *pig*. 3. /m/ + -op.
4. The rest — *-un* ("the ending" accepted). Secure = 3 of 4.
**Task 5 — Sound-play talk circle:** one rule stated; one accurate
sound-play item shared (rhyme pair, clapped word, take-apart, or the
recipe); one genuine question asked.

## Project — My Rhyme Book

**Deliverable 1:** 4 pages, each with a drawn picture pair and a dictated
rhyming pair in large print (accept any true rhyming pair the learner
chose; silly pairs accepted), syllable dots under each word (one dot per
word for these one-syllable pairs — verify the learner clapped one beat
each), pages numbered 1–4.
**Deliverable 2 (observed):** reads the pairs aloud; claps syllables in
at least two words (expect 1 clap each — note if the learner correctly
identifies them as one-beat words); takes at least one word apart into
beginning + rest (e.g., *cat* → /c/ + -at).
**Deliverable 3:** one answered question (e.g., "Do they rhyme? Yes —
same at the end") and one asked question (any genuine question),
scribed on the back cover.
**Rubric scoring:** 10–12 secure; 7–9 developing (re-teach lowest
criterion); below 7 → flexible-week re-teach.
