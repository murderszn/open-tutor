# Teacher Guide — Unit 04: Blending, Segmenting, and Regular CVC Words

## How to run this unit

Sessions are 15–20 minutes, four per week, for four weeks (track weeks
15–18). Every session starts with the learner's ears, not their eyes:
say the sounds, stretch them, and only then show the letters. If a
session runs long, stop at the exit check — the exit check is the
record of the day, and unfinished guided items roll into the next
review session. Never rush a learner through a blend to "finish the
lesson"; a slow correct blend beats a fast guessed word.

## Session-by-session notes

- **Session 1 (L1):** keep the first blends to two word families
  (-at, -og) so the vowel changes are few. If the learner blends
  onset-and-rime only (/c/ /at/), praise it as the Unit 02 skill and
  then re-split: "Now three sounds: /c/ /a/ /t/."
- **Sessions 2–4 (practice, game, review):** the picture blend game
  (Session 3) uses the generated illustration; run it on a screen or
  as a large print so all three pictures are visible at once.
- **Session 5 (L2):** teach positions in the order first → middle →
  last, and always in that order for the first week. Mixing the order
  too early turns a listening task into a memory task.
- **Sessions 6–8:** bingo (Session 7) works best with picture cards
  the adult names aloud; the learner never needs to read the grid.
- **Session 9 (L3):** chips before tiles, always. If the learner
  reaches for tiles first, cover them until the chips are right.
- **Session 10 (G):** sound boxes are drawn left to right; the
  learner pushes chips in reading order, never right to left.
- **Session 11/14 (project):** the flip book's flaps must move freely
  — test each flap before the session. A stuck flap turns a reading
  task into a fine-motor task.
- **Session 12 (re-teach):** pick the weakest objective from the
  Session 1–11 exit checks, not the most recent lesson. Use
  [practice.md](practice.md#session-h--mixed-review) for word sets.
- **Session 13 (L4 + L5):** teach L4's chain first, while energy is
  high; L5's sight words come second and need only the four cards
  and one sort. If the learner tires, move L5's sort to Session 12's
  slot next time and keep Session 13 to L4 alone (the unit's design
  survives the swap, as noted in the README pacing).
- **Session 14 (L6 + project):** dictation spelling comes before the
  project pages, so the learner writes the project words with fresh
  segmenting practice.
- **Sessions 15–16 (check + assess):** do the quiz in the morning
  slot and the project share after a break. Split the unit assessment
  across two sittings if the learner tires.

## Misconceptions — quick reference

| You see | It usually means | Do this |
|---|---|---|
| Spells out letter names ("cee-ay-tee") | Blending confused with naming | "Squish the sounds, not the names: /c/ /a/ /t/." |
| Drops the middle vowel ("ct") | Vowel not stretched | Stretch the middle sound longest: "/c/…/aaaa/…/t/." |
| Blends only two sounds (/m/ /op/) | Unit 02 onset-rime habit | Praise it, then re-split into three sounds. |
| Segments into two chips | Same onset-rime habit | "Three sounds, three chips — split /op/ into /o/ and /p/." |
| Segments into four chips ("sssun") | A sound stretched twice | Say the word at normal speed first, stretch once. |
| Changes two sounds at once | Chain rule not counted | "How many tiles moved? Two — move one back." |
| Accepts a non-word (*cag*) | "Change one sound" without the real-word rule | "Real words only — is *cag* a word we know?" |
| Sounds out *the* or *of* | Sight-word rule not learned | "That is a face-word. We know it whole." |
| Reads *cap* as *cat* | Stopped at the first letter | "Read to the end. The last letter can change the word." |
| Spells *mp* for *mop* | Middle vowel missed | Stretch the middle sound and write it second. |
| Writes letters in the wrong order (*mpo*) | Sound order not tracked | Sound boxes: one letter per box, left to right. |
| Says /b/ for *cup*'s last sound | Voicing mix-up, /p/ vs. /b/ | Contrast *cup*/*cub* aloud; the quiet pop is /p/. |
| Pronounces /r/ as /w/ | Developmental, common at five | Accept, model /r/, never drill to frustration. |

## Re-teach triggers

- **Blending below 6/10 (quiz items 1–3 plus Lesson 01 exits):**
  repeat Sessions A–C with only -at and -ig families for one
  flexible week before moving on.
- **Isolation below 4/6 positions:** repeat Sessions D–F with the
  same three words daily (*dog, mop, hen*) until positions are
  stable, then vary the words.
- **Segmenting below 4/6 words:** repeat Session G with chips only
  (no tiles) for a week; add tiles only when chip counts are
  reliably three.
- **Change-one-sound below 3/5:** repeat Lesson 04 chains with
  tiles in boxes, moving only the changed box's tile, for a week.
- **Sight words below 3/4:** drill the four cards as a fast daily
  routine (look–say–use) for a week; do not sound them out.
- **Spelling below 3/5:** dictate only three words per session and
  let the learner build each word with tiles first, then write it.
- **Look-alike errors still frequent after Session 14:** note as a
  watch item for Unit 05 (where sentence reading raises the cost of
  guessing), not as a failure; keep the "read to the end" rule in
  every review.

## Readiness for Unit 05

The learner is ready for Unit 05 (shared reading, retelling, and
sequence) when the unit assessment shows Tasks 1–3 at "secure" and
Tasks 4–5 at "secure" or "nearly there." A "re-teach" result on any
task means a flexible week on that objective first — Unit 05 assumes
the learner can blend a CVC word on sight and spell one from
dictation, and shared reading without those skills is guessing, not
reading. If the learner is secure on blending but shaky on sight
words, Unit 05's first week will still be hard: *the* appears in
nearly every sentence, so prioritize the four sight-word cards over
speed.
