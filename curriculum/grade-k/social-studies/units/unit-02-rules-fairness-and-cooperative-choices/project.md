# Project — Our Class Rule Book and Turn-Captain Fair

**Type:** investigation / community-action project · **Sessions:** 8 (setup),
11 (Part 1), 14 (Part 2) · **Unit:** [U02](README.md)

The learner co-creates the class's own rules in child words, illustrates one
rule for a class rule book, and then runs a real fair-turn game as "Turn
Captain" for puppet friends — keeping a fair-turn log and reporting how the
rules worked. The class ends the unit with a rule book it actually follows
and a turn captain who has proven fair turns work.

## Driving question

"Can our class make its own rules — and can we keep them fair for real?"

## Materials

- The rule poster sketch from [Session E](practice.md#session-e-practice-votes)
- Large paper, crayons or markers, tape
- The sand timer, the coveted toy, wooden blocks
- Two puppets or stuffed animals (the Turn-Captain Fair "players")
- A simple "fair-turn log": one row per turn with three picture prompts
  (Whose turn? Did the timer decide? Did we pass fairly?) — the adult scribes
  the learner's dictation

## Steps

### Part 1 — Co-create our rules + the rule book page (Session 11, ~20 min)

1. **Co-create 3–4 class rules in child words.** The adult proposes the
   shape; the learner supplies the words. Start from what the unit taught:
   "We need one rule for moving safely, one rule for talking fairly, one
   rule for turns, and one rule for our things." For each, the learner
   suggests the wording; the adult tests it with the class: "Safe or fair?"
   Typical child-worded results: "Walking feet inside." / "One person talks
   at a time." / "Fair turns — the timer decides." / "We clean up our toys."
   Keep the learner's wording wherever possible — ownership is the point.
   (Teacher background: CSEFEL's rule guidelines — few simple rules,
   children involved in developing them, posted visually, taught
   systematically; see the [resource pack](resource-pack.md).)
2. **The rule book page:** the learner draws ONE rule being followed (their
   choice) on a large paper page — e.g., feet walking in the hallway, hands
   passing the timer. The adult scribes the rule underneath in the learner's
   exact words. **No names anywhere on the page** — the page shows the rule,
   not the ruler.
3. Post the four rules where the class gathers (the poster sketch from
   Session 8 becomes the real poster). Read them together, with gestures:
   "These are OUR rules. We made them. We follow them."

### Part 2 — Turn-Captain Fair (Session 14, ~20 min, then the report)

4. **The Fair:** the learner becomes Turn Captain and runs a fair-turn game
   for two puppet "friends" with the coveted toy and the sand timer — three
   full rotations. The captain's jobs: start each turn ("Your turn!"), watch
   the sand, call "Pass!" when it runs out, and settle disputes with "Not
   yet — your turn is coming." The adult voices the puppets (one puppet
   grumbles once; one puppet tries to keep the toy — the captain must hold
   the rule kindly).
5. **The fair-turn log:** after each rotation, the learner dictates one line:
   "Turn ___. The timer decided. We passed fairly." (Or honestly: "Pip kept
   the toy. I said 'not yet' and Pip passed.") The adult scribes; the
   learner may draw a small timer beside each line.
6. **Rule book assembly:** the learner's rule page joins the poster. Read
   the whole book aloud together: "Our rules are ___. We made them, and we
   keep them."
7. **The report:** the learner presents to the adult (and the puppets):
   "Our rules are ___. I was Turn Captain. I kept turns fair by ___. The
   hardest part was ___. Our rules worked because ___." The adult asks one
   follow-up: "What would happen with no rules at the Fair?" (The learner
   reasons: grabbing, no turns, nobody has fun — retrieving L1.)

## Deliverables

1. One rule book page: a drawing of a rule being followed + the rule scribed
   in the learner's own words. Displayed anonymously on the class poster.
2. A completed fair-turn log: at least three rotation entries (dictated,
   adult-scribed, pictures optional). Kept in private storage.
3. An oral report using the frame (rules / what I did as captain / how it
   worked / what-if-no-rules reasoning).

## Rubric

| Criterion | Emerging (1) | Developing (2) | Secure (3) |
|---|---|---|---|
| Co-created rules | Repeats the adult's wording only | Suggests words for 1–2 rules with help | Own child-words for 3–4 rules; can say safe/fair for each |
| Rule book page | Drawing unrelated to the rule | Drawing shows the rule's action | Drawing shows the rule being followed; scribed words match the picture |
| Turn Captain | Needed the adult to run the turns | Ran turns with reminders; settled one dispute | Ran 3 full rotations; timer decided every turn; held the rule kindly under pressure |
| Report | One-word or gestured answers | Uses parts of the frame with prompting | Full frame; answers "what if no rules?" with a real consequence |

**Scoring:** 10–12 = Secure · 7–9 = Developing · 4–6 = Emerging (re-run one
Fair rotation with coaching, then re-report). The rubric assesses the *work*,
never the child; share only the descriptive feedback with the learner ("you
held the rule even when Pip grumbled — that's a real captain!"), not the
numbers.

## Privacy

The rule book is anonymous by design — rules and drawings, never names. The
fair-turn log records actions ("we took 3 turns"), never a list of who
misbehaved. If the adult photographs the poster for a portfolio, the photo
shows the poster only — no children, no names.
