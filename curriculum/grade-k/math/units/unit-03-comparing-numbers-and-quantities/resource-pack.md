# Resource Pack — Unit 03: Comparing Numbers and Quantities

## Summary

**Goal:** give the guiding adult free, no-account routes to support
kindergarten comparison — more/fewer/same by matching, comparing by
counting, comparing written numerals 1–10, one more / one fewer, and
making groups equal — plus songs and interactive practice a 5-year-old
will actually enjoy.
**Age fit:** kindergarten (about 5–6); all items are visual, musical,
or hands-on, with no reading required of the learner.

## Web references

Checked 2026-10-22 unless noted.

1. **The Math Learning Center — free math apps**
   `https://www.mathlearningcenter.org/apps`
   *Why:* free web apps, no account needed. **Number Frames** (place
   counters in five/ten frames — build two groups and compare counts,
   Lessons 01–02), **Number Line** (virtual number line — compare
   numerals by position and hop one more / one fewer, Lessons 03–04),
   and **Number Rack** (slide beads — count out and compare groups,
   Lesson 02). Verified live 2026-10-22: the apps page states the apps
   are free with web versions for modern browsers, and describes
   Number Frames, Number Line, and Number Rack as above.
   Adult-guided use.
2. **PBS LearningMedia — Counting and Cardinality collection**
   `https://www.pbslearningmedia.org/subjects/mathematics/k-8-mathematics/counting-and-cardinality/`
   *Why:* curated K–8 counting resources including comparing groups
   (K.CC.C.6) and comparing numerals (K.CC.C.7). Found via web search
   and verified reachable 2026-10-01; collection description matches
   the unit's standards. Free; core videos viewable without an account.
3. **NCTM Illuminations**
   `https://illuminations.nctm.org`
   *Why:* standards-based math lessons and interactive tools for
   grades PK–12 from the National Council of Teachers of Mathematics.
   Verified homepage 2026-10-01. Adult selects PK–K number-sense
   lessons (comparing groups, ordering numbers). Free, no account.
4. **Common Core State Standards for Mathematics — kindergarten**
   `https://www.thecorestandards.org/Math/`
   *Why:* **adult reference only** — the authoritative text of
   K.CC.C.6, K.CC.C.7, K.CC.A.2, and K.CC.B.4–B.5 cited in this unit.
   Descriptions verified against the official framework on 2026-10-01
   during the track audit (see
   [scope-and-sequence](../../scope-and-sequence.md#standards-crosswalk));
   no state adoption or accreditation claimed.
5. **Inclusive Education — Comparing Objects, More or Less**
   `https://inclusivelearning.sssvv.org/week-1_comparing-objects-more-or-less/`
   *Why:* teacher-facing lesson page (more/less/equal with objects,
   matching and counting strategies) found via web search 2026-10-22;
   its learning outcome ("compares two numbers up to 9 and uses
   vocabulary like more than, less than, equal") matches this unit.
   Adult reads and adapts; not assigned to the learner directly.
