# Teacher Guide — Unit 03: Comparing Numbers and Quantities

**Unit:** [U03](README.md) · **Track weeks:** 11–14 · **Sessions:** 16 ×
15–20 minutes, adult-led, oral/manipulative/drawing responses.

This guide is for the guiding adult. Learner-facing pages never link
here with answers; the [answer key](answer-key.md) is a separate file.

## Unit at a glance

| Lesson | Idea | Proof method taught |
|---|---|---|
| L1 | More, fewer, same | Matching (leftovers decide) |
| L2 | Compare by counting | Counting (both numbers, then decide) |
| L3 | Compare written numerals | Number-line position (further right = greater) |
| L4 | One more, one fewer | Number-line hops (right = more, left = fewer) |
| L5 | Greater, less, equal in a picture | Counting a picture; making equal |

Golden rule, all unit long: **count first, compare second, and always
say both numbers.** A comparison with only one number stated is a
guess wearing a conclusion's clothes.

## Session-by-session guidance

- **Sessions 1–4 (Week 11):** matching only. Do not let counting sneak
  in as the decision method yet — the point is that leftovers alone
  prove a comparison. Session 4's review should include the
  spread-vs.-bunched trap (Lesson 01, Worked example 2) at least once.
- **Sessions 5–8 (Week 12):** counting comparison. Insist on the
  sentence "___ and ___. ___ is greater." If the learner decides from
  one count alone, cover the other tray and ask "but how many are in
  this one?" Session 8 re-teaches whichever of matching/counting is
  weaker — check both exit checks from Lessons 01–02.
- **Sessions 9–10 (Week 13, part 1):** numerals alone. The number line
  stays visible; removing it early creates guessing. Card game
  (Practice C) is the fluency builder — play it twice if Session 10
  runs short.
- **Sessions 11–12 (Week 13, part 2):** one more / one fewer, then the
  picture lesson. Lesson 05's picture is deliberately tricky (bigger
  apples on top, fewer of them) — let the learner fall for looks once,
  then re-count together. That correction is the lesson.
- **Sessions 13–14 (Week 14, part 1):** the Comparison Fair project.
  Part 1 must end with all three comparison methods agreeing; if they
  disagree, a count is wrong somewhere — recount, do not average.
- **Sessions 15–16 (Week 14, part 2):** stations + formative quiz, then
  the unit assessment. Quiz misses set the re-teach list for Session
  16 planning; do not re-teach everything, only the missed pattern.

## Misconceptions and re-teaching moves

| Misconception | What you see | Re-teaching move |
|---|---|---|
| Spread out / bigger = more | "The spread-out row has more" for 5 spread vs. 8 bunched | Re-run Lesson 02, Worked example 2; scrunch and spread the same groups and recount both ways |
| First-shown = greater | Numeral pairs always answered with the first card as greater | Number-line pointing before every answer; sentence frame "___ is greater than ___" with the line as referee |
| Close numbers are "the same" | "7 and 8 are equal" | One-step hop: stand on 7, hop right once — "see, 8 is one step greater, not the same" |
| One number decides | "This one is 6, so it has more" (other group uncounted) | Cover-and-ask: "How many in the other group? We need both numbers." |
| Hop direction reversed | One more answered by hopping left | Direction chant ("right is more, left is fewer") + counters check (add one, recount) |
| Equal means "looks alike" | Two groups called equal because the objects match in kind/size | Count both; equal means the same number, even for different-looking objects (Lesson 01, example 2) |
| "One more than 10 is 0" | Wrap-around thinking at the line's end | Correct at once: numbers keep going right; 11 comes in Unit 04 — the line ending is not a wall that bounces back |

## Catch-up guidance

- **Matching weak:** drop to numbers 5 and under, two colors, big
  counters, and re-run Practice A daily for a week. Do not advance to
  numeral comparison until matching is secure — it is the proof method
  everything else rests on.
- **Counting weak:** return to Unit 02's keep-track strategies
  (move-aside, touch-count) before comparing; comparing with shaky
  counts teaches guessing.
- **Numerals weak:** keep the number line out permanently, play
  Practice C with numbers 1–5 only until fluent, then expand to 1–10.
- **One-more weak:** whole-body floor-line hops, 5 minutes a day as a
  warm-up, before any new lesson.
- **If the whole unit is shaky:** use a flexible track week (the track
  has diagnostic/catch-up weeks built in), re-run Lessons 01–03 and
  Practice A/B/C, and re-check with the formative quiz before the unit
  assessment. Unit 04 (teen numbers) assumes secure 1–10 comparison;
  do not carry a comparison gap into it.

## Readiness criteria for Unit 04

The learner is ready for Unit 04 (teen numbers and ten frames) when
they can, without adult coaching: compare two groups to 10 by matching
and by counting; compare two numerals 1–10 (including equal pairs);
give one more and one fewer for 2–9; and make two unequal groups equal
by adding to the smaller group. One-more-than-10 is **not** required —
Unit 04 teaches it.

## Materials prep checklist (before Session 1)

- [ ] 40 counters total (two colors, 20 each) — check for choking-size
  pieces if younger siblings share the space
- [ ] Numeral cards 1–10, large and high-contrast (two sets if playing
  Practice C head-to-head)
- [ ] Number line 1–10 (floor tape version + a strip version for the
  table)
- [ ] Two trays/placemats, paper, crayons, dot stickers (optional)
- [ ] Unit picture printed large (or on a screen the learner can point
  at): [assets/two-rows-apples-5-and-8.png](assets/two-rows-apples-5-and-8.png)
- [ ] Stuffed-animal "judge" for the project (optional)
- [ ] Allergy check if any snack-based application is planned

## Notes on the generated illustration

The apple-rows picture is an AI-generated illustration, not a
photograph and not evidence of real objects — its counts (5 top, 8
bottom) were verified by direct inspection before linking, and the
lesson uses the learner's own counters alongside it for the make-equal
step. The top apples are drawn larger than the bottom ones on purpose
in the sense that the lesson exploits the size difference: it teaches
that count, not drawn size, decides a comparison. Full record:
[assets/README.md](assets/README.md).
