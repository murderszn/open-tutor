# Unit 02 — Numbers to 10 and One-to-One Correspondence

**Grade:** Kindergarten · **Subject:** Mathematics · **Track weeks:** 7–10
**Backlog:** [issue #6](https://github.com/murderszn/open-tutor/issues/6), section U02
**Status:** validated draft (this unit); not educator-reviewed, not merged

Unit 01 taught the learner to touch, count, and say "how many?" for real
objects. This unit adds the **written numerals 0–10** — the symbols that
stand for those counts — and strengthens one-to-one counting in harder
situations: counting on from a number other than 1, and counting scattered
groups without losing track. By the end, the learner reads, writes, and
matches numerals 0–10 and counts any set to 10 with a keep-track strategy.

## Essential question

How can a written mark stand for "how many," and how do we keep track when
counting gets tricky?

## Prerequisites

- Unit 01: touch-count sets to 10 with one-to-one correspondence; state the
  total when asked "how many?"; count out a requested number 1–10
- Rote count sequence to at least 10 (stable order)
- Can hold a crayon or marker and make deliberate marks (tracing is enough)

No numeral reading or writing is assumed — this unit teaches it from zero.

## Measurable objectives

By the end of the unit the learner will be able to (adult-observed):

1. Name each numeral 0–10 when shown out of order, and match a numeral card
   to a set of that many objects (and a set to its numeral).
2. Trace and then write the numerals 0–10 so the adult can read them
   (reversals of 3/5/7 accepted at first if the count of strokes is right;
   see teacher guide).
3. Count forward from any given number within 10 (e.g., hear "start at 4,"
   count "4, 5, 6, 7, 8, 9") without restarting at 1.
4. Count a scattered set of up to 10 objects with one-to-one correspondence
   by using a keep-track strategy (move each counted object aside, or mark
   each counted drawing), and state the total.
5. Represent a counted set with its written numeral, and build a set of
   objects to match a shown numeral, for 0–10 — including 0 as "none."

## Vocabulary (taught with objects and numerals together)

numeral (the written mark) · number word (the spoken word) · zero / none ·
match · in order · count on · keep track · number line · "how many" ·
digit · one more

## Materials

Household or dollar-store items (see the track
[scope-and-sequence](../../scope-and-sequence.md) for the full safe-materials
list): numeral cards 0–10 (adult-made: one large numeral per index card),
counters (buttons, dried beans, blocks), crayons or thick markers, paper,
a shallow tray of sand or salt (optional, for tracing), the generated
illustration [`assets/numeral-baskets-6-8-10.png`](assets/numeral-baskets-6-8-10.png),
floor tape or chalk for the number-line walk. No sharp tools; no small parts
for children under 3 in shared settings without adult supervision.

## Accessibility

Every check accepts oral, pointing, or drawing responses; the adult scribes.
Numeral cards use large, high-contrast print; color is never the only cue
(the basket illustration also differs by fruit kind and arrangement). Each
lesson includes a seated-table and a floor-play variant, a language-access
support, an alternate response mode, and an extension. The generated
illustration ships with a text-only alternative containing every count the
activity needs.
