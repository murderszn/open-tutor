# Unit Assessment — Unit 02: Numbers to 10 and One-to-One Correspondence

**Format:** performance tasks; oral, pointing, drawing, and writing
responses; the adult observes and scribes.
**Time:** 20–25 minutes (may split across two sittings) · **Pacing:** Session 16 of 16
**Unit:** [U02](../README.md)

Read each task's directions aloud exactly as written. Do all six tasks.
Record the learner's actual responses — this assessment is evidence for the
adult, not a grade for the learner.

## Task 1 — Read the numeral line (Objective 1)

Lay the 0–10 cards **out of order** on the table.
"Read these numerals to me, in any order you like."
*Record: which numerals were named correctly; any consistent confusions
(e.g., 6/9).*

## Task 2 — Build and write (Objectives 2, 5)

Place 8 counters in a scattered pile.
"Count these. Then write the numeral that says how many."
*Record: the count (one-to-one? total correct?), the written numeral
(readable? matches the count?).*

## Task 3 — Count on (Objective 3)

"Start at 3 and count to 8." Then: "Start at 6 and count to 10."
*Record: exact words said; any restart at 1.*

## Task 4 — Basket picture (Objectives 1, 4, 5)

Show the generated illustration
[`assets/numeral-baskets-6-8-10.png`](../assets/numeral-baskets-6-8-10.png)
(or its text alternative: "Three baskets — 6 red apples, 8 yellow bananas,
10 blue balls").
"Count what is in each basket. Then put the right numeral card on each
basket."
*Record: counts for each basket; cards placed; whether the learner used a
keep-track strategy (pointing each object once).*

## Task 5 — Scattered keep-track (Objective 4)

Scatter 10 small counters. Hand the learner the done bowl.
"Count all of these into the bowl, then tell me how many."
*Record: one move per word? any misses or doubles? final total stated?*

## Task 6 — Zero and order (Objectives 1, 5)

Show the empty bowl and the cards 0, 4, 9.
"Which numeral goes with this bowl? Now put these three numerals in order
from smallest to biggest."
*Record: 0 chosen for the empty bowl? order 0, 4, 9 correct?*

## Scoring guidance

| Task | Secure (2) | Developing (1) | Not yet (0) |
|---|---|---|---|
| 1 — read numerals | 10–11 correct | 8–9 correct | Fewer than 8 |
| 2 — build and write | Count correct, numeral readable and matching | Count correct, numeral unreadable/mismatched (or vice versa) | Count wrong |
| 3 — count on | Both sequences, no restart | One restart, self-corrected | Restarts at 1 both times |
| 4 — basket picture | 6, 8, 10 all correct with cards | Two of three correct | Fewer than two |
| 5 — scattered keep-track | 10, one move per word | Correct total, one self-corrected slip | Misses/doubles unnoticed |
| 6 — zero and order | 0 chosen; order correct | One of the two correct | Neither |

**Totals:** 10–12 = secure — begin Unit 03. 6–9 = developing — re-teach the
lowest tasks (see [teacher guide](../teacher-guide.md#catch-up-guidance)),
then re-check those tasks only. 0–5 = not yet — repeat the unit's core
sessions (Lessons 01–03 + Practice A/B/E) before Unit 03; use a flexible
track week.
