# Lesson 01 — Touch and Count to 5

**Student goal:** I can touch each object one time and say one counting word
for each touch, up to 5.
**Time:** 15–20 minutes · **Unit:** [U01](../README.md) · **Session 1 of 16**

## Materials

- 5 identical counters (blocks, large buttons, or dried beans)
- A tray or placemat to keep counters from rolling

## Readiness check (1 minute)

Count aloud together to 5 while clapping once per word: "1, 2, 3, 4, 5."
If the learner cannot yet say the sequence to 5, spend this session on the
sequence with claps and touches before counting objects, and note it for
re-teaching.

## Teaching

When we count things, we give **one counting word to each thing** and we touch
each thing **exactly one time**. Touch, say a word. Touch, say the next word.
If we touch something twice, we count it twice — and that is wrong. If we skip
something, we miss it — and that is wrong too.

Watch my finger. I touch and I talk at the same time.

## Worked example 1 — three buttons in a line

The adult places 3 buttons in a row, then models slowly:

> "One." *(touches the first button)*
> "Two." *(touches the second button)*
> "Three." *(touches the third button)*
> "I touched each button one time. There are **three** buttons."

Then the adult asks the learner to do the same row while the adult watches the
finger: "Your turn. Touch each one, one time, and count with me."

**Reasoning to name aloud:** the finger and the word move together. The last
word I said — "three" — is the answer to "how many?"

## Worked example 2 — five blocks, then a recount check

The adult places 5 blocks in a row.

> "One, two, three, four, five. Five blocks."
> "Let me check: did I touch each one once?" *(adult re-touches each block
> slowly while the learner watches, counting again: 1, 2, 3, 4, 5)*
> "Same answer — five. When we count carefully, we get the same number every
> time."

**Reasoning to name aloud:** recounting is how mathematicians check their
work. The same careful count gives the same total.

## Guided practice (adult stays close, hints allowed)

Do 4–6 short rounds. The adult may guide the learner's hand for the first
round, then fade help.

1. 2 counters in a line — "Touch each one. Count."
   *Hint: "Slow finger. One word each touch."*
2. 3 counters in a line — learner counts alone; adult watches for
   double-touches.
3. 4 counters in a line.
   *Hint if the learner rushes: "Freeze your finger after each touch."*
4. 5 counters in a line.
5. 4 counters — the adult "counts" incorrectly on purpose, touching one
   counter twice and saying "1, 2, 3, 4, 5 — five!" Ask: "Did I count right?
   What did I do wrong?" *(Error-analysis task: the expected answer is "you
   touched that one twice.")*
6. 3 counters scattered (not in a line) — "Touch each one once. This is
   trickier because they are not in a row."

## Independent practice

The learner takes 5 counters, lines them up alone, and counts: "1, 2, 3, 4,
5." Then recounts to check. The adult observes silently and notes: one touch
per word? Any skips or double-touches? Same total on the recount?

*Alternate response mode:* the learner points with a pointer stick instead of
touching, or taps the table beside each object. For limited mobility, eye-gaze
plus an adult touch confirmed by the learner's "yes/next" works.

## Application

Snack math: place 5 crackers (or grapes, with allergen check) on the plate.
"Count your crackers before you eat. Touch each one." The learner counts to 5,
says "five crackers," then eats. Counting now has a purpose: knowing exactly
how many you have.

## Exit check

The adult holds up 4 fingers on one hand. "Touch each finger and count. How
many fingers?" The learner should touch each finger once, count "1, 2, 3, 4,"
and answer "four." The adult records: secure / developing / not yet.

## Supports

- **Language access:** teach the word "count" by doing it first, then naming
  it. Accept the home-language number words alongside English ("uno, dos,
  tres" counts as counting).
- **Alternate response mode:** pointing, eye-gaze with adult touch, or moving
  each counted object into a "done" bowl one at a time (the bowl makes
  double-counting visible).
- **Floor-play variant:** sit on the floor and count 5 stuffed animals in a
  row; the learner "visits" each one.

## Extension

Count 6 and 7 objects. Or count 5 objects, close your eyes while the adult
adds one more, and count again — "what changed?" (previews "one more").

## Teacher note

**Likely misconceptions:** (1) saying the words faster than the finger moves —
slow the hand, not the mouth; (2) recounting the first object — start at one
end and move in one direction; (3) treating the last word as just another word
rather than the total — always follow a count with "how many?" and the answer.
