# Resource Pack — Unit 01: Counting and Classifying Objects

## Summary

**Goal:** give the guiding adult free, no-account routes to support
kindergarten counting (one-to-one to 10), "how many?" cardinality, counting
out, and sorting/comparing groups — plus music and interactive practice a
5-year-old will actually enjoy.
**Age fit:** kindergarten (about 5–6); all items are visual, musical, or
hands-on, with no reading required of the learner.

## Web references

Checked 2026-10-01 (all reachable in a text browser; noted where a page could
not fully render).

1. **The Math Learning Center — free math apps**
   `https://www.mathlearningcenter.org/apps`
   *Why:* free web apps, no account needed. **Number Frames** (place counters
   in five/ten frames — matches Lessons 01–03) and **Number Rack** (slide beads
   to show numbers — supports counting out, Lesson 04). Verified: apps page
   states the apps are free and run in modern browsers. Adult-guided use.
2. **PBS LearningMedia — Counting and Cardinality collection**
   `https://www.pbslearningmedia.org/subjects/mathematics/k-8-mathematics/counting-and-cardinality/`
   *Why:* curated K–8 counting resources including one-to-one correspondence
   videos ("Let's Learn" series) and dot-card activities. Found via web search
   2026-10-01; collection description matches K.CC.B.4/B.5. Free; some features
   ask for a free educator account — core videos are viewable without one.
3. **NCTM Illuminations**
   `https://illuminations.nctm.org`
   *Why:* standards-based math lessons and interactive tools for grades PK–12
   from the National Council of Teachers of Mathematics. Verified homepage
   2026-10-01 ("Standards-based math lessons for grades PK-12"; interactives
   for all grades). Adult selects PK–K counting/sorting lessons. Free, no
   account.
4. **Starfall**
   `https://www.starfall.com/h/`
   *Why:* nonprofit (501(c)(3)) early-learning site with free interactive

5. **Common Core State Standards for Mathematics — kindergarten**
   `https://www.thecorestandards.org/Math/`
   *Why:* **adult reference only** — the authoritative text of K.CC and K.MD
