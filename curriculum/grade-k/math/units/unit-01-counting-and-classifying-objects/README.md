# Unit 01 — Counting and Classifying Objects

**Grade:** Kindergarten · **Subject:** Mathematics · **Track weeks:** 3–6
**Backlog:** [issue #6](https://github.com/murderszn/open-tutor/issues/6), section U01
**Status:** validated draft (this unit); not educator-reviewed, not merged

Counting is touching, saying, and keeping track — one number word for each
object. Sorting is putting together things that are alike and noticing how many
are in each group. In this unit the learner counts real objects to 10, answers
"how many?", counts out a requested number, and sorts objects by color or size
and compares the groups.

## Essential question

How do we find out exactly how many things are in a group, and what happens
when we put alike things together?

## Prerequisites

- Rote count sequence to at least 10 (not necessarily stable) — from diagnostic
  weeks 1–2
- Can point to or touch individual objects
- Emerging color and size words ("red", "big/little")

No numeral reading or writing is required in this unit; Unit 02 introduces
numerals 0–10.

## Measurable objectives

By the end of the unit the learner will be able to (adult-observed):

1. Count a set of up to 10 objects arranged in a line or circle, touching or
   pointing to each object exactly once while saying one number word per
   object (one-to-one correspondence).
2. State the total number of objects when asked "how many?" after counting
   (cardinality), for sets to 10.
3. Count out a requested number of objects (1–10) from a larger pile,
   stopping at the requested number.
4. Sort a mixed set of objects into groups by color or by size and name the
   sorting rule used.
5. Count each sorted group and tell which group has more, which has fewer, or
   that two groups have the same number.

## Vocabulary (taught with objects first, word second)

count · how many · one-to-one (one touch, one word) · sort · same · different ·
group / pile · more · fewer · same number · color names · big / little ·
long / short (informal, revisited in Unit 08)

## Materials

Household or dollar-store items (see the track
[scope-and-sequence](../../scope-and-sequence.md) for the full safe-materials
list): counters (buttons, dried beans, blocks, linking cubes), two or three
sorting trays or shoebox lids, crayons or markers, paper, the generated
illustration [`assets/counting-sorting-tray.png`](assets/counting-sorting-tray.png).
No sharp tools; no small parts for children under 3 in shared settings without
adult supervision; check food-allergen safety before using any food as counters.

## Accessibility

Every check accepts oral, pointing, or drawing responses; the adult scribes.
Color is never the only cue (sorting also uses size and shape differences).
Each lesson includes a seated-table and a floor-play variant, a language-access
support, an alternate response mode, and an extension. The generated
illustration ships with a text-only alternative containing every count the
activity needs.
