# Starter Lesson — Count, compare, and make a teen number

**Status:** draft supplement; this is one lesson, not a completed unit. **Time:** three 15–20 minute sessions across a week. **Goal:** Count small sets once per object, compare two sets to 10, and show a teen number as ten and some more.

## Adult preparation and readiness

Gather 20 large counters (blocks or paper circles), numeral cards 0–20, paper, and crayons. Avoid small counters if a child may mouth them; use drawings. Read aloud and accept pointing, moving objects, speech, or adult-scribed answers. Readiness check: place 4 objects in a line and ask the learner to touch-count them, then ask “How many?” If one-to-one counting is still developing, start with 1–4 and record the observation without pressure.

## Teach and model

Explain: “When we count, each object gets one number word. The last number we say tells the total, even if we move the objects.” Model counting five counters into an empty cup. Move them into a line and recount: still five. Then show a ten-frame drawing with 10 boxes. Fill all ten; add 3 counters beside it. Say, “Thirteen is one full ten and three more: 10 + 3 = 13.”

**Worked example 1:** A set of 6 counters is counted: 1, 2, 3, 4, 5, 6. The total is 6. Moving them into a circle does not change the total.

**Worked example 2:** 14 counters fill one ten-frame and leave 4: 14 = 10 + 4. The “1” in 14 names one ten; the “4” names four ones.

**Pacing and roles:** Session 1: adult models counting and guides tasks 1–2. Session 2: adult models a ten-frame; learner completes task 3 with counters, then independently draws or builds one new teen number. Session 3: guide task 4, do error check 5 together, and let learner choose a safe set for task 6.

## Guided and independent tasks

1. **Adult-guided:** Count 7 objects, move them, and recount. Explain what changed and what stayed the same.
2. **Guided, then independent:** Count out exactly 9 objects from a larger pile. Check by touching each once.
3. **Adult-guided:** Draw or fill a ten-frame for 12. Complete: `12 = 10 + __`.
4. **Guided:** Compare 8 counters and 6 counters by matching pairs. Say which set has more and how many more.
5. **Adult-guided error check:** An adult counts a set of 5 objects as “1, 2, 3, 4, 6.” Ask the learner to spot and repair the mistake.
6. **Independent application with adult supervision:** Choose an everyday set of 5–10 safe objects and show its total in a drawing.

**Answers/checks:** Tasks 1–2 totals remain 7 and selected 9; task 3 blank is 2; task 4, 8 is more by 2; task 5 recount in order, 1–5; task 6 accepts accurate one-to-one counting up to 10.

## Exit check and product

Ask the learner to show 16 using objects or drawing and finish “16 is 10 and ___ more.” Expected: 6 more. Save one labeled drawing or an adult note of the oral response as the lesson product; do not publish learner work in this repository.

## Review rubric

| Criterion | 2 — shows skill | 1 — developing | 0 — not yet observed |
|---|---|---|---|
| Counts a set to 10 | Touches each object once and names total | Misses/recounts objects with prompting | Cannot yet coordinate count and objects |
| Represents teen number | Shows full ten plus correct ones | Correct total with adult model | Needs smaller numbers first |
| Explains | Uses “same total,” “more,” or a matching/counting reason | Gives answer without reason | No response yet |

**Adult note:** If counting objects and number words do not stay matched, return to smaller arranged sets and model moving counted objects aside. Offer a floor or table setup, large high-contrast counters, extra wait time, home-language number words, and oral/pointing answers. Never require fine-motor drawing as proof of math understanding. Household materials only; supervise all manipulatives. This aligns with the K math track’s counting/cardinality and teen-number objectives; it is not a full unit or placement test.
