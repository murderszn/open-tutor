# Grade k — Independent Curriculum Track

This folder is an anonymous, grade-specific track in the public OpenTutor curriculum library.

**Contents:** The [mathematics](math/README.md) and [science](science/README.md)
tracks each have a delivered audit and scope-and-sequence (drafts; units planned,
not yet written). Language arts and social studies are still blank,
educator-adaptable prompts and assessments.

**Do not refer learners to other grade tracks.** Each track is self-contained.
