# Grade k — Independent Curriculum Track

This folder is an anonymous, grade-specific track in the public OpenTutor curriculum library.

**Contents:** The [mathematics](math/README.md) track has a delivered audit and
scope-and-sequence (merged; Unit 01 in a draft PR, other units planned, not yet
written). The [social studies](social-studies/README.md) track has a delivered
audit and scope-and-sequence (draft PR; units planned, not yet written).
Science and language arts audits exist as open draft PRs. All other subjects
are still blank, educator-adaptable prompts and assessments.

**Do not refer learners to other grade tracks.** Each track is self-contained.
