# Resource Pack — Unit 03: Local History, Timelines, and Evidence

**Goal (one sentence):** Give the guiding adult short, grade-2-appropriate
videos, references, and search routes that reinforce past/present/future,
timelines, then-and-now comparisons, kinds of historical sources, and
evidence-backed reasons.
**Age fit:** grade 2 (ages 7–8); the adult previews every video and
co-views with the learner.

**Fact-check record (2026-10-23):** C3 Framework K–2 indicator wordings
used in this unit (D2.His.1, 2, 3, 4, 6, 9, 10, 11, 14, 16; D3.1, D3.2;
D4.2, D4.3) were verified against the framework's K–2 indicator table
opened 2026-10-23. The Maple Lane schoolhouse, library, park, and
timeline events are fictional practice material invented for this unit,
not claims about any real place. No video below is claimed as a verified
single episode: all video entries are clearly labeled preferred-channel
search links, and the adult picks and previews one short episode.

## Web references

1. **Reading Rockets — "Using primary sources in the classroom"** —
   https://www.readingrockets.org/blogs/sound-it-out/using-primary-sources-classroom
   *Why good:* explains primary sources (photographs, artifacts,
   diaries, letters) for elementary classrooms and points to the Library
   of Congress Teacher's Guides and Primary Source Analysis Tool
   (observe / reflect / question). Adult background for Lesson 04; the
   tool's three steps mirror this unit's source questions. *Found via
   search 2026-10-23; free, no account; adult previews.*
2. **Smithsonian Learning Lab — "Collections by Grade"** —
   https://learninglab.si.edu/collections-by-grade
   *Why good:* browseable Smithsonian museum collections organized by
   grade; the adult picks an elementary-appropriate collection of objects
   and photographs to show what sources look like beyond this unit's
   practice set. Adult-selected only; most linked collections are aimed
   above grade 2, so the adult previews and adapts. *Found via search
   2026-10-23; free, no account.*
3. **Library of Congress — "Teaching About Community and Place with
   Library of Congress Maps" (Teaching with the Library blog)** —
   https://blogs.loc.gov/teachers/2025/11/teaching-about-community-and-place-with-library-of-congress-maps
   *Why good:* teacher-facing ideas for using community sources with
   elementary students; supports the Maple Lane local-history framing and
   the Unit 01 map connection. Adult background and activity ideas only.
   *Verified live 2026-10-10 in Unit 01; free, no account.*
4. **Colorín Colorado — "Primary Sources, the Library of Congress, and
   English Learners"** —
   https://www.colorincolorado.org/article/primary-sources-library-congress-and-english-learners
   *Why good:* explains the Library of Congress classroom materials
   (Primary Source Sets, lesson plans, themed resources), notes they are
   free with no registration required, and gives ideas for using visual
   sources with language learners — directly useful for this unit's
   picture-first approach. Adult background. *Found via search
   2026-10-23; free, no account.*
5. **C3 Framework — K–2 indicators guide** —
   https://5il.co/p0qk
   *Why good:* the K–2 indicator table whose wordings this unit's
   standards notes follow (history indicators D2.His.1–16, D3.1–3.2,
   D4.1–4.3 in the K–2 band). Adult reference only; not assigned to the
   learner. No state adoption or alignment certification is claimed.
   *Found via search 2026-10-23; adult reference.*
