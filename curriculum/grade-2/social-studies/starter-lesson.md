# Starter Lesson — Use symbols to read a community map

**Status:** draft supplement. **Time:** three 20–25 minute sessions. **Goal:** Read a map key, describe simple directions, and explain how community places meet needs.

## Adult preparation and readiness

Use this fictional map, paper, and pencil. No private location details are needed. Readiness: learner recognizes familiar symbols (e.g., a simple drawing used for a place).

```text
N ↑
┌─────────────┐
│ L     P    C│
│             │
│ S     H    M│
└─────────────┘
Key: L library; P park; C clinic; S school; H homes; M market
```

## Teach and model

Explain that a map key connects a symbol to a place; north is the direction shown by the arrow. This map is fictional and not to scale.

**Worked example 1:** The key says C = clinic, so C on the map represents a clinic, not the letter C itself.

**Worked example 2:** Library is north of school because L appears above S. “Above” describes this page map; exact travel distance is unknown.

## Pacing and tasks

Session 1: adult models the key; guide tasks 1–2. Session 2: learner does route tasks 3–4 with optional finger tracing. Session 3: application and error check, then exit response.

1. **Guided:** Use the key to tell what P and M represent.
2. **Guided:** Which place is north of school? Which is east/right of homes on the page?
3. **Independent:** Describe a route from school to clinic using a start, destination, and one intermediate place. (A route can be chosen by the learner on this schematic; accept a direction sequence consistent with the drawing.)
4. **Independent:** Add a symbol for a bus stop and put it in the key.
5. **Adult-guided error check:** Adult changes key to P = library. Ask why the map is now confusing and repair it.
6. **Application:** Choose one place and explain one need it can help meet.

**Answer checks:** P = park, M = market; library is north of school; market is east/right of homes. Routes depend on chosen path but must use the map consistently. A bus-stop symbol and key must match. Plausible needs: healthcare, learning/borrowing, recreation, food, schooling.

## Exit check and product

Learner explains one key symbol and one relationship between places. Product: annotated map and short oral/scribed explanation.

## Review rubric

| Criterion | 2 — shows skill | 1 — developing | 0 — not yet observed |
|---|---|---|---|
| Key | Interprets two symbols correctly | Uses key with prompt | Reread key together |
| Direction | Uses page direction consistently | Correct with finger tracing | Adult models north arrow |
| Community | Links one place to a plausible need | Chooses from examples | Discuss familiar services |

Use large/tactile symbols, a finger route, read-aloud, and dictation. A fictional map avoids disclosure and works offline. Do not treat a schematic as to scale or as safe real-world directions.
