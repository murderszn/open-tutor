# Teacher Guide — Unit 05

**For the guiding adult.** This guide covers objectives, common
misconceptions, differentiated supports, extensions, and what "ready to
move on" looks like. Solutions live in [answer-key.md](answer-key.md) —
keep it separate from the learner's materials.

## Objectives recap

1. Define **habitat** and name the four things it gives: food, water,
   shelter, space.
2. Observe one local habitat and tally the **different kinds** of
   plants and animals, counting kinds not individuals.
3. Observe a second local habitat with the same rules and tally its
   kinds.
4. Compare two habitats' tally charts and state which holds more
   kinds, with the counts as evidence (2-LS4-1).
5. Describe a pattern (more food/water/shelter/space, or more plant
   kinds, goes with more kinds) with observations behind it.

## Lesson-by-lesson misconception notes

- **L01:** "A habitat is just where it sleeps." Counter with the
  four-things check: "Does it give food? Water? Shelter? Space?
  Then it is a habitat." Also: "a habitat is a place on a map" — a
  map label is not a habitat until you can name what it gives.
- **L02:** "Count how many" instead of "count kinds." This is the
  unit's biggest trap and it recurs all unit. Counter every time with
  "Is this a new kind, or one I already wrote down?" The ant example
  (100 ants = 1 kind) is the cleanest counter.
- **L03:** "More time or more lookers is fine." Counter with the
  unfair-comparison example: the pond counted for 30 minutes with a
  friend cannot be compared with the garden counted for 10 minutes
  alone. Same time, same rules, same lookers.
- **L04:** "Feelings are evidence" ("prettier," "busier," "I like
  it"). Counter by asking for the numbers every time: "How many kinds
  did you count in each?" Also: a tie (7 vs. 7) is a real answer —
  "the same" counts as a comparison.
- **L05:** "More kinds is always better" / "gardens always beat
  lawns." Counter with the desert: few kinds, but exactly right for
  the living things there. A pattern is "usually," not "always," and
  it explains what we saw — it does not judge habitats.

## Differentiated supports

- **Response modes:** Every check accepts oral, pointing, drawing,
  manipulative, or adult-scribed answers. Never require handwriting to
  demonstrate science understanding.
- **Sentence frames:** "A habitat gives ___, ___, ___, and ___." /
  "This is a new kind." / "I already wrote this kind." / "My claim is
  ___. My evidence is ___." / "___ holds more kinds because ___."
  Keep them visible all unit.
- **Language:** Teach vocabulary with places and pictures first, word
  second; keep the visual word wall current (habitat, kind, tally,
  compare, pattern, shelter, space); welcome home-language labels,
  and pair *kind* with a "one row per kind" hand gesture.
- **Attention/pacing:** Sessions are 25–30 minutes by design. If a
  session runs long, split it: teach the worked examples one day,
  practice the next. Outdoor surveys work best in the morning, when
  more animals are active — count both habitats at about the same
  time of day.
- **Low vision:** Tactile tallying (a pebble per kind in a cup),
  large-print tally charts, high-contrast picture cards; the text-only
  alternative in Lesson 04 gives every picture count in words.
- **Outdoor access:** Every outdoor step has an indoor picture-based
  alternative using the generated image. A windowsill, a potted
  plant, or a picture habitat all count as habitats for this unit.
- **Assessment boundary reminder:** Never ask the learner to name a
  species or to match a specific plant/animal name to a specific
  habitat. Everyday descriptions ("a yellow flower," "a small brown
  bird") are the right level; the comparison is about counts of kinds.

## Extensions

- Survey a third habitat the same way and rank all three.
- Predict the kinds in a new habitat before visiting, then check.
- Keep a season log: revisit Habitat A in a different season and
  compare the kind counts (a later unit's retrieval thread).
- Research one pictured habitat (ocean, desert, rainforest) from the
  Resource Pack and report three kinds that live there — as a
  reading-and-talk activity, not as assessed species knowledge.

## Readiness to move on

The learner is ready for Unit 06 when they can: (1) name the four
things a habitat gives; (2) tally a habitat by kinds without counting
individuals; (3) compare two tally charts with both counts as
evidence; and (4) state one pattern with an observation behind it.
The project rubric (8–10 points) and the unit assessment are the
evidence; the quiz (6 of 8) is the formative check. If the learner
still counts individuals, re-teach Lesson 02 with the picture tally
before moving on — Unit 06's map work assumes the learner can observe
and record a place carefully.
