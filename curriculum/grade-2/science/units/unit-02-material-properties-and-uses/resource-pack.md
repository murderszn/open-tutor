# Resource Pack — Unit 02

**Goal:** Support a grade-2 learner (ages 7–8) in describing and sorting
materials by observable properties, testing absorbency and sink-or-float
fairly, and choosing the best material for a purpose with evidence.
**Age fit:** all items below were checked 2026-10-16 for grade-2
appropriateness; nothing here requires an account.

## Videos

Search links (preferred channels — pick a current episode together with
the learner; the adult previews before showing):

1. **Preferred-channel search (SciShow Kids):** search YouTube for
   `SciShow Kids materials properties` — the channel's early-elementary
   episodes model observing and testing material properties with simple
   language. Supports Lessons 01–03.
2. **Preferred-channel search (PBS LearningMedia):** search
   pbslearningmedia.org for `properties of matter grade 2` — short
   captioned clips on sorting and testing materials. Supports Lessons
   01–04.
3. **Preferred-channel search (Sid the Science Kid):** search YouTube for
   `Sid the Science Kid materials` — playful property-sorting segments that
   reinforce "same rule for every object." Good discussion starter for
   Lesson 01's extension.

Direct resource:

4. **ACS Inquiry in Action animations** — the Chapter 1 lessons include
   short animations (e.g., why felt and paper absorb water while plastic
   and foil do not) embedded in the lesson pages. Open via Web 1 below;
   adult previews. Supports Lesson 03.

## Web references

1. **ACS Inquiry in Action — Chapter 1: Properties of Materials (Grade
   2)** — full classroom lessons: 1.1 classifying objects by observable
   properties, 1.2 testing materials, 1.3 designing an absorbency test,
   1.4 using properties to improve a model boat. Free, no account. The
   unit's Lessons 01–03 and project follow the same test-fairly logic.
   https://www.acs.org/education/resources/k-8/inquiryinaction/second-grade/chapter-1.html
2. **ACS Grade 2, Lesson 1.1 NGSS alignment (PDF)** — official-style
   alignment sheet naming 2-PS1-1, its clarification language, and the
   "same characteristics" grouping routine; corroborates this unit's
   standards notes.
   https://acs.org/content/dam/acsorg/education/k-8/inquiry-in-action/second-grade/g2-l1.1-ngss.pdf
3. **ACS Grade 2, Lesson 1.3 NGSS alignment (PDF)** — absorbency testing
   of paper, plastic, felt, and foil with the fair-test setup ("all
   materials need to be tested in the same way") and the 2-PS1-2
   assessment boundary. Direct model for Lesson 03 and the project.
   https://www.acs.org/content/dam/acsorg/education/k-8/inquiry-in-action/second-grade/g2-l1.3-ngss.pdf
4. **NSTA reproduction of the official NGSS 2-PS1 document (PDF)** — full
   performance expectations, clarification statements, and assessment
   boundaries the standards notes were verified against.
   https://static.nsta.org/ngss/20130509/dci-individual/2-PS1-MatterAndItsInteractions.pdf
5. **NGSS disciplinary core idea PS1.A page** (nextgenscience.org) —
   official performance-expectation text for 2-PS1-1 and 2-PS1-2, grade-2
   band.
   https://www.nextgenscience.org/disciplinary-core-idea/ps1a-structure-and-properties-matter?page=4
6. **NSTA NGSS standard display: 2-PS1-1** — performance expectation with
   clarification statement and CCSS connections (W.2.7, W.2.8, 2.MD.D.10).
   https://my.nsta.org/ngss/DisplayStandard?view=pe&id=59
