# Practice — Unit 02: Material Properties and Uses

Short written or scribed practice (6–8 tasks per session slice), reviewed
the same day by the guiding adult. Tasks 1–3 pair with Week 7 (properties);
tasks 4–6 with Week 8 (absorbency, sink-or-float); tasks 7–8 with Week 9
(data and claims). The adult reads every task aloud; the learner may
answer orally, by pointing, by drawing, or in writing, and the adult
scribes dictated answers.

## Testing-station practice (Sessions 2 and 6)

**Task 1 — One-rule sort.** Here are 6 objects: wooden block, metal spoon,
cotton ball, plastic cup, rock, rubber band. Sort them by *flexibility*
into "bends easily" and "does not bend easily." Write or dictate your rule
first.

**Task 2 — Property hunt.** Find 3 objects in the room. For each, name the
material it is made of and one property (color, texture, hardness, or
flexibility). Example: "The doorknob is metal. It is smooth and hard."

**Task 3 — Test table.** Run the scratch test and the bend test (Lesson
02) on these 4 materials, the same way each time. Fill the table:

| Material | Scratch test (mark? no mark?) | Bend test (bends? stays stiff? breaks?) |
|---|---|---|
| Chalk | | |
| Cardboard strip | | |
| Sponge | | |
| Plastic lid | | |

**Task 4 — Predict, then test: sink or float.** For each object, write your
prediction FIRST (sink or float), then test it in a bin of water, then
write what happened:

| Object | My prediction | What happened |
|---|---|---|
| Metal spoon | | |
| Wooden block | | |
| Plastic bottle cap | | |
| Rock | | |
| Sponge | | |
| Orange (with peel) | | |

Circle the predictions that were wrong. Wrong predictions are good —
they mean the test taught you something.

**Task 5 — Absorbency re-test.** Re-run the Lesson 03 absorbency test on
two NEW materials (adult's choice). Same-size pieces, one spoon of water,
count to 30, lift and look. Record: "soaks" or "does not soak."

**Task 6 — Fair or not?** Read each test plan. Say "fair" or "not fair,"
and fix the unfair ones.

a. "Which soaks more — towel or sponge? I'll use same-size pieces, one
   spoon of water on each, and wait 30 counts for both."
b. "Which is harder — rock or chalk? I'll scratch the rock once gently
   and the chalk ten times hard."
c. "Which floats better — wood or metal? I'll drop both in the water at
   the same time and watch."

## Data-talk practice (Session 11)

**Task 7 — Read the table.** A scientist tested two materials for a
"keep-dry" job. One spoon of water on each, 30-count wait, 3 trials.

| Material | Trial 1 (dry underneath?) | Trial 2 | Trial 3 |
|---|---|---|---|
| Wax paper | Yes — dry | Yes — dry | Yes — dry |
| Napkin | No — wet | No — wet | No — wet |

a. Which material won the keep-dry job?
b. What is your evidence? (Use the table.)
c. Was the test fair? How do you know?

**Task 8 — Best material for the job.** Match each job to the better
material AND the property that matters. Write one sentence for each using
the frame: "The ___ is better for ___ because ___."

a. Raincoat: plastic sheet or paper towel?
b. Bridge for heavy toy trucks: wooden planks or cooked spaghetti?
c. Pillow: feathers or rocks?
d. Winter boots that keep feet dry: rubber or cloth?
