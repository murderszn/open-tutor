# Starter Lesson — Compare how far an object rolls

**Status:** draft supplement. **Time:** three 25–30 minute sessions. **Goal:** Ask a question, observe a rolling object on two surfaces, and explain a pattern using evidence.

## Adult preparation and readiness

Use a toy car/ball, short ramp made from a book and board, smooth paper, a towel, and a ruler or tape measure (or equal paper strips as units). Clear a floor-level path. Adult sets ramp height and supervises; no rolling near stairs, pets, or people. Readiness: learner can compare “farther/shorter” in a demonstration.

## Teach and model

Explain that a fair comparison changes one thing and keeps other conditions similar. The object starts at the same point, from the same ramp height, and is released without a push. Measure from the end of the ramp to where it stops.

**Worked example 1:** Smooth surface: runs 42, 40, and 41 cm. The distances are close to each other, so repeated tries show a similar result.

**Worked example 2:** Towel surface: runs 25, 24, and 26 cm. Compare matching attempts: smooth was farther each time (42 > 25, 40 > 24, and 41 > 26). In this practice dataset the toy went farther on smooth paper, but one toy and two surfaces cannot prove a rule for all objects.

## Pacing and tasks

Session 1: model variables and guide tasks 1–2. Session 2: learner collects three trials (or uses clearly labeled sample values); adult helps measure. Session 3: compare, complete error check, and explain.

1. **Guided:** State the question: Does surface change how far the toy travels?
2. **Guided:** Name what changes (surface) and two things to keep the same.
3. **Independent with adult supervision:** Record three distances for each surface.
4. **Independent:** Circle the surface with the greatest travel distance in each run.
5. **Adult-guided error check:** One trial used a push and two were released. Explain why the trials are not a fair comparison.
6. **Application:** Complete “The toy went farther on ___ because my data show ___.”

**Sample answer checks:** Smooth paper went farther in all three sample runs; the repeated results are similar within each surface. The push changes the release force. Actual learner data may differ; report what was measured rather than forcing the sample result.

## Exit check and product

Learner points to the data and states one supported claim. Product: labeled data table and one evidence sentence or oral/scribed explanation.

## Review rubric

| Criterion | 2 — shows skill | 1 — developing | 0 — not yet observed |
|---|---|---|---|
| Fair-test plan | Changes only surface and keeps start conditions similar | Names one control | Re-demonstrate release |
| Data | Records distances with units | Records with adult help | Compare farther/shorter qualitatively |
| Claim | Uses a measured value to support a result | Gives result without evidence | Model evidence sentence |

For access, use a ball rolled by an adult, wider ramp, visual distance markers, or a preprinted table. A learner can point or dictate. Avoid heights and hard objects; adult manages the ramp. Sample numbers are practice data, not actual observations.
