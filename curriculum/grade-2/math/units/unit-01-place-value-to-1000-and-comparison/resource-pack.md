# Resource Pack — Unit 01: Place Value to 1000 and Number Comparison

**Summary (adult planning judgment):** supplements for teaching hundreds
place value, three-digit reading/writing/expanded form, skip-counting, and
three-digit comparison to a 2nd grader; every core objective also has a
free, no-account, offline path (blocks, thousand chart, number line).

**Check date:** 2026-10-09/10 (all items below). Video runtimes and caption
availability are reported only where the source page showed them; anything
else is marked unverified — preview before assigning.

## Videos (3 curated + labeled search links)

1. **Khan Academy — "Expanded form of numbers"** (2nd-grade place-value
   unit): works through 832 as 800 + 30 + 2 and 415 as 400 + 10 + 5 —
   directly models Lesson 03's expanded form. Free; watchable without an
   account. Runtime unverified — preview first.
   <https://www.khanacademy.org/math/cc-2nd-grade-math/cc-2nd-place-value/x3184e0ec:numbers-in-standard-word-and-expanded-form/v/expanded-form-of-numbers>
2. **Nagwa — "Comparing Three-Digit Numbers Using a Place Value Table"**:
   compares 251 and 234 with a place-value grid, hundreds first — the same
   number pair as this unit's generated illustration (234 vs. 241 is the
   sibling case). Free; no account. Runtime unverified.
   <https://www.nagwa.com/en/videos/832123267034/>
3. **PBS / Wyoming PBS — "Teaching in Room 9: Place Value & Comparing
   Three-Digit Numbers"** (2nd Math): full classroom lesson with charts and
   manipulatives on three-digit value and comparison; 28m32s; closed
   captions; free stream on pbs.org / PBS app. Best as an adult preview or
   a watch-together segment, not a full sitting for a 7-year-old.
   <https://video.wyomingpbs.org/video/place-value-comparing-three-digit-numbers-2-2nd-math-i1ylyo/>
4. **Open search (labeled, unverified item):** YouTube search
   `place value hundreds tens ones second grade` — use only after previewing
   a specific result for age fit, ads, and accuracy.
5. **Open search (labeled, unverified item):** YouTube search

## Web references

1. **Common Core State Standards — Mathematics** (framework source; the

## Access notes

- Every core objective is teachable fully offline: base-ten blocks (or
  banded straws), a hand-drawn thousand chart, and a number-line strip
  require no account, no device, and no purchase beyond dollar-store
  supplies.
- All five web references above are free with no account required to view.
- Videos supplement explicit teaching; none replaces the lessons. Preview
  for ads, comments, and age fit (especially open-search results).
- Captions/runtime were verified only for the PBS item (28m32s, closed
  captions per its page); all others are marked unverified above.
