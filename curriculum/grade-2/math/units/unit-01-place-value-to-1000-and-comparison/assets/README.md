  squares, 3 vertical bars, 4 tiny squares; bottom row = 2 large squares, 4

  two numbers and record the comparison). The learner points to each block
  kind, counts by place, and records `234 < 241` with hundreds-first
  reasoning.

- **Caption:** "An AI-generated picture of base-ten blocks. Top row: big

  blocks. What number does each row show — and which is greater?"
- **Alt text:** "Two rows of solid orange base-ten blocks on white. Top row:

- **Text-only alternative** (carries every count the activities need, so the

- **Known limitations:** AI illustration, not a photograph — stylized flat
  shapes. The large squares stand for hundreds **by agreement**: the learner
  builds a real hundred-flat from 10 ten-rods in Lesson 01, so the class
  treats the picture's large squares as the same agreed hundred unit; the
  picture itself does not prove each square holds 100 cells (it is drawn
  without internal grid lines for exactly this reason). Color is never the
  only cue in unit activities: blocks are distinguished by size and shape,
  and the same tasks are done with the learner's own manipulatives. Do not
  use this image as evidence of real observations; counts in learner
  activities come from the learner's own blocks.
