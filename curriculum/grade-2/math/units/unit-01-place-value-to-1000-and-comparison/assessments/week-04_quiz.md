# Formative Quiz — Unit 01 (Session 15)

**Format:** oral / observed / built with blocks; the adult scribes written
work. 6 items, ~15 minutes. This is a check, not a grade — misses go to the
Session 12/16 re-teach list.

**Unit:** [U01](../README.md) · **Answer key:**
[answer-key.md](../answer-key.md#formative-quiz)

1. **Build and name.** "Build 342 with blocks. Tell me what each digit
   means." *(Objective 1)*
2. **Number name → numeral.** The adult says: "seven hundred five." "Write
   the numeral." *(Objective 2)*
3. **Expanded form.** "Write 680 in expanded form." *(Objective 2)*
4. **Skip-count.** "Skip-count by 10s from 370 to 420." *(Objective 3)*
5. **Compare.** "Compare 518 and 581. Write the comparison with `>`, `=`,
   or `<`, and tell me why." *(Objective 4)*
6. **Order.** "Put 299, 292, and 309 in order from least to greatest."
   *(Objective 5)*

**Scoring (adult use):** 5–6 correct = secure, move to the unit assessment;
3–4 = developing — re-teach the missed objectives before Session 16;
0–2 = not yet — use the track's flexible weeks before continuing.
