# Lesson 03 — Read, Write, and Expand Numbers to 1000

**Student goal:** I can write a three-digit number as a numeral, a number
name, and an expanded form — and go back the other way.
**Time:** 25–30 minutes · **Unit:** [U01](../README.md) · **Session 8 of 16**

## Materials

- Built block numbers from Lesson 02 (or rebuild: 647, 830)
- Paper folded into three columns labeled **Numeral | Number name | Expanded form**
- Number cards 100–999

## Readiness check (2 minutes)

"Build 520. Tell me each digit's place." (Expected: 5 flats, 2 rods, 0 cubes
— "5 hundreds, 2 tens, 0 ones.") If zero-place builds are shaky, re-do
Lesson 02's exit check first.

## Teaching

One number, three costumes:

1. **Numeral** (base-ten digits): 647.
2. **Number name** (words): "six hundred forty-seven." Say the hundreds part,
   then the rest like a two-digit number. Note: we say "six hundred," not
   "six hundreds," and there is no "and" — "six hundred forty-seven."
3. **Expanded form** (value of each place added): 600 + 40 + 7.

Zero places: in the numeral we write the 0 (830, not 83). In the number name
we skip the zero place ("eight hundred thirty" — no "zero tens"). In expanded
form we can write 800 + 30 + 0 or just 800 + 30 — both are correct, but the
numeral keeps the 0.

**Key vocabulary:** *numeral*, *number name*, *expanded form*.

## Worked example 1 — 647 in three forms

The adult builds 6 flats + 4 rods + 7 cubes, then fills the three columns:

> "Numeral: **647** — write the digits in place order."
> "Number name: **six hundred forty-seven** — hundreds part first, then
> 'forty-seven' like a two-digit number."
> "Expanded form: **600 + 40 + 7** — each digit's value, added. Check: 600 +
> 40 + 7 = 647. The parts add back to the whole."

**Reasoning to name aloud:** expanded form proves the numeral is honest —
each piece is exactly what its place is worth, and the pieces sum to the
number.

## Worked example 2 — 830: the silent zero

The adult builds 8 flats + 3 rods + 0 cubes:

> "Numeral: **830** — the zero stays! Without it we'd have 83."
> "Number name: **eight hundred thirty** — we don't say the zero tens."
> "Expanded form: **800 + 30 + 0**, or 800 + 30. Both true."

Then the reverse direction: the adult writes "400 + 50 + 9" and asks for the
numeral. "4 hundreds, 5 tens, 9 ones — **459**."

**Reasoning to name aloud:** going backward (expanded → numeral) is just
reading the hundreds, tens, ones counts as digits in order. The forms are
three views of one number, not three different numbers.

## Guided practice (adult stays close, hints allowed)

Do 4–6 short rounds across all three forms and both directions.

1. Dictation: adult says "three hundred twenty-six" — learner builds and
   writes the numeral. (Expected: 326.)
2. The adult writes 700 + 20 + 5: "Numeral and number name?"
   (Expected: 725, "seven hundred twenty-five.")
3. Write 590 in expanded form. (Expected: 500 + 90 + 0, or 500 + 90.)
4. Error analysis: the adult writes the number name "five hundred eight" as
   58. Ask: "Right or wrong? Fix it." (Expected: wrong — missing the zero
   tens placeholder; correct numeral is 508.)
5. Build 914, then write all three forms. (Expected: 914; "nine hundred
   fourteen"; 900 + 10 + 4.)
6. Reverse challenge: "900 + 60 + 3 = ?" (Expected: 963.)

## Independent practice

The learner draws 4 number cards and completes the three-column chart for
each: numeral → number name → expanded form. Then the adult gives 2 expanded
forms (e.g., 300 + 40 + 8; 500 + 7) for the learner to convert to numerals
(348; 507 — note the zero tens!). The adult checks zero placeholders.

*Alternate response mode:* say each form aloud while the adult writes; the
learner points to the matching blocks for verification.

## Application

Number-name telephone: the adult whispers a number name ("four hundred
seventy-one"); the learner builds it, writes the numeral, and whispers a new
number name back. Three rounds each. Listening carefully is the skill —
misheard tens become wrong numerals, caught by the build.

## Exit check

"Write 592 as a numeral, a number name, and in expanded form." Expected:
592; "five hundred ninety-two"; 500 + 90 + 2. Record: secure / developing /
not yet.

## Supports

- **Language access:** post the number-name pattern: "[hundreds word]
  hundred [tens-ones word]"; practice teen names (thirteen–nineteen) which
  don't follow the tens pattern.
- **Alternate response mode:** match pre-written form cards (numeral ↔ name ↔
  expanded) instead of writing from scratch.
- **Floor-play variant:** three floor zones labeled with the form names; the
  learner carries the number card to each zone and says that form.

## Extension

"Write 1,000 in expanded form." (1000, or 900 + 100 — discuss: expanded form
usually stops at the largest place, so just 1000. Teaser for thousands.)
Or: "Find the mistake: 600 + 30 + 12 = 642." (Expected: 12 ones should be
regrouped — 1 ten and 2 ones — so it's 600 + 40 + 2 = 642. Each place holds
one digit.)

## Teacher note

**Likely misconceptions:** (1) dropping zero placeholders in numerals (508 →
58) — always build first; (2) writing "and" in number names ("six hundred
and forty-seven") — standard school usage omits it; accept "and" orally but
model without; (3) thinking expanded form changes the number — recombine the
parts to check.
