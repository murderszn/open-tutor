# Unit Assessment — Unit 05: Equal Groups, Arrays, and Repeated Addition

**Unit:** [U05](../README.md) · **Format:** performance tasks, oral/observed,
adult-scribed where the learner is not yet writing independently
**Adult note:** the learner builds with counters or graph paper before
writing anything. Solutions and scoring guidance are in
[answer-key.md](../answer-key.md) — kept separate from this student page.
This assessment is a teaching check, not a standardized or validated
assessment. Total: 10 points.

## Part A — Odd or even (2 points)

Sort each number by pairing counters: 7, 10, 15, 18. For each one, say
odd or even and name the pairs and the leftover (or "none left over").

**Scoring:** 2 points if all four are sorted correctly with the pairs
and leftover named; 1 point if three are correct; 0 points if two or
fewer are correct.

## Part B — Two equal addends (2 points)

1. Write 8 as a sum of two equal addends.
2. Write 16 as a sum of two equal addends.
3. Pick one more even number up to 20 and write it as a sum of two
   equal addends.

**Scoring:** 2 points if all three are correct (any valid third number
with its matching split); 1 point if two are correct; 0 points if one
or none are correct.

## Part C — The apple array (3 points)

Use the picture in
[Lesson 04](../lessons/lesson-04-rectangular-arrays-rows-and-columns.md)
(or its text alternative: 4 rows with 5 apples in each row).

1. Write the repeated-addition equation by rows, and the total.
2. Write the repeated-addition equation by columns, and the total.
3. Draw or build a new array with 3 rows of 4 counters and write its
   row equation and total.

**Scoring:** 1 point per item (each needs the equation and the total).
3 points total.

## Part D — Partition a rectangle (2 points)

On graph paper, draw a rectangle 4 squares wide and 3 squares tall.
Partition it into same-size squares and count them.

1. How many squares are there? Write the row equation.
2. Write the column equation and check that the totals match.

**Scoring:** 1 point for the correct count with the row equation; 1
point for the correct column equation with matching totals.

## Part E — An array story (1 point)

"Mia plants 5 rows with 3 seeds in each row. How many seeds? Write the
equation."

**Scoring:** 1 point for the correct equation and total (the build must
match the story: 5 rows, 3 in each row).

**Total score:** 8–10 = secure; 5–7 = developing (re-teach the
lowest-scoring part before Unit 06); 0–4 = not yet (replay the matching
lesson, then re-assess with fresh numbers).
