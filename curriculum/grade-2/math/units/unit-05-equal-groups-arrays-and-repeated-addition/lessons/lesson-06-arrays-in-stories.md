# Lesson 06 — Arrays in Stories

**Student goal:** I can read a story, build the array it describes,
write the repeated-addition equation, and check my answer a second way.
**Time:** 25–30 minutes · **Unit:** [U05](../README.md) · **Session 11 of 16**

## Materials

- 25 counters
- Graph paper and crayons

## Readiness check (2 minutes)

"Build a 4-by-3 array. Tell me the row equation and the total."
(Expected: 3 rows of 4 — 4 + 4 + 4 = 12.) If arrays are shaky, replay
Lesson 04 with 4 rows of 3 before starting — this lesson only adds the
story around the array.

## Teaching

A story can hide an array. Find it in four moves:

1. **Read the story.** Find the groups: how many groups, and how many
   in each group? ("5 rows with 3 seeds in each row" — 5 groups, 3 in
   each.)
2. **Build the array** with counters — one row per group, the same
   number in every row.
3. **Write the equation**: the group size, once per group. Add left to
   right, saying the running total.
4. **Check a second way**: count by columns, or re-pair the total as
   odd/even. If the two counts disagree, rebuild — do not pick one and
   hope.

**Key vocabulary:** *groups of* (the story's clue words). "5 rows of 3"
and "5 groups of 3" both mean five 3s added together.

## Worked example 1 — Seeds in rows

"Mia plants 5 rows with 3 seeds in each row. How many seeds?"

Build it: 5 rows, 3 counters in each row.

> "5 groups of 3: 3 + 3 + 3 + 3 + 3. Add left to right: 3 + 3 = 6;
> 6 + 3 = 9; 9 + 3 = 12; 12 + 3 = 15. **15 seeds.** Check by columns:
> 3 columns of 5 — 5 + 5 + 5 = 15. Same total."

## Worked example 2 — Books on shelves

"There are 4 shelves with 2 books on each shelf. How many books?"

Build it: 4 rows, 2 counters in each row.

> "4 groups of 2: 2 + 2 + 2 + 2 = 8. **8 books.** Check by pairing:
> 8 is even — 4 pairs, none left over — and 8 = 4 + 4, two equal
> addends. The checks agree."

**Reasoning to name aloud:** the story's numbers are not the addends
until you know which one is the group size. "5 rows with 3 seeds" —
the addend is 3 (what is IN a row), written 5 times. Writing 5 five
times would count the rows, not the seeds.

## Guided practice (adult stays close, hints allowed)

Do 4–6 short rounds with the counters.

1. "3 trays with 5 muffins on each tray. How many muffins? Build it
   and write the equation." (Expected: 5 + 5 + 5 = 15 muffins.)
2. "2 rows with 4 chairs in each row. How many chairs? Build it and
   write the equation." (Expected: 4 + 4 = 8 chairs.)
3. "5 bags with 2 marbles in each bag. How many marbles? Build it,
   write the equation, and check by columns." (Expected: rows
   2 + 2 + 2 + 2 + 2 = 10; columns 5 + 5 = 10 marbles.)
4. Error analysis: the adult reads, "4 rows with 5 stickers in each
   row," builds 4 rows of 5, and writes "4 + 4 + 4 + 4 = 16." Ask:
   "Is it?" (Expected: wrong — the build is right but the equation
   counts the rows, not the stickers. Each row holds 5 stickers, so
   the equation is 5 + 5 + 5 + 5 = 20 stickers.)
5. "Say it two ways: the story's groups, then the equation." (Use
   round 1: "3 trays of 5 — 5 + 5 + 5 = 15 muffins.")

## Independent practice

The learner builds and writes, without hints: "4 boxes with 3 crayons
in each box. How many crayons?"; "2 rows with 5 plants in each row.
How many plants?"; "5 rows with 4 dots in each row. How many dots?"
The adult checks that the built array matches the story before the
equation is written.

*Alternate response mode:* build the array and point to each row while
saying its count aloud; the adult writes the equation.

## Application

Class garden: "Our class garden has 3 beds. Each bed holds 4 plants.
Draw the beds as a partitioned rectangle and tell me how many plants
there are." (Expected: a 3-by-4 rectangle — 3 rows of 4 squares —
4 + 4 + 4 = 12 plants. Accept a counter-built array as the drawing's
equal: the rectangle, the equation, and the total are what count.)

## Exit check

"4 rows with 3 apples in each row. Build it, write the equation, and
tell me the total." Expected: 3 + 3 + 3 + 3 = 12 apples. Record:
secure / developing / not yet.

## Supports

- **Language access:** always say the story's groups first ("5 rows
  with 3 seeds"), then the equation; never let a bare equation be the
  only answer.
- **Alternate response mode:** build the array and point to each row
  while saying its count; the adult writes the equation.
- **Floor-play variant:** lay out the story's rows on the floor with
  counters and walk each row, saying the running total at the end of
  each row.

## Extension

"Write your own array story with a total of 20, build it, and solve
it." (For example: "5 rows with 4 stickers in each row" —
4 + 4 + 4 + 4 + 4 = 20 stickers; or "4 rows with 5 stickers" —
5 + 5 + 5 + 5 = 20.) Or: "A story says '3 groups of 5' and another
says '5 groups of 3.' Do they have the same total? Prove it." (Both
are 15: 5 + 5 + 5 = 15 and 3 + 3 + 3 + 3 + 3 = 15.)

## Teacher note

**Likely misconceptions:** (1) writing the number of groups as the
addend (the Lesson 03 error, back in a story) — ask "how many are IN
one row?" before writing; (2) building unequal rows because the story
was misread — the build must match the story exactly, or the equation
answers a different story; (3) skipping the check — the second count
is the lesson, not a chore: a mismatch means rebuild, not a coin flip.
