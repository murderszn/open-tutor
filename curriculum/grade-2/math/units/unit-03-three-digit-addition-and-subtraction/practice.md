# Practice, Game, and Review Sessions — Unit 03

**Unit:** [U03](README.md) · **Sessions:** 2, 4, 6, 8, 10, 13 of 16
**Adult note:** every session is 25–30 minutes. The learner builds first,
writes second, and checks by the inverse operation third. Solutions are in
[answer-key.md](answer-key.md) — kept separate from this student page.

## Session A — Build-and-add trays

Use base-ten blocks and the place-value mat. For each round, build both
numbers, trade where a column reaches ten, then write the sum.

**No-regrouping round (Session 2):**

1. 432 + 125
2. 671 + 203
3. 508 + 340
4. 724 + 151

**Regrouping round (Session 6):**

1. 347 + 128
2. 562 + 289
3. 194 + 357
4. 476 + 153

**Success criterion:** 3 of 4 builds correct, with every trade named aloud
("ten ones become one ten" / "ten tens become one hundred").

## Session B — Trade-down stations

Use base-ten blocks. For each round, build the starting number, trade down
where a column runs short, take blocks away, then write the difference and
check by adding back.

1. 876 − 432 (no trade)
2. 543 − 218 (decompose a ten)
3. 635 − 487 (decompose a hundred)
4. 702 − 356 (across zero)
5. 900 − 468 (across zero, double trade)

**Success criterion:** 4 of 5 differences correct, with every trade marked
on the written method before the answer is read.

## Session C — Compose-and-decompose games

**Compose-ten card race (Session 4):** the adult turns over two number
cards (100–999). The learner builds the sum and calls out "trade!" or "no
trade!" before solving. First to 5 correct trade calls wins the round;
accuracy beats speed — a wrong trade call loses the point.

Suggested card pairs: 253 + 166, 318 + 423, 342 + 125, 386 + 274, 147 + 232.

**Decompose dash (Session 10):** the adult turns over two number cards
for a subtraction. The learner calls out "trade in ones / tens / hundreds
/ across zero / no trade" before solving, then builds it. Suggested pairs:
486 − 231, 453 − 128, 521 − 376, 403 − 158, 712 − 456.

**Success criterion:** the trade call is correct for at least 4 of 5
pairs in each game, even if one final answer is still developing.

## Session D — Mixed review and error hunt (Session 13)

Solve each problem, then hunt the planted error in the last two items.
All problems use blocks first.

1. 245 + 371
2. 608 − 274
3. 359 + 100 (mental — which digit changes?)
4. 840 − 100 (mental — which digit changes?)
5. Planted error: "674 + 183 = 747." Is it? Find the error and correct it.
6. Planted error: "800 − 357 = 543." Is it? Find the error and correct it.

**Success criterion:** 4 of 6 correct including at least one planted
error found and explained; the adult re-teaches the highest-need objective
from the exit checks before the Session 14 quiz.
