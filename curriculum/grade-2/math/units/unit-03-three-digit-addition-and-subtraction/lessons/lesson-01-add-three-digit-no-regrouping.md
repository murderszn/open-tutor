# Lesson 01 — Add Without Regrouping: Hundreds with Hundreds

**Student goal:** I can add two three-digit numbers with blocks when no
column reaches ten, and I can write the sum the same way I built it.
**Time:** 25–30 minutes · **Unit:** [U03](../README.md) · **Session 1 of 16**

## Materials

- Base-ten blocks: hundred-flats, ten-rods, one-cubes
- A place-value mat with three columns: hundreds, tens, ones

## Readiness check (2 minutes)

"Build 342 with blocks. How many hundreds, tens, and ones?" (Expected: 3
flats, 4 rods, 2 cubes.) If building a three-digit number is shaky, replay
Unit 01 Lesson 02 before starting — this lesson adds two builds together.

## Teaching

Addition does not change the rules of place value; it just puts two builds
on one mat.

1. Build the first number on the mat, one column at a time.
2. Build the second number underneath it (or beside it), in the same
   columns.
3. Add **ones with ones, tens with tens, hundreds with hundreds** — always
   in that order, right to left, so the habit is ready for regrouping later.
4. Read the combined build as the sum. The written method is a record of
   the build: write each column total under its column.

**Key vocabulary:** *column*, *written method*. A column is one place on
the mat. The written method is not a new kind of math — it is the build,
written down.

## Worked example 1 — 342 + 125

Build 342 (3 flats, 4 rods, 2 cubes) and 125 (1 flat, 2 rods, 5 cubes).

> "Ones first: 2 cubes + 5 cubes = 7 cubes. Tens: 4 rods + 2 rods = 6 rods.
> Hundreds: 3 flats + 1 flat = 4 flats. The build is 4 hundreds, 6 tens,
> 7 ones — **467**."

Written method, matching the build column by column:

```text
  342
+ 125
-----
  467
```

**Reasoning to name aloud:** no column reached ten, so nothing had to be
traded. That is why this lesson is called "no regrouping" — the columns
stayed as they were.

## Worked example 2 — 213 + 405

Build 213 and 405. Ones: 3 + 5 = 8. Tens: 1 + 0 = 1 — the zero tens in 405
is a real column, not a gap to skip. Hundreds: 2 + 4 = 6.

> "2 hundreds, 1 ten, 8 ones — **618**. The zero in 405 mattered: it told
> us to add no tens in that column, so the tens total stayed 1."

**Reasoning to name aloud:** a zero digit still votes in its column.
Skipping it is the easiest way to turn 618 into a wrong answer.

## Guided practice (adult stays close, hints allowed)

Do 4–6 short rounds with the blocks.

1. "Build and add 461 + 237." (Expected: 698 — ones 8, tens 9, hundreds 6.)
2. "Build and add 502 + 341." (Expected: 843 — ones 3, tens 4, hundreds 8;
   name the zero tens in 502.)
3. "Build and add 730 + 148." (Expected: 878 — ones 8, tens 7, hundreds 8.)
4. Error analysis: the adult shows the written work "254 + 133 = 377" and
   asks: "Is it? Check each column with blocks." (Expected: wrong — ones
   4 + 3 = 7, tens 5 + 3 = 8 (not 7), hundreds 2 + 1 = 3; correct sum **387**.
   The tens column was added wrong, not traded.)
5. "Say the sum two ways: as hundreds/tens/ones, then as one number."
   (Use round 1: "6 hundreds, 9 tens, 8 ones — 698.")

## Independent practice

The learner builds and writes, without hints: 621 + 236, 104 + 523,
350 + 219. The adult checks that each build is made before the written
method is written, and that columns line up (ones under ones).

*Alternate response mode:* point to each column's blocks and say the
column total aloud; the adult writes the written method.

## Application

Library shelves: "One shelf holds 412 books. Another holds 263 books. How
many books on both shelves?" (Expected: build both, add column by column —
ones 5, tens 7, hundreds 6 — **675** books.)

## Exit check

"Build 345 + 132 and tell me the sum, column by column." Expected: ones
5 + 2 = 7, tens 4 + 3 = 7, hundreds 3 + 1 = 4 — **477**. Record: secure /
developing / not yet.

## Supports

- **Language access:** always say the sum two ways ("4 hundreds, 6 tens,
  7 ones — 467"); never let a bare numeral be the only answer.
- **Alternate response mode:** point to each column and hold up fingers
  for its total; the adult says the words and writes the numeral.
- **Floor-play variant:** lay the two builds as two rows on the floor,
  then slide matching columns together — the combined piles are the sum.

## Extension

"Add three three-digit numbers with no regrouping: 121 + 232 + 111."
(121 + 232 = 353; 353 + 111 = 464. Ones 1 + 2 + 1 = 4, tens 2 + 3 + 1 = 6,
hundreds 1 + 2 + 1 = 4 — **464**.) Or: "Invent a no-regrouping addition
whose sum is exactly 999, and prove it with blocks."

## Teacher note

**Likely misconceptions:** (1) adding left to right and losing track when
regrouping arrives in Lesson 02 — insist on ones first now, while it is
easy; (2) skipping a zero column (405, 502) — point at the empty column
and say "zero tens is a real vote"; (3) misaligning columns in the written
method (writing 342 + 125 as 342 + 1250) — the mat is the alignment check.
