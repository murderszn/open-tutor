# Unit Assessment — Unit 01: Vowel Teams, Syllables, and Word Parts

**When:** Session 16. **How:** adult administers; learner responds orally,
by pointing, or in writing. **Time:** 25–30 minutes.

Each task is tagged with its objective (O1–O6). The adult scores against
[answer-key.md](../answer-key.md#unit-assessment-session-16).

**Task 1 — Long or short? (O1).** Read: *cape, pin, hope, tub, kite*.
After each, say "long" or "short."

**Task 2 — Name the team (O2).** Read: *paint, away, green, each, night,
coat, soon, house*. After each, name the vowel team.

**Task 3 — Friend-card match (O2).** Look at
[`assets/vowel-team-friends.png`](../assets/vowel-team-friends.png).
"Which friend's name hides the **ai** team?" (rain cloud.) "Which hides
**oa**?" (boat.) "Name a word with the same team as the bee card." (Any
real ee word: *see, tree, green*….) "Name a word with the same team as
the leaf card." (Any real ea word: *sea, read, dream*….)

**Task 4 — Clap-and-break (O3).** Break into beats, read each beat, blend:
*picnic, paper, window, napkin*.

**Task 5 — Strip and define (O4).** Strip the prefix or suffix, read the
root, tell the meaning: *unlock, rewrite, careful, hopeless, jumped,
singing*.

**Task 6 — Tricky words (O5).** Read instantly: *said, have, of, was,
were, some, come, what*.

**Task 7 — Two-sound sort (O5).** Sort into two columns: *moon, book,
snow, cow, leaf, head*. (Column A — usual sound: moon, snow, leaf.
Column B — the flip: book, cow, head.) Say the team's sound in each word.

**Task 8 — Compound meaning (O6).** Break into parts and tell the meaning:
*lighthouse, popcorn, toothbrush*.

**Task 9 — Spell by pattern (O6).** The adult dictates: *badge* ("borrow
from *cage*"), *boil* ("borrow from *boy*"), *train* ("borrow from
*rain*"). The learner writes or tiles each.

**Task 10 — Case sentences (O2, O4).** Say or write two original
sentences: one using a vowel-team word from this unit, one using a
prefix or suffix word from this unit. Both words must be used correctly.

## Scoring

| Task | Points | Full credit |
|---|---|---|
| 1 | 5 | Each word read correctly + long/short correct (1 pt each) |
| 2 | 8 | Each word read + team named (1 pt each) |
| 3 | 4 | Each answer correct (1 pt each) |
| 4 | 4 | Each word broken, beats read, blended (1 pt each) |
| 5 | 6 | Each word stripped, root read, meaning told (1 pt each) |
| 6 | 8 | Each word read instantly (1 pt each) |
| 7 | 6 | Each word in the right column with the right sound (1 pt each) |
| 8 | 3 | Each compound broken + meaning told (1 pt each) |
| 9 | 3 | Each word spelled correctly via the pattern (1 pt each) |
| 10 | 4 | Two original sentences, both words used correctly (2 pts each) |
| **Total** | **51** | |

**Readiness signal:** 41+ points (80%) with no objective's tasks all
missed → ready for Unit 02. Below 41, or any objective fully missed →
re-teach that objective's lesson content before Unit 02 begins (see
[teacher-guide.md](../teacher-guide.md#reteach-map)).
