# Lesson 02 — Text Features Scavenger Hunt

**Goal (learner hears):** "I can use headings, bold words, captions,
glossaries, and indexes to find facts fast — without reading the whole
book front to back."
**Time:** 25–30 minutes · **Materials:** Lesson 01's text (with its
headings, bold words, glossary, and the index below); a pencil or
pointer.
**Standards:** RI.2.5, RI.2.4.

## Readiness check (1–2 min)

The adult holds up the Lesson 01 text and asks: "Without reading every
word, how fast can you find the word *lodge*?" If the learner scans
headings or bold words, say: "You just used text features." If the
learner starts reading from the top, stop them kindly: "That works, but
it is slow. Today we learn the shortcuts."

## The index (added to the end of "Beavers: Nature's Builders")

An **index** is an alphabetical list at the end of a book that tells
you where each topic is. This text's index:

- bark — What Beavers Eat
- dam — Building a Dam
- gnaw — A Beaver's Body
- kit — What Beavers Eat
- lodge — A Home Called a Lodge
- pond — Building a Dam
- teeth — A Beaver's Body

## Explicit teaching

Text features are the book's tools. Each one answers a different
question:

- **Heading / subheading** — a title over a paragraph or section. It
  tells you what that part is about. Use it to pick which part to read.
- **Bold print** — dark, heavy letters. A bold word is important; its
  meaning is usually explained right nearby or in the glossary.
- **Caption** — words under or beside a picture that explain what the
  picture shows. Read the caption before you study the picture.
- **Glossary** — a mini-dictionary at the end of a book. Use it when a
  bold word is new to you.
- **Index** — an alphabetical list of topics with where to find them.
  Use it to jump straight to a topic.
- **Icon** — a small picture that stands for an idea (for example, a
  magnifying glass for "look closer"). On a screen, icons in menus help
  you find things without reading long lists.

Rule: name the feature you used, every time. "I found it" is not
enough; "I found it in the glossary" is the skill.

### Modeled example 1 — Bold print + glossary

Adult thinks aloud: "Question: what does *gnaw* mean? First I see the
bold word **gnaw** in the body paragraph. The sentence says 'chew, on
wood' right after it — that is a clue. To be sure, I check the
glossary: **gnaw** — to chew on something hard, again and again. Two
clues agree, so I trust the meaning."

### Modeled example 2 — Index + heading

"Question: where does the text say what a lodge is? I could read the
whole text — slow. Instead I check the index: *lodge — A Home Called a
Lodge*. I jump to that heading and read only that paragraph: 'A lodge
is a dome-shaped home made of branches and mud.' Fast, and I can point
to the proof."

## Guided practice (adult does it with the learner; 5 tasks)

1. "Use the index. Where do you find *teeth*?" (A Beaver's Body.)
   "Read the sentence about teeth there."
2. "Use a heading. Which paragraph tells you what beavers eat?"
   (What Beavers Eat.)
3. "Use the glossary. What is a **dam**?" (A wall built across a
   stream to slow water and make a pond.)
4. "Use bold print. Name two bold words in the text and tell me what
   each one means." (**dam**, **lodge**, **kit**, **gnaw** — any two
   with correct meanings.)
5. **Error-analysis:** the adult says, "I used the index to find what
   *gnaw* means." "Did I use the right feature?" (No — the index tells
   you *where* a topic is, not what it means. The glossary tells you
   what a word means. The index sent you to A Beaver's Body, where the
   sentence explains it — but the glossary is the meaning tool.)

## Independent practice (adult-scribed or written; 6 tasks)

1. Use the index: where do you find *pond*? Write the heading.
2. Use the glossary: what is a **kit**?
3. Use a heading: which paragraph tells you how a beaver swims under
   water?
4. Use bold print: find the bold word in the "What Beavers Eat"
   paragraph and tell its meaning.
5. A friend asks, "What do beavers eat in winter?" Which feature helps
   you find the answer fastest — index, glossary, or heading? Explain
   your pick in one sentence.
6. Draw the icon you would put beside a "look closer" box (for
   example, a magnifying glass) and say what it tells the reader.

## Applied task

The learner picks one fact from the text and hides it: the adult must
find it using only one feature the learner names ("Find it with the
index"). Then they swap. Each find must end with the learner or adult
pointing to the exact sentence.

## Exit check

"Find me one fact with the glossary and one fact with the index, and
name the feature each time." Ready to move on: both facts found and
both features named correctly.

## Supports and extensions

- **Reading access:** adult reads the glossary and index aloud first;
  the learner tracks with a pointer.
- **Alternate response mode:** point to the feature, circle it, or
  dictate the answer.
- **Extension:** the learner adds one new index entry of their own
  (for example, *swim — A Beaver's Body*) in alphabetical order and
  explains where it belongs.

## Teacher note

Likely misconception: confusing glossary (word meanings) with index
(topic locations), or reading the whole text instead of using a
feature. Reteach with the "which tool for which job" question in
Guided practice item 5. Answer-key reference:
