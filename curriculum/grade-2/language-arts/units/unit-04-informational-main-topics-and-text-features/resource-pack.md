# Resource Pack — Unit 04: Informational Reading: Main Topics, Details, and Text Features

**Goal in one sentence:** help a grade-2 learner find main topics and
paragraph focuses, use text features to locate facts fast, explain what
pictures add, follow an author's purpose and reasons, retell steps in
order, and compare two texts on the same topic — with free, no-account
routes for every core objective; videos supplement, never replace, the
lessons.
