# Teacher Guide — Unit 04

**For the guiding adult only.** Never show this guide or
[answer-key.md](answer-key.md) to the learner.

## Materials

Paper, crayons or colored pencils, a pencil, six hand-written question
cards (WHO, WHAT, WHERE, WHEN, WHY, HOW) for Lesson 01 review, and six
hand-written step cards for Lesson 05. Nothing to buy. The generated
picture is in [assets/](assets/README.md); its text-only alternative
is in [Lesson 03](lessons/lesson-03-what-pictures-add.md) and carries
every detail the activities need.

## Pacing notes

- Four sessions per week, 25–30 minutes. If a session runs long, split
  the independent practice across two sittings rather than skipping
  the exit check.
- Week 18 doubles as the track's midyear review: Session 15 is the
  formative quiz; Session 16 is the unit assessment, project sharing,
  and the Unit 01/03 revisit in Assessment Task F. Record any
  re-teaching need from Task F here after Session 16.
- Every written task has an oral, pointing, drawing, or adult-scribed
  option. Review independent practice the same day; a next-day review
  loses the misconception window this unit relies on.

## Misconceptions and reteaching

| If the learner… | Likely cause | Do this |
|---|---|---|
| Names the title as the main topic without checking paragraphs | Title-guessing | Run the "every paragraph?" test (Lesson 01, Modeled example 1) on a new paragraph |
| Names one paragraph's focus as the main topic | Part–whole confusion | Ask: "Does that fit *every* paragraph, or just one?" |
| Confuses glossary with index | Tool–job mix-up | Ask: "Do you want a meaning or a location?" (Lesson 02, Guided item 5) |
| Reads the whole text instead of using a feature | Feature habit not formed | Give a timed find: "30 seconds, index only" |
| Calls a picture proof of everything ("one beaver, so beavers live alone") | Picture over-reading | Lesson 03, Guided item 5: a picture shows one moment, not the whole truth |
| Calls any interesting fact a reason | Reason vs. fact mix-up | "Take it away" test (Lesson 04): if removing it leaves the point standing, it is not a reason |
| Retells steps as a loose list, out of order | Order not treated as meaning | "What had to happen before this?" after each step (Lesson 05) |
| Calls a missing fact a disagreement between texts | Difference vs. contradiction | Lesson 06, Modeled example 2: different focus is not a mistake |
| Guesses a lesson for a story instead of finding it | Unit 03 skill fade (Task F) | Re-run Unit 03, Lesson 02 retell routine before Unit 05 |

## Readiness and next steps

- **Ready to move on (to Unit 05):** quiz 8/10 or better; assessment
  Tasks A–E at their pass lines; project rubric mostly 3s, no 1s.
- **Reteach before Unit 05:** any assessment task below its pass line
  — re-teach the matching lesson the same week and re-check with the
  parallel practice set (A→Lesson 01, B→Lesson 02, C→Lesson 03,
  D→Lessons 04–05, E→Lesson 06).
