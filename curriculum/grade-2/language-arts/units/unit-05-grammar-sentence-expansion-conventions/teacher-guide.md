# Teacher Guide — Unit 05

**For the guiding adult only.** Never show this guide or
[answer-key.md](answer-key.md) to the learner.

## Materials

Paper, a pencil, crayons or colored pencils. Word cards for Lessons
01–04 (group words, plural pairs, yesterday verbs, adjective/adverb
pairs) — hand-written on paper or card. A beginning dictionary
(print, or the free Wordsmyth children's dictionary in the
[resource-pack.md](resource-pack.md)) for Practice E and Assessment
Task F. The generated picture is in [assets/](assets/README.md); its
text-only alternative is in
[Lesson 03](lessons/lesson-03-adjectives-and-adverbs.md) and carries
every detail the activities need. Nothing to buy.

## Pacing notes

- Four sessions per week, 25–30 minutes. If a session runs long, split
  the independent practice across two sittings rather than skipping
  the exit check.
- Week 19 carries four grammar topics across two lessons (Lesson 01
  collective nouns; Lesson 02 plurals + reflexive pronouns). Do not
  rush Lesson 02: the plural pairs need oral repetition, and the
  reflexive pronouns need the "points back to the doer" test said out
  loud.
- Week 22 is the review week: Session 13 is Practice E (spelling
  patterns, dictionary, formal/informal); Session 14 finishes and
  shares the letter project; Session 15 is the formative quiz;
  Session 16 is the unit assessment plus letter sharing.
- Every written task has an oral, pointing, drawing, or adult-scribed
  option. Review independent practice the same day; a next-day review
  loses the misconception window this unit relies on.
- The unit opens with a fluency reread (Unit 02 retrieval) and ends
  with one inside the assessment (Task F, item 5). Record the reread
  result below after Session 16.

## Misconceptions and reteaching

| If the learner… | Likely cause | Do this |
|---|---|---|
| Uses any group word for any group ("a herd of birds") | Group-word matching not formed | Match test (Lesson 01, Modeled example 1): say the members first, then ask their special group word |
| Regularizes plurals ("childs," "foots," "mouses") | Over-applying the -s rule | Oral pair drill (Lesson 02, Modeled example 1): say the pair three times; no rule to work out, learn by heart |
| Uses a personal pronoun for a reflexive ("I hurt me") | Doer/receiver sameness not noticed | "Points back" test (Lesson 02): who did it, and who felt it? If the same person, use the -self word |
| Says "theirselves" | Overgeneralization | Correct to *themselves* on the spot; the -selves words are *ourselves, yourselves, themselves* |
| Uses the adjective for the adverb ("runs quick") | Form confusion | "What does it tell about?" test (Lesson 03): a thing → adjective; an action → adverb |
| Believes every adverb ends in -ly | Pattern overgeneralization | Counterexamples from the picture: *fast, high, well, hard* (Lesson 03, Guided item 5 note) |
| Regularizes past tense ("goed," "eated," "hided") | Over-applying the -ed rule | Yesterday-word drill (Lesson 04, Modeled example 1); the clue words *yesterday, last night, last week* |
| Joins sentences without a comma | Comma-before-joining-word habit not formed | Say the rule as a habit: "joining word, comma before it" (Lesson 04) |
| Capitalizes common nouns ("Dog," "Park") | Importance feels like a name | "Is it the special name of one holiday, product, or place?" (Lesson 05) |
| Puts the comma after *Dear* ("Dear, Grandma Rosa") | Comma placement guess | Point to the model letter: the comma follows the name (Lesson 05, Modeled example 2) |
| Writes "do'nt" / "ca'nt" | Apostrophe placement guess | "What letters went missing?" (Lesson 06): the apostrophe sits in the missing letters' spot |
| Uses *it's* for belonging ("it's tail") | Its/it's confusion | Swap test (Lesson 06): if "it is" fits, use *it's*; if not, use *its* |
| Adds *'s* to a plural ending in -s ("the girls's game") | Possessive rule over-applied | Rule (Lesson 06): plural ending in -s takes just the apostrophe after the -s |
| Treats formal as "right" and informal as "wrong" | Moral framing | L.2.3a is about fit, not right/wrong: formal for teachers and people you do not know well; informal for friends and family (Practice E) |
