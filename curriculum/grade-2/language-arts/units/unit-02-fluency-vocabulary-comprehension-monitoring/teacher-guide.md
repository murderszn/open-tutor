# Teacher Guide — Unit 02: Fluency, Vocabulary, and Comprehension Monitoring

Adult-facing guidance for all 16 sessions. Learner materials stay
learner-facing; answers live in [answer-key](answer-key.md).

## How this unit works

Unit 01 built decoding. This unit builds **reading behavior**: purpose,
self-monitoring, expressive rereading, word-solving, describing language,
and retelling. The engine is **successive reading** — the same short
passages read again and again, each time for a new job. Never introduce a
new long text when a reread will do; familiarity is what frees the brain
for expression and thinking.

## The fluency rubric

Score each dimension 1–3 during any oral reading (Practice C, project,
assessments).

| Dimension | 3 — Strong | 2 — Growing | 1 — Starting |
|---|---|---|---|
| **Accuracy** | 0–2 errors; self-corrects slips | 3–5 errors; fixes most when prompted | 6+ errors; plows past mistakes |
| **Rate** | Conversational speed throughout | Mostly conversational; rushes or drags in spots | Word-by-word or racing |
| **Expression** | Voice matches meaning; punctuation honored | Some expression; flat in places | Monotone |

Optional: a one-minute words-correct count on Passage A during Session 6
and Session 14 to show growth. Record it privately; never compare with
another learner or grade band.

### Using the rubric

Share scores as coaching, not grades: "Accuracy 3 — you caught that slip
yourself! Rate 2 — let's try that middle part at talking speed." The
learner self-scores in the project; the adult confirms.

## Common misconceptions

- **"Fast = good."** Redirect to the purpose check and the rubric: speed
  without understanding fails both.
- **"Fixing means I'm bad."** Reframe: catching errors is the job. Strong
  readers self-correct the most.
- **"Expression means loud/silly."** Anchor every voice choice to meaning
  and punctuation evidence.
- **"The first letter is enough of a clue."** Require the whole sentence
  before guessing a word's meaning.
- **"Retelling means saying every sentence."** Praise the skeleton: big
  idea, key details, in order.

## Reteach signals

- **Reteach self-correction** if the learner reads past 2+ planted errors
  without stopping → replay Lesson 02's modeled examples with new planted
  errors; reduce to two errors.
- **Reteach expression** if Read 3 is still monotone → go back to pure echo
  reading (adult models, learner copies) for a full session.
- **Reteach context clues** if guesses come from single letters → cover the
  word, read the sentence as a cloze ("The wind is a strong ___ force"),
  and guess from sense alone before uncovering.
- **Reteach describing words** if adjectives/adverbs are mixed → sort with
  the picture columns (palette = thing-words, shoe = action-words).
- **Back up to Unit 01** if decoding errors exceed 6 per passage → fluency
  cannot grow on shaky decoding; run a Unit 01 vowel-team sort session
  first.

## Accessibility and supports

- All tasks work orally, by pointing, or with adult scribing.
- Let the learner echo-read entire passages instead of soloing.
- Mark expression spots with stickers/colors; use picture-labeled sort columns.
- Whisper-reads to a stuffed listener count as performance rehearsal.
- Keep sessions to 25–30 minutes; split any session across two days rather
  than rushing the exit check.
