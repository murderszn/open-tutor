# Practice Sessions — Unit 02

Five named practice sessions (A–E), each 20–25 minutes. The adult observes
and reviews the same day. Full solutions: [answer-key](answer-key.md#practice).

## Practice A — Purpose Rereads (Session 2)

*Goal: read Passage A twice, each time hunting a different purpose.*

1. **Purpose 1 — WHO:** Read Passage A to find out **who** the characters
   are. List them. (Sam, Lee.)
2. **Purpose 2 — WHAT HAPPENS:** Reread to find out **what** goes wrong and
   **how** it gets fixed. Tell it in two sentences. (The string snaps and
   the kite falls in the tall grass; Lee finds it and ties the string back
   on.)
3. Which purpose was easier to hunt? Why? (Accept reasoning: who-questions
   have names that stand out; what-happens needs the whole story.)
4. Set your own purpose — "I want to find out ___" — and reread once more.
5. **Fix-it check:** did anything not make sense on these reads? Name one
   word you double-checked.

## Practice B — Error-Hunt Rereading (Session 4)

*Goal: catch and fix every planted error using Stop → Check → Reread.*

The adult prepares a copy of Passage A with **four planted errors**
(*dark/park, glass/grass, frowned/smiled, swing/string* — see Lesson 02).

1. Read the copy aloud. Stop at each wrong-feeling word; say "Stop!"
2. For error 1, state the two clues: what the letters really say and what
   makes sense.
3. Fix it and reread the sentence correctly.
4. Repeat for errors 2–4. Tally: how many did you catch before the adult
   hinted?
5. **Explain:** which clue — letters or sense — caught the most errors
   today, and why?

## Practice C — Reread Relay (Session 6)

*Goal: three successive readings of Passage A, each smoother.*

1. **Read 1 — accuracy:** read Passage A aloud; the adult marks errors
   silently. Count: how many words needed a fix?
2. **Read 2 — rate:** read again at talking speed. The adult notes: too
   fast, too slow, or just right?
3. **Read 3 — expression:** performance read with the expression marks from
   Lesson 03. The adult scores with the
   [fluency rubric](teacher-guide.md#fluency-rubric).
4. Compare: which read felt easiest? Why does rereading make it easier?
   (The words get familiar, so the brain can spend energy on feeling.)
5. **Echo challenge:** the adult reads "Then — snap! The string broke."
   three ways (bored, scared, excited). The learner echoes each and names
   which feeling fits the story. (Scared/surprised — the kite is lost.)

## Practice D — Context-Clue Cards (Session 8)

*Goal: define clue words from Passage B with sentence evidence.*

Use the five clue-word cards from Lesson 04 (*invisible, gusty, tangle,
drifts, flutters*) plus three new ones the adult adds from Passage B
(*force, burst, knot*).

1. Shuffle the 8 cards. For each: read the word, say the meaning in your
   own words.
2. For each: quote the clue words from the passage that gave it away.
3. **Sort:** which words were defined *in the sentence itself* (gusty,
   tangle) vs. figured out from the *scene* (invisible, drifts, flutters,
   force, burst, knot)?
4. Pick the hardest word. Reread its whole sentence aloud and explain the
   clue path step by step.
5. **Make one:** the learner writes (or dictates) a sentence that defines a
   new word for the adult to figure out — e.g., "The **dawdle** was slow,
   so we were late." The adult must name the clue.

## Practice E — Word-Wall Build (Session 10)

*Goal: grow the describing-word wall and play with shades.*

1. Hunt both passages for **4 new adjectives** not yet on the wall and add
   them under ADJECTIVES with their nouns (*green trees, tall grass, flat
   kite, bright day*).
2. Hunt for **2 adverbs or how-words** (*fast, up* — accept *proudly* style
   additions the learner invents with adult help).
3. **Shade strip race:** the adult says a word (*cold, big, tired*); the
   learner gives a lighter and a darker shade. (*chilly → cold → freezing*;
   *large → big → huge*; *sleepy → tired → exhausted*.)
4. Use one dark-shade word in a sentence about the kite passages.
5. **Wall check:** read the whole word wall aloud; the learner explains one
   adjective–adverb pair: which describes a thing, which describes an
   action?
