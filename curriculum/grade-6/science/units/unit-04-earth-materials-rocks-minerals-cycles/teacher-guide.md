# Teacher Guide — Unit 04 (separate from student materials)

This guide is for the guiding adult. Do not hand it to the learner
before assessments are complete; the [answer key](answer-key.md) is a
separate file for the same reason.

## The assessment boundary — read first

**NGSS MS-ESS2-1's assessment boundary states that assessment does not
include the identification and naming of minerals.** Honor it exactly:
never ask the learner, in a quiz, assessment, or graded task, to name
a mineral from a sample or a test result. The unit teaches properties
and property-based reasoning, and practice cards use letters, not
names. Mentioning a mineral in prose (for example, "granite contains
quartz") is teaching, not identification assessment, and is acceptable.
If a real sample set comes with a name key, cover the names during
testing and grade only properties, processes, energy tags, and model
reasoning.

## Pacing guidance

- **Week 15 (minerals)** is the vocabulary-heavy week. Do not rush
  Lesson 01: learners who cannot say "streak," "luster," "cleavage,"
  and "hardness" precisely will misuse them for the rest of the unit.
  Session S2's test stations matter more than finishing Set B early.
- **Week 16 (rocks)** lives or dies on the S6 sort. If real samples
  are unavailable, the six descriptions (R1–R6) are a complete
  substitute — grade the reasoning chain, not the label alone.
- **Week 17 (cycle + energy)** is the conceptual peak. Expect the
  compaction/cementation tag to be wrong on first attempt; that error
  is the lesson working. Re-teach it in S11, not by re-lecturing but
  by asking "what is physically doing the squeezing?"
- **Week 18 (midyear)** is diagnostic. The quiz is formative: use its
  results to choose the S16 reteach topic from the learners' own exit
  checks, not from a fixed script.

## Safety procedures

- Eye protection whenever rocks are handled, broken, or rubbed.
- The adult handles the iron nail and any hammering. Learners never
  hammer samples.
- Never taste a sample. Wash hands after handling rocks.
- Streak plates: rub gently; if a sample will not streak, record "no
  streak — harder than the plate" and move on. Do not force it.
- The generated test-station illustration is a drawing, not a
  photograph and not evidence. Never present it as an observation.

## Misconceptions and reteaching moves

| Misconception | Reteach move |
|---|---|
| Color identifies a mineral | Quartz in many colors (Lesson 01, Worked example 1); Sample B's streak vs. color |
| Hardness = unbreakability | Diamond: hardest, yet shatterable; hardness is scratch resistance only |
| Streak plate works on every mineral | Only minerals softer than the plate streak; "no streak" is itself a result |
| Mineral = rock | Mineral is an ingredient; granite shows several minerals in one rock |
| Metamorphic = melted | Melted rock becomes magma and restarts as igneous; metamorphism is solid-state change |
| Fossils prove an age in years | Fossils prove environment and relative order in sedimentary burial, not a number |
| The cycle must visit every box in order | Shortcuts are valid (Lesson 03, Worked example 2); the cycle is a network |
| Sediment can melt directly to igneous rock | Arrows run rock → magma; sediment must first become rock |
| Every arrow must alternate engines | Engines do not take turns; tag each arrow on its own physics |
| Compaction is Sun-driven | The Sun moved the sand once; the squeezing is burial weight + groundwater (Lesson 04) |
| "Gone" = destroyed | Moved, broken smaller, or changed form — conservation (Lesson 04, Worked example 2) |
| A model that distorts is a bad model | Every model distorts; judge a model by what it is *for* (Lesson 05, Station 1) |
| Seasons come from distance to the Sun | Opposite hemispheres, opposite seasons, same distance (Lesson 05, Station 2) |
| Gravity belongs only to Earth | Gravity acts between any two masses (Lesson 05, Station 3) |

## Differentiation

- **Reading/language access:** property and process words are defined
  in context in every lesson; let the learner say each term while
  pointing at its tool, sample, or arrow.
- **Alternate response modes:** oral answers, pointing/sorting with
  trays or cards, and token-walking on the diagram are full
  equivalents of written answers throughout the unit.
- **Extensions:** Lesson 01 (untested property research), Lesson 02
  (one step backward/forward in the cycle), Lesson 04 (rock cycle vs.
  water cycle comparison), Lesson 05 (write a quiz question).
- **Support:** learners who struggle with the cycle should trace
  paths with a finger on the diagram while narrating, before writing
  anything; learners who struggle with energy tags should chant "S =
  Sun at the surface, E = Earth's heat below" while tagging.

## What signals readiness, and what to do when it is missing

- **Ready for Unit 05:** the learner traces a two-arrow path with
  correct processes and tags, classifies a rock from formation
  evidence (not color), and names one model limit unprompted.
- **Reteach minerals** if the learner still uses color as an
  identifier: repeat Lesson 01's activity with the sample cards,
  requiring two properties per claim.
- **Reteach rocks** if families are sorted by appearance: repeat the
  S6 sort with the "birth certificate" task (Lesson 02 application),
  requiring a process in every justification.
- **Reteach energy** if compaction is tagged S or cooling is tagged S:
  repeat Lesson 04's "honest exceptions" with the physical question
  "what is doing the work in this step?"
- **Reteach the cycle** if paths must visit every box: repeat Lesson 03
  Worked example 2 and ask for a second valid shortcut.

## Midyear look-ahead

Unit 05 (plate tectonics, Earth history, geologic evidence) takes this
unit's deep-time story further: MS-ESS2-2 (surface change at varying
scales), MS-ESS2-3 (plate-motion evidence), and MS-ESS1-4 (the geologic
time scale). Nothing in Unit 05 assumes mineral names; the boundary
carries forward.
