# Unit 01 — Teacher Guide

**For the guiding adult.** Worked solutions live in
[answer-key.md](answer-key.md) — this guide gives misconception notes,
reteach moves, readiness signals, and scoring guidance without duplicating
solutions. Assessment is evidence-based and untimed; never speed-test.

## How to use this unit

- Review each lesson's **Teacher note** the evening before; the misconception
  listed there is the one most likely to surface.
- The learner's written work (12–16 tasks per session) is reviewed the **same
  day**. A wrong answer is a teaching moment, not a grade — ask "show me your
  thinking" before correcting.
- **Oral, drawn, pointing, and manipulative responses are always valid.**
  Scribe dictated answers when writing stamina lags; grade-6 learners should
  still produce growing amounts of written reasoning.
- The **question board** (Lesson 01) is a year-long artifact — keep it visible
  and revisit it in every later unit.

## Per-lesson misconception notes and reteach moves

### Lesson 01 — Testable questions, observation vs. inference

- **Misconception:** any science-sounding question counts as testable.
  **Move:** require the *named measurement* — "What would you count, measure,
  or time?" A question without one is "not testable *yet*," and rewording is
  praised as real scientific thinking.
- **Misconception:** inferences are "wrong answers." **Move:** affirm
  inferences as starting ideas; the error is stopping at the inference.
  Practice the test-an-inference habit ("what would you observe next?").
- **Reteach:** if sorting stays shaky, replay the readiness check with the
  learner's own questions from the question board until 8/8 sorts are clean.

### Lesson 02 — Variables, fair tests, repeated trials

- **Misconception:** the measured variable is the changed one ("the distance
  changed!"). **Move:** ask "who *set* it?" — the investigator sets the
  changed variable; nature answers with the measured one. Physically point at
  the books (changed by hand) vs. the ruler reading (answered by the roll).
- **Misconception:** "controlled" means "in control of the experiment."
  **Move:** anchor as "kept the *same* on purpose" — have the learner list
  three things they deliberately did NOT change while setting up the ramp.
- **Misconception:** more trials means changing something each time.
  **Move:** trials repeat *identical* conditions; the point is checking, not
  exploring. Use the fictional 14.3/14.1/21.6 s dataset to show an outlier
  caught only because conditions were identical.
- **Reteach:** variable-sorting cards (scenario on front, learner places
  "changed / measured / controlled" labels). Three clean sorts in a row =
  ready.

### Lesson 03 — Metric measurement and conversions

- **Misconception:** the decimal moves the wrong way. **Move:** "bigger unit,
  smaller number" + the reality check (is 2.5 m of string the same string as
  250 cm? yes — so the number *must* shrink). Never let a conversion stand
  without the check.
- **Misconception:** reading the graduated cylinder from above. **Move:**
  demonstrate the meniscus once at eye level, then require eye-level reads;
  spot-check Session 6 stations.
- **Mass vs. weight:** accept "how heavy" language; model "mass" for what the
  scale measures. Do not teach the mass/weight distinction formally (above
  band).
- **Reteach:** the floor "decimal hop" mat — physically hop left/right per
  conversion until 8/8 conversions are clean, then return to paper.

### Lesson 04 — Line graphs

- **Misconception:** "the line goes down" read as "the temperature *is* low"
  rather than "*falling*." **Move:** practice value-vs.-change language with
  finger-tracing: "at 2 minutes the value is 74 °C; between 0 and 2 minutes
  the value *fell* 6 °C."
- **Misconception:** overclaiming ("this proves…"). **Move:** enforce the
  "in this sample" sentence frame on every trend description until automatic.
- **Misconception:** extending the trend beyond the data (task 8). **Move:**
  praise the curiosity, then ask "what did we actually measure?" — the graph
  is a record, not a promise.
- **Reteach:** re-plot the sample cooling data point by point together,
  narrating each axis choice aloud.

### Lesson 05 — Bar graphs, patterns, models vs. reality

- **Misconception:** bar graphs for everything. **Move:** drill the
  two-question flowchart ("time order? in-between values make sense?") until
  the choice is *justified*, not guessed.
- **Misconception:** "the model is wrong because it leaves things out."
  **Move:** reframe — *all* models leave things out; the question is whether
  what was left out matters for the question asked. The ramp model is fine
  for planning the test, useless for predicting exact centimeters.
- **Misconception:** variability means failure. **Move:** celebrate the range
  as information about steadiness; compare the 3-cm-spread set with the
  50-cm-spread set and ask which you would trust.
- **Reteach:** have the learner sort six new datasets (three time-series,
  three categorical) with justification before re-attempting graph sketches.

## What "ready" looks like (before Unit 02)

- Sorts 8/8 questions as testable/not-testable with a named measurement.
- Names changed, measured, and ≥3 controlled variables for a new scenario
  without prompting.
- Converts within the metric system 8/8 with the reality check stated.
- Produces a labeled data table (units in every header) and a correctly
  chosen, labeled graph from own data.
- Describes a trend with the "in this sample" frame and no overclaiming.
- Writes a model-vs.-reality statement naming includes and leaves-out.
- Project scores 14+/20 (see rubric in [project.md](project.md)).

## Reteach guidance

- **If variables are shaky:** return to the physical ramp — set up two heights
  together, narrating each variable type while touching the object that
  represents it. Do not re-lecture; re-*handle*.
- **If conversions are shaky:** drop back to cm↔mm only (one decimal hop)
  until fluent, then add m, then L/mL, then g/kg. One new prefix pair per
  session.
- **If graphing is shaky:** graph the learner's *own* project data (Session
  11/13) rather than more fictional sets — ownership fixes axis-label
  forgetting faster than drills.
- **If overclaiming persists:** make it a game — the adult deliberately
  overclaims ("this proves all cars…") and the learner earns the correction.
  Three sessions of this usually kills the habit.

## Project scoring guidance

- Score against the observable criteria in [project.md](project.md#rubric-20-points--observable-criteria);
  detailed acceptable-variation notes are in
  [answer-key.md](answer-key.md#project-scoring).
- **Acceptable variation (do not penalize):** different numbers of settings
  (3–5 fine); hand-drawn vs. ruled graphs; "controlled variables" listed in
  the learner's own words; the improvement idea differing from the key's as
  long as it is concrete and testable.
- **Penalize:** missing units in headers, changed variable on the wrong axis,
  a claim without the "in this sample" frame, an unmarked suspicious trial
  presented as good data.
- **Simulation route:** if the learner used PhET instead of the physical
  build, the model-vs.-reality statement must name the simulation as the
  apparatus — score the statement on honesty, not on which apparatus was
  used.

## Accessibility and extension notes

- **Low vision:** high-contrast, large-print table and graph templates; the
  ruler SVG prints at true scale — verify against a real ruler before
  measuring with it (printer scaling varies); tactile model parts (string,
  washers, textured board) for the project build.
- **Fine-motor:** sticker plotting on large grids; adult-assisted model
  drawing with learner-directed labels; dictated reports scribed by the
  adult.
- **Language access:** vocabulary with objects first, words second;
  home-language labels welcome on the word wall and question board; the adult
  reads all scenarios aloud on request.
- **Extensions (do not require of all learners):** Lesson 02's two-question
  investigation design; Lesson 03's five-reading variability write-up; Lesson
  04's range-plotting; Lesson 05's misleading-graph ethics analysis. Each
  foreshadows later units (U02 modeling, U06 weather data, U07 evidence
  evaluation).

## Session-by-session watch points

- **S2:** the observation stations — keep the mystery-bag strictly
  touch-only; the inference habit ("I think it is…") needs the follow-up
  "what would you observe to check?"
- **S6:** the measuring ritual (estimate → measure → record with units) —
  this is the session that makes or breaks the unit; do not rush it.
- **S8:** finish the mini-trial table — Session 11's graphing depends on it.
- **S12:** approve the project plan *before* any building; check the four
  lines (changed / measured / controlled / trials) yourself.
- **S13:** watch for unmarked suspicious trials — the honesty habit is the
  point, more than the numbers.
- **S15:** the formative quiz — same-day review, every miss corrected aloud.
