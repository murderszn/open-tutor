# Project — The Pendulum-or-Ramp Investigation

**Sessions:** 12 (launch and plan), 13 (trials and data), 14 (graph and
report), 16 (showcase). **Adult supervision required throughout.**

## The task

Plan and carry out a **controlled investigation** that changes **exactly one
variable**, run at least **three repeated trials** per setting, record data in
a **labeled table with units**, display the results in a **labeled graph**,
build a **labeled system model**, and write an honest **model-vs.-reality
statement**. Then present what you found — and what your test *cannot* prove.

**Choose ONE investigation:**

- **Option A — Ramp:** Does the ramp's height change how far a toy car rolls
  past the ramp? Changed variable: ramp height (at least 3 heights, e.g. 10,
  20, 30 cm of book-stack height). Measured variable: roll distance (cm).
- **Option B — Pendulum:** Does the string length change the swing time of a
  pendulum? Changed variable: string length (at least 3 lengths, e.g. 30, 60,
  90 cm). Measured variable: time for 10 complete swings (s), divided by 10
  for the per-swing time. (Sanity check from physics: a 1-meter string swings
  about 2.0 s per swing; a much longer or shorter string gives a much longer
  or shorter time. If your numbers are wildly different, check your timing
  method before trusting them.)

*Sample data shown in the lessons (ramp roll distances near 63/90/119 cm;
pendulum times near 1.4 s) are fictional practice data. Your report uses only
measurements you made yourself.*

## Materials (household; adult gathers and supervises)

- **Both options:** notebook, pencil, ruler or tape measure, stopwatch (phone
  or kitchen timer), graph paper.
- **Ramp:** a smooth board about 60 cm long, a stack of books, a toy car that
  rolls straight, a flat clear floor or table run of at least 2 meters.
- **Pendulum:** string or yarn, a small dense bob (a metal washer, a large
  nut, or a ball of clay — nothing breakable, nothing mouth-sized), a fixed
  support (a doorway pull-up bar, a clamped ruler over a table edge — the
  adult secures it), a protractor or printed angle guide for a consistent
  release angle (about 20–30° from vertical; keep it small and identical every
  trial).

**Safety:** the adult secures the pendulum support and supervises every
release; the bob is never swung toward people, pets, or breakables; the ramp
run is cleared of trip hazards; stop and re-secure anything that wobbles.

**Accessibility / alternatives:** if building is not possible, run the
investigation in the free PhET "Pendulum Lab" simulation (see
[resource-pack.md](resource-pack.md)) with the same plan, trials, table, and
graph — the simulation is the *apparatus*, and the model-vs.-reality
statement must name that the data came from a simulation, not a physical
build.

## Steps

1. **Plan (Session 12).** Write the testable question and the four-line plan
   from Lesson 02's application: changed variable, measured variable,
   controlled variables (at least three), number of trials (at least three
   per setting — and why that many).
2. **Model first (Session 12).** Draw the labeled system model (side view,
   at least four labels: the changed variable, the measured variable, the
   release point, one controlled variable). Write the first draft of the
   model-vs.-reality statement.
3. **Trials (Session 13).** Run at least three trials per setting. Record
   every measurement *as you go* in the data table — no copying from memory
   later. If a trial looks wrong (the car hit a wall, the bob bumped the
   support), mark it, note why, and re-run it.
4. **Table and graph (Session 14).** Compute the mean for each setting; build
   the final labeled data table (units in every column header); draw the
   graph (line graph for both options — the changed variable is a continuous
   scale; axes labeled with units; title naming the test).
5. **Claim and limits (Session 14).** Write the claim in the "in this sample"
   frame, then finish the model-vs.-reality statement: what the model
   includes, what it leaves out, and one thing you would change to make the
   test fairer or steadier.
6. **Showcase (Session 16).** Present the report in 3–5 minutes: the
   question, the plan, the graph, the claim, and the honest limits. Answer
   one adult question about what the test cannot prove.

## Deliverables

1. The written four-line test plan.
2. The labeled data table with units (at least 3 settings × 3 trials).
3. The labeled graph (line graph, axes with units, title).
4. The labeled system model with the model-vs.-reality statement.
5. The written claim in the "in this sample" frame, plus one named
   limitation and one improvement idea.
6. The showcase talk.

## Rubric (20 points — observable criteria)

| Points | Criterion | What earns full credit |
|---|---|---|
| 4 | **Plan** | Testable question written; changed, measured, and ≥3 controlled variables correctly named; one variable changed; ≥3 trials planned with a reason (catching mistakes / checking consistency). |
| 4 | **Data table** | Every column header names the quantity AND its unit; ≥3 settings × ≥3 trials recorded; changed-variable column present; suspicious trials marked with a note, not silently deleted. |
| 4 | **Graph** | Line graph (continuous changed variable); changed variable on the horizontal axis, measured on the vertical; both axes labeled with units; points plotted from the table's means; title names the test. |
| 4 | **Model** | Side-view diagram with ≥4 correct labels; model-vs.-reality statement names ≥2 things the model includes and ≥2 things it leaves out; statement explains why the model is still useful. |
| 4 | **Claim and honesty** | Claim uses the "in this sample" frame and matches the graphed pattern; one real limitation named (e.g., one car, one room, small sample); one concrete improvement proposed; no overclaiming ("proves," "always"). |

**Scoring bands:** 18–20 = thorough investigator — ready for Unit 02's
modeling work; 14–17 = solid — review the missed criterion's lesson before
Unit 02; 10–13 = re-teach the missed criteria with the teacher guide, then
re-run the weak section (not the whole project); below 10 = rebuild the
investigation with the adult, one criterion at a time. Scoring guidance with
acceptable variation is in [answer-key.md](answer-key.md#project-scoring).
