# Resource Pack — Unit 02 (Earth–Sun–Moon systems and seasons)

**Goal:** support a grade-6 learner (with an adult) in modeling day/night,
lunar phases, eclipses, and seasons — and in rejecting the shadow-phases and
distance-seasons misconceptions with evidence.
**Age fit:** grades 6–8; reading level ~grade 6; every investigation is
adult-supervised.

## Web references (checked 2026-10-19 unless noted)

1. **Space Atlas — Moon Phase Simulator** (interactive)
   <https://saramjh.github.io/space_atlas_student/moon/phases/> —
   opened and read 2026-10-19. Synchronized system-view/Earth-view phase
   simulator with a prediction activity, the "Earth's shadow causes phases"
   misconception check, and explicit model-limitation notes (distance
   compressed, tilt flattened). Free, no account. Note: the hosting site uses
   Google Analytics and AdSense — adult preview advised; used in this unit as
   a *supplement* to the physical lamp-and-ball model, not a replacement.
2. **Space Atlas — Seasons Simulator** (interactive)
   <https://saramjh.github.io/space_atlas_student/earth/seasons/> —
   opened and read 2026-10-19. Tilt/orbit simulator with solstice/equinox
   presets, a 0°-tilt comparison, and a perihelion/aphelion reference table
   (147.1M / 152.1M km). Same privacy note as above.
3. **NOAA NESDIS — "Why does Earth have Seasons?"**
   <https://www.nesdis.noaa.gov/about/k-12-education/understanding-our-planet/why-does-earth-have-seasons> —
   found via web search 2026-10-19 (search-page text reviewed; open the page
   before classroom use). NASA Space Place team content (published
   2025-08-26): tilt explanation plus perihelion 91.4M miles / aphelion 94.5M
   miles, used to corroborate this unit's distance values.
4. **NASA eClips — Guide Lite: Seasons (PDF, teacher-facing)**
   <https://assets.science.nasa.gov/content/dam/science/cds/eclips/assets/documents/nasa-spotlite-interactive-lesson-seasons.pdf> —
   found via web search 2026-10-19 (open before use). ~45-minute lesson guide
   naming the distance misconception explicitly; background notes on the 23°
   tilt usable for adult preparation. Published January 2018.
5. **NGSS performance expectation MS-ESS1-1 (verification record)**
   <https://www2.cde.ca.gov/cacs/id/web/29056> — California Department of
   Education content-standards record quoting the national MS-ESS1-1 text
   ("Develop and use a model of the Earth-sun-moon system to describe the
   cyclic patterns of lunar phases, eclipses of the sun and moon, and
   seasons"), reviewed via search 2026-10-19. No state adoption claimed.
