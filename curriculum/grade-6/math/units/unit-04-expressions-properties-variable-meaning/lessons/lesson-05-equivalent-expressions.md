# Lesson 05 — Equivalent Expressions and Substitution Tests

**My goal:** I can decide whether two expressions are equivalent, and
I can prove a pair is *not* equivalent with a single counterexample.

**Time:** about 45 minutes (5 readiness · 15 teaching · 10 guided ·
12 independent · 3 exit).

**Materials:** paper, pencil.

**Standards:** 6.EE.A.4 (with 6.EE.A.3) · **Unit objectives:** UO17
(and UO16)

## Readiness check (5 minutes)

Answer before we start — this tells us what is already solid.

1. Evaluate y + y + y and 3y for y = 2. Do they match?
2. Evaluate x + 3 and 3x for x = 1. Do they match?
3. Expand 2(x + 3). What do you get?

*(Question 1's pair matches at y = 2 — but one matching value does
not prove equivalence. Today you learn what does.)*

## Explicit teaching

### What "equivalent" means

Two expressions are **equivalent** when they name the **same number
regardless of which value is substituted** for the variable. Not
"the same for the value we tried" — the same for *every* value.
That one word, *regardless*, is the whole definition, and it makes
the testing rules asymmetric:

- To show two expressions are **not** equivalent, **one**
  counterexample is enough: a single value where they differ proves
  they cannot be equivalent.
- To show they **are** equivalent, testing values is never enough on
  its own — there are infinitely many values, and you cannot try them
  all. Instead, use the properties of operations (Lesson 04) to turn
  one expression into the other, and use substitution at two or three
  values as a *check* on your reasoning, not as the proof.

In grade 6, the working standard is: transform with a property, then
verify with substitution. If the transformation is valid, the pair is
equivalent; if you find a counterexample, it is not.

### Worked example 1 — y + y + y and 3y: equivalent

Transform: y + y + y is three copies of y added together, which is
3 × y = 3y (the distributive property in reverse: y + y + y =
(1 + 1 + 1)y = 3y). The transformation is valid, so the pair is
equivalent.

Check with substitution, at two values, to catch any slip:

- y = 2: y + y + y = 6; 3y = 6. Match.
- y = 5: y + y + y = 15; 3y = 15. Match.

Now the contrast — x + 3 and 3x:

- x = 1: x + 3 = 4; 3x = 3. They differ.
- One counterexample is decisive: x + 3 and 3x are **not**
  equivalent. Note the trap: they *do* match at x = 3 (both give 6).
  That single matching value is exactly why one matching value proves
  nothing — pairs can agree sometimes and still not be equivalent.

### Worked example 2 — 2(x + 3) and 2x + 6: equivalent; 5a + 2 and 5(a + 2): not

**Pair 1:** Expand 2(x + 3) with the distributive property:
2 × x + 2 × 3 = 2x + 6. The expansion *is* the second expression, so
they are equivalent. Check x = 4: 2(7) = 14; 2 × 4 + 6 = 14. Match,
as expected.

**Pair 2:** Expand 5(a + 2): 5a + 10. Compare with 5a + 2: the
constant terms differ (10 vs 2), so they are not the same expression.
Counterexample, a = 1: 5a + 2 = 7; 5(a + 2) = 5 × 3 = 15. They
differ, so the pair is **not** equivalent. The error to watch for is
distributing to only the first term: 5(a + 2) is 5a + 10, never 5a + 2.

## Guided practice (with hints)

Decide whether each pair is equivalent. If it is, show the
transformation; if it is not, give a counterexample value.

1. 4m + m and 5m. *(Hint: combine like terms.)*
2. 6 + 2n and 2(3 + n). *(Hint: expand the second expression.)*
3. 3k + 1 and 3(k + 1). *(Hint: expand, then compare constant terms.)*
4. a + a + a + a and 4a. *(Hint: how many copies of a?)*

## Independent practice

1. Decide equivalence; justify with a transformation or a
   counterexample:
   (a) 2x + 2 and 2(x + 1) (b) 7 + 3t and 3(t + 7) (c) 5n + 5 and
   5(n + 1) (d) 4p + 3 and 4p + 4 (e) 6y + 2y and 8y.
2. Find the error: Lee claims 2m + 5 and 2(m + 5) are equivalent
   "because the 2 distributes." Is Lee right? Test m = 1 and explain.
3. Two expressions both give 20 when x = 4. Does that prove they are
   equivalent? Explain, using an example pair from this lesson.
4. Write a pair of expressions of your own that are equivalent, and
   a pair that are not. Prove each claim the right way (transformation
   for the equivalent pair, counterexample for the other).

## Application

Two stall owners describe the same order differently. Ana writes
3n + 4 (3 bags of n apples, plus 4 loose). Ben writes 3(n + 1) + 1
(3 bags with 1 extra apple each, plus 1 loose). (a) Expand Ben's
expression. (b) Are Ana's and Ben's expressions equivalent? Justify.
(c) Check both for n = 5.

## Exit check

Are 6 + 2m and 2(3 + m) equivalent? Show the transformation or a
counterexample, and check with m = 2.

## Supports and extensions

- **Reading/language access:** Use a two-column test table (value |
  expression 1 | expression 2) for every pair. The table makes
  "matches sometimes" visible and stops one-value proofs.
- **Alternate response mode:** The learner may build both expressions
  with tiles or counters for a chosen value (a counterexample made
  concrete) and explain the transformation orally.
- **Extension:** Are 2(x + 3) + 4 and 2x + 10 equivalent? (Yes:
  2x + 6 + 4 = 2x + 10.) Are x² and 2x equivalent? (No: x = 3 gives
  9 vs 6.) Explain why x² = 2x happens to hold at x = 2 (4 = 4) and
  x = 0 (0 = 0) without the pair being equivalent.

## Teacher note

Likely misconceptions: "they matched at one value, so they're
equivalent"; "equivalent means they look alike" (2x + 6 and 6 + 2x
look different but are equivalent by commutativity); "equivalent
means they have the same value at the value I care about." The
x + 3 / 3x pair, matching at x = 3, is the antidote — teach it
explicitly. See the teacher guide and the answer-key reference.
