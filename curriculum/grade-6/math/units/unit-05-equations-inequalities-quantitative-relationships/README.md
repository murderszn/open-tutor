# Unit 05 — Equations, Inequalities, and Quantitative Relationships

**Grade 6 Mathematics · Weeks 19–22 · 16 sessions (~45 minutes each, 4 per week)**

**Standards:** 6.EE.B.5, 6.EE.B.6, 6.EE.B.7, 6.EE.B.8, 6.EE.C.9

**Issue:** [#30](https://github.com/murderszn/open-tutor/issues/30)
(section U05 — draft delivery; not educator-reviewed)

## Overview

Units 01–04 built ratio reasoning, fraction and decimal computation, the
signed number line and the four-quadrant plane, and the language of
expressions. This unit turns that language into **solving**: the learner
learns to ask of an equation or an inequality, *"which values, if any, make
this true?"* Week 19 starts with **substitution** — testing candidate
values to find solutions, and learning that an equation usually has one
solution while an inequality can have many. Week 20 turns to
**solving equations** of the forms x + p = q and px = q for nonnegative
rational numbers, using the balance idea: whatever is done to one side
must be done to the other, and every solution is checked by putting it
back in. Week 21 turns to **inequalities as constraints** — writing
x > c or x < c for real limits, recognizing infinitely many solutions,
and graphing solution sets on number lines. Week 22 turns to **two
quantities that change together** — dependent and independent variables
shown in tables, graphs, and equations (d = 65t connects back to the
unit rates of Unit 01) — and closes with review, the courier project,
and the culminating assessment.

Nothing here asks the learner to solve two-step equations, work with
negative solutions, or use ≥ / ≤. Those come in grade 7. Every equation
in this unit has p, q, and x nonnegative and rational, exactly as
6.EE.B.7 requires; every inequality is of the strict form x > c or
x < c, exactly as 6.EE.B.8 requires.

## Essential question

*When a number is missing, how do we find which values make a statement
true — and when two quantities change together, how do we describe the
pattern that ties them?*

## Prerequisites (re-checked in Lessons 01–02)

- Writing and evaluating expressions with variables (Unit 04): substitution,
  order of operations, parts of an expression
- Fraction and decimal computation (Unit 02): division of fractions,
  decimal division — these return when solving px = q with rational p, q
- Ratio and unit-rate reasoning (Unit 01): constant speed and unit pricing
  return in Lesson 05 as d = 65t
- Ordering rational numbers and reading number lines (Unit 03):
  inequalities as statements about position return in Lesson 04
- Plotting ordered pairs in Quadrant I (grade 5; Unit 03): used for the
  distance–time graph in Lesson 05

Sessions 01–02 re-check expression evaluation and fraction division
before any equation is solved. The diagnostic weeks (Weeks 1–2)
baselined these before Unit 01, and the midyear review (Unit 04,
Week 18) re-checked them.

## Vocabulary

equation · solution · substitution · test value · solution set · inverse
operation · balance (of an equation) · isolate · coefficient ·
constraint · inequality · infinitely many · open circle · number-line
graph · independent variable · dependent variable · constant rate ·
ordered pair · table · graph · unknown

(Vocabulary is taught with objects and drawings first, the word second;
home-language labels are welcomed alongside English terms. "Solve" is
introduced as "find the value or values that make the statement true" —
never as "do the steps." The balance picture in Lesson 02 is a story
prompt: the numbers are always given in words.)

## Verified standards / source notes

Reference framework: **Common Core State Standards for Mathematics**,
Grade 6, Expressions and Equations, as published at
[thecorestandards.org/Math](https://thecorestandards.org/Math) (Grade 6
EE page at <https://thecorestandards.org/Math/Content/6/EE/>; codes and
descriptions re-verified 2026-11-06 for this unit). Exact official
wording used:

- **6.EE.B.5** — "Understand solving an equation or inequality as a
  process of answering a question: which values from a specified set,
  if any, make the equation or inequality true? Use substitution to
  determine whether a given number in a specified set makes an equation
  or inequality true."
- **6.EE.B.6** — "Use variables to represent numbers and write
  expressions when solving a real-world or mathematical problem;
  understand that a variable can represent an unknown number, or,
  depending on the purpose at hand, any number in a specified set."
- **6.EE.B.7** — "Solve real-world and mathematical problems by writing
  and solving equations of the form x + p = q and px = q for cases in
  which p, q and x are all nonnegative rational numbers."
- **6.EE.B.8** — "Write an inequality of the form x > c or x < c to
  represent a constraint or condition in a real-world or mathematical
  problem. Recognize that inequalities of the form x > c or x < c have
  infinitely many solutions; represent solutions of such inequalities
  on number line diagrams."
- **6.EE.C.9** — "Use variables to represent two quantities in a
  real-world problem that change in relationship to one another; write
  an equation to express one quantity, thought of as the dependent
  variable, in terms of the other quantity, thought of as the
  independent variable. Analyze the relationship between the dependent
  and independent variables using graphs and tables, and relate these
  to the equation. *For example, in a problem involving motion at
  constant speed, list and graph ordered pairs of distances and times,
  and write the equation d = 65t to represent the relationship between
  distance and time.*"

No state adoption, accreditation, or complete-alignment claim is made.
All place names, prices, speeds, weights, and account balances in this
unit are fictional practice data unless a task says otherwise; the
balance-scale illustration is an AI-generated story prompt, not a
photograph or a measurement — its numbers are stated in the lesson
words, and no other task asks the learner to count from the picture.
