# Lesson 01 — Which Values Make It True?

**My goal:** I can test values by substitution to find which ones, if any,
make an equation or inequality true, and I can explain what a solution is.

**Time:** about 45 minutes (5 readiness · 15 teaching · 10 guided ·
12 independent · 3 exit).

**Materials:** paper, pencil; number-line tape (optional, for Lesson 04
preview — not needed today).

**Standards:** 6.EE.B.5 · **Unit objectives:** UO18

## Readiness check (5 minutes)

Answer before we start — this tells us what is already solid.

1. Evaluate 3x + 2 for x = 4.
2. Is the statement 5 + 3 = 9 true or false? How do you know?
3. What number added to 6 gives 11?

*(If #2 felt easy, good — today we use exactly that true/false test,
but with a mystery number inside the statement.)*

## Explicit teaching

### An equation is a question

An **equation** is a statement that two things are equal — it has an
equals sign. An **inequality** is a statement that one thing is greater
than or less than another — it has a < or > sign.

When a letter stands for a number we do not know yet, the statement
becomes a question:

- x + 5 = 12 asks: *which number, added to 5, gives 12?*
- 3n < 20 asks: *which numbers, multiplied by 3, give less than 20?*

A **solution** is a value that makes the statement **true**. A value
that makes it false is not a solution. Solving is finding the value or
values that make it true — nothing more mysterious than that.

### How to test a value: substitution

To test a value, **substitute** it — put it in place of the letter —
and check whether the statement is true:

- Test x = 7 in x + 5 = 12: 7 + 5 = 12. True. So 7 is a solution.
- Test x = 9 in x + 5 = 12: 9 + 5 = 14. 14 = 12 is false. So 9 is
  not a solution.

Never guess and move on. Substitute, compute, and say "true" or
"false" out loud. That is the whole method for this lesson, and it is
also the check you will use for every solution in this unit: put the
answer back in and see if the statement is true.

### Worked example 1 — test the set {5, 7, 9} in x + 5 = 12

Test each value, one at a time:

- x = 5: 5 + 5 = 10. Is 10 = 12? **False.** 5 is not a solution.
- x = 7: 7 + 5 = 12. Is 12 = 12? **True.** 7 is a solution.
- x = 9: 9 + 5 = 14. Is 14 = 12? **False.** 9 is not a solution.

The solution set is {7}. This equation has exactly one solution in
this set — and, as Lesson 02 will show, exactly one solution anywhere.

### Worked example 2 — test the set {4, 6, 7} in 3n < 20

- n = 4: 3 × 4 = 12. Is 12 < 20? **True.** 4 is a solution.
- n = 6: 3 × 6 = 18. Is 18 < 20? **True.** 6 is a solution.
- n = 7: 3 × 7 = 21. Is 21 < 20? **False.** 7 is not a solution.

The solution set from this set is {4, 6}. Notice the difference from
example 1: an inequality can have **more than one** solution. Lesson 04
will show that this inequality has infinitely many solutions — every
number less than 20/3 — but the testing method is the same: substitute,
compute, true or false.

### Two warnings

1. **"Close" is not true.** In example 1, x = 9 gives 14, which is
   close to 12 — but 14 = 12 is false, so 9 is not a solution. A
   solution must make the statement exactly true.
2. **Test every candidate.** Do not stop at the first true value when
   the question asks which values make it true: an inequality may have
   several, as example 2 shows.

## Guided practice (with hints)

1. Test x = 3 in x + 8 = 11. *(Hint: 3 + 8 = ? Is it 11?)*
2. Test x = 9 in x + 8 = 11.
3. Test n = 5 in 4n = 20. *(Hint: 4 × 5 = ?)*
4. Test n = 6 in 4n = 20.
5. Which of {2, 3, 4} make y − 2 = 1 true? Test each one.
6. Which of {1, 2, 3} make 5m > 12 true? Test each one.

## Independent practice

1. Test each of {6, 8, 10} in a + 7 = 15. Which are solutions?
2. Test each of {3, 5, 7} in 2b = 14. Which are solutions?
3. Test each of {4, 5, 6} in c ÷ 2 = 3. Which are solutions?
4. Which of {0, 1, 2, 3} make d + 4 < 7 true?
5. Error analysis: Sam tests x = 4 in 3x = 15 and writes "3 × 4 = 12,
   so x = 4 is a solution." Explain Sam's error and give the correct
   solution.
6. Write your own: (a) an equation whose solution is 6; (b) an
   inequality that has 6 as a solution and also has another solution.
   Show the substitution that proves each one works.

## Application

A mystery number: twice a number, plus 1, is 11. Test the numbers 4,
5, and 6 in the equation 2n + 1 = 11. Which one is the mystery number?
Show each substitution.

## Exit check

Test whether 8 makes 2x + 1 = 17 true. Show the substitution and write
"true" or "false." Then, in one sentence, explain what a solution is.

## Supports and extensions

- **Reading/language access:** Read every equation aloud as a question
  ("x plus five equals twelve — which x makes that true?") before
  testing. Keep the words "substitute," "true," and "false" on the
  word wall.
- **Alternate response mode:** The learner may test values with
  counters or a number line (for x + 5 = 12, start at 5 on the line
  and jump by the test value), then write the true/false verdict.
- **Extension:** Test the set {1, 2, 3, 4, 5, 6, 7} in n + n < 10.
  Which values work? What do you notice about the pattern — and what
  would happen if the set were {1, 2, 3, 4, 5, 6, 7, 8, ...} with no
  end? (Preview of Lesson 04: infinitely many solutions.)

## Teacher note

Likely misconception: treating "close to true" as true, and stopping
after the first true value. Insist on the spoken verdict — "true" or
"false" — for every candidate, and on testing the whole set. See the
teacher guide for the full misconception list and the answer-key
reference.
