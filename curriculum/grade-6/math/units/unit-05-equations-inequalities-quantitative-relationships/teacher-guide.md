# Teacher Guide — Unit 05: Equations, Inequalities, and Quantitative Relationships

**Adult-facing. Do not hand this guide to the learner before they
have attempted the work; the answer key is a separate file.**

## How this unit fits

Unit 05 is where the expression language of Unit 04 becomes solving.
The unit deliberately stays inside the grade-6 forms: x + p = q and
px = q with nonnegative rational numbers, inequalities of the strict
forms x > c and x < c, and one-operation relationships between two
quantities. Two-step equations, negative solutions, and ≥ / ≤ belong to
grade 7 — if the learner asks for them, name the boundary honestly
rather than teaching ahead. The payoff for this restraint is that every
solution in the unit can be checked by the Lesson 01 method
(substitution), so the learner never has to take a procedure on trust.

## Lesson-by-lesson guidance

### Lesson 01 — Which values make it true?

- **Core move:** the spoken verdict — "true" or "false" — for every
  candidate, out loud, before moving on. Substitution is the unit's
  checking method, not a warm-up exercise; it returns in every later
  lesson.
- **Misconceptions:** (1) "close to true" counted as true (14 = 12 is
  false); (2) stopping after the first true value when the question
  asks which values make it true; (3) comparing the test value to the
  right side instead of comparing the two sides after substitution
  (Max's error in practice Set A #6: 10 ÷ 2 = 5 *is* the statement
  being true).
- **Reteach:** if testing is shaky, use true/false statements with no
  letters at all (Is 7 + 5 = 12 true? Is 7 + 5 = 13 true?) until the
  verdict habit is automatic.

### Lesson 02 — Solving x + p = q

- **Core move:** write the operation on **both sides** of the equation
  every time. The balance rule is not a metaphor to memorize — it is
  the reason the step is written twice.
- **Misconceptions:** (1) doing the inverse operation to only one
  side; (2) adding when the equation needs subtracting (Kim's error in
  practice Set B #4 and quiz item 10); (3) writing the equation
  backwards from the story ("$3 per package" is 3p, not p + 3).
- **The illustration:** the balance picture is a story prompt whose
  numbers match the worked example exactly: one bag plus 3 loose
  apples balances 5 loose apples, so b + 3 = 5 and b = 2. No other
  task in the unit asks the learner to count from the picture; all
  other counts are given in words. The text alternative in the lesson
  carries the same information as the picture.
- **Reteach:** if one-sided work persists, return to the counter model
  (a closed bag of counters plus loose counters on one side, loose
  counters on the other) and physically remove the same number from
  both sides before writing any symbols.

### Lesson 03 — Solving px = q

- **Core move:** name the coefficient before solving ("In 4x = 28,
  the coefficient is 4, so I divide both sides by 4"). Naming it
  prevents the subtraction slip.
- **Misconceptions:** (1) subtracting the coefficient instead of
  dividing (Lee's error in practice Set B #6); (2) dividing only one
  side; (3) dividing by a fraction as multiply-by-the-fraction instead
  of multiply-by-the-reciprocal (9 ÷ 3/4 computed as 9 × 3/4). For
  (3), re-teach the Unit 02 reciprocal rule — it is a fraction
  problem, not an equation problem.
- **Reteach:** if the fraction step is shaky, use the counter-group
  model for whole-number coefficients first (4x = 28 as four equal
  groups totaling 28), then reintroduce the fraction coefficient with
  fraction strips.

### Lesson 04 — Inequalities

- **Core move:** translate the constraint aloud twice — once in words
  ("shorter than 48 inches") and once in symbols ("h < 48") — before
  graphing. The graph is then a picture of the words.
- **Misconceptions:** (1) the endpoint counted as a solution (48 < 48
  is false — a number is never less than itself); (2) the arrow
  pointing the wrong way (the arrow follows the sign: > points right,
  < points left); (3) "infinitely many" read as "very many, ending
  somewhere" — use a decimal between two whole solutions (47.5, then
  47.99) to show the solutions never end.
- **Language:** "at most" and "at least" need ≥ and ≤, which are out of
  scope this year. Redirect such stories to "more than" / "less than"
  forms and name the gap honestly; do not teach the new symbols.
- **The diagram:** the SVG shows x > 3 (open circle at 3, arrow
  right) and x < 2 (open circle at 2, arrow left). It is deterministic
  and exact; the text alternative in the lesson carries the same
  information.

### Lesson 05 — Two quantities that change together

- **Core move:** the "which would you choose first?" test for
  independent vs dependent. The equation is the referee: if the table
  and the graph disagree, the equation decides.
- **Misconceptions:** (1) swapping the variables (calling distance
  independent because "the car goes somewhere first"); (2) reading
  the table but not connecting it to the graph or the equation;
  (3) treating the graph as decoration instead of a representation —
  ask for one reading from the graph that is not already in the table.
- **Reteach:** if the trio does not cohere, shrink the rate (use
  d = 5t with counters) and build table, graph, and equation together
  on one page before returning to 65.

## Readiness, reteach, and next steps

- **Ready for Unit 06 when:** the learner solves x + p = q and
  px = q reliably with both-sides steps and substitution checks;
  writes and graphs x > c and x < c with the open circle and correct
  arrow; and reads a table, graph, and equation as three forms of one
  relationship.
- **Reteach targets from the quiz (Session 08):** items 1–3 missed →
  revisit Lesson 01 substitution and the spoken verdict; items 4–5
  missed → revisit Lesson 02 both-sides steps; items 6–8 missed →
  revisit Lesson 03 (item 7 decimals, item 8 fractions — check the
  Unit 02 skills first); item 9 missed → revisit Lesson 03 equation
  writing ("per" means multiply); item 10 missed → the
  inverse-operation error needs another day with the balance model,
  not another worksheet.
- **Reteach targets from the assessment (Session 14):** item 1 →
  Lesson 01; items 2, 6 → Lessons 02–03; items 3–5 → Lesson 03;
  items 7–9, 11 → Lesson 04; item 10 → Lesson 05; item 12 → Lessons
  01 and 04 together (substitution testing of an inequality) and the
  project rubric.
- **Retrieval signal (Session 13, Practice Set E):** missed retrieval
  items are prerequisite gaps, not a reason to re-teach a whole prior
  unit. Item 2 (fraction division) is the one to watch: it is the
  skill Lesson 03's fraction equations depend on.

## Accessibility and supports

- Keep the substituted form, the both-sides step, and the check
  visible on the page; do not require mental arithmetic as a gate for
  algebraic reasoning.
- Accept oral explanations of solutions, dictated equations, and
  counter/balance models as full evidence of the objectives; written
  symbols are the goal, not the only route.
- The generated illustration and the SVG both have text alternatives
  in their lessons; the same information is fully available in words,
  so no learner depends on the picture.
- Sessions are about 45 minutes with movement breaks; every lesson
  includes a seated-table and a floor-play variant (walking the
  number-line tape in Lesson 04, building counter groups in
  Lesson 03).
