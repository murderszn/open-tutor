# Practice — Unit 05: Equations, Inequalities, and Quantitative Relationships

Work each set in order. Show the substitution for every test, the
operation on both sides for every solution step, and the check for
every equation you solve. The adult reviews the work the same day;
full worked solutions are in `answer-key.md` (adult only — do not
read ahead).

## Set A — Substitution and true/false testing (Lesson 01; UO18)

1. Test each of {2, 4, 6} in x + 9 = 13. Which are solutions?
2. Test each of {1, 3, 5} in 6y = 18. Which are solutions?
3. Which of {2, 4, 5} make 2n + 3 = 11 true?
4. Which of {3, 4, 5, 6} make m − 3 < 2 true?
5. Test each of {0, 2, 4} in 10 − q = 6. Which are solutions?
6. Error analysis: Max tests x = 10 in x ÷ 2 = 5 and writes "10 ÷ 2
   = 5, so 10 is not a solution because 5 is not 10." Explain Max's
   error.

## Set B — Writing and solving x + p = q and px = q (Lessons 02–03; UO19, UO20)

1. Solve and check each one: (a) x + 5 = 18 (b) y − 6 = 11
   (c) 3z = 24 (d) w ÷ 5 = 7.
2. Solve: (a) n + 3.2 = 7.5 (b) 4.5m = 18. Check both answers.
3. Solve (3/5)k = 12. Show the division step and the check.
4. A school trip costs $15 per student. The total collected is $180.
   How many students are going? Write the equation, solve it, and
   check it.
5. Write an equation and solve it: "After spending $7, Maya has $23
   left. How much money did she start with?"
6. Error analysis: Jo solves 5x = 40 as x = 40 − 5 = 35. Explain Jo's
   error and give the correct solution with its check.

## Set C — Inequalities and quantitative relationships (Lessons 04–05; UO21, UO22)

1. Write the inequality for this constraint: "A dog must weigh less
   than 25 kilograms to fly in the cabin." Let d stand for the dog's
   weight in kilograms.
2. List 4 solutions of a > 15. Then describe the graph of a > 15 in
   words.
3. A train travels at a steady 55 miles per hour. Let t stand for
   hours and d stand for miles. (a) Write the equation. (b) Complete
   the table for t = 0, 1, 2, 3, 4. (c) How far does the train travel
   in 2.5 hours? (d) Which variable is independent, and which is
   dependent?
4. Is 20 a solution of x < 20? Is 19.9 a solution? Explain both
   answers.
5. A rectangle's length is twice its width w. Its perimeter is
   P = 6w. (a) Complete the table for w = 1, 2, 3, 5. (b) If w = 7,
   what is P? (c) Which variable is independent, and why?
6. Error analysis: Sam graphs y > 6 with a closed dot at 6 and an
   arrow pointing left. What is wrong with Sam's graph?

## Set D — Mixed review (all lessons; UO18–UO22)

1. Test each of {8, 9, 10} in 3x − 5 = 22. Which are solutions?
2. Solve and check: (a) x + 11 = 47 (b) 9y = 108.
3. A taxi charges $3 per mile plus a $5 pickup fee. Let m stand for
   miles and C stand for the total cost in dollars. (a) Write the
   equation. (b) Complete the table for m = 0, 1, 2, 3, 4.
   (c) Which variable is independent, and why? (Do not solve for m —
   this task is about the relationship, not about solving.)
4. Write the inequality for "You need less than 30 minutes to finish
   the puzzle" (let t stand for minutes) and describe its graph in
   words.
5. A car travels at a steady speed given by d = 60t. How long does it
   take to travel 180 miles? Show the equation you solved.
6. Error analysis: Pat says the solutions of x > 4 are 5, 6, 7, 8,
   and so on, stopping at some biggest number. Explain Pat's error.

## Set E — Mixed review and retrieval (all lessons; UO18–UO22 + Units 01–04)

1. **Retrieval — ratios (Unit 01):** A recipe uses 2 cups of flour
   for every 3 cups of milk. How many cups of flour go with 12 cups
   of milk? (A ratio table is allowed.)
2. **Retrieval — fraction and decimal operations (Unit 02):** Compute
   (a) 5/6 ÷ 1/3 (b) 2.4 ÷ 0.6.
3. **Retrieval — integers and the plane (Unit 03):** (a) Which is
   greater, −8 or −3? (b) What is |−12|? (c) In which quadrant is
   the point (3, −4)? (d) What is the distance between (−2, 1) and
   (5, 1)?
4. **Retrieval — expressions (Unit 04):** (a) Evaluate 3x² for x = 4.
   (b) Expand 5(2 + n). (c) Are 2a + 6 and 2(a + 3) equivalent?
   Justify your answer.
5. **Mixed:** A square has side s. Its perimeter is 4s and its area
   is s². (a) Find the perimeter and the area for s = 6 cm.
   (b) Write the equation for the side length if the perimeter is
   40 cm, and solve it.
