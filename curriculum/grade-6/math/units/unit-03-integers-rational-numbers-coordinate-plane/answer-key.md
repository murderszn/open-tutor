# Answer Key — Unit 03: Integers, Rational Numbers, and the Coordinate Plane

**Adult only — do not show to the learner before they have attempted
the work.** Every student item in the lessons, practice sets, quiz, and
assessment is solved here. Open-response answers give the expected
reasoning and acceptable variation.

readings.

## Lesson 03

**Readiness:** 1. −1 (farther right). 2. 3 > 7 is false; −3 > −7 is
true — position, not digit size, decides. 3. 5 > 2; the symbol opens
toward 5, the greater number.

**Guided:** 1. (a) True. (b) True. (c) False — correct: −0.25 < 0.
(d) False — correct: 0 > −3. 2. −4, −1, 0, 3, 4. 3. Warmer: −2 °C, so
−2 > −8. As numbers: −5 > −12; the larger number is NOT the larger
debt — the larger debt is $12 (more negative). 4. −1, −3/4, −1/2, 0,
1/4.

**Independent:** 1. (a) <; (b) >; (c) >; (d) <; (e) >. 2. −6, −2.5,
−0.5, 0, 2, 5. 3. 1/2, 0, −1/4, −3/4, −2. 4. (a) −$45, −$10, $0, $20.
(b) −$45 (the largest debt). (c) −$45 < −$10. 5. (a) Wednesday −11 °C,
Monday −9 °C, Friday −6 °C, Tuesday −4 °C, Thursday 0 °C. (b)
−11 < 0. (c) Wednesday's temperature sits farther left on the number
line — smaller number means colder here — even though 11 > 9 as
plain digits.

**Exit:** 1. True — −8 sits left of −3. 2. "Negative five degrees
Celsius is warmer than (greater than) negative nine degrees Celsius."

## Lesson 04

**Readiness:** 1. 4 steps; 4 steps. 2. 4 is greater; −7 is farther
from 0. 3. The account owes $30.

**Guided:** 1. 7, 7, 0.75, 4.5. 2. (a) 5 °C is warmer. (b) −12 °C is
farther from 0 (12 > 5). (c) 5 > −12; |−12| > |5|. 3. (a) −$45 is
greater. (b) The $60 debt is greater. (c) −$45 > −$60;
|−$60| > |−$45|. 4. False — counterexample: a = −5, b = 3 gives
|−5| = 5 > |3| = 3, but −5 < 3.

**Independent:** 1. 3, 8, 1/2, 0, 10. 2. |0|, |−1|, |2|, |−4|, |−9|
(magnitudes 0, 1, 2, 4, 9). 3. (a) +20 is greater as a number.
(b) +20 has the greater magnitude (20 > 15). (c) 15 meters and
20 meters from sea level. 4. (a) $50 is greater. (b) −$80, magnitude
80 > 50 — a debt of $80. (c) Its debt is greater than $80 (for
example, −$90 has magnitude 90 > 80). 5. (a) −20, −14, −9, −3.
(b) −20 °C. (c) Yes, colder (−25 < −20) and yes, greater magnitude
(25 > 20).

**Exit:** 1. |−6| = 6 — six steps from 0. 2. Yes: −10 sits left of −4
(smaller), but 10 steps from 0 beats 4 steps (greater magnitude).

## Lesson 05

**Readiness:** 1. x = 3, y = 2; x moves horizontally, y vertically.
2. −4; 4. 3. 3 − (−4) = 7.

**Guided:** 1. (5, 1) Quadrant I; (−2, 4) Quadrant II; (−3, −6)
Quadrant III; (4, −1) Quadrant IV; (0, −3) y-axis; (−5, 0) x-axis.
2. x-axis: (−2, −5), Quadrant III. y-axis: (2, 5), Quadrant I. Both:

|−3 − 3| = 6 units.

**Independent:** 1. (2, 3) Quadrant I; (−6, 1) Quadrant II; (−1, −4)
Quadrant III; (5, −2) Quadrant IV; (0, 5) y-axis; (3, 0) x-axis.
2. x-axis: (4, 3), Quadrant I. y-axis: (−4, −3), Quadrant III. Both:
(−4, 3), Quadrant II. 3. (a) |5 − (−1)| = 6 units. (b) |6 − (−3)| = 9
units. (c) |3 − (−7)| = 10 units — not 4, because the segment crosses
0: 3 steps above plus 7 steps below = 10 (7 − 3 ignores the sign
change). 4. (a) Well: Quadrant III; gate: Quadrant II. (b)

Quadrant I; (−3, 4) Quadrant II. (b) Reflection across the y-axis.

**Exit:** 1. x is negative, y is negative. 2. |5 − (−2)| = 7 units
(or |−2 − 5| = 7).

**Set E:** E1. Sample: −1/6. Proof: −1/3 < −1/6 < 0 (on the line,
−1/6 sits between −1/3 and 0; any number in that interval works).
E2. Impossible: a given distance from 0 has exactly two points — the
number and its opposite — so same absolute value with different
numbers means opposites. E3. (a) Neither coordinate is shared, so the
shared-coordinate rule has no pair to apply to. (b) Horizontal gap
|4 − 1| = 3; vertical gap |6 − 2| = 4. (c) The straight-line

measures horizontal and vertical segments. E4. Confused: order with
magnitude. Correct order: −20 < −10, so −20 °C is colder. Correct
magnitude: |−20| = 20 > |−10| = 10, so the cold is greater in size

(−2, 1), (2, 1), (2, −3), (−2, −3) — the same set as the original:

it onto itself. E6. Sample: (1, 2) Quadrant I; (1, −3) Quadrant IV —

## Unit assessment

1. (a) +45 meters; −30 meters. (b) 0 is sea level.
2. (a) 12. (b) −7/2. (c) Between −4 and −3 (−7/2 = −3.5).
3. −4.5, −1.25, −0.5, 0, 2.75.
4. (a) −$48 < −$12. (b) The $48 debt is larger. The inequality says
   the *number* is smaller; for debts, a smaller (more negative)
   number means a larger debt — order and magnitude point opposite
   ways here.
5. |−15| = 15; |9| = 9. (a) −15 (magnitude 15). (b) 9 (9 > −15).
   (c) Order compares position (farther right wins); magnitude
   compares distance from 0 (farther from 0 wins) — different
   questions, different winners.
6. (a) $64. (b) Greater than $64 — a balance below −$64, say −$80,
   has magnitude 80 > 64.
7. (a) Quadrant III. (b) (6, −2), Quadrant IV. (c) (−6, 2), Quadrant II.
8. (a) |1 − (−6)| = 7 units. (b) |−4 − 3| = 7 units.
9. Mia ignored the sign of y (and the sign rule for quadrants):
   quadrants need both signs. (3, −4) has x positive and y negative,
   so it is in Quadrant IV, not II.
10. (a) |3 − (−4)| = 7 map units. (b) (−1, 4), Quadrant II.
11. (a) −18, −12, −7, 0 (coldest to warmest). (b) −18 °C (magnitude
    18). (c) Yes — for these readings the farthest-left point is also
    farthest from 0, because all readings are ≤ 0.
12. Sample: "Order asks which number sits farther right: 2 sits right
    of −5, so −5 < 2. Magnitude asks which number sits farther from
    0: −5 is 5 steps away while 2 is 2 steps away, so |−5| > |2|.
    Position and distance-from-zero are different measurements, so
    one number can lose the first and win the second."
