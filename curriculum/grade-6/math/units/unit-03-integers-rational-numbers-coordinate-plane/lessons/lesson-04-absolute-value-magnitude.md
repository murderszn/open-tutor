# Lesson 04 — Absolute Value: Distance and Magnitude

**My goal:** I can find the absolute value of a rational number, use it
as magnitude in a real situation, and explain why absolute-value
comparisons are not the same as order statements.

**Time:** about 45 minutes (5 readiness · 15 teaching · 10 guided ·
12 independent · 3 exit).

**Materials:** paper, pencil, a number line from −10 to 10.

**Standards:** 6.NS.C.7.c, 6.NS.C.7.d · **Unit objectives:** UO11

## Readiness check (5 minutes)

Answer before we start — this tells us what is already solid.

1. How far is 4 from 0 on the number line? How far is −4 from 0?
2. Which is greater: −7 or 4? Which is farther from 0: −7 or 4?
   (Those are two different questions — keep them separate.)
3. A bank balance is −$30. In plain words, does the account hold money
   or owe money? How much?

## Explicit teaching

### Absolute value is distance from 0

The **absolute value** of a number is its distance from 0 on the number
line. Distance is never negative, so absolute value is never negative.
It is written with vertical bars:

- **|5| = 5** — 5 is 5 steps from 0.
- **|−5| = 5** — −5 is also 5 steps from 0, on the other side.
- **|0| = 0** — 0 is 0 steps from itself.
- **|−2.5| = 2.5** and **|3/4| = 3/4**.

A quick rule: absolute value strips the sign and keeps the size.
|−a| = |a| = the number's distance from 0. It does *not* make a number
positive in the sense of "good" — it only reports how far from zero the
number sits.

### Absolute value as magnitude in a story

In real situations, absolute value answers "how big is this, ignoring
direction?" — the **magnitude**:

- An account balance of **−$30** has **|−30| = 30**: the debt is $30
  in size. The standard's own example says exactly this: write
  |−30| = 30 to describe the size of the debt in dollars.
- A temperature swing from 0 °C to −8 °C has magnitude 8 degrees: the
  temperature moved 8 degrees, downward.
- An elevation of −40 meters has magnitude 40 meters below sea level;
  an elevation of +40 meters has the same magnitude, above.

### Order vs magnitude: the distinction that matters

This is the lesson's whole point, so say it plainly:

- **Order** asks: which number sits farther right? (−7 < 4.)
- **Magnitude** asks: which number sits farther from 0? (|−7| = 7 >
  |4| = 4.)

Both statements are true at the same time. A number can be *smaller*
and *bigger in magnitude* simultaneously. The standard's example: an
account balance **less than −$30** represents a debt **greater than
$30** — for example, −$40 < −$30, but |−40| = 40 > |−30| = 30. The
debt grew while the number shrank. If you confuse the two questions,
you will say the debt shrank — exactly backwards.

### Worked example 1 — computing and comparing

Find |−9|, |6|, |−2.5|, and |0|; then decide which is greatest as a
number and which has the greatest magnitude.

- |−9| = 9, |6| = 6, |−2.5| = 2.5, |0| = 0.
- As numbers, the originals order as −9 < −2.5 < 0 < 6, so 6 is
  greatest.
- By magnitude: 9 > 6 > 2.5 > 0, so −9 has the greatest magnitude.

**A common error:** writing |−9| = −9, "because the number inside is
negative." The bars ask for *distance*, and distance cannot be
negative. If your answer has a minus sign, re-read the question: it
asked how far, not which side.

### Worked example 2 — two debts, two questions

Two fictional accounts: A = −$18, B = −$25.

- **Order question:** which balance is greater? −$18 > −$25, because
  −18 sits right of −25. Account A is closer to even.
- **Magnitude question:** which debt is larger? |−25| = 25 >
  |−18| = 18. Account B's debt is $7 larger.
- **Both sentences together:** "B's balance is smaller, but B's debt is
  bigger." If a learner can say that sentence without hesitation, the
  distinction has landed.

## Guided practice

Work these with your adult or partner. For each, answer the order
question *and* the magnitude question separately.

1. Find: |7|, |−7|, |−0.75|, |4.5|.
2. Two temperatures: −12 °C and 5 °C. (a) Which is warmer? (b) Which
   is farther from 0 °C? (c) Write both answers with symbols.
3. Two balances: −$60 and −$45. (a) Which balance is greater?
   (b) Which debt is greater? (c) Write an inequality for each answer.
4. True or false: "If |a| > |b|, then a > b." If false, give a
   counterexample with numbers.

## Independent practice

1. Find: |−3|, |8|, |−1/2|, |0|, |−10|.
2. Order these by magnitude (smallest to largest): |−4|, |2|, |−9|,
   |0|, |−1|.
3. A hiker's camp is at −15 meters (below sea level) and a lookout is
   at +20 meters. (a) Which position is greater as a number?
   (b) Which has the greater magnitude? (c) How far is each from sea
   level?
4. Two fictional bank balances: −$80 and $50. (a) Which balance is
   greater? (b) Which has the greater magnitude, and what does that
   magnitude mean in words? (c) A third balance is less than −$80.
   Is its debt greater or less than $80? Explain.
5. **Application — the storm log:** A fictional storm log lists wind
   chill readings: −14 °C, −9 °C, −20 °C, −3 °C. (a) Order them from
   coldest to warmest. (b) Which reading has the greatest magnitude?
   (c) A new reading of −25 °C arrives. Is it colder than every
   reading in the log? Does it have a greater magnitude than every
   reading in the log? Answer both, with symbols.

## Exit check

1. What is |−6|? What does it mean as a distance?
2. Is −10 < −4 but |−10| > |−4|? Explain in one sentence.

## Supports, extensions, teacher note

**Reading/language access:** Always pair the symbols with the question
words: "order = farther right?" and "magnitude = farther from zero?"
before computing.

**Alternate response mode:** Count steps from 0 on a floor number line
with footsteps, or stretch a string from 0 to the number and measure
its length — the length is the absolute value.

**Extension:** Prove that |a| = |−a| for any number a, using the
number line and the definition of opposite from Lesson 02. Then find
two different numbers with the same absolute value that are *not*
opposites — or explain why that is impossible.

**Teacher note — likely misconception:** Learners will answer the
magnitude question with the order answer (or vice versa) whenever a
problem does not label which question it asks. Train the habit: before
computing, write "O:" or "M:" beside the question — order or magnitude.
The extension's answer is that it is impossible: same absolute value
means same distance from 0, and only two points sit at a given distance
— the number and its opposite. See the
[teacher guide](../teacher-guide.md#lesson-04) and
[answer key](../answer-key.md#lesson-04) (separate — do not show the key
to the learner).
