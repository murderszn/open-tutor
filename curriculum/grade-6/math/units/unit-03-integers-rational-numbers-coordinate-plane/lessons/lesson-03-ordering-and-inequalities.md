# Lesson 03 — Ordering and Inequalities as Position

**My goal:** I can compare rational numbers, and I can read and write
inequality statements as claims about position on the number line.

**Time:** about 45 minutes (5 readiness · 15 teaching · 10 guided ·
12 independent · 3 exit).

**Materials:** paper, pencil, a number line from −10 to 10.

**Standards:** 6.NS.C.7.a, 6.NS.C.7.b · **Unit objectives:** UO10

## Readiness check (5 minutes)

Answer before we start — this tells us what is already solid.

1. Plot −4 and −1 on a number line. Which one is farther right?
2. Is 3 greater than 7? Is −3 greater than −7? Answer both, and say
   what is different about the second question.
3. Write "5 is greater than 2" using the > symbol. Which side does the
   symbol open toward?

## Explicit teaching

### Inequalities are position statements

The symbols < and > are not just "less than" and "greater than" — on a
number line, they are **position claims**:

- **a < b** means "a sits to the **left** of b."
- **a > b** means "a sits to the **right** of b."

The symbol always opens toward the greater number (the one farther
right) and points at the smaller number (the one farther left). Read
−3 > −7 as "negative three is greater than negative seven" — and check
it on the line: −3 is to the right of −7, so the statement is true,
even though 3 is smaller than 7. With negatives, "greater" means "farther
right," not "bigger pile."

### Ordering a set: plot first, then read left to right

To order rational numbers, plot them all on one line and read the line
left to right — that reading *is* smallest-to-largest order. For
fractions and decimals, convert mentally to a common picture: quarters
and halves on the same line, or decimals with the same number of places.

Compare like with like: −1/2 and −3/4 share the denominator 4 once you
rewrite −1/2 as −2/4. Then compare numerators on the negative side:
−3/4 is farther left (more negative) than −2/4, so −3/4 < −1/2.

### Worked example 1 — is it true? Check with position

Decide whether each statement is true. Plot first; never trust the
digits alone.

1. **−5 < −2.** On the line, −5 sits left of −2. Left means smaller,
   so −5 < −2 is **true**. (Say it: "negative five is less than
   negative two.")
2. **−1 > −4.** −1 sits right of −4. Right means greater, so −1 > −4
   is **true**. A debt of $1 is smaller than a debt of $4 — but as
   numbers, −1 is greater than −4. Keep the number claim and the story
   claim in separate sentences.
3. **0 > −0.5.** 0 sits right of −0.5, so 0 > −0.5 is **true**. Zero is
   greater than every negative number and less than every positive
   number — that is what makes it the dividing line.

**A common error:** "−5 is bigger than −2 because 5 is bigger than 2."
That reads the digits and ignores the sign. On the number line, the
digits tell you distance from 0, not position. Position decides order:
farther left = smaller, farther right = greater. Always.

### Worked example 2 — order statements in a real context

A fictional weather station reports three morning temperatures:
−7 °C, −3 °C, and 2 °C. Which morning was warmest? Write the order
statement.

Plot: −7, then −3, then 2, left to right. So:

**−7 < −3 < 2** (coldest to warmest).

In words: "−3 °C is warmer than −7 °C," written **−3 °C > −7 °C**. The
standard's own example says exactly this: −3 °C > −7 °C expresses that
−3 °C is warmer than −7 °C. Notice the trap: the *warmer* temperature
has the *smaller-looking* digits (3 < 7) but the greater position.

Now write a constraint-style statement: "The temperature stayed below
0 °C all morning." If t stands for the temperature, that claim is
**t < 0**. (Full inequality-with-variables work comes in Unit 05; here
the point is only that < and > describe position, not just size.)

## Guided practice

Work these with your adult or partner. Plot before you decide.

1. True or false: (a) −6 < −1; (b) −2 > −9; (c) −0.25 > 0; (d) 0 < −3.
   Correct any false statement.
2. Order from least to greatest: 4, −4, 0, −1, 3.
3. Write an inequality comparing −8 °C and −2 °C that says which is
   warmer. Then write one comparing a $5 debt (−$5) and a $12 debt
   (−$12) that says which debt is larger as a number — and in one
   sentence, say whether "larger number" means "larger debt" here.
4. Order from least to greatest: −1/2, −3/4, 1/4, 0, −1.

## Independent practice

1. Write < or > to make each true: (a) −9 ___ −4; (b) −0.5 ___ −1.5;
   (c) 2.5 ___ −2.5; (d) −3/4 ___ −1/2; (e) 0 ___ −6.
2. Order from least to greatest: −6, 2, −2.5, 0, 5, −0.5.
3. Order from greatest to least: −3/4, 1/2, −1/4, 0, −2.
4. A bank lists four balances (fictional): −$45, $20, −$10, $0. (a)
   Order them from least to greatest. (b) Which balance is the largest
   debt? (c) Write an inequality that compares the two negative
   balances.
5. **Application — the cold snap:** A fictional town records five
   nightly lows: Monday −9 °C, Tuesday −4 °C, Wednesday −11 °C,
   Thursday 0 °C, Friday −6 °C. (a) Order the nights from coldest to
   warmest. (b) Write the coldest night's temperature with < to compare
   it to Thursday's. (c) In one sentence, explain why Wednesday was
   colder than Monday even though 11 > 9.

## Exit check

1. Is −8 < −3 true or false? Explain with left/right.
2. Write −5 °C > −9 °C in words, as a temperature comparison.

## Supports, extensions, teacher note

**Reading/language access:** Read every inequality aloud in both
directions ("negative five is less than negative two" / "negative two
is greater than negative five") before deciding true or false.

**Alternate response mode:** Place number cards on a floor line and
physically stand at each position; the learner on the left is the
smaller number.

**Extension:** Find a rational number between −3/4 and −1/2, prove it
with a number line, and write two true inequalities using it. Then
explain why there are infinitely many numbers between any two different
numbers.

**Teacher note — likely misconception:** The digit-size trap (−5 "bigger"
than −2 because 5 > 2) is the single most persistent error in this unit.
It returns in Lesson 04 disguised as an absolute-value question, so do
not let it pass here: every comparison must be justified with a
position word (left/right) before it is justified with a symbol. See
the [teacher guide](../teacher-guide.md#lesson-03) and
[answer key](../answer-key.md#lesson-03) (separate — do not show the key
to the learner).
