# Teacher Guide — Unit 04: Ancient South and East Asian Societies

**Adult only.** Do not hand this file to the learner. It
contains session notes, misconception alerts, reteach moves,
and sensitive-content guidance. Solutions are in
[answer-key.md](answer-key.md).

## Session-by-session notes (S1–S16, about 40 minutes each)

- **S1 (L01):** Teach monsoon as a seasonal wind reversal, not
  a storm. Have the learner trace summer arrows (sea → land)
  on the map before any writing. Check the picture task:
  observation vs. inference must stay separate.
- **S2 (Set A + map):** Expect map-label errors on the Yellow
  vs. Yangtze (north vs. south). Reteach: "Yellow = north,
  loess; Yangtze = south, rice." Require a map feature in
  every answer.
- **S3 (monsoon tray investigation):** Adult supervises water.
  Two slopes in trays: one with stepped cardboard terraces,
  one smooth slope. Pour equal "rain" (a cup through holes).
  Record soil loss qualitatively (clear vs. muddy runoff, soil
  at tray bottom). Prediction must be written before pouring.
  Alternative without water: tilt boards and roll dry sand.
- **S4 (review + check):** Spiral: monsoon sentence, one
  barrier (Himalayas/desert/sea distance), one route. Reteach
  any missing piece with the map, not with a lecture.
- **S5 (L02):** Stress the honesty point: planned ≠ known
  rulers. If the learner invents an Indus king, stop and
  re-teach "undeciphered." Ashoka's edicts: paraphrase only;
  distinguish policy from behavior.
- **S6 (Set B + timeline):** Timeline arithmetic is the
  stumbling block. Within BCE: subtract. Across BCE/CE:
  add and subtract 1. Drill one example aloud before Set B5.
- **S7 (L03 + project launch):** Keep descriptions neutral.
  If the learner ranks beliefs, use Lesson 03's Worked
  example B as the correction model. Launch the project:
  approve two-society choices today.
- **S8 (review + check):** Ask for one spread route from
  memory (monks/merchants along Silk Roads or sea routes)
  and one evidence limit.
- **S9 (L04):** Dynasties in order first, then change vs.
  continuity. Do not let "Qin built the Great Wall" stand
  uncorrected: Qin joined/extended earlier walls; the famous
  brick wall is mostly Ming-era.
- **S10 (Set C + tax perspectives):** Run the three
  perspectives as a short role play before writing. The
  learning goal is that all three can be partly right and
  that records favor officials.
- **S11 (standardization test):** Fictional practice data:
  two "local" measure sets (different cup sizes) vs. one
  shared set; measure the same grain pile three ways. The
  point is comparability, not precision. No real weighing
  hazards; use dry rice and cups.
- **S12 (spiral check):** Four facts from memory (geography,
  South Asia, belief, China). Any gap becomes S15 project
  support, not a new lecture.
- **S13 (L05):** Model the comparison table on the board
  before the learner writes. Insist on the same five
  questions for both societies.
- **S14 (Set D + quiz):** Quiz is formative: score it the
  same day, reteach missed items in S15, and do not record
  the quiz as a final grade.
- **S15 (project work):** Check each exhibit for the four
  parts and the source list. The most common gap is the
  "cannot prove" sentence — send learners back to it.
- **S16 (review + assessment + project due):** Assessment is
  open to the map and timeline diagrams but not to the
  answer key or lesson texts. Collect exhibits with rubrics.

## Misconception notes

- Monsoon = one storm → seasonal wind pattern with wet and
  dry seasons.
- Terraces are natural → built steps; maintenance is a cost.
- "Undeciphered" = "no writing" → writing exists and cannot
  yet be read; a bilingual text would change that.
- Edicts = behavior → edicts = ruler's public policy.
- Dynasties = clean breaks → institutions (writing, tax,
  irrigation) continue across dynasties.
- Diffusion = copying → ideas change as they travel.
- Longevity = superiority → longevity is a fact, not a
  ranking; compare with the same questions.
- "Hinduism" as one uniform system → say "Hindu traditions."
- Qin wall = today's Great Wall → Qin joined earlier walls;
  the iconic brick wall is much later.

## Reteach moves

- **Map confusion:** Cover labels; learner rebuilds the map
  from memory in three passes (mountains, rivers, routes).
- **BCE/CE arithmetic:** Draw the number line with no 0;
  walk two examples (same-era subtraction; cross-era add
  minus 1) before re-attempting.
- **Ranking beliefs:** Return to Lesson 03, Worked example B;
  require a rewrite that gives each tradition its own logic.
- **Single-cause explanations:** Ask "What else had to be
  true for that cause to work?" until a second cause appears.
- **Vague comparisons:** Require the five-question frame and
  one cited evidence item per row.

## Sensitive-content guidance

- Social hierarchy (varna/jati), forced labor, warfare, and
  book burning: name plainly, briefly, no graphic detail, no
  glorification. Who was forced, who decided, who resisted
  or suffered — in one or two sentences each.
- Belief systems: describe, never evaluate; use present
  tense for living traditions; preview every video for
  respectful framing; skip anything that mocks a tradition.
- Present-day connections stay descriptive (for example,
  "Buddhism is practiced in many countries today") and never
  treat living peoples as relics.
- If the learner asks about their own family's beliefs,
  welcome it, but do not grade the answer and do not make
  the lesson about any one learner's faith.

## Readiness and follow-up

- **Ready for Unit 05 (Greece):** Learner can compare two
  societies with the same questions, rank causes with reasons,
  and state an evidence limit unprompted.
- **Reteach before Unit 05:** Learner still ranks beliefs,
  gives single-cause explanations, or cannot place BCE/CE
  dates. Reuse Lessons 03 and 05 with new society pairs.
- **Extension:** Learner adds a third society (from Unit 03)
  to the Lesson 05 table for one row, with sources.
