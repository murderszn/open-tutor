# Resource Pack — Unit 02: Literature: Theme, Plot, and Narrator

**For the adult.** Summary: this pack supports a grade-6
literature unit on theme (RL.6.2), plot episodes and character
change (RL.6.3), word choice and structure (RL.6.4–6.5), point
of view (RL.6.6), reading-vs-listening and cross-form comparison
(RL.6.7, RL.6.9). All core objectives are teachable offline
with the unit's original passages; every external item below is
a supplement, not a requirement. Checked 2026-10-19 unless
noted. Nothing here requires a learner account.
