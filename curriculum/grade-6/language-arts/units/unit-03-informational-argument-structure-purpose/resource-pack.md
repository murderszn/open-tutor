# Resource Pack — Unit 03: Informational Reading, Argument, and Author Purpose

**Goal (adult planning judgment):** Give the guiding adult free,
no-account videos and references that reinforce this unit's five
objectives — central idea and objective summary, key-individual
development and structure, author purpose and word meanings,
argument evaluation, and comparing accounts across media — for a
grade-6 learner (ages 11–12). Videos supplement the lessons; they
never replace explicit teaching, practice, or the adult's check.

All external links below were found via web search on 2026-10-25
and are described only as far as the search results establish
them. Runtimes and captions were not checked — preview before
assigning. YouTube serves ads; use an ad-blocked or supervised
session with the learner. Search links are labeled as such: they
are not single verified videos.

## Web references (5, found 2026-10-25)

1. [How Do I Teach Main Idea? — Reading
   Rockets](https://www.readingrockets.org/blogs/shanahan-literacy/how-do-i-teach-main-idea)
   — teacher guidance on separating topics, main ideas, key
   details, and trivial information, including crossing out
   unimportant information and building paragraph summaries into
   whole-text summaries. Adult-facing; supports Lesson 01 and
   Practice A.
2. [Summarizing — Reading
   Rockets](https://www.readingrockets.org/classroom/classroom-strategies/summarizing?ref=blog.tldrthis.com)
   — classroom strategy page: framework questions ("What are
   the main ideas? What details support them? What is
   irrelevant?"), keyword approaches, and demonstration notes.
   Adult-facing; supports Lesson 01's objective-summary work.
3. [Grade 6 Reading: Informational Text standards
   listing](https://www.coursemason.com/Standards/English-Language-Arts/Grade-6/Reading-Information-Text)
   — plain listing of the RI.6.1–RI.6.10 standard texts used in
   this unit's crosswalk (central idea, key individual,
   structure, purpose, media integration, argument evaluation,
   author comparison, text complexity). Adult reference for the
   unit's standards notes; the authoritative framework is the
   published Common Core ELA standards.
4. [Analyze How Authors Present Evidence Differently in Articles
   — EL Education
   Curriculum](https://curriculum.eleducation.org/curriculum/ela/2019/grade-7/module-4/unit-2/lesson-3)
   — a grade-7 lesson (adult-facing for grade-6 adaptation)
   modeling how two authors' evidence choices shape different
   interpretations of the same topic, with a compare-evidence
   note-catcher routine. Supports Lesson 05's comparison work;
   the adult adapts the grade level and previews the articles.
5. [Six Steps to Assess the Reasoning and Evidence Used to
   Support the Author's Claims — Thinkport
   (Maryland Public Television)](https://socialstudies.thinkport.org/mod33/interactives/drag-and-drop/review-it.html)
   — interactive ordering activity for the evaluation steps:
   identify the claim, identify evidence, judge relevance,
   judge evidence type/validity, check counterclaims. Adult
   previews for keyboard accessibility before assigning;
   supports Lesson 04's trace routine.
