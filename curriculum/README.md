# Independent Grade Curriculum

Four separate, anonymous tracks: **Grade 4, Grade 5, Grade 7, and Grade 8**. Each folder is self-contained, with its own prompts, assignments, assessments, and intended products. Select one grade folder for one learner at a time.

**Do not refer a learner to another grade's folder. Do not combine assignments across grades, ask learners to work together, compare their results, or refer to siblings/peers.** These are reusable teaching materials, not learner profiles or records.

## Using a Track

1. Choose exactly one grade folder.
2. Select a subject, then a blank assignment or assessment inside that same folder.
3. Preview external resources and check prerequisite knowledge, accessibility, safety, and readiness.
4. Keep completed work, names, grades, schedules, and feedback in private storage—not this public repository.
5. Treat these materials as adaptable drafts, not a formal accreditation or standards guarantee. Optional Christian enrichment is explicitly separate from secular instruction.

Some retained unit titles may be ambitious or unevenly aligned with grade-level standards. Review individual materials before assigning.

See [Teaching Library Usage](../docs/teaching-library-usage.md), [Assignments](../assignments/README.md), and [Resources](../resources/README.md).

Never cross-link a learner's assignment to a different grade track.
