# Lesson 02 — Reading, Writing, and Comparing Numbers to 1,000,000

**Session:** 3 · **Time:** 35 minutes · **Goal:** I can read and write numbers
to 1,000,000 as numerals, number names, and expanded form, and compare two
numbers by working place-by-place from the left.

**Materials:** place-value chart, digit cards, paper and pencil.

## Readiness check (4 min)

Dictate: "five thousand, two hundred forty." Learner writes the numeral
(5,240). Then: "What is the 2 worth?" (200.) If dictation is shaky, do two
more small dictations before the six-digit work.

## Explicit teaching (10 min)

We write a number three ways:

- **Numeral:** 58,204 (digits and commas)
- **Number name:** fifty-eight thousand, two hundred four (words)
- **Expanded form:** 50,000 + 8,000 + 200 + 4 (each digit's true value, added)

To read a big number: split it into periods at the commas, read each
three-digit group as if it were alone, then say the period name: 317,650 →
"three hundred seventeen **thousand**, six hundred fifty." We do not say
"thousand" after the last group, and we never say "and" inside a whole number
("three hundred and seventeen thousand" is a common slip — skip the "and").

To **compare** two numbers: first check the number of digits (more digits =
bigger number). If the digit counts match, start at the leftmost place and find
the first place where the digits differ — the number with the bigger digit
there is bigger. Record with `>`, `=`, `<`.

## Worked example 1 — Three ways to write 58,204

1. Periods: 58 | 204 → "fifty-eight **thousand**," then "two hundred four."
2. Number name: fifty-eight thousand, two hundred four.
3. Expanded form: 50,000 + 8,000 + 200 + 4.
4. Check: 50,000 + 8,000 = 58,000; + 200 = 58,200; + 4 = 58,204. ✓

## Worked example 2 — Compare 486,210 and 468,210

1. Both have six digits — go place by place from the left.
2. Hundred-thousands: 4 and 4 — tie. Ten-thousands: 8 and 6 — differ!
3. 8 > 6, so 486,210 > 468,210. The remaining digits do not matter.
4. Common slip: starting the comparison at the ones place. Place value reads
   left to right, biggest place first.

## Guided practice (with hints)

1. Write the number name for **317,650**. *(Hint: split at the comma; read the
   left group, say "thousand," read the right group.)*
2. Write the expanded form of **317,650**. *(Hint: what is the 3 worth? The 1?
   Keep going right.)*
3. Write the numeral for "nine hundred four thousand, twenty-one."
   *(Hint: the thousands group is "nine hundred four" — write it, then a comma,
   then three digits for the ones group.)*
4. Compare 705,330 and 705,303 with `>`, `=`, or `<`. *(Hint: scan left to
   right — which is the first place that differs?)*
5. Order these from least to greatest: 89,610; 98,601; 89,061. *(Hint: compare
   the first two places; two of them tie until the hundreds.)*

## Independent practice

6. Write the expanded form of **246,531**.
7. Write the numeral for "two hundred six thousand, four hundred eight."
8. True or false: 550,000 > 505,000. Explain with places.
9. In 60,715, what place is the 0 in, and what is its value? Why does it matter?
10. Write the number name for **1,000,000**. What is special about its expanded
    form?

## Application

Zero-holder hunt: the adult writes five six-digit numbers, each with at least
one zero (e.g., 507,300; 60,715; 900,460). The learner reads each aloud and
circles every zero, labeling its place. Then the learner explains: what would
happen to 507,300 if we erased the 0 in the ten-thousands place?

## Exit check

Write one number between 340,000 and 350,000 as a numeral and in expanded form.

## Supports

- **Reading/language access:** pair every written number with a spoken reading;
  let the learner trace the commas with a finger while reading periods.
- **Alternate response mode:** build numbers with digit cards on the chart
  instead of writing; compare by sliding cards.
- **Extension:** write 999,999 and 1,000,000 in expanded form. What changes at
  the million boundary? (A new period begins; 1,000,000 = 1,000 × 1,000.)

## Teacher note

Likely misconception: writing "four thousand twenty-one" as 421 (dropping the
thousands group) or 4,021 vs 4021-style comma errors. Reteach: every period
after the first must contribute exactly three digits — use leading zeros
("nine hundred four thousand, twenty-one" → 904 | 021). Answer-key reference:
[answer-key.md](../answer-key.md#lesson-02).
