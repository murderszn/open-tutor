# Lesson 05 — Ordering Sets and Equivalence Chains

**Session:** 9 · **Time:** 35 minutes · **Goal:** I can order a set of
three or more fractions with a common denominator, write an equivalence
chain of at least three names for one amount, and solve a comparison word
problem with a justified answer.

**Materials:** paper strips, colored pencils, paper and pencil.

## Readiness check (4 min)

Warm-up retrieval: "Rewrite 1/2, 3/4, and 5/8 all with denominator 8."
(1/2 = 4/8; 3/4 = 6/8; 5/8 stays.) "Now read them in order, least to
greatest." (4/8 < 5/8 < 6/8, so 1/2 < 5/8 < 3/4.) Ordering a set is one
comparison done several times at once — today's lesson.

## Explicit teaching (10 min)

**Ordering a set.** Rewrite every fraction in the set with the same
denominator, then order by numerator — the pieces are now the same size,
so more pieces means a greater amount. Keep the denominators inside the
grade-4 list where the set allows it.

> Order 1/2, 3/4, 5/8 → 4/8, 6/8, 5/8 → 1/2 < 5/8 < 3/4

Write the final order with the ORIGINAL fractions, not the rewrites —
the rewrites were your working, not your answer.

**Equivalence chains.** One amount can have many names, linked by
multiplying or dividing both numbers by the same number at each step:

> 1/3 = 2/6 = 4/12

Read a chain left to right and check each link: 1/3 → 2/6 multiplies
both by 2 (each third cut in half); 2/6 → 4/12 multiplies both by 2
again (each sixth cut in half). Every link must keep the amount — a
chain with one bad link is a broken chain.

Chains can also reach denominator 100, which is where Unit 06's decimal
work will pick them up: 2/5 = 4/10 = 40/100 (×2, then ×10).

**Word problems.** A comparison word problem always hides two jobs:
(1) name the whole and check that it is the same for both amounts, and
(2) compare. Do job (1) first, in words, before any computation. If the
wholes differ, say so and stop — that is a complete answer.

## Worked example 1 — Ordering 1/2, 3/4, 5/8

Problem: "Order 1/2, 3/4, and 5/8 from least to greatest."

1. Common denominator: 8 works for all three (2 × 4 = 8; 4 × 2 = 8;
   8 × 1 = 8), and 8 is in the grade-4 list.
2. Rewrite: 1/2 = 4/8; 3/4 = 6/8; 5/8 stays 5/8.
3. Same denominator — order by numerator: 4/8 < 5/8 < 6/8.
4. Answer with the original fractions: **1/2 < 5/8 < 3/4**. ✓
5. Model check: three bars of the same length, shaded 4, 5, and 6
   eighths — the shaded lengths grow in exactly that order. ✓

## Worked example 2 — A chain and a check against 1/2

Problem: "Write an equivalence chain of three names for 1/3, and show
that every name in the chain is less than 1/2."

1. Chain: 1/3 = 2/6 = 4/12. Check the links: ×2, then ×2. Both links
   multiply numerator and denominator by the same number. ✓
2. Compare each name with 1/2: 1/3 < 1/2 (1 < 1.5); 2/6 = 1/3, so it is
   also less; 4/12 = 1/3, so it is also less. (Or rewrite 1/2 as 6/12:
   4/12 < 6/12.) ✓
3. Lesson: every name in a chain names the same amount, so if one name
   is less than 1/2, they all are. Chains do not change comparisons —
   they only rename.

## Guided practice (with hints)

1. Order 2/5, 1/2, and 7/10 from least to greatest. Show the rewrites.
   *(Hint: denominator 10 works for all three: 2/5 = 4/10, 1/2 = 5/10,
   7/10 stays. Order: 2/5 < 1/2 < 7/10.)*
2. Order 5/6, 3/4, and 2/3 from least to greatest. Show the rewrites.
   *(Hint: denominator 12 works for all three: 5/6 = 10/12, 3/4 = 9/12,
   2/3 = 8/12. Order: 2/3 < 3/4 < 5/6.)*
3. Write an equivalence chain of three names for 2/5, and check each
   link.
   *(Hint: 2/5 = 4/10 = 40/100. Links: ×2, then ×10. Both denominators
   — 10, 100 — are in the grade-4 list.)*
4. Word problem: "Ana ran 3/4 km, Ben ran 5/6 km, and Cid ran 2/3 km on
   the same track. Who ran farthest? Who ran least? Justify."
   *(Hint: the whole is the same (the track, 1 km) for all three, so
   compare freely. Denominator 12: 3/4 = 9/12, 5/6 = 10/12, 2/3 = 8/12.
   Order: Cid (2/3) < Ana (3/4) < Ben (5/6). Ben ran farthest; Cid ran
   least.)*

## Independent practice

5. Order 1/4, 3/8, and 1/2 from least to greatest. Show the rewrites.
6. Write an equivalence chain of three names for 3/5, and check each
   link.
7. Word problem: "Three identical juice bottles are drunk down: Pia's
   bottle is 5/8 full, Quinn's is 3/4 full, Ria's is 1/2 full. Order the
   bottles from least juice to most juice. Justify."
8. **Error analysis:** Sam says, "I can order fractions by their
   numerators alone: 2/5 > 1/2 because 2 > 1." Show that Sam is wrong,
   with a rewrite or a model.

## Applied task

Make an "ordering wall": three same-length strips showing 2/3, 3/4, and
5/6, lined up at the left edge, with each strip labeled and the order
written underneath (2/3 < 3/4 < 5/6). Then write one sentence explaining
why the strips must be the same length for the wall to mean anything.
(Answer: the strips are the wholes — if they differed in length, the
shaded lengths would not be comparable, and the order could be wrong
even with correct fractions.)

## Exit check

Order 3/5, 1/2, and 4/5 from least to greatest. Show the rewrites.
(Answer: denominator 10: 3/5 = 6/10, 1/2 = 5/10, 4/5 = 8/10, so
1/2 < 3/5 < 4/5. If you ordered by numerator alone (1, 3, 4), you got
the same order by luck this time — re-read Sam's error in item 8.)

## Supports, extensions, teacher note

- **Reading/language support:** an ordering frame on a card: "Rewrite →
  order by numerator → answer with the original fractions."
- **Alternate response mode:** order physical strips by shaded length
  before writing any symbols; the adult scribes the rewrites.
- **Extension:** order a set that includes a whole: 3/4, 4/4, 5/6, 1/2
  → 1/2 = 6/12 < 3/4 = 9/12 < 5/6 = 10/12 < 4/4 = 12/12, so
  1/2 < 3/4 < 5/6 < 4/4.
- **Teacher note — likely misconception:** ordering by numerator alone
  (Sam's error) or by denominator alone both survive into this lesson.
  Require the common-denominator rewrite in writing until the learner
  can do it mentally — and keep the same-whole check as the first
  sentence of every word-problem answer. **Answer-key reference:**
  [../answer-key.md](../answer-key.md), Lesson 05.
