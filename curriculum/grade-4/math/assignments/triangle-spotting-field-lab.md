# Triangle Spotting Field Lab - Learner

Shared spec: Shared reference(use the selected grade’s private workspace)

## Learner Checklist

- [ ] Find at least 5 real-world triangles.
- [ ] Photograph or sketch each triangle without private information in the image.
- [ ] Label each one as equilateral, isosceles, or scalene if you can tell.
- [ ] Label each one as acute, right, or obtuse if you can tell.
- [ ] Pick your favorite triangle from the hunt.
- [ ] Write 4-6 sentences explaining where you found it and what kind of triangle it is.

Use the Resource Pack in the shared spec for videos, web references, and quick-open searches. Start with Math Antics or Khan Academy triangle videos if you need a reminder before the hunt.
