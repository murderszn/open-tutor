# Grade 4 — Step-by-Step Algorithm Card

## Goal
Write a clear sequence that sorts a small set of classroom objects by color.

## Steps
1. List the objects and the rule for sorting them.
2. Write at least six numbered actions, one action per step.
3. Draw a simple flowchart with start, action, decision, and finish symbols.
4. Ask an adult to follow the instructions literally; revise one ambiguous step.

**Product:** An illustrated instruction card and a short note about the revision. No peer or cross-grade comparison.
