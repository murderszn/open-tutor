# Project — Two-Source Topic Report

**Time:** Sessions W13 S12 (launch), W14 S13 (draft), W14 S14
(presentations). **Standards:** RI.4.1, RI.4.2, RI.4.5, RI.4.9,
W.4.8, SL.4.3, SL.4.4.

## The task

Choose one topic from the adult-approved list below. The adult
selects two short texts on that topic (library books, magazine
articles, or passages the adult writes — never open web searching by
the learner). Read both texts, take categorized notes, write a
short report that integrates both texts, list your sources, and
present your report aloud in about two minutes.

**Adult-approved topics (pick one):** honeybees · lighthouses ·
pumpkins · composting · school gardens · the Moon · bridges ·
recycling · the water cycle · local weather.

## Steps

1. **Choose and preview.** Pick a topic. Preview both texts: read
   the titles and first paragraphs. Write one question you want the
   texts to answer.
2. **Read and note.** Read Text 1. Write notes in phrases — no
   copied sentences — under category headings you choose (for
   example: *What it is / How it works / Why it matters*). Do the
   same for Text 2, in a different color or column so you can tell
   which notes came from which text.
3. **Compare.** Answer: What does Text 1 tell you that Text 2 does
   not? What does Text 2 tell you that Text 1 does not? What do
   they agree on? Is one firsthand and the other secondhand — and
   does that change what you trust each one for?
4. **Draft.** Write a report of 3–4 paragraphs: (a) an opening with
   the main idea; (b) one or two paragraphs weaving facts from both
   texts, with a note of which text each fact came from; (c) a
   closing paragraph with your own conclusion — a sentence that
   needs both texts to be true. Add a source list naming both
   texts.
5. **Revise.** Read the draft aloud. Check: does every fact point
   to a text? Is any sentence copied word for word? Does the
   conclusion need both texts? Fix what fails.
6. **Present.** Present the report aloud in about two minutes,
   speaking clearly at an understandable pace (SL.4.4). Listeners
   use the listening check below.

## Deliverables

- Categorized notes from both texts (phrases, not copies), with the
  source of each note marked
- A 3–4 paragraph report with main idea, facts from both texts, your
  own conclusion, and a source list
- A two-minute oral presentation

## Listening check (for the audience, SL.4.3)

While listening, each listener writes: the speaker's main idea, one
reason the speaker gave, and one piece of evidence for that reason.
After the talk, listeners share one reason-evidence pair they
heard.

## Rubric

| Criterion | Strong (3) | Developing (2) | Starting (1) |
|---|---|---|---|
| Main idea and key details (RI.4.2) | Main idea is a full sentence covering the topic; at least 3 key details from the texts support it | Main idea is present but partly a topic or partly off-target; 1–2 key details | Main idea is a topic word or a copied sentence; details are random or missing |
| Two-text integration (RI.4.9) | Facts from both texts are woven into shared paragraphs; closing conclusion needs both texts | Both texts are used but mostly in separate paragraphs; conclusion leans on one text | Only one text is used, or the report is two summaries |
| Notes and sources (W.4.8) | Notes are phrases in categories with sources marked; source list names both texts | Notes mix phrases and copied sentences, or one source is unmarked | Notes are copied sentences, or no source list |
| Structure and vocabulary (RI.4.5, L.4.6) | Report names or shows a clear structure (chronology, comparison, cause/effect, or problem/solution); domain words used correctly | Structure is unclear; domain words mostly correct | No recognizable structure; domain words missing or misused |
| Presentation and listening (SL.4.3, SL.4.4) | Clear, organized, understandable pace; listener can name the point, a reason, and evidence | Understandable but rushed or disorganized; listeners catch only part | Hard to follow; listeners cannot name point or reasons |

**Scoring:** 13–15 = strong; 9–12 = developing; 5–8 = starting with
reteaching. The adult records one strength and one next step for
every learner; a first draft is never graded for perfection.

## Safety and privacy

All sources are adult-selected. No learner work, names, photos, or
schedules go into the public repository; the report stays in
private storage. Presentations happen in the learning setting only.
