   adoption claimed.
4. [ReadWriteThink — lesson and strategy resources](https://www.readwritethink.org/) —
   established ELA educator library (NCTE/ILA); adult searches its
   grades 3–5 theme and point-of-view lessons for alternate models.
5. [PBS LearningMedia](https://www.pbslearningmedia.org/) — free
   (account optional for some features); captioned ELA videos; adult
   previews any item before assigning.

## Access notes

- Every core objective is reachable **offline**: all anchor texts,
  the illustration (with text-only alternative), practice, and
  assessments are in the unit folder — no account, purchase, or video
  required.
- Videos are supplements only; each has a labeled search link so the
  adult can preview and choose. Nothing requires a learner account.
- Traditional tales are the unit's **original retellings** of
  public-domain plots; the LOC collection is an adult reference and an
  optional alternate read-aloud, not a quoted source.
