# Project — Message Across the Room: The Information-Transfer Fair

**Job:** Send a 4-item message across the room — without speaking and
without walking over — using patterns, and prove with fair tests which
of your two solutions works best.

The unit's investigation. Runs across Sessions 12 (planning), 13
(testing), and 15 (the fair). Adult-supervised throughout. This project
is the applied form of 4-PS4-3 and 3-5-ETS1-2/3-5-ETS1-3: generate,
compare, and fair-test pattern solutions.

## Materials

Drum or upturned pot with spoon; flashlight (battery only,
adult-handled); grid paper or printed 5-column grids; index cards for
code cards; science journal; the agreed 4-message list (choose any
four messages, for example: come, stop, look, help — the same four for
both solutions and every trial); a timer or clock.

**Safety:** never shine a flashlight into anyone's eyes and never look
into the beam; drumming in short bursts at a comfortable level; the
adult handles the flashlight for flashlight-code trials.

## Steps

1. **Choose two solutions** (Session 12): pick any two pattern
   solutions from the unit — drum code, tap code, flashlight code
   (long/short flashes), or picture-grid code (the grid is "sent" by
   holding it up or passing the numbers aloud in order — the sender
   still does not walk over). Write a code card for each, and do not
   change either card after testing starts.
2. **Agree criteria and constraints first** (Session 12): copy these
   into your journal, or write your own with the adult and keep them
   fixed:
   - **Criteria:** (1) the receiver writes the message correctly;
     (2) each message arrives in under 1 minute; (3) the receiver can
     repeat the message back correctly.
   - **Constraints:** (1) no speaking, no walking over; (2) only
     materials on hand; (3) sound levels comfortable; (4) flashlight
     never aimed at eyes.
3. **Plan the fair test** (Session 12): same four messages, same
   distance, same receiver, 3 trials of 4 messages each per solution
   (12 messages per solution). Name the one change (the solution
   itself) and at least three things kept the same. Name one failure
   point and its prevention (for example: "the receiver miscounts
   beats" → "send each message twice and the receiver repeats it
   back"; "a flash is missed in bright light" → "dim the room for
   flashlight trials and note the light level").
4. **Test** (Session 13): run all trials. Record every trial honestly,
   including failures and constraint breaks. A trial that breaks a
   constraint (someone speaks, the flashlight aims at eyes) does not
   count — mark it "disqualified" and re-run it, noting both.
5. **Compare** (Session 13): total the correct messages for each
   solution (out of 12). Judge constraints first: any solution that
   repeatedly broke a constraint cannot be recommended even if its
   score is higher. Then judge criteria: accuracy first, then time.
6. **Recommend and present** (Session 15, the fair): present both
   solutions live, show the test table, and state a recommendation
   supported by the totals. Name one honest limitation (for example:
   "we tested with one receiver in one room; a different room or a
   noisier day might change the result").
7. **Report** (Session 16, with the unit assessment): complete the
   six-part report — question, plan (criteria, constraints, fair-test
   design), data table, comparison, recommendation with evidence, and
   limitation — in the Unit 01 investigation-report format.

## Deliverables

1. Two code cards (fixed before testing; any mid-test change noted and
   earlier trials re-run).
2. The written criteria, constraints, and fair-test plan (one change,
   ≥3 things kept the same, trials, failure point with prevention).
3. The labeled test table: 3 trials × 4 messages per solution, every
   result recorded, disqualified trials marked, totals out of 12.
4. A comparison paragraph and a one-sentence recommendation naming the
   winner and the numbers behind it.
5. The six-part investigation report with one honest limitation.

## Rubric

| Criterion | Strong (3) | Developing (2) | Starting (1) |
|---|---|---|---|
| **Fair plan** | Two code cards fixed before testing; criteria + constraints written; one change named; ≥3 things kept the same; 3 trials per solution; failure point with prevention | Code cards present but one changes mid-test without re-running, or plan names only 1–2 things kept the same | No fixed code cards, or >1 change between solutions, or no trials planned |
| **Honest data** | Every trial recorded with correct/incorrect; disqualified trials marked, not erased; totals out of 12 correct | Most trials recorded; one failure or disqualification missing | Trials missing or totals wrong; failures erased |
| **Comparison** | Constraints judged first; accuracy compared with totals (e.g., 10 of 12 vs. 8 of 12); time checked against the 1-minute criterion | Comparison names a winner but cites only one trial, or ignores a constraint break | Winner named with no numbers, or winner contradicts the table |
| **Recommendation and limitation** | One-sentence recommendation supported by the totals; one honest limitation named | Recommendation given but weakly tied to data, or limitation vague | No recommendation, or claim without data, or no limitation |

**Scoring:** 10–12 = strong; 7–9 = developing (revise the missed part
and re-present); 4–6 = starting (re-run the investigation with adult
support, keeping the same code cards).
