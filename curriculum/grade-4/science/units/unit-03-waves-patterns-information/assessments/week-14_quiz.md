# Week-14 Formative Quiz

**Adult administers in Session 14.** 10 items covering all five unit
objectives. Oral, drawn, or manipulative answers are acceptable; the
adult records them. Keys in [answer-key.md](../answer-key.md) (adult
only).
**This is a practice check, not a standardized or validated test.**

1. Define *amplitude* and *wavelength* in your own words. *(Objective 1)*
2. A cork floats in a water tray. Ripples reach it. What does the cork
   do, and what does that show about waves? *(Objective 1)*
3. Look at the wave diagram in
   [assets/wave-diagram.svg](../assets/wave-diagram.svg): which wave,
   A or B, has the bigger amplitude? Which has the longer wavelength?
   *(Objective 1)*
4. A rubber band is plucked loose, then stretched tight and plucked
   again. What changes about the sound — pitch, volume, or both?
   Explain. *(Objective 1 — sound as waves; Objective 2 thread: waves
   carry energy)*
5. Draw the seeing chain for a lamp, a book, and an eye, with arrows
   in the correct order. What happens if the lamp is switched off?
   *(Objective 2)*
6. You look through a peephole into a sealed dark box. You see nothing.
   A friend says the toy vanished. Give the better explanation.
   *(Objective 2)*
7. Decode this grid. What letter is it? *(Objective 3)*
   Row 1: 1 1 1 1 1; Row 2: 0 0 1 0 0; Row 3: 0 0 1 0 0; Row 4: 0 0 1 0 0.
8. A drum code sends "help" as 4 beats, but the receiver hears 3 beats
   and reads "look." What went wrong, and what check would catch it?
   *(Objective 3)*
9. Two solutions are tested fairly, 3 trials of 4 messages each.
   Solution M: 4, 3, 4 right. Solution N: 2, 4, 3 right. Which is more
   accurate, and by how many messages? *(Objective 4)*
10. A team tests its code in a quiet room while the other team tests
    while music plays. Is this a fair comparison? Name what else
    changed besides the solution. *(Objective 4; Objective 5: the
    pattern, tested fairly, is what carries the message)*

**Scoring guide:** 9–10 = strong, ready for the unit assessment; 7–8 =
review the missed objectives with the matching practice set, then
proceed; ≤6 = reteach the missed lessons before Session 16 (see
teacher-guide).
