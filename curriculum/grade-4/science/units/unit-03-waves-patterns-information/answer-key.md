# Answer Key — Unit 03: Waves, Patterns, and Information

**Adult only.** Every item below was solved independently from the
student materials and reconciled with them. Where a learner's answer
differs but is supported by the unit's evidence (a different everyday
example, a different four-message code), accept it and note the
reasoning.

## Lesson 01 — guided practice

1. The cork bobs up and down in about the same place as each ripple
   passes; it does not sail across.
2. Tall wave with close crests labeled amplitude (height); low wave
   with far-apart crests labeled wavelength (crest-to-crest spacing).
   Accept any correctly labeled pair.
3. Bigger shakes made the bigger amplitude — the rope rose higher
   and fell lower. Evidence: the height of the rope's peaks.
4. Crest = a top; trough = a bottom; wavelength = the distance from
   one crest to the next crest on the wire model.
5. The friend is wrong: the tray test shows the cork bobbing in place
   (marked-start test confirms it ends close to its mark). Waves move
   objects up and down; they do not carry them across.

## Lesson 01 — independent practice

1. Drawing with ≥3 crests; labels correct: crest (top), trough
   (bottom), amplitude (middle-to-crest height), wavelength
   (crest-to-crest distance).
2. Wave X has the bigger amplitude (it is taller). Wave Y has the
   longer wavelength (its crests are farther apart).
3. Example: "A wave is a repeating pattern that carries energy from
   place to place." / "The cork bobbed up and down in place instead
   of traveling across the tray." Accept any accurate pair.
4. Accept any honest example: water ripples, a shaken rope, a flag
   rippling, sound from a speaker, light flashing. The adult checks
   the example is a repeating pattern.

## Lesson 01 — applied task

Cork ends close to its rim mark after three pebble drops. Claim:
"The waves bobbed the cork in place; they did not carry it across
the tray." If a cork drifts slightly, the claim still holds — drift
of a centimeter or two from splashing is not "carried across."

## Lesson 02 — guided practice

1. The throat buzzes/vibrates; humming a higher note, the buzzing
   feels faster; a lower note feels slower.
2. Firm hits are louder. Cause: the bigger vibration from the harder
   hit.
3. The same band loose → low sound; tight → high sound. Fair: only
   tightness changed (same band). Cause: the tighter band vibrates
   back and forth faster.
4. Tight string: the message is clearer (the pattern travels along a
   taut string; a slack string does not carry the pushes well).
   Accept "clearer when tight, muffled/lost when slack" with that
   reasoning.
5. Whisper vs. shout = louder/softer. Baby's voice vs. deep grown-up
   voice = higher/lower. Drum gentle vs. hard = louder/softer.

## Lesson 02 — independent practice

1. Accept any two real sounds with correct loud/soft and high/low
   labels (for example, a siren: loud and high; a refrigerator hum:
   soft and low).
2. Volume changes (harder pluck = louder); pitch stays about the
   same, because the same string at the same tightness vibrates at
   about the same speed.
3. Pitch rises as the band gets tighter (faster vibration). Loosening
   it lowers the pitch again.
4. Example: "A drum hit makes a big vibration you can feel, so it is
   loud; a whistle makes a fast, small vibration, so it is high and
   not necessarily loud. Loudness is size of vibration; pitch is
   speed of vibration." Accept any accurate version using all three
   required words.
5. The friend confuses the two words. Example: a big drum struck hard
   is loud AND low — loud does not mean high. A quiet whistle is
   soft AND high — soft does not mean low.

## Lesson 02 — applied task

Two-sound instrument plays low–high–low–high. After tightening one
band, that band's sound rises in pitch; the other band is unchanged.
The second test is fair for tightness only if the same band was
compared loose vs. tight and pluck strength stayed similar; if
thickness also changed, it is not fair. Accept the learner's
recorded result with that judgment.

## Lesson 03 — guided practice

1. Chain in order: light source (lamp) → object (book) → eye, with
   arrows lamp → book → eye.
2. Sealed box: nothing/black. Flap open: the toy appears. What
   changed: light entered. Proof: light reaching the eye is what
   allows seeing; the toy, peephole, and eye were unchanged.
3. Prediction: tilting the mirror the other way moves the spot the
   opposite way. Result: the spot jumps to a new place — reflected
   light keeps traveling in a new direction.
4. Light source = sunlight. Object = red ball. End point = the eye
   (light reflected from the ball enters the eye).
5. The friend is wrong: if eyes sent out light, the learner would see
   the toy in the sealed dark box. They see nothing, so seeing
   depends on light coming *into* the eye.

## Lesson 03 — independent practice

1. Model: sun → cat → eye, arrows in that order, all three labeled.
2. The lamp was the light source (link 1). With it gone, no light
   reflects off the chair (link 2 fails), so no light enters the eye
   (link 3 fails) — the chair cannot be seen even though it is
   still there.
3. Arrows: flashlight → mirror → wall. The light does not stop at
   the mirror; it reflects (bounces) and keeps traveling to the wall.
4. Light source: lamp only. Mirror: not a source — it reflects light
   made elsewhere. Moon: not a source — it reflects sunlight. Book:
   not a source — it reflects light so we can see it.
5. Better explanation: "The toy did not disappear. With the box
   sealed, no light reaches the toy, so no light can reflect off it
   into my eye — and without reflected light entering my eye, I
   cannot see it."

## Lesson 03 — applied task

Mirror: bright spot elsewhere (strong, clear reflection). White
paper: soft glow, no sharp spot (light scattered in many
directions). Dark cloth: almost nothing (little reflection). Best
for a light signal: the mirror, because its reflection stays a
clear, directable beam.

## Lesson 05 — applied task

Mini-comparison totals are out of 8 per solution (2 trials × 4
messages). The recommendation must name the higher total and the
numbers (for example, "drum 7 of 8 beats flashlight 5 of 8, so we
recommend the drum code"). If totals tie, the recommendation must
say so and use the time criterion or call for a third trial — a
tie claimed as a win is marked wrong.

## Unit assessment

1. Drawing with ≥3 crests; labels correct (crest = top, trough =
   bottom, amplitude = middle-to-crest height, wavelength =
   crest-to-crest distance). Judge labels, not art.
2. (a) Wave A has the bigger amplitude (it is tall). (b) Wave B has
   the longer wavelength (crests far apart). (c) Wave A would bob
   the cork higher, because its bigger amplitude means bigger
   up-and-down motion.
3. Wrong: the tray test shows the cork bobbing up and down in place,
   ending close to its starting mark. Waves move objects; they do
   not carry them across. The pattern travels, the cork stays.
4. Drum soft → hard: volume increases (bigger vibration); pitch
   about the same. Band loose → tight: pitch increases (faster
   vibration); volume about the same at similar pluck strength.
5. Model: sunlight (sun) → red ball → person's eye, arrows in that
   order. Cloud blocking the sun: the light source is cut off, so no
   light reflects off the ball into the eye — the ball cannot be
   seen (or is seen only dimly by remaining light; accept either if
   the chain reasoning is stated).
6. The light reflected off the mirror and kept traveling to the wall,
   then to the ceiling when the mirror tilted. Reflection redirects
   light; it does not stop it.
7. Missing link: light reaching the object and reflecting into the
   eye. With the box sealed, no light source reaches the toy, so no
   light reflects off it into the eye — nothing to see, though the

9. Letter T grid:
   Row 1: 1 1 1 1 1; Row 2: 0 0 1 0 0; Row 3: 0 0 1 0 0;
   Row 4: 0 0 1 0 0. Changing one number in row 1 breaks the top
   bar, so the picture — and therefore the message — changes.

## Project scoring

Apply the project rubric (project.md): fair plan, honest data,
comparison, recommendation and limitation. Totals are out of 12 per
solution (3 trials × 4 messages). A recommendation is "supported"
only if it names the higher total; a tie must be reported as a tie
(or broken by the time criterion with that reasoning stated).
Disqualified trials must be marked, not erased; a solution with
repeated constraint breaks cannot be recommended even with a higher
score. Score bands: 10–12 strong, 7–9 developing, 4–6 starting.
