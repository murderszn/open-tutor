# Unit 01 — Evidence, Measurement, and Scientific Models

**Grade:** 4 · **Subject:** Science · **Track issue:** [#23](https://github.com/murderszn/open-tutor/issues/23)
**Status:** draft — awaiting educator review and merge. **Weeks:** 3–6 of the 36-week track (see [scope-and-sequence](../../scope-and-sequence.md)).
**Session model:** 4 sessions per week, about 35 minutes each (16 sessions total).

## What this unit is about

This unit teaches the *practices* that power the rest of the year: how to ask a
question that can be answered by observing or measuring, how to measure length,
mass, and volume with standard tools (and convert within a measurement system),
how to run a **fair test** (change one thing, keep the rest the same, repeat
trials), and how to show data in tables, two-column conversion tables, bar
graphs, pictographs, and line plots so a claim can be trusted. Along the way
the learner builds their first **models** — labeled diagrams of what they
observed — and meets the vocabulary (amplitude, wavelength) that Unit 03's wave
work will reuse. The unit closes with a fair-test investigation of paper-towel
absorbency written up in the unit's investigation-report format — the same
report format the year's later investigations will use.

This unit also carries the grade-4 **math measurement connection** from the
scope-and-sequence: unit conversion within one system (4.MD.1 — km/m/cm, kg/g,
L/mL), two-column tables, and line plots (4.MD.2). Measurement conversions
here are mathematical practice in a science context, not a separate math
lesson; the grade-4 math track (#22) teaches the operations, this unit puts
them to work on real measurements.

## Prerequisites (from grade-3 science; re-taught here as needed)

- Asking questions that can be explored by observing or testing.
- Planning simple fair investigations (one variable changed at a time, repeated
  trials).
- Measuring length to the nearest centimeter with a ruler; recording in
  labeled drawings, tallies, and simple tables.
- Science safety practices: the adult supervises every investigation; materials
  stay away from the mouth; living things are handled gently; never look
  directly at the sun.

The unit's diagnostic-style moments (Lesson 01's tool stations, Lesson 02's
measuring ritual) re-teach these explicitly rather than assuming they are
secure — per the scope-and-sequence, Weeks 1–2 only probed entry points.

## Objectives (measurable, adult-assessed)

By the end of the unit the learner will be able to:

1. Ask a **testable question** and name what would be measured or observed to
   answer it (SEP-1).
2. Measure **length** to the nearest millimeter/centimeter, **mass** to the
   nearest gram, and **volume** to the nearest 10 milliliters with standard
   tools; **convert** within one measurement system (km/m/cm, kg/g, L/mL);
   record equivalents in **two-column tables** (4.MD.1; science practice of
   careful measurement).
3. Plan and carry out a **fair investigation**: change one thing (the
   *variable*), keep everything else the same (*controls*), repeat at least
   three **trials**, and record data in a labeled table (3-5-ETS1-3;
   SEP-3). The fair-test routine introduced here is the one Units 02, 07,
   and 08 reuse.
4. Build and read **bar graphs**, **pictographs**, and **line plots** from
   collected data; answer "how many more," comparison, and simple trend
   questions (SEP-4; 4.MD.2).
5. Use evidence to **define a simple design problem** with criteria and
   constraints (3-5-ETS1-1), name a **model** as a representation that helps
   explain something, and write a complete **investigation report** in the
   unit's format.

## Essential question

*How do careful questions, careful measurements, and honest data displays help
us trust what a test found?*

## Vocabulary

**Testable question** — a question answerable by observing, measuring, or
testing. · **Observation** — something noticed with the senses or a tool. ·
**Measure** — find out how long, how heavy, or how much with a tool. ·
**Millimeter / centimeter / meter / kilometer** — metric length units;
10 mm = 1 cm, 100 cm = 1 m, 1,000 m = 1 km. · **Gram / kilogram** — metric
mass units; 1,000 g = 1 kg. · **Milliliter / liter** — metric volume units;
1,000 mL = 1 L. · **Convert** — rewrite a measurement in a different unit of
the same system. · **Estimate** — a careful guess *before* measuring. ·
**Trial** — one try of a test; scientists repeat trials to see patterns. ·
**Data** — recorded measurements and observations. · **Fair test** — a test
that changes only one thing while everything else stays the same. ·
**Variable** — the one thing changed. · **Control** — a thing kept the same
on purpose. · **Table** — rows and columns that hold data. · **Two-column
table** — a table that pairs equivalent measurements (unit-conversion
record). · **Bar graph / pictograph / line plot** — displays of data. ·
**Trend** — a pattern in how data changes. · **Claim** — what we say is true
because of evidence. · **Evidence** — data used to support a claim. ·
**Model** — a drawing, object, or description that represents and helps
explain something real. · **Criteria** — what a successful solution must do. ·
**Constraints** — limits on materials, time, or cost.

## Standards and source notes

- Reference framework: **Next Generation Science Standards**, grade-4
  performance expectations and the 3–5 engineering band (from the track audit's
  crosswalk, verified 2026-10-04 against the California Department of
  Education's official reproduction of the NGSS grade-4 release, "NGSS Grade
  Four Arranged by DCI," revised March 2015, cross-checked with
  nextgenscience.org). No state adoption, accreditation, or alignment
  certification is claimed.
- **3-5-ETS1-3** — *Plan and carry out fair tests in which variables are
  controlled and failure points are considered to identify aspects of a model
  or prototype that can be improved.* This unit introduces the fair-test
  routine and the "name the failure point" habit; Unit 08 runs the full
  cycle.
- **3-5-ETS1-1** — *Define a simple design problem reflecting a need or a
  want that includes specified criteria for success and constraints on
  materials, time, or cost.* Introduced in Lesson 05; later units reuse the
  criteria-and-constraints language.
- **4.MD.1** — *Know relative sizes of measurement units within one system
  of units* (km, m, cm; kg, g; L, mL). Covered mathematically in the grade-4
  math track; this unit applies the conversions to real science measurements.
- **4.MD.2** — *Use the four operations to solve word problems involving
  distances, intervals of time, liquid volumes, masses of objects, and money
  … Represent measurement quantities using diagrams such as number line
  diagrams that feature a measurement scale.* This unit's two-column tables,
  line plots of repeated measurements, and conversion word problems are the
  science-side practice of these ideas.
- Science and engineering practices: **SEP-1** (asking questions), **SEP-2**
  (developing and using models — labeled diagrams of observations),
  **SEP-3** (planning and carrying out investigations), **SEP-4** (analyzing
  and interpreting data). Crosscutting concepts: **patterns** (repeated
  trials; graphs reveal patterns), **cause and effect** (the changed variable
  causes the measured change — tested, not assumed), **scale, proportion, and
  quantity** (choosing the right-sized unit to measure with).

## Materials (for the whole unit)

Hand lens; metric ruler with centimeter/millimeter markings; a simple balance
or kitchen scale (grams); graduated cylinder or marked measuring cup
(milliliters); paper towels (three brands or types); measuring cup or spoon
for water; toy car, book ramp, two cloths (for the Lesson 03 demo); science
journal; pencils and colored pencils; index cards for the "question sort" and
"step cards." **Adult reads the safety rules aloud before each investigation:**
tool-tray rules (tools back in the tray after use), non-mercury thermometer
readings are adult-handled only, nothing near the mouth, water kept away from
outlets, spills wiped at once. All investigations are adult-supervised.

Session type rotation per the scope-and-sequence: investigation lesson →
measuring-and-modeling practice → reading-and-talk about evidence → review
game. Each session names its activity and success criterion.

| 3 | 3 | Reading-and-talk | Read-aloud: "How scientists ask" (original passage in teacher-guide); talk: what counts as evidence? | Learner gives one example of evidence and one of non-evidence |

| 5 | 4 | Investigation lesson | Lesson 02: the measuring ritual; measuring challenge | Every measurement starts at 0, unit recorded |
| 6 | 4 | Measuring/modeling practice | Lesson 03: fair-test routine; paper-towel project question framed | Fair plan names one variable, ≥2 controls, 3 trials |
| 7 | 4 | Reading-and-talk | Read-aloud: "One change, or nothing learned" (original passage); error-analysis of unfair tests | Learner finds both extra changes in a two-change test |
| 8 | 4 | Review game | Practice set B (fair-test judge items); step-card race | ≥80% of judge items correct |
| 9 | 5 | Investigation lesson | Lesson 04: build bar graph, pictograph, line plot from own measurement data | Each display labeled with title, labels, units |
| 10 | 5 | Measuring/modeling practice | Practice set C (graphs) + start project data collection | Project table has ≥3 trials per brand, all in mL |
| 11 | 5 | Reading-and-talk | Lesson 05: define a design problem with criteria and constraints; investigation-report format | Report skeleton filled for the paper-towel test |
| 12 | 5 | Review game | Practice set D (conversions, two-column tables) | Conversion table rows all equivalent and correct |
| 13 | 6 | Investigation lesson | Project investigation: run trials, finish data display, draft report | Completed fair test + labeled bar graph |
| 14 | 6 | Review | Measurement challenge stations + fair-test redesign game (Practice set E) | Stations scored; redesign fixes all extra changes |

| 16 | 6 | Assessment/review | Unit assessment + report polish | Assessment and investigation report complete |
