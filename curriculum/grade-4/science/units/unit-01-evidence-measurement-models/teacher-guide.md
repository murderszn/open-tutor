# Teacher Guide — Unit 01: Evidence, Measurement, and Scientific Models

Adult-facing. The learner never needs this file; student pages link to it
with clear labeling. All investigations are adult-supervised.

## Pacing at a glance

16 sessions, ~35 minutes each, Weeks 3–6. Session rotation: investigation
lesson → measuring/modeling practice → reading-and-talk → review game (see
the full session table in [README.md](README.md)). If a session runs long,
carry the unfinished practice into the next practice session rather than
cutting the investigation — the hands-on work is the curriculum.

## Readiness evidence and reteach triggers

The learner is ready for **Unit 02** when they can:

- plan a fair test naming one variable, ≥2 controls, and 3 trials
  (Lesson 03 / project plan);
- measure length, mass, and volume with the correct tool and unit, and
  convert within one system (Lesson 02 / Practice Set B);
- support a claim with two data values and name one limitation
  (Lesson 04–05 / project report).

**Reteach triggers:** if the week-06 quiz scores ≤6, reteach Lessons 02 and
03 with the step cards and the measurement picture before Session 16; if
the learner cannot name the six report parts, redo Lesson 05's skeleton
orally before the unit assessment. Targeted follow-up: the missed
objective's practice set (A–E), one set per session, adult-reviewed the
same day.

## Misconceptions to watch (by lesson)

- **L1:** testable = "has an answer." Re-anchor: testable means answerable
  by *observing or measuring* ("blue is best" has an answer and is still
  untestable).
- **L2:** bigger number = bigger amount ("2,000 g > 2 kg"). Re-anchor with
  the two-column table: same thing, smaller unit, bigger number.
- **L3:** "fair" = "nice/equal turns." Re-anchor: fair = one change.
  Watch learners who name a control and change it mid-test.
- **L4:** the tallest bar "proves" the winner forever. Re-anchor: data
  supports a claim *for this test*; also insist on units on every axis.
- **L5:** criteria = constraints. Re-anchor: criteria = what success does
  (measurable); constraints = limits (materials, time, cost). Push
  unmeasurable criteria ("works well") toward a number or an observable.

## Differentiation

- **Supports:** sentence frames are in every lesson; the adult may scribe
  spoken answers; oral, drawn, and manipulative responses always count;
  keep the conversion ladder card and fair-test step cards visible.
- **Extensions:** each lesson has one; the strongest is Lesson 05's Unit 03
  pre-seed (design a no-talking message system with criteria and
  constraints).
- **Reading/language access:** read every lesson aloud; vocabulary is
  defined in context first, then collected in the unit glossary
  ([README.md](README.md#vocabulary)).

## Original read-aloud passages

Two short original passages written for this unit's reading-and-talk
sessions (Sessions 3 and 7). Read aloud by the adult; the learner is never
tested on the text itself — only on the ideas.

**Session 3 — "How scientists ask" (original, ~120 words):**

> Scientists ask questions the way detectives look for clues. A detective
> does not ask, "Was it a nice crime?" — there is no way to measure "nice."
> A detective asks, "What time did the lights go out?" — and then looks for
> a clock. Scientists do the same. They ask questions that hide a
> measurement inside: how tall, how heavy, how much, how many, how long.
> Then they pick the tool that can find it. A question you can answer by
> looking, measuring, or testing is called testable. The measurement hiding
> inside the question is the beginning of the test.

**Session 7 — "One change, or nothing learned" (original, ~130 words):**

> Imagine you bake two cakes. In one you use sugar; in the other you use
> salt — and you also bake the second one hotter, in a bigger pan, for less
> time. You taste them. One is awful. Which change made it awful? You cannot
> know. You changed four things. Scientists call a test like that unfair —
> not because it was mean, but because it taught nothing. A fair test
> changes exactly one thing and keeps everything else the same. Then,
> whatever is different in the result must come from the one thing you
> changed. One change, everything else the same, and try it more than once.
> That is the whole rule. It fits on an index card, and it powers every
> investigation in this year's science.

## Safety checklist (read aloud before each investigation)

- Tools back in the tool tray after use.
- Nothing near the mouth; hands washed after soil or plant work (later
  units).
- The adult handles pouring beyond the learner's safe reach; spills wiped
  at once; water kept away from outlets.
- Non-mercury thermometer readings are adult-handled (this unit does not
  use thermometers; later units may).
