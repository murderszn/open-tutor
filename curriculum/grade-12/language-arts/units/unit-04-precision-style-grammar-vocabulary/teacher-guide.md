# Teacher Guide — Unit 04: Precision Style: Grammar and Vocabulary Refinement

**For the guiding adult only.** Do not place this file beside
student materials; the answer key (`answer-key.md`) is a
separate file. This guide covers pacing, misconceptions,
discussion moves, and reteaching. All lesson sentences are
original, written for this unit; reference claims were checked
2026-11-03 (see the resource pack).

## Pacing and workload

- The 20-session plan assumes ~50-minute sessions, five per
  week. If sessions run 30 minutes, split each lesson across
  two sessions and move the workshops as marked; do not cut
  the portfolio studios (sessions 12–13, 17–18) — the revised
  passages and style sheet are the unit's primary summative
  evidence, alongside the unit assessment.
- The usage workshop (sessions 2–3) is the unit's hinge. Do
  not rush it: learners who can run the four-step test slowly
  will use it for the rest of the year; learners who memorize
  verdicts ("less is wrong") will misapply them for the rest
  of the year.
- The peer style-check (session 14) needs the portfolios
  drafted by session 13; never run it on first drafts written
  the same day — a checker cannot verify claims in work the
  writer has not yet thought through.
- Check at least one usage reference per portfolio passage
  yourself before session 20. The most common portfolio
  failure is a confident reference claim the reference does
  not actually support (usually a dictionary definition
  quoted for a usage question it does not answer).

## Misconceptions by lesson (and the redirect)

**Lesson 01.** *"The dictionary says it, so it is right for
every audience."* Redirect to step 3 of the test: a dictionary
describes usage; a house style or formal audience can still
require the stricter form, and the learner's job is to choose
knowingly. *"Contested means anything goes."* Redirect: a
contest means the choice must be defended, not that it needs
no defense — the case card is the defense.

**Lesson 02.** *"Varied = better, so every sentence must
differ from its neighbors."* Redirect: variation serves
emphasis and clarity; a methods paragraph may rightly run
several loose sentences in a row. Assess deliberate choice
with a stated effect, not maximum variety. *"Passive voice is
an error."* Redirect: passive is a choice with legitimate
uses (unknown/irrelevant actor, object as topic); assess the
justification, not the form alone.

**Lesson 03.** *"Shorter is always better."* Redirect to
Lesson 03, Worked example 2: a repair that loses a true claim
is a worse sentence, however short. *"Every noun from a verb
must go."* Redirect: concepts that will be discussed for a
page deserve names; the test is whether the noun names a
concept or hides an action.

**Lesson 04.** *"Knowing the root means knowing the word."*
Redirect to Lesson 04, Worked example 2: roots open the
family; context and the dictionary fix the shade.
*"A thesaurus synonym is interchangeable."* Redirect: the
original sentence is the test — a synonym fitting one sense
often fails in another.

**Lesson 05.** *"A revision note is extra work on top of
revising."* Redirect: the note is the revision's evidence,
and it is what lets a peer checker verify the work instead of
trusting it. *"Step 1 can be skipped when the paragraph is
already good."* Redirect: step 1 is how you know it is good;
a polished paragraph with no claim is the unit's most
expensive failure.

## Discussion and conferencing moves

- **Usage conferences:** ask for the reference before the
  verdict. "Show me the note" beats "what do you think?" every
  time. If the learner cannot name the reference, the case
  card is incomplete, whatever the choice.
- **Syntax conferences:** ask the learner to read the
  paragraph aloud, then ask: "Where did your voice naturally
  pause, and where did it rush?" The ear finds monotony the
  eye misses. Then ask: "Which sentence should the reader
  remember, and is it last?"
- **Vocabulary conferences:** ask for the original sentence
  first, not the definition. A correct definition with a
  broken sentence is recognition, not learning.
- **Portfolio conferences:** ask for the weakest revision
  first, not the best. "Which move are you least sure about?"
  is the fastest route to the reteaching that matters.

## Reteaching

- **Usage confusion persists:** return to two cases only —
  less/fewer and singular they — and run the full test aloud
  together, with the dictionary open. Do not add new cases
  until those two are solid.
- **Syntax monotony persists:** use the sentence-strip
  activity (Lesson 02) physically, not on screen. Cutting and
  reordering makes structure visible in a way highlighting
  does not.
- **Nominalization persists:** take one paragraph and rewrite
  it with every action as a verb, even where the result is
  ugly; then restore only the nouns that name genuine
  concepts. The ugly version teaches the test.
- **Vocabulary inference without verification persists:**
  require the dictionary step in writing (entry named, meaning
  paraphrased) for five words before any new inferencing.
  Verification is a habit, and habits form by repetition, not
  by exhortation.

## Scoring notes

- **Formative quiz (50 points):** Part A 4 points each (1 for
  the mark, 3 for the choice with reason); Part B 6 points
  each (shape/fault identification plus a correct revision);
  Part C 4 points each (clue/parts, meaning, original
  sentence — the dictionary note is required for full marks).
  Accept any correct revision or sentence, not only the key's.
- **Unit assessment (100 points):** Part A 5 points each
  (full case card); Part B 20 points (5 for length variation,
  5 for the labeled periodic sentence and parallel structure,
  5 for fault repair, 5 for the revision note); Part C 5
  points each; Part D 30 points (10 for each example pair with
  explanation, 10 for the general principle stated with unit
  vocabulary). Passing is 70/100 with no part below half
  marks; reteach and resubmit the weakest part only.
- **Portfolio (40 points):** score by the project rubric, not
  by impression. A portfolio with a lost true claim in a
  revised passage cannot score in the top band for that
  criterion, however polished the prose reads.
