# Teacher Guide — Unit 03: Rhetorical Analysis and Media Criticism

This guide is for the guiding adult. It is separate from all student
questions; do not hand it to the learner as a worksheet. Answers to
student items are in `answer-key.md`.

## Pacing help

- **Sessions 1–2 (Lesson 01):** spend Session 2 mostly on the image
  task. Learners who rush the image task usually invent a topic for
  the screens; stop and re-read the caption: the screens carry no
  words, so the topic is *not* in the image. That restraint is the
  point.
- **Sessions 3–4 (Lesson 02):** the paired examples (Speech A vs. the
  administrative version) do the teaching. Do not summarise them for
  the learner; ask, "What disappeared between the two versions?"
- **Sessions 6–7 (Lesson 03):** the cover-the-claim warrant test is
  the single most transferable move in the unit. Model it aloud once
  on a learner's own sentence before assigning the mapping task.
- **Sessions 8–9 (Lesson 04):** insist on the repair step, not only
  the label. A learner who can label six fallacies but cannot repair
  one has learned vocabulary, not reasoning.
- **Sessions 11–12 (Lesson 05):** the SIFT lab works best on a source
  the adult has already checked. Never send a learner to an unchecked
  live post as the first SIFT exercise.
- **Sessions 14–16 (Lesson 06 + seminar):** protect the seminar
  norms. If one voice dominates, the leader's job — not the adult's
  lecture — is to invite the missing objection. Debrief the leader's
  moves, not only the positions taken.
- **Session 18 (quiz):** review missed items the same day, while the
  reasoning is still fresh. A quiz score without same-day review
  teaches nothing in this unit.
- **Session 19–20 (assessment + revision):** revision in Session 20
  should target one response only, chosen by the learner, and
  rewritten with the key's reasoning in view — not a wholesale
  re-do.

## Misconceptions and reteaching moves

| Misconception | Reteaching move |
|---|---|
| "Persuasive = true" | Return to Speech A (Lesson 02): persuasive, vivid, and incomplete (no cost figure). Ask: "What would you still need to know before voting?" |
| "A fallacy means the conclusion is false" | Use Lesson 04 §1, caution 1, with a true conclusion argued fallaciously (e.g., "the library is popular because I love it"). The conclusion may be true; this reasoning does not show it. |
| "Bias means lying" | Use Lesson 05 items A vs. B: both use the same count 242; neither invents a fact; B omits the roof. Selection and emphasis mislead without invention. |
| "More sources = more truth" | Use Lesson 05: B repeats A's figure, so A + B is one count, not two confirmations. Ask: "Did this source do its own checking?" |
| "Style = pretty language" | Use the Lesson 02 pair: same count, different power. Ask what disappeared (people, verbs, agency) when the style flattened. |
| "Fairness means agreeing with both sides" | Lesson 06: fairness is stating the opposition's best version accurately, then answering it. Agreement is not required and is not scored. |
| "Evidence = any number" | Lesson 03: a true number can be weak evidence if its warrant fails (annual total for evening demand). Ask: "What would this number need to prove *this* claim?" |

## Discussion moves

- "Quote it before you judge it." No claim about a text without a
  quotation in the same turn.
- "For whom?" After every appeal label, ask which audience it should
  work on, and which audience it would leave cold.
- "What is missing?" After every summary, ask what the text omitted
  and whether the omission matters to the decision.
- "What would change your mind?" End seminar turns with this
  question; it turns positions into testable claims.

## Readiness, reteach, and follow-up

- **Ready for U04** if the learner can: map claim/evidence/warrant/
  counterclaim in a new paragraph; diagnose and repair one fallacy;
  and integrate two formats with a named discrepancy. These are the
  assessment's Tasks 2 and 4, and the project rubric's argument and
  integration criteria.
- **Reteach Lesson 03–04** if the assessment's Task 2 scores below 6
  of 10: rework the learner's own evidence map (project, Session 15)
  as the worked example, one part at a time.
- **Reteach Lesson 05** if Task 4 scores below 6 of 10: run a second
  SIFT lab on an adult-supplied source, with the adult modelling the
  "Find better coverage" move aloud.
- **Follow-up into U04:** this unit's style analysis (Lesson 02) is
  the entry skill for U04's precision-style revision work; keep the
  learner's Task 3 response in private storage as the U04 starting
  point. Do not file learner work in the repository.
