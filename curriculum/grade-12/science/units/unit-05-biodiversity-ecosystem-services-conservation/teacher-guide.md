# Teacher Guide — Unit 05: Biodiversity, Ecosystem Services, and Conservation

**Adult-facing. Keep from the learner.** This guide covers pacing,
common misconceptions, reteaching moves, and differentiation. All
worked solutions are in the separate adult-only `answer-key.md`.

## How to use this guide

- Sessions run about 50 minutes, five per week, Weeks 19–22.
  The pacing table in the unit README is the plan; this guide
  explains what to watch for in each session.
- Preview every external link before the learner opens it
  (advertising, comments, reading level). All video
  recommendations are labeled search links: run them, watch
  them, and reject any that fail the criteria in the resource
  pack.
- Score practice sets same-day and return errors with the
  reasoning, not just the corrected number. A wrong H′ with the
  method right is a calculator slip; a right H′ with no
  interpretation is a bigger gap.
- The project is a proposal, not a permission slip. Nothing is
  built, planted, or removed. You approve every procedure before
  field work begins.

## Lesson 01 — What biodiversity measures (S1–S2)

**Watch for:** learners treating H′ as a grade ("1.47 is good").
Ask "good for what?" — the index compares communities; it does
not judge them. Also watch for learners comparing H′ values
across different sampling methods; the effort warning is the
point of the lesson.
**Reteach:** if logarithms block the work, do one full
calculation together on the board with the ln table, then hand
the arithmetic to the spreadsheet and keep the learner on
interpretation.
**Differentiation:** oral/pointing answers accepted for the image
activity; the adult scribes the organism list. Extension learners
take the 60/30/10 case (Lesson 01 § Extension) and then invent
their own 3-species sample to test.
**Readiness check:** the ecosystem definition (living + nonliving,
interacting) must be solid before the three levels are introduced.

## Lesson 02 — How biodiversity changes (S6–S7)

**Watch for:** the proportional-area error ("half the area, half
the species") — the power law is the correction, and the worked
halving example is the moment to catch it. Also watch the
Yellowstone story hardening into a slogan; the debate about
willow recovery is itself evidence teaching.
**Reteach:** if "fourth root" confuses, use the SVG curve
(`assets/species-area-curve.svg`) instead of the formula: read
points off the curve, then check one point against the formula.
**Film session (S7):** preview the HHMI film; if it is
unavailable, use the worked-data alternative (Paine's 15 → 8
species, Estes's otter–urchin–kelp chain) from the lesson text.
**Differentiation:** the cascade chain may be drawn as arrows
instead of written. Extension learners do the log–log plot.

## Lesson 03 — Ecosystem services (S11)

**Watch for:** double-counting — learners adding a supporting
service to the total it already supports. Insist every valuation
ends with "and this leaves out…". Also watch for learners valuing
the whole crop as pollination's contribution; only the yield
difference belongs to the pollinators.
**Reteach:** if the four categories blur, use the one-line tests
(harvest = provisioning; keeps conditions steady = regulating;
experience = cultural; underneath everything = supporting) and
sort service cards into four piles.
**Differentiation:** classification by card sort instead of
writing; the adult keeps the category list visible throughout.

## Lesson 04 — Threats to biodiversity (S12)

**Watch for:** the "73% of wildlife is gone" misreading — slow
down on Example 1 and require the learner to say what the number
is an average *of* before moving on. Also the Data Deficient
misreading ("not enough data" = "probably fine"); it usually
means the opposite risk.
**Reteach:** if the five drivers blur, sort the learner's own
examples into the five named drivers before attempting the
ranking task. A ranking is only as good as its place evidence —
pull discussion back to the fictional place whenever it drifts
into global generalities.
**Differentiation:** ranking by ordering five labeled cards
instead of writing.

## Lesson 05 — Conservation design (S16)

**Watch for:** matrix scores that are all 3s — the criteria are
not biting. Ask which option is *worst* on each criterion and
make the learner defend one low score aloud. Also watch designs
that sprawl ("protect everything"); pull back to one driver, one
tool, one refinement.
**Reteach:** if the "do nothing" option confuses, score it
together (total 9) and ask why cost and feasibility scores do
not save it — the weighted biodiversity criterion is the answer.
**Differentiation:** scoring with numbered tokens on a printed
table instead of writing.

## Project — A Conservation Plan for One Local Green Space (S14–S19)

- **S14 planning:** approve the plan in writing before any field
  work. Check the site's rules (some parks forbid off-path
  walking). Confirm the public-data alternative if the site,
  weather, or supervision is inadequate.
- **S15 survey:** go with the learner. Check the data table has
  units and effort recorded *during* the survey, not
  reconstructed later. Unknown organisms are described, not
  guessed at.
- **S17 analysis:** check the Shannon calculation against the
  survey table (the common error is using the number of *types*
  as the total N). Check the species–area prediction uses the
  halved area, and that the valuation names its method and its
  omissions.
- **S19 write-up:** use the rubric in `project.md`. A narrow
  design done well outscores a broad design asserted. "Cost not
  estimated," stated honestly, outscores an invented precise cost.
- **Privacy:** the plan stays in private storage. Site photos
  stay private. No learner names, schedules, or locations go in
  the repository.

## Quiz (S18) and unit assessment (S20)

- **Quiz (40 pts):** formative — use it to find gaps, not to
  grade the unit. If Part A scores are low, re-teach the Shannon
  calculation with the spreadsheet before S19. If Part C scores
  are low, re-run Lesson 04's Example 1 aloud.
- **Unit assessment (50 pts):** culminating. Score with the
  answer key; for open responses, accept any answer that names
  the required evidence and reasoning (sample answers are in the
  key). Record objective mastery per learner in private storage.
- **Reteaching triggers:** H′ errors → Lesson 01 worked examples
  with the spreadsheet; species–area errors → the SVG curve
  before the formula; 73%/1-million misstatements → Lesson 04
  Example 1; matrix scores without evidence → Lesson 05
  Example 1, scored together aloud.
