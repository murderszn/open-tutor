# Answer Key — Unit 03 (Adults Only)

Worked solutions for every scored item: lesson exercises, Practice
Sets A–G, the project (key numbers and rubric guidance), the Week 14
quiz, and the culminating assessment. Directions are in standard
position unless a bearing is stated. Exact answers are given where
exact values exist; approximations are rounded to two decimal places
unless noted.

## Lesson 01

**Guided.** 1. `|v| = √(36 + 64) = 10`; direction `arctan(8/6) ≈ 53.13°`
(Quadrant I); unit vector `<3/5, 4/5>`. 2. Components
`<2 − (−2), 6 − 3> = <4, 3>`; magnitude 5. Yes, it is the same vector
as `<4, 3>`: same components, so same magnitude and direction,
regardless of starting point. 3. `10 cos 210° = −5√3 ≈ −8.66`,
`10 sin 210° = −5`, so `<−5√3, −5>`; Quadrant III (both components
negative) — known before computing, from the angle 210°.

**Independent.** 1. `<5, −12>`: magnitude 13; reference angle
`arctan(12/5) ≈ 67.38°`, Quadrant IV, so direction ≈ 292.62° (or
−67.38°). `<−8, −15>`: magnitude 17; reference angle
`arctan(15/8) ≈ 61.93°`, Quadrant III, so direction ≈ 241.93°.
2. `26 cos 135° = −13√2 ≈ −18.38`, `26 sin 135° = 13√2 ≈ 18.38`:
`<−13√2, 13√2>` N. 3. Both displacements have components `<3, 4>`
(the second: `<5 − 2, 5 − 1> = <3, 4>`), so they are the same vector;
they would differ if either component differed — that is, if the
distance or the direction changed. 4. Error: the classmate used the
calculator's arctangent as the angle. `<−3, 4>` is in Quadrant II
(negative x, positive y); reference angle `arctan(4/3) ≈ 53.13°`, so
the direction is `180° − 53.13° = 126.87°`. Rule: write the quadrant
before the angle.

**Application.** Legs `<5, 0>` and `<0, 12>`; displacement `<5, 12>`;
magnitude 13 km; direction `arctan(12/5) ≈ 67.38°` from east (or
22.62° east of north). Distance walked is 17 km because it adds the
legs' lengths; displacement magnitude is the straight-line distance
from start to finish, 13 km — magnitudes do not add unless the
vectors point the same way.

**Exit check.** `|v| = √(81 + 144) = 15`; reference angle
`arctan(12/9) ≈ 53.13°`, Quadrant II, so direction ≈ 126.87°;
unit vector `<−3/5, 4/5>`; `v = 15 · <−3/5, 4/5>`.

## Lesson 02

**Image activity.** 1. The curved arrows represent the current
pushing the boat; reversed, the boat would drift the other way (north
instead of south in the numbered version). 2. Velocity over ground
`<8, −6>` knots; speed `√(64 + 36) = 10` knots; direction
`arctan(6/8) ≈ 36.87°` south of east (standard position ≈ 323.13°).
3. To travel due east over ground the boat must steer north of east
so its northward component cancels the 6-knot southward current:
`sin φ = 6/8`, `φ ≈ 48.59°` north of east; eastward speed over ground
`√(64 − 36) = √28 ≈ 5.29` knots. (Note: the boat's speed through
water is 8 knots, so the heading triangle is 6-√28-8, not 6-8-10.)

**Guided.** 1. `u + v = <−1, 3>`; `u − v = <5, −5>`;
`3u + 2v = <6 − 6, −3 + 8> = <0, 5>`; `u · v = 2(−3) + (−1)(4) = −10`.
2. `<1, 0>` vs `<1, 1>`: `cos θ = 1/(1 · √2)`, `θ = 45°`.
`<1, 2>` vs `<2, −1>`: dot product `2 − 2 = 0`, so `θ = 90°`:
orthogonal. 3. Velocity over ground `<−200, −50>` km/h; speed
`√(40000 + 2500) = √42500 ≈ 206.16` km/h; direction
`arctan(50/200) ≈ 14.04°` south of west. For a due-west ground course,
the plane must head north of west by `arcsin(50/200) ≈ 14.48°`, so
its northward airspeed component cancels the southward wind.

**Independent.** 1. Dot product `3(−4) + 4(3) = 0`, so orthogonal.
Also: `|u| = 5`, `|v| = 5`, `|u + v| = |<−1, 7>| = √50 = 5√2`, and
`5² + 5² = (5√2)²`, the Pythagorean check for a right angle between
them. 2. Ground velocity `<1.5, 2>` m/s; speed 2.5 m/s; angle east of
north `arctan(1.5/2) ≈ 36.87°`. (The 1.5-2-2.5 triangle is the 3-4-5
triangle scaled by 0.5 — check the ratio, do not assume it.)
3. Resultant `<10, 10>` N; the canceling force is `<−10, −10>` N,
magnitude `10√2 ≈ 14.14` N, direction 225° (southwest).
4. Error: magnitudes do not add for non-parallel vectors. Actual
resultant `<10, 10>` N, magnitude `10√2 ≈ 14.14` N, not 20 N.
"Add the magnitudes" is wrong in general because the resultant is the
diagonal of the parallelogram, whose length equals the sum of the
magnitudes only when the vectors point the same way.

**Exit check.** Ground velocity `<−4, 9>` km/h; speed
`√(16 + 81) = √97 ≈ 9.85` km/h; direction west of north
`arctan(4/9) ≈ 23.96°`. For a due-north course the boat must steer
east of north by `arcsin(4/9) ≈ 26.39°`.

## Lesson 03

**Guided.** 1. `t = (x − 2)/3`; `y = 1 − 2(x − 2)/3 = (7 − 2x)/3`.
As `t` increases, `x` increases and `y` decreases (slope −2/3,
rightward and downward). Points: `t = 0 → (2, 1)`; `t = 3 → (11, −5)`,
and `(7 − 22)/3 = −5` checks. 2. Same curve (`y = x²`, for `x ≥ 0`
in both cases), different motion: at the same `t`, P is at
`(t, t²)` and Q at `(2t, 4t²)`; Q is ahead on the curve at every
`t > 0`, and moving faster: Q's position at time `t` is P's position
at time `2t`. Same trace, Q twice as fast in parameter time.
3. For `0 ≤ t ≤ 1`: `x(t) = 4t`, `y(t) = 6t`. For `0 ≤ t ≤ 2`:
`x(t) = 2t`, `y(t) = 3t` (same segment, half the parameter speed).
What stays the same: the segment and its direction; what changes:
the speed (position as a function of `t`).

**Independent.** 1. `t = (x + 1)/3`; `y = 2(x + 1)/3 + 5 = (2x + 17)/3`;
as `t` increases, `x` and `y` both increase. 2. Table: `t = 0 → (4, 0)`;
`π/4 → (2√2, 2√2)`; `π/2 → (0, 4)`; `3π/4 → (−2√2, 2√2)`;
`π → (−4, 0)`. Upper semicircle, traveled counterclockwise from
`(4, 0)` to `(−4, 0)`. 3. Landing: `−5t² + 30t = 0` gives `t = 6` s;
distance `15 · 6 = 90` m. Maximum at `t = 3` s:
`y = −45 + 90 = 45` m. Rectangular: `t = x/15`,
`y = −5x²/225 + 2x = −x²/45 + 2x`, `0 ≤ x ≤ 90`. 4. Error: the
reported parabola is the full curve `y² = x`, but with `t ≥ 0` only
the upper half is traced: `y = √x`, `x ≥ 0`. The statement is right
about the equation's shape and wrong about the trace.

**Application (drone).** Start `(0, 8)`; end at `t = 2`: `(12, 4)`;
at `t = 1`: `(6, 7)`. Rectangular: `t = x/6`,
`y = 8 − x²/36`, `0 ≤ x ≤ 12`. Ground (`y = 0`) would need
`x² = 288`, `x ≈ 16.97`, beyond the interval's end (`x = 12`): the
drone does not land during the planned interval; the plan ends at
height 4 m, and landing would occur later if the model continued.

**Exit check.** One correct answer: `x(t) = 3 sin t`,
`y(t) = −3 cos t`; at `t = 0`, `(0, −3)`; small `t > 0` gives
`x > 0`, `y ≈ −3`, i.e. clockwise motion. Rectangular equation:
`x² + y² = 9`. Any equivalent parametrization with the starting
point and direction stated earns full credit.

## Lesson 04

**Guided.** 1. `(4, 5π/6)`: `x = 4 cos 150° = −2√3`,
`y = 4 sin 150° = 2`, so `(−2√3, 2)`. `(−3, π/4)`:
`x = −3(√2/2) = −3√2/2`, `y = −3(√2/2) = −3√2/2`.
2. `(−4, 0)`: `(4, π)`. `(0, −5)`: `(5, 3π/2)` (or `(5, −π/2)`).
3. `r = 3 sin θ` → `x² + y² = 3y` → `x² + (y − 3/2)² = 9/4`:
circle center `(0, 3/2)`, radius `3/2`. 4. Three names for
`(2, π/3)`: e.g. `(2, π/3)`, `(2, 7π/3)`, `(−2, 4π/3)`.

**Independent.** 1. `(2√3, 2)`: `r = √(12 + 4) = 4`;
`tan θ = 2/(2√3) = 1/√3`, Quadrant I, so `θ = π/6`: `(4, π/6)`.
2. `x² + y² = 6y` → `r² = 6r sin θ` → `r = 6 sin θ` (for `r ≠ 0`;
the pole satisfies both forms). 3. `r = 2 sec θ = 2/cos θ` →
`r cos θ = 2` → `x = 2`: vertical line. 4. Error: `(−1, −1)` is in
Quadrant III, not I. Correct: `r = √2`, reference angle π/4, so
`θ = π + π/4 = 5π/4`: `(√2, 5π/4)`. Rule: write the quadrant before
the angle; `tan θ` alone cannot distinguish opposite quadrants.

**Application (radar).** Noon: `(10 cos 30°, 10 sin 30°) = (5√3, 5)`
≈ `(8.66, 5)`. 1 p.m.: `(10 cos 120°, 10 sin 120°) = (−5, 5√3)`
≈ `(−5, 8.66)`. Displacement: `(−5 − 5√3, 5√3 − 5)` ≈
`(−13.66, 3.66)`; distance `√(200) = 10√2 ≈ 14.14` km (the chord of a
90° rotation at radius 10). The distance from the station never
changed because both positions have `r = 10`; polar form shows this
at a glance (`r` constant), while rectangular form hides it in two
changing coordinates.

**Exit check.** `(−2√3, 2)`: `r = 4`, Quadrant II, reference angle
30°, so `θ = 150° = 5π/6`: `(4, 5π/6)`. `r = −4 sin θ` →
`x² + y² = −4y` → `x² + (y + 2)² = 4`: circle center `(0, −2)`,
radius 2.

## Lesson 05

**Guided.** 1. `r = 3 cos θ` → `x² + y² = 3x` →
`(x − 3/2)² + y² = 9/4`: circle center `(3/2, 0)`, radius `3/2`,
through the pole. Polar prediction: zero at `θ = π/2` and `3π/2`
(`cos θ = 0`), maximum `r = 3` at `θ = 0` — consistent.
2. `r = 2 − 2 sin θ`: cardioid (equal coefficients), symmetric
about the line `θ = π/2` (sin form); zero when `sin θ = 1`,
`θ = π/2` (cusp at the pole, pointing north); maximum `r = 4` at
`θ = 3π/2` (bulk to the south). 3. `r = 5 cos(4θ)`: `n = 4`, even,
so `2n = 8` petals, each reaching 5. Table at multiples of `π/8`:
`θ = 0 → 5` (a tip on the polar axis) confirms the reach.

**Independent.** 1. `r = 4 + 2 cos θ`: limaçon, `a > b`, dimpled
single loop; no zeros (minimum `r = 2 > 0`); maximum 6 at `θ = 0`.
`r = 1 + 3 sin θ`: limaçon, `a < b`, inner loop; zeros when
`sin θ = −1/3`, at `θ ≈ 199.47°` and `340.53°`; maximum 4 at
`θ = π/2`, minimum −2 at `θ = 3π/2` (plotted 2 units north, the
inner loop's far side). 2. `r = 2 cos(3θ)`: zeros when
`cos(3θ) = 0`: `3θ = π/2, 3π/2, 5π/2, 7π/2, 9π/2, 11π/2`, so
`θ = π/6, π/2, 5π/6, 7π/6, 3π/2, 11π/6`. A rose's zeros are the
angles between petals because `r = 0` is where one petal ends and
the next begins at the pole. 3. Plausible equation: `r = 2 + 2 sin θ`
(cardioid; symmetry about `θ = π/2` from the sin form; `r = 4` at
`θ = π/2`; zero at `θ = 3π/2`, the cusp at the pole). More than one
equation fits because feature descriptions do not determine
coefficients uniquely (e.g. `r = 4 sin²(θ/2)`-type rewrites, or a
scaled cardioid with different `a`, would need the stated maximum
to pin down — and even then, a different family could share these
three features). 4. Error: for even `n`, a rose has `2n` petals, not
`n`. `r = 3 cos(2θ)` has 4 petals. Mechanism: as `θ` runs over
`[0, 2π)`, `2θ` covers `[0, 4π)`; negative-`r` values retrace petals
in opposite directions, completing 4 distinct petals.

**Application (antenna).** `r = 5 + 3 cos θ`: maximum 8 at `θ = 0`
(east); minimum 2 at `θ = π` (west); minimum `r = 2 > 0`, so the
pattern never drops to zero. Sketch: dimpled limaçon, bulk east.
Physical reading is simpler than the rose because `r` is never
negative here: no direction is ever drawn by a negative radius, so
each `θ` reads directly as a signal strength in that direction.

**Exit check.** `r = 4 sin(2θ)`: rose, `n = 2` even → 4 petals,
reach 4; symmetry about the line `θ = π/2` (sin form) and about the
pole; zeros when `sin(2θ) = 0`: `θ = 0, π/2, π, 3π/2`; maxima
`|r| = 4` at `θ = π/4, 3π/4, 5π/4, 7π/4`. Desmos verification should
show 4 petals with tips at those angles.

## Lesson 06

**Guided.** 1. `−1 − √3 i`: modulus 2; `tan θ = √3`, Quadrant III,
so principal argument −120° (240° equivalently): `2 cis(−120°)`.
`3 cis 270° = 3(0 − i) = −3i`. 2. `(3 cis 20°)(2 cis 50°) = 6 cis 70°`
≈ `6(0.3420 + 0.9397i) ≈ 2.05 + 5.64i`.
`(6 cis 80°)/(3 cis 30°) = 2 cis 50°`. 3. 4th roots of `16 cis 120°`:
modulus 2; arguments `(120° + 360°k)/4 = 30°, 120°, 210°, 300°`:
`2 cis 30°`, `2 cis 120°`, `2 cis 210°`, `2 cis 300°` — four points
on a circle of radius 2, 90° apart.

**Independent.** 1. `2 − 2i`: modulus `2√2`, argument −45°:
`2√2 cis(−45°)`. Square: `(2√2)² cis(−90°) = 8 cis(−90°) = −8i`.
Rectangular check: `(2 − 2i)² = 4 − 8i + (2i)²·(−1)` — computed
directly: `(2 − 2i)² = 4 − 8i − 4 = −8i`. Agrees. 2. Polar:
`1 + i = √2 cis 45°`; fourth power: `(√2)⁴ cis 180° = 4 cis 180° = −4`.
Rectangular: `(1 + i)² = 2i`; `(2i)² = −4`. Agrees. 3. Distance:
`|(4 + i) − (−2 + 5i)| = |6 − 4i| = √52 = 2√13 ≈ 7.21`. Midpoint:
`((4 + (−2))/2, (1 + 5)/2) = (1, 3)`, i.e. `1 + 3i`. 4. Missing: the
other two cube roots. `27 cis 90°` has modulus-3 roots with
arguments `(90° + 360°k)/3 = 30°, 150°, 270°`: `3 cis 30°`,
`3 cis 150°`, `3 cis 270°`. A cubic over the complex numbers has
three roots because the arguments split a full turn into three equal
steps of 120°; stopping at one root discards two solutions.

**Exit check.** `5 cis 150° = 5 cos 150° + 5i sin 150°`
= `−5√3/2 + (5/2)i`. Times `2 cis 30°`: `10 cis 180° = −10`
(rectangular form: `−10 + 0i`).

**Task 6.** (a) Ground velocity = boat velocity + current. Steering
the same direction faster scales the boat vector but leaves the
current vector unchanged, so the resultant still has a downstream
component: the crossing time shrinks (so the downstream landing
distance, current × time, shrinks), but the direction of travel is
still downstream of the destination — the error is reduced, not
removed, and it only vanishes in the limit of infinite speed.
(b) The captain must aim upstream of the destination by the angle
whose cross-current component cancels the current (as in Lesson 02
and the project); the ground track is then a straight line directly
to the destination.
