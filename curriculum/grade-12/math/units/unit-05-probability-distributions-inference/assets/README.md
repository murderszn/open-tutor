## normal-curve.svg

- **File:** `assets/normal-curve.svg` (SVG, deterministic diagram)
- **How it was made:** generated by a Python script from the standard
  normal density formula `f(z) = exp(−z²/2) / √(2π)` on 2026-11-12;
  the curve path, the shaded ±1σ / ±2σ / ±3σ regions, and the axis
  ticks are computed from that formula, not drawn by hand or by an
  image model. Density values used: `f(0) = 0.3989`, `f(±1) = 0.2420`,
  `f(±2) = 0.0540`, `f(±3) = 0.0044`.
- **Learning purpose:** Lesson 05 ("The normal distribution"). The
  learner reads probabilities off the curve: about 68% within 1
  standard deviation, 95% within 2, 99.7% within 3. The SVG's `<title>`
  and `<desc>` carry the same information in text.
- **Factual review (2026-11-12):** the SVG parses as valid XML; the
  density values match the formula; the shaded regions are symmetric
  about `z = 0` and the labels state the empirical-rule percentages.
- **Alt text:** "A bell-shaped standard normal curve centered at
  z equals 0. About 68 percent of the area lies within one standard
  deviation of the mean, about 95 percent within two, and about 99.7
  percent within three."
- **Caption:** "Deterministic diagram of the standard normal curve,
  computed from the density formula. Percentages are the empirical
  rule, not measurements from the picture."
