# Week 4 Formative Quiz (S10) — about 30 minutes

Covers Lessons 01–04 only: function analysis across families,
equivalent forms, composition/decomposition/inverses, average rate
of change and the difference quotient. Notebook and calculator
allowed; Desmos allowed for checking, not for skipping the algebra.
The adult scores same-day; solutions are in the adult-only answer
key (`../answer-key.md`).

---

**Q1.** (5 pts) For `f(x) = (x − 3)/(x² − 4)`: state the domain, the
vertical asymptotes, the horizontal asymptote, the x-intercept, and
the y-intercept.

**Q2.** (5 pts) Analyze `g(x) = 4 − x²` completely: zeros, vertex,
intervals of increase and decrease, range, symmetry (with algebra),
and end behavior.

**Q3.** (4 pts — explain your reasoning) Mara says `h(x) = 1/x²` is
even because `h(−x) = 1/(−x)² = 1/x² = h(x)`. Jalen says it cannot
be even because its graph has a break at `x = 0`. Who is right, and
why? Answer in 3–5 sentences.

**Q4.** (4 pts) Write `p(x) = 2x² + 12x + 7` in vertex form. Give the
minimum value and where it occurs. One sentence: which form would
you use to find the y-intercept, and why?

**Q5.** (4 pts) Let `f(x) = √x` and `g(x) = x² − 4`. Write `(f∘g)(x)`
with its domain, and evaluate `(f∘g)(3)`.

**Q6.** (5 pts) The function `f(x) = x² + 2x` is restricted to the
domain `x ≥ −1`.
a) Explain in one sentence why the restriction makes `f`
   invertible.
b) Find `f⁻¹` by swap-and-solve and state its domain.

**Q7.** (4 pts) Simplify the difference quotient
`[f(x + h) − f(x)]/h` fully for `f(x) = 3x² + 2x`.

**Q8.** (4 pts) A ball's height is `s(t) = −4.9t² + 20t + 1.5`
(meters, `t` seconds). Find the average rate of change of `s` on
`[0, 2]` with units, and interpret it in one sentence.

**Q9.** (3 pts) A print shop charges `C(n) = 25 + 1.75n` dollars for
`n` T-shirts, `0 ≤ n ≤ 200`. State the domain and range with units,
and solve `C(n) = 0` — then explain what that solution means for
the realistic domain.

**Q10.** (2 pts) Decompose `m(x) = (5x + 2)⁴` into an inner and an
outer function, and verify by recomposing.

---

## Scoring criteria (40 points total)

- **Q1:** 1 pt each for domain, vertical asymptotes, horizontal
  asymptote, x-intercept, y-intercept. (Vertical asymptote answers
  must exclude the points from the domain.)
- **Q2:** 1 pt each for zeros, vertex, monotonicity intervals,
  range, symmetry-with-algebra, end behavior. (Deduct the symmetry
  point if no `f(−x)` algebra is shown.)
- **Q3:** 2 pts for the correct verdict with the definition of
  evenness cited; 2 pts for addressing Jalen's confusion
  (continuity vs. symmetry). No credit for a verdict alone.
- **Q4:** 2 pts for the correct vertex form; 1 pt for the minimum
  value and location; 1 pt for the one-sentence form choice with a
  reason.
- **Q5:** 2 pts for `(f∘g)(x)`; 1 pt for the correct domain;
  1 pt for the evaluation.
- **Q6:** 1 pt for the invertibility sentence (must mention
  monotonicity or the horizontal line test); 3 pts for the correct
  inverse with the right square-root sign; 1 pt for its domain.
- **Q7:** full credit only for the fully simplified form
  (`6x + 3h + 2`); 2 pts for correct expansion with an algebra
  slip in the final step.
- **Q8:** 2 pts for the value with units; 2 pts for an
  interpretation that names "average upward velocity."
- **Q9:** 1 pt each for domain, range, and the equation's solution
  with the interpretation that it falls outside the realistic
  domain.
- **Q10:** 1 pt for the decomposition, 1 pt for the verification.

**Reading the score:** 34–40 = on track for the unit assessment;
26–33 = revisit the flagged lessons before S11; below 26 =
re-teach Lessons 01–04 with the adult before continuing.
