# Resource Pack — Unit 01: Advanced Function Analysis and Mathematical Modeling

**Summary (adult planning judgment):** a one-unit shelf for a grade-12
precalculus learner analyzing functions across families and defending a
chosen model with residuals and rate-of-change reasoning; every core
objective has a free, no-account route.

## Web references (checked 2026-10-14 unless noted)

1. **Desmos graphing calculator** — <https://www.desmos.com/calculator> —
   free in the browser; no account needed to graph (an account only saves
   work). The unit's verify step for every sketch and every model fit.
   Checked via site open + search 2026-10-14. Adult previews for
   advertising before first use.
2. **Paul's Online Math Notes (Lamar University)** —
   <https://tutorial.math.lamar.edu/> — free notes with practice problems
   and worked solutions. The **Algebra** notes cover functions,
   graphing, and rational expressions; the **Algebra/Trig Review**
   covers exponentials, logarithms, and trig functions used in Lessons
   01–05. Page opened and read 2026-10-14.
3. **OpenStax *Precalculus 2e*** —
   <https://openstax.org/details/books/precalculus-2e> — free textbook
   (CC BY-NC-SA 4.0; web version last updated June 12, 2026): functions
   through trigonometry, worked examples, exercise sets. Reference for
   Lessons 01–06 and the project. Details page opened 2026-10-14.
4. **Khan Academy — Precalculus course** —
   <https://www.khanacademy.org/math/precalculus> — free course covering
   composite and inverse functions, rational functions, trigonometry, and
   series. Existence and topic coverage confirmed by search 2026-10-14;
   the course page itself would not load for direct browsing (client
   challenge), so treat item-level details as unverified and let the adult
   confirm the unit needed.
5. **CCSS-M High School Functions and Algebra pages** —
   <https://www.thecorestandards.org/Math/> — the standards framework the
   unit's codes are quoted from; verified against the official text by the
   track audit runs on 2026-10-07 and 2026-10-08 (paraphrases in the unit
   README, not reproductions).
6. **`resources/weights_and_measures.md`** (internal) — conversion
   reference for Lesson 04 / Lesson 06 / project quantity-definition work
   (N-Q); the adult checks conversion facts before use.
7. **Repository datasets** (internal): `resources/us_states.csv`,
   `resources/un_countries.csv`, `resources/solar_system_planets.csv` —
   anonymous public counting/data sources for extension modeling tasks;
   every dataset task must name columns and units and state whether values
   are real, rounded, or fictional practice data.
