# Project and Investigation — Unit 03: Energy, Work, Simple Machines, and Conservation

**Answer key and scoring guidance:** [answer key](answer-key.md#project)
**Safety box (adult reads first):** The adult sets up and supervises
every trial. The runout area must be clear of people, pets, and
breakables; nobody stands in the car's path. Cars are rolled, never
thrown. Springs and rubber bands are pulled only within their
normal stretch — never aimed at anyone. The adult stops any trial
that sends a car off the table or toward a person. Learners who
cannot safely handle the materials use the PhET observation
alternative below for the same analysis.

## Part 1 — Investigation: the ramp lab (Sessions 8–9)

### Question

How does the release height of a rolling car affect how far it
travels on a flat surface — and what does that tell us about the
energy in the system?

### Materials

Toy car or low-friction cart, a smooth board (1–1.5 m) for a ramp,
books to change the height, a flat track or floor runout, masking
tape for a start line and distance marks, a meter stick or tape
measure, a stopwatch (optional), notebook and data table.

### Method (adult-supervised)

1. Build the ramp: one end on a stack of books, the other on the
   flat surface. Mark the release point on the ramp and the point
   where the flat runout begins.
2. Choose three release heights (for example 10 cm, 20 cm, and
   30 cm, measured vertically from the flat surface to the release
   point). Keep everything else the same: same car, same ramp,
   same surface, same release (let go, do not push).
3. For each height, run three trials. In each trial, release the car
   and measure how far it travels along the flat surface from the
   bottom of the ramp to where it stops. Record every trial, then
   compute the mean travel distance for each height.
4. Record one observation per height about what the car did at the
   end of the run (rolled smoothly to a stop? hit the spring
   bumper? wobbled?) — observations, not opinions, in this column.

### Data table (copy into the notebook)

| Release height (cm) | Trial 1 (cm) | Trial 2 (cm) | Trial 3 (cm) | Mean travel (cm) | End-of-run observation |
|---|---|---|---|---|---|
| 10 | | | | | |
| 20 | | | | | |
| 30 | | | | | |

### Analysis (write, do not just answer in your head)

1. Describe the pattern: as release height increased, what
   happened to mean travel distance?
2. Explain the pattern in energy language: higher release → more
   gravitational potential energy → more kinetic energy at the
   bottom of the ramp → the car can do more work against friction
   before stopping, so it travels farther.
3. Why is travel distance only an indirect measure of energy?
   (Name two things that also affect it: friction differences
   along the track, small pushes at release, the car's wheels.)
4. Where did the car's energy go by the time it stopped? Name the
   forms and places (thermal energy in wheels/track/air, sound).
5. Predict: what would happen to travel distance on a rougher
   flat surface, and what energy explanation supports that
   prediction?

### Observation alternative (PhET)

If the physical lab is not possible, use the PhET "Energy Skate
Park: Basics" simulation (resource pack): set friction to none and
then to some, release the skater from two heights, and record the
bar-graph readings (PE, KE, thermal) at the top, bottom, and end of
each run. Answer analysis questions 1–5 from the simulation's bar
graphs instead of travel distances, and say so in the report.

## Part 2 — Design challenge: the machine lifter (Sessions 14–15)

### Problem

Lift a load (a bag or box the adult weighs and records — for
example a 1 kg bag, weight about 9.8 N) vertically by 20 cm, using
a lever, a pulley system, or a ramp you build — with the smallest
effort force you can manage, and prove with numbers that your
machine did not create energy.

### Criteria and constraints (agreed before building)

- The load must rise 20 cm vertically, without being lifted by
  hand.
- The machine must be one of the three types from Lesson 05 (or a
  combination the adult approves).
- Effort force and effort distance must both be measured or
  estimated honestly (spring scale if available; otherwise the
  adult helps estimate effort by comparing with known weights —
  and the report must say which method was used).
- One improvement round is required: test, change one thing
  (longer effort arm, more rope segments, longer ramp), re-test,
  and report both rounds.

### Deliverables

1. A labeled sketch of the design, naming the machine type, the
   fulcrum or pulley count or ramp length, and the load.
2. A test log for both rounds: load weight (N), effort force (N),
   load distance (m), effort distance (m), work in, useful work
   out, mechanical advantage, efficiency.
3. A short paragraph answering: did your machine multiply force?
   Did work out exceed work in? Where did the missing energy go
   (if efficiency was below 100%)?
4. A 3-minute presentation (Session 18) walking the adult through
   the sketch, one test round's numbers, and the improvement.

### Rubric (scored by the adult; see the teacher guide for levels)

| Criterion | 4 — Strong | 3 — Solid | 2 — Developing | 1 — Starting |
|---|---|---|---|---|
| Energy explanation | Correctly links height/force to energy with numbers, and names thermal losses | Correct links, minor number slip, losses named | Links stated but vague or one number wrong | No energy link, or claims energy was created |
| Investigation / test quality | Controlled variables named; 3 trials per height; means computed; honest method note | Most controls named; trials complete; means present | Some controls or trials missing | Single trial, or variables confounded |
| Machine design and improvement | Machine works; one clear improvement tested and compared with numbers | Machine works; improvement tested, comparison thin | Machine partly works; improvement unclear | Machine does not lift the load |
| Communication | Sketch labeled; tables complete; presentation argues from data | Sketch and tables mostly complete; presentation clear | Gaps in sketch or tables; presentation mostly description | Deliverables incomplete |

## Capstone presentations (Session 18)

Each learner presents the machine lifter in 3 minutes: the problem,
the machine, one round's numbers (work in vs. work out), the
improvement, and one sentence answering the unit's essential
question for their machine ("Why did a smaller force still need
the longer distance?"). The adult scores with the rubric above and
asks one follow-up: "Where did the energy go that did not become
useful work?"
