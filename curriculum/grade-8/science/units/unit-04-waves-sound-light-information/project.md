# Project — Send It Twice

**Unit 04 investigation/project** · Two 50-minute blocks (Sessions
14–15) plus the Lessons 01–06 background · **Rubric:** 40 points
· **Answer key and scoring notes:**
[answer key](answer-key.md#project)

## The challenge

Send the same five messages across a room (or a yard) twice:
once as an **analog-style signal** and once as a **pulse-code
(digital-style) signal** — then add noise and find out which one
survives. You will argue, from your own test counts, which kind of
signal is more reliable, exactly as Lesson 06's claim requires.

## Materials (adult-supervised, household items only)

- Notebook and pencil; a flashlight (adult-operated, pointed at a
  wall or screen, never at eyes) or two paper cups and string, or
  hands for clapping — pick one sender for both channels so the
  comparison is fair
- A smooth-wave drawing: the adult draws one wavy line as the
  "original analog message"
- A timer or clock with seconds
- Optional: the PhET "Wave on a String" simulation as the
  observation alternative if rope or clapping work is not
  possible (see the [resource pack](resource-pack.md))

## Safety rules (adult reads aloud before starting)

- Flashlights point at walls, never at faces or eyes. No laser
  pointers. No shouting: claps and normal speaking voices only.
- Rope/slinky work stays at waist height or below; nothing is
  aimed at anyone. Stop immediately if anyone is uncomfortable
  with a sound level.

## Steps

1. **Write the five messages.** Choose five short messages you
   might need across a playground (for example: "come here,"
   "bring water," "game over," "help," "wait"). Write them in a
   numbered list: Message 1–5.
2. **Build the analog channel.** The adult draws a smooth wavy
   line for each message — a different shape for each message
   (tall, short, wiggly, flat, double-humped). These five shapes
   *are* the analog code: shape 1 means Message 1, and so on.
   Copy the chart into your notebook.
3. **Build the pulse channel.** Agree a pulse code: short flash
   (or clap), long flash (or clap), and a pause between messages.
   Give each of the five messages a different short/long pattern
   (for example: Message 1 = short-short, Message 2 = short-long,
   Message 3 = long-short, Message 4 = long-long, Message 5 =
   short-long-short). Write the code chart. This is a pulse code;
   it does not use binary counting.
4. **Send clean (no noise).** For each channel, send all five
   messages once from sender to receiver across the room, with
   the receiver writing down what arrived. Record: analog clean
   score ___/5; pulse clean score ___/5.
5. **Send with noise.** Repeat step 4, but now a third person
   makes steady background noise (soft clapping, humming, or
   rustling paper — same noise for both channels). For the analog
   channel, the "noise" is an extra wobble: the copier adds one
   small random squiggle to each shape as it is copied once more
   (copy of the copy). Record: analog noisy score ___/5; pulse
   noisy score ___/5.
6. **Count and compare.** Fill in the table:

   | Channel | Clean (out of 5) | Noisy (out of 5) | Messages lost to noise |
   |---|---|---|---|
   | Analog (shapes) | | | |
   | Pulse (short/long) | | | |

7. **Recommend.** Write a short recommendation (4–6 sentences):
   which channel would you trust for an important message across
   a noisy playground, and what evidence from your table supports
   that choice? Name one noise that could still break your pulse
   code, and one fix for it (for example, sending each message
   twice and comparing).

## Deliverables

1. The five-message list and both code charts (analog shapes
   described or drawn; pulse chart written out).
2. The completed test table (clean and noisy scores for both
   channels).
3. The written recommendation with evidence from the table, the
   named breaking noise, and the fix.

## Rubric (40 points)

| Criterion | 10 points | 6–7 points | 3–4 points | 0–1 points |
|---|---|---|---|---|
| Code charts (10) | Both charts complete, unambiguous, and usable by a stranger to send/receive all five messages | One chart complete; the other partly ambiguous | Charts incomplete or ambiguous for two or more messages | No usable chart |
| Analog test and log (10) | All five messages sent clean and noisy; scores recorded honestly, including failures | Most messages tested; scores recorded with small gaps | One round tested only, or scores missing | No test log |
| Pulse test and log (10) | All five messages sent clean and noisy; scores recorded honestly, including failures | Most messages tested; scores recorded with small gaps | One round tested only, or scores missing | No test log |
| Recommendation (10) | Recommends a channel, cites the table's counts, names a breaking noise and a workable fix | Recommends with some evidence, but the noise or the fix is missing | Recommendation with no evidence from the table | No recommendation |
