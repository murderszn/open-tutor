# Resource Pack — Unit 04: Waves, Sound, Light, and Information

**Summary (adult planning judgment):** Weeks 15–16 need a wave
anatomy explainer at grade-8 level and a live wave simulation for
the rope investigation; Week 16 needs a sound-speed and echo
reference; Week 17 needs a spectrum reference and a noisy-channel
demonstration the adult can run without equipment. Videos
supplement the lessons; they never replace the learner's own
calculations, observations, and builds. All external links were
checked 2026-11-02; unverified items are labeled as open search
links, and the adult previews every video before showing it.

## Web references (reputable; free, no account required)

1. **NGSS MS-PS4 topic listing (NSTA)** —
   [https://my.nsta.org/ngss/DisplayStandard.aspx?id=28&view=topic](https://my.nsta.org/ngss/DisplayStandard.aspx?id=28&view=topic)
   — official-text paraphrase source for MS-PS4-1, MS-PS4-2,
   MS-PS4-3 wording, clarification statements, and assessment
   boundaries; verified 2026-11-02 via search-result page check.
   Use for adult planning, not as a learner handout.
2. **NGSS MS-PS4 official text (PDF, via the track audit)** —
   [https://4.files.edl.io/c1df/03/05/24/214228-b8fecb94-10a2-410f-97e5-a4de5c4c65e2.pdf](https://4.files.edl.io/c1df/03/05/24/214228-b8fecb94-10a2-410f-97e5-a4de5c4c65e2.pdf)
   — the MS-PS4 official-text PDF cited in the track
   scope-and-sequence audit (checked 2026-10-06). Adult planning
   reference for the same boundaries.
3. **PhET Wave on a String — teacher guide (PDF)** —
   [https://phet.colorado.edu/files/teachers-guide/wave-on-a-string-html-guide_en.pdf](https://phet.colorado.edu/files/teachers-guide/wave-on-a-string-html-guide_en.pdf)
   — University of Colorado Boulder PhET guide for the "Wave on a
   String" simulation (transverse waves, frequency, amplitude,
   damping, tension, reflection); verified 2026-11-02 via
   search-result page check. The simulation itself is found by
   searching the PhET site for "Wave on a String"; free, no
   account, runs in a browser. Use for Sessions 4–5 and as the
   project's observation alternative.
4. **Sound-speed reference values** — air 343 m/s at 20 °C, water
   about 1,480 m/s, steel about 5,960 m/s; verified 2026-11-02 via
   search-result page checks against multiple consistent
   listings. These are the values used in every calculation in
   this unit; the adult need not re-verify them per lesson.
5. **Light in a vacuum (reference value)** — about 300,000,000
   m/s, stated in Lesson 05 for comparison only and never used
   in a graded calculation, per the MS-PS4-1 assessment boundary.
