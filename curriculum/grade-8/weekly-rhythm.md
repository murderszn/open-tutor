# Grade 8 — Independent Weekly Learning Plan

A flexible five-session outline, not a prescribed timetable.

| Session | Focus | Individual evidence |
|---|---|---|
| 1 | Set a learning goal and review prerequisites | Short plan and initial question |
| 2 | Mathematics and analytical practice | Worked problem with reasoning |
| 3 | Reading, research, and writing | Cited draft or annotated source |
| 4 | STEM investigation or coding project | Test log, model, or code artifact |
| 5 | Critique and revision | Revised work and reflection |

Adjust workload and supports to the individual learner. Keep drafts and progress records in private storage; peer comparison is not required.
