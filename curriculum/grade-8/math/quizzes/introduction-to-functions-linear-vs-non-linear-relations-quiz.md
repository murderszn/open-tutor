## 🔑 Parent Answer Key (Educator)

> [!NOTE]
> *This section is for Educator (educator) to verify answers, assess computational precision, and provide targeted feedback.*

**Question 1:**  
- **Target Answer & Key Steps:** A function is a relation that assigns to each input (from the domain) exactly one output (in the range).

**Question 2:**  
- **Target Answer & Key Steps:** No, it is not a function because the input $2$ is paired with two different outputs ($7$ and $9$).

**Question 3:**  
- **Target Answer & Key Steps:** If any vertical line intersects the graph at more than one point, the graph is not a function because a single input $x$ has multiple outputs $y$.

**Question 4:**  
- **Target Answer & Key Steps:** $f(-4) = -3(-4) + 8 = 12 + 8 = 20$.

**Question 5:**  
- **Target Answer & Key Steps:** a) Linear (degree 1)<br>b) Non-linear (quadratic, degree 2)<br>c) Non-linear (variable in denominator)<br>d) Linear (slope-intercept with $b=0$)

**Question 6:**  
- **Target Answer & Key Steps:** Yes. The rate of change $\frac{\Delta y}{\Delta x}$ is constant: $\frac{10-4}{3-1} = \frac{6}{2} = 3$; $\frac{16-10}{5-3} = 3$; $\frac{22-16}{7-5} = 3$. Since rate of change is constant, it is a linear function ($y = 3x + 1$).

**Question 7:**  
- **Target Answer & Key Steps:** Function A rate of change $= 4$. Function B rate of change $= \frac{13 - 3}{2 - 0} = \frac{10}{2} = 5$. Function B has the greater rate of change ($5 > 4$).

**Question 8:**  
- **Target Answer & Key Steps:** Domain (inputs): $\{-3, 0, 4, 7\}$. Range (outputs): $\{-1, 2, 5\}$.

**Question 9:**  
- **Target Answer & Key Steps:** Yes, every input in the domain maps to exactly one output (even though $-3$ and $7$ share output $5$, each input has only one assignment).

**Question 10:**  
- **Target Answer & Key Steps:** No, it is non-linear because the independent variable $t$ is squared (degree 2), creating a parabolic curve where rate of change is not constant.

**Question 11:**  
- **Target Answer & Key Steps:** Initial value $= 15\text{ gallons}$; Rate of change $= -0.04\text{ gallons/mile}$. Function: $f(m) = -0.04m + 15$.

**Question 12:**  
- **Target Answer & Key Steps:** $g(-2) = 2(4)-1 = 7$<br>$g(-1) = 2(1)-1 = 1$<br>$g(0) = 2(0)-1 = -1$<br>$g(1) = 2(1)-1 = 1$<br>$g(2) = 2(4)-1 = 7$<br>Table: $(-2, 7), (-1, 1), (0, -1), (1, 1), (2, 7)$.
