## 🔑 Parent Answer Key (Educator)

> [!NOTE]
> *This section is for Educator (educator) to verify answers, assess computational precision, and provide targeted feedback.*

**Question 1:**  
- **Target Answer & Key Steps:** $a^2 + b^2 = c^2$, where $a$ and $b$ are the lengths of the legs of a right triangle, and $c$ is the length of the hypotenuse (the side opposite the $90^\circ$ right angle).

**Question 2:**  
- **Target Answer & Key Steps:** $c^2 = 9^2 + 12^2 = 81 + 144 = 225 \implies c = \sqrt{225} = 15\text{ cm}$.

**Question 3:**  
- **Target Answer & Key Steps:** $7^2 + b^2 = 25^2 \implies 49 + b^2 = 625 \implies b^2 = 576 \implies b = \sqrt{576} = 24\text{ in}$.

**Question 4:**  
- **Target Answer & Key Steps:** $c^2 = 5^2 + 8^2 = 25 + 64 = 89 \implies c = \sqrt{89} \approx 9.43$.

**Question 5:**  
- **Target Answer & Key Steps:** Check: $8^2 + 15^2 = 64 + 225 = 289$. Compare to $17^2 = 289$. Since $289 = 289$, yes, it forms a right triangle.

**Question 6:**  
- **Target Answer & Key Steps:** Check: $6^2 + 10^2 = 36 + 100 = 136$. Compare to $12^2 = 144$. Since $136 \ne 144$, no, it is not a right triangle (it is obtuse since $c^2 > a^2 + b^2$).

**Question 7:**  
- **Target Answer & Key Steps:** $d = \sqrt{(7 - 1)^2 + (11 - 3)^2} = \sqrt{6^2 + 8^2} = \sqrt{36 + 64} = \sqrt{100} = 10\text{ units}$.

**Question 8:**  
- **Target Answer & Key Steps:** $d = \sqrt{(2 - (-3))^2 + (10 - (-2))^2} = \sqrt{5^2 + 12^2} = \sqrt{25 + 144} = \sqrt{169} = 13\text{ units}$.

**Question 9:**  
- **Target Answer & Key Steps:** Let $h$ be height: $5^2 + h^2 = 13^2 \implies 25 + h^2 = 169 \implies h^2 = 144 \implies h = 12\text{ feet}$.

**Question 10:**  
- **Target Answer & Key Steps:** $d = \sqrt{100^2 + 64^2} = \sqrt{10000 + 4096} = \sqrt{14096} \approx 118.7\text{ meters}$.

**Question 11:**  
- **Target Answer & Key Steps:** Leg $AB = 6$. Leg $AC = 8$. Hypotenuse $BC = \sqrt{6^2 + 8^2} = 10$. Perimeter $= 6 + 8 + 10 = 24\text{ units}$.

**Question 12:**  
- **Target Answer & Key Steps:** $d = \sqrt{(1 - (-4))^2 + (-7 - 5)^2} = \sqrt{5^2 + (-12)^2} = \sqrt{25 + 144} = \sqrt{169} = 13\text{ units}$.
