## 🔑 Parent Answer Key (Educator)

> [!NOTE]
> *This section is for Educator (educator) to verify answers, assess computational precision, and provide targeted feedback.*

**Question 1:**  
- **Target Answer & Key Steps:** $d = \sqrt{40^2 + 30^2} = \sqrt{1600 + 900} = \sqrt{2500} = 50\text{ inches}$.

**Question 2:**  
- **Target Answer & Key Steps:** $d = \sqrt{7^2 + 24^2} = \sqrt{49 + 576} = \sqrt{625} = 25\text{ miles}$.

**Question 3:**  
- **Target Answer & Key Steps:** Space diagonal $D = \sqrt{l^2 + w^2 + h^2} = \sqrt{4^2 + 3^2 + 12^2} = \sqrt{16 + 9 + 144} = \sqrt{169} = 13\text{ cm}$.

**Question 4:**  
- **Target Answer & Key Steps:** $D = \sqrt{6^2 + 6^2 + 6^2} = \sqrt{3 \times 36} = 6\sqrt{3}\text{ in} \approx 10.39\text{ in}$.

**Question 5:**  
- **Target Answer & Key Steps:** The altitude bisects the base into two 5 cm segments. $5^2 + h^2 = 10^2 \implies 25 + h^2 = 100 \implies h = \sqrt{75} = 5\sqrt{3}\text{ cm} \approx 8.66\text{ cm}$.

**Question 6:**  
- **Target Answer & Key Steps:** $A = \frac{1}{2}(10)(5\sqrt{3}) = 25\sqrt{3}\text{ cm}^2 \approx 43.3\text{ cm}^2$.

**Question 7:**  
- **Target Answer & Key Steps:** $a^2 + 24^2 = 26^2 \implies a^2 + 576 = 676 \implies a^2 = 100 \implies a = 10\text{ feet}$.

**Question 8:**  
- **Target Answer & Key Steps:** Diagonal $D = \sqrt{9^2 + 10^2 + 6^2} = \sqrt{81 + 100 + 36} = \sqrt{217} \approx 14.73\text{ inches}$. Since $14.73 > 14$, yes, the rod fits along the 3D interior diagonal.

**Question 9:**  
- **Target Answer & Key Steps:** The two base wings are $\frac{22 - 10}{2} = 6$. Slant legs: $s = \sqrt{6^2 + 8^2} = \sqrt{36 + 64} = 10$. Perimeter $= 10 + 22 + 10 + 10 = 52\text{ units}$.

**Question 10:**  
- **Target Answer & Key Steps:** Return leg $= \sqrt{12^2 + 9^2} = \sqrt{144 + 81} = \sqrt{225} = 15\text{ km}$. Total distance $= 12 + 9 + 15 = 36\text{ km}$.

**Question 11:**  
- **Target Answer & Key Steps:** Side $s = \sqrt{50}$. Diagonal $d = \sqrt{s^2 + s^2} = \sqrt{50 + 50} = \sqrt{100} = 10\text{ cm}$.

**Question 12:**  
- **Target Answer & Key Steps:** $d = \sqrt{90^2 + 90^2} = \sqrt{8100 + 8100} = \sqrt{16200} \approx 127.3\text{ feet}$.
