## 🔑 Parent Answer Key (Educator)

> [!NOTE]
> *This section is for Educator (educator) to verify answers, assess computational precision, and provide targeted feedback.*

**Question 1:**  
- **Target Answer & Key Steps:** Slope $m = \frac{13 - 7}{4 - 2} = \frac{6}{2} = 3$. Use $(2, 7)$: $7 = 3(2) + b \implies b = 1$. Equation: $y = 3x + 1$.

**Question 2:**  
- **Target Answer & Key Steps:** Slope $m = \frac{-1 - 9}{3 - (-2)} = \frac{-10}{5} = -2$. Use $(-2, 9)$: $9 = -2(-2) + b \implies 9 = 4 + b \implies b = 5$. Equation: $y = -2x + 5$.

**Question 3:**  
- **Target Answer & Key Steps:** Numerator: $3^5$. Quotient: $\frac{3^5}{3^3} = 3^{5-3} = 3^2 = 9$.

**Question 4:**  
- **Target Answer & Key Steps:** $(4.0 \times 8.5) \times 10^{-3 + 7} = 34 \times 10^4 = 3.4 \times 10^5$.

**Question 5:**  
- **Target Answer & Key Steps:** $8^2 = 64$ and $9^2 = 81$. $72$ is equidistant (8 away from 64 and 9 away from 81), closest to 8 (actual $\approx 8.49$, rounds to 8).

**Question 6:**  
- **Target Answer & Key Steps:** $12x - 8 = 10x + 14 \implies 2x = 22 \implies x = 11$.

**Question 7:**  
- **Target Answer & Key Steps:** $6x + 9 = 6x + 15 \implies 9 = 15$. **No solution**.

**Question 8:**  
- **Target Answer & Key Steps:** x-intercept: set $y = 0 \implies 5x = 20 \implies (4, 0)$. y-intercept: set $x = 0 \implies -2y = 20 \implies (0, -10)$.

**Question 9:**  
- **Target Answer & Key Steps:** Equation: $h = 4s + 10$. After $18\text{ s}$: $h = 4(18) + 10 = 72 + 10 = 82\text{ meters}$.

**Question 10:**  
- **Target Answer & Key Steps:** Parallel lines have identical slopes ($m = -3$). With y-intercept $(0, -4)$, the equation is $y = -3x - 4$.

**Question 11:**  
- **Target Answer & Key Steps:** $2y - 3 + 4 = 2y + 1 \implies 2y + 1 = 2y + 1$. **Infinitely many solutions**.

**Question 12:**  
- **Target Answer & Key Steps:** Let $x = 0.1818\ldots$. $100x = 18.1818\ldots \implies 99x = 18 \implies x = \frac{18}{99} = \frac{2}{11}$.
