**Independent practice**

2. (10³)² = 10⁶ = 1,000,000 (expansion: six 10s).
3. 10⁸ ÷ 10² = 10⁶ = 1,000,000. Verify: 100,000,000 ÷ 100 = 1,000,000 ✓.

   n zeros."
5. 2 × 10³ = 2,000 (two thousands).

**Application:** 9,460,000,000,000 = 9.46 × 10¹². Digits "946" are the
number's shape; the exponent 12 counts the places — the size.

**Exit check:** 10⁵ ÷ 10 = 10⁴ = 10,000.

## Lesson 02

**Guided practice**
1. 10⁻⁴ = 1/10⁴ = 1/10,000 = 0.0001.
2. 2⁻³ = 1/2³ = 1/8 = 0.125.
3. 9⁰ + 9⁻¹ = 1 + 1/9 = 10/9 ≈ 1.111.

   it does not negate. 3⁻² = 1/3² = 1/9.

   reaches 1 for every nonzero base.
2. 2⁻⁴ = 1/16; (1/2)⁴ = 1/16. Noticed: a⁻ⁿ = (1/a)ⁿ — the flip and the
   power commute.
3. 10⁻¹ + 10⁻² + 10⁻³ = 1/10 + 1/100 + 1/1,000 = 111/1,000 = 0.111.
4. Priya's error: the minus belongs to the *exponent*, not the base.
   5⁻³ = 1/5³ = 1/125; her 1/(−5³) = −1/125 has the wrong sign.
5. Exact: 4⁻³ = 1/64 ≈ 0.01563. The display 2.5E-2 = 2.5 × 10⁻² =
   0.025 ≠ 1/64, so the display is *not* reasonable for 4⁻³ — the entry

**Application:** 0.0003 m = 3/10,000 m = 3 × 10⁻⁴ m.

   (10⁴)⁻¹ × 10² = 10⁻⁴ × 10² = 10⁻² ✓.

## Project — analysis checkpoints

- **Step 3 spot-check method:** convert to meters first (mm → ×10⁻³,
  cm → ×10⁻²), then shift the decimal to normalize.
- **Step 5:** both entries in meters in scientific notation; ratio =
  (coefficient ratio) × 10^(big exp − small exp).
- **Step 6:** addition requires matched exponents (shift the smaller);
  multiplication adds exponents then normalizes. Accept either answer
  for "harder" with a rule-based reason.
