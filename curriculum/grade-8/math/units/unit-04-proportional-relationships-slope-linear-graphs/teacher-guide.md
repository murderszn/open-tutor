# Teacher Guide — Unit 04: Proportional Relationships, Slope, and Linear Graphs

Adult-facing guidance. Student materials are in the unit README,
lessons, practice, project, and assessments; worked solutions are
in the separate [answer key](answer-key.md).

## Session guidance

- **Sessions 1–2 (Lesson 01, Practice A).** Drill both tests
  (ratio test and zero test) on every item. Do not let "goes up by
  the same amount" pass as a proportionality argument — that
  confusion is the unit's most durable misconception and returns
  in Lessons 04 and 06.
- **Sessions 3–4 (Lesson 02, Practice B).** Insist on graph paper
  and a third-point check. The unit-rate-from-a-point error
  (reading `y` instead of `y ÷ x`) is best caught here, while the
  numbers are still small.
- **Sessions 5–6 (Lesson 03, Practice C).** Make learners draw the
  triangles. The drawing is the proof: learners who draw rarely flip
  rise and run. Name the vertical-line case explicitly
  (undefined, not 0) so it does not resurface as a quiz error.
- **Sessions 7–8 (Lesson 04, Practice D).** Enforce the order:
  slope first, intercept second, second-point check third. Tables
  whose `x` does not start at 0 are the trap — learners must work
  backwards from a known point to find `b`.
- **Sessions 9–10 (Lesson 05, Practice E).** Grade context answers
  on units and meaning sentences, not just numbers. A bare "−4"
  is an incomplete answer in this unit. Discuss model limits
  (negative gallons, zero-bus bookings) out loud; learners who can
  say where a model stops are ready for Unit 05's systems work.
- **Sessions 11–12 (Lesson 06, Project Part 1).** The project needs
  counts that straddle the crossing — check each learner's table
  before they graph. A table with no crossing row means the counts
  were too narrow, not that the plans never cross (unless the
  slopes are equal, which the edge case covers separately).
- **Session 13 (Midyear review clinic).** This is the unit's
  cumulative week (track week 18). Use the review set diagnostically:
  an error on a Unit 01–03 item is a reteach signal for that unit's
  skill, not a Unit 04 failure. Record which objective each learner
  missed before Session 16.
- **Session 14 (Project Part 2).** Presentations are checked for
  number agreement across tables, graphs, and recommendations
  before any praise for polish. A pretty poster with mismatched
  numbers is not a pass.
- **Sessions 15–16 (Quiz, Assessment).** The quiz is formative: a
  learner below 7/10 needs reteaching on the missed objective
  before Unit 05, especially slope computation and equation
  writing. The assessment is the unit's culminating evidence, not a
  standardized or validated test.

## Misconceptions and reteaching moves

| Misconception | Reteaching move |
|---|---|
| "Steady increase" = proportional | Return to Lesson 01's taxi non-example; run both tests on the learner's own table |
| Unit rate read as a point's `y` | "Per *one* what?" — divide `y` by `x` for the point, every time |
| Rise/run flipped | Draw the triangle; say "rise over run" while pointing up, then across |
| Mixed ordering flips the sign | Same-order rule: first point to second point for both coordinates; redo with the order swapped to show the sign flip |
| Second point's `y` taken as slope | Re-derive slope as a difference (Lesson 04, Independent practice item 6) |
| First table row taken as `b` when `x ≠ 0` | Work backwards: `b = y − mx` from a known point |
| Vertical slope called 0 | Run 0 means division by zero — undefined, and horizontal (rise 0) is the 0-slope case |
| Steeper always wins / starts-ahead always wins | Lesson 06 tables: read the gap at each row out loud until the crossing is visible |
| Model outputs past a physical limit treated as real | Ask "can a tank hold −15 gallons?" and require a stopping-point sentence |

## Adaptations from legacy material

- The legacy `assignments/linear-equations-lab.md` two-plan modeling
  prompt is a blank prompt with no numbers, tables, or method. This
  unit adapts its *idea* (compare two plans) into Lesson 05's
  worked example and the project, supplying numbers, a
  table-reading method, and a crossing-point interpretation. The
  legacy file itself is unchanged and remains an untaught bank.
- The legacy slope/proportional-relationship quizzes remain
  untaught practice banks with inline keys; no item was copied
  verbatim into the quiz or assessment. Where a legacy item covers
  the same skill, the unit's version was re-derived with new
  numbers (see the answer key's reconciliation notes).

## Readiness criteria

The learner is ready for Unit 05 (systems of linear equations) when
they can, without prompting: decide proportionality from any
representation; compute slope from two points with the sign right;
write `y = mx + b` from a graph or table and check it; state slope
and intercept meanings with units; and read a crossing point from a
table. A learner who can do the first three but not the last two
needs one more context session (Lesson 05/06 items), not a repeat
of the whole unit.

## Accessibility notes

- Slope may be found by counting grid steps, by a differences
  table, or by the formula — accept any correct route, and ask for
  a second route as a check rather than as a redo.
- Graph-drawing stamina: a learner may plot from a completed table
  (adult plots if motor stamina is the barrier) as long as the
  learner reads the slope and intercept from the result.
- The generated illustration and the slope diagram both ship with
  text-only alternatives carrying every number the questions need;
  no question depends on seeing the picture.
