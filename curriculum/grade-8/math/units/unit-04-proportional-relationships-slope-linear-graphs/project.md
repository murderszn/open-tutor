# Project — Two Plans, One Choice (Slope Edition)

**Time:** Sessions 12 and 14 (plus at-home drafting) · **Materials:**
notebook, pencil, ruler, graph paper, calculator for checking only,
the two-cyclists illustration from Lesson 06 if it helps you picture
two things racing.

## The task

You run a small service — tutoring, bike repair, dog walking, lawn
care, streaming lessons, or your own idea. Design **two pricing
plans** for the same service, then answer the question a customer
would actually ask: *when does each plan win?*

Your project must contain:

1. **Two plans, clearly priced.** One plan must be proportional
   (no starting fee: `y = mx`). The other must have a starting fee
   (a nonzero intercept: `y = mx + b`, with `b ≠ 0`). Name the
   service, the unit (hour, ride, walk, gigabyte — your choice),
   and both prices, with units on every rate.
2. **Tables for both plans** at the same unit counts — include 0
   and at least three nonzero counts that straddle the crossing
   point (one below it, one at it or near it, one above it). Show
   every computation.
3. **Graphs of both plans on the same axes**, each line labeled
   with its equation. Mark the crossing point and label which line
   is on top on each side of it.
4. **The crossing point and a recommendation.** State where the
   plans cost the same (from the table or graph — not by solving a
   system; Unit 05 will do that algebraically). Then recommend a
   plan for a small user, a medium user, and a large user (pick
   three unit counts), saying which plan wins each time and why.
   Write the recommendation as a customer-facing sentence, not just
   numbers.
5. **What the slope and intercept mean, for each plan.** One
   sentence each: what the slope means in the story, and what the
   intercept means in the story, for Plan 1 and for Plan 2.
6. **An edge case.** Using the same service, write a second pair of
   plans with the **same slope but different intercepts** (parallel
   lines). Show from a table that one plan is always cheaper, state
   by how much, and explain in plain language why they never cross.
   (If your main plans already have the same slope, change one
   plan's slope for this edge case and say so.)

## Steps

**Session 12 — Invent, tabulate, graph.** Choose the service and
the two prices. Check the rules: one proportional, one with a fee.
Build both tables at the same counts, choosing counts that will
show the crossing. Draw both lines on one set of axes. If your
tables show no crossing in the counts you picked, widen the counts
— a crossing must exist for plans with different slopes, so keep
looking until the table shows it.

**Session 14 — Compare and present.** Read the crossing point off
the table or graph. Write the three-user recommendation and the
slope/intercept sentences. Build the parallel-lines edge case.
Present on one page (written, poster, or spoken with notes) that a
customer could follow: the two plans, the crossing point, the
three-user recommendation, and the edge-case note.

## Worked mini-example (your numbers must differ)

Service: bike repair, unit = hour. Plan 1 (proportional):
`y = 12h`. Plan 2 (fee): `y = 8h + 20`. Table: 2 hours → $24 vs.
$36; 5 hours → $60 vs. $60 (crossing); 10 hours → $120 vs. $100.
Recommendation: under 5 hours choose Plan 1; over 5 hours choose
Plan 2. Slope meanings: Plan 1 costs $12 per extra hour; Plan 2
costs $8 per extra hour. Intercept meanings: Plan 1 has no starting
fee; Plan 2 charges $20 before any work begins. Edge case: plans
`y = 12h` and `y = 12h + 15` never cross — the second is always $15
more, because equal slopes mean the gap never changes.

## Rubric (40 points)

| Criterion | Points | What earns full marks |
|---|---|---|
| Plans priced correctly (one proportional, one with a fee, units on rates) | 10 | Both plans named with service, unit, and prices; one has intercept 0, the other nonzero; rates carry units |
| Tables at matching counts, straddling the crossing | 8 | Same counts for both plans, including 0; computations shown; a below-, at-, and above-crossing row all present |
| Graphs on shared axes, labeled, crossing marked | 8 | Both lines on one axes set, each labeled with its equation, crossing point marked, "on top" side labeled on both sides |
| Crossing point + three-user recommendation | 8 | Crossing stated from table/graph; small/medium/large recommendations correct and written as customer-facing sentences |
| Slope/intercept meanings for both plans | 4 | Four correct meaning sentences (slope and intercept, each plan), with units |
| Parallel-lines edge case | 2 | Second pair with equal slopes, table showing a constant gap, plain-language "never cross" explanation |
| **Total** | **40** | |

A project with invented numbers that do not match its own tables
or graphs loses the affected rows' points even if the ideas are
right: the numbers must agree everywhere. An adult checks the
crossing point against the tables before the presentation.
