# Answer Key — Unit 05: Systems of Linear Equations

Teacher-only. Do not hand this file to a learner. Every solution
below was worked independently and checked by substitution in both
original equations. Accept equivalent reasoning and equivalent
forms (for example, a system solved by a different valid method)
when the final pair and the checks are correct.

## Lesson 01

**Readiness check:** `2(3) + 1 = 7`, so `x = 3` is a solution.

**Guided practice**

1. `(1, 4)`: `y = 2x + 2` gives `4 = 2(1) + 2 = 4`, true;
   `y = −x + 5` gives `4 = −1 + 5 = 4`, true. **Solution.**
2. `(0, 1)`: `x + y = 5` gives `0 + 1 = 1`, not 5. **Not a
   solution** (fails the first equation).
3. `(3, 0)`: `y = −x + 3` gives `0 = −3 + 3 = 0`, true;
   `2y + x = 3` gives `2(0) + 3 = 3`, true. **Solution.**
4. `(2, 3)`: `x + y = 4` gives `2 + 3 = 5`, not 4. **Not a
   solution** (fails the first equation).
5. A pair can satisfy the first equation and fail the second, so
   one check can never prove it satisfies both.

**Independent practice**

1. `(1, 5)`: `4(1) + 1 = 5`, true; `−1 + 6 = 5`, true. **Solution.**
2. `(3, 2)`: `3 + 2 = 5`, true; `2(3) − 2 = 4`, true. **Solution.**
3. `(0, 4)`: `2(0) + 4 = 4`, true; `0 + 4 = 4`, true. **Solution.**
4. `(2, −1)`: `2 − 3 = −1`, true; `2(2) + (−1) = 3`, true.
   **Solution.**
5. `(5, 1)`: `5 + 2(1) = 7`, true; `3(5) − 14 = 1`, true.
   **Solution.**
6. `(1, 1)`: `3(1) + 1 = 4`, true; `1 − 1 = 0`, not 1. **Not a
   solution** (fails the second equation).
7. `(−2, 3)`: `−(−2) + 1 = 3`, true; `2(−2) + 3(3) = −4 + 9 = 5`,
   true. **Solution.**
8. `(0, 0)`: `y = 2x` gives `0 = 0`, true; `y = x + 1` gives
   `0 = 1`, false. **Not a solution.** The first check passes and
   the second fails, so the pair does not satisfy the system.

**Application:** one valid system is `x + y = 3` and `2x − y = 3`.
Check `(2, 1)`: `2 + 1 = 3`, true; `2(2) − 1 = 3`, true. Accept any
system both of whose equations are true at `(2, 1)`.

**Exit check:** `(4, 2)`: `y = x − 2` gives `2 = 4 − 2 = 2`, true;
`x + y = 6` gives `4 + 2 = 6`, true. **Solution.**

**Extension:** `(1, 2)` satisfies `y = 2x` (`2 = 2`) but fails
`y = x + 3` (`2 ≠ 4`). `(0, 3)` satisfies `y = x + 3` (`3 = 3`)
but fails `y = 2x` (`3 ≠ 0`). `(3, 6)` satisfies both
(`6 = 2(3)` and `6 = 3 + 3`), so it is the solution — the two
lines cross at `(3, 6)`.

## Lesson 02

**Readiness check:** points `(0, −1)` and `(2, 3)` both satisfy
`y = 2x − 1` (`−1 = −1`; `3 = 3`); the line through them is the
graph.

**Guided practice**

1. Graph `y = −x + 4` (intercept `(0, 4)`, slope `−1`) and
   `y = x − 2` (intercept `(0, −2)`, slope `1`). They cross at
   **`(3, 1)`**. Check: `1 = −3 + 4`, true; `1 = 3 − 2`, true.
2. Same slope `3`, different intercepts `−2` and `4` → parallel
   lines → **no solution**.
3. The second equation divides by 2 to `y = −x + 5`, slope `−1`,
   while the first has slope `1`. Different slopes → the lines
   cross once → **one solution**, `(0, 5)`. Check: `5 = 0 + 5`,
   true; `2(0) + 2(5) = 10`, true.

**Independent practice**

1. **`(1, 2)`**. Check: `2 = 1 + 1`, true; `2 = −2 + 3`, true.
2. Rewrite: `y = −x + 4` and `y = x`. They cross at **`(2, 2)`**.
   Check: `2 + 2 = 4`, true; `2 − 2 = 0`, true.
3. The lines appear to cross at **`(2, 2)`**. Check:
   `(1/2)(2) + 1 = 2`, true; `−2 + 4 = 2`, true. The estimate
   is confirmed exactly by the check.
4. The second equation is twice the first (`4x + 2y = 12` is
   `2(2x + y) = 2(6)`), so both equations graph the same line →
   **infinitely many solutions**.
5. **`(1, 4)`**. Check: `4 = 3(1) + 1`, true; `4 = −1 + 5`, true.
6. `(1, 4)` is the point that lies on both lines, so `x = 1`,
   `y = 4` satisfies both equations. Before calling it the
   solution, check it by substitution in both equations — a graph
   reading can be off, especially between grid lines.

**Application:** the solution is `(0, −1)`: `x = 0`, `y = −1`
makes both equations true. A graph alone is not a proof because
the crossing point is read by eye and can be misread; the
substitution check confirms it exactly.

**Exit check:** `x + 1 = −x + 3` → `2x = 2` → `x = 1`, `y = 2`.
Solution **`(1, 2)`**. Check: `2 = 1 + 1`, true; `2 = −1 + 3`,
true.

**Extension:** same slope `2/3`, different intercepts `1` and
`−2` → parallel → **no solution**. Change the second equation to
`y = (2/3)x + 1` (same slope, same intercept) → the same line →
**infinitely many solutions**.

## Lesson 03

**Readiness check:** `5x = 15`, so `x = 3`; `y = 3(3) = 9`.

**Guided practice**

1. Substitute `y = 2x + 3` into `5x − 2y = −4`:
   `5x − 2(2x + 3) = −4` → `5x − 4x − 6 = −4` → `x = 2`.
   Then `y = 2(2) + 3 = 7`. Solution **`(2, 7)`**. Check:
   `7 = 2(2) + 3`, true; `5(2) − 2(7) = 10 − 14 = −4`, true.
2. Substitute: `4x − 7 = 4x + 2` → `−7 = 2`, false. **No
   solution.** The two equations describe parallel lines with
   slope 4 and different intercepts.

**Independent practice**

1. `3x + (x − 2) = 10` → `4x = 12` → `x = 3`, `y = 1`.
   Solution **`(3, 1)`**. Check: `1 = 3 − 2`, true;
   `3(3) + 1 = 10`, true.
2. `x + (−2x + 5) = 2` → `−x = −3` → `x = 3`, `y = −1`.
   Solution **`(3, −1)`**. Check: `−1 = −2(3) + 5`, true;
   `3 + (−1) = 2`, true.
3. `(2y + 1) + 3y = 11` → `5y = 10` → `y = 2`, `x = 5`.
   Solution **`(5, 2)`**. Check: `5 = 2(2) + 1`, true;
   `5 + 3(2) = 11`, true.
4. Substitute: `2x + (−2x + 8) = 8` → `8 = 8`, always true.
   **Infinitely many solutions** — the equations describe the
   same line.
5. `2x + (5x − 3) = 11` → `7x = 14` → `x = 2`, `y = 7`.
   Solution **`(2, 7)`**. Check: `7 = 5(2) − 3`, true;
   `2(2) + 7 = 11`, true.
6. Sam's error: substituting `y = x + 1` into `2x − y = 3`
   gives `2x − (x + 1) = 3`, not `2x + x + 1 = 3` — the minus
   sign in front of `y` must distribute over the whole
   expression. Correct: `2x − x − 1 = 3` → `x = 4`, `y = 5`.
   Solution **`(4, 5)`**. Check: `5 = 4 + 1`, true;
   `2(4) − 5 = 3`, true.

**Application:** `C = 2m + 5` and `C = 3m`. Set equal:
`3m = 2m + 5` → `m = 5`, `C = 15`. The plans cost the same
after **5 movies, at $15**.

**Exit check:** `2x + (x + 6) = 21` → `3x = 15` → `x = 5`,
`y = 11`. Solution **`(5, 11)`**. Check: `11 = 5 + 6`, true;
`2(5) + 11 = 21`, true.

**Extension:** `3x + 2(2x − 5) = 4` → `7x = 14` → `x = 2`,
`y = −1`. Graphing gives the same crossing point `(2, −1)`.

## Lesson 04

**Readiness check:** adding gives `8x = 32`; the `y` terms cancel
(`2y + (−2y) = 0`).

**Guided practice**

1. Multiply the first equation by 3 (`9x + 12y = 54`) and the
   second by 4 (`8x − 12y = −20`); add: `17x = 34` → `x = 2`.
   Then `3(2) + 4y = 18` → `y = 3`. Solution **`(2, 3)`**.
   Check: `3(2) + 4(3) = 18`, true; `2(2) − 3(3) = −5`, true.
2. Add the equations: `2x = 10` → `x = 5`, `y = 2`. Solution
   **`(5, 2)`**. No multiplying is needed because the `y` terms
   are already opposites. Check: `5 + 2 = 7`, true;
   `5 − 2 = 3`, true.

**Independent practice**

1. Subtract: `x = 3`, `y = 3`. Solution **`(3, 3)`**. Check:
   `2(3) + 3 = 9`, true; `3 + 3 = 6`, true.
2. Multiply the second equation by 3: `6x + 3y = 21`; add:
   `11x = 44` → `x = 4`. Then `2(4) + y = 7` → `y = −1`.
   Solution **`(4, −1)`**. Check: `5(4) − 3(−1) = 23`, true;
   `2(4) + (−1) = 7`, true.
3. Multiply the second equation by 2: `−6x + 2y = −10`; add:
   `0 = 0`, always true. **Infinitely many solutions** — the
   second equation is `−1/2` times the first.
4. Multiply the first equation by `−2`: `−4x − 6y = −24`; add:
   `0 = −6`, false. **No solution** — the equations describe
   parallel lines.
5. Add: `3x = 12` → `x = 4`, `y = 1`. Solution **`(4, 1)`**.
   Check: `2(4) − 1 = 7`, true; `4 + 1 = 5`, true.
6. Dana's error: subtracting `3x − 3y = 8` from `2x + 3y = 7`
   gives `(2x − 3x) + (3y − (−3y)) = −x + 6y = −1`, not
   `−x + 0y = −1` — subtracting `−3y` adds `3y`. The efficient
   move is to *add*: `5x = 15` → `x = 3`. Then
   `2(3) + 3y = 7` → `y = 1/3`. Solution **`(3, 1/3)`**.
   Check: `2(3) + 3(1/3) = 7`, true; `3(3) − 3(1/3) = 8`, true.

**Application:** `x + y = 48`, `x − y = 14`. Add: `2x = 62` →
`x = 31`, `y = 17`. The numbers are **31 and 17**. Check:
`31 + 17 = 48`, true; `31 − 17 = 14`, true.

**Exit check:** add: `4x = 16` → `x = 4`. Then `4 + 2y = 11` →
`y = 7/2`. Solution **`(4, 7/2)`**. Check: `4 + 2(7/2) = 11`,
true; `3(4) − 2(7/2) = 12 − 7 = 5`, true.

**Extension:** add: `12x = 24` → `x = 2`. Then `14 + 2y = 16`
→ `y = 1`. Solution `(2, 1)`; substitution gives the same point.

## Lesson 05

**Readiness check:** `y = −x + 4`; slope `−1`, intercept `4`.

**Guided practice**

1. Elimination by adding: `3x = 15` → `x = 5`, `y = 5`.
   Solution **`(5, 5)`**. Check: `5 + 5 = 10`, true;
   `2(5) − 5 = 5`, true.
2. Substitution: `3x + 2(−x + 7) = 12` → `x + 14 = 12` →
   `x = −2`, `y = 9`. Solution **`(-2, 9)`**. Check:
   `9 = −(−2) + 7`, true; `3(−2) + 2(9) = 12`, true.

**Independent practice**

1. Same left side, different right sides → **no solution**.
   `2x + y` cannot be both 3 and 9.
2. The second equation is twice the first (`2y = 10x` is
   `2(y) = 2(5x)`) → the same line → **infinitely many
   solutions**.
3. Elimination by adding: `5x = 15` → `x = 3`, `y = 7`.
   Solution **`(3, 7)`**. Check: `4(3) − 7 = 5`, true;
   `3 + 7 = 10`, true.
4. Substitute: `4x − 2(2x − 3) = 6` → `6 = 6`, always true.
   **Infinitely many solutions.**
5. Elimination by adding: `3x = 15` → `x = 5`, `y = 1`.
   Solution **`(5, 1)`**. Check: `2(5) + 1 = 11`, true;
   `5 − 1 = 4`, true.
6. Not always true. Counterexample: `y = 2x + 1` and `y = 2x + 1`
   have the same slope and the same intercept — they are the same
   line, so the system has infinitely many solutions, not none.
   The rule needs the intercept too: same slope *and different*
   intercepts means no solution.

**Application:** sample system: `y = 2x + 1` and `y = −x + 7`.
Substitution: `2x + 1 = −x + 7` → `x = 2`, `y = 5`. Change the
second equation to `y = 2x + 5`: now both lines have slope 2 with
different intercepts (1 and 5), so the new system has **no
solution**. Accept any valid pair of systems with the same
structure.

**Exit check:** divide the second equation by 2: `2x + y = 7/2`,
so `y = −2x + 7/2`. Same slope `−2` as the first equation,
different intercepts (`3` vs. `7/2`) → parallel lines → **no
solution**.

**Extension:** slopes `3` and `3`, intercepts `1` and `1` → the
same line → **infinitely many solutions**. Intercepts `1` and
`−4` → parallel lines → **no solution**.

## Lesson 06

**Readiness check:** cost expression `20 + 5g`; `20 + 5g = 35 + 2g`
→ `g = 5`, cost `5(5) + 20 = $45`.

**Guided practice**

1. System: `2t + 3v = 21`, `2t + 4v = 24`. Subtract the first
   from the second: `v = 3`. Then `2t + 3(3) = 21` → `t = 6`.
   One laser-tag game costs **$6**; one VR round costs **$3**.
   Check: `2(6) + 3(3) = 21`, true; `2(6) + 4(3) = 24`, true.

**Independent practice**

1. Let `s` = student tickets, `a` = adult tickets.
   `s + a = 200`, `5s + 10a = 1450`. Multiply the first by `−5`
   and add: `5a = 450` → `a = 90`, `s = 110`. **110 student
   tickets and 90 adult tickets.** Check:
   `110 + 90 = 200`, true; `5(110) + 10(90) = 550 + 900 = 1450`,
   true.
2. Let `x` = pounds of $8 beans, `y` = pounds of $14 beans.
   `x + y = 30`, `8x + 14y = 300`. Multiply the first by `−8`
   and add: `6y = 60` → `y = 10`, `x = 20`. **20 pounds of the
   $8 beans and 10 pounds of the $14 beans.** Check:
   `20 + 10 = 30`, true; `8(20) + 14(10) = 160 + 140 = 300`,
   true.
3. Downstream speed `c + w = 24/2 = 12` mph; upstream speed
   `c − w = 24/4 = 6` mph. Add: `2c = 18` → `c = 9` mph,
   `w = 3` mph. The canoe's speed in still water is **9 mph**;
   the current is **3 mph**. Check: `9 + 3 = 12`, true;
   `9 − 3 = 6`, true.
4. `x + y = 48`, `x − y = 14`. Add: `2x = 62` → `x = 31`,
   `y = 17`. The numbers are **31 and 17**.
5. No solution means the two cost lines are parallel: one gym is
   cheaper at every number of months, so there is no month where
   they tie. The cheaper gym is always the better deal on price
   alone; the choice is made on other factors.

**Application:** red truck `C = 4m + 15`; teal truck `C = 2m + 25`.
Set equal: `4m + 15 = 2m + 25` → `m = 5`, `C = 35`. The daily
costs are equal after **5 meals, at $35**. On a 10-meal day the
red truck costs `4(10) + 15 = $55` and the teal truck costs
`2(10) + 25 = $45`, so the **teal truck is cheaper by $10**.

**Exit check:** `8 + 3m = 14 + m` → `2m = 6` → `m = 3`,
`C = 8 + 3(3) = $17`. The plans cost the same after **3 movies
per month, at $17**.

**Extension:** taxi `C = 2m + 3`, rideshare `C = m`. Set equal:
`2m + 3 = m` → `m = −3`. A negative distance is impossible, so
the lines cross outside the real situation: for every real trip
the rideshare is cheaper. At 0 miles the taxi costs $3 and the
rideshare costs $0.
