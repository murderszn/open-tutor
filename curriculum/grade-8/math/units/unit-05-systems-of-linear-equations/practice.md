## Review — Error-analysis clinic (Session 13)

Each item shows a flawed solution. Find the error, name the move
that broke the work, and give the corrected solution with a check.

1. **Flawed:** `y = 2x − 1` and `y = −x + 5`. "The lines cross at
   `(2, 3)`. Check: `3 = 2(2) − 1 = 3`, and `3 = −2 + 5 = 3`. So
   `(3, 2)` is the solution."
2. **Flawed:** `x + y = 10` and `2x − y = 5`. "Add: `3x = 5`, so
   `x = 5/3`."
3. **Flawed:** `y = 3x` and `x + y = 12`. "Substitute: `x + 3 = 12`,
   so `x = 9` and `y = 27`."
4. **Flawed:** `2x + y = 4` and `4x + 2y = 10`. "Multiply the first
   equation by 2: `4x + 2y = 8`. Subtract: `0 = 2`, so there are
   infinitely many solutions."
5. **Mixed set (solve and check):**
   a. Solve by graphing (sketch or describe the lines):
      `y = x − 1` and `y = −2x + 5`.
   b. Solve by substitution: `y = 5x − 2` and `3x + y = 22`.
   c. Solve by elimination: `4x − y = 9` and `2x + y = 3`.
   d. Classify: `5x + 2y = 11` and `10x + 4y = 22`. Explain.
   e. Two gyms: Gym A charges a $30 joining fee plus $25 per
      month; Gym B charges a $10 joining fee plus $35 per month.
      After how many months do the gyms cost the same, and what is
      that cost?

## Reference — The three cases

- Different slopes → the lines cross once → **one solution**.
- Same slope, different intercepts → parallel lines →
  **no solution**.
- Same slope and same intercept → the same line →
  **infinitely many solutions**.
- In algebra: solving leaves `x = a` → one solution; a true
  statement like `8 = 8` → infinitely many; a false statement
  like `−7 = 2` → no solution.
