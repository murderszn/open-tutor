# Unit Assessment — Unit 05: Systems of Linear Equations

**Grade:** 8 · **Subject:** Mathematics · **Unit:** 05 — Systems of
Linear Equations · **Track week:** 22 · **Points:** 30

**Instructions:** Complete all questions. Show your work
step-by-step. Exact answers (simplified fractions where they occur)
are preferred unless decimal rounding is specified. Check every
solution in both original equations. The answer key is separate —
do not work from it. This assessment is not standardized or
validated; it measures the objectives of this unit only.

---

## Questions

### Question 1 (2 points)

Test whether `(3, 4)` is a solution of the system `y = x + 1` and
`2x − y = 2`. Then test whether `(1, 2)` is a solution of the same
system. Show both checks for each pair.

### Question 2 (3 points)

Solve the system by graphing:

`y = 3x − 5`

`y = −x + 3`

Sketch both lines (or describe the graph), state the solution, and
check it by substitution in both equations.

### Question 3 (3 points)

Solve the system by substitution:

`y = 3x + 2`

`2x − y = −4`

Show the substitution step, the one-variable equation, the
back-substitution, and the check in both original equations.

### Question 4 (3 points)

Solve the system by elimination:

`3x + 2y = 16`

`x − 2y = 0`

Show the add/subtract step, the back-substitution, and the check in
both original equations.

### Question 5 (4 points)

Classify each system, without fully solving it. For each, state how
many solutions it has and explain why in one sentence.

a. `y = −4x + 2` and `2y = −8x + 4`

b. `3x + y = 8` and `3x + y = 1`

### Question 6 (6 points)

A movie theater sold 150 tickets to a film, raising $1,080. Adult
tickets cost $9 each and child tickets cost $6 each. Let `a` be the
number of adult tickets sold and `c` the number of child tickets
sold.

a. Write the system of equations. (2 points)

b. Solve the system. (2 points)

c. State how many adult tickets and how many child tickets were
sold, and check the money total. (2 points)

### Question 7 (3 points)

The sum of two numbers is 73. Their difference is 21. Write the
system, solve it by elimination, and name the two numbers.

### Question 8 (3 points)

Choose the most efficient method and solve:

`y = −2x + 9`

`5x + 2y = 21`

Name the method you chose, explain why it is the efficient choice
for this system, and check your answer in both equations.

### Question 9 (3 points)

Design a system of two linear equations whose only solution is
`(4, −2)`. Write the system, then prove `(4, −2)` is its solution
by testing it in both equations, and explain in one sentence how
you know it is the *only* solution.
