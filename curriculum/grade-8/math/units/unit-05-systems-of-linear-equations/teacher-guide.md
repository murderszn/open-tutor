# Teacher Guide — Unit 05: Systems of Linear Equations

## Session-by-session guidance

| Session | Focus | Watch for | If stuck |
|---|---|---|---|
| 1 (L1) | Testing ordered pairs; both checks | Stopping after the first equation passes | Require the second check line on every item; the "two locks, one key" image |
| 2 (Practice A) | Substitution-check fluency | Sign errors in the second equation | Slow down: compute one equation fully before starting the other |
| 3 (L2) | Graphing systems; intersection | Reading the intersection as `(y, x)`; treating an estimate as exact | Point to the dot in Figure 1 and read `x` first; insist on the substitution check |
| 4 (Practice B) | Graph-and-classify fluency | Parallel vs. same-line confusion | Slope *and* intercept check, every time |
| 5 (L3) | Substitution | Substituting without parentheses; losing a minus sign | Parentheses around every substituted expression; check catches the slip |
| 6 (Practice C) | Substitution fluency | Back-substituting into the wrong equation | Either original equation works — but it must be an *original* one, not the substituted form |
| 7 (L4) | Elimination | Multiplying only some terms; subtracting without flipping signs | "Multiply every term, including the constant"; write subtraction as "add the opposite" |
| 8 (Practice D) | Elimination fluency | Choosing elimination when substitution is easier (or vice versa) | Ask: "which variable is already alone?" before choosing |
| 9 (L5) | Inspection; method choice | "Same slope means no solution" over-generalization | Two-part check: slope *and* intercept |
| 10 (Practice E) | Inspection + construction | Building a "no solution" pair that actually has one | Test the constructed pair by solving; the false statement `a = b` must appear |
| 11 (L6) | Real-world modeling | Variables with no stated meaning; one equation used twice | "Let" sentence with units before any equation; each equation matches one fact |
| 12 (Project 1) | Invent and solve | Plans with no fixed part and no per-unit part (a constant, not a plan) | Require both parts named, even if one is $0 |
| 13 (Review) | Error clinic | Defending the flawed move instead of finding it | Ask: "which move broke the balance?" not "what's the answer?" |
| 14 (Project 2) | Data table; variants; present | Reading the table's slope wrong (cost change per meal) | Compute the change between two rows before writing the equation |
| 15 (Quiz) | Formative check | Missing substitution checks | Return to the matching practice session per the quiz guide below |
| 16 (Assessment) | Culminating check | Rushing the open-response items | Items 6, 8, 9 carry rubric credit — time is allocated for them |

## Misconceptions and reteaching moves

1. **"It passed one equation, so it's the solution."** Reteach with
   Lesson 01's two-locks image: a key must open *both* locks. Use
   Practice A item 8 (Mia's error) as the anchor example.
2. **"The lines cross, so the answer is `(y, x)`."** Reteach:
   ordered pairs are always `(x, y)` — across first, then up. The
   substitution check catches a swap immediately, so require it.
3. **"Substituting means dropping the expression in as-is."**
   Reteach: the substituted expression is a *quantity* in
   parentheses. `2x − y` with `y = x + 1` becomes `2x − (x + 1)`,
   and the minus distributes. Practice C item 7 is the drill.
4. **"Elimination means always adding."** Reteach: add when terms
   are opposite, subtract when they are equal, multiply first when
   neither is true. Lining the equations up in columns makes the
   choice visible.
5. **"Same slope means no solution."** Reteach: same slope *and*
   different intercepts means no solution; same slope *and* same
   intercept means infinitely many. Lesson 05's extension is the
   drill.
6. **"A negative answer must be wrong."** Reteach: a negative
   *coordinate* can be a fine answer (Practice D item 6 gives
   `x = −1`); a negative *count of tickets* cannot. The check is
   against the situation, not the sign.

## Readiness and reteaching

**Ready for Unit 06 if the learner can:** test an ordered pair in
both equations without prompting; solve a system by substitution
and by elimination with checks; classify a system by inspection;
and write and solve a two-equation word problem with units in the
answer.

**If substitution is insecure:** return to Lesson 03 with the
one-variable warm-up (solve `2x + 3x = 15`, then find `y = 3x`)
and require parentheses on every substitution for a full session.

**If elimination is insecure:** return to Lesson 04 worked example
1 and practice adding equations with opposite terms only, then add
the multiply-first step as a separate session.

**If graphing is insecure:** return to Unit 04's slope-intercept
work and Lesson 02, graphing each line separately on its own axes
before combining them on one set of axes.

**If modeling is insecure:** return to Lesson 06 and require the
"let" sentence and the two-column plan table before any equation
is written; use the phone-plan worked example as the template.

## Quiz and assessment guidance

- **Quiz (10 points):** Q1 checks the meaning (8.EE.C.8.a); Q2
  graphing; Q3 testing; Q4 substitution; Q5 elimination; Q6
  inspection; Q7 modeling; Q8 method choice. A miss on Q3 usually
  means the second check was skipped — return to Practice A. A
  miss on Q6 usually means the slope-intercept comparison was not
  done — return to Lesson 05.
- **Assessment (30 points):** Q1–Q2 cover 8.EE.C.8.a; Q3–Q5 cover
  8.EE.C.8.b; Q6–Q9 cover 8.EE.C.8.c and method choice. Q9 is
  rubric-scored: 1 point for a valid system, 1 point for correct
  testing in both equations, 1 point for the uniqueness explanation
  (different slopes → the lines cross once). Partial credit follows
  the same split.
- **Scoring note:** an answer with no check earns at most half
  credit on that item; the check is part of the method, not an
  optional extra.
