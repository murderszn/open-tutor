# Formative Quiz — Unit 03, Week 14

**Student-facing.** Show every move. Finish each item with a
substitution check in the original equation. For classification
items, show the transforming steps and box the final form.
Solutions are in the separate unit answer key — this page contains
no answers.

1. Solve for `x`: `7x + 9 = 44`.
2. Solve for `x`: `3(2x − 5) = 27`.
3. Solve for `x`: `5x − 8 = 2x + 19`.
4. Solve for `x`: `4(x + 3) − 2x = 22`.
5. Classify: `6x + 4 = 6(x + 2)`. Show the transforming steps.
6. Classify: `3(2x − 1) = 6x − 3`. Show the transforming steps.
7. Solve for `x`: `(2/5)x + 7 = 11`.
8. Solve for `x`: `0.5x − 3 = 9`.
9. A taxi charges a $3 pickup fee plus $2 per mile. A ride costs $17.
   How many miles was the ride? Write the equation, solve it, and
   check.
10. **Error analysis:** Lee solved `4(x − 2) = 12` as follows:
    "`4x − 2 = 12`, so `4x = 14`, so `x = 3.5`." Find Lee's error,
    explain why it breaks equality, and give the correct solution
    with a check.

**How to use the result:** 8–10 items correct with checks shown means
ready for the unit assessment. Fewer than 8, or missing checks,
means re-work the matching practice session first: items 1–2 →
Practice B, items 3–4 → Practice C, items 5–6 → Practice D, items
7–8 → Practice E, item 9 → Lesson 06, item 10 → Review clinic.
