# Unit Assessment — Unit 03: Linear Equations and Solution Types

**Student-facing.** Show every move. Check each numerical answer by
substitution in the original equation. For classification and
construction items, show the transforming steps. Open-response items
are scored on reasoning, not on matching one exact sentence.
Solutions and scoring guidance are in the separate unit answer key —
this page contains no answers.

## Part A — Solve (items 1–4, 7–8)

1. Solve for `x`: `8x − 13 = 27`.
2. Solve for `x`: `4(2x − 3) = 28`.
3. Solve for `x`: `9x + 4 = 3x + 28`.
4. Solve for `x`: `2(x − 5) + 3x = 25`.
5. (Classification — see Part B.)

## Part B — Classify (items 5–6)

5. Classify `7x − 3 = 7x + 8` (one solution / no solution /
   infinitely many solutions). Show the transforming steps and box
   the final form.
6. Classify `2(4x + 3) = 8x + 6`. Show the transforming steps and
   box the final form.

## Part C — Rational coefficients (items 7–8)

7. Solve for `x`: `(3/4)x − 5 = 7`.
8. Solve for `x`: `1.5x + 2.5 = 10`.

## Part D — Construct (item 9)

9. Write one original equation with **no solution** and one original
   equation with **infinitely many solutions**. For each, show the
   transforming steps that prove the classification. (Your equations
   must differ from every example in the lessons.)

## Part E — Model (items 10–11)

10. Two gyms: Gym A charges a $30 joining fee plus $25 per month.
    Gym B charges $55 per month with no joining fee. After how many
    months do they cost the same? What is that cost? Write the
    equation, solve it, and check in both cost expressions.
11. A rectangle's length is 3 meters more than twice its width, and
    its perimeter is 36 meters. Find the width and the length. Write
    the equation, solve it, and check.

## Part F — Analyze (items 12–14)

12. **Error analysis:** Ana solved `5x − 2(x + 3) = 11` as follows:
    "`5x − 2x + 3 = 11`, so `3x = 8`, so `x = 8/3`." Find Ana's error,
    explain why it breaks equality, and give the correct solution
    with a check.
13. **Challenge:** Solve `(1/3)(2x + 9) − x = 5`. Show every move and
    check in the original equation.
14. **Explain:** Why does simplifying an equation to `5 = 5` prove
    that every number is a solution, while simplifying to `x = 5`
    proves that only 5 is? Answer in 3–5 sentences, using the idea
    that the simplified statement is true or false regardless of
    what `x` was.

**Scoring note for the adult:** items 1–8 and 10–11 are scored
correct/incorrect with partial credit for correct moves with an
arithmetic slip if the check catches it. Items 9, 12, and 14 are
scored with the rubric in the teacher guide. Item 13 is a challenge
item: full credit for a correct solution, no penalty for an
attempted-but-incomplete solution beyond the item itself.
