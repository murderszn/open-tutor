# Teacher Guide — Unit 03: Linear Equations and Solution Types

## Session-by-session guidance

| Session | Focus | Watch for | If stuck |
|---|---|---|---|
| 1 (L1) | Testing values; substitution checks | Treating any number in the equation as a solution; skipping checks | Return to the balance-scale diagram; require the check line on every item |
| 2 (Practice A) | Substitution fluency | Sign errors inside parentheses | Slow down: compute the parentheses first, out loud |
| 3 (L2) | Distribute, collect, solve | Distributing to only the first term; `−2(x − 1)` sign | Arrow-drawing from the outside factor to every inside term |
| 4 (Practice B) | Multi-step fluency | Dropping the constant when collecting | Circle each term before combining; re-check with substitution |
| 5 (L3) | Variables on both sides | Teleporting terms; sign flips | Require "subtract ___ from both sides" sentences |
| 6 (Practice C) | Both-sides fluency | Adding the variable term instead of subtracting | Balance demonstration: remove the same tiles from both sides |
| 7 (L4) | Three solution types | `0 = 0` read as "no solution"; stopping before `x` is gone | Test-two-values move; the three-line chant |
| 8 (Practice D) | Classify and construct | Asserting a classification without transforming steps | Box-the-final-form rule: no box, no credit |
| 9 (L5) | Rational coefficients | Clearing denominators but missing a term; checking in the cleared equation | Check line must copy the original equation |
| 10 (Practice E) | Efficient first moves | Always distributing, even when dividing first is cleaner | Compare both paths on the same problem (Practice E item 7) |
| 11 (L6) | Modeling | Swapped fixed/per-unit parts; "−3 baskets" reports | Two-column plan/expression table before the equation |
| 12 (Project 1) | Invent and solve | Plans with no fixed part and no per-unit part (a constant, not a plan) | Require both parts named, even if one is $0 |
| 13 (Review) | Error clinic | Defending the flawed move instead of finding it | Ask: "which move broke the balance?" not "what's the answer?" |
| 14 (Project 2) | Classify and present | Variant pairs that are actually the same pair | Check: one variant must end `a = a`, the other `a = b` |
| 15 (Quiz) | Formative check | Missing substitution checks | Return to the matching practice session per the quiz guide |
| 16 (Assessment) | Culminating check | Rushing the open-response items | Items 9, 12, 14 carry rubric credit — time is allocated for them |

## Misconceptions and reteaching moves

1. **"Distribute to the first term only."** Reteach: `3(x + 4)` means
   three groups of `(x + 4)` — write `x + 4 + x + 4 + x + 4` once,
   then collect. Use arrow diagrams until the habit sticks.
2. **"Moving a term changes its sign automatically."** Reteach with
   properties of equality: nothing "moves"; you add or subtract the
   same thing from both sides. The sign change is a consequence of
   adding the opposite, not magic.
3. **"`0 = 0` means no solution."** Reteach: `0 = 0` is true. A true
   statement that no longer mentions `x` is true for every `x`.
   Contrast with `0 = 5`, which is false for every `x`.
4. **"No solution means I failed."** Reteach with Lesson 06's stalls:
   two plans that never cost the same are a real, useful finding.
   Grade the proof (the transforming steps), not the "niceness" of
   the answer.
5. **"Checking is optional once I'm confident."** Reteach: the check
   is part of the solution in this unit. An unchecked answer is an
   unfinished answer, including on the assessment (partial credit
   only).
6. **"A negative answer to a word problem is fine."** Reteach: check
   the model against the domain. A negative number of baskets means
   the story was translated wrong or the break-even point lies
   outside the situation — both are worth discussing, neither is
   reported as "−3 baskets."

## Readiness criteria

The learner is ready for Unit 04 (proportional relationships, slope,
linear graphs) when they can, without prompting: solve a multi-step
equation with distribution and rational coefficients; classify an
equation by its final form and defend the classification; and write
and solve a one-variable equation from a short description. A quiz
score of 8–10 with checks shown, plus a project rubric of 3+ on each
criterion, is the usual evidence.

## Re-teach paths

- **Distribution/sign errors dominate:** one extra session on
  Lessons 02–03 items only, with arrow diagrams and color-coded
  terms, before Lesson 04.
- **Classification errors dominate:** one extra session sorting
  pre-written equations into the three piles by final form, with the
  three-line chant, before Lesson 05.
- **Modeling errors dominate:** one extra session of two-column
  plan/expression tables with no solving at all — translation
  practice only — before the project.
- **Fraction/decimal arithmetic dominates:** a fraction-skills
  session (reciprocals, clearing denominators) before Lesson 05's
  independent set; keep the algebra intact.

## Scoring guidance for open responses

- **Assessment item 9 (construct):** full credit requires two
  original equations, correct classifications, and transforming
  steps ending in `a = a` / `a = b`. An equation copied from a
  lesson earns at most half credit.
- **Assessment item 12 (error analysis):** full credit names the
  exact move (distributing `−2` across `+3` gave `+3` instead of
  `−6`), explains the break, and gives the corrected solution
  `x = 17/3` with a check.
- **Assessment item 14 (explain):** full credit explains that the
  simplified statement no longer depends on `x`, so its truth value
  is fixed: true (`5 = 5`) means every `x` works; `x = 5` still
  depends on `x`, so only 5 works. Accept any correct version of
  this argument in 3–5 sentences.
- **Project:** use the rubric in `project.md`. A project with a
  correct break-even but no variant proofs scores at most 2 on the
  classification criterion.

unit does not replace or edit them, and the unit's own quiz and
assessment are new.

## Differentiation

- **Support:** fewer items per set (odds only), calculator for
  arithmetic after moves are written, color-coded terms, oral
  move-naming with adult scribing, algebra tiles for Lessons 02–03.
- **Extension:** the extension items in each lesson; a third plan
  added to the project (three-way break-even comparison); proving
  that clearing denominators never changes the solution set when
  the multiplier is nonzero.
