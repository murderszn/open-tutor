# Unit 03 — Linear Equations and Solution Types

**Grade:** 8 · **Subject:** Mathematics · **Track weeks:** 11–14
**Backlog:** [issue #38](https://github.com/murderszn/open-tutor/issues/38), section U03
**Status:** validated draft (this unit); not educator-reviewed, not merged

An equation is a question: which number, if any, makes both sides equal?
Sometimes exactly one number works. Sometimes every number works.
Sometimes no number works at all. In this unit the learner solves
multi-step linear equations in one variable — distributing, collecting
like terms, and handling rational coefficients — and learns to tell the
three cases apart by transforming an equation until it reads
`x = a`, `a = a`, or `a = b`. The unit ends with real pricing and
measurement problems, where "no solution" and "infinitely many solutions"
turn out to mean something concrete: two plans that never cost the same,
or two plans that are secretly the same plan.

## Essential question

How do we know whether an equation has one solution, infinitely many
solutions, or no solution — and what does each case mean in a real
situation?

## Prerequisites

From the diagnostic weeks, grade 7, and Units 01–02:

- Adding, subtracting, multiplying, and dividing integers, fractions,
  and decimals; simplifying fractions
- The distributive property: `a(b + c) = ab + ac`, including with
  negative multipliers
- Combining like terms; order of operations
- Solving one- and two-step equations; checking a solution by
  substitution (Unit 01 readiness; Unit 02 equation warm-ups)
- Evaluating expressions for a given value of the variable

No graphing of two-variable equations is required before this unit;
that arrives in Unit 04. Function language is not used here.

## Measurable objectives

By the end of the unit the learner will be able to (adult-observed):

1. Solve multi-step linear equations in one variable with rational
   coefficients, using the distributive property and collecting like
   terms, and verify each solution by substitution.
2. Solve equations with the variable on both sides, justifying each
   move with a property of equality, and choose an efficient first move
   (distribute first vs. divide first) with a reason.
3. Classify a linear equation as having one solution, infinitely many
   solutions, or no solution by transforming it to `x = a`, `a = a`, or
   `a = b`, and explain what the final form shows.
4. Construct original examples of each solution type and prove the
   classification by showing the transforming steps.
5. Write a one-variable linear equation from a real-world description,
   solve it, and interpret the solution — including a no-solution or
   infinitely-many-solutions result — in the context.
6. Find and correct errors in a flawed solution, naming the exact move
   that broke equality and showing the corrected steps.

## Accessibility

Every check accepts written, oral, or drawn responses; the adult
scribes when writing stamina is the barrier rather than the math. Each
lesson includes a language-access support, an alternate response mode,
and an extension. The balance-scale diagram and the two-stalls
illustration both ship with text-only alternatives carrying every
number the questions need. Equation work may be done with color-coded
terms (one color per side) or with physical algebra tiles as an
alternate representation; the classification rule (final form
`x = a` / `a = a` / `a = b`) is also taught as a chantable three-line
check for oral rehearsal.
