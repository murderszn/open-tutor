# Project — Two Plans, One Choice

**Time:** Sessions 12 and 14 (plus at-home drafting) · **Materials:**
notebook, pencil, calculator for checking only, the two-stalls
illustration from Lesson 06 if it helps you picture your plans.

## The task

You run a small business at a fair — or you offer a service such as
tutoring, bike repair, or streaming lessons. Design **two pricing
plans** for the same service, then answer the question a customer
would actually ask: *when does each plan win?*

Your project must contain:

1. **Two plans, clearly priced.** Each plan has a fixed part (possibly
   $0) and a per-unit part. Name the service, the unit (basket,
   hour, session, gigabyte — your choice), and both prices.
2. **The break-even equation and its solution.** Let the variable
   stand for the number of units, write both cost expressions, set
   them equal, solve with all moves shown, and check by substitution
   in both expressions.
3. **A recommendation.** For a small user, a medium user, and a large
   user (pick three unit counts), compute both costs in a table and
   say which plan wins each time and why. State the break-even point
   in a customer-facing sentence.
4. **Two variant pairs.** Using the same service, write:
   - a pair of plans that **never** cost the same (no solution), and
   - a pair of plans that **always** cost the same (infinitely many
     solutions).
   Show the transforming steps that prove each classification, and
   write one sentence explaining each variant in plain language.
5. **A presentation.** One page (written, poster, or spoken with
   notes) that a customer could follow: the two plans, the
   break-even point, the three-user table, and the recommendation.
   Include the variant pairs as a short "edge cases" note.

## Steps

**Session 12 — Invent and solve.**

1. Choose your service and unit. Write both plans as a two-column
   table (plan / fixed part / per-unit part).
2. Write both cost expressions and the break-even equation.
3. Solve it, check both expressions, and build the three-user table.
4. Draft the recommendation sentence.

**Between sessions — Draft.**

Write the variant pairs and their proofs. Draft the presentation page.

**Session 14 — Classify and present.**

1. Finish the variant proofs and plain-language explanations.
2. Present your page to the adult. Answer one "what if" question:
   the adult changes one price — recompute the break-even point on
   the spot (or explain why the classification changes).
3. Revise one sentence of your recommendation based on feedback.

## Deliverables

- Plan table with prices and units named.
- Break-even equation with moves, solution, and both-expression check.
- Three-user cost table and recommendation sentence.
- Two variant pairs with transforming-step proofs and plain-language
  explanations.
- One presentation page.

## Rubric

| Criterion | 4 — Strong | 3 — Solid | 2 — Developing | 1 — Starting |
|---|---|---|---|---|
| Correct equations and solutions | Both plans expressed correctly; break-even solved with all moves and verified in both expressions | One small arithmetic slip, caught by the check; moves shown | Missing moves or an unverified answer; equation setup mostly right | Equations do not match the plans, or no check |
| Interpretation | Recommendation follows from the table for all three users; break-even sentence is customer-clear | Recommendation follows for most users; sentence mostly clear | Recommendation asserted without table evidence | No recommendation, or one contradicting the table |
| Classification of variants | Both variant pairs correct, proved by transforming steps, with plain-language explanations | One variant correct and proved; the other attempted | Variants present but classifications asserted without proof | Variants missing or both misclassified |
| Communication | Presentation page is complete, ordered, and readable by a customer | Page complete with minor gaps | Page partial or hard to follow | No presentation page |

**Ready signals:** the break-even answer is verified in both cost
expressions; the three-user table agrees with the recommendation;
each variant's final form (`a = a` or `a = b`) is boxed and named.

**Re-teach moves:** if the break-even equation is set up backwards
(fixed and per-unit parts swapped), return to Lesson 06's two-column
table habit. If a variant proof stops before `x` disappears,
revisit Lesson 04's "transform until `x` is gone or alone" rule.
