# Answer Key — Unit 03: Linear Equations and Solution Types

**Teacher-only.** Keep separate from student materials. Every item
below was solved independently and checked by substitution in the
original equation. Where an item asks for explanation, the key gives
the acceptable reasoning and notes acceptable variation.

## Lesson 01

**Readiness:** `3(4) + 5 = 17`.

**Guided practice:**
1. `5(7) − 8 = 27`. ✓ Solution.
2. `x = 3`: `4(3) + 9 = 21`. ✓ Solution. `x = 4`: `4(4) + 9 = 25 ≠ 21`.
   Not a solution.
3. `2(−3) + 10 = 4`. ✓ Solution.
4. `3(6 + 2) = 24`. ✓ Solution.
5. `2 + 9 = 11 ≠ 12`, so `x = 2` cannot be a solution — the left side
   is already fixed at 11.

**Independent practice:**
1. `7(5) − 9 = 26`. ✓
2. `3(−4) + 20 = 8`. ✓
3. `2(8 − 5) = 6`. ✓
4. `2(3 − 5) = −4 ≠ 6`. Not a solution. Together with item 3: only
   `y = 8` (of the two tested) works; testing one value says nothing
   about other values.
5. `10/2 + 7 = 12`. ✓
6. `12/2 + 7 = 13 ≠ 12`. Not a solution.
7. `20(5) + 15 = 115`. ✓ Yes, 5 months gives $115.
8. Maya is not justified: one successful test shows that value is a
   solution, not that it is the *only* solution. (In fact
   `4x + 3 = 7` does have exactly one solution, `x = 1`, but that
   takes solving or a uniqueness argument to establish — the single
   test alone does not prove it. Accept any answer making this
   distinction.)

**Application:** answers vary; check both substitutions.

**Exit check:** `2(6) + 7 = 19`. ✓ Yes, `x = 6` is a solution.

**Extension:** `x = 9`: `3(9) − 4 = 23` and `2(9) + 5 = 23`. ✓
Testing is slow because each test covers only one value; solving
moves find the value directly.

## Lesson 02

**Readiness:** `3x + 12`; `7x − 7`.

**Guided practice:**
1. `4(x − 2) = 20` → `x − 2 = 5` → `x = 7`. Check: `4(5) = 20`. ✓
2. `8x − 4 = 28` → `x = 4`. Check: `32 − 4 = 28`. ✓
3. `10x + 6 = 34` → `x = 14/5 = 2.8`. Check: `2(14 + 3) = 34`. ✓
4. `5x + 9 = 34` → `x = 5`. Check: `35 − 10 + 9 = 34`. ✓
5. `3(x + 2) = 3x + 6` only simplifies the left side; no equation has
   been solved. You still need a right side and further moves to
   isolate `x`.

**Independent practice:**
1. `6x + 18 = 42` → `x = 4`. Check: `6(7) = 42`. ✓
2. `8x − 6 = 26` → `x = 4`. Check: `12 + 20 − 6 = 26`. ✓
3. `10x − 15 = 35` → `x = 5`. Check: `5(7) = 35`. ✓
4. `3x + 9 = 30` → `x = 7`. Check: `28 + 9 − 7 = 30`. ✓
5. `5x + 14 = 47` → `x = 33/5 = 6.6`. Check: `2(13.6) + 19.8 = 47`. ✓
6. `8 − 2x + 2 = 2` → `10 − 2x = 2` → `x = 4`. Check:
   `8 − 2(3) = 2`. ✓
7. `10x − 15 = 43` → `x = 29/5 = 5.8`. Check:
   `3(18.2) − 11.6 = 43`. ✓
8. Both are correct. Neither method is "better" in general: dividing
   first is shorter here because 28 is divisible by 4; distributing
   first is safer when the division is not clean. Accept reasoned
   preferences either way.

**Application:** `2(3x + 3) = 54` → `6x + 6 = 54` → `x = 8`.
Width 8 m, length `2(8) + 3 = 19` m. Check: `2(8 + 19) = 54`. ✓

**Exit check:** `x − 4 = 5` → `x = 9`. Check: `5(5) = 25`. ✓

**Extension:** `6x + 3 − 4x + 8 = 23` → `2x + 11 = 23` → `x = 6`.
Check: `3(13) − 4(4) = 39 − 16 = 23`. ✓

## Lesson 03

**Readiness:** `x = 7`; check `23 = 23`. ✓

**Guided practice:**
1. `7x − 5 = 3x + 15` → subtract `3x`: `4x − 5 = 15` → `x = 5`.
   Check: `30 = 30`. ✓
2. `8y − 6 = 5y + 12` → `3y = 18` → `y = 6`. Check: `42 = 42`. ✓
3. `9x + 2 = 5x + 22` → `4x = 20` → `x = 5`. Check: `47 = 47`. ✓
4. `6x − 8 = 2x + 4` → `4x = 12` → `x = 3`. Check: `10 = 10`. ✓
5. Acceptable: subtracting `3x` from both sides keeps the scale
   balanced because both sides change by the same amount; the new
   equation has the same solution set as the old one.

**Independent practice:**
1. `3x = 18` → `x = 6`. Check: `41 = 41`. ✓
2. `3x = 21` → `x = 7`. Check: `53 = 53`. ✓
3. `3x + 12 = 2x + 20` → `x = 8`. Check: `36 = 36`. ✓
4. `15 = 3x` → `x = 5`. Check: `29 = 29`. ✓
5. `6x − 10 = x + 15` → `5x = 25` → `x = 5`. Check: `20 = 20`. ✓
6. `6x = 30` → `x = 5`. Check: `43 = 43`. ✓
7. `8x − 12 = 3x + 14` → `5x = 26` → `x = 26/5 = 5.2`. Check:
   `6(3.2) + 10.4 = 29.6`; `3(5.2) + 14 = 29.6`. ✓
8. Jordan is correct. The move "subtract `3x` from both sides" is
   legal, and the check confirms `26 = 26`.

**Application:** Let `w` = weeks. `40 + 15w = 10 + 25w` →
`30 = 10w` → `w = 3`. Amount: `40 + 45 = 85`. Each has $85 after
3 weeks. ✓

**Exit check:** `2x = 12` → `x = 6`. Check: `26 = 26`. ✓

**Extension:** `10x + 6 − 4x = 3x + 18` → `6x + 6 = 3x + 18` →
`3x = 12` → `x = 4`. Check: `2(23) − 16 = 30`; `3(10) = 30`. ✓

## Lesson 04

**Readiness:** `2x + 6`; `5`.

**Guided practice:**
1. `6w + 12 = 6w + 12` → `12 = 12`. **Infinitely many.**
2. `4k − 8 = 4k + 11` → `−8 = 11`. **No solution.**
3. `5x + 3 = 2x + 12` → `3x = 9` → `x = 3`. **One solution.**
4. `7x − 4 = 7x − 4` → `−4 = −4`. **Infinitely many.**
5. Acceptable: `a = a` no longer mentions `x`, so its truth does
   not depend on which `x` was chosen — every value works. `x = a`
   still mentions `x`, so it picks out exactly one value.

**Independent practice:**
1. `2x + 9 = 2x + 9` → `9 = 9`. **Infinitely many.**
2. `6x − 5 = 6x + 2` → `−5 = 2`. **No solution.**
3. `3x + 15 = 3x + 15` → `15 = 15`. **Infinitely many.**
4. `8x + 1 = 5x + 10` → `3x = 9` → `x = 3`. **One solution.**
5. `4x − 12 = 4x − 12` → `−12 = −12`. **Infinitely many.**
6. `5x + 7 = 5x + 7` → `7 = 7`. **Infinitely many.**
7. `6x − 8 = 6x + 1` → `−8 = 1`. **No solution.**
8. `9x − 6 = 9x − 6` → `−6 = −6`. **Infinitely many.**
9. Answers vary. Sample: one solution `2x + 3 = 11` (`x = 4`);
   no solution `2x + 7 = 2x − 3` (`7 = −3`); infinitely many
   `5(x + 1) = 5x + 5` (`5 = 5`). Any correct triple earns credit.
10. Sam is wrong. `0 = 0` is a true statement of the `a = a` form,
    so it shows **infinitely many solutions** — every number
    works. "Zero means nothing" confuses the number 0 with the
    absence of solutions.

**Application:** `25 + 10g = 10g + 25` → `25 = 25`.
**Infinitely many solutions.** The plans are identical (same monthly
fee, same per-gigabyte charge, just listed in a different order), so
they cost the same for every usage level.

**Exit check:** `5x + 10 = 5x + 10` → `10 = 10`.
**Infinitely many solutions.**

**Extension:** answers vary. Sample: `3x + 6 = 3x + 6` (infinite)
becomes `3x + 6 = 3x + 7` (no solution) by changing one constant, or
`4x + 6 = 4x + 6` (infinite) becomes `5x + 6 = 4x + 6` (one solution,
`x = 0`) by changing one coefficient.

## Lesson 05

**Readiness:** `x = 9`; `x = 6`.

**Guided practice:**
1. `(1/2)x = 6` → `x = 12`. First move: subtract 5, then multiply by
   2. Check: `6 + 5 = 11`. ✓
2. `0.5x = 12` → `x = 24`. Check: `12 − 3 = 9`. ✓
3. Divide first: `x + 9 = 30` → `x = 21`. Check: `(1/3)(30) = 10`. ✓
4. Multiply every term by 5: `2x − 5 = x + 20` → `x = 25`. Check:
   `10 − 1 = 9`; `5 + 4 = 9`. ✓
5. If the `−1` is not multiplied, the cleared equation is
   `2x − 1 = x + 20` (wrong), giving `x = 21` instead of 25. Every
   term must be scaled or equality breaks.

**Independent practice:**
1. `(3/4)x = 9` → `x = 12`. Check: `9 + 2 = 11`. ✓
2. `0.25x = 2.5` → `x = 10`. Check: `2.5 + 1.5 = 4`. ✓
3. `(2/3)x = 12` → `x = 18`. Check: `12 − 4 = 8`. ✓
4. `1.2x = 6` → `x = 5`. Check: `6 − 0.6 = 5.4`. ✓
5. Divide first: `2x − 8 = 24` → `x = 16`. Check:
   `(1/2)(24) = 12`. ✓
6. Multiply by 6: `5x + 2 = x + 12` → `x = 5/2 = 2.5`. Check:
   `25/12 + 4/12 = 29/12`; `5/12 + 24/12 = 29/12`. ✓
7. `0.6x = 3.6` → `x = 6`. Check: `4.8 + 1.4 = 6.2`;
   `1.2 + 5 = 6.2`. ✓
8. Both are valid. Dividing by `1/4` means multiplying by its
   reciprocal, 4 — the two descriptions are the same operation.

**Application:** Let `b` = batches. `(3/4)b + 1/2 = 7/2` →
`(3/4)b = 3` → `b = 4`. Check: `3 + 1/2 = 7/2`. ✓ 4 batches.

**Exit check:** `(4/5)x = 12` → `x = 15`. Check: `12 − 3 = 9`. ✓

**Extension:** `(2/3)x − 4 + (1/2)x = 11` → `(7/6)x = 15` →
`x = 90/7`. Check (approximate): `(2/3)(90/7 − 6) + (1/2)(90/7) =
(2/3)(48/7) + 45/7 = 96/21 + 135/21 = 231/21 = 11`. ✓

## Lesson 06

**Readiness:** `4 + 3b`.

**Guided practice:**
1. Let `s` = sessions. `50 + 20s = 30s` → `s = 5`. Cost: $150.
   Check: `50 + 100 = 150`; `150`. ✓
2. Let `m` = months. `60m = 40m + 100` → `m = 5`. Cost: $300.
   Check: `300`; `200 + 100 = 300`. ✓
3. `8 + 2v = 2v + 8` → `8 = 8`. **Infinitely many.** The plans are
   identical; every usage level costs the same.
4. Let `g` = guests. `150 + 25g = 40g` → `g = 10`. Cost: $400.
   Check: `150 + 250 = 400`; `400`. ✓
5. Acceptable: "no solution" tells the customer the plans never tie,
   so the choice is simply "which is always cheaper" — here, the
   plan with the lower fixed fee (same per-unit rate) wins at every
   usage level. That settles the decision instead of leaving it open.

**Independent practice:**
1. Let `h` = hours. `12 + 6h = 9h` → `h = 4`. Cost: $36. Check:
   `12 + 24 = 36`; `36`. ✓
2. `30 + 5g = 45 + 5g` → `30 = 45`. **No solution.** Plan B always
   costs $15 more (same per-gigabyte rate, higher monthly fee).
3. Let `h` = hours. `80 + 60h = 100 + 50h` → `h = 2`. Cost: $200.
   Check: `80 + 120 = 200`; `100 + 100 = 200`. ✓
4. Let `c` = candles. `2c + 30 = 5c` → `c = 10`. Cost: $50. Check:
   `20 + 30 = 50`; `50`. ✓
5. The report is wrong because the domain excludes negative baskets.
   The learner should check the **model** first: either the story
   was translated backwards (fixed/per-unit parts swapped) or the
   two plans' order is reversed. Algebra that is internally correct
   can still answer the wrong question.

**Application:** answers vary; check the equation, solution, and
interpretation sentence.

**Exit check:** Let `h` = hours. `5 + 2h = 3h` → `h = 5`. Cost $15.
Check: `5 + 10 = 15`; `15`. ✓

**Extension:** Cost differences (striped − blue): 0 baskets +$4;
1 basket +$2; 2 baskets $0; 3 baskets −$2; 4 baskets −$4. The striped
stall's cost grows $3 per basket vs. the blue stall's $5, so the gap
shrinks $2 per basket and the cheaper stall switches after the
break-even point at 2 baskets.

## Project — sample solution path (scoring reference)

Sample plans (learner plans vary): tutoring Plan A $20 per session
plus $50 sign-up; Plan B $30 per session, no sign-up. Break-even:
`50 + 20s = 30s` → `s = 5` sessions, cost $150. Three-user table:
1 session — A $70, B $30 (B wins); 5 sessions — both $150 (tie);
10 sessions — A $250, B $300 (A wins). Recommendation: B for
occasional users, A for regulars, with the tie at 5 sessions.
Variant pairs: no-solution — A' $50 + $20s vs. B' $20s + $80
(`50 = 80`); infinite — A'' $50 + $20s vs. B'' `2(25 + 10s)`
(`50 + 20s = 50 + 20s`). Score learner projects against the rubric
in `project.md`, not against this sample's numbers.
