# Practice Sessions — Unit 03

Student-facing practice. Solutions are in the separate
[answer key](answer-key.md) — do not work from the key. Show every
move and finish each item with a substitution check (in the original
equation for Lessons 05–06 items).

## Practice A — Test it, don't guess (Session 2)

1. Test `x = 9` in `4x − 5 = 31`.
2. Test `x = 9` in `4x − 5 = 41`. What does the pair of results tell you?
3. Test `t = -6` in `2(t + 4) = −4`.
4. Test `t = -2` in `2(t + 4) = −4`.
5. Test `p = 20` in `p/4 + 3 = 8`.
6. Test `p = 12` in `p/4 + 3 = 8`.
7. **Error analysis:** Kim tested `x = 3` in `5x + 2 = 17` and wrote
   "`5(3) = 15, 15 + 2 = 17, so x = 3 is not a solution because 15
   comes first." Find the flaw in Kim's reasoning and state the
   correct conclusion.

## Practice D — Classify and construct (Session 8)

Classify each equation (one / none / infinitely many). Show the
transforming steps and box the final form.

1. `4x + 8 = 4(x + 2)`
2. `9x − 3 = 9x + 6`
3. `2(5x + 1) = 10x + 2`

## Review — Error-analysis clinic (Session 13)

Each item shows a flawed solution. Find the error, name the move
that broke equality, and give the corrected solution with a check.

1. **Flawed:** `3(x + 4) = 27` → `3x + 4 = 27` → `3x = 23` →
   `x = 23/3`.
2. **Flawed:** `5x − 2(x − 3) = 19` → `5x − 2x − 6 = 19` →
   `3x = 25` → `x = 25/3`.
3. **Flawed:** `4x + 9 = 4x + 9` → "No solution, because both sides
   are the same and `x` cancels."
4. **Flawed:** `(2/3)x = 10` → "Multiply by `2/3`: `x = 20/3`."
5. **Mixed set (solve and check):**
   a. `8(x − 3) + 2x = 42`
   b. `6x + 11 = 2x + 31`
   c. `3(2x + 5) = 6x + 15` — classify, don't just solve.
   d. `(1/2)x + 9 = (3/2)x − 5`
   e. A phone plan costs $15 per month plus $4 per gigabyte; another
      costs $7 per gigabyte with no monthly fee. After how many
      gigabytes do they cost the same? What is that cost?

## Reference — The three final forms

- `x = a` → one solution (that number).
- `a = a` → infinitely many solutions (every number).
- `a = b` (different numbers) → no solution (no number).
