# Lesson 03 — Variables on Both Sides

**Goal (student-readable):** I can solve equations with the variable
on both sides and justify each move.
**Time:** ~45 minutes · **Materials:** notebook, pencil.

## Readiness check

Solve `2x + 9 = 4x − 5` by moving all `x` terms to one side.
(Answer: `14 = 2x`, so `x = 7`. Check: `23 = 23`.)

## Teaching

When `x` appears on both sides, the goal is unchanged: get `x` alone
on one side and a number on the other. The new move is to **add or
subtract a variable term from both sides** so that `x` ends up on only
one side. It does not matter which side you collect the variables on,
but two habits help: (1) move the smaller `x` term if you can, so the
coefficient stays positive; (2) write the move explicitly — "subtract
`2x` from both sides" — instead of teleporting terms across the
equals sign. Teleporting is where sign errors hide.

Remember the balance: every move applies to the whole side, not to
one term. Subtracting `2x` from both sides means both sides lose
`2x`; it does not mean erasing `2x` wherever you see it.

### Worked example 1

**Solve `4x + 7 = 2x + 15`.**

Subtract `2x` from both sides: `2x + 7 = 15`.
Subtract 7 from both sides: `2x = 8`.
Divide by 2: `x = 4`.
Check: left `4(4) + 7 = 23`; right `2(4) + 15 = 23`. ✓

### Worked example 2

**Solve `3(2x − 1) = 5x + 4`.**

Distribute first: `6x − 3 = 5x + 4`.
Subtract `5x` from both sides: `x − 3 = 4`.
Add 3 to both sides: `x = 7`.
Check: left `3(2(7) − 1) = 3(13) = 39`; right `5(7) + 4 = 39`. ✓

Notice the efficient choice in Example 2: subtracting the smaller
`x` term (`5x`) left a positive `x`. Subtracting `6x` instead would
also work but would produce negatives to manage.

## Guided practice

Solve each equation. Name each move, then check by substitution.

1. `7x − 5 = 3x + 15`
2. `2(4y − 3) = 5y + 12`
3. `9x + 2 = 5x + 22`
4. `6x − 8 = 2x + 4`
5. Explain why the move "subtract `3x` from both sides" in item 1 is
   legal, using the balance idea in your own words.

## Independent practice

Solve and check each equation.

1. `5x + 11 = 2x + 29`
2. `8x − 3 = 5x + 18`
3. `3(x + 4) = 2x + 20`
4. `4x + 9 = 7x − 6`
5. `2(3x − 5) = x + 15`
6. `10x − 7 = 4x + 23`
7. `6(x − 2) + 2x = 3x + 14`
8. **Explain your reasoning:** Jordan solved `5x + 6 = 3x + 14` as
   follows: "Subtract `3x`: `2x + 6 = 14`. Subtract 6: `2x = 8`.
   Divide: `x = 4`." Then Jordan checked: `5(4) + 6 = 26` and
   `3(4) + 14 = 26`. Is Jordan's work correct? Point to the move
   that proves it, or find the error.

## Application

Two friends save money. Ana starts with $40 and saves $15 per week.
Ben starts with $10 and saves $25 per week. After how many weeks will
they have the same amount? Write the equation, solve it, and state
the amount they will each have then.

## Exit check

Solve `3x + 8 = x + 20` and check your answer by substitution.

## Supports, alternate modes, extension

- **Language access:** "Variable on both sides" means the letter
  appears left and right of the equals sign. Circle each `x` before
  solving so the goal (one side only) is visible.
- **Alternate response mode:** Move physical counters or algebra
  tiles: remove the same tiles from both sides of a drawn balance.
  Oral move-naming with adult scribing is accepted.
- **Extension:** Solve `2(5x + 3) − 4x = 3(x + 6)`. (Distribute both
  groups, collect, then move variables together.)

## Teacher note

Learners who "move terms" without naming the operation often flip a
sign. Require the sentence "subtract ___ from both sides" for the
first four problems of this lesson. If `4x + 9 = 7x − 6` (independent
item 4) produces `x = 5` only after a sign struggle, re-teach with
the smaller-term habit: subtract `4x`, not `7x`. Answer-key
reference: [answer-key.md](../answer-key.md#lesson-03).
