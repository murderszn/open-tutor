# Lesson 04 — One, None, or Infinitely Many

**Goal (student-readable):** I can classify an equation by
transforming it and explain what the final form proves.
**Time:** ~45 minutes · **Materials:** notebook, pencil.

## Readiness check

Simplify `2(x + 3)` and `3x + 5 − 3x`. (Answers: `2x + 6`; `5`.)
Notice the second result has no `x` left — that is the key to today.

## Teaching

Keep simplifying an equation with legal moves. Eventually one of
three things happens:

| Final form | Meaning | Example |
|---|---|---|
| `x = a` (a number) | **One solution:** exactly that number works | `x = 4` |
| `a = a` (same number both sides) | **Infinitely many solutions:** every number works | `6 = 6` |
| `a = b` (different numbers) | **No solution:** no number works | `5 = 9` |

Why? If the equation simplifies to `6 = 6`, that statement is true
no matter what `x` was — so every value of `x` is a solution. If it
simplifies to `5 = 9`, that statement is false no matter what `x`
was — so no value of `x` is a solution. The final form is the proof;
you do not need to test values to decide.

A warning: a "no solution" equation is not a mistake, and an
"infinitely many" equation is not unfinished. Both are complete,
correct answers. Saying "no solution" when you mean "I couldn't solve
it" is the error to avoid — the classification must come from the
transforming steps.

### Worked example 1 — Infinitely many solutions

**Classify `2x + 6 = 2(x + 3)`.**

Distribute the right side: `2x + 6 = 2x + 6`.
Subtract `2x` from both sides: `6 = 6`.
Same number both sides → **infinitely many solutions**. Test two
values to feel it: `x = 0` gives `6 = 6`; `x = 10` gives `26 = 26`.

### Worked example 2 — No solution, and one solution for contrast

**Classify `3x + 5 = 3x + 9`. Then classify `4(x − 2) = 3x + 1`.**

First equation: subtract `3x` from both sides: `5 = 9`. Different
numbers → **no solution**. No value of `x` can make 5 equal 9.

Second equation: distribute: `4x − 8 = 3x + 1`. Subtract `3x`:
`x − 8 = 1`. Add 8: `x = 9`. Form `x = a` → **one solution**.
Check: `4(7) = 28` and `3(9) + 1 = 28`. ✓

## Guided practice

Classify each equation (one / none / infinitely many). Show the
transforming steps; do not just guess.

1. `3(2w + 4) = 6w + 12`
2. `4(k − 2) = 4k + 11`
3. `5x + 3 = 2x + 12`
4. `7x − 4 = 7x − 4`
5. Explain in your own words why `a = a` means every number is a
   solution, but `x = a` means only one number is.

## Independent practice

Classify each equation. Show the transforming steps and box the
final form.

1. `2x + 9 = 2x + 9`
2. `6x − 5 = 6x + 2`
3. `3(x + 5) = 3x + 15`
4. `8x + 1 = 5x + 10`
5. `4(x − 3) = 4x − 12`
6. `5x + 7 = 5x + 7`
7. `2(3x − 4) = 6x + 1`
8. `9x − 6 = 3(3x − 2)`
9. **Construct:** Write one original equation of each type (one
   solution, no solution, infinitely many solutions) and prove each
   classification with transforming steps.
10. **Explain your reasoning:** Sam says, "If I get `0 = 0`, the
    equation has no solution, because zero means nothing." Is Sam
    right? Explain what `0 = 0` actually shows.

## Application

A phone plan charges $25 per month plus $10 per gigabyte. A second
plan charges $10 per gigabyte plus $25 per month. Write the equation
that asks when the plans cost the same, simplify it, and classify it.
What does the classification mean for a customer comparing the plans?

## Exit check

Classify `5(x + 2) = 5x + 10`. Show the transforming steps.

## Supports, alternate modes, extension

- **Language access:** Post the three-line chant: "`x` equals a
  number: one. Same equals same: all. Different equals different:
  none." Rehearse it orally before the independent set.
- **Alternate response mode:** Sort pre-written equations into three
  labeled piles (one / none / infinite) after transforming, instead
  of writing full sentences; the adult scribes the final forms.
- **Extension:** Create an equation whose classification changes if
  one coefficient changes by 1 (for example, turn an
  infinitely-many-solutions equation into a one-solution equation by
  changing one number). Show both versions and both final forms.

## Teacher note

The persistent confusion is `0 = 0` vs. "no solution": learners read
zero as "nothing works." Re-teach with the test-two-values move from
Worked example 1 whenever `a = a` appears. Also watch for learners
who stop at `2x + 6 = 2x + 6` and call it "one solution" because
`x` is still visible — insist on transforming until `x` is gone or
alone. Answer-key reference:
