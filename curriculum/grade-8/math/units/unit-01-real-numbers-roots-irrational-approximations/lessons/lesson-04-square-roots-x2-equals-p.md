# Lesson 04 — Square Roots and x² = p

**Student goal:** I can evaluate square roots of perfect squares and solve
equations of the form x² = p, listing every solution.
**Time:** ~45 minutes · **Unit:** [U01](../README.md) · **Session 7 of 16**

## Materials

- Notebook, pencil, graph paper, calculator (check only)
- Perfect-square reference: 1²–15² (build it in the lesson, don't just hand
  it out)

## Readiness check (5 minutes)

Compute: 7², 11², 13², (−9)², 15². (Expected: 49, 121, 169, 81, 225.) Then:
"Each of these was *squaring*. Today we learn the undo button." If integer
squaring is shaky, rebuild the 1²–12² table together first.

## Teaching

The **square root** of a number a, written √a, is the *nonnegative* number
that squares to a. So √49 = 7, because 7² = 49 and 7 ≥ 0.

> **√a = "the nonnegative number whose square is a"**

A **perfect square** is a whole number that is some integer squared: 1, 4,
9, 16, 25, 36, 49, 64, 81, 100, 121, 144, 169, 196, 225. Memorize this
list's *shape* (the gaps grow: 3, 5, 7, 9, … — consecutive odd numbers!),
not just the digits.

The number under the root sign is the **radicand**. √ always means the
*principal* (nonnegative) square root — that is why √81 = 9 and *only* 9,
even though (−9)² = 81 too.

But **solving x² = p** is a different question from **evaluating √p**.
Evaluating asks "what is √p?" (one answer: the nonnegative one). Solving
asks "which numbers, squared, give p?" (up to two answers):

> **x² = p, with p > 0 → x = √p or x = −√p (two solutions)**
> **x² = 0 → x = 0 (one solution)**
> **x² = p, with p < 0 → no real solution** (no real number squares to a
> negative)

**Geometry connection:** a square with area A has side length √A. A 169 m²
garden bed is √169 = 13 m on each side.

**Key vocabulary:** *square root (√)*, *perfect square*, *radicand*,
*principal square root*.

## Worked example 1 — evaluating roots

Evaluate: √169, √196, −√144, √(81/100).

- √169 = 13, because 13² = 169. (Check neighbors: 12² = 144 < 169 <
  14² = 196, so 13 is the only candidate.)
- √196 = 14, because 14² = 196.
- −√144 = −(√144) = −12. The negative sign is *outside* the root: negate
  after evaluating.
- √(81/100) = 9/10, because (9/10)² = 81/100.

**Reasoning to name aloud:** bracket first (which two consecutive integers
could it be?), then verify by squaring. Never guess from the digits alone.

## Worked example 2 — solving x² = p completely

Solve x² = 81. List **all** solutions.

> x = √81 = 9, or x = −√81 = −9.
> Check: 9² = 81 ✓; (−9)² = 81 ✓. Both work.

Now solve x² = 7. Neither solution is a whole number — that is fine:

> x = √7 or x = −√7. (√7 ≈ 2.6458, so the solutions are ≈ ±2.6458.)

And x² = −25? No real solution: every real square is ≥ 0.

**Reasoning to name aloud:** "evaluate √p" gives one number; "solve x² =
p" asks a question with (usually) two answers. Forgetting the negative
solution is the #1 error in this unit.

## Guided practice (adult stays close, hints allowed)

1. Evaluate √121. *(Hint: "11² or 12²?")* Expected: 11.
2. Evaluate −√64. *(Hint: "The minus is outside.")* Expected: −8.
3. Solve x² = 49; list all solutions. Expected: x = 7 or x = −7.
4. Solve x² = 20. *(Hint: "Solutions don't have to be whole numbers.")*
   Expected: x = √20 or x = −√20 (≈ ±4.4721).
5. How many real solutions does x² = −9 have? Expected: none.
6. Error analysis: "Nadia solves x² = 144 and writes x = 12." What's
   missing? Expected: the second solution x = −12; she evaluated √144
   instead of solving the equation.

## Independent practice

1. Evaluate: √225, √81, −√100, √(25/36).
2. Solve, listing all real solutions: x² = 16, x² = 50, x² = 0, x² = −4.
3. A square photo has area 196 cm². What is its side length? What if the
   area were 200 cm² — give the exact side length and a one-decimal
   approximation.
4. Explain in your own words why √81 has one value but x² = 81 has two
   solutions.

*Alternate response mode:* for #2, write each solution pair as "±√p" and
verify one pair by squaring aloud.

## Application

Falling-object physics preview: the time t (seconds) for an object to fall
d feet is t = √(d/16). How long does a rock take to fall 64 feet? 100
feet? (Expected: √(64/16) = √4 = 2 s; √(100/16) = √6.25 = 2.5 s. Note the
principal root is the right choice — time can't be negative.)

## Exit check

"Solve x² = 225. How do you know you found every solution?" Expected: x =
15 or x = −15; squaring is two-to-one for nonzero numbers (a and −a give
the same square), so these are all. Record: secure / developing / not yet.

## Supports

- **Language access:** "principal" = "the main one, the nonnegative one";
  contrast "evaluate" (one answer) vs. "solve" (find all answers) with a
  two-column chart.
- **Alternate response mode:** build perfect squares with tiles on graph
  paper — a 13×13 tile square *is* √169 = 13.
- **Calculator boundary:** use the calculator to *verify* a guessed root by
  squaring, not to produce the root first.

## Extension

Between which consecutive integers is √200? (14² = 196 < 200 < 225 = 15²,
so 14 < √200 < 15.) Then: is √200 rational or irrational? (Irrational —
200 is not a perfect square.) Generalize: the square root of a whole
number is either a whole number or irrational — never a "messy fraction."

## Teacher note

**Likely misconceptions:** (1) Writing only the positive solution for
x² = p. (2) √(−25) = −5 — no real square root of a negative exists.
(3) −√144 = √(−144) — the minus is outside the radicand. (4) √(a + b) =
√a + √b — false (quiz error-analysis task).

**Answer-key reference:** [answer-key.md](../answer-key.md#lesson-04) has
expected responses for all items, including √(25/36) = 5/6 and the photo
side lengths (14 cm; √200 ≈ 14.1 cm).
