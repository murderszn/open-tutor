# Teacher Guide — Unit 01: Real Numbers, Roots, and Irrational Approximations

Adult-facing. Keep this file and [answer-key.md](answer-key.md) away from
the learner.

## Session-by-session guidance

| Session | Focus | What to watch for |
|---|---|---|
| 1 (L1) | Rational expansions | Learner predicts *before* dividing; insist on naming the repeated remainder, not just the digits. |
| 2 (Practice A) | Decimal detectives | Check hand division, not just final decimals. Flag calculator-first habits. |
| 3 (L2) | Irrationals + √2 proof | The proof is a story in 4 beats — have the learner retell it before writing anything. Don't rush to "memorize." |
| 4 (Review) | Card sort | Defenses matter more than sorting speed. Note every shaky placement for Session 13. |
| 5 (L3) | Conversion method | The shift must match the repetend *length*; delayed repetends need two shifts. Watch simplification. |
| 6 (Practice B) | Conversion lab | Error-analysis items diagnose "repeating = terminating" confusion directly. |
| 7 (L4) | Square roots | Drill the evaluate-vs.-solve distinction until it's automatic. Tile squares help. |
| 8 (Practice C) | Roots + geometry | The √18 area item is the lesson's payoff — let the learner notice it. |
| 9 (L5) | Cube roots | Contrast with L4 explicitly: sign kept vs. sign erased. The card-bin sort cements it. |
| 10 (Reference) | Number-system map | Learner *draws* the map from description — copying a picture teaches nothing. |
| 11 (L6) | Bracketing | Squaring must be exact; one arithmetic slip breaks the bracket. Verify 2.64²-style computations. |
| 12 (Project P1) | Measuring | Check the tables before Session 14. Re-measure outliers. String method for circumferences. |
| 13 (Review) | Re-teach menu | Pick two stations from the Session 4/weekly exit-check evidence — not all four. |
| 14 (Project P2) | Analysis + report | The #3 question (perfect measuring vs. π's digits) is the unit's thesis — discuss it aloud first. |
| 15 (Quiz) | Formative | Score same-day; map misses to objectives (see below). |
| 16 (Assessment) | Culminating | Score with the rubric in answer-key.md; plan re-teach before Unit 02. |

## Misconceptions and reteaching moves

| Misconception | Where it appears | Reteach move |
|---|---|---|
| "Long decimal = irrational" | L1, L2 | Pattern-not-length: show 0.7̄ (short, rational) vs. 0.101001… (patterned but non-repeating, irrational). |
| Calculator digits are the whole decimal | L1 | Divide 2/3 by hand to 8 places; compare with the calculator display. |
| Repeating treated as terminating | L3, Practice B | Always re-divide the "answer" — 18/25 = 0.72 ≠ 0.7̄2̄. |
| 0.999… < 1 | L2 exit, L3 | Run the 9x = 9 algebra; then: "name a number strictly between 0.999… and 1." |
| Only the positive solution for x² = p | L4 | "Evaluate √81" vs. "solve x² = 81" side-by-side drill until the ± is reflex. |
| √(−25) = −5 | L4 | Square −5: (−5)² = 25, not −25. No real square root of a negative. |
| ± copied onto cube roots | L5 | Bin sort: x³ = 8 vs. x² = 64 — check (−2)³ = −8 ≠ 8 aloud. |
| √(a+b) = √a + √b | Quiz Q10 | 7 ≠ 5 counterexample; roots don't distribute over addition. |
| Approximation = the number itself | L2 (Leo), Task 5 | "1.4142 is a *photo* of √2, not √2." Photos are finite; the number isn't. |
| Truncation = rounding | L6 | Bracketing needs both fences; a rounded middle alone proves nothing. |

## Readiness criteria ("ready to move on")

The learner is ready for Unit 02 when **all** of these hold:

1. Classifies 8/10 mixed numbers correctly with a valid reason (Quiz Q5 /
   Assessment Task 1 style).
2. Converts one- and two-digit repetends (including one delayed repetend)
   to simplest fractions.
3. Solves x² = p and x³ = p correctly, including solution counts and the
   no-real-solution case.
4. Brackets a square root between consecutive tenths by exact squaring.
5. Can state in their own words why no measurement can capture all of π's
   digits (project Part 2, Q3).

If 1–2 criteria are shaky: use the track's flexible weeks (or Session 13
stations) before Unit 02. If 3+ are shaky: re-teach the corresponding
lessons fully — Unit 02's exponent work assumes root fluency.

## Differentiation

- **Support:** string-and-clothespin number line; oral proof retelling;
  adult scribing; pre-made repetend cards; calculator for *checking*
  squaring only.
- **Extension:** L1 (1/7, 1/13, 1/17 repetends), L2 (√3 proof), L3
  (0.123123…, two-way 0.0̄9̄), L4 (√200 irrationality), L5 (∛2 ≈ 1.26),
  L6 (√2 + √3 > π proof). Extensions are optional and never prerequisites.
