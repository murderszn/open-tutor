# Teacher Guide — Unit 02: Revolution, Independence, Contested Ideals

**For the guiding adult.** Student materials never contain answer keys; all solutions live in [answer-key.md](answer-key.md).

## Lesson-by-lesson notes

- **Lesson 1 (road to war):** The change/continuity coding is new — model Worked example 2 aloud before independent work. If the learner codes everything "change," re-teach: continuity asks "what stayed the same *about power*?" (Parliament's authority claim survived the Stamp Act repeal via the Declaratory Act).
- **Lesson 2 (Declaration):** Read the excerpts aloud together; 18th-century syntax is the main barrier, not the ideas. The deleted-passage discussion can unsettle learners who memorized a heroic narrative — frame it as historians do: a decision with causes (unity) and consequences (a promise deferred).
- **Lesson 3 (turning points):** Keep the causal chain diagram posted through Week 10. The counterfactual test ("remove one link — does the outcome hold?") is the unit's core reasoning move; reuse it in Lesson 6.
- **Lesson 4 (whose liberty):** Preview both excerpts yourself first. Wheatley's "modern Egyptians" is deliberate provocation — explain the Pharaoh analogy before reading. Dunmore's proclamation can confuse learners into thinking Britain opposed slavery; correct early (see misconceptions).
- **Lesson 5 (images):** The reconstruction activity works from the text-only alternative alone — no learner must interpret the image visually. If showing Revere's engraving, use the Gilder Lehrman page (resource pack #2), which frames it as propaganda; preview for the "Butcher's Hall" label and the poem's violent language.
- **Lesson 6 (turning point):** The S4 essay is the first fully supported claim/counterclaim/limit argument in the track. Allow the speech alternative for learners who write slowly — the reasoning, not the medium, is assessed.

## Mature-content preview notes

- **Enslavement:** Lessons 2 and 4 quote sources about slavery directly; the unit names the Middle Passage only by reference to U01. Keep discussion on the sources' arguments, not graphic detail.
- **War:** Lesson 3 discusses battles at the strategic level; no battle-detail gore is included. The Boston Massacre (five dead) is named factually in Lessons 1 and 5.
- **Propaganda and persuasion:** Lesson 5 teaches that images persuade; connect to the learner's own media diet only with care — the Application task is optional if it becomes personal.

## Reteaching moves

- **Timeline confusion:** rebuild the 1763–1783 strip physically with event cards before re-quizzing; have the learner narrate it as a story twice.
- **Change/continuity:** use the sentence frame "It was change in ___ because ___, but continuity in ___ because ___."
- **Maker/audience/purpose:** use the prompt "What did the maker need?" — if the learner answers with the source's *content*, redirect to the maker's *situation*.
- **Counterclaim weakness:** require the learner to steelman — "write the best version of the other side before you answer it" (Lesson 6 Worked example 2).

## Readiness and next steps

- **Ready for U03** if the learner can: sequence 8+ events with change/continuity coding; paraphrase a founding-document argument; identify maker/audience/purpose for an unfamiliar excerpt; and write a qualified claim with one counterclaim and one limit.
- **Re-teach** if the assessment §2 source analysis scores below half: repeat Lesson 4's chart with a new excerpt (e.g., the Abigail Adams letter) before U03's ratification debates, which assume these skills.
- U03 re-teaches founding-document close reading in the ratification context — this unit's Declaration work is the prerequisite.
