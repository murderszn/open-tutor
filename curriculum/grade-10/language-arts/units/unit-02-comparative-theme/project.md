# Project — Two-Tradition Theme Casebook

**Due:** Session 18 (week 10) · **Weight:** with the unit assessment, the
unit's major evidence · **Answer-key reference:** [answer-key § P](answer-key.md#project-casebook)

## The task

You are building a **casebook**: a small comparative study of how *two
literary traditions* handle one human concern. Choose:

- **One concern** from this list (or propose your own with the adult):
  hospitality to strangers · exile and return · duty to the dead ·
  cleverness vs. wisdom · promises and oaths · what the old owe the young
- **Two texts:** one from this unit ("The Salt Road," "The Harbor Light,"
  the fable + "The Rematch," or the crossroads passage + illustration)
  and one adult-approved public-domain text from another tradition
  (examples: a Grimm tale, an Aesop fable, a myth from Bulfinch's
  *Mythology*, a Chekhov or Maupassant short story — the adult helps
  choose at reading level).

## Deliverables

1. **Dual theme tracker** (Lesson 03 format): three+ rows per text, with
   a v1→v3 revision visible in each. The shared theme must be stated as a
   *claim*, not a topic.
2. **Structural contrast chart** (Lesson 04 format): order, pacing, and
   point of view for each text, one cited detail per cell — plus two
   sentences on which structural difference most shapes the theme
   difference.
3. **Transformation or medium page** (choose one):
   - *Transformation page:* if your second text draws on the first (or
     on a shared source), a three-layer inventory (kept / changed /
     transformed) — Lesson 05 format; or
   - *Medium page:* one illustration, painting, photograph, or film still
     connected to your concern (adult-approved, lawful to view), with an
     emphasized/absent analysis in the Lesson 06 format and a text-only
     description you write yourself.
4. **Comparative brief** (500–700 words): a three-part thesis, handled
   quotations from both texts, and an answered "so what." (This is a
   rehearsal for the unit assessment essay, not a duplicate of it — use
   *different* texts or a different shared question.)
5. **Ten-minute talk:** present the casebook to the adult (or family).
   The talk must include one quotation read aloud from each text and one
   visual (the tracker, the chart, or the medium page).

## Steps (with the adult)

1. **Session 9:** Choose the concern and the second text; record the
   edition/source and why it counts as another tradition.
2. **Session 13:** Draft both trackers; adult checks one row per text
   for quotation accuracy.
3. **Session 15:** Draft the chart and the transformation/medium page.
4. **Sessions 16–17:** Draft the brief; revise with Practice F moves
   (handled quotations, answered "so what," counter-thesis sentence).
5. **Session 18:** Assemble the casebook, rehearse the talk once, deliver.

## Materials

Notebook, the unit texts, the second text (print or screen), index cards
for the talk. No purchases. All work stays anonymous — no names on
anything submitted beyond "learner."

## Rubric (40 points)

| Criterion | 4 — Strong | 3 — Proficient | 2 — Developing | 1 — Beginning |
|---|---|---|---|---|
| Theme tracking (8) | Both trackers show v1→v3 revision driven by quoted details; theme stated as claim | Trackers complete with revision in one text; claims present | Rows present but theme never revised; details paraphrased only | Tracker missing or theme = topic |
| Structural analysis (8) | Chart complete with citations; the two-sentence judgment ties a structural difference to the theme difference | Chart complete; judgment present but loosely tied | Chart partial; judgment missing or generic | Little structural analysis |
| Transformation / medium page (8) | Three-layer inventory reaches layer 3 with specifics, or medium analysis names emphasized + absent with the trade stated | Layers/medium elements present; layer 3 or the trade thin | Stops at description (layer 2 / visual listing) | Missing or off-task |
| Comparative brief (10) | Arguable three-part thesis; quotations handled; "so what" answered; counter-thesis addressed | Thesis arguable; quotations mostly handled; "so what" present | Thesis = topic; quotations dropped; no "so what" | Brief missing or incoherent |
| Talk (6) | Ten minutes; one quotation per text read aloud; visual used to *show* a claim, not decorate | Talk complete; quotations read; visual present | Talk short or missing a quotation/visual | No talk |

**Scoring:** 36–40 = exceeding; 30–35 = meeting; 24–29 = approaching
(revise one criterion with the adult); below 24 = re-teach (see
[teacher guide](teacher-guide.md)).

## Academic honesty

All words are yours except marked quotations. The second text's source
is cited (title, author/translator, where you read it, date). AI tools
were not used to write any part of the casebook — the adult confirms.
