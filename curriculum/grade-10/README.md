# Grade 10 — Independent Curriculum Track

This folder is an anonymous, grade-specific track in the public OpenTutor curriculum library.

**Contents:** The language arts track has a draft audit and scope-and-sequence
(delivered as a validated draft by this run, issue #48). The mathematics
track's audit and scope-and-sequence were delivered as a validated draft in
unmerged draft PR #114 (files not yet on `main`), as was the science track's
in unmerged draft PR #115 (files not yet on `main`). The eight units of each
subject are planned, not yet written. The social studies track is planned and
does not yet have a folder. No subject track is complete. All materials still
require educator review.

**Do not refer a learner to another grade track.** Each track is
self-contained for one learner at a time; a guiding adult adapts pacing,
materials, and supports. Keep completed learner work, names, photos, schedules,
and grades in private storage — never in this public repository.

See also: [curriculum index](../README.md).
