# Teacher Guide — Unit 01 (Adult Only)

Do not share this guide or `answer-key.md` with the learner. Student pages never link here.

## Unit at a glance

Six lessons, 20 sessions, one investigation. The unit's intellectual arc: *measure safely → convert
honestly → read precisely → round honestly → state uncertainty → defend a result in writing.* Every
lesson ends with an exit check — use it the same session; do not let a shaky Lesson 02 ride into
Lesson 04.

## Per-lesson notes

**Lesson 01 (safety/SI).** Walk the actual bench together. If you have no glassware, do the tour
with `assets/lab-measurement-station.png` and narrate what each instrument would feel like. Have
the learner *sign* the contract — the signature matters psychologically. Misconception watch:
"the beaker scale is close enough." Counter: pour 100 mL by beaker, then check it in the cylinder.

**Lesson 02 (conversion).** Insist on written unit cancellation for the first two weeks — the
leading cause of conversion failure is mental math skipping the setup. The temperature trap
(°C→K is addition) will resurface all year; fix it now. If Session-4 practice is below 80%,
re-do guided items with the learner narrating each cancellation aloud.

**Lesson 03 (instruments).** Demo parallax physically: read a water glass at three eye heights and
watch the apparent level move. Check the learner's eye level on every early cylinder reading.
Remind: the generated illustration is number-free by design; graded readings come only from the
exact SVG or written practice values.

**Lesson 04 (sig figs).** Drill the two rules separately before mixing: five +/− items, then five
×/÷ items. The killer misconception is applying the figure-count rule to addition. Keep the
reference card visible through Unit 04 (stoichiometry leans on it hard).

**Lesson 05 (accuracy/precision).** Return to the 62.3-kg scale story whenever "precise therefore
accurate" appears — it is the unit's best antidote. When the learner takes five home readings,
watch for suspiciously identical repeats; use it as an integrity conversation about whether the
instrument can truly resolve that finely.

**Lesson 06 (density + reports).** Require the data table and calculations *before* the conclusion
is drafted — conclusions written first get defended instead of derived. Ban the phrase "human
error" from error analyses starting now; demand source + classification + direction.

## The density investigation (Sessions 13–14, 17)

- Approve the written procedure before water is poured. Confirm the sample's identity privately
  (aluminum) and keep it private until reports are in.
- Typical student results: 2.6–2.8 g/mL with 1–3% error. Above 5% error, check for: meniscus read
  at the top, splashed water, or an untared balance — in that order.
- The simulation alternative (PhET Density) is a full deliverable, not a consolation prize; grade
  it with the same rubric.
- Common failure: learners compute density from a *single* trial and skip the mean/range. Require
  all three trials in the report.

## Misconception table

| Misconception | Where it surfaces | Response |
|---|---|---|
| Beaker scale is fine for measuring | L01, L03 | Pour-and-check demo; ±5% figure |
| "Big-to-small multiply" as a memorized rule | L02 | Force written cancellation every time |
| °C→K uses a conversion factor | L02, quiz | Number line: 0 °C = 273.15 K, same-size degrees |
| Read the top of the meniscus / nearest mark | L03 | Finger-trace the curve; mark the lowest point first |
| Dropping the estimated digit is "more honest" | L03, L04 | The estimate *is* the honest part |
| Figure-count rule applied to addition | L04 | "Places for plus/minus, figures for times/divide" chant |
| Precise ⟹ accurate | L05 | The 62.3-kg scale story, on repeat |
| ± means "wrong by that much" | L05 | Reframe: ± is the spread of honest repetition |
| "Human error" as an error source | L06, project | Require source + classification + direction |
| "Proved" in conclusions | L06, project | Consistent with / supports; proof is for math |

## Reteaching paths

- **Conversions shaky at quiz:** 15 minutes of narrated cancellations daily for a week; do not
  advance past Lesson 04 until ≥80% on fresh items.
- **Sig figs collapse in multi-step work:** isolate — one week of single-operation items, then
  reintroduce two-step items with the "round once, at the end" rule highlighted.
- **Error analysis stays generic:** model one full source→classification→direction sentence
  together, then require the learner to produce two more before writing the report.
- **Pacing:** the unit's 20 sessions assume ~50 minutes. If sessions run 30 minutes, split each
  lesson across two sessions and move the investigation to four short sessions; keep the session
  order.

## Answer-key use

`answer-key.md` contains independently solved solutions for every lesson item, practice item, quiz
question, and assessment task, plus acceptable variation notes for open responses. Re-solve any
item you dispute before marking — if you find a genuine key error, note it for the curriculum
review rather than silently working around it.
