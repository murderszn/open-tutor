# Teacher Guide — Unit 02 (Adult Only)

Do not hand this file to the learner. It contains misconception notes, reteaching plans, and
references to `answer-key.md`.

## Pacing notes

- The unit's hard parts, in order, are: Lesson 04 calculations (percentage-to-decimal errors),
  Lesson 03 valence counting (last-subshell trap), and Lesson 06 justifications (predictions
  without reasons). Budget extra feedback time at Sessions 9, 7, and 15 respectively.
- Session 4's timeline activity is the unit's best diagnostic for Lesson 02: a learner who
  pairs "gold foil" with "Thomson" or "cathode ray" with "Rutherford" has memorized names
  without the evidence chain. Re-teach with Lesson 02's worked examples before Session 10.
- The Session 10 quiz covers Lessons 01–04 only. Do not let a weak quiz score delay Lesson 05:
  reteach the failed items in Sessions 11–12 warm-ups instead, and re-check them in Session 16.

## Per-lesson misconceptions and reteaching

### Lesson 01 — Particles and notation

- **Swap of A and Z:** anchor "A is on top because the mass is the bigger number." If errors
  persist, have the learner write "Z = protons (defines element)" above every notation for a
  week.
- **Charge sign:** learners compute electrons − protons. Anchor: "protons are positive, so
  protons come first: charge = protons − electrons."
- **Neutrons change the element:** repeat the definition sentence — "protons define the
  element; neutrons define the isotope" — and use carbon-12/carbon-14 as the standing example.
- **Reteach:** PhET "Build an Atom" (resource pack): add/remove one particle at a time and
  watch which readouts change. If the simulation is unavailable, use counters.

### Lesson 02 — Models and evidence

- **"Proved the nucleus":** correct the language to "supported the nuclear model by
  falsifying Thomson's." Models are supported, not proved; this distinction returns in every
  later unit.
- **Bohr orbits as literal truth:** Lesson 03's orbital language must be introduced as a
  correction, not an addition: "Bohr's circles were a useful step; the modern picture is
  probability regions."
- **"Most particles passed through, so atoms are mostly solid":** the error-analysis item B6
  exists for this. The foil is solid gold; the empty space is inside each atom.
- **Reteach:** Lesson 02 Activity A with the text-only alternative read aloud, then the image.
  Learners who can state both pattern halves and both implications have the lesson.

### Lesson 03 — Configurations and valence

- **Valence = last subshell only:** the fluorine trap (2s²2p⁵ → valence 7, not 5). Reteach by
  summing the whole outermost level for five elements in a row.
- **4s before 3d:** for potassium and calcium, the taught order is 1s, 2s, 2p, 3s, 3p, 4s.
  Do not introduce 3d filling in this unit except as the Lesson 03 extension.
- **Group = valence for transition metals:** state the boundary explicitly — the group =
  valence rule is a main-group rule (groups 1, 2, 13–18). Transition-metal ions are Unit 03
  enrichment at most.
- **Reteach:** shell diagrams (the unit's SVG) before subshell notation for learners who
  struggle with superscripts; translate diagram → notation together.

### Lesson 04 — Isotopes and average mass

- **Percentages used directly:** the table layout in Lesson 04 (isotope, mass, fraction,
  contribution) prevents this. Require the layout for every calculation until it is automatic.
- **Simple mean instead of weighted mean:** re-use the class-average analogy from the
  readiness check (15 × 10 and 5 × 20 averages to 12.5, not 15).
- **"35.45 u is one atom's mass":** repeat: no single chlorine atom weighs 35.45 u; the value
  describes a large sample.
- **Reteach:** boron with whole numbers first (easy arithmetic, method visible), then chlorine
  with exact masses. Do not start a struggling learner on exact-mass arithmetic.

### Lesson 05 — The table as a map

- **Period = electron count:** correct to "number of occupied levels." Sodium (11 electrons)
  is period 3, not period 11.
- **Helium's block:** the dataset lists helium as p-block (group-18 placement); its
  configuration fills s. Accept either answer for helium's block with the convention noted;
  never mark it wrong without that note.
- **Metalloids as a sharp set:** note honestly that tables differ on borderline elements
  (polonium, astatine). Assess the staircase concept, not one borderline membership.
- **Reteach:** color-coded printed table; every location question answered by pointing to the
  row and column first.

### Lesson 06 — Trends, predictions, nuclear change

- **"Bigger = more reactive" for all elements:** split reactivity by mechanism — metals lose,
  nonmetals gain — so the reactive corners are opposite (bottom-left vs. top-right).
- **Ionization energy vs. electronegativity:** one removes an electron, the other pulls on
  shared electrons. Related trends, different definitions; quiz items keep them separate.
- **Nuclear = "very energetic chemical":** the distinguishing marks are a changed element
  (new proton count) and a vastly larger energy per atom. Carbon-14 → nitrogen-14 is the
  standing example.
- **Reteach:** require the justification chain for every prediction — "group → valence →
  gain/lose → ion/bond" — spoken aloud before it is written.

## Differentiation

- **Support:** for every calculation, allow the table layout and a calculator; for every
  prediction, allow the spoken justification chain before writing; for the gold-foil activity,
  the text-only alternative carries full marks.
- **Extension:** Lesson 04's backwards-abundance problem; Lesson 06's ionization-energy dips
  (boron, oxygen); the project report's limitations section can be expanded into a short essay
  on when table predictions fail (transition metals, heavy elements, extreme conditions).
- **Reading access:** all lessons define vocabulary in context; the unit README's vocabulary
  list can be printed as a glossary card.

## Assessment guidance

- **Quiz (25 pts), Session 10:** score bands — 21–25: proceed, no reteach beyond warm-ups;
  16–20: reteach the missed lesson(s) in Sessions 11–12 warm-ups; below 16: re-teach Lessons
  01–04 with the supports above and re-administer two or three missed items in Session 16
  before the unit assessment.
- **Unit assessment (50 pts), Session 18:** score bands — 42–50: objectives met; 35–41:
  objectives mostly met, review the weakest part (usually Part D arithmetic or Part E
  justifications) in Session 19; below 35: targeted reteach of the weakest part and a
  second attempt at that part only in Session 20.
- **Project (20 pts):** see the rubric in `project.md`. A report scoring 16+ with all four
  mystery elements correct shows the prediction objectives are met.
- **What "validated draft" means:** this unit's keys were solved independently from its
  questions and checked against the verified values in the unit README. It has not been
  educator-reviewed or merged; the adult's judgment during marking outranks any key entry
  that a learner shows to be wrong with evidence — record such cases in the issue's delivery
  thread for the next revision.
