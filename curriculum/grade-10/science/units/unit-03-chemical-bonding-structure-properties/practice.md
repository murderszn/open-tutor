# Practice Sets — Unit 03

Learner-facing. Solutions are in `answer-key.md` (adult only). Use the Pauling values from
Lesson 01: H 2.20, Li 0.98, C 2.55, N 3.04, O 3.44, F 3.98, Na 0.93, Mg 1.31, Si 1.90, P 2.19,
S 2.58, Cl 3.16, K 0.82, Ca 1.00, Br 2.96. Guides: ΔEN ≥ 1.7 ionic; 0.4–1.7 polar covalent;
< 0.4 nonpolar covalent.

## Set A — Bond classification (Lesson 01)

For each pair, show the ΔEN calculation, name the bond type, and give the electron story in
one sentence (transfer, unequal sharing, or equal sharing).

1. Na–Cl (Na 0.93, Cl 3.16)
2. O–H (O 3.44, H 2.20)
3. C–H (C 2.55, H 2.20)
4. Mg–O (Mg 1.31, O 3.44)
5. N–H (N 3.04, H 2.20)
6. Br–Br (Br 2.96)
7. Ca–F (Ca 1.00, F 3.98)
8. S–O (S 2.58, O 3.44)

## Set B — Lewis structures (Lesson 02)

Draw each structure with all valence electrons accounted for, lone pairs shown, and brackets
with charges for ions. Check each total against the valence count before moving on.

1. Methane, CH₄
2. Ammonia, NH₃
3. Oxygen gas, O₂
4. Nitrogen gas, N₂
5. Hydrogen chloride, HCl
6. Sodium chloride, NaCl (ionic: show the electron transfer result, not a shared pair)
7. Calcium chloride, CaCl₂ (ionic: show both chloride ions)
8. Hydroxide ion, OH⁻

## Set C — Shape and polarity (Lesson 03)

For each molecule, draw (or recall) its Lewis structure, count electron domains on the
central atom, name the shape, give the approximate bond angle, and state polar or nonpolar
with the symmetry reason.

1. Ammonia, NH₃
2. Methane, CH₄
3. Boron trifluoride, BF₃
4. Water, H₂O
5. Carbon dioxide, CO₂
6. Sulfur dioxide, SO₂ (hint: sulfur has one lone pair, one double bond, and one single bond
   in the form used here; count domains, not bonds)

## Set D — Bulk properties (Lesson 04)

1. Rank these from lowest to highest melting point, with a reason for each step:
   CO₂, H₂O, NaCl, Cu, diamond. Use the reference data in Lesson 04.
2. Predict whether each of these conducts electricity, with a reason: solid MgO; molten MgO;
   sugar solution; copper wire.
3. Which of these dissolve readily in water, and why: NaCl, sucrose, copper, diamond?
   (One sentence each.)
4. Explain why graphite conducts electricity but diamond does not, even though both are pure
   carbon. (Use structure, not just names.)
5. A solid is hard, shatters when struck, does not conduct as a solid, but its solution
   conducts. What type is it, and which two observations are the strongest evidence?
6. Predict the melting behaviour and conductivity of calcium fluoride, CaF₂ (ionic, from
   Set A item 7's pattern), and state one property you would test to check your prediction.

## Set E — Designed materials (Lesson 05)

Use the three-step pattern from Lesson 05 (structure → forces → function) for each answer.

1. A phone-charging cable needs a flexible insulator around a conductor. Which part should
   be metal, which part polymer, and why does each structure fit its job?
2. A cutting blade needs to stay sharp through hard use. Why is a network solid a better
   choice than a metal or a polymer for the cutting edge?
3. Explain why a plastic raincoat keeps water out but can still fold into a pocket.
4. Pure silicon conducts poorly. In two or three sentences, explain why adding a tiny number
   of phosphorus atoms makes it conduct, and why this is called a designed material.

## Set F — Mixed review and error analysis (Lesson 06)

1. Classify the bond in potassium bromide, KBr (K 0.82, Br 2.96), with a ΔEN calculation.
2. Draw the Lewis structure for hydrogen sulfide, H₂S, then predict its shape and polarity
   with reasons.
3. Correct each statement, with the reason: (a) "A molecule of salt boils at 1465 °C."
   (b) "Ammonia is tetrahedral because it has four electron domains." (c) "Sugar melts
   easily because its bonds are weak."
4. Hydrogen fluoride has ΔEN = 1.78 but is covalent, not ionic. Explain why, in two or three
   sentences, using both the continuum idea and bulk evidence.
5. Unknown W is a shiny solid that conducts electricity and bends without breaking. What is
   it, and which single observation rules out an ionic lattice?
6. A classmate says: "CO₂ cannot be nonpolar — oxygen is more electronegative than carbon,
   so the molecule must be polar." Write the correction, naming the lesson's key distinction.
