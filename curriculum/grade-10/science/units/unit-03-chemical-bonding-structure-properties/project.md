# Project — Bulk-Properties Investigation (HS-PS1-3)

**Question:** Can bulk observations — solubility, conductivity, and handling — plus published
melting-point data tell you how strongly particles are held together in a substance, and
therefore what kind of bonding it has?

**Time:** Sessions 9, 12, 14, and 16 (plus report writing). **Adult supervision required
throughout.** No sample is heated. No unknown household substance is tested: Part B unknowns
are paper-only practice data.

## Materials

- Table salt (sodium chloride), granulated sugar (sucrose), clean sand (silicon dioxide) —
  small samples, each in a labeled cup. A short length of copper wire.
- Room-temperature water, three clear cups, spoons, goggles.
- Conductivity tester: a 9 V battery, a small LED, insulated wires, and two metal probes,
  assembled by the adult and checked before use. If any wire feels warm, stop and tell the
  adult at once. Never connect the tester to a wall outlet or any mains supply.
- Notebook, Lesson 04 reference-data table, this project's data table (below).

## Safety rules (adult reads aloud before Station 1)

1. Goggles on whenever a solid is crushed or a solution is stirred vigorously.
2. The adult assembles and approves the conductivity tester; the learner never strips wires
   or changes the battery connections.
3. Never taste any sample. Never test anything not listed above.
4. Spills are wiped up at once; salt and sugar solutions go down the sink with running water.
5. Simulation alternative: if materials or supervision are unavailable, use the PhET
   simulations in the resource pack and the worked dataset in Part B — the same inferences
   can be made from the reference table plus the fictional unknowns, and the report states
   clearly that no bench work was done.

## Part A — Stations (Session 9)

### Station 1 — Solubility

For each solid (salt, sugar, sand): add one level spoonful to a cup with the same amount of
room-temperature water, stir for one minute, and record: dissolves readily / dissolves slowly
or partly / hardly dissolves. Record the appearance of the liquid (clear, cloudy, solid
remaining).

### Station 2 — Conductivity

With the adult's tester, test each of these in turn and record LED on (bright/dim) or off:
(a) the dry solid pressed against both probes (salt, sugar — do not press hard enough to
break the probes); (b) distilled or tap water alone; (c) the salt solution from Station 1;
(d) the sugar solution from Station 1; (e) the copper wire held across both probes (adult
holds the wire). Record every result, including "off" results — a negative result is data.

### Station 3 — Handling

Try to bend the copper wire (it bends). Press the back of a spoon gently onto a few grains of
salt and then sugar on a hard surface (they crush to powder; they do not bend). Record:
bends / crushes / neither, for each solid.

### Data table (copy into your notebook)

| Substance | Solubility in water | Conducts: solid? | Conducts: solution? | Handling | Reference melting point (Lesson 04) |
|---|---|---|---|---|---|
| Salt (NaCl) | | | | | 801 °C |
| Sugar (sucrose) | | | | | Decomposes ~186 °C |
| Sand (SiO₂) | | | | | 1713 °C (quartz) |
| Copper wire (Cu) | | | | | 1085 °C |

Expected pattern (check your results against it, and report any disagreement honestly):
salt dissolves readily and its solution conducts; sugar dissolves readily but its solution
does not conduct; sand hardly dissolves and does not conduct; copper does not dissolve but
conducts as a solid and bends.

## Part B — Inference and unknowns (Session 12)

1. For each Part A substance, write one paragraph: what bond type does the evidence support,
   and which single observation is the strongest evidence for it?
2. Now identify the four fictional unknowns. These are **practice data, not real samples**:
   do not try to find or test substances matching them.

| Unknown | Dissolves in water? | Conducts as solid? | Conducts in solution? | Handling / melting |
|---|---|---|---|---|
| U1 | Readily | No | Yes | Hard, brittle; high melting point |
| U2 | No | Yes | — (does not dissolve) | Bends without breaking; high melting point |
| U3 | Readily | No | No | Soft; decomposes at a low temperature |
| U4 | No | No | No | Very hard; very high melting point |

For each unknown, state the most likely bond type, rule out at least one alternative with a
reason, and name one further test that would strengthen (or overturn) your identification.

3. Write the general rule your group used: "If a solid does X and Y, then its particles are
   probably held by ___ because ___." Test your rule against all four Part A substances
   and all four unknowns; if it fails anywhere, revise the rule and say what changed.

## Part C — Report and peer review (Sessions 14 and 16)

Write a structured report (Unit 01 format): question, procedure, data table with units,
inference for each substance and unknown, error analysis, conclusion. The error analysis
must cover at least: (a) one way the conductivity test could give a false "off" (for example,
poor probe contact, a flat battery, or too little solid dissolved); (b) why the melting-point
column is reference data, not a classroom measurement, and what that means for the strength
of the melting inference; (c) one observation in your own data that did not match the
expected pattern, or, if all matched, one way the design could still mislead (for example,
testing only one concentration).

Present the report in 3 minutes (Session 16), take peer questions, and revise one section in
response to feedback. The revised report is the submitted product.

## Rubric (20 points)

| Criterion | Full marks | Partial | Missing |
|---|---|---|---|
| Data table (5) | All stations, all substances, units and "off" results recorded | Gaps in one station or substance | Table missing or invented results |
| Inference (5) | Every substance and unknown assigned a type with a stated strongest evidence and one ruled-out alternative | Assignments present but reasons thin or one alternative missing | Types asserted without evidence |
| Report structure (5) | Question, procedure, data, inference, error analysis, conclusion all present | One section missing or merged unclearly | No recognisable structure |
| Error analysis (5) | Covers false "off", reference-data status, and one mismatch or design weakness | Two of three covered | One or none covered |

**Scoring note:** a report that honestly records a result disagreeing with the expected
pattern, and explains it, scores higher on error analysis than a report that silently
"corrects" the result to match. Invented data scores zero on the data-table criterion.
