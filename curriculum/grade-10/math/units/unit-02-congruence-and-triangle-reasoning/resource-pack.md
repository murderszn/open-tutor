# Resource Pack — Unit 02: Congruence, Rigid Motions, and Triangle Reasoning

**Goal:** Give a grade-10 learner (and guiding adult) free, no-account
routes to every core objective: rigid motions as functions, composition
results, the rigid-motion definition of congruence, the four triangle
criteria, the perpendicular-bisector theorem, and triangle reasoning.
**Age fit:** high-school geometry (grade 10); the adult previews every
link for advertising, comments, and suitability before the learner opens
it.

## Web references

Checked 2026-10-20 unless noted.

1. **Common Core State Standards — High School Geometry: Congruence
   (G-CO)** — the official domain page; G-CO.A.2 through G-CO.C.10
   state exactly this unit's targets (transformations as functions,
   symmetry, composition, rigid-motion congruence, the criteria,
   perpendicular-bisector and triangle theorems). Descriptions in the
   unit README are paraphrases of this page. Free, no account.
   <https://www.thecorestandards.org/Math/Content/HSG/CO/>
2. **Math is Fun — Transformations** — clear illustrated page on
   rotation/reflection/translation ("turn, flip, slide"), resizing as
   the non-rigid contrast, and the congruent-vs-similar distinction.
   Good first-reading for Lesson 01; pairs with the unit's dilation
   non-example. Free, no account.
   <https://www.mathsisfun.com/geometry/transformations.html>
3. **Euclid's *Elements*, D. E. Joyce edition (Clark University)** —
   complete text of all 13 books; Book I, Propositions 4 (SAS), 5
   (base angles — the *pons asinorum*), and 8 (SSS) are the S13
   reading. Public-domain translation lineage (Heath). Note: the
   interactive figures use dated Java applets — use the text and
   static figures.
   <https://aleph0.clarku.edu/~djoyce/java/elements/elements.html>
4. **GeoGebra Geometry** — free dynamic-geometry app (no account) for
   the S4 transformation lab, the project simulation alternative, and
   checking hand-drawn images. Browser-based; the adult previews for
   advertising and age suitability. (URL verified 2026-10-20; app
   content loads via JavaScript.)
   <https://www.geogebra.org/geometry>
5. **Desmos graphing calculator** — free, no-account coordinate grid
   for checking image coordinates from Lessons 01–02. (URL verified
   2026-10-20; app content loads via JavaScript.)
   <https://www.desmos.com/calculator>
6. **Khan Academy — High school geometry: Congruence** — practice and
   video unit covering transformations and triangle congruence. URL
   resolves (checked 2026-10-20); the page is JavaScript-driven and
   its lesson list could not be text-verified here — the adult
   previews before assigning. Free, no account.
   <https://www.khanacademy.org/math/geometry/hs-geo-congruence>
7. **Unit 01 materials (internal)** — `../unit-01-geometry-foundations/`
   lessons 03 (perpendicular-bisector construction — the theorem proved
   in Lesson 04 closes its honesty gap) and 05 (parallel-line angle
   theorems — used in Lesson 05's angle-sum proof). Reuse, don't
   re-teach.

## Access notes

Every core objective has a free, no-account route: the lessons
themselves (explicit teaching), tracing-paper constructions, web refs
1–3, and the labeled search links. GeoGebra and Desmos are optional
enhancements, never required — every lab has a paper alternative.
Videos supplement the lessons; none replaces the written proofs.
