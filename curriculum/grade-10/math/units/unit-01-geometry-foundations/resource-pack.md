# Resource Pack — Unit 01: Geometry Foundations

**Goal:** Give a grade-10 learner (and guiding adult) free, no-account
routes to every core objective: precise geometric language, classical
constructions, and first proofs. **Age fit:** high-school geometry
(grade 10); the adult previews every link for advertising, comments, and
suitability before the learner opens it.

## Web references

Checked 2026-10-13 unless noted.

1. **Euclid's *Elements*, D. E. Joyce edition (Clark University)** —
   complete text of all 13 books with figures; Book I holds the
   definitions, postulates, and first propositions this unit echoes.
   Public-domain translation lineage (Heath). Note: the interactive
   figures use dated Java applets — use the text and static figures.
   <https://aleph0.clarku.edu/~djoyce/java/elements/elements.html>
2. **Math Open Reference — Constructions index** — step-by-step animated
   constructions (copy segment/angle, bisectors, perpendiculars,
   parallels, inscribed polygons) with printable worksheets. Free, no
   account.
   <https://www.mathopenref.com/tocs/constructionstoc.html>
3. **GeoGebra Geometry** — free dynamic-geometry app (no account) for
   checking hand constructions and exploring angle relationships.
   Browser-based; the adult previews for advertising and age suitability.
   <https://www.geogebra.org/geometry>
4. **Common Core State Standards — Mathematics, High School Geometry** —
   the official domain pages (G-CO, G-SRT, G-C, G-GPE, G-GMD, G-MG) used
   for this unit's standards crosswalk; read 2026-10-07 during the track
   audit. Reference only — not learner-assigned.
   <https://www.thecorestandards.org/Math/>
5. **Khan Academy — Geometry (full course page)** — free practice and
   articles aligned to the same high-school geometry topics; useful for
   extra angle-chasing practice. Free, account optional.
   <https://www.khanacademy.org/math/geometry>
6. Internal: `resources/math_fundamentals.md` — **bridge reference
   only** (grades 4–7 band): integer/fraction warm-ups if equation
   solving is insecure; never assigned as grade-10 instruction.
7. Internal: `resources/weights_and_measures.md` — unit-conversion
   reference supporting the N-Q.3 precision work (mm/in conversions);
   the adult checks any conversion fact before use.

## Safety & notes

- Every external link above was opened 2026-10-13 except the labeled
  search links, which the adult must run and preview. Re-check any link
  before reuse in a later school year — URLs and page content change.
- No video here replaces the lessons' explicit teaching; videos
  supplement and offer a second voice.
- At least one free, no-account route supports each core objective:
  notation (Video 1), measurement (Video 2), every construction
  (Math Open Reference), proof models (Euclid text + search links),
  digital checking (GeoGebra). Nothing required in this unit sits behind
  a login or paywall.
