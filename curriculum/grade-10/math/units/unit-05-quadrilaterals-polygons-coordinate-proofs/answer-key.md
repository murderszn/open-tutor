## Lesson 01 — Polygon angle sums

1. Interior sum for n = 6: (6 − 2) · 180° = 720°. Known angles add
   to 120 + 130 + 110 + 140 + 125 = 625°. Unknown = 720 − 625
   = **95°**.
2. Exterior = 360° / n = 360° / 15 = **24°**. Interior = 180° − 24°
   = **156°**. (The question states the exterior angle; the
   interior follows by supplementary angles.)
3. Regular octagon: interior sum = (8 − 2) · 180° = 1080°; each
   interior angle = 1080° / 8 = **135°**.
4. 12-gon: (12 − 2) · 180° = **1800°**. 15-gon: (15 − 2) · 180° =
   **2340°**.
5. Exterior method: exterior = 180° − 162° = 18°; n = 360° / 18° =
   **20**. Algebra: (n − 2) · 180 = 162n → 180n − 360 = 162n →
   18n = 360 → n = **20**. A 20-gon (icosagon).
6. Known angles add to 100 + 110 + 120 + 90 = 420°. Pentagon sum =
   540°, so x = 540 − 420 = **120°**. It is less than 180° because
   this is a convex pentagon, whose every interior angle is under
   180°; a value of 180° or more would make the figure concave or
   degenerate.
7. (a) Hexagon interior = 120°; octagon interior = 135°. The
   octagon's is larger, by **15°**. (b) The gap angle at a shared
   corner is 360° − 120° − 135° = **105°** (the angles around a
   point add to 360°).
8. Interior-angle sum = (n − 2) · 180°; exterior-angle sum = 360°.
   The exterior sum is one full turn around the polygon, so it
   cannot depend on how many sides the turn is split into.

## Lesson 02 — Parallelogram theorems

1. Opposite sides: YZ = WX = **9**; WZ = XY = **4**. Opposite
   angles: ∠Y = ∠W = **105°**. Consecutive angles supplementary:
   ∠X = ∠Z = 180° − 105° = **75°**. Check: 105 + 75 + 105 + 75
   = 360°. ✓
2. AC = 2 · AE = **10**; BD = 2 · BE = **14**. It is not necessarily
   a rectangle: bisecting diagonals are a property of every
   parallelogram; a rectangle needs the diagonals to be congruent,
   which is not given.
3. Half-diagonals are 6 and x with hypotenuse 10: 6² + x² = 10² →
   x² = 64 → x = 8. Other diagonal = **16**.
4. Opposite angles are congruent: 3x + 10 = x + 50 → 2x = 40 →
   x = **20**. ∠A = ∠C = 3(20) + 10 = **70°**; ∠B = ∠D = 180° −
   70° = **110°**.
5. Proof (paragraph): let the diagonals AC and BD meet at E. In
   △AEB and △CED, AB = CD (opposite sides of a parallelogram),
   ∠BAE = ∠DCE and ∠ABE = ∠CDE (alternate interior angles from
   the parallel sides), so △AEB ≅ △CED by ASA. Then AE = CE and
   BE = DE by CPCTC, so E is the midpoint of both diagonals — the
   diagonals bisect each other, which is the Lesson 04 test for a
   parallelogram. The equal vertical angles at E are what make the
   ASA argument work.
6. Other side = √(13² − 5²) = √(169 − 25) = √144 = **12**. The
   diagonal is the hypotenuse of the right triangle formed by two
   sides, and the hypotenuse is always the longest side.
7. (a) The diagonal should be √(6² + 8²) = √100 = **10 m**.
   (b) 9.8 m is 0.2 m short of 10 m, outside the 0.1 m tolerance,
   so **no** — the bed is not a true rectangle (or the measurement
   is off by more than the tolerance allows).
8. The three theorems: opposite sides are congruent; opposite angles
   are congruent; the diagonals bisect each other. A right angle (or
   congruent diagonals) makes a parallelogram a rectangle; congruent
   adjacent sides (or perpendicular-bisector diagonals) make it a
   rhombus.

## Lesson 04 — Coordinate proofs

1. Slopes: AB = 0, BC = 2, CD = 0, DA = 2. AB ∥ CD and BC ∥ DA:
   **parallelogram**. AB = 3, BC = √5 — adjacent sides unequal,
   so not a rhombus; no adjacent slopes multiply to −1, so not a
   rectangle.
2. The diagonals share the midpoint (2, 3), so they bisect each
   other: that proves a **parallelogram**. It does not prove a
   rectangle — that would need congruent diagonals (or a right
   angle), which is not given.
3. **D = (0, 4).** By slopes: AB is horizontal, BC vertical, CD
   horizontal, DA vertical — a rectangle. By midpoints: midpoint
   of AC = (3, 2); midpoint of BD = ((6 + 0)/2, (0 + 4)/2) =
   (3, 2). ✓
4. Slopes: MN = 1/4, NO = 4, OP = 1/4, PM = 4 → parallelogram.
   Distances: MN = √17, NO = √17, OP = √17, PM = √17 — all four
   sides equal → **rhombus**. Adjacent slopes multiply to 1, not
   −1, so no right angle: not a square. (Diagonals MO = 5√2,
   NP = 3√2, unequal — consistent with a rhombus that is not a
   rectangle.)
5. All four sides: AB = √(9 + 4) = √13; BC = √(9 + 4) = √13; CD
   = √13; DA = √13. All equal → **rhombus**. Diagonals: AC = 6,
   BD = 4 — unequal, so not a square. Diagonal slopes: AC = 0, BD
   undefined (vertical) — perpendicular, as a rhombus's diagonals
   must be.
6. **Parallelogram: yes** (slopes 0, 3, 0, 3 — two pairs parallel).
   **Trapezoid: no** (exclusive definition: it has two pairs of
   parallel sides, not exactly one). **Rectangle: no** (adjacent
   slopes 0 and 3 multiply to 0, not −1).
7. (a) Slopes 0 (bottom/top) and undefined (sides) give right
   angles; opposite sides 80 and 60: **rectangle**. (b) Not a
   square: 80 ≠ 60. (c) Diagonal = √(80² + 60²) = √10000 =
   **100 m**.
8. The test chain: (1) slopes of all four sides; (2) adjacent-slope
   products for right angles; (3) side distances; (4) diagonal
   midpoints; (5) diagonal lengths. The **diagonal-midpoint test**
   alone proves a parallelogram: equal midpoints mean the diagonals
   bisect each other.

   = **$688.50**. Turf: 88 m² × $9 = **$792.00**. (Fictional
   practice prices; fencing + turf together $1,480.50.)
8. Section formula in words: the point m/(m + n) of the way from A
   to B — a weighted average with B's coordinates weighted by m
   and A's by n. Shoelace: list the vertices in order, sum the
   cross-products one way, subtract the cross-products the other
   way, halve the absolute value. Order matters because each term
   is a signed triangle area from the origin; going around in order
   lets the outside parts cancel, while a crossed order cancels
   everything.
