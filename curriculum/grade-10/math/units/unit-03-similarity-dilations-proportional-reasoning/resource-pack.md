# Resource Pack — Unit 03: Similarity, Dilations, and Proportional Reasoning

**Goal:** Give a grade-10 learner (and guiding adult) free,
no-account routes to every core objective: dilations and their
image properties, the similarity definition, the AA criterion,
the side-splitter theorem and its converse, Pythagoras by
similarity, indirect measurement, scale drawings, area/volume
scaling, and slope criteria by similar triangles.
**Age fit:** high-school geometry (grade 10); the adult previews
every link for advertising, comments, and suitability before the
learner opens it.

## Web references

Checked 2026-10-27 unless noted.

1. **Common Core State Standards — High School Geometry:
   Similarity, Right Triangles, and Trigonometry (G-SRT)** —
   the official domain page; G-SRT.A.1 through G-SRT.B.5 state
   exactly this unit's targets (dilation properties, similarity
   definition, AA, side-splitter and Pythagoras-by-similarity,
   criteria applications). Descriptions in the unit README are
   paraphrases of this page. Free, no account.
   <https://www.thecorestandards.org/Math/Content/HSG/SRT/>
2. **Common Core State Standards — High School Geometry:
   Expressing Geometric Properties with Equations (G-GPE)** —
   the official domain page; G-GPE.B.5 states the slope
   criteria for parallel and perpendicular lines used in
   Lesson 05. Free, no account.
   <https://www.thecorestandards.org/Math/Content/HSG/GPE/>
3. **Math is Fun — Similar** — clear illustrated page defining
   similar shapes via resize, flip, slide, and turn; states
   that similar shapes have equal corresponding angles and
   sides in proportion; includes the "all circles are similar"
   argument. Good first reading for Lesson 02. Free, no
   account.
   <https://www.mathsisfun.com/geometry/similar.html>
4. **Euclid's *Elements*, D. E. Joyce edition (Clark
   University), Book VI** — complete text; Definition 1
   (similar figures), Proposition 2 (the side-splitter theorem
   and its converse), Proposition 4 (equiangular triangles
   have proportional sides), Proposition 8 (altitude to the
   hypotenuse), and Propositions 19–20 (the "duplicate ratio"
   for areas of similar figures — the k² rule in Euclid's
   language). Public-domain translation lineage (Heath). The
   S8 reading uses Propositions 2 and 4; Proposition 8 and
   19–20 are extension reading.
   <https://aleph0.clarku.edu/~djoyce/java/elements/bookVI/bookVI.html>
5. **GeoGebra Geometry** — free dynamic-geometry app (no
   account) for the Lesson 01 dilation lab, the similarity
   checks, and the project simulation alternative; the same
   tool used in Units 01–02. The adult previews for
   advertising and age suitability.
   <https://www.geogebra.org/geometry>
6. **Internal reference — resources/math_fundamentals.md**
   (grades 4–7 bridge reference only) — proportion and ratio
   fluency warm-ups where grade-9 skills are insecure; never
   assigned as grade-10 instruction. See the track
   scope-and-sequence for the reuse note.
   [resources/math_fundamentals.md](../../../../../resources/math_fundamentals.md)
7. **Internal reference — resources/weights_and_measures.md**
   — unit-conversion reference for Lesson 04's map and scale
   work (cm/m/km conversions); the adult checks conversion
   facts before use.
   [resources/weights_and_measures.md](../../../../../resources/weights_and_measures.md)

  standards pages, Math is Fun, Euclid (public domain), and
  GeoGebra. Videos supplement teaching; they never replace the
  lessons.

  search links are adult-run and adult-previewed; the learner
  never needs a YouTube account.
- If a link fails, use the focused queries above to find an
  equivalent reputable source, and preview it before assigning.
