# Formative Quiz — Unit 04 (Track Week 18)

**Session 16 of 20 · 12 questions · 20 points.** Answer in writing, orally,
or by model — the adult records the response mode. No stage-name-only
answers: every stage answer must name an event.

1. (2 pts) A cell is in S phase. What is it doing, and why must this
   happen before division?
2. (1 pt) Name the three stages of interphase in order.
3. (2 pts) A cell has 2n = 6. State chromosomes and chromatids (a) after
   S phase, (b) in each daughter cell after mitosis.
4. (2 pts) Put these mitosis stages in order and name one event per
   stage: anaphase, prophase, telophase, metaphase, prometaphase.
5. (1 pt) Mitosis produces two cells that are genetically _______ to the
   parent (one word).
6. (2 pts) A parent cell has 2n = 4. After meiosis, how many cells result
   and how many chromosomes does each carry? Show the two divisions in
   your answer.
7. (2 pts) Define crossing over and independent assortment, one sentence
   each, and say which meiosis-I stage each belongs to.
8. (2 pts) A fruit fly has n = 4 pairs. How many chromosome combinations
   can independent assortment alone produce? Show the calculation.
9. (2 pts) A student claims, "All heritable variation comes from
   meiosis." Using the Lesson 5 dataset logic, name one other source and
   the experiment number that supports it.
10. (1 pt) A skin cell and a nerve cell have the same DNA but do different
    jobs. What is the one-word term for which genes are active in a cell?
11. (2 pts) A human gamete carries 24 chromosomes because one pair failed
    to separate in meiosis I. If fertilized by a normal gamete (23), how
    many chromosomes does the zygote carry? Name the failure.
12. (1 pt) True or false: "A tumor is a mass of cells dividing without
    normal control." If false, correct it.

**Scoring:** 18–20 secure; 14–17 mostly secure, re-teach the missed
objective in Session 17; below 14, re-teach with the teacher guide's
targeted follow-ups before the unit assessment.
