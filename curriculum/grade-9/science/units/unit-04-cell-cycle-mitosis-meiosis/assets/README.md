## one-cell-becomes-two.png (generated raster image)

- **File:** `one-cell-becomes-two.png`
- **Prompt:** "Flat, simple educational illustration for a high-school
  biology lesson, no text, no labels, no people, exactly three panels
  left to right: first panel, one large round parent cell containing
  exactly four short rod-shaped chromosomes (two dark blue rods, two
  light blue rods); second panel, the same cell pinched in the middle
  into two lobes, each lobe containing exactly four rods (two dark blue,
  two light blue); third panel, two separate smaller identical daughter
  cells side by side, each containing exactly four rods (two dark blue,
  two light blue). Clean white background, bold outlines, uncluttered,
  suitable for counting chromosomes in a classroom activity."
- **Tool:** Muse built-in image generation (`media.generate_image`),
  2026-11-02. A first generation was rejected on inspection: its middle
  panel showed 3 rods per lobe instead of 4. The second generation was
  accepted.
- **Intended use:** Lesson 2 readiness check and counting activity
  ("How many rods in the parent? How many in each daughter?").
- **Factual review (inspected 2026-11-02):** Parent panel: 4 rods (2
  dark blue, 2 light blue) — correct for the 2n = 4 model cell. Middle
  panel: each lobe holds 4 rods (2 dark, 2 light) — correct. Daughter
  panels: each holds 4 rods (2 dark, 2 light) — correct and identical to
  the parent. Colors mark chromosome pairs only; they carry no other
  meaning. The image is a simplified model, not a micrograph: real
  chromosomes are not smooth rods, and a dividing cell does not look
  this tidy.
- **Caption (as used in Lesson 2):** "Left: a parent cell with four
  rod-shaped chromosomes — two dark blue, two light blue. Middle: the
  cell pinching apart, each side receiving the same four rods. Right:
  two daughter cells, each with the same four rods as the parent."
- **Alt text:** "Three-panel diagram: one large cell with four rod
  shapes inside (two dark blue, two light blue); the same cell pinched
  in the middle with four rods on each side; two smaller cells, each
  with the same four rods."
- **Text-only alternative:** Parent cell: 4 rods (2 dark blue, 2 light
  blue). Dividing cell: two lobes, each with 4 rods (2 dark blue, 2
  light blue). Daughter cells: two cells, each with 4 rods (2 dark blue,
  2 light blue). Question answered from this alternative alone: "How
  many chromosomes does each daughter cell have, and how does that
  compare with the parent?" Answer: 4 each — the same as the parent.
- **Known limitations:** The image shows the outcome of mitosis, not
  its stages, and it does not show chromatid pairs, spindle fibers, or
  cytokinesis mechanics. Stage-by-stage structure comes from the
  deterministic SVG below, not from this illustration.

## cell-division-stages.svg (deterministic diagram)

- **File:** `cell-division-stages.svg`
- **Method:** hand-written SVG; every chromosome count is a text label,
  never color alone. Chromosome counts follow the unit's 2n = 4 model
  cell and were checked against the answer key.
- **Intended use:** Lessons 2–4 stage reference; the project modeling
  template; the text-and-table alternative for learners who cannot use
  pipe cleaners.
- **Reading the diagram:** Top row, mitosis: parent (2n = 4) → after S
  (4 chromosomes, 8 chromatids) → metaphase (4 chromosomes, 8
  chromatids on the plate) → two daughters (4 chromosomes each).
  Bottom row, meiosis: parent (2n = 4) → after S (4 chromosomes, 8
  chromatids) → after meiosis I (2 cells, 2 chromosomes each) → after
  meiosis II (4 cells, 2 chromosomes each, n = 2).
