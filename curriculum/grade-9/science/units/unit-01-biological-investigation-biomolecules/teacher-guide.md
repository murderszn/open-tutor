# Teacher Guide — Unit 01: Biological Investigation and Biomolecules

Adult-facing. Student lessons, practice, and assessments link here; the
[answer key](answer-key.md) holds all solutions.

## Unit at a glance

Twenty 50-minute sessions across track weeks 3–6. Weeks 3–5 build the two
strands — investigation design/evidence (Sessions 1–4, 7–9) and biomolecule
modeling (Sessions 5–6, 10–13); week 6 is report, critique, check, review,
present, and assess. The unit serves track objectives 1 and 2 and standard
HS-LS1-6.

## Session-by-session facilitation notes

- **S1 (L1):** run the two-cup bean demo live. The readiness check is the
  whole lesson in miniature — do not skip it.
- **S2 (Practice A):** let the learner find flaws before you name them;
  the rewrite challenge is the session's real product.
- **S3 (L2):** keep the two-column "Sensed it / Concluded it" chart up all
  lesson. Physically separate the columns — learners remember the spatial
  split.
- **S4 (Practice B):** the learner's data table from task 1 is the actual
  table used in Sessions 8–9. Review it tonight if needed.
- **S5 (L3):** show the generated illustration *after* teaching the four
  classes, so predictions use new knowledge. State the honest framing
  aloud: the picture is a prompt, not evidence.
- **S6 (Reference):** you read aloud; the learner tracks ideas. If the
  session stalls, use the accessibility fallback — the ideas are the
  requirement, not the source.
- **S7 (L4):** approve the lab plan tonight. Confirm allergies and that
  *you* will handle iodine.
- **S8–S9 (Lab):** set a visible timer for the 30-second iodine reads and
  the 2-minute paper waits. Photograph results as backup. Enforce the
  separate-pen rule for inferences.
- **S10 (L5):** count tokens with the learner — do not pre-count for them.
  The SVG's text equivalent works as a printed handout.
- **S11 (Practice C):** the CSV lookup needs a spreadsheet app or a
  printed excerpt of the five element rows.
- **S12 (L6):** label the nitrogen-source tokens "simplified stand-in"
  every time they are touched.
- **S13 (Practice D):** the peer-swap works with you as the partner.
- **S14–S15:** protect the critique time — Session 15's revision is
  graded. A learner who "has nothing to revise" has not looked hard
  enough; prompt with "which result surprised you most?"
- **S16 (Quiz):** score same-day; sort misses by objective for S17.
- **S17 (Review):** re-teach only the lowest objective(s); use the
  re-check bank below.
- **S18 (Presentations):** ask the challenge question last, after the
  learner has shown everything.
- **S19 (Flex):** catch-up, or the Lesson 3/6 extensions.
- **S20 (Assessment):** calm conditions; scribe if needed.

## Misconception watch (across the unit)

1. "The thing I care about is the independent variable." Re-anchor every
   time: *independent = changed by the investigator*.
2. "I observed that it has starch." Redirect to sensed language, then
   license the inference through the test's rule.
3. "Reasoning = restating the evidence." Require the scientific idea, not
   the data repeated.
4. "Nucleic acids are only in the genetics unit." Every cell, every food
   made of cells, from Lesson 3 onward.
5. "Water is created from nothing in dehydration synthesis." Its atoms came
   from the monomers — count them.
6. "The model is wrong because molecules aren't colored balls." A model is
   judged by what it shows (atom accounting), not by being the thing.
7. "One negative trial ruins the experiment." Variation is data; hiding it
   is the only real error.

## Reteaching map

| If the learner misses... | Re-teach with... | Re-check with... |
|---|---|---|
| Variables/controls/trials | L1 worked examples + Practice A #5 (rewrite) | Two new scenarios: "the music-and-plants test," "the fertilizer test with 2 plants" |
| Observation vs. inference | L2 two-column chart + Practice B #2 (sloppy records) | Classify 6 new statements; write one CER from a fresh demo |
| Biomolecule classes/atoms | L3 cards + the illustration re-sort | Name classes/atoms for 4 new foods from labels |
| Atom inventory | L5 tokens + Practice C #1–2 | A new 2-monomer and 3-monomer inventory |
| CER writing | Practice D #1–4 | Rewrite one weak CER from the learner's own report |
| HS-LS1-6 explanation | L6 Worked example 1 rebuild | "Explain to a 7th grader" 5-sentence version |

## Re-check bank (for quiz/assessment follow-ups)

1. Name the variables in: "Does sugar amount change how fast ice melts?"
   (Independent: sugar amount; dependent: melt time; controlled: ice size,
   temperature, container.)
2. "The paper stayed translucent after 2 minutes." Observation or
   inference? (Observation.)
3. Which atoms in a protein are not in a carbohydrate? (Nitrogen.)
4. Join two fictional monomers C₄H₈O₄ + C₄H₈O₄ by dehydration synthesis:
   show the inventory. (Start: 2 × 16 = 32 atoms; minus one water
   water 3 = 29; C 8, H 14, O 7.)

## Readiness criteria — moving to Unit 02

The learner is ready when: the project rubric totals ≥ 20 with no row at
1; the unit assessment totals ≥ 26; and the learner can state the HS-LS1-6
claim and run a conservation check without prompting. If not, use flex
weeks before Unit 02 — Unit 02's osmosis investigation assumes all of
this.

## Safety summary

Adult handles iodine; nothing tasted; hands washed; allergy check before
food selection; brown-paper test has no chemical hazard. The label-only
alternative removes all reagent handling with no objective lost.

## Accessibility notes

- Spreadsheet alternative to hand tables (keyboard: tab/arrow navigation;
  the adult confirms the app's shortcuts).
- Token models: color + letter stamp; large-format tokens available on
  request (the adult makes them).
- All sessions have a seated-table variant; the lab's observation-only
  alternative covers mobility and allergy constraints.
- The generated illustration's text alternative is the activity's
  equivalent path — never an afterthought.
