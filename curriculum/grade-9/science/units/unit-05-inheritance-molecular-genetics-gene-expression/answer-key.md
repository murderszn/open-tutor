## Lesson 01

**Guided practice**

1. Complement of 5'-C C A T G G-3' is 3'-G G T A C C-5'; written 5' → 3'
   it reads 5'-C C A T G G-3' — this sequence is self-complementary (the
   complement read backwards is the original). Accept either direction
   labeling as long as the pairing is right.
2. 12 base pairs × 2 nucleotides per pair = **24 nucleotides**.
3. Wrong: A pairs with T, not G. A and G are both purines (two-ring
   bases); an A–G rung would be too wide. Correct pairings: A–T, G–C.
4. Strand 5'-G G G A A A-3': 3 G–C pairs (3 × 3 = 9 bonds) + 3 A–T pairs
   (3 × 2 = 6 bonds) = **15 hydrogen bonds**.
5. Accept: each strand is a template for the other — because A pairs only
   with T and G only with C, building the matching partner for each base
   reproduces the original sequence exactly.

**Independent practice**

1. Complement of 5'-A T C G T A C G-3' is 3'-T A G C A T G C-5'; written
   5' → 3': **5'-C G T A C G A T-3'**.
2. A = 30%, so T = 30% (A pairs with T). Remaining 40% is G + C, split
   equally: **G = 20%, C = 20%**.
3. C = 22%, so G = 22%. A + T = 100% − 44% = 56%, split equally:
   **A = 28%, T = 28%**.
4. Accept any labeled sketch with: two sugar–phosphate backbones, six
   rungs as A–T or G–C pairs, and a 5' → 3' direction marked on one
   strand (the other runs the opposite way).
5. Accept: the strands must run in opposite directions so that each
   base meets its partner along the whole molecule — the 5' end of one
   strand lines up with the 3' end of the other. If both ran the same
   way, the pairing geometry would not line up.
6. Accept, e.g.: "A gene is a segment of DNA that codes for a product,
   such as a protein. A chromosome is one very long DNA molecule, packaged
   with proteins. Genes are segments along a chromosome — one chromosome
   carries many genes."

## Lesson 02

**Guided practice**

1. Template 3'-T A C C C A A T T-5' → mRNA 5'-A U G G G U U A A-3'.
2. AUG → Met; GGU → Gly; UAA → Stop. Protein: **Met–Gly** (translation
   ends at the stop codon).
3. Right: UAA is a stop codon, so translation ends. Missing: the protein
   is *complete* at two amino acids (Met–Pro) — the stop codon is not a
   missing amino acid, it is the end signal.
4. UUU and UUC both code for Phe — the protein is unchanged. A **silent**
   change.
5. Accept: the DNA is the protected master copy and stays in the nucleus;
   the cell sends mRNA copies to the ribosomes instead, and can make many
   copies from one gene.

**Independent practice**

1. Coding strand 5'-A T G C C A T A A-3' → mRNA 5'-A U G C C A U A A-3' →
   **Met–Pro**, then stop (UAA).
2. Template 3'-T A C G G C A T A C T T-5' → mRNA 5'-A U G C C G U A U G A
   A-3' → **Met–Pro–Tyr–Glu**.
3. Original mRNA 5'-A U G C C U A C G U A A-3' → Met–Pro–Thr–Stop. Delete
   the C at position 5: new mRNA 5'-A U G C U A C G U A A-3' → codons AUG
   CUA CGU → **Met–Leu–Arg**, and no stop codon remains in frame (the
   message runs out after two leftover bases). The deletion shifts the
   reading frame, so every codon after it is read differently.
4. GAA and GAG both code for Glu — the protein is unchanged. A **silent**
   change.
5. AAA codes for Lys; UAA is a stop codon — a **nonsense** change.
   Translation ends at that point, so the protein is cut short and almost
   certainly cannot do its job. More serious than item 4 because it
   truncates the protein instead of leaving it unchanged.
6. Accept, e.g.: "DNA holds the instructions in the nucleus. mRNA carries
   a working copy of one gene out to the ribosome. The ribosome reads the
   mRNA's codons and builds the protein, amino acid by amino acid."
7. Counterexample: the UUU → UUC change in guided practice 4 (or GAA →
   GAG in item 4) — the codon changes but codes for the same amino acid,
   so the protein is identical.

## Project

**Part 1 — Alvarez pedigree genotypes:** I-1 **Ee** (free, but has an
attached child II-2, so gave e and must also carry E); I-2 **ee**
(attached); II-1 **Ee** (free, received e from I-2 and E from I-1); II-2
**ee** (attached); II-3 **Ee** (same reasoning as II-1); II-4 **ee**
(attached); II-5 **Ee** (free, but has an attached child III-3, so gave e
and must also carry E); III-1 **Ee** (free, from II-1 Ee × II-4 ee);
III-2 **ee** (attached); III-3 **ee** (attached). P(II-1 × II-4 next
child attached) = **1/2** (Ee × ee test cross).

**Part 2 — Population data:** expected at 3:1 in 400 plants: **300
purple, 100 white**. Deviations: 296 − 300 = **−4**; 104 − 100 = **+4**
(1 percentage point each). The 40-plant version (29 purple, 11 white)
has the same percentages but expected counts of 30 and 10, so the same
4-plant total deviation is 10 percentage points — a weaker test. The
dataset cannot *prove* the model; a repeat cross with another trait, or
more plants, would strengthen it.

**Part 3 — CER claims:** (1) Recessive — the trait appears in III-3,
child of two free-earlobed parents (II-3 × II-5), which is impossible for
a dominant trait. (2) The pea data support 3:1 — observed 296:104 vs.
expected 300:100, a 1-percentage-point deviation; a much larger deviation
(e.g., 200:200) would have counted against the model. (3) DNA mechanism
— the four-step trace: DNA in the parent's cells is copied and passed via
meiosis into a gamete carrying one allele; fertilization combines two
gametes into a zygote with two alleles; the gene is transcribed and
translated into a protein; the protein produces the trait.
