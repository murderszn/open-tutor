# Teacher Guide — Unit 02: Cells, Membranes, and Transport

**For the guiding adult.** This unit's five objectives are assessed by
observation across the 20 sessions, not by a single test. The
[answer key](answer-key.md) holds worked solutions for every item; keep it
separate from the learner. Session numbers below match the
[20-session pacing](README.md#20-session-pacing).

## Session-by-session guidance

- **S1 (L1):** The dependency web is the point, not the nine names. If the
  learner can say "the Golgi needs the ER's products," the lesson worked —
  even if a job title is fuzzy. Keep the org chart; Lesson 2 extends it.
- **S2 (Practice A):** The "most cascading failure" question has no single
  right answer (mitochondria and membrane are both defensible). Grade the
  *defense*, not the pick.
- **S3 (L2):** Insist on the "what it buys" column, not just names.
  Learners who can list wall/chloroplast/vacuole but cannot say what each
  makes possible have memorized, not understood — send them back to the
  trade-off writing.
- **S4 (Practice B):** The blind annotation is the first retrieval test.
  Missing the difference-makers (not the shared crew) is the signal to
  re-teach.
- **S5 (L3):** Build the bilayer *physically* before reading the SVG.
  "Heads out, tails in" must be in the hands before it is in the eyes.
  The guided diagram reading (cover-and-recall) is mandatory, not
  optional — Session 17 repeats it.
- **S6 (Reading):** Work through the OpenStax §5.1 guide in the
  [resource pack](resource-pack.md#reference-session-guide-openstax-biology-2e-section-51).
  If the textbook and the lesson disagree on a detail, the textbook wins
  and the lesson gets a dated correction note in the learner's notebook.
- **S7 (L4):** The prediction must be *written before* the real dye drop.
  No prediction, no observation — the ordering is the lesson. Time the
  real glass loosely; "slow" is itself a finding (see the extension).
- **S8–S9 (Lab):** See the safety block in [project.md](project.md). The
  adult does all vinegar/egg/knife handling. The design (variables,
  control, repeats, predictions) is written in S8 *before* any measuring.
  If the 24-hour egg timing slips a session, that is fine — the track's
  flex sessions exist for exactly this; do not rush the design step to
  save time.
- **S10 (L5):** Teach the hyper/hypo/iso language *onto* the learner's own
  data, not in the abstract. Every row of their table gets the
  two-sentence gradient explanation before the lesson ends.
- **S11 (Practice C):** The PhET simulation is adult-supervised: the adult
  confirms it loads, mutes any audio, and checks for advertising. Keyboard
  operation: Tab moves between controls, arrow keys adjust sliders, Space
  toggles buttons — the learner can complete the whole exploration
  keyboard-only. The text-and-table equivalent: the learner works the
  eight prediction drills on paper with the two-question card; no
  simulation required.
- **S12 (L6):** The three-question machine is the unit's portable tool.
  Drill it until it is automatic — Sessions 13, 16, and 20 all assume it.
- **S13 (Practice D):** The decision tree is graded on whether it sorts
  correctly, not on beauty. If the tree fails scenario 4 or 7, the learner
  fixes the tree — that debugging *is* the learning.
- **S14–S15:** Critique only the *explanation* row first (claims tied to
  numbers, gradient language present). Praise specifically, then require
  the revision the same session. The diagram annotation must reference a
  real result from the learner's table.
- **S16 (Quiz):** Score the same day. The lowest objective becomes S17's
  re-teach target — decide before S17 starts.
- **S17 (Review):** Rebuild-the-diagram-from-memory is the centerpiece.
  Re-teach the quiz's weakest objective with its lesson's worked examples,
  not with new material.
- **S18:** Five-minute presentations; score communication only. Keep them
  short and kind.
- **S19 (Flex):** Catch-up on the weakest objective, or the Lesson 6
  extension (real pump-failure research), or the Lesson 4 timing
  extension. Do not start Unit 03 content.
- **S20 (Assessment):** Use the scoring guidance in the assessment. The
  readiness bands there decide whether Unit 03 starts on schedule.

## Misconceptions — quick reference

| Misconception | Correction move |
|---|---|
| Nucleus as "brain" giving step-by-step orders | Instruction vault: issues instructions, does not supervise |
| Chloroplasts replace mitochondria in plants | Making sugar ≠ releasing energy; plants do both |
| Membrane as solid wall with holes | Fluid, selective chemistry; channels are specific, not gaps |
| "Small = free, large = protein" (forgetting charge) | Ions are small and still need help — drill Na⁺ |
| Equilibrium means particles stopped | Still jiggling; net movement is zero |
| "Particles want to spread out" | Random motion + imbalance = net flow; no wants |
| Osmosis moves salt / salt moves instead of water | Water moves; mass change is water; membrane blocks most solute |
| Hyper/hypo without "relative to what" | Demand the full phrase: "hypertonic *to the cell*" |
| Facilitated diffusion needs energy (uses a protein) | Protein ≠ energy; the gradient test decides |
| Energy makes transport faster | Energy buys *direction against the gradient*, not speed |
| Homeostasis = everything stays the same | Regulated stability maintained by constant work |

## Reteaching triggers

- **Objective 1:** quiz Q1–Q2 or assessment A2–A3 below half → replay
  Lesson 1's "what breaks if this stops?" with two new failures the adult
  invents on the spot.
- **Objective 2:** quiz Q3–Q4 below half → rebuild the bilayer physically
  and re-run the "who needs a protein?" sort with new substances (the
  adult picks: e.g., ethanol, chloride ion, starch).
- **Objective 3:** quiz Q5–Q6 or practice C below half → return to the
  two-rooms door picture and re-do five fresh gradient scenarios before
  any tonicity language.
- **Objective 4:** project design row at "developing" → the adult models
  one full design aloud (variables, control, repeats) for a *new*
  question (e.g., "does temperature change osmosis speed?"), then the
  learner redesigns the egg lab.
- **Objective 5:** quiz Q7/Q10 below half → drill the three-question
  machine on ten rapid scenarios; the adult calls them out, the learner
  answers with the machine's three steps.

## Readiness criteria (entering Unit 03)

The learner is ready when they can, without notes: (1) rebuild the
membrane diagram with all three arrows; (2) run the three-question machine
on a new scenario; (3) classify a solution hyper/hypo/iso relative to a
cell and explain with the gradient model; (4) describe the osmosis
investigation's design (variables, control, repeats) from memory. If any
one is missing, use the flex guidance above before starting Unit 03.

## Safety recap

Adult handles vinegar, raw eggs, and all knife work. Nothing is tasted.
Hands and surfaces washed after raw-egg handling. Egg allergy → potato
version. The PhET alternative covers the full investigation when hands-on
work is unsuitable. No open flames, no culturing, no dissection anywhere
in this unit.

## Accessibility notes

All checks accept any response mode; the adult scribes on request.
Diagrams use text labels, never color alone; the SVG and the generated
image both ship with full text alternatives. The simulation notes keyboard
operation above; every simulation task has a paper equivalent. Sessions
include movement breaks; the lab has a seated-table variant (the adult
does the pouring while the learner directs and records).
