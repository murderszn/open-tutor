# Project — The Osmosis Investigation

**Unit:** [U02](README.md) · **Sessions 8–9 (lab), 14–15 (report), 18
(presentations)** · Adult-supervised throughout

## The question

*In which direction does water move across a selectively permeable
membrane — and how do you know?*

The learner designs and runs a fair osmosis investigation, measures mass
change as evidence of water movement, and defends a claim with a
claim–evidence–reasoning report. This project retrieves Unit 01's
investigation skills (variables, controls, repeated trials, precise
recording) and applies Lessons 4–5's gradient model.

## Materials

**Egg version** (choose one version): 2–3 raw eggs, white vinegar (adult
handles and pours), three solutions — distilled/pure water, 0.9% salt
(control), 10% salt — kitchen scale (0.1 g precision preferred), ruler,
clear cups, spoon, paper towels.

**Potato version:** one large potato, knife (**adult only**), salt, sugar,
water, three cups, ruler, kitchen scale, cutting board.

**Both versions:** notebook, the two-question card from Lesson 4, the
hyper/hypo/iso chant from Lesson 5.

**Safety (adult reads aloud before starting):** the adult handles vinegar
and raw eggs; the adult does all knife work; nothing is tasted at any
point; hands and surfaces are washed after handling raw egg; spills are
wiped immediately (wet floors). If anyone in the household has an egg
allergy, use the potato version.

**Observation-only alternative:** if materials, allergies, or access rule
out the hands-on version, run the PhET Membrane Channels simulation
([resource pack](resource-pack.md#web-references-4-verified-2026-10-20),
adult-supervised) with the adult's provided dataset below, and complete
the same report. The rubric's "technique" row is then scored on simulation
control and data recording instead of hands-on technique.

*Provided dataset (fictional — labeled as invented practice data, not
measurements):* four egg masses before/after 24 h in unknown solutions:
W: 60.0→60.2 g; X: 61.5→55.0 g; Y: 59.8→66.1 g; Z: 60.5→60.4 g.

## Procedure

### Osmosis lab: setup and first measurements

**Egg version:**

1. *Prep (adult, day before):* submerge each raw egg in vinegar 24–48
   hours until the shell dissolves, leaving the membrane intact. Rinse
   gently; pat dry. (The class transcript in the resource pack explains
   why this models a cell membrane — read it together first.)
2. *Design (learner, Session 8 start):* write the testable question,
   identify independent variable (solution concentration), dependent
   variable (egg mass change), controlled variables (egg size, solution
   volume, time, temperature), and the control (0.9% saline ≈ isotonic).
   Predict each egg's mass direction with hyper/hypo/iso language
   *before* measuring.
3. *Baseline:* mass each egg (grams, one decimal), record in a table with
   columns: Egg | Solution | Start mass | Prediction (gain/lose/same +
   why).
4. *Expose:* place each egg in its cup of solution, fully submerged.
   Start the clock. Note the time; the exposure runs 12–24 hours.
5. *Session 9:* remove, pat dry *gently and identically*, re-mass, record
   end mass. Compute change (g) and percent change for each egg:
   `(end − start) / start × 100`.
6. *Repeats:* the design must include at least **two eggs per solution**
   (repeated trials) — with 2–3 eggs total this means prioritizing: at
   minimum, duplicate the most informative solution, and state in the
   report which comparison the single trial limits.

**Potato version:**

1. *Design (learner):* same variables as above; control = 0.9% saline.
   Predict first.
2. *Prep (adult cuts):* identical potato cylinders or slices (same
   dimensions — control the surface area).
3. *Baseline:* mass each piece, record.
4. *Expose:* one piece per cup — distilled water, 0.9% saline, strong
   salt solution (or strong sugar solution as a fourth comparison).
   2–4 hours (potato responds faster than egg).
5. *Re-mass and compute* change and percent change. Two pieces per
   solution where potato allows.

### Report, critique, and revision

1. *Draft (Session 14):* write the full report — question, design
   (variables, control, trials), data table, percent-change calculations,
   one paragraph per solution (mass evidence → hyper/hypo/iso
   classification → gradient explanation, per Lesson 5), and a final
   claim–evidence–reasoning paragraph answering the project question.
2. *Peer critique (Session 14, adult as the peer):* the adult checks the
   report against the rubric's "explanation" row only — is every claim
   tied to a number, and does the gradient language appear? The learner
   revises the same session.
3. *Membrane-model rebuild (Session 15):* revise the Lesson 3 zoom-box
   diagram to include one annotation from the investigation (for example,
   an osmosis arrow labeled with your hypertonic result). Models are
   revised when evidence requires — say so in one sentence under the
   diagram.

### Capstone presentations

**Session 18.** Five minutes, any format (spoken with notes, poster, slides): the
question, the design in 30 seconds, the data (table or graph), the claim
with evidence and reasoning, and one thing you would change if you ran it
again. The adult scores with the rubric's "communication" row.

## Deliverables

1. Investigation plan (question, variables, control, trials, predictions)
2. Data table with start/end masses and percent changes
3. Written report (design + per-solution paragraphs + CER conclusion)
4. Revised membrane zoom-box diagram with an investigation annotation
5. Capstone presentation (Session 18)

## Rubric

| Criterion | Exceeding (3) | Meeting (2) | Developing (1) |
|---|---|---|---|
| **Design** | Variables, control, and repeats all defined *before* measuring; predictions use hyper/hypo/iso language; a limitation of the trial count is named | Variables, control, and repeats defined; predictions recorded before measuring | Plan written after measuring, or variables/control missing |
| **Technique & data** | Masses to 0.1 g, identical drying/handling, full table with units; percent changes computed correctly; repeats shown separately (not averaged away silently) | Masses recorded with units; table complete; percent changes computed | Missing units, no repeats, or percent-change errors uncorrected |
| **Explanation** | Every solution classified hyper/hypo/iso *relative to the cell*; each paragraph runs the gradient model (water toward higher solute); control result interpreted as noise bound | Classifications correct; gradient language present for most solutions | Classifications missing or asserted without the gradient mechanism |
| **Reasoning & revision** | CER conclusion ties the claim to specific numbers; peer-critique feedback visibly revised; diagram annotation connects a result to the membrane model | CER present with evidence; revision attempted | Claim without evidence, or no revision after critique |
| **Communication** | Presentation moves question → design → data → claim in order; the "what I'd change" reflection names a real design improvement | All five presentation parts present | Parts missing or out of order; no reflection |

**Scoring:** 13–15 = exceeding; 10–12 = meeting; 7–9 = developing (re-teach
the lowest row before Unit 03); below 7 = re-run the report sessions with
adult support.
