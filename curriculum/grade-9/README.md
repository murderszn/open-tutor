# Grade 9 — Independent Curriculum Track

This folder is an anonymous, grade-specific track in the public OpenTutor curriculum library.

**Contents:** The mathematics track (Algebra I pathway), the science track
(Biology), the language arts track (literary reading and composition), and the
social studies track (modern world history) each have a draft audit and
scope-and-sequence; the eight units and the review package for each are
planned, not yet written. No subject track is complete. All materials still
require educator review.

**Do not refer a learner to another grade's track.** Each track is
self-contained for one learner at a time; a guiding adult adapts pacing,
materials, and supports. Keep completed learner work, names, photos, schedules,
and grades in private storage — never in this public repository.

See also: [curriculum index](../README.md).
