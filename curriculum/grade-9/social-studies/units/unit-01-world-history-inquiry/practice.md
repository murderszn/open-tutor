# Unit 01 Practice Sets

Complete one set per week (S2). Show reasoning, not just answers. All
solutions are in `answer-key.md` — attempt first, then check with the adult.

**Dataset note (read before Set B):** `resources/un_countries.csv` lists
*modern* countries (195 rows). Usable columns: `name_common`,
`region`, `subregion`, `capital`, `area_km2`. The `population`, `lat`,
and `lng` columns are **empty** in this snapshot — do not use them.
Modern boundaries are **not** 1450 boundaries: use the file to practice
reading region data, and always note the anachronism when you answer.

## Set A — Regions and routes (Week 3, after Lesson 01)

A1. List the three Afro-Eurasian connection systems and, for each, name
    two nodes (cities/ports) it linked.
A2. Which two regions from Lesson 01's twelve were connected by the
    *trans-Saharan* system? Which good flowed each direction?
A3. Using the Lesson 01 comparison frame (who rules / how power passes /
    how the economy is organized), compare **the Ottoman lands** and
    **Mali/Songhai West Africa** in a three-row table.
A4. Explain in 2–3 sentences why historians say "Silk *Roads*" (plural).
A5. **Data task:** Open `resources/un_countries.csv`. Find three modern
    countries whose `subregion` is "South-Eastern Asia" (note the hyphen)
    and record their `area_km2`. Then write one sentence explaining why
    these modern areas cannot tell us the size of any 1450 polity.
A6. **Error analysis:** A learner writes, "The Silk Roads were built by
    the Chinese government in 1450." Identify two errors and correct them.

## Set B — Exchange and sources (Week 4, after Lesson 02)

B1. Name three *non-goods* that traveled Afro-Eurasian networks, each with
    the route it used.
B2. Build an effect chain of at least three links starting from:
    *"The winter monsoon blows from Asia toward East Africa."*
B3. **Source check:** A court poet in Timbuktu writes a praise-poem for
    the city's scholars. Classify it (kind / maker / audience-purpose /
    limits) and state one inquiry it *cannot* answer.
B4. **Illustration analysis:** Using
    `assets/indian-ocean-port-1450-illustration.png` (or its text-only
    alternative in Lesson 02), match five visible items to their origin
    regions, and write one sentence this image cannot prove about 1450.
B5. Compare Ibn Battuta's merchant-network world with Zheng He's state
    fleets: which was more resilient after 1450, and what is your
    evidence? (3–4 sentences.)
B6. **Data task:** From `un_countries.csv`, list all rows whose
    `subregion` is "Eastern Africa" and give each country's `capital`.
    Then write two sentences: what does this list suggest about Swahili
    coast trade geography — and what does it *hide* about 1450?

## Set C — Americas and Oceania (Week 5, after Lesson 03)

C1. For the Mexica and the Inca, state: (a) how labor/tribute was
    organized, (b) how records were kept, (c) one staple food system.
C2. Why is "Cahokia declined by 1400" *not* the same as "Mississippian
    culture ended"? (2–3 sentences.)
C3. Name two navigational techniques of Polynesian voyagers and explain
    what each one replaced (i.e., what Europeans used instead).
C4. **Perspective rewrite:** Take one sentence from Lesson 03's
    Description A and rewrite it in Description B's frame without
    changing the facts.
C5. Give two reasons there was no regular Afro-Eurasian–American contact
    circa 1450. For each, state whether it is about *capability* or
    *motive/knowledge*.
C6. **Explain-your-reasoning:** "Tenochtitlan was bigger than London, so
    the Mexica were more advanced than the English." Identify the
    reasoning error and give a better comparison.

## Set D — Synthesis toolkit (Week 6, after Lesson 04)

D1. Define *compelling question* and *supporting question*; write one of
    each about Indian Ocean trade.
D2. Run the four source-lab checks on: *"A 1430s Ming court painting
    showing Zheng He's treasure ships."* (kind / maker / audience-purpose
    / limits.)
D3. **Change/continuity:** Name one continuity and one change in
    Afro-Eurasian trade between 1200 and 1450, each with a cause.
D4. **Gap hunt:** You want to know what ordinary dockworkers in Calicut
    thought of foreign merchants circa 1450. Name the source type most
    likely to help, and explain why it probably does not survive.
D5. State a claim about which connection mattered most circa 1450 in one
    sentence, then list the *yardstick* your claim depends on
    ("mattered most for ___").
D6. **Data task:** From `un_countries.csv`, pick one `region` value and
    count how many countries share it. Write one sentence on what that
    count does and does not tell a historian of 1450.

M1. On your working map, draw and label all three connection systems with
    a key. Add at least 10 nodes total, each labeled with one good or
    idea that passed through it.
M2. Add the routes of Ibn Battuta (Tangier → Mecca → Delhi → Maldives →
