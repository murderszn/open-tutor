# Unit 01 Teacher Guide

**For the guiding adult — not for the learner.** Answer keys live in
`answer-key.md`; keep the two separate.

## How to use this unit

- **Pacing:** five ~50-minute sessions per week for four weeks (see unit
  README for the session table). S1 = the written lesson; S2 = practice
  set; S3 = project/investigation; S4 = writing/deliberation; S5 = review.
- **Your role:** preview every source, run the readiness checks aloud,
  score the quiz and assessment with `answer-key.md`, and record gaps
  after each S5. Nothing here is self-grading.
- **Sensitive content:** this unit is low-sensitivity (trade, geography,
  source analysis). Lesson 03 mentions Mexica human sacrifice only in its
  teacher note — raise it factually and briefly only if the learner asks;
  do not assign graphic material.

## Lesson-by-lesson notes

### Lesson 01 — Regions and routes

- **Watch for:** learners placing nodes by modern country rather than
  region (e.g., "India" as one thing). Redirect to the region list: in
  1450 there was no India-as-state — there was the Delhi Sultanate,
  Vijayanagara, and coastal ports.
- **The comparison table** is the lesson's core skill. Accept any
  accurate three-row comparison; the frame matters more than the
  regions chosen.
- **Reteach trigger:** if the learner cannot name all three systems and
  one good each by S5, re-teach with the pepper-tracing worked example
  before week 4.

### Lesson 02 — Exchange and sources

- **The four-check source habit** (kind/maker/audience/limits) is the
  year's most reused tool. Model it aloud on the first passage; make the
  learner do the second one solo.
- **Illustration analysis:** enforce question (c) — *what the image
  cannot prove*. If the learner treats the AI illustration as evidence,
  stop and re-teach primary vs. reconstruction before continuing.
- **Monsoon effect chains** often stall at one link. Prompt: "and then
  what did the waiting sailors need?"

### Lesson 03 — Americas and Oceania

- **Jigsaw option:** assign one society per session if reading stamina is
  low; the learner teaches each back to you.
- **The "advanced" paragraph (C4)** is a trap-check for presentism.
  Strong answers define the term first. If the learner skips the
  definition, send it back.
- **Deliberation (S4):** play devil's advocate for whichever side the
  learner takes. The goal is *both* claims voiced with evidence, not a
  winner.

### Lesson 04 — Synthesis toolkit

- **Compelling vs. supporting** is the hardest distinction in the unit.
  Use the test: *could two historians with the same sources disagree?*
- **Source lab (guided practice 2):** the expected gap is some version of
  "ordinary people's perspectives" — dockworkers, porters, enslaved
  people, women. Any well-reasoned gap earns full credit; the point is
  noticing *absence*.
- **Project Part 2 drafts** due at S3 — read them before S4's workshop so
  critique is specific.

## Differentiation

- **Reading support:** chunk lessons into the numbered parts; use the OER
  Project 860L/780L Silk Road readings (resource pack) alongside Lesson
  02; allow text-to-speech for passages.
- **Alternate response modes:** comparison tables → labeled diagrams;
  effect chains → arrow diagrams; the argument → spoken case + evidence
  sheet (same rubric).
- **Extensions:** each lesson has one; the Lesson 03 "fifth profile" and
  Lesson 01 "correction card" are the strongest.

## Reteaching map

| Signal | Reteach |
|---|---|
| Quiz total < 22 | Week 4 S1–S2 again, one system per day, with fresh tracing exercises |
| Source classification wrong on 2+ quiz/assessment items | Re-run the four checks on three new sources together |
| "Isolated" used uncritically in week 5+ | Re-do Lesson 03 Worked Example B aloud |
| Project Part 2 claim is factual, not arguable | Lesson 04 Worked Example A rewrite exercise |
| Evidence use below proficient on project or Part C | Source-citation reteach: claim → evidence → source-kind → citation, with two modeled examples, before U02 |

## Review prompts (S5)

- Week 3: "Teach me the three systems in 90 seconds using your map."
- Week 4: "What is one thing networks carry besides goods — and one cost
  of connection?"
- Week 5: "What does 'isolated' hide and reveal? Give one example."
- Week 6: "Ask me your compelling question, then tell me your yardstick."

## Answer-key discipline

Solve from `answer-key.md` only after the learner attempts. For open
responses, the key gives acceptable ranges and sample reasoning — credit
any defensible answer inside the range. Record scores and the reteach
plan in your own notes (never in this repo).
