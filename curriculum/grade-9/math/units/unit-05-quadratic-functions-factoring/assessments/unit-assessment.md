# Unit Assessment — Quadratic Functions and Factoring

**Session 18 · Culminating · 28 points · About 45 minutes**

Show your work. Factor-checks and expand-back checks are part of the
answer. This assessment is not standardized or validated; it measures
this unit's five objectives only.

## Part A — Skills (18 points, 3 points each)

1. Factor `6x² + 15x` completely.
2. Factor `x² − 11x + 30`.
3. Factor `9x² − 16`.
4. Factor `2x² − 7x + 3` by the ac method, showing the
   split-middle-term step.
5. Write `f(x) = x² − 6x + 7` in vertex form; give the vertex and the
   minimum value.
6. For `g(x) = −2(x + 1)² + 8`: name the vertex, state whether the
   parabola opens up or down, and give the maximum or minimum value
   and the axis of symmetry.

## Part B — Extended tasks (10 points)

7. **The second throw (5 points).** A ball's height in feet after `t`
   seconds is `h(t) = −16t² + 20t + 6` (fictional practice data).
   (a) What is the launch height? (b) Find the maximum height and
   the time it happens. (c) Find the landing time exactly and as a
   decimal. (d) State the domain in context and the intervals where
   the height is increasing and decreasing.
8. **Two forms, one function — and a function that never meets it
   (5 points).** `f(x) = x² − 4x + 3` and `g(x) = (x − 2)² + 2`.
   (a) Give the vertex and the zeros of `f` (or state that it has
   none). (b) Give the vertex of `g` and say whether `g` has any
   zeros. (c) At `x = 0`, which function has the smaller value?
   (d) Do the graphs of `f` and `g` intersect? Justify your answer
   algebraically, and explain the result as a transformation.

## Scoring guide (adult)

- Below 20: reteach the weakest objective (Part A items map to
