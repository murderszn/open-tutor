# Practice — Unit 05: Quadratic Functions and Factoring

Work each set on the session named in the unit README. Show the
multiply-back check for every factorization, and the vertex-form
expansion check for every completed square. Solutions are in
`answer-key.md` — try first, then check.

## Practice A — GCF and reversing products (Session 2)

1. Factor `9x² + 12x`.
2. Factor `x² + 10x + 21`.
3. Factor `7x³ − 14x²`.
4. Factor `x² − 3x − 18`.
5. Factor `4x² + 20x`.
6. One learner factored `6x² − 9x` as `3(2x² − 3x)`. Is that
   complete? Explain, and give the complete factorization.
7. Factor `x² + 4x − 12`.
8. Factor `12x³ + 8x²`.
9. **Error analysis.** One learner factored `x² + 11x + 30` as
   `(x + 10)(x + 3)`. Multiply it out, name the error, and give the
   correct factorization.
10. A rectangle has area `x² + 12x + 35` square units and length
    `x + 7` units. Factor the area to find the width.

## Practice B — Trinomials and the ac method (Session 4)

1. Factor `x² + 13x + 36`.
2. Factor `x² − 8x + 15`.
3. Factor `2x² + 9x + 4` by the ac method.
4. Factor `3x² − 8x − 3` by the ac method.
5. Factor `x² + 6x − 16`.
6. Factor `4x² + 4x − 3` by the ac method.
7. Is `x² − 7x + 11` prime over the integers? Justify by listing the
   factor pairs you tried.
8. Factor `6x² + 13x + 5` by the ac method.
9. **Error analysis.** One learner factored `x² − 10x + 24` as
   `(x − 12)(x − 2)`. Multiply it out, name the error, and give the
   correct factorization.
10. A rectangle has area `3x² + 14x + 8` square units and length
    `3x + 2` units. Factor the area to find the width.

## Practice C — Special forms, factor completely, zeros (Session 6)

1. Factor `x² − 81`.
2. Factor `x² + 16x + 64`.
3. Factor `9x² − 36` completely.
4. Factor `4x² + 28x + 49`.
5. Factor `6x² − 24` completely.
6. Factor `x⁴ − 16` completely.
7. For `f(x) = x² + 2x − 15`: factor it, state its zeros, give the
   y-intercept, and find the vertex.
8. For `f(x) = x² − 9x + 20`: factor it, state its zeros, give the
   y-intercept, and find the vertex.
9. In one or two sentences, explain why `x² + 25` cannot be factored
   over the integers while `x² − 25` can.
10. Factor `18x² − 50` completely.

## Practice D — Completing the square (Session 9)

1. Write `f(x) = x² + 8x + 15` in vertex form; give the vertex and the
   minimum value.
2. Write `f(x) = x² − 6x + 2` in vertex form; give the vertex and the
   minimum value.
3. Write `f(x) = 2x² + 16x + 5` in vertex form; give the vertex and
   the minimum value.
4. Write `f(x) = −x² + 4x + 1` in vertex form; give the vertex and the
   **maximum** value.
5. Write `f(x) = x² + 3x − 2` in vertex form; give the vertex and the
   minimum value.
6. **Error analysis.** One learner wrote `x² + 6x + 8 = (x + 3)² + 8`.
   Expand the right side, name the error, and give the correct vertex
   form.
7. Write `f(x) = x² − 4x − 1` in vertex form; give the vertex.
8. A garden's area is `A(x) = −2x² + 48x` square feet. Write `A` in
   vertex form and state the greatest area and the width that gives it.
9. Which form of `f(x) = x² + 8x + 15` answers "what is the minimum
   value?" and which answers "what are the zeros?" Give both forms
   and both answers.
10. Write `f(x) = 3x² − 12x + 11` in vertex form; give the vertex and
    the minimum value.

## Practice E — Transformations and graphs (Session 12)

1. Describe the graph of `g(x) = x² + 7` as a transformation of
   `f(x) = x²`; name its vertex.
2. Describe the graph of `g(x) = (x − 5)²` as a transformation of
   `f(x) = x²`; name its vertex.
3. Describe the graph of `g(x) = 3x²` as a transformation of
   `f(x) = x²`; is it narrower or wider than `f`?
4. Describe the graph of `g(x) = f(x + 4) − 1` where `f(x) = x²`;
   name its vertex.
5. A parabola is a vertical stretch of `f(x) = x²` with vertex
   `(0, 2)` and passes through `(2, 10)`. Find its function.
6. Make a table for `f(x) = x²` and for `f(2x)` at `x = 0, 1, 2, 3`.
   Is `f(2x)` narrower or wider than `f(x)`?
7. For `h(x) = −(x − 2)² + 3`: name the vertex, state whether it opens
   up or down, and give the maximum or minimum value.
8. Which is wider, `y = (1/3)x²` or `y = 3x²`? Explain in one
   sentence.
9. For `g(x) = (x + 2)² − 5`: name the vertex and the axis of
   symmetry, and find the zeros exactly.
10. **Error analysis.** One learner said `(x + 3)²` shifts the graph of
    `x²` three units to the right. Explain the error and state the
    correct shift.

## Practice F — Feature analysis and comparing quadratics (Session 14)

1. For the ball's height `h(t) = −16t² + 24t + 5` (Lesson 06): state
   the maximum height, when it happens, and the landing time.
2. For `f(x) = x² − 8x + 12`: give the factored form, the zeros, the
   vertex, the axis of symmetry, the y-intercept, and the intervals
   where `f` is increasing and decreasing.
3. `f(x) = x² − 2x − 8` and `g(x) = −x² + 2x + 8`. Find the zeros and
   the vertex of each. At `x = 0`, which function has the greater
   value?
4. Find where the graphs of `f(x) = x² − 4x + 3` and `g(x) = x − 1`
   intersect. Give both points and check each in both functions.
5. A garden's area is `A(x) = −2x² + 48x` square feet, where `x` is
   the width in feet. What is the domain of `A` in context, and why?
6. **Error analysis.** One learner said the maximum height of the ball
   in `h(t) = −16t² + 24t + 5` is 0.75 feet. Name the error and give
   the correct maximum height and the time it happens.
