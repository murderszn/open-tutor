# Answer Key — Unit 05: Quadratic Functions and Factoring

**Teacher use only.** Every solution below was solved independently
and reconciled with the lesson, practice, quiz, assessment, and
project prompts. Accept equivalent factored forms and equivalent
wording for explanations; the checks are the non-negotiable part.

## Lesson 01

**Guided practice:** 1. `4x(2x − 3)` — check: `4x · 2x = 8x²`,
`4x · (−3) = −12x`. 2. `(x + 3)(x + 5)` — 3 and 5 multiply to 15
and add to 8; check: `x² + 8x + 15`. 3. `5x(x + 2)` — check:
`5x² + 10x`; nothing inside factors further.

**Independent practice:** 1. `4x(x + 4)`. 2. `(x + 3)(x + 6)` —
3 and 6 multiply to 18 and add to 9. 3. `2x²(x + 3)`. 4. `(x + 2)(x + 4)`.
5. `4x(3x + 6)` is incomplete because `3x + 6` still has a GCF of 3;
the complete factorization is `12x(x + 2)`.

**Application:** width `x + 2`, because `(x + 5)(x + 2)
= x² + 7x + 10`. Factoring turns an area back into its side lengths.

**Exit check:** `10x² − 15x = 5x(2x − 3)`; check: `5x · 2x = 10x²`,
`5x · (−3) = −15x`.

## Lesson 02

**Guided practice:** 1. `(x − 4)(x − 5)` — both numbers negative
(`c` positive, `b` negative); 4 and 5 multiply to 20 and add to 9.
2. `(3x + 2)(x + 3)` — `ac = 18`, numbers 9 and 2;
`3x² + 9x + 2x + 6 = 3x(x + 3) + 2(x + 3)`. 3. `(x + 5)(x − 3)` —
opposite signs; 5 − 3 = 2.

**Independent practice:** 1. `(x + 3)(x + 8)`. 2. `(x − 5)(x − 7)`.
3. `(2x + 1)(x − 3)` — `ac = −6`, numbers −6 and 1;
`2x² − 6x + x − 3 = 2x(x − 3) + 1(x − 3)`. 4. `(5x + 3)(x + 2)` —
`ac = 30`, numbers 10 and 3; `5x² + 10x + 3x + 6 = 5x(x + 2) + 3(x + 2)`.
5. Prime. Factor pairs of 9: 1 and 9 (sum 10), 3 and 3 (sum 6),
−1 and −9 (sum −10), −3 and −3 (sum −6). None sums to 4.

**Application:** width `x + 4`, because `(2x + 1)(x + 4)
= 2x² + 9x + 4`.

**Exit check:** `(3x − 4)(x − 2)` — `ac = 24`, numbers −6 and −4;
`3x² − 6x − 4x + 8 = 3x(x − 2) − 4(x − 2)`.

## Lesson 03

**Guided practice:** 1. `(4x − 3)(4x + 3)`. 2. `(x − 7)²` —
`2 · x · 7 = 14x`. 3. `3(x − 3)(x + 3)` — GCF 3 first, then the
difference of squares.

**Independent practice:** 1. `(5x − 1)(5x + 1)`. 2. `(x + 9)²`.
3. `5(x − 3)(x + 3)`. 4. `f(x) = (x + 5)(x − 2)`; zeros −5 and 2;
y-intercept −10; vertex `(−1.5, −12.25)`, since the axis is halfway
between the zeros (`x = −1.5`) and `f(−1.5) = 2.25 − 4.5 − 10 = −12.25`.
5. `x² + 16` is a sum of squares, which has no binomial factors over
the integers; `x² − 16 = (x − 4)(x + 4)` is a difference of squares.

**Application:** `f(x) = (x − 3)(x − 4)`; zeros 3 and 4. The points
`(3, 0)` and `(4, 0)` are where the graph crosses the x-axis — where
the modeled quantity is zero.

**Exit check:** `8x² − 50 = 2(4x² − 25) = 2(2x − 5)(2x + 5)`.

## Lesson 04

**Guided practice:** 1. `(x + 5)² − 4`; vertex `(−5, −4)`.
2. `(x − 1)² − 9`; vertex `(1, −9)`. 3. `3(x − 3)² − 7`; vertex
`(3, −7)` — the 9 added inside is multiplied by 3 outside.

**Independent practice:** 1. `(x + 2)² − 3`; vertex `(−2, −3)`;
minimum −3. 2. `(x − 6)² − 9`; vertex `(6, −9)`; minimum −9.
3. `2(x − 2)² − 5`; vertex `(2, −5)`; minimum −5. 4. `−(x − 3)² + 4`;
vertex `(3, 4)`; maximum 4. 5. Completing the square on `x² + 6x`
means adding `(6/2)² = 9`, which turns `x² + 6x + 9` into `(x + 3)²`;
you must also subtract 9 so the expression's value does not change.

**Application:** `A(x) = −2(x − 12)² + 288`; greatest area 288 square
feet at width 12 feet.

**Exit check:** `(x + 7)² − 9`; vertex `(−7, −9)`.

## Lesson 05

**Guided practice:** 1. Shift left 1, down 2; vertex `(−1, −2)`.
2. `f(x)`: 0, 1, 4 at `x = 0, 1, 2`; `f(2x)`: 0, 4, 16. `f(2x)` is
narrower — a horizontal compression. 3. `g(x) = −(x − 3)² + 1`;
vertex `(3, 1)`, maximum 1.

**Independent practice:** 1. Shift down 4; vertex `(0, −4)`.
2. Shift left 3; vertex `(−3, 0)`. 3. Vertical compression by 1/2;
wider. 4. Shift right 1, up 2; vertex `(1, 2)`. 5. `a = 1`:
`f(0) = a(0 − 2)² − 3 = 4a − 3 = 1`, so `a = 1` and
`f(x) = (x − 2)² − 3`.

**Application:** the highest point is the vertex (the maximum height);
the landing moment is a zero (where the height is 0).

**Exit check:** vertex `(−1, 4)`; opens downward; maximum value 4.

## Lesson 06

**Guided practice:** 1. At `t = 0.5` and `t = 1.0` seconds — both
heights are 13 feet, symmetric about `t = 0.75`. 2. Domain
`0 < x < 24` (a width of 0 or 24 leaves no garden); area is
increasing on `0 < x < 12`. 3. Factored form shows the zeros faster
(`(x − 1)(x − 5)` gives zeros 1 and 5); vertex form shows the vertex
faster (`(x − 3)² − 4` gives vertex `(3, −4)`).

**Independent practice:** 1. Factored form `(x − 2)(x − 4)`; zeros 2
and 4; vertex form `(x − 3)² − 1`; vertex `(3, −1)`; axis `x = 3`;
y-intercept 8; decreasing for `x < 3`, increasing for `x > 3`.
2. `g`'s vertex has the greater y-value (4 > −1). At `x = 2`:
`f(2) = 4 − 8 + 3 = −1` and `g(2) = −4 + 12 − 5 = 3`, so `g` is
greater at `x = 2`. 3. Set `x² + 2x − 3 = −x² + 4x − 3`, so
`2x² − 2x = 0` and `x = 0` or `x = 1`. Points: `(0, −3)` (check:
`p(0) = −3`, `q(0) = −3`) and `(1, 0)` (check: `p(1) = 0`,
`q(1) = 0`). 4. The first garden can be larger, by
`288 − 225 = 63` square feet. 5. The formula accepts any real input,
but in context `t` starts at the throw (`t = 0`) and stops at the
landing (`t ≈ 1.69`); before and after that, the ball is not in the
air, so the height model does not apply.

**Application:** the second throw goes higher. Its vertex is at
`t = 1` second with height `h₂(1) = −16 + 32 + 6 = 22` feet, above the
first throw's maximum of 14 feet.

**Exit check:** maximum height 22 feet at `t = 1` second; landing at
`t = 1 + √22 / 4 ≈ 2.17` seconds.

## Unit Assessment

**Part A:** 1. `3x(2x + 5)`. 2. `(x − 5)(x − 6)`. 3. `(3x − 4)(3x + 4)`.
4. `(2x − 1)(x − 3)` — `ac = 6`, numbers −6 and −1;
`2x² − 6x − x + 3 = 2x(x − 3) − 1(x − 3)`. 5. `(x − 3)² − 2`; vertex
`(3, −2)`; minimum −2. 6. Vertex `(−1, 8)`; opens downward; maximum
value 8; axis of symmetry `x = −1`.

**Part B, item 7:** (a) Launch height `h(0) = 6` feet. (b) The axis is
`t = −20 / (2 · −16) = 0.625` seconds; `h(0.625) = −16(0.625)²
+ 20(0.625) + 6 = −6.25 + 12.5 + 6 = 12.25` feet, so the maximum height
is 12.25 feet at 0.625 seconds. (c) `−16t² + 20t + 6 = 0` divides to
`8t² − 10t − 3 = 0`; `t = (10 ± √196) / 16 = (10 ± 14) / 16`, so
`t = 3/2` seconds (1.5 seconds) or `t = −1/4` second. The landing time
is exactly `3/2` seconds. (d) Domain `0 ≤ t ≤ 1.5` seconds; increasing
on `[0, 0.625]`, decreasing on `[0.625, 1.5]`.

**Part B, item 8:** (a) `f` has vertex `(2, −1)` and zeros 1 and 3.
(b) `g` has vertex `(2, 2)` and no zeros — its minimum value is 2,
which is above 0. (c) `f(0) = 3` and `g(0) = 6`, so `f` has the
smaller value at `x = 0`. (d) The graphs never intersect:
`x² − 4x + 3 = (x − 2)² + 2 = x² − 4x + 6` simplifies to `3 = 6`,
which is false. `g` is `f` shifted up 3 units, so the two parabolas
are parallel copies that never meet.

## Project — The Greatest Garden

- **Model:** long side `48 − 2x` feet; `A(x) = x(48 − 2x) = −2x² + 48x`
  square feet; domain `0 < x < 24` (width and length must both be
  positive).
- **Table:** `x = 4` → 160 sq ft (4 × 40); `x = 8` → 256 sq ft (8 × 32);
  `x = 12` → 288 sq ft (12 × 24); `x = 16` → 256 sq ft (16 × 16);
  `x = 20` → 160 sq ft (20 × 8). Areas rise, then fall, symmetric
  about `x = 12`.
- **Graph:** parabola through `(0, 0)`, `(4, 160)`, `(8, 256)`,
  `(12, 288)`, `(16, 256)`, `(20, 160)`, `(24, 0)`; vertex `(12, 288)`.
- **Vertex form:** `A(x) = −2(x − 12)² + 288`; greatest area 288 square
  feet at width 12 feet; dimensions 12 ft × 24 ft.
- **Factored form:** `A(x) = −2x(x − 24)`; zeros 0 and 24. At `x = 0`
  there is no width, so no garden; at `x = 24` the length is zero, so
  no garden either.
- **Recommendation (sample):** Build the bed 12 feet wide and 24 feet
  long for 288 square feet — the largest area this fencing allows.
  The vertex of the area graph sits at width 12 feet, and the areas on
  either side (256 at both 8 and 16 feet) are smaller, so no other
  width beats it.
- **Extension:** with 60 feet, `A(x) = x(60 − 2x) = −2x² + 60x
  = −2(x − 15)² + 450`; greatest area 450 square feet at width 15 feet,
  dimensions 15 ft × 30 ft. More fencing raises the maximum and moves
  it to a wider rectangle.
