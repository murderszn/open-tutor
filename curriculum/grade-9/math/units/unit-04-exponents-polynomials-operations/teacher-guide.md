# Teacher Guide — Unit 04: Exponents, Polynomials, and Operations

For the guiding adult. Student pages never contain answers; this
guide and `answer-key.md` stay separate from them.

## How to run the unit

- **Session rhythm:** each lesson (Sessions 1, 3, 5, 8, 11, 13) is
  followed by a practice session before the next lesson, so errors
  surface while the method is fresh. Do not skip Practice B's
  "nothing left to pull out" check — unfinished radicals are this
  unit's most common assessment gap.
- **The three non-negotiables:** (1) rational exponents are
  computed root-first, with the root named before any power;
  (2) exact forms are kept through all algebra, with `≈` used
  whenever a decimal appears; (3) every polynomial product shows
  its partial products (or its named pattern) and a degree
  prediction made before multiplying.
- **Checking standard:** a numeric check at a small value of `x`
  (usually `x = 1` or `x = 2`) catches most polynomial and
  special-product errors. A check that gives `0 = 0` (both sides
  zero) is weak — pick a value where the expressions are nonzero.

## Misconceptions and reteach moves

| Where it shows | What the learner does | Reteach move |
|---|---|---|
| Lesson 01, Practice A | Reads `a^(1/2)` as `a ÷ 2`, or `a^(m/n)` as `a^m ÷ n` | Return to the power-rule argument: `(a^(1/2))²` must be `a`. Test with `25^(1/2) = 5`, not `12.5`. |
| Lesson 01 | Powers before rooting, and loses track (e.g., cubing 16 first) | Require the root-first line every time: `16^(3/4) = (16^(1/4))³ = 2³ = 8`. |
| Lesson 01 | Gives a real value for an even root of a negative number | Ask: "what real number, squared, is negative?" No answer exists; the expression has no real value. Contrast with the odd-root case. |
| Lesson 02, Practice B | Stops at the first perfect-power factor (`√72 = 3√8`) | Require the "nothing left to pull out" check: is the remaining radicand divisible by any perfect square (or cube)? `8` hides `4`. |
| Lesson 02 | Writes `=` where `≈` belongs, or rounds before finishing algebra | Ban the calculator until the exact form is written. The `≈` sign is a required character in any rounded answer. |
| Lesson 03, Practice C | Subtracts only the first term of the second polynomial | Circle the whole second polynomial and flip every sign before combining. Re-do Worked example 2 aloud. |
| Lesson 03 | Combines unlike terms (`x² + x = x³`) | Sort terms by degree (columns or colors) before adding. Like means same variables, same exponents. |
| Lesson 04, Practice D | Drops a partial product, or uses FOIL on a trinomial factor | Require the "terms × terms" count before combining: a binomial times a trinomial has six partial products, not four. |
| Lesson 04 | Sign error on a negative term's products | Write each partial product with its sign on its own line; check at `x = 1`. |
| Lesson 05, Practice E | Writes `(a + b)² = a² + b²` | Draw the area model for a square of side `(x + 3)`: the two `3x` regions are the missing middle term, visible. |
| Lesson 05 | Squares only the variable: `(2x)² = 2x²` | Require the `a = …, b = …` line: `a = 2x`, so `a² = 4x²`. The coefficient squares too. |
| Lesson 06, Practice F | Claims irrational × irrational is always irrational | Show the pair `√2 · √8 = 4` (rational) beside `√2 · √3 = √6` (irrational). The computation decides it. |
| Lesson 06 | Rounds early, then wonders why a later result is off | Re-do Practice F item 8: `(6.7)² = 44.89` against the exact `45`. The gap is the cost of rounding early. |

## Readiness signals and next steps

- **Ready for Unit 05** (quadratic functions and factoring): the
  learner evaluates rational exponents root-first, simplifies
  radicals completely, adds/subtracts/multiplies polynomials in
  standard form, uses special products without expanding, and
  keeps exact forms separate from approximations — assessment
  42+/48 or a corrected Session 19 with no repeated error type.
- **Reteach rational exponents** (Session 17 focus) if Practice A
  items 1–4 or quiz items 1–2 are wrong: re-do Lesson 01's worked
  examples with the learner naming the root aloud before writing
  any value.
- **Reteach radical simplification** if Practice B or quiz item 3
  are wrong: re-do Lesson 02 with factor trees, circling the
  largest perfect-power factor before any root is taken.
- **Reteach polynomial multiplication** if Practice D or quiz
  item 6 are wrong: return to the area model and the partial-
  product count, and re-test with one binomial-times-binomial and
  one binomial-times-trinomial product.
- **Reteach special products** if Practice E or quiz item 7 are
  wrong: re-do Lesson 05 with the `a = …, b = …` line required
  and one numeric check per item.

## Scoring guidance

- **Formative quiz (Session 16):** 1 point per item; items 2, 6,
  and 7 earn the point only with the root-first step or the
  partial products/pattern step shown. Use the result to choose
  the Session 17 reteach focus, not as a grade.
- **Culminating assessment (Session 18):** Part A 2 points each
  (1 for the correct value, 1 for the reasoning or check shown);
  Part B 6 points each (2 for setup, 2 for correct computation,
  2 for interpretation, justification, or a correct conclusion).
  Accept any correct method in Part A items 5–7 and Part B item 14.
- **Project (Sessions 10, 14, 15):** use the rubric in `project.md`
  (5 criteria × 4 points = 20). Project notes: the worked example
  uses `a = 3, b = 5, c = 2, x = 6`, giving bed `x² + 8x + 15`,
  patio `x² + 4x + 4`, strip `x² − 4`, and total cost `$1,362`.
  For a learner's own design, the patio-minus-strip simplification
  is always `2cx + 2c²` (patio `x² + 2cx + c²` minus strip
  `x² − c²`); the strip's width `(x − c)` must stay positive,
  which is why the project requires `x > c` — a learner who
  picks `c ≥ x` has designed a strip with no (or negative) width,
  and the reflection (part c) should say so.
