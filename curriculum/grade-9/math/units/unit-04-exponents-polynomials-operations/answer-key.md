# Answer Key — Unit 04: Exponents, Polynomials, and Operations

For the guiding adult only. Every item from the lessons, practice
sets, quiz, assessment, and project is solved here. Where a lesson
asks for an explanation, the key gives the reasoning a complete
answer must contain; wording may vary.

## Lesson 01

- **Guided:** 1. `6`. 2. `5`, `2`. 3. `9^(1/2) = 3`, `3³ = 27`.
  4. `1/2`. 5. `(-16)^(1/2)` is not real (even index, negative
  base); `(-27)^(1/3) = -3` is real (odd index, `(-3)³ = -27`).
- **Independent:** 1. `7`, `4`, `3`. 2. `25^(3/2) = 125`
  (`5³`); `8^(2/3) = 4` (`2²`). 3. `16^(-3/4) = 1/8`
  (`2³ = 8`, reciprocal); `100^(-1/2) = 1/10`. 4. `(-32)^(1/5)
  = -2`, because `(-2)⁵ = -32` — an odd power preserves the sign.
  5. `36^(1/2) = 6` is larger than `27^(1/3) = 3`. 6. A complete
  answer says `25^(1/2)` asks for the number whose square is
  `25`, which is `5`, while `25 ÷ 2 = 12.5`, and `12.5² ≠ 25`.
- **Application:** side `144^(1/2) = 12` feet. Division by `2`
  would give `72`, which is not a side of a `144`-square-foot
  square (`72² ≠ 144`).
- **Exit:** `81^(3/4) = (81^(1/4))³ = 3³ = 27`.
  `(-81)^(1/4)` is not real: no real number to the fourth power
  is negative.
- **Extension:** `32^(3/5) = 2³ = 8`; `64^(-5/6) = 1/32`
  (`64^(1/6) = 2`, `2⁵ = 32`, reciprocal).

## Lesson 02

- **Guided:** 1. `√72 = 6√2` (`36 · 2`). 2. `√98 = 7√2`
  (`49 · 2`); `∛40 = 2∛5` (`8 · 5`). 3. `64^(5/6) =
  (64^(1/6))⁵ = 2⁵ = 32`. 4. `√(27x²) = 3x√3` for `x ≥ 0`.
  5. Exact `5√2`; approximate `≈ 7.07`.
- **Independent:** 1. `√80 = 4√5`; `√125 = 5√5`; `∛24 = 2∛3`.
  2. `81^(3/4) = 27`; `125^(-2/3) = 1/25`. 3. `√(50x²) = 5x√2`
  for `x ≥ 0`; `√18 + √8 = 3√2 + 2√2 = 5√2`. 4. `∛(x⁴) =
  x^(4/3)`; `x^(3/2) = √(x³)`. 5. Exact `√72 = 6√2` feet;
  nearest tenth `≈ 8.5` feet. The carpenter gets the rounded
  length to cut; the algebra keeps the exact form so later
  results are not corrupted by rounding.
- **Application:** `√50 = 5√2`, `√32 = 4√2`, total `9√2` inches.
  Roots do not add by adding radicands: `√50 + √32 ≠ √82`
  (and `9√2 ≈ 12.73`, while `√82 ≈ 9.06`).
- **Exit:** `√180 = √(36 · 5) = 6√5 ≈ 13.42`.
- **Extension:** `√(72x⁴) = 6x²√2` for `x ≥ 0`;
  `3/√5 = (3√5)/5`.

## Lesson 03

- **Guided:** 1. `3x² − 3x + 7`. 2. `3x² − 4x + 6` (every sign
  of the second polynomial flips). 3. Standard form `2x³ − 3x +
  7`; degree `3`, leading coefficient `2`, constant term `7`.
  4. No: `1/x = x^(-1)` has a negative exponent, not a
  whole-number exponent.
- **Independent:** 1. `3x³ + 6x + 7`. 2. `5x² + 7x − 4`.
  3. `−x³ − 5x² + 2x + 6`. 4. Perimeter `2(2x + 3) + 2(x − 1) =
  6x + 4` feet. 5. A complete answer: adding combines like
  terms, and every term of a sum of polynomials still has a
  whole-number exponent, so the result is a polynomial (for
  example, `(x² + 1) + (2x) = x² + 2x + 1`); a quotient can
  introduce a negative exponent, so it need not be a polynomial
  (for example, `(2x)/(x²) = 2/x = 2x^(-1)`).
- **Application:** combined cost `5x² + 30x + 40` dollars; at
  `x = 2`, `$120`. It is still a polynomial, by closure under
  addition.
- **Exit:** sum `5x³ + 4x` (degree `3`); difference `x³ − 6x + 8`
  (degree `3`).
- **Extension:** `3x²y − 2xy + 3y²`, degree `3`. `x²y` and `xy²`
  are not like terms: the exponents on `x` and `y` are swapped.

## Lesson 04

- **Guided:** 1. `x² + 8x + 15`. 2. `3x² + 10x − 8`.
  3. `x³ + x² + x − 3` (six partial products). 4. Degree `5`
  (`2 + 3`).
- **Independent:** 1. `x² + 5x − 14`; `4x² − 4x − 15`.
  2. `x³ + 3x² − 3x + 4`. 3. `9x² − 6x + 1`. 4. Area
  `2x² + 7x + 3` square feet; at `x = 4`, `63` square feet
  (check: `(9)(7) = 63`). 5. A complete answer: the area model
  draws one region per pair of terms, so a trinomial factor
  gives six regions, while FOIL names only the four products of
  two binomials; using FOIL on a trinomial drops two products.
- **Application:** patio `(x + 2)² = x² + 4x + 4`; bed
  `(x + 2)(x − 1) = x² + x − 2`. The patio is larger by
  `3x + 6`. At `x = 5`: patio `49`, bed `28`, difference `21 =
  3(5) + 6` ✓.
- **Exit:** `x³ + 7x² + 4x − 12`; degree `3` (predicted: `1 + 2`).
- **Extension:** `2x⁴ + 3x³ − 7x² + 5x − 3`; degree `4`,
  leading coefficient `2` (predicted: `2 + 2`, `1 · 2`).

## Lesson 05

- **Guided:** 1. `x² − 81`; `25x² − 1`. 2. `x² + 12x + 36`;
  `9x² − 12x + 4`. 3. `99 · 101 = (100 − 1)(100 + 1) = 10,000 −
  1 = 9,999`. 4. Missing term `2(2x)(3) = 12x`; correct
  `4x² + 12x + 9`.
- **Independent:** 1. `x² − 64`; `16x² − 25`; `x⁶ − 9`.
  2. `x² − 8x + 16`; `4x² + 28x + 49`; `25x² − 10x + 1`.
  3. `52² = (50 + 2)² = 2,500 + 200 + 4 = 2,704`;
  `98 · 102 = (100 − 2)(100 + 2) = 10,000 − 4 = 9,996`.
  4. (a) No pattern (constants `2` and `−7` differ):
  `x² − 4x − 21`. (b) Difference of squares: `4x² − 25`.
  (c) Square of a difference: `x² − 12x + 36`. 5. A complete
  answer: in `(a + b)²` the two middle terms are both `+ab`,
  so they add to `2ab` (three terms total); in `(a + b)(a − b)`
  they are `+ab` and `−ab`, so they cancel (two terms total).
- **Application:** square area `x² + 8x + 16`; rectangle area
  `x² − 16`. The rectangle area is zero when `x = 4`: its width
  `(x − 4)` becomes `0`, so the "rectangle" collapses to a line
  segment — not a plot. (For a real plot, `x > 4`.)
- **Exit:** `9x² − 24x + 16`; `4x² − 81`;
  `203 · 197 = (200 + 3)(200 − 3) = 40,000 − 9 = 39,991`.
- **Extension:** `(x + y + 2)² = x² + 2xy + y² + 4x + 4y + 4`;
  `1003 · 997 = 1,000,000 − 9 = 999,991`.

## Lesson 06

- **Guided:** 1. `5 + √7` irrational (rational + irrational);
  `3√2` irrational (nonzero rational × irrational). 2. `√3 ·
  √12 = √36 = 6`, rational; `√3 · √5 = √15`, irrational.
  3. Exact `6√2` feet; nearest hundredth `≈ 8.49` feet.
  4. `3x − 7 = 11`: add `7` to both sides, `3x = 18`; divide by
  `3`, `x = 6`. Check: `18 − 7 = 11` ✓.
- **Independent:** 1. `1/3 + √2` irrational; `0 · √5 = 0`
  rational; `√5 · √20 = √100 = 10` rational; `√5 · √7 = √35`
  irrational; `2√3 − 2√3 = 0` rational. 2. Expand:
  `x² + 5x + 6`; at `x = 2`, `20`. Substitute first:
  `(4)(5) = 20` ✓. 3. Exact product `12.345 · 37 = $456.765`;
  a bill charges `$456.77` (rounded to cents); the bill rounds
  the exact product to the nearest cent. 4. Adding the equations:
  `3x = 12`, `x = 4`, `y = 5`. Checks: `4 + 5 = 9` ✓,
  `2(4) − 5 = 3` ✓.
- **Application:** `√200 = 10√2`, `√50 = 5√2`, exact total
  `15√2` miles, nearest tenth `≈ 21.2` miles. The sign's number
  must not replace the exact sum for three laps: three laps from
  the exact sum is `45√2 ≈ 63.64` miles (to hundredths), while
  tripling the rounded sign value gives `3 · 21.2 = 63.60`
  miles — a `0.04`-mile gap created purely by rounding early.
- **Exit:** `√6 · √10 = √60`, irrational; `√6 · √24 = √144 =
  12`, rational. `√80 = 4√5 ≈ 8.9`.
- **Extension:** `(√2 + 1)(√2 − 1) = 2 − 1 = 1`, rational.
  This does not contradict the nonzero-rational-times-irrational
  rule: that rule is about one rational factor times one
  irrational factor, not about a product of two binomials each
  containing an irrational term.

## Culminating assessment (Session 18)

**Part A.** 1. `3`, `25`. 2. `1/7`, `8`. 3. `6√3`
(`36 · 3`); `2∛2`. 4. `√(x⁵) = x^(5/2)` for `x ≥ 0`;
`y^(3/4) = ⁴√(y³)`. 5. Sum `x³ + 7x + 5`; difference `3x³ + 3x
− 7`. 6. `x² − 3x − 40`; `6x² + x − 12`. 7. `16x² − 8x + 1`;
`x⁴ − 9`. 8. `4 + √6` irrational; `√5 · √45 = √225 = 15`
rational; `√5 · √11 = √55` irrational. 9. Exact `5√5`;
nearest tenth `≈ 11.2`. 10. Degree `5` (`2 + 3`), leading
coefficient `2` (`2 · 1`): the leading term of the product
comes from multiplying the leading terms, `2x² · x³ = 2x⁵`.

**Part B.** 11. (a) Partial products: `2x · x = 2x²`,
`2x · (−2) = −4x`, `3 · x = 3x`, `3 · (−2) = −6`; area
`2x² − x − 6` square feet. (b) At `x = 7`: substitute first,
`(17)(5) = 85`; expand first, `2(49) − 7 − 6 = 85` ✓.
(c) Width `(x − 2)` is zero at `x = 2`; a rectangle with a
zero side has no area and is not a rectangle, so `x = 2` (and
any `x ≤ 2`, which would give a zero or negative width) is
excluded. 12. `1002 · 998 = (1000 + 2)(1000 − 2) = 1,000,000 −
4 = 999,996`; `75² = (70 + 5)² = 4,900 + 700 + 25 = 5,625`.
A complete explanation of `(x + 9)² ≠ x² + 81`: expanding
gives `x² + 18x + 81`, and the middle term `18x` is present
whenever `x ≠ 0`; dropping it is the error. 13. (a) Side
`√60 = 2√15 ≈ 7.75` feet. (b) `√60 + √15 = 2√15 + √15 =
3√15` feet. (c) The rounded sides sum to `7.75 + 3.87 =
11.62`, and the exact sum rounded is `3√15 ≈ 11.62` — the
same here, but that agreement is not guaranteed: rounding
first can change the last digit, for example `√2 + √3 ≈
1.41 + 1.73 = 3.14` from rounded addends versus `≈ 3.15`
from the exact sum rounded. Round at the end, not in the
middle. 14. (a) `4x − 9 = 2x + 5`: subtract `2x`, `2x − 9 =
5`; add `9`, `2x = 14`; divide by `2`, `x = 7`. Check:
`28 − 9 = 19 = 14 + 5` ✓. (b) Subtracting the equations (or
substitution): `y = 3`, `x = 5`. Checks: `5 + 6 = 11` ✓,
`5 − 3 = 2` ✓. (c) `y = 3x − 4`; at `x = 5`, `y = 11`.

## Project (worked example verification)

The project page's worked example uses `a = 3, b = 5, c = 2,
x = 6`: bed `(x + 3)(x + 5) = x² + 8x + 15 = 99` at `x = 6`;
patio `(x + 2)² = x² + 4x + 4 = 64`; strip `(x + 2)(x − 2) =
x² − 4 = 32`; costs `$594 + $640 + $128 = $1,362`; patio
minus strip `4x + 8` (the general form `2cx + 2c²` at `c = 2`).
For a learner's own design, verify by expanding the learner's
own binomials and substituting the learner's own `x`; accept
any design meeting `x > c` with whole-number `a, b, c` in
range and `a ≠ b`.
