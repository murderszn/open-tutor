# Unit Assessment — Unit 01: Algebra Foundations (Session 18)

**Grade 9 Math** · ~50 minutes · Calculator allowed for checking only.
Show all work. Justifications are required wherever steps are shown.

**Objective key:** O1 = expression structure (A-SSE.1) · O2 = equivalent
expressions (A-SSE.2) · O3 = solving, justification, solution types
(A-REI.1, A-REI.3) · O4 = creating equations/inequalities (A-CED.1) ·
O5 = formulas, units, accuracy (A-CED.4, N-Q)

---

## Part A — Expression structure (O1)

1. A gym membership costs $35 signup plus $22 per month: `C = 35 + 22m`.
   (a) Name the terms, the coefficient of `m`, and the constant term.
   (b) Explain what each part means for a new member. (2+2 pts)
2. In `E = 5(3x − 2) + 7x`, identify the terms. Which chunk would you view
   as a single entity, and why? (3 pts)
3. Evaluate `E` from #2 for `x = 4`. Show the substitution. (2 pts)

## Part B — Equivalent expressions (O2)

4. Rewrite each in simplest form: (a) `6(2a − 5) + 3a`, (b) `−4(x + 1) + 2(x − 3)`. (4 pts)
5. Factor completely: `18y − 12`. Verify by substituting `y = 2` into both
   forms. (3 pts)
6. **Error analysis.** "Rin wrote `3(x + 4) = 3x + 4`." Explain the error and
   write the correct equivalence. (3 pts)

## Part C — Solving equations (O3)

7. Solve `7x − 9 = 3x + 15`. Justify each step and check the solution. (5 pts)
8. Solve `2(3n − 4) + 5 = n + 11`. Justify each step and check. (5 pts)
9. Solve `(2/5)x + 3 = 11 − (3/5)x`. Show the denominator-clearing step. (4 pts)
10. Classify each — one solution, infinitely many, or no solution — and solve
    when a solution exists:
    (a) `5(t + 2) = 5t + 10` (b) `8 − 3x = 8 − 3x + 5` (c) `6x + 1 = 2(3x + 4)` (6 pts)
11. Solve `ax + 9 = 25` for `x`. State any restriction on `a`. (3 pts)

## Part D — Inequalities (O3)

12. Solve `4x − 7 < 5x + 2`. Graph the solution set (describe: boundary,
    circle type, direction) and verify with one test value inside and one
    outside. (5 pts)
13. Solve `−6x + 4 ≥ 28`. Explain *why* the inequality sign changes, then
    graph the solution set. (5 pts)
14. Solve `0 < 3x − 6 ≤ 12`. Write the solution set. (4 pts)

## Part E — Modeling and formulas (O4, O5)

15. A car rental costs $55 per day plus $0.25 per mile: `C = 55d + 0.25m`.
    (a) For a 3-day rental driven 240 miles, find the cost with units.
    (b) A traveler has $300 for a 2-day rental. Write and solve an equation
    for the miles they can drive. Answer in a sentence. (3+4 pts)
16. A club's bake sale must raise at least $450. They already have $90 and
    earn $6 per box sold. Write and solve an inequality for the number of
    boxes; give the answer as a sensible whole number and explain the
    rounding. (5 pts)
17. Solve `V = πr²h`... no — Unit-01 tools cannot isolate `r` there (it is
    squared). Instead: solve `d = rt` for `r`, then use your result to find
    the rate for `d = 195` miles and `t = 3` hours, with units. Explain in
    one sentence why the `V = πr²h` rearrangement is out of reach for now.
    (2+2+2 pts)

**Total: 78 pts.** Grade bands (adult-set; adjust to your scale):
68–78 = exceeds · 55–67 = meets · 42–54 = approaching · below 42 = reteach
and reassess. Every item's solution is worked in
