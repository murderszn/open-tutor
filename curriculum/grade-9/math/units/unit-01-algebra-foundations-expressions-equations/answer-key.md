## Lesson 01 {#lesson-01}

**Readiness:** (a) `3 + 8 − 1 = 10`; (b) `10 + 15 = 25`.

**Guided:** 1. Terms: `25`, `0.10m`; coefficient of `m`: 0.10; constant: 25.
2. `T = 25 + 0.10(120) = 25 + 12 = 37` → $37. 3. Factors: `5` and `(3x − 1)`;
entity: `(3x − 1)`. 4. The coefficient is **−7** — the sign belongs to the
term.

**Independent:** 5. `C = 45 + 60h`; terms `45`, `60h`; coefficient 60;
constant 45. 6. `C = 45 + 60(3) = 225` → $225: $45 trip fee + $180 labor.
7. Terms: `6(x + 2)` and `−x`; entity `(x + 2)`; "six copies of the quantity
(x + 2), minus x." 8. `P = 2(7.5 + 3) = 2(10.5) = 21` meters.

**Application:** Terms `8s`, `−120`; coefficient 8; `−120` = daily fixed
costs (the truck loses $120 selling zero sandwiches). Profit zero:
`8s − 120 = 0` → `8s = 120` → `s = 15` sandwiches.

**Exit:** (a) terms `4(2x + 5)` and `−3x`; (b) coefficient −3; (c) entity
`(2x + 5)`.

## Lesson 03 {#lesson-03}

**Readiness:** `x = 8` (subtract 7 both sides); `x = 9` (divide both sides by 2).

**Guided:** 1. `5x + 9 = 3x − 7` → subtract `3x`: `2x + 9 = −7` → subtract 9:

→ subtract `x`: `x + 8 = 13` → subtract 8: `x = 5`. Check: `2(9) = 18`;
`5 + 13 = 18` ✓.

**Independent:** 4. (a) `7n − 3 = 4n + 15` → `3n − 3 = 15` → `3n = 18` →

(c) `(1/2)y + 6 = 14 − (3/2)y` → multiply by 2 (multiplication property):

`2 + 6 = 8`; `14 − 6 = 8` ✓.
5. Tomas's illegal step: `4x = 12 − 8` — he subtracted 8 from the right

6. Sample: `2x + 1 = −5` → `2x = −6` → `x = −3` (subtract 1; divide 2).

**Application:** `40 + 25h = 165` → `25h = 125` → `h = 5` half-hours =

**Exit:** `6(x − 1) = 2x + 10` → `6x − 6 = 2x + 10` (distributive) →
`4x − 6 = 10` (subtract 2x) → `4x = 16` (add 6) → `x = 4` (divide 4).

## Lesson 04 {#lesson-04}

**Readiness:** `2x + 6`; the second has `5x` on both sides — the variable
will vanish, leaving a true or false statement.

**Guided:** 1. (a) `3x + 2 = 3x + 2` → `0 = 0`: **infinitely many**.
(b) `7 − 2x = 7 − 2x + 1` → `7 = 8`: **no solution**.
2. `mx + 4 = 10` → `mx = 6` → `x = 6/m`, **provided `m ≠ 0`** (if `m = 0`,
`4 = 10` is false).

**Independent:** 3. (a) `6y − 12 = 6y − 12` → infinitely many.
(b) `4t + 9 = 4t − 1` → `9 = −1` → no solution.
(c) `−3z − 6 = −3z − 5` → `−6 = −5` → no solution.
(d) `8x − 3 = 5x + 12` → `3x = 15` → `x = 5` (one solution). Check:
`40 − 3 = 37`; `25 + 12 = 37` ✓.
4. (a) `l = A/w` (`w ≠ 0`). (b) `y − b = mx` → `m = (y − b)/x` (`x ≠ 0`).
(c) `ax = 10` → `x = 10/a` (`a ≠ 0`).
5. `x = 0` example: `5x = 0` → `x = 0` (check: `0 = 0` ✓ — zero is a genuine
solution). No-solution example: `x + 5 = x + 7` → `5 = 7` (false). Tell
them apart: one ends `x = <number>`; the other ends with a false statement
and no variable.

**Application:** (a) `C = 20 + 0.05d` → `0.05d = C − 20` → `d = (C − 20)/0.05`
`= 20(C − 20)`. (b) `C = 47.50`: `d = 27.50/0.05 = 550` MB. Check:
`20 + 0.05(550) = 47.50` ✓.

**Exit:** `9x − 4 = 9x + 4` → `−4 = 4`: **no solution**. `bx + 1 = 9` →
`bx = 8` → `x = 8/b`, `b ≠ 0`.

**Extension:** `2(x + k) = 2x + 10` → `2k = 10` → `k = 5` makes it an
identity. `kx + 4 = 10` → `kx = 6`: no solution exactly when `k = 0`.

## Lesson 05 {#lesson-05}

**Readiness:** `x = 5`: `11 < 12` yes. `x = 6`: `13 < 12` no.

**Activity:** (a) Line 1 (`x > 3`): 4 is a solution (`4 > 3` ✓), 3 is not
(`3 > 3` false). Line 2 (`x ≤ −1`): −1 is a solution (`−1 ≤ −1` ✓), 0 is not.
Line 3 (`−1 < x ≤ 3`): 0 is a solution, −1 is not (`−1 < −1` false).
(b) Line 1's `>` excludes 3 (open circle); line 3's `≤` includes 3 (filled
circle) — the circle shows whether the boundary satisfies the inequality.
(c) `2 ≤ x < 7`: filled circle at 2, open circle at 7, segment between.

**Guided:** 1. `5x + 2 > 3x + 10` → `2x > 8` → `x > 4`. Open circle at 4, ray
right. 2. `−2x + 5 < 13` → `−2x < 8` → `x > −4` (flip). Open circle at −4,
ray right. 3. `40 + 25m ≤ 200` → `25m ≤ 160` → `m ≤ 6.4`: at most 6 full
months.

**Independent:** 4. (a) `4x − 9 ≥ x + 6` → `3x ≥ 15` → `x ≥ 5`. Filled circle
at 5, ray right. (b) `−3(x + 2) > 9` → `−3x − 6 > 9` → `−3x > 15` → `x < −5`
(flip). Open circle at −5, ray left. (c) `1 < 2x − 3 ≤ 11` → add 3:
`4 < 2x ≤ 14` → `2 < x ≤ 7`. Open at 2, filled at 7, segment between.
5. Test trio for (b): boundary `x = −5`: `−3(−3) = 9 > 9` false — excluded ✓;
inside `x = −6`: `−3(−4) = 12 > 9` true ✓; outside `x = 0`:
`−3(2) = −6 > 9` false ✓.
6. Lena forgot the flip: `−5x < 20` → divide by −5 (negative) → `x > −4`.
Mirror idea: multiplying by −1 reflects the number line through 0, reversing
order, so the symbol must reverse too. Graph: open circle at −4, ray right.

**Application:** `120 + 8s < 300` → `8s < 180` → `s < 22.5` → at most **22**
sandwiches (23 would cost `120 + 184 = 304 ≥ 300`).

**Exit:** `6 − 2x ≥ 14` → `−2x ≥ 8` → `x ≤ −4` (flip). Filled circle at −4,
ray left. Solution: `x = −5` (`6 + 10 = 16 ≥ 14` ✓). Non-solution: `x = 0`
(`6 ≥ 14` false).

## Lesson 06 {#lesson-06}

**Readiness:** (a) `3 + 2m = 17`; (b) the ride's length in miles.

**Guided:** 1. `h` = hours. `45 + 60h = 285` → `60h = 240` → `h = 4`. **Four
hours of labor.** Check: `45 + 240 = 285` ✓. 2. `C = 2πr` → `r = C/(2π)`.

**Independent:** 3. `m` = MB over. `20 + 0.08m = 34.40` → `0.08m = 14.40` →
`m = 180`. **180 MB over.** Check: `20 + 14.40 = 34.40` ✓.
4. `9.5n ≤ 1200` → `n ≤ 126.3` → **126 students** (127 would cost $1,206.50,
over budget — round down because the cap is a maximum).
5. (a) `A = πr²`: `r` is squared; isolating it needs a square root, which is
beyond linear equation tools (arrives in U06). (b) `F = (9/5)C + 32` →
`F − 32 = (9/5)C` → `C = (5/9)(F − 32)`. (c) `ax + by = c` → `by = c − ax` →
`y = (c − ax)/b`, `b ≠ 0`.
6. Jo's error: `vt` is a product, not a sum — you cannot "subtract" `v`.
Undo multiplication with division: `S = vt + d` → `S − d = vt` →
`t = (S − d)/v`.

**Application:** `120 ≤ r ≤ 150`. A reading of 118 is **below the target
zone** — under, not in, the intended range.

**Exit:** `4.50n + 5 = 50` → `4.5n = 45` → `n = 10`. **Ten notebooks**
(`10 × $4.50 = $45`, leaving $5.00 on the card).

## Project — The Plan Audit (sample solution for the rubric) {#project}

1. `C_A(x) = 30 + 4x`; `C_B(x) = 50 + 1.5x`. Plan A: constant term $30 (base
even at 0 GB), coefficient 4 ($4/GB). Plan B: constant $50, coefficient 1.5.
2. E.g. `C_B(x) = 50 + 1.5x = 0.5(100 + 3x)`; at `x = 10`: `50 + 15 = 65`
and `0.5(130) = 65` ✓.
3. `30 + 4x = 50 + 1.5x` → `2.5x = 20` → `x = 8` GB — **one solution**.
Below 8 GB Plan A is cheaper (test `x = 0`: $30 vs $50); above 8 GB Plan B
is cheaper (test `x = 20`: $110 vs $80).
4. Plan A: `30 + 4x ≤ 75` → `x ≤ 11.25` → **11 GB**. Plan B:
`50 + 1.5x ≤ 75` → `x ≤ 16.67` → **16 GB**. Number lines: filled circles at
the boundaries, rays leftward.
5. `B = 50 + 1.5x` → `1.5x = B − 50` → `x = (B − 50)/1.5`. At `B = 75`:
`x = 25/1.5 ≈ 16.67` → 16 whole GB, matching Part 4.
6. At 12 GB: Plan A costs `30 + 48 = $78` — **over the $75 cap**; Plan B
costs `50 + 18 = $68` — under cap. **Recommend Plan B**, citing the $8
break-even and the budget analysis; note the model ignores taxes, fees,
coverage, and throttling.
7. Extension: identical to Plan A for all `x` when `m = 30`, `p = 4`
(identity: `30 + 4x = 30 + 4x`). Never matches when the lines are parallel
but distinct: `p = 4` with `m ≠ 30` (contradiction, e.g. `30 = 40`).
