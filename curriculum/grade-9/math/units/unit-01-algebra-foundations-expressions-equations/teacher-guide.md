# Teacher Guide — Unit 01: Algebra Foundations

## Pacing at a glance

20 sessions across Weeks 3–6; see the session table in the unit
[README](README.md#session-pacing--20-sessions-four-weeks--five-50-minute-sessions).
The project ([project.md](project.md)) launches Session 10 and is due
Session 19. The formative quiz lands Session 15 so Session 17 can reteach
before the Session 18 assessment.

## Misconceptions to hunt (with reteaching moves)

1. **Term vs. factor.** Learners call the `4` in `4(2x + 5)` a term.
   *Move:* the "bill" analogy — a term is a separate charge on the bill; a
   factor scales a whole chunk. Return to Lesson 1, Worked example 1.
2. **Partial distribution** — `4(x + 5) = 4x + 5`. *Move:* the tile image
   (Lesson 2 activity): count the tiles. Four groups of (x + five 1s) cannot
   total `4x + 5`.
3. **Unjustified "moves."** "Move the 3 over" with no property named.
   *Move:* require the justification word bank (distributive, combine like
   terms, add/subtract/multiply/divide both sides) on every solution until
   Session 12; spot-check aloud.
4. **`x = 0` vs. no solution.** *Move:* keep one identity, one contradiction,
   and one `x = 0` equation on the board all week; ask "which ending is
   this?" as a warm-up.
5. **The sign flip without the mirror.** Learners flip on `−x < 5` → `x > −5`
   only if the mirror story stuck. *Move:* have them test `x = 0` and
   `x = −10` in the original before and after solving.
6. **Reversed modeling equations** (`12 + 2.5 = 87h`). *Move:* the four-step
   habit plus the substitution check — if the check fails, the model (not
   the arithmetic) is usually wrong.

## Differentiation

- **Supports:** justification word bank; four-row modeling template
  (variable / unit / equation / interpretation); pre-sorted equation bins for
  Lesson 4; tactile number lines; dictated steps with learner-supplied
  justifications; text alternatives for both images (in Lessons 2 and 5).
- **Extensions:** each lesson carries one; the project extension (letter-
  coefficient plan analysis) can replace a practice set for fast finishers.
- **Language access:** read expressions aloud before analyzing; keep the
  vocabulary list posted with one example each.

## Reteaching triggers and next steps

- **Quiz (Session 15) below 30/44:** reteach the flagged objective in
  Session 17 using its lesson's error-analysis task; do not advance to new
  content that session.
- **Project break-even misclassified:** return to Lesson 4's three endings
  with the learner's own plan numbers.
- **Fractional-GB budget answers with no comment:** revisit Lesson 6's
  accuracy discussion (N-Q.3) before Session 18.
- **Ready for U02:** learners justify steps unprompted, classify solution
  types on sight, and interpret answers in sentences with units. U02 builds
  directly on the structure language here (slope as a coefficient, intercept
  as a constant term) — keep that vocabulary alive.
