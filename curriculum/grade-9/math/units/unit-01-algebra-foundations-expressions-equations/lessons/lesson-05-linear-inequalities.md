# Lesson 05 — Linear Inequalities: Solving, Graphing, and Meaning

**Goal:** I can solve linear inequalities in one variable, graph the solution
set on a number line, and explain what the solution set means in context.
**Time:** 50 minutes · **Materials:** notebook; the number-line SVG below
(with text alternative)

## Readiness check (5 min)

Is `x = 5` a solution to `2x + 1 < 12`? What about `x = 6`? (`2(5)+1 = 11 <
12` yes; `2(6)+1 = 13 < 12` no.) An inequality has many solutions — today you
describe all of them at once.

## Teaching: inequalities describe a crowd, not a person (15 min)

A **solution set** is every number that makes the inequality true. You find it
with the same moves as equations — **except one**: multiplying or dividing by
a **negative** number reverses the inequality sign.

**Why the flip?** On the number line, multiplying by −1 mirrors everything
through 0: `2 < 5` becomes `−2 > −5`. The order genuinely reverses, so the
symbol must too. Adding or subtracting never flips — sliding the line left or
right keeps the order.

Graphing conventions: an **open circle** means the endpoint is *not* included
(`<`, `>`); a **filled circle** means it *is* (`≤`, `≥`). Shade the ray or
segment of all solutions.

### Worked example 1 — solve and graph

> Solve `3x − 7 < 2x + 8`. Graph the solution set.

1. Subtract `2x` from both sides: `x − 7 < 8`. Add 7 to both sides: `x < 15`.
2. Graph: open circle at 15, ray to the left (all numbers less than 15).
3. **Check with test values.** Boundary `x = 15`: `3(15) − 7 = 38`,
   `2(15) + 8 = 38`; `38 < 38` is false — correct, the boundary is excluded.
   Inside pick `x = 0`: `−7 < 8` true ✓. Outside pick `x = 20`:
   `53 < 48` false ✓. The test trio (boundary, inside, outside) proves the
   graph matches the algebra.

### Worked example 2 — the sign flip

> Solve `−4x + 3 ≥ 19`. Graph the solution set.

1. Subtract 3 from both sides: `−4x ≥ 16`.
2. Divide both sides by `−4` — **negative, so flip `≥` to `≤`**: `x ≤ −4`.
3. Graph: filled circle at −4 (included), ray to the left.
4. Check. Boundary `x = −4`: `−4(−4) + 3 = 19`, and `19 ≥ 19` true —
   boundary included ✓. Inside `x = −5`: `23 ≥ 19` true ✓. Outside `x = 0`:
   `3 ≥ 19` false ✓.

### Worked example 3 — compound inequality

> Solve `−2 < 3x + 1 ≤ 10` and describe the solution set.

Work all three parts at once — whatever you do to the middle, do to both
ends:

1. Subtract 1 everywhere: `−3 < 3x ≤ 9`.
2. Divide by 3 (positive — no flip): `−1 < x ≤ 3`.
3. Meaning: every number strictly greater than −1 and at most 3. Graph: open
   circle at −1, filled circle at 3, segment between (see the SVG's third
   line).

## Guided practice (8 min, with hints)

1. Solve `5x + 2 > 3x + 10` and graph. *Hint: same as equations — no flip
   needed here.*
2. Solve `−2x + 5 < 13` and graph. *Hint: watch the sign when you divide.*
3. Solve `40 + 25m ≤ 200` and graph. Then interpret: if `m` is months of a
   $40-signup, $25/month gym membership, what does your solution set mean for
   the buyer?

## Independent practice (9 min)

4. Solve and graph: (a) `4x − 9 ≥ x + 6`, (b) `−3(x + 2) > 9`,
   (c) `1 < 2x − 3 ≤ 11`.
5. For (b), run the test trio (boundary, inside, outside) and show each check.
6. **Explain-your-reasoning:** "Lena solved `−5x < 20` and got `x < −4`."
   Identify the error, explain *why* the rule she broke exists (use the
   number-line mirror idea), and give the correct solution set.

## Application (3 min)

A food truck must keep daily costs under $300. Costs are `$120 + 8s` where `s`
is sandwiches made. Write and solve the inequality for `s`, and state the
answer as a whole number of sandwiches with a reason (you cannot make a
fraction of a sandwich).

## Exit check

Solve `6 − 2x ≥ 14`, graph the solution set, and give one solution and one
non-solution with checks.

## Supports and extensions

- **Reading access:** chant the flip rule with the reason — "negative
  multiply or divide, the order flips, mirror through zero."
- **Alternate response:** use a physical number line and counters to test
  candidate solutions.
- **Extension:** Solve and graph `|x − 2| < 3` by reasoning about distance
  (foreshadows absolute value; not required).

## Teacher note

The sign-flip is the #1 error source. Learners who memorize "flip when
negative" without the mirror intuition will flip on `−x < 5` rewrites too —
probe with `−x < 5` (answer `x > −5`) until the mirror story is theirs.
