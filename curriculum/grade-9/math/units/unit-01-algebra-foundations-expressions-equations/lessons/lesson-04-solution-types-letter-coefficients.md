# Lesson 04 — Solution Types and Equations with Letter Coefficients

**Goal:** I can tell whether a linear equation has one solution, infinitely
many, or none — and solve equations where the coefficients are letters.
**Time:** 50 minutes · **Materials:** notebook

## Readiness check (5 min)

Simplify both sides of `2(x + 3)` and `5x − 3 = 5x + 4`. What do you notice
before solving anything? (`2x + 6`; the second has `5x` on both sides.)

## Teaching: three possible endings (15 min)

Simplifying a linear equation can only end three ways:

1. **`x = <a number>` — one solution.** The equation pins the variable down.
2. **A true statement like `0 = 0` — infinitely many solutions (an identity).**
   The equation is true no matter what `x` is.
3. **A false statement like `−3 = 4` — no solution (a contradiction).** The
   equation is true for no value of `x`.

The classification is in *equation form* today (grade 8 saw it; here it
returns with justification). Warning: `x = 0` is **one solution** (the number
zero), not "no solution." And `0 = 0` means every number works, not "zero."

**Letter coefficients.** In `ax + 5 = 13`, the letters `a` is a known-but-
unspecified number. Solve the same way, and note any division restriction:
`ax = 8` (subtract 5 both sides), then `x = 8/a` (divide both sides by `a`),
**provided `a ≠ 0`**. If `a = 0`, the equation `5 = 13` is false — no
solution. Formulas are just equations with letter coefficients, which is why
this skill unlocks Lesson 6.

### Worked example 1 — identity

> Classify and solve `2(x + 3) = 2x + 6`.

1. Distribute: `2x + 6 = 2x + 6`.
2. Subtract `2x` from both sides: `6 = 6`. Subtract 6: `0 = 0`.
3. `0 = 0` is always true → **infinitely many solutions**. Check with
   `x = 10`: `2(13) = 26` and `2(10) + 6 = 26` ✓; with `x = −4`: `2(−1) = −2`
   and `2(−4) + 6 = −2` ✓.

### Worked example 2 — contradiction

> Classify and solve `5x − 3 = 5x + 4`.

1. Subtract `5x` from both sides: `−3 = 4`.
2. `−3 = 4` is always false → **no solution**. (Notice the variable vanished —
   that is the signal to read the remaining statement, not to force an
   answer.)

### Worked example 3 — one solution, check it

> Solve `4x + 7 = 2x − 5`.

1. Subtract `2x` both sides: `2x + 7 = −5`. Subtract 7 both sides:
   `2x = −12`. Divide by 2: `x = −6`.
2. Check: `4(−6) + 7 = −24 + 7 = −17`; `2(−6) − 5 = −12 − 5 = −17` ✓.

### Worked example 4 — letter coefficients

> Solve `P = 2l + 2w` for `w` (perimeter formula, solve for width).

1. Subtract `2l` from both sides: `P − 2l = 2w` (subtraction property).
2. Divide both sides by 2: `w = (P − 2l)/2`, equivalently `w = P/2 − l`.
3. Check with numbers: `l = 5`, `P = 26` → `w = (26 − 10)/2 = 8`. Original:
   `2(5) + 2(8) = 10 + 16 = 26` ✓.

## Guided practice (10 min, with hints)

1. Classify: (a) `3x + 2 = 3x + 2`, (b) `7 − 2x = 7 − 2x + 1`. *Hint: simplify
   both sides first, then read the ending.*
2. Solve `mx + 4 = 10` for `x`. State the restriction on `m`. *Hint: same
   steps as numbers — what would you do if m were 3?*

## Independent practice (12 min)

3. Classify and solve (or state no solution): (a) `6(y − 2) = 6y − 12`,
   (b) `4t + 9 = 4t − 1`, (c) `−3(z + 2) = −3z − 5`, (d) `8x − 3 = 5x + 12`.
4. Solve for the indicated letter: (a) `A = lw` for `l`; (b) `y = mx + b`
   for `m` (assume `x ≠ 0`); (c) `ax − 3 = 7` for `x`.
5. **Explain-your-reasoning:** A learner says "`x = 0` means no solution
   because there's nothing there." Correct them with an example equation whose
   solution really is `x = 0`, and contrast it with a genuine no-solution
   equation.

## Application (5 min)

A phone plan's monthly cost is `C = 20 + 0.05d` dollars for `d` megabytes over
the allowance. (a) Solve for `d` in terms of `C`. (b) If the bill is $47.50,
how many extra megabytes were used? Show the substitution.

## Exit check (3 min)

Classify `9x − 4 = 9x + 4` and solve `bx + 1 = 9` for `x` (state any
restriction).

## Supports and extensions

- **Reading access:** use the signal words — "variable vanished, true
  statement" → identity; "variable vanished, false statement" → no solution.
- **Alternate response:** sort pre-written equations into three labeled bins
  before solving any.
- **Extension:** For what value of `k` does `2(x + k) = 2x + 10` become an
  identity? For what values does `kx + 4 = 10` have no solution?

## Teacher note

The `x = 0` vs "no solution" confusion is the durable misconception — probe
it every session this week. Letter coefficients feel alien until learners see
they already solved `3x + 4 = 10`; `mx + 4 = 10` is the same moves with `m`
standing in for 3. Answer-key reference:
