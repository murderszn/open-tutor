# Culminating Assessment — Unit 03 (Session 18)

Show all work. Check claimed solutions in both equations (or in every
inequality). This assessment is a practice check, not a standardized
or validated assessment.

## Part A — short tasks (2 points each, 24 points)

1. Is `(5, 1)` a solution of `2x + y = 11` and `x − y = 4`?
2. Solve `y = x − 2` and `2x + y = 10` by substitution.
3. Solve `3x − y = 7` and `x + y = 5` by elimination.
4. Solve `x + 3y = 12` and `2x − 3y = 6` by elimination.
5. Classify `y = −2x + 3` and `2x + y = 3`, with a reason.
6. Classify `x + 2y = 5` and `x + 2y = 9`, with a reason.
7. A shop sells pens for $2 and notebooks for $5. It sells 30 items
   for $96. How many pens and notebooks? (Fictional practice data.)
8. Plan A costs $20 plus $0.40 per minute; plan B costs $0.80 per
   minute with no base fee. At how many minutes do they cost the
   same, and what is that cost? (Fictional practice data.)
9. For `y < 2x − 3`: is the boundary solid or dashed? Give a test
   point and its result, and state which side is shaded.
10. Test `(2, 2)` and `(6, 2)` in the system `y ≥ x − 1`, `x + y ≤ 7`.
    Which are feasible?
11. Find the corner points of the system `x ≥ 0`, `y ≥ 0`,
    `x + y ≤ 8`, `2x + y ≤ 10`.
12. For the system in item 11, compute `P = 2x + 3y` at each corner and
    name the greatest-profit corner.

## Part B — extended tasks (6 points each, 24 points)

13. **Checking, completely.** Lee solves `2x + y = 10` and `y = x + 1`
    by substitution, getting `x = 3`, `y = 4`. Lee "checks" by plugging
    into `y = x + 1` only. Is Lee's answer correct? Is Lee's check
    complete? Explain which equation Lee still needs to check and why
    that check matters, even when the answer happens to be right.
14. **Modeling.** A food truck sells tacos for $4 and burritos for $7.
    One day it sells 120 items for $660. (a) Write the system, with
    variables defined. (b) Solve it. (c) Interpret the answer in a
    sentence. (d) If instead it sold 121 items for the same $660,
    show whether a whole-number solution exists. (Fictional practice
    data.)
15. **Feasible region.** For the system `x ≥ 0`, `y ≥ 0`,
    `x + 3y ≤ 12`, `2x + y ≤ 10`: (a) find all corner points;
    (b) test `(2, 2)` and `(5, 3)`; (c) compute `P = 3x + 2y` at each
    corner and name the greatest-profit corner. Note whether that
    corner is a whole-number combination, and what that would mean
    if `x` and `y` counted items.
16. **Write your own.** (a) Write a system of two equations whose
    solution is `(2, 5)`, and show that `(2, 5)` satisfies both.
    (b) Write a system of inequalities (including `x ≥ 0`, `y ≥ 0`
    if you wish) for which `(2, 5)` is feasible but `(2, 6)` is not,
    and show the checks that prove it.

**Total: 48 points.** 42–48: thorough; 34–41: solid with gaps to
revisit in Session 19; below 34: reteach the weakest objective with
the teacher guide before moving to Unit 04.
