## Lesson 01 — Two equations, one pair

- **Readiness:** `y = 2(3) + 1 = 7`; `y = −3 + 4 = 1`.
- **Guided:** 1. `(1, 4)`: `3(1) + 1 = 4` ✓; `1 + 4 = 5` ✓ — yes.
  2. `(2, 3)`: `2 + 1 = 3` ✓; `2(2) + 3 = 7 ≠ 8` — no.
  3. `x + 2 = −2x + 5` → `3x = 3` → `x = 1`, `y = 3`. Solution `(1, 3)`.
- **Independent:** 1. `(4, 1)`: `4 − 1 = 3` ✓; `2(4) + 1 = 9` ✓ — yes.
  2. `(0, 5)`: `2(0) + 5 = 5` ✓; `0 + 2(5) = 10 ≠ 11` — no.
  3. `4x − 3 = −x + 7` → `5x = 10` → `x = 2`, `y = 5`. 4. `3x = −x + 8`
  → `x = 2`, `y = 6`. 5. Sample: "The crossing point lies on both
  lines, and a point on a line satisfies that line's equation — so
  the crossing pair satisfies both equations at once."
- **Application:** (a) The bench is the only spot on both paths.
  (b) "The bench" is the ordered pair that satisfies both equations.
- **Exit:** `(5, 2)`: `5 + 2(2) = 9` ✓; `3(5) − 2 = 13` ✓ — yes.
- **Extension:** `(1/2)x + 3 = −(3/2)x − 1` → `2x = −4` → `x = −2`,
  `y = 2`.

## Lesson 02 — Substitution

- **Readiness:** `y = 3x − 5`.
- **Guided:** 1. `2x + (x + 4) = 13` → `x = 3`, `y = 7`.
  2. `x = y + 1`; `2(y + 1) + 3y = 12` → `y = 2`, `x = 3`.
  3. `x + 2x = 9` → `x = 3`, `y = 6`.
- **Independent:** 1. `x + (5x − 1) = 11` → `x = 2`, `y = 9`.
  2. `x = 10 − y`; `2(10 − y) − y = 5` → `y = 5`, `x = 5`.
  3. `3x + (2x − 1) = 14` → `x = 3`, `y = 5`.
  4. `x = 2y − 3`; `2(2y − 3) + y = 4` → `y = 2`, `x = 1`.
  5. Sam's error: Sam added `(x + 2)` instead of subtracting it —
  `3x − y = 4` with `y = x + 2` gives `3x − (x + 2) = 4`, not
  `3x + (x + 2) = 4`. Correct: `2x − 2 = 4` → `x = 3`, `y = 5`.
  Check: `5 = 3 + 2` ✓; `3(3) − 5 = 4` ✓.
- **Application:** `l = 2w + 3`, `2(l + w) = 36` → `l + w = 18` →
  `3w + 3 = 18` → `w = 5` cm, `l = 13` cm.
- **Exit:** `2x + (−x + 9) = 14` → `x = 5`, `y = 4`. Check:
  `4 = −5 + 9` ✓; `2(5) + 4 = 14` ✓.
- **Extension:** substituting for `x`: `x = y + 1` →
  `2(y + 1) + 3y = 7` → `y = 1`, `x = 2`; substituting for `y`:
  `y = x − 1` → `2x + 3(x − 1) = 7` → `x = 2`, `y = 1`. Either way,
  `(2, 1)`; isolating `x` in the second equation avoids fractions.

## Lesson 03 — Elimination and equivalent systems

- **Readiness:** `2x = 12`.
- **Guided:** 1. Add: `4x = 12` → `x = 3`, `y = 2`.
  2. Add: `4x = 12` → `x = 3`, `y = 5/2`. Check: `3 + 5 = 8` ✓;
  `9 − 5 = 4` ✓. 3. Divide the second equation by 2: `x + y = 4` —
  the same line as `y = −x + 4`: infinitely many solutions.
  4. One expression cannot equal both 3 and 7: no solution.
- **Independent:** 1. Add: `3x = 9` → `x = 3`, `y = 1`.
  2. Add: `6x = 12` → `x = 2`, `y = 1`.
  3. Add: `4x = 8` → `x = 2`, `y = 2`.
  4. Add: `8x = 20` → `x = 5/2`, `y = 7/4`. Check:
  `5(5/2) − 2(7/4) = 25/2 − 7/2 = 9` ✓; `3(5/2) + 2(7/4) = 15/2 + 7/2
  = 11` ✓. 5. The second equation is twice the first: infinitely
  many solutions, all pairs `(x, 2 − x/3)` — equivalently, all pairs
  satisfying `x + 3y = 6`. 6. Substituting: `3x − (3x − 2) = 2 ≠ 5`:
  no solution.
- **Application:** `x + y = 27`, `x − y = 5` → add: `2x = 32` →
  `x = 16`, `y = 11`.
- **Exit:** Add: `6x = 24` → `x = 4`, `y = 9/5`. Check: `2(4) + 5(9/5)
  = 8 + 9 = 17` ✓; `4(4) − 5(9/5) = 16 − 9 = 7` ✓. Justification
  sample: "The added equation `6x = 24` came from adding the two
  originals, and the first original can be recovered from it, so the
  new system has exactly the same solutions."
- **Extension:** multiplying by 0 turns an equation into `0 = 0`,
  which every pair satisfies — information is destroyed, so the
  system is not equivalent. Elimination multiplies only by nonzero
  constants.

## Lesson 05 — Inequalities in two variables

- **Readiness:** `(0, 0)` is above the line `y = 2x − 1`.
- **Guided:** 1. `y < x + 3`: dashed boundary; test `(0, 0)`:
  `0 < 3` true — shade the origin side. 2. `x − y ≥ 2`: solid
  boundary; test `(0, 0)`: `0 ≥ 2` false — shade the opposite side
  (the side containing `(3, 0)`, which passes: `3 ≥ 2` ✓).
  3. `(2, 4)`: `6 + 4 = 10 > 9` ✓ — yes. `(1, 2)`: `3 + 2 = 5 > 9`
  ✗ — no.
- **Independent:** 1. `y ≥ −x + 2`: solid boundary; test `(0, 0)`:
  `0 ≥ 2` false — shade the side away from the origin.
  2. `x + 2y < 6`: dashed boundary; test `(0, 0)`: `0 < 6` true —
  shade the origin side. 3. `(4, 1)`: `1 ≤ 2(4) − 5 = 3` ✓ — yes.
  `(2, 0)`: `0 ≤ −1` ✗ — no. 4. `y < x − 2` (dashed line, region
  below it, line excluded). 5. Sample: "A boundary point makes both
  sides equal, so substituting it gives a true equality statement
  for the boundary equation no matter which side is shaded — it
  cannot distinguish the sides."
- **Application:** `4n + 2p ≤ 20` (solid boundary). Sample affordable
  combinations: `(5, 0)` spends exactly $20; `(0, 10)` spends exactly
  $20; `(2, 5)` spends $18.
- **Exit:** `y > −2x + 3`: dashed boundary; test `(0, 0)`:
  `0 > 3` false — shade the side away from the origin. In the region:
  `(0, 4)` (`4 > 3` ✓). Outside: `(0, 0)`.
- **Extension:** `y ≥ 2` shades everything at or above the horizontal
  line `y = 2`; `x < −1` shades everything left of the dashed vertical
  line `x = −1`; both together give the upper-left quadrant region
  above `y = 2` and left of `x = −1`.

## Lesson 06 — Systems of inequalities, feasible regions

- **Readiness:** `(2, 3)`: `2 + 3 = 5 ≤ 10` ✓; `2(2) + 3 = 7 ≤ 14` ✓.
- **Guided:** 1. `(3, 2)`: `5 ≤ 8` ✓; `2 ≥ 2(3) − 4 = 2` ✓;
  nonnegative ✓ — feasible. 2. `(5, 5)`: `10 ≤ 8` ✗ — not feasible.
  3. Corners: `(0, 0)`; `(6, 0)` (where `x + y = 6` meets `y = 0`);
  `(2, 4)` (where `x + y = 6` meets `y = 2x`, since `x + 2x = 6`).
- **Independent:** 1. `(0, 2)`: `2 > −1` ✓; `2 ≤ 5` ✓ — feasible.
  `(4, 0)`: `0 > 3` ✗ — not feasible.
  2. (a) Corners: `(0, 0)`; `(5, 0)`; `(4, 2)` (intersection of
  `2x + y = 10` and `x + 2y = 8`: doubling the second gives
  `2x + 4y = 16`, subtracting the first gives `3y = 6`, `y = 2`,
  `x = 4`); `(0, 4)`. (b) `(3, 1)`: `7 ≤ 10` ✓, `5 ≤ 8` ✓ —
  feasible. `(4, 4)`: `12 ≤ 10` ✗ — not feasible.
  3. `P = 4x + 3y`: `(0, 0) → 0`; `(5, 0) → 20`; `(4, 2) → 22`;
  `(0, 4) → 12`. Greatest-profit corner: `(4, 2)`, $22.
  4. Sample: "A point can pass every inequality yet still be
  impossible in context — for example, 2.5 buses cannot be rented,
  so a solution with a fractional bus count is feasible but not
  viable."
- **Application:** system: `2m + 3c ≤ 12`, `m ≥ 0`, `c ≥ 0`. Sample
  feasible combinations: `(6, 0)`, `(3, 2)`, `(0, 4)`, `(4, 1)`

- **Exit:** `(2, 5)`: `7 ≤ 10` ✓; `9 ≤ 14` ✓ — feasible. `(6, 3)`:
  `9 ≤ 10` ✓; `15 ≤ 14` ✗ — not feasible.
- **Extension:** `(0, 10)` disappears (it fails `y ≤ 2x`); new
  corners: `(0, 0)`, `(7, 0)`, `(4, 6)`, `(10/3, 20/3)` — the last is
  where `y = 2x` meets `x + y = 10` (`x + 2x = 10`).

## Project — The School Fair Stall

1. **System:** let `x` = number of snack bags, `y` = number of drink
   cups. Prep: `5x + 2y ≤ 120` ("prep minutes used cannot exceed
   120"). Cooler: `x + 2y ≤ 70` ("cooler units used cannot exceed
   70"). Nonnegativity: `x ≥ 0`, `y ≥ 0`.
2. **Graph and corners:** `(0, 0)`; `(24, 0)` (prep boundary meets
   `y = 0`); `(0, 35)` (cooler boundary meets `x = 0`); `(12.5, 28.75)`
   (slanted boundaries meet: `5x + 2y = 120` and `x + 2y = 70`
   subtract to `4x = 50`, so `x = 12.5`, `y = 28.75`).
3. **Sample combo table** (profit `P = 3x + 2y`): `(24, 0) → $72`
   (prep 120, cooler 24); `(0, 35) → $70` (prep 70, cooler 70);
   `(12, 29) → $94` (prep 118, cooler 70); `(12, 28) → $92` (prep 116,
   cooler 68); `(20, 10) → $80` (prep 120, cooler 40); `(0, 0) → $0`.
   Non-feasible sample: `(13, 28)` — prep `65 + 56 = 121 > 120`,
   fails the prep constraint (cooler `13 + 56 = 69 ≤ 70` passes).
4. **Recommendation:** 12 snack bags and 29 drink cups, profit $94.
   Why nothing beats it: from the cooler constraint,
   `P = 3x + 2y ≤ 70 + 2x`, and from prep, `P ≤ 120 − 2x`. Reaching
   $95 would require `70 + 2x ≥ 95` (so `x ≥ 13`, whole) and
   `120 − 2x ≥ 95` (so `x ≤ 12`) — impossible. Checking the corners
   and the whole-number neighbors of `(12.5, 28.75)` — `(12, 29)`
   works at $94, `(13, 28)` fails prep, `(12, 28)` gives $92,
   `(11, 29)` gives $91 — confirms $94 is the best sellable total.
5. **"What if" (prep 150 minutes):** the slanted corner becomes
   `x = 20`, `y = 25` (`5x + 2y = 150` and `x + 2y = 70` subtract to
   `4x = 80`), profit `3(20) + 2(25) = $110` — so the recommendation
   *would* change, to 20 snack bags and 25 drink cups.
