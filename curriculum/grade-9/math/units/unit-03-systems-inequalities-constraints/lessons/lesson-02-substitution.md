# Lesson 02 — Substitution: Solve One, Plug Into the Other

**Goal:** I can solve a system by substitution and verify the answer in
both original equations.
**Time:** 50 minutes · **Materials:** notebook, calculator (check only).

## Readiness check (5 min)

Solve `3x − y = 5` for `y`. If you got `y = 3x − 5`, you are ready:
substitution starts exactly there — by isolating one variable so its
expression can stand in for it in the other equation.

## Teaching: substitution turns two equations into one (15 min)

**Substitution** means: solve one equation for one variable, then
replace that variable in the *other* equation with the expression you
found. The other equation then has only one variable left, so you can
solve it the way you solved one-variable equations in Unit 01. Then go
back to either original equation to find the second value.

Choose the easiest isolation: a variable with coefficient `1` or `−1`,
or an equation already solved for a variable (like `y = 3x − 2`).
Isolating a variable that forces fractions at the first step is legal
but slow — pick the other variable or the other equation instead.

The final step is not optional: substitute the pair into **both**
original equations. A sign slip while substituting is easy to make and
easy to catch this way.

### Worked example 1 — one equation already solved for y

> Solve `y = 3x − 2` and `2x + y = 13` by substitution.

1. The first equation already says what `y` equals, so substitute
   `3x − 2` for `y` in the second equation:
   `2x + (3x − 2) = 13`.
2. Combine: `5x − 2 = 13`, so `5x = 15` and `x = 3`.
3. Find `y` from the first equation: `y = 3(3) − 2 = 7`.
4. Check both originals: `7 = 3(3) − 2` ✓; `2(3) + 7 = 13` ✓.
   The solution is `(3, 7)`.

### Worked example 2 — isolate first, then substitute

> Solve `x + 2y = 11` and `3x − y = 5` by substitution.

1. Isolate `y` in the second equation: `3x − y = 5` gives
   `−y = 5 − 3x`, so `y = 3x − 5`. (Watch the sign: subtracting `3x`
   from both sides, then multiplying by `−1`, flips both terms.)
2. Substitute into the first equation:
   `x + 2(3x − 5) = 11`, so `x + 6x − 10 = 11`, `7x = 21`, `x = 3`.
3. Find `y`: `y = 3(3) − 5 = 4`.
4. Check both originals: `3 + 2(4) = 11` ✓; `3(3) − 4 = 5` ✓.
   The solution is `(3, 4)`.

## Guided practice (10 min, with hints)

1. Solve `y = x + 4` and `2x + y = 13` by substitution.
   *Hint: the first equation is already solved for `y`.*
2. Solve `x − y = 1` and `2x + 3y = 12` by substitution.
   *Hint: solve the first equation for `x` — it has coefficient 1.*
3. Solve `y = 2x` and `x + y = 9` by substitution.
   *Hint: replacing `y` with `2x` leaves one equation in `x` alone.*

## Independent practice (10 min)

1. Solve `y = 5x − 1` and `x + y = 11` by substitution.
2. Solve `x + y = 10` and `2x − y = 5` by substitution. (Start by
   solving the first equation for `x`.)
3. Solve `3x + y = 14` and `y = 2x − 1` by substitution.
4. Solve `x − 2y = −3` and `2x + y = 4` by substitution.
5. **Error analysis.** Sam solves `y = x + 2` and `3x − y = 4` like
   this: "Substitute: `3x + (x + 2) = 4`, so `4x = 2`, `x = 1/2`,
   `y = 5/2`." Find Sam's error, explain it in one sentence, and give
   the correct solution. (Check your answer in both equations.)

## Application (5 min)

A rectangle's length is 3 cm more than twice its width, and its
perimeter is 36 cm. Let `w` be the width and `l` the length. Write the
system, solve it by substitution, and give the rectangle's dimensions
with units.

## Exit check (5 min)

Solve `y = −x + 9` and `2x + y = 14` by substitution. Show the check
in both original equations.

## Supports, extension, teacher note

- **Reading/language access:** keep a two-column board layout — left
  column "what I substituted," right column "the equation it went
  into" — so the substitution step stays visible.
- **Alternate response mode:** a learner may dictate each substitution
  step ("replace `y` with `3x − 5`") while the adult or a partner
  writes it, then check the arithmetic themselves.
- **Extension:** solve `2x + 3y = 7` and `x − y = 1` two ways — by
  substituting for `x` and by substituting for `y` — and say which
  isolation you would choose next time and why.
- **Teacher note — misconception:** the classic slip is substituting
  into the *same* equation the expression came from, which collapses
  to an identity (`3x − 5 = 3x − 5`) and goes nowhere. When a learner
  gets an identity, ask: "which equation did that expression go into?"
