# Practice — Unit 03: Systems, Inequalities, and Constraints

Work each section in its pacing session. Check every claimed solution
in **both** original equations (or in every inequality of the system).
Solutions are in `answer-key.md`. All contexts use fictional practice
data.

## Practice A — testing pairs, graphing systems (Session 2)

1. Is `(3, 2)` a solution of `x + y = 5` and `2x − y = 4`?
2. Is `(1, 6)` a solution of `y = 2x + 4` and `x + y = 7`?
3. Is `(−1, 3)` a solution of `y = −2x + 1` and `x − y = −4`?
4. Find the solution of `y = x − 1` and `y = −3x + 7` by setting the
   expressions equal.
5. Find the solution of `y = 2x + 5` and `y = x + 8` by setting the
   expressions equal.
6. A system has lines `y = 4x − 2` and `y = −x + 3`. Without solving,
   explain in one sentence how you know the lines are not parallel.
7. Write one ordered pair that satisfies `x + y = 9` but is *not* a
   solution of the system `x + y = 9`, `x − y = 1`. Explain why it
   fails the system.
8. True or false, with a reason: "If a pair satisfies one equation of
   a system, it is a solution of the system."

## Practice B — substitution (Session 4)

Solve each system by substitution. Show the substitution step and both
checks.

1. `y = 2x − 3` and `3x + y = 17`
2. `x = y + 2` and `2x − 3y = 4`
3. `2x + y = 9` and `y = 3x − 1`
4. `x − 2y = −1` and `3x + y = 11`
5. `y = −2x + 6` and `4x + y = 14`
6. **Error analysis.** Jo solves `y = 2x + 1` and `x + y = 10` by
   writing `x + (2x + 1) = 10`, getting `x = 3`, `y = 7`, then checks
   only the first equation. Is Jo's answer correct? Check it in both
   equations and say what Jo should have done differently, if anything.

## Practice C — elimination and classification (Session 6)

Solve items 1–4 by elimination. Classify items 5–8, with a reason.

1. `x + y = 12` and `x − y = 4`
2. `3x + 2y = 16` and `x − 2y = 0`
3. `2x + 3y = 7` and `3x − y = 5`
4. `5x − y = 13` and `2x + y = 8`
5. `y = 2x + 5` and `2x − y = −5`
6. `3x + y = 9` and `6x + 2y = 18`
7. `y = −4x + 1` and `4x + y = 6`
8. `x − 2y = 3` and `2x − 4y = 5`

## Practice D — modeling (Session 9)

Define variables with units, write the system, solve, and interpret.

1. A concert sells adult tickets for $15 and student tickets for $9.
   It sells 400 tickets for $4,800. How many of each?
2. Plan M costs $18 plus $0.25 per gigabyte; plan N costs $0.55 per
   gigabyte with no base fee. At how many gigabytes do they cost the
   same, and what is that cost? Which plan is cheaper at 100 GB?
3. A chemist mixes a 5% acid solution with a 20% acid solution to
   make 30 liters of a 14% solution. How many liters of each?
4. Two numbers sum to 84 and differ by 18. Find both numbers.
5. A rectangle's length is 3 cm more than twice its width, and
   its perimeter is 30 cm. Find its dimensions.

## Practice E — half-planes (Session 12)

For items 1–3, graph the inequality, stating the boundary style and
the test point used. For items 4–6, answer without graphing.

1. `y ≤ 3x − 2`
2. `x − 2y > 4`
3. `2x + y ≥ 6`
4. Is `(3, 0)` a solution of `y < 2x − 4`? Is `(1, 0)`?
5. Is `(0, 0)` a solution of `3x − y ≤ 5`? Is `(3, 0)`?
6. A shaded region lies strictly above a dashed line with equation
   `y = −x + 4`. Write the inequality it represents.

## Practice F — feasible regions (Session 14)

1. Test `(1, 4)` and `(5, 2)` in the system `x ≥ 0`, `y ≥ 0`,
   `x + 2y ≤ 12`, `3x + y ≤ 15`. Which are feasible?
2. Find the corner points of the system `x ≥ 0`, `y ≥ 0`,
   `x + y ≤ 9`, `x + 2y ≤ 12`.
3. For the system in item 2, compute the profit `P = 5x + 2y` at each
   corner and name the greatest-profit corner.
4. A point satisfies every inequality of a system, but one of its
   coordinates is `4.5` and the context counts whole buses. Is the
   point viable? Explain in one sentence.
5. Write a system of inequalities (with `x ≥ 0`, `y ≥ 0`) whose
   feasible region has corners `(0, 0)`, `(6, 0)`, and `(0, 4)`.
   (Hint: one slanted boundary through `(6, 0)` and `(0, 4)`.)
6. Project work: finish the graph and combo table for
   `project.md` — bring a draft to Session 15.
