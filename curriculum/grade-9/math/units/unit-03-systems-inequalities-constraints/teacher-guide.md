# Teacher Guide — Unit 03: Systems, Inequalities, and Constraints

For the guiding adult. Student pages never contain answers; this guide
and `answer-key.md` stay separate from them.

## How to run the unit

- **Session rhythm:** each lesson (Sessions 1, 3, 5, 8, 11, 13) is
  followed by a practice session before the next lesson, so errors
  surface while the method is fresh. Do not skip Practice C's
  classification items — classification is where this unit's
  understanding shows, and it is the most common assessment gap.
- **The two non-negotiables:** (1) every claimed solution is checked
  in *both* original equations (or every inequality); (2) every
  shaded half-plane is justified by a test point, never by "greater
  means up." Enforce both from Lesson 01 onward; by Session 13 they
  should be automatic.
- **Graphing standard:** axes labeled with variable names and scales,
  boundary lines drawn with a ruler, solid vs. dashed visible. A
  graph without labels earns no credit yet, even if the region is
  right — labels are part of the mathematics here (A-CED.2).

## Misconceptions and reteach moves

| Where it shows | What the learner does | Reteach move |
|---|---|---|
| Lesson 01, Practice A | Checks only one equation and declares a solution | Return to Worked example 2: a pair that passes one equation and fails the other. Require a two-column check table until the habit sticks. |
| Lesson 02 | Substitutes into the same equation the expression came from, gets an identity, and stalls | Ask: "which equation did that expression go into?" Re-do the lesson's Worked example 2 with the two equations in different colors. |
| Lesson 02 | Drops the minus when substituting `(x + 2)` into `3x − y = 4` | Rewrite as `3x − (x + 2) = 4` with the parentheses kept, then distribute: `3x − x − 2 = 4`. Practice B's error analysis exists for this. |
| Lesson 03 | Multiplies only part of an equation before adding | Rule: "every term, both sides." Have the learner rewrite the full multiplied equation on its own line before adding. |
| Lesson 03 | Guesses classification from how the equations "look" | Require the test: same slope + different intercept → none; one equation a multiple of the other → infinite; otherwise solve. |
| Lesson 04 | Writes only the money equation, misses the count equation | Ask: "what is the second fact the problem gave you?" Then require the "let" sentence with units before any equation. |
| Lesson 04 | Leaves a bare pair as the answer | Require the interpretation sentence ("106 adult tickets and 94 child tickets") and a viability check (whole? nonnegative?). |
| Lesson 05 | Shades by direction ("greater means above") | Ban the shortcut for one session: every shading needs a written test point and result. Revisit with an inequality not solved for `y`, like `x − 2y > 4`. |
| Lesson 05 | Uses a boundary point as the test point | Show it: a boundary point gives a true equality statement for any inequality, so it decides nothing. Pick `(0, 0)` whenever it is off the line. |
| Lesson 06 | Graphs each inequality separately, never intersects | Require one axes, all shadings, and a darkened overlap before any point is tested. |
| Lesson 06, project | Confuses feasible with viable | Keep the two words posted side by side: feasible = passes every constraint; viable = feasible *and* possible in the situation (whole items, real limits). The project's fractional corner `(12.5, 28.75)` is the teaching example. |

## Readiness signals and next steps

- **Ready for Unit 04** (exponents, polynomials): the learner solves
  systems by two methods, classifies correctly, graphs a feasible
  region with labeled corners, and interprets a model answer in
  context — assessment 42+/48 or a corrected Session 19 with no
  repeated error type.
- **Reteach elimination** (Session 17 focus) if Practice C items 1–4
  or quiz item 3 are wrong: re-do Lesson 03's worked examples with
  the learner narrating each step, then re-test with two fresh
  systems.
- **Reteach half-planes** if Practice E or quiz item 7 are wrong:
  re-do Lesson 05 with the boundary-style chart posted and a test
  point written for every item.
- **Reteach modeling** if Practice D or quiz item 6 are wrong:
  return to the four-step modeling routine (define, write two facts,
  solve, interpret) and re-do one ticket problem and one break-even
  problem from scratch.

## Scoring guidance

- **Formative quiz (Session 16):** 1 point per item; items 6 and 8
  earn the point only with both checks shown. Use the result to
  choose the Session 17 reteach focus, not as a grade.
- **Culminating assessment (Session 18):** Part A 2 points each
  (1 for the correct value, 1 for the check/reason shown); Part B 6
  points each (2 for setup, 2 for correct computation, 2 for
  interpretation/justification). Accept any correct method in
  Part A items 2–4.
- **Project (Sessions 10, 14, 15):** use the rubric in `project.md`
  (5 criteria × 4 points = 20). Project notes: the slanted boundaries
  are `5x + 2y = 120` (prep) and `x + 2y = 70` (cooler); they meet at
  `(12.5, 28.75)` — a corner of the region, but not a sellable
  combination, which is exactly the viable-vs-feasible distinction
  this project teaches. If prep time rose to 150 minutes, the slanted
  corner becomes `(20, 25)` with profit $110, so the recommendation
  would change. The key's proof that no whole-number combination
  beats $94 is the model for Deliverable 4's
  justification: from the two constraints, `P = 3x + 2y` satisfies
  `P ≤ 70 + 2x` (cooler) and `P ≤ 120 − 2x` (prep); reaching $95
  would need `x ≥ 13` from the first and `x ≤ 12` from the second —
  impossible. A learner argument that checks the corners and the
  nearest whole-number neighbors earns full marks even without this
  proof.
- **Session 19 corrections:** every missed assessment item is
  re-solved with a written reason for the original error ("I checked
  only one equation," "I shaded by direction"). A correction that
  only copies the key earns no credit.
