# Formative Quiz — Unit 02 (Session 15)

**Grade 9 Math · Unit 02: Linear Functions** · ~25 minutes · Calculator
allowed for checking only. This quiz diagnoses gaps before the review session;
it is not the unit grade.

**Objective key:** O1 = function concept & notation · O2 = domain & range ·
O3 = graphs & representations · O4 = average rate of change · O5 = building
models · O6 = interpreting models

---

1. (O1) Is `{(3, 1), (4, 2), (3, 5)}` a function? Explain in one sentence,
   using the one-output rule. (3 pts)

2. (O1) For `f(x) = 2x − 9`, find `f(5)` and `f(−1)`. (3 pts)

3. (O2) A driver covers `D(t) = 40t` miles, `t` hours after leaving, for
   `0 ≤ t ≤ 3`. Give the domain and range with units, and explain in a
   sentence what the domain `0 ≤ t ≤ 3` means in the story. (4 pts)

4. (O3) Graph `y = x − 2` by hand on labeled axes. State the x- and
   y-intercepts. (5 pts)

5. (O4) A table gives `x`: 0, 2, 5 and `y`: 7, 15, 27. Find the average rate
   of change over `[0, 5]` and over `[2, 5]`. The two rates are equal — what
   does that suggest about the function? (4 pts)

6. (O5) A line passes through `(2, 31)` and `(6, 83)`. Build the linear
   function `y = mx + b`. (4 pts)

7. (O6) A tutor charges `C(h) = 25h + 60` dollars for `h` hours. Interpret
   the slope and the intercept in context, with units. (4 pts)

8. (O6) **Explain your reasoning.** A table gives `x`: 0, 1, 2, 3 and `y`:
   2, 4, 8, 16. Is this a linear function? Justify with differences over
   equal intervals. (3 pts)

**Total: 30 pts.** Scoring guide: 26+ = on track; 20–25 = review flagged
objectives in Session 17; below 20 = targeted reteach before the unit
assessment. Solutions: [answer-key.md](../answer-key.md#formative-quiz).
