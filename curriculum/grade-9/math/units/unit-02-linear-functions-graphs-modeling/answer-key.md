## Lesson 01 {#lesson-01}

**Readiness:** `C = 12 + 2.5(4) = 12 + 10 = 22` → $22. No — the same rule
gives the same output for the same input; that sameness is the function
idea.

**Guided:** 1. Function — inputs −3, 0, 3 have no repeats. 2. Not a function
— input −3 has two outputs, 4 and 9. 3. Function — each day has exactly one
letter count. Monday → 6, Wednesday → 9. 4. Dez broke the one-output rule:
`f(2)` can equal only one value. Fix: `f(2) = 5` (one value); what is
allowed is different outputs for different inputs, e.g. `f(2) = 5` and
`f(3) = 7`.

**Independent:** 5. (a) Function; domain {1, 2, 3}; range {2, 4, 6}.
(b) Not a function (1 → 2 and 1 → 3); domain {1, 2}; range {2, 3, 4}.
(c) Not a function (5 → 0, 1, and 2); domain {5}; range {0, 1, 2}.
6. Function — each title has exactly one page count. Two titles may share a
page count (allowed); one title cannot have two page counts.
7. Sample: `{(1, chips), (2, chips), (3, crackers), (4, crackers), (5, nuts),
(6, nuts)}` — every input appears once: a function. Broken: replace
`(2, chips)` with both `(2, chips)` and `(2, crackers)` — input 2 now has
two outputs, so it is not a function.
8. Sample: function `{(2, 10), (4, 20), (6, 30), (8, 40)}`; non-function
`{(2, 10), (2, 15), (4, 20), (6, 25)}` — input 2 has two outputs.

**Application:** (a) is a function — each student ID has exactly one absence
count. (b) is not — many students can share the count 3, so one input has
many outputs.

**Exit:** Check that every button press yields exactly one item. If any
button can give two different items (or no reliable item), the rule is not a
function.

## Lesson 02 {#lesson-02}

**Readiness:** (a) "chips"; (b) {1, 2, 5}.

**Guided:** 1. `g(5) = 3(5) − 8 = 7`; `g(0) = −8`; `g(−2) = −6 − 8 = −14`.
2. `G(6) = 40 + 150 = 190` — "6 months cost $190." `40 + 25m = 340` →
`25m = 300` → `m = 12`. 3. `t = 15` is outside `0 ≤ t ≤ 12` — not in the
domain. `V = 1500` is inside `0 ≤ V ≤ 3000` — in the range (at `t = 6`).
4. The formula accepts any `t`, but the model describes a 12-second fill.
`t = 15` would mean the bottle keeps filling after it is full — the story,
not the formula, sets the domain.

**Independent:** 5. `f(4) = −8 + 7 = −1`; `f(−3) = 6 + 7 = 13`;
`−2x + 7 = 1` → `−2x = −6` → `x = 3`.
6. `C(10) = 5 + 30 = 35` — "10 hours cost $35." Domain: whole hours,
`0 ≤ h ≤ 24`; range: `C(0) = 5` to `C(24) = 77`, so `5 ≤ C ≤ 77` dollars.
`h = 10.5` is excluded because the garage charges whole hours.
7. Domain `−2 ≤ x ≤ 4`; range `1 ≤ y ≤ 13`. (The line is `y = 2x + 5`:
`2(−2) + 5 = 1` ✓, `2(4) + 5 = 13` ✓.)
8. `f(1) = 2(1) + 5 = 7`. Output 9: `2x + 5 = 9` → `x = 2`. Sentences:
"At input 1 the output is 7"; "the input that gives output 9 is 2."

**Application:** (a) `M(0) = 30`: no texts still costs the $30 base fee.
`M(200) = 50`: 200 texts cost $50. (b) `d` a whole number, `d ≥ 0` —
fractional texts do not exist. (c) `30 + 0.10d = 62` → `0.10d = 32` →
`d = 320` texts.

**Exit:** (a) `h(6) = 30 − 2 = 28`. (b) "6 concert tickets cost $28."

## Lesson 03 {#lesson-03}

**Readiness:** (−1, 2) is 1 left, 2 up; (3, −4) is 3 right, 4 down.

**Guided:** 1. Table: (0, 4), (2, 2), (4, 0); intercepts (0, 4) and (4, 0).
2. `2(−0.5) + 1 = −1 + 1 = 0` ✓ — the point satisfies the equation with
`y = 0`, so it is the x-intercept. 3. `m = (0 − 4)/(4 − 0) = −1` ✓.
4. Rin graphed `y = 2x`, forgetting the `+ 1`. An intercept check would show
the line passing through (0, 0) instead of the true y-intercept (0, 1).

**Independent:** 5. Points (0, −3), (2, −2), (6, 0); x-intercept (6, 0):
`(1/2)(6) − 3 = 0` ✓; y-intercept (0, −3) ✓.
6. Table: `h = 0 → 5`, `2 → 21`, `4 → 37`, `6 → 53`. Y-intercept (0, 5) is
the $5 fee; the x-intercept (−5/8, 0) lies outside the domain — negative
hours are meaningless. No arrows past `h = 6`: the domain ends there.
7. P: `y = 3x + 8` (check `x = 2`: 14 ✓). Q: `y = 3x + 14` (check `x = 3`:
23 ✓). Different functions — same slope, different intercepts.
8. `3x − 2 = −x + 6` → `4x = 8` → `x = 2`; `y = 3(2) − 2 = 4`. The
intersection (2, 4) means `x = 2` makes both sides equal (4) — it is the

**Application:** `T(6) = 2.5(6) + 3.5 = 18.50`. The point (6, 18.5): a

**Exit:** y-intercept (0, 5); x-intercept: `−2x + 5 = 0` → `x = 2.5`.

## Lesson 04 {#lesson-04}

**Readiness:** 60 mph.

**Guided:** 1. `(86 − 59)/(3 − 2) = 27` mph.
2. `V(12) = 200`, `V(4) = 400`; `(200 − 400)/8 = −25` gal/min.
3. `(14 − 2)/(5 − 1) = 12/4 = 3`.
4. Priya must use `[f(6) − f(2)]/(6 − 2)` — change in output over change in
input. `f(6) = 31`, `f(2) = 11`; `(31 − 11)/4 = 5`.

**Independent:** 5. (a) `W(15) = 300`, `W(0) = 900`;
`(300 − 900)/15 = −40` L/min. (b) The pond loses 40 liters per minute.
(c) `W(10) = 500`, `W(5) = 700`; `(500 − 700)/5 = −40` L/min — the same rate,
so the drain is linear.
6. Over [0, 6]: `(36 − 12)/6 = 4`; over [2, 4]: `(28 − 20)/2 = 4`. The

7. (a) `E(2) = 1900`, `E(0) = 1200`; `(1900 − 1200)/2 = 350` ft/hr.

8. Runner 1 covered `6 × 2 = 12` miles; runner 2 covered `9 × 2 = 18`

## Lesson 05 {#lesson-05}

**Readiness:** `(25 − 10)/(5 − 2) = 15/3 = 5`.

**Guided:** 1. `m = (24 − 9)/(4 − 1) = 5`. 2. `9 = 5(1) + b` → `b = 4`;

`m = (25 − 10)/(5 − 2) = 15/3 = 5`; `10 = 5(2) + b` → `b = 0`; `y = 5x`.

**Independent:** 5. `m = (22 − 6)/80 = 0.20` $/copy; `6 = 0.20(20) + b` →
`b = 2`; `C(n) = 0.20n + 2`, `n` whole, `n ≥ 0`. 60 copies: `C(60) = 12 + 2
= $14`. Verify: `C(20) = 6` ✓, `C(100) = 22` ✓.
6. `m = (65 − 25)/5 = 8`; `y = 8x + 25`. Story, e.g.: "A savings account
holds $25 and gains $8 per week."

(check `x = 6`: 29 ✓).
8. `W(n) = 12n + 5`; `n` = walks per week (whole, `n ≥ 0`); `W` = weekly

## Lesson 06 {#lesson-06}

**Readiness:** 10 means $10 per mug; 5 means the $5 setup fee.

**Guided:** 1. Slope: each additional hour adds $45. Intercept: 0 hours
still cost $30 (base charge). 2. `1.2 × 60 = 72` meters per minute —
meters per minute fits a 30-minute walk better. 3. Differences: 6, 6, 6 —
equal; x-steps are 2, so the per-unit rate is 3; linear (`y = 3x + 3`).
4. Two mistakes: (0, 200) is the starting value, not a rate of growth; the
cost does not grow $200/day — it starts at $200 and *decreases* $15 per day.

**Independent:** 5. Slope: each additional guest adds $45. Intercept: 0
guests still cost $300 (kitchen fee). `C(50) = 2250 + 300 = $2550`.
6. Differences: 100, 150, 200 — not equal, and growing. Not linear; the
growth is accelerating. (Equal differences would look like 2000, 2150,
2300, 2450.)
7. Ignores (any two): gas price changes, repairs/maintenance, tolls,
traffic delays. A 2000-mile week extrapolates far past the supported domain
`0 ≤ m ≤ 600`.
8. Plan A grows faster per text ($0.10 vs $0.05). Plan B costs more at zero
texts ($45 vs $30). For a very heavy texter, B is cheaper — A's steeper
slope eventually overtakes B's higher starting fee (break-even at 300
texts).

**Application:** (a) G's intercept $40 is the signup fee; H's intercept $0
means no signup fee. (b) `G(12) = 180 + 40 = $220`; `H(12) = $300`.
(c) H charges $25/month vs G's $15 — the steeper monthly climb eats G's
$40 head start.

**Exit:** Slope: the bin loses 8 pounds of feed per day. Intercept: 120
pounds of feed at delivery (`t = 0`).

## Project — The Fare Audit (sample solution for the rubric) {#project}

1. Input `m` = miles driven (real, `m ≥ 0` — negative miles are
meaningless); output = fare in dollars. `Z(m) = 1.8m + 4.5`,
`G(m) = 1.1m + 9`.
2. ZipGo: each mile adds $1.80; the $4.50 base fare applies at 0 miles.
GlideRide: each mile adds $1.10; the $9.00 base fare applies at 0 miles.
ZipGo's fare grows faster per mile; GlideRide charges more before any miles.
3. ZipGo: `m = 0 → 4.50`, `5 → 13.50`, `10 → 22.50`, `15 → 31.50`,
`20 → 40.50`. GlideRide: `0 → 9.00`, `5 → 14.50`, `10 → 20.00`,
`15 → 25.50`, `20 → 31.00`. Both lines on labeled "miles"/"dollars" axes;
ZipGo starts lower and climbs steeper, crossing GlideRide near 6.4 miles.
4. `1.8m + 4.5 = 1.1m + 9` → `0.7m = 4.5` → `m = 45/7 ≈ 6.43` miles.
Below 6.43 (test `m = 5`: Z = $13.50, G = $14.50) ZipGo is cheaper; above
(test `m = 10`: Z = $22.50, G = $20.00) GlideRide is cheaper. The
intersection is the point where both fares are equal — its x-coordinate
solves `Z(m) = G(m)`.
5. ZipGo: `(40.50 − 4.50)/20 = 1.8` $/mi. GlideRide: `(31 − 9)/20 = 1.1`
$/mi. The rates differ because the per-mile prices differ. A 40-mile run:
Z = $76.50, G = $53.00 — GlideRide by a wide margin.
6. Sample memo: GlideRide for the daily 15-mile ride — $25.50 vs $31.50 per
trip from the table, and the 15-mile distance sits well past the 6.43-mile
break-even. Limitations: wait times, tips, surge pricing, traffic, and
vehicle type are not in the rate card; for very short trips (under ~6.4
miles) ZipGo wins instead.
7. Extension: `1.8m + 4.5 = 40` → `1.8m = 35.5` → `m ≈ 19.72` miles; check
`1.8(19.72) + 4.5 ≈ 40.00` ✓. An estimate only — real fares add tips,
surge, and rounding the model ignores.
