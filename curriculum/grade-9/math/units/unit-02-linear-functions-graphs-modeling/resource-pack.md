# Resource Pack — Unit 02: Linear Functions

**Goal (one sentence):** Give a grade-9 learner free, no-account routes to
see the function concept, function notation, graphing, rate of change, and
linear modeling explained a second way, with practice beyond this unit's
pages.
**Age fit:** 14–15; assumes the grade-8 prerequisite fluency and the Unit 01
solving skills listed in the unit README.

## Focused queries

1. `what is a function exactly one output per input explained`
2. `function notation f of x evaluate interpret in context`
3. `domain and range from graph linear function`
4. `graph linear equation slope intercept by hand steps`
5. `average rate of change from table formula graph`
6. `write linear equation from two points word problem`

## Web references (verified 2026-10-19 via direct page check; free, no account)

1. **OpenStax — College Algebra with Corequisite Support, §3.1 "Functions
   and Function Notation."** Relations vs. functions, the one-output rule,
   reading `f(x)`, evaluating from equations/tables/graphs, the vertical
   line test — with worked examples and "Try It" practice. Directly supports
   Lessons 1–2.
   <https://openstax.org/books/college-algebra-corequisite-support/pages/3-1-functions-and-function-notation>
2. **OpenStax — College Algebra with Corequisite Support, Chapter 3 Key
   Concepts.** One-page summary of §3.1–3.3: function notation, domain and
   range (including from graphs), and average rate of change — good
   retrieval-review sheet for Session 14.
   <https://openstax.org/books/college-algebra-corequisite-support/pages/3-key-concepts>
3. **OpenStax — Elementary Algebra 2e, §4.4 "Understand Slope of a Line."**
   Rise over run from graphs, the slope formula between two points,
   horizontal/vertical lines, graphing from a point and a slope — the
   strategies taught in Lessons 3–4.
   <https://openstax.org/books/elementary-algebra-2e/pages/4-4-understand-slope-of-a-line>
4. **OpenStax — Elementary Algebra, Chapter 4 Key Concepts.** One-page
   summary: plotting points, graphing with intercepts, slope, slope-intercept
   form, and — in §4.6 — finding an equation of a line from a point, from
   two points, and from slope-intercept form. Supports Lessons 3 and 5 and
   Session 14 review.
   <https://openstax.org/books/elementary-algebra/pages/4-key-concepts>
