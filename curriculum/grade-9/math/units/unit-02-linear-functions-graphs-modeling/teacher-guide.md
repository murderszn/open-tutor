## Misconceptions to hunt (with reteaching moves)

1. **Shared outputs rejected.** Learners call `{(1, 2), (2, 2)}` "not a
   function" because the outputs repeat. *Move:* the vending machine —
   buttons 1 and 2 both vending chips is fine; the rule breaks only when one
   button gives two different snacks. Return to Lesson 1, Worked example 1.
2. **`f(x)` read as multiplication.** "f times x," then attempts to "solve
   for f." *Move:* drill the read-aloud "f of x" at the start of every
   session through Session 10; the parentheses mark an input.
3. **Domain from the formula, not the story.** "You can substitute any t, so
   the domain is all real numbers." *Move:* Lesson 2's water-bottle example —
   ask what `V(−5)` would mean physically. The story constrains the math.
4. **Unlabeled axes and made-up scales.** Graphs that are correct
   point-wise but unreadable. *Move:* no graph earns credit without both
   axis labels (quantity + unit) and a stated scale; spot-check Session 4
   graphs against the SVG's conventions.
5. **Reversed subtraction in rates.** Earlier-minus-later, then a
   hand-waved sign. *Move:* require "later minus earlier" written in the
   formula before numbers go in; the sign carries increase/decrease meaning.
6. **Slope computed, intercept forgotten.** Models like `y = 10x` that fit
   only one of the two pairs. *Move:* the verify-against-both-pairs step in
   Lesson 5 — it catches the missing `b` every time.
7. **Intercept read as a rate.** "The $85 grows each week." *Move:* the
   sentence frames ("when the input is zero, the output is ___") said aloud
   until the roles are automatic.
8. **"Steady increase" called linear without checking.** *Move:* the
   equal-differences test from Lesson 6 — run it on the learner's own
   example before accepting the label.

## Differentiation

- **Supports:** the four-row modeling template (input / unit / output /
  unit); the "later minus earlier" rate template; sentence frames for slope
  and intercept; large-format or tactile grids; dictated steps with
  learner-supplied reasoning; text alternatives for both images (Lessons 1
  and 3); Desmos/GeoGebra keyboard navigation for graph checks.
- **Extensions:** each lesson carries one; the project extension (exact-fare
  distance with an accuracy discussion) can replace a practice set for fast
  finishers.
- **Language access:** read `f(x)` aloud before evaluating; keep the
  vocabulary list posted with one graphed example each; home-language labels
  welcomed alongside English terms.

## Reteaching triggers and next steps

- **Quiz (Session 15) below 20/30:** reteach the flagged objective in
  Session 17 using its lesson's error-analysis task; do not advance to new
  content that session.
- **Break-even set up but unsolved or uninterrupted:** return to Lesson 4's
  rate work and Unit 01's justification habit with the learner's own plan
  numbers.
- **Parameter interpretations without units:** revisit Lesson 06's sentence
  frames before Session 18 — unitless interpretations earn no credit on the
  assessment.
- **Ready for U03:** learners translate fluently between table, graph,
  equation, and description; read intersections as solutions of `f(x) =
  g(x)`; and interpret slope and intercept in context with units. U03 solves
  systems by exactly these moves — keep the intersection language alive.
