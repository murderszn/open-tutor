# Resource Pack — Unit 04 (Grade 9 Language Arts)

**Summary:** supports a grade-9 (ages 14–15) four-week unit on
grammar precision, syntax variety, vocabulary systems, and
style — adult planning judgment; preview everything before
assigning. All links below were checked on **2026-11-02**
unless labeled otherwise.

## Internal resources

- [The Lighthouse Log, A Letter Home, vocabulary sentences,
  word bank, Sentence Sets 1–2](texts/sentence-bank.md) —
  original unit texts; every lesson, practice, quiz, and
  assessment draws on them.
- [Generated illustration: lighthouse logbook](assets/lighthouse-logbook.png)
  — Lesson 1's sentence-combining scene, with text-only
  alternative in the lesson.
- [Clause diagram](assets/clause-diagram.svg) — deterministic
  diagram of one unit sentence, labeled by the unit's own
  analysis.
- [`resources/language_arts_parts_of_speech.md`](../../../../../resources/language_arts_parts_of_speech.md)
  — adult-side reference for parts of speech; accurate
  grammar vocabulary behind the grade-9 syntax work; never
  assigned as grade-9 instruction (its tone and examples skew
  younger), per the track audit.
- [`resources/language_arts_sentence_structure.md`](../../../../../resources/language_arts_sentence_structure.md)
  — adult-side reference for subject/predicate, phrases,
  clauses, and sentence types; grade-9 adds participial,
  prepositional, and absolute phrases plus noun, relative,
  and adverbial clauses (L.9-10.1.b), which this unit teaches
  explicitly.

## Web references

1. **Common Core State Standards — Language, Grades 9–10**
   ([thecorestandards.org/ELA-Literacy/L/9-10/](https://www.thecorestandards.org/ELA-Literacy/L/9-10/))
   — verified 2026-11-02. The official code and description
   text for L.9-10.1.b, L.9-10.2.a, L.9-10.3.a, L.9-10.4.a–d,
   L.9-10.5.a, and L.9-10.6, quoted in paraphrase in the unit
   README. Free, no account.
2. **Purdue OWL — "Commas vs. Semicolons"**
   ([owl.purdue.edu/owl/general_writing/punctuation/commas/commas_vs_semicolons.html](https://OWL.Purdue.edu/owl/general_writing/punctuation/commas/commas_vs_semicolons.html))
   — verified via search 2026-11-02. Semicolons between
   independent clauses, including with conjunctive adverbs
   (however, moreover, therefore, consequently, otherwise,
   nevertheless, thus). Free, no account.
3. **Purdue OWL — "MLA Works Cited Page: Basic Format"**
   ([owl.purdue.edu/owl/research_and_citation/mla_style/mla_formatting_and_style_guide/mla_works_cited_page_basic_format.html](https://owl.purdue.edu/owl/research_and_citation/mla_style/mla_formatting_and_style_guide/mla_works_cited_page_basic_format.html))
   — verified via search 2026-11-02. Separate Works Cited
   page, alphabetical order, double spacing, hanging indent,
   author–page in-text citations; the full MLA guide for
   Lesson 5 and U06/U07. Free, no account. (Note: OWL
   restructured its URLs in past years; this address was
   returned by search on the check date — if it moves, use
   OWL's site search for "MLA Works Cited basic format.")
4. **Purdue OWL — "MLA Works Cited Page: Books"**
   ([owl.purdue.edu/owl/research_and_citation/mla_style/mla_formatting_and_style_guide/mla_works_cited_page_books.html](https://owl.purdue.edu/owl/research_and_citation/mla_style/mla_formatting_and_style_guide/mla_works_cited_page_books.html))
   — verified via search 2026-11-02. MLA 9th-edition core
   elements and book-format examples, for the Works Cited
   work in Lesson 5 and the project. Free, no account.
5. **Internal — parts-of-speech and sentence-structure guides**
   (see Internal resources above): the adult's vocabulary
   reference for the phrase and clause terms used across
   Lessons 1–2.
