# Unit Assessment — Unit 03

**Adult-administered. 20 points.** Oral, pointing, and short written
responses all count. The adult reads every item aloud and reviews
written work the same day. Do not show the learner
[answer-key.md](../answer-key.md).

## Task 1 — Read long-vowel words (8 points)

Read each word aloud. Name the pattern only if asked; reading the
word correctly earns the point.

1. *cake*
2. *pine*
3. *rain*
4. *stay*
5. *tree*
6. *leaf*
7. *coat*
8. *grow*

## Task 2 — Short or long? (4 points)

Read each word, then say "short" or "long" for its vowel.

1. *cap*
2. *cape*
3. *pin*
4. *pine*

## Task 3 — Ending dictation (4 points)

The adult dictates each word slowly, twice. The learner writes it.
Conventional spelling earns the point; a phonetic attempt that
maps every sound in order earns half credit (adult judgment — see
the key).

1. *dogs*
2. *watches*
3. *jumped*
4. *hoping*

## Task 4 — Two-syllable words (4 points)

Break each word into syllables (clap and say the parts), then read
the whole word.

1. *sunset*
2. *lemon*
3. *tiger*
4. *robot*

## Scoring

- 16–20: Ready for Unit 04 — all objectives at least Developing.
- 12–15: Re-teach the missed pattern or ending type, then re-test
  those tasks only.
- Below 12: use the flexible/catch-up weeks; re-teach in this
  order: (a) the weakest pattern in isolation, (b) its practice
  session, (c) the failed assessment tasks only — never the whole
  assessment at once.
