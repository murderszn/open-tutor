# Teacher Guide — Unit 05: Informational Reading

Adult-facing. Keep this file separate from learner pages; it
holds solutions, misconception notes, and reteaching paths. Full
solutions: [answer-key.md](answer-key.md).

## How to run the unit

- **Sessions are 20–25 minutes, four per week.** Read unit texts
  aloud; the learner reads with support. Every lesson states its
  standard(s) so the adult can see what is being practiced.
- **Responses:** oral, pointing, and drawing responses count
  everywhere. The adult scribes dictated words. Review written
  practice the same day.
- **New vocabulary** is taught with pictures, objects, and
  actions first, the written word second. Do not drill the word
  list as spelling words.
- **The generated illustration** is an AI illustration, not a
  photograph. Teach plainly that real lodge entrances are under
  the water even though the picture draws the opening at the
  water's edge.

## Session-by-session notes

| Session | Watch for | If stuck |
|---|---|---|
| 1 (L1) | Topic vs. heading confusion ("dams" as the topic) | Ask: "What are ALL the parts about?" |
| 2 (A) | Retelling every word instead of key details | Ask: "What would a friend most need to know?" |
| 3 (L2) | Reading the whole book to answer | Praise finding: "A reader who finds fast is smart." Model contents-first once more. |
| 4 (B) | Page-number mix-ups | Keep Text A pages in order; contents numbers count the book's pages. |
| 5 (L3) | "Pictures are just decoration" | Ask the duck question: the words never mention the duck. |
| 6 (C) | Label/caption mix-up | One finger for a label word; a whole hand for a caption sentence. |
| 7 (L4) | Guessing from first letters | Stop; use a tool (sentence clue, word part, glossary). Praise every glossary use. |
| 8 (D) | Glossary treated as a test | Let the learner keep the glossary open. Using it IS the skill. |
| 9 (L5) | One-link answers ("dams keep beavers safe") | Ask: "What happens in between?" to stretch the chain. |
| 10 (E) | Backward chains | Accept because-answers; flip to forward order once together. |
| 11 (L6) | "Same = same topic" only | Push for a shared fact (the lodge), not just the shared topic. |
| 12 (Project 1) | Made-up facts in the book | Look the fact up together in Text A/B; correcting it is the lesson. |
| 13 (F, G) | Sorting from memory | Always flip back and check the texts. |
| 14 (Project 2) | Page numbers not matching contents | Re-count pages together before the share. |
| 15 (Quiz + H) | Quiz gaps | Replay the matching Session H game; re-quiz orally. |
| 16 (Assessment) | Fatigue on 8 tasks | Split across two sittings if needed; this is a check, not a race. |

## Readiness: what "ready to move on" looks like

- Names the main topic and retells two or more key details from
  either text.
- Finds a named fact using a heading or the table of contents
  without reading the whole book.
- Names one picture-only fact and one word-only fact from the
  illustration/text pair.
- Explains one beaver chain (dam → pond → safety) and one
  author reason.
- Compares Texts A and B with one true likeness and one true
  difference.
- Project rubric total 12–15, or 8–11 with the weak page
  re-shared after review.

## Reteaching paths

- **Features (RI.1.5) weak:** replay Session B with the adult
  modeling each find first; use a household information book so
  the skill transfers beyond Text A.
- **Picture/word distinction (RI.1.6) weak:** replay Session C;
  cover the caption and list picture-only facts before reading
  any words.
- **Word meaning (RI.1.4/L.1.4) weak:** replay Session D with
  the glossary open from the start; add two new affix examples
  (*unhappy*, *retell*).
- **Connections/reasons (RI.1.3/RI.1.8) weak:** replay Session E
  chain 1 with physical cards; act out each link before
  ordering.
- **Comparison (RI.1.9) weak:** replay Session F with the adult
  reading each fact's source sentence aloud before sorting.
- **Retelling (RI.1.2) weak:** replay Session A with three
  picture prompts (dam, lodge, food) in order.
