# Lesson 06 — Word Families and Blending Ladders

**Goal (learner hears):** "I can read a whole family of words by changing
just the first letter — and climb a blending ladder from word to word."
**Time:** 20–25 minutes · **Materials:** letter tiles (lowercase);
word-family cards: -at, -an, -it, -in, -ot, -op, -un, -ug, -et, -en.
**Standards:** RF.1.3, RF.1.3.b.

## Readiness check (1–2 min)

Build c-a-t with tiles. "Read it." (cat.) Swap c→s: "Read it now."
(sat.) Swap s→m: "Now?" (mat.) "You just read three words by changing
ONE letter. That is today's superpower."

## Explicit teaching

A **word family** is a group of words that share the same ending chunk —
the vowel plus the last letter(s). The ending chunk of *cat, sat, mat,
hat* is **-at**. Once you can read the chunk, you can read the whole
family: just change the **first letter** and blend again.

Why it works: the middle and last sounds stay the same, so your brain
only solves one new sound per word. Reading gets fast because the hard
part (the -at chunk) is already solved.

A **blending ladder** climbs from word to word by changing one letter at
a time: cat → sat → sit → bit → bit? No — one change per rung:
**cat → sat** (change c→s) → **sit** (change a→i) → **bit** (change
s→b) → **big** (change t→g). Every rung is a real word, and you read
each one with the 4 decoding steps.

### Modeled example 1 — building the -at family

*Adult builds -at with tiles and thinks aloud:*
"The chunk is -at: /ă/ /t/ — 'at'. Now I add a first letter: c-at...
/k/ /ă/ /t/ — 'cat'!" *(Adds each new onset card in front of the fixed
-at chunk:)* "s-at — 'sat'. m-at — 'mat'. h-at — 'hat'. b-at — 'bat'."
*Adult points to the unchanging -at:* "Look — the -at never moved. Only
the first letter changed. Five words, and I only had to think hard
once."

### Modeled example 2 — climbing a ladder: pig → big → bit → hit

*Adult writes the ladder rungs:*
"Rung 1: **pig** — /p/ /ĭ/ /g/. Rung 2: change p→b: **big** — /b/ /ĭ/
/g/. The -ig chunk stayed! Rung 3: change g→t: **bit** — /b/ /ĭ/ /t/.
Rung 4: change b→h: **hit** — /h/ /ĭ/ /t/."
"If a rung wobbles — say you read 'bit' as 'bet' — climb back down one
rung and try again. Ladders are for climbing slowly."

## Guided practice (adult does it with the learner; 5 tasks)

1. Fixed chunk -an. Add onsets: c, p, r, v, m → read can, pan, ran,
   van, man.
2. Fixed chunk -op. Add onsets: t, m, p, h → read top, mop, pop, hop.
3. Climb: **sun → run** (change s→r) → **rug** (change n→g).
4. Climb: **pet → get** (change p→g) → **wet** (change g→w).
5. **Find the wobble:** ladder "bed → red → rid → rid"? The adult
   writes bed → red → **rod** → rid. The learner spots the wobble:
   "rod doesn't fit the -ed family!" and fixes it (red → **fed**? No —
   keep it simple: the fix is to notice rod breaks the pattern and
   replace with a real -ed word or restart the ladder).

## Independent practice (learner tries; adult observes, 5 tasks)

1. Build the -it family: sit, bit, kit, hit (tiles; read each).
2. Build the -un family: run, sun, fun.
3. Climb this ladder, reading each rung: **map → cap → cup → pup**.
4. Climb: **hot → hop → pop**.
5. **Explain-your-reasoning:** "Why is reading 'mat, sat, hat' easier
   than reading 'mat, pig, sun'? " (Same chunk -at — only the first
   letter changes; the other three share nothing.)

## Application

"Ladder race — against yourself." The learner builds a 5-rung ladder
starting from any unit word, changing one letter per rung, every rung a
real word. The adult times it (gently — "beat your own best time, not
mine"). Sample learner ladder: **tin?** no — must be unit words:
**pin → win → fin → fun → run**. The learner reads the whole ladder
aloud at the end, smooth and fast.

## Exit check

1. "Read the -en family: ten, pen, men, hen." (Reads all four.)
2. "Climb: log → dog → dig." (Reads each rung.)
3. "What stays the same in a word family?" (The ending chunk — vowel +
   last letters.)
4. "How many letters change on each ladder rung?" (One.)

## Supports and extension

- **Language access:** pre-teach meanings with pictures ("a vat? skip
  it — use 'bat', the animal AND the baseball stick").
- **Alternate response mode:** the learner may build every rung with
  tiles and read aloud; no writing required.
- **Seated-table variant:** onset cards in a pile; the learner flips one
  onto the fixed chunk and reads.
- **Floor-play variant:** giant chunk card on the floor; the learner
  runs a new onset letter to it and reads the word.
- **Extension:** two-rung challenge ladders that change the vowel
  (cat → cot → cut); mixed-family sorts (-at vs. -an vs. -ap).

## Teacher note — likely misconceptions

- *Changing two letters at once:* "cat → sit" in one jump confuses the
  pattern. Enforce: "one letter per rung — that's the rule of the
  ladder."
- *Non-word rungs:* "zat" or "vug" — celebrate the pattern, then check:
  "Is 'zat' a real word? The ladder only climbs on real words."
- *Reading the chunk but mumbling the onset:* "at... sat?" Insist the
  new first sound is said crisply before blending.
- *Families vs. rhymes:* "-at words rhyme, but the family is about the
  shared chunk, not just the sound." (Rhyming "eight" with "late" is a
  Unit 03 spelling conversation.)
