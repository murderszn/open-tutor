# Grade 1 — Independent Curriculum Track

This folder is an anonymous, grade-specific track in the public OpenTutor curriculum library.

**Contents:** The [science track](science/README.md) audit and scope-and-sequence are
delivered as a validated draft (units not yet written); the math track audit and
scope-and-sequence are likewise delivered as a draft (see
[PR #67](https://github.com/murderszn/open-tutor/pull/67)); other subjects
still placeholder.

**Do not refer learners to other grade tracks.** Each track is self-contained.
