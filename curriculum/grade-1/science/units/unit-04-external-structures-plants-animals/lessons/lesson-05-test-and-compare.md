# Lesson 05 — Test Two Designs and Compare

**Student goal:** I can test two designs the same way, compare their
results, and say which works better and why.
**Time:** 20–25 minutes · **Unit:** [U04](../README.md) · **Session 13 of 16**

## Materials

- Version 1 of the learner's nature-tool (built in Session 12)
- Materials to build version 2 (one change only — see below)
- The test materials for the chosen problem: dried beans and a table
  (Problem A), a bowl of water with leaves/bits (Problem B), or a paper
  sign and a fan or gentle blowing (Problem C)
- Science journal with the comparison table (adult-ruled: two rows,
  "Version 1" and "Version 2," and one column, "Did it work? How well?")
- The sketch from Lesson 04

**Safety note for the adult:** water work happens over a tray or towel;
the fan, if used, is on its lowest setting and never pointed at faces.
Scissors and tape are adult-supervised throughout. Spills are expected
and are not failures — they are data.

## Readiness check (2 minutes)

"Show me version 1. What problem does it solve? What nature part does
it copy?" If the learner can answer both (by speaking or pointing to
the sketch), begin. If not, re-read the sketch labels together first.

## Teaching

A design is only a guess until it is **tested**. And one test is not
enough to be sure — scientists test **two designs the same way** and
compare. "The same way" is the fair-test rule from Unit 03: same
problem, same materials, same number of tries. Only **one thing**
changes: the design itself. If two things change at once, we cannot tell
which change made the difference.

Version 2 is version 1 with **one change** — the learner picks it:

- Problem A (seed pickup): version 2 has wider, narrower, or longer
  pinching arms than version 1.
- Problem B (pond scoop): version 2 has bigger, smaller, or more drain
  holes than version 1.
- Problem C (sign anchor): version 2 has wider, longer, or heavier
  "roots" than version 1.

Each version gets **three tries**. The adult records each try honestly:
worked / partly worked / did not work. Then the learner compares: which
version worked more often? Which version worked better, and **why** —
what did its shape do that the other shape did not?

The comparison sentence, said aloud and written (adult-scribed) in the
journal: "**Version ___ works better, because ___.**" Then the choice:
keep the better version, or improve the weaker one with what was
learned. Either choice is scientific, as long as the reason comes from
the test results — not from "I like this one more."

## Worked example 1 — testing Problem B, three tries each (modeled)

The adult runs the example with the learner's own scoop if it is ready,
or with two spoons (one with holes poked by the adult beforehand, one
without) as a stand-in.

> "Problem B: scoop leaves out of water. Version 1 — a plain spoon, no
> holes. Try 1: scoops leaves, but also a spoonful of water. Try 2:
> same — leaves plus water. Try 3: same. Result: works, but brings
> water along. Version 2 — a spoon with holes. Try 1: scoops leaves,
> water drains through the holes. Try 2: same. Try 3: one leaf slipped
> through a hole — mostly works. Compare: version 2 works better,
> because water drains out and leaves mostly stay in. The holes are the
> duck-beak copy doing its job."

**Reasoning to name aloud:** three tries matter because one try can be
luck. When version 2 wins two or three times, we trust it more than a
single lucky scoop.

## Worked example 2 — an unfair test, and how to fix it (modeled)

The adult describes a test: "Version 1 scooped leaves from a calm bowl.
Version 2 scooped leaves from a bowl someone was stirring. Version 2
lost. So version 1 is better — right?"

> "No! That test was **unfair** — two things changed: the design AND
> the water. Stirred water is harder to scoop from. We cannot tell
> whether version 2 lost because of its shape or because of the
> stirring. Fix it: test both versions in the **same** calm bowl, three
> tries each. Then the winner wins because of its **shape**."

**Reasoning to name aloud:** fair tests change one thing at a time.
This is the Unit 03 fair-test rule, used again — good science reuses
its rules.

## Guided practice (adult stays close, hints allowed)

Do 4–6 short rounds. Offer choices; never demand a spoken answer.

1. One-change round: "What one thing will version 2 change?" The
   learner names it; the adult writes it on the table. (Any single
   change counts; if the learner names two, the adult asks them to pick
   one for today.)
2. Fair-test round: "What must stay the same for both versions?"
   (Same bowl / same table / same beans or leaves, same three tries.)
3. Test round: the learner runs three tries for version 1 while the
   adult records worked / partly / did not work. Then three tries for
   version 2. (Actual results vary — the adult records what really
   happened; there is no "correct" winner in advance.)
4. Compare round: "Which version worked more often? Which version
   works better, and why?" The learner finishes the sentence:
   "Version ___ works better, because ___."
5. Error-analysis round: the adult says, very seriously: "Version 2
   won once, so it is the best, even though version 1 won the other two
   tries." Ask: "Is that right?" (Expected: no. Count all three tries:
   the version that wins more often is better, not the one that won
   once.)
6. If the learner is verbal: "Finish the sentence: a fair test changes
   ___ thing at a time." (One.)

## Independent practice

The learner completes the comparison table in the journal (adult
scribes the results) and draws a star beside the winning version. The
adult observes: are the results honestly recorded (including failures),
and does the winner match the recorded tries? When finished, the adult
asks, "What would you change to make the loser better?" Full solutions
are in the [answer key](../answer-key.md).

## Application

"Your friend says, 'My design is better because I like it more.' What
do you say?" The learner answers: liking is not testing — test both
designs the same way, count the wins, and let the results decide.
(Accept any answer that appeals to the test results rather than to
liking.)

## Exit check

The learner states the comparison sentence ("Version ___ works better,
because ___") and names the one thing that changed between versions.
Both parts correct counts as secure for today; the comparison table is
kept for Session 14's improve-and-retest work.

## Supports, alternate response, extension

- **Language access:** the comparison table uses worked / partly /
  did-not-work faces (smiling / straight / frowning) as well as words;
  the adult reads every result aloud.
- **Alternate response mode:** pointing to the winning row, drawing a
  star, or acting out the test all count; no writing is required.
- **Seated-table variant:** the whole test runs on a tray on the table.
- **Floor-play variant:** Problem C's sign test runs on the floor with
  the learner blowing gently from a marked spot.
- **Extension:** "Design version 3: combine the best part of each
  version. What would it look like?" (The learner sketches it; building
  it is optional enrichment in Session 14 if time allows.)

## Teacher note

Likely misconception: "the first design is best because I made it" or
"one win decides it." Re-teach with the three-tries count: the winner
is the design with more wins, and a failed test is useful data, not a
personal failure. Also watch for unfair tests (changing the bowl, the
beans, and the design at once) — reset to one change and re-run. See the
[teacher guide](../teacher-guide.md). Answer-key reference:
[answer key, Lesson 05](../answer-key.md#lesson-05).
