# Project — The Long-Distance Messenger

**Sessions 11–12 (plus Session 14 redesign) · Adult-supervised · 20–25
minutes each**

## The challenge

"Your voice cannot reach across the room. **Design and build a device that
uses sound to send a message across the room.** Test **two** different
designs, compare them, and show which one solves the problem better."

The message to send (adult's choice, kept the same for both designs): a
two-word message like "cleanup time" or "story time."

## Materials

Paper cups, string/yarn (adult handles), paper clips, a bell, the sealed
shaker, two sticks, rubber bands and the shoebox, journal and crayons.
The adult opens and closes any sealed containers.

## Steps

1. **Define the problem** (Session 11, 5 min). Learner says it aloud; the
   adult scribes: "My voice is too quiet to reach across the room. I need
   a device that carries my message ___ meters." (Measure with footsteps.)
2. **Sketch design A** (K-2-ETS1-2). Learner draws the device and tells
   the adult how its **shape** helps it do its job. Adult scribes labels.
3. **Build design A** exactly (or note what changed and why).
4. **Test design A** at the measured distance: send the message 3 times.
   Record each as **message arrived / did not arrive** (tally + drawing).
5. **Sketch, build, and test design B** — a *different* idea (Session 12).
   Same message, same distance, 3 trials.
6. **Compare** (K-2-ETS1-3). Fill the compare chart together:

   | | Design A: ___ | Design B: ___ |
   |---|---|---|
   | Message arrived (of 3) | | |
   | What worked well | | |
   | What was weak | | |

7. **Decide and share.** Learner announces: "Design ___ worked better
   because ___." One drawing of the winning device goes in the journal.
8. **Improve** (Session 14): change one thing about the winner, retest
   once, record whether the message arrived.

## Deliverables

- Two labeled sketches (A and B) in the journal.
- A compare chart with 3-trial results for each design.
- One oral or drawn "winner announcement" with a reason tied to the
  problem (distance), not to fanciness.
- (Session 14) One improvement test record.

## Rubric

| Criterion | Getting started (1) | Growing (2) | Strong (3) |
|---|---|---|---|
| Problem defined | Names "too far to hear" with heavy prompting | Names the distance problem in own words | Names the problem *and* the message to send |
| Sketch before build (K-2-ETS1-2) | Builds first, sketches after | Sketches first; build roughly follows it | Sketch labels parts and says how shape helps the job |
| Two designs tested | Tests one design | Tests two designs, same message/distance | Two designs, 3 trials each, results recorded |
| Compare with evidence (K-2-ETS1-3) | Picks a favorite with no reason | Compares and names which worked better | Compares with trial data and ties the win to the problem |
| Sound safety | Needs reminders | Follows rules with one reminder | Protects ears, keeps materials off the table edge and out of mouths, string never near necks — unprompted |

**Scoring:** 12–15 = strong engineer; 8–11 = growing — revisit the weak
row in Session 14; below 8 = rebuild one design together with the adult
modeling each step.

## Safety

All building and testing is adult-supervised. One ring/shake per test,
never next to an ear. String is handled by the adult and never wrapped
around a neck. Small parts stay on the table. If anything feels unsafe,
the adult stops the build and the learner names the rule that applies
(track objective 10).

## Teacher notes

- The classic pair is **cup-and-string telephone vs. bell code** (one ring
  = "come here"). Both are buildable in 20 minutes and produce clearly
  different distance results.
- If the learner's two designs are nearly identical (two telephones),
  require design B to use a *different* sound-maker — the comparison
  needs contrast.
- Accept "neither worked at 5 meters, but the bell worked at 3" as a
  strong, honest result; engineers report limits.
