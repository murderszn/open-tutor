# Answer Key — Unit 02

Worked solutions for every lesson item, practice task, quiz question,
assessment task, and the project. Each was solved independently against
the unit's materials; the adult accepts any scientifically equivalent
learner response. Misconception notes live in
[teacher-guide.md](teacher-guide.md).

## Lesson 01

**Guided practice (sound hunt):** accept any honest loud/soft + high/low
labels; the check is that the learner *describes* before moving on. Sample
journal row: "keys jingle | loud, high | keys hitting each other."

**Independent practice:** 4 learner-made sounds, each with 2 labels, e.g.,
stomp = loud + low; whisper = soft + (high or low — accept either with the
learner's reasoning); finger snap = soft + high; table tap = soft + low.
Star on the loudest.

**Application:** the loud clap — the whisper would not travel to the
other room. Accept "clap because it is louder and loud sounds go farther"
as the complete answer.

**Exit check:** any 2 sounds from the walk, each with both labels.

## Lesson 02

**Guided practice (three bands):** for each band — "yes, I saw it shake
(the blur)"; "yes, I heard the sound at the same time"; thin → high,
medium → middle, thick → low. The pattern (thinner/faster shake = higher
sound) is noted, not tested.

**Independent practice:** 2 new vibrating sound-makers with wiggle-line
drawings, each with the sentence "It vibrates, so it makes sound."
Examples: humming throat ("I feel the buzz in my throat"), plucked hair
tie ("I see it wiggle"), tapped spoon ("it shivers after the tap").

**Application:** accept any plan linking a shake to the sound: "Feel the
TV speaker buzz while it plays" or "watch the speaker shake." The key
move is *proposing a vibration check*, not the specific method.

**Exit check:** "It shakes fast, so it makes sound" — both shake and sound
must be mentioned.

## Lesson 03

**Guided practice (tally):** expected pattern — 3 soft strikes →
trembled ×3; 3 loud strikes → hopped ×3. Accept "wiggled a little" for
trembled and "jumped" for hopped. Conclusion: "Loud strikes made the rice
hop."

**Independent practice:** loud hum moves the paper strip more than the
soft hum. (If the learner uses claps: hard clap moves it more.)

**Application:** the loud CLANG could startle or wake the baby — the
sound's shaking traveled across the room and moved (startled) something.
Accept any answer connecting loud sound → travel → effect at a distance.

**Exit check:** loud strike → rice hopped/jumped; louder sound → moves
things more.

## Lesson 04

**Guided practice (relay):** 3 messages sent and repeated back. If a
message fails, the fix is tightening the string — record the retry, not
the miss, as the learning.

**Independent practice:** saggy string → message fuzzy or lost; tight
string → message arrives. Normal voice arrives clearer than a whisper
(and clearer than a shout, which distorts).

**Application:** accept any deliberate sound-carrier: cupped hands +
shout, clap code, stick banging, bell. The point is *using sound on
purpose to bridge distance*.

**Exit check:** two cups + string; "the string carries the sound/message
from one cup to the other."

## Lesson 05

**Guided practice (sketch):** accept either problem choice. The sketch
must show the device; the shape-help answer must link a feature to the
job, e.g., "the cup is open wide to catch my voice," "the bell is small
so I can shake it," "the string is long to reach far."

**Independent practice:** build from the sketch; one test recorded as
yes/not-yet + one observed detail ("the bell was heard from the hallway,"
"the whisper did not arrive").

**Application:** change one thing and test again — quitting is the wrong
answer. Accept: "Try a louder sound," "make the string tighter," "move
closer and retest."

**Exit check:** problem + device + test result, all three stated.

## Practice

**L01:** (1) 4 mystery sounds, 2 labels each. (2) loud pile: dog, drum,
car horn; soft pile: whisper, bird, rain. (3) near tap louder — closer is
louder. (4) squeak = high, stomp = low. (5) correct the adult: a whisper
is *soft*; high/low is separate.

**L02:** (1) buzz felt = throat vibrating. (2) the blur — fast shaking.
(3) vibrate: ringing bell, bouncing ball (while bouncing); not: sleeping
cat, book on shelf. (4) 3 drawings with wiggle lines + one sentence each.
(5) the shake was stopped, so the sound shrank.

**L03:** (1–2) soft → tremble ×3; loud → hop ×3. (3) soft = tickle, loud =
thump. (4) loud hum moves the strip more. (5) the loud sound's shaking is
stronger — it moves things more.

**L04:** (1) assembly in order: thread, knot with paper clip, pull tight.
(2) tight wins; the string carries the shaking better when taut. (3) 2
sent + 2 received, ✓/✗ scribed. (4) find the sag, tighten, resend.
(5) points to talking cup, listening cup, string; names all three from
memory.

**L05:** (1) problem → sketch → build → test → compare → improve, in
order. (2) across the room → bell or telephone; playground → shout
through cupped hands (loudest); secret yes-no → tap code. (3) new sketch
with a shape-help reason. (4) yes/not-yet + detail. (5) correct the
adult: a failed test is data — change one thing and retest.

## Week-04 quiz

1. Loud clap / soft whisper identified; learner produces one high and one
   low sound (any).
2. High: bell, bird; low: drum, whisper (whisper is soft; accept high or
   low with reasoning).
3. "I saw it shake/blur" + "I heard the twang at the same time."
4. "…make **sound**."
5. Rice hopped/jumped; loud sounds move things more.
6. Points to the **string**.
7. Any built sound-carrier: telephone, bell code, shaker signal, tap code.
8. Bang softly / move it away / cover ears; string in hands, never around
   a neck.

## Unit assessment

**Part A:**
1. 6 labels (bell: loud+high; book tap: soft+low; shaker: soft+high-ish —
   accept the learner's consistent reasoning).
2. Must link: "the band shook/blurred AND I heard the twang — shaking
   makes sound." Teaching the stuffed animal in own words = full marks.
3. Prediction (hop) stated before the strike; result read as evidence:
   "I was right — the loud sound moved the rice more."

**Part B:**
4. Message arrives = full marks. Message fails but learner diagnoses
   (saggy string, cup not at ear) and fixes = full marks. Message fails
   with no diagnosis = partial; adult models the fix and retests.
5. Reason must cite a test result: "the bell won because we heard it from
   the hallway and the telephone only reached the door" (example). "It
   looks cooler" = no marks — redirect to evidence.

**Part C:**
6. (b) is unsafe. Fix: one gentle ring at arm's length (plan a), or cover
   ears / move away / strike softly. Must name ear protection.
7. Demonstrates: string held in hands; states "never around a neck" (self,
   others, or toys).

## Project

**Compare chart (sample):** Design A (telephone): arrived 2/3 ("string
went saggy once"); strengths: "whispers arrived," weaknesses: "needs two
people and a tight string." Design B (bell code): arrived 3/3; strengths:
"heard from the hallway," weaknesses: "only sends one message — ring
means come here." Winner: bell, because the problem was *distance*.

**Rubric scoring:** apply the project.md rubric row by row; 12–15 strong,
8–11 growing (revisit the weak row in Session 14), below 8 rebuild one
design with the adult modeling. Accept "neither reached 5 m; bell won at
3 m" as strong — honest limits are good engineering.
