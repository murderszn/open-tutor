# Starter Lesson — Read a map and describe a route

**Status:** draft supplement. **Time:** three 20–25 minute sessions. **Goal:** Use a simple key, describe relative location, and explain one way a community place helps people.

## Adult preparation and readiness

Use this fictional map and a pencil. Do not ask the learner to share a real address or route. Readiness: ask what is beside the door; accept pointing, gesture, or speech.

```text
N ↑
┌────────────┐
│ L     P    │
│            │
│ H     S    │
└────────────┘
Key: L = library; P = park; H = homes; S = school
```

## Teach and model

Explain: the key tells what each letter stands for; the north arrow helps describe direction. Model, “The library is north of the homes.” The map is a simplified model and is not drawn to scale.

**Worked example 1:** H means homes. If H is in the lower-left box, the homes are represented there; the letter is a symbol, not the actual building.

**Worked example 2:** A route from H to S can be described as “start at homes, move across to the school.” The route uses map positions, not private travel directions.

**Pacing and roles:** Session 1: adult models the key and guides tasks 1–2. Session 2: learner follows or describes a route in tasks 3–4. Session 3: adult presents the mismatch for task 5; learner completes the community example and exit check.

## Guided and independent tasks

1. Use the key to tell what P and L mean.
2. Name one place north of homes. (Library.)
3. Describe a route from homes to park using start and destination.
4. Draw a new symbol for a library and add it to a key.
5. Explain one reason a person might visit a library or park.
6. Error check: adult points to P but says “library.” Ask learner to check the key and correct the mismatch.

**Answer checks:** P = park, L = library; library is north of homes; route descriptions may vary but must match the map; symbol/key must agree; plausible reasons include reading/borrowing books or recreation.

## Exit check and product

Learner describes one map relationship and gives a reason a community place is useful. Product: labeled map with one corrected/created symbol and a two-sentence or dictated explanation.

## Review rubric

| Criterion | 2 — shows skill | 1 — developing | 0 — not yet observed |
|---|---|---|---|
| Key | Interprets symbols correctly | Uses key with prompt | Revisit one symbol at a time |
| Route | Names start/destination and an appropriate direction | Names start/end with help | Trace route with a finger |
| Community | Gives a plausible use of a shared place | Gives one with choices | Adult models examples |

Use tactile large shapes, a finger route, adult scribing, and oral answers. Use a fictional map if mapping real surroundings is inaccessible or unwanted. Do not record or post private location details.
