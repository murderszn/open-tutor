# Unit 03 — Teacher Guide

For the guiding adult (teacher, tutor, or family member). Learner-facing pages
never link here without a clear "for the adult" label. Pair with
[answer-key.md](answer-key.md), which holds every solution.

## How to use this unit

- **Session length:** 15–20 minutes, four sessions a week. Stop while energy
  is high; a split session beats a forced one.
- **Response modes:** accept oral, pointing, drawing, and acted-out answers
  everywhere. You scribe dictated words. Written output stays at 2–3 word
  labels plus dictated sentences.
- **Language:** teach each vocabulary word with an object, picture, or walk
  first and the word second. Welcome the home language alongside English.
- **Pacing:** the 16-session table in the [unit README](README.md) is the
  order that matters. Combine or split sessions freely; do not skip the
  project (Sessions 13–14) — it is where the objectives come together.
- **Privacy:** keep the learner's own-day strip, dictated sentences, quiz
  notes, and assessment evidence in private storage. Nothing with the
  learner's work or name enters this public repository. The only
  class-shareable artifact is the fictional Willow Street strip.
- **Family-neutral delivery:** never ask the learner to describe their own
  family structure, and never present a "mom and dad" household as the
  default in examples. Willow Street characters are a lamp-lighter, a baker,
  a cart driver, children, a librarian, and an elder neighbor — roles, not
  family positions.

## Session-by-session adult directions

| Session | Do this | Watch for |
|---|---|---|
| 1 (L1) | Teach past/present/future with the behind–feet–ahead gestures; sort 5 spoken events | "Past = yesterday only" — ask "yesterday-past or long-ago-past?" every time |
| 2 (Practice A) | Build the learner's own-day strip (3 cards + 1 future card) | Private storage only; if the learner's morning differs, use their real events |
| 3 (L2) | Teach timeline order with the morning cards; run the deliberate-error fix | Ordering by liking ("play first") — always ask "did it *happen* first?" |
| 4 (Timeline game) | Willow Street morning, 4 events, shuffled; swap round twice | Accept any order defended with before/after reasoning; dawn and school-start anchor the ends |
| 5 (L3) | Teach change / stayed-the-same with lamp, washing, travel pairs | "Everything was worse long ago" — return to the stay-the-same column every time |
| 6 (Practice B) | Spot differences and stay-the-sames in the Willow Street illustration | Say out loud that it is a practice drawing, not a photograph of a real street |
| 7 (Read-aloud A) | Read *The Lantern on Willow Street* with voices; run the 4 response tasks | The retell order matters more than exact words; picture cards are fine |
| 8 (Sort + game) | Changed/stayed sort (6 cards), then "Change or same?" movement game | Lamp cards: either lamp in "changed" is fine if the reasoning is about the tool |
| 9 (L4) | Teach the three source kinds with a real photo, a real object, a told story | "Every picture is a photograph" — ask "camera of a real moment, or drawn?" |
| 10 (Source sort) | Sort 6 source examples; the illustration trap question | The illustration answer ("none") is the key item — reteach L4 if missed |
| 11 (L5) | Teach the evidence frame with one real source; run the perspective task | Answers from prior knowledge, not the source — cover the picture and ask "what does *this source* show?" |
| 12 (Read-aloud B) | Read *Two Pictures of One Street*; run the 3 detective questions | "Cannot tell" is a good answer — praise it explicitly |
| 13 (Project 1) | Build long-ago and today panels; check one stay-the-same feature | Panels swapped is the common error — check-in step 4 exists for this |
| 14 (Project 2) | Future-idea panel (labeled IDEA), source card, gallery share | Future panel must be labeled as an idea, not presented as a fact |
| 15 (Quiz) | [week-14_quiz.md](assessments/week-14_quiz.md), gently, then reteach stations | Mark got it / getting there / not yet + one evidence line per item; move at least one objective up |
| 16 (Assessment) | [unit-assessment.md](assessments/unit-assessment.md) + reflection | 20 min max; break halfway; record evidence lines; apply the readiness rules |

## Misconception map (all five lessons)

1. Past = yesterday only; future = tomorrow only (L1) → ask the
   yesterday-past vs. long-ago-past question for every past example.
2. Timeline order = liking or importance order (L2) → "did it *happen*
   first?" is the only ordering question.
3. "Everything changed" or "everything was worse long ago" (L3) → the
   stay-the-same column (needs: light, clean clothes, travel, news) is the
   anchor; revisit it before moving on.
4. Every picture counts as a photograph / a drawing counts as evidence
   (L4) → the camera test: "taken with a camera of a real moment, or drawn
   by someone?"
5. Answering from what you already know instead of from the source (L5) →
   the evidence frame's first blank ("The ___ shows ___") must be filled
   from the source before the answer is given.
6. Perspective = "they were wrong" (L5) → different normal things, not
   right/wrong: "Nia's normal was a basin; your normal is a machine."

## Readiness, reteach, and follow-up

- **Ready to move on (Unit 04):** secure or developing on objectives 1, 2,
  and 4, with the evidence habit (objective 5) at least developing. A
  developing objective 3 or 6 carries forward with review games in the
  Week 15–16 flex time.
- **Reteach triggers:** objective 2 emerging → replay the Session 4 game
  with 3 cards; objective 4 emerging → reteach with photograph vs. object
  only, then re-add stories; objective 5 emerging → replay Lesson 5's
  photograph example with the picture-frame posted, then re-check with a
  different source. Do not advance past a guessing habit — Unit 07's figure
  work depends on source discipline.
- **Targeted follow-up by objective:** Obj. 1 — daily time-word sorting
  (Lesson 1 extension); Obj. 3 — the Session 8 movement game; Obj. 6 —
  Lesson 5's perspective task with a new pair (letter vs. phone call).
- **What "secure" means here:** observed in this unit's tasks, not a
  standardized score. Report it to the learner's family as "observed during
  Weeks 11–14 activities," never as a test grade.
