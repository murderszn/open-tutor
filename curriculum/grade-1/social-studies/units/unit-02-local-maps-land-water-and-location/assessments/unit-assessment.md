# Unit 02 — Culminating Assessment (Session 16)

Adult-led performance assessment, ~15–20 minutes, oral/point/draw with adult
scribing. Each task is tagged to its objective. **Learners never see the
answer key** ([answer-key.md](../answer-key.md) §UA).

## Task 1 — Location words in action (Obj. 1)

The adult places a ball, a book, and a cup on the table. "Put the ball *next
to* the book. Put the cup *above* the book — no, wait, *below* the book.
Point *left*, then point *right*." (4 placements/points; secure = 4 correct.)

## Task 2 — What is a map? (Obj. 2)

"Tell me what a map is, in your own words." Follow-up if needed: "Would a
bird see the side of a house or the top?" (Secure = "a picture of a place
from above" or equivalent + names the top view.)

## Task 3 — Read the key (Obj. 3)

The adult draws a fresh mini-map: two blue wavy lines, three red squares, one
green triangle placed touching one of the squares, with a key the learner has
not seen (blue wavy line = river, red square = house, green triangle = tree).
"Read the key, then tell me: how many houses? Is there a river? Is a tree
next to a house?" (Secure = reads the key first, then 3 of 3 correct: three
houses, yes a river, yes the tree touches a house.)

## Task 4 — Draw and key a map (Obj. 4)

"Draw a map of this room from above. Show at least three things, and make a
key that tells what each drawing stands for." (Secure = ≥3 features placed
sensibly + key explains every symbol.)

## Task 5 — Land and water (Obj. 5)

On the globe: "Point to land. Point to water." Then: "Name one land shape and
one water you have seen in real life." (Secure = both points correct + one
of each named from experience.)

## Task 6 — Features of our place (Obj. 6)

"Name one cultural feature of our neighborhood — something people made. Name
one environmental feature — something people did not make. How are they
different?" (Secure = one of each + states the difference.)

## Scoring

| Task | Secure (2) | Developing (1) | Emerging (0) |
|---|---|---|---|
| 1 — location words | 4 correct | 2–3 correct | 0–1 correct |
| 2 — map defined | Above-view definition | "A picture of a place" only | Cannot define |
| 3 — key reading | Reads key, 3/3 | 2/3, or skips the key | 0–1 |
| 4 — draw + key | ≥3 features, full key | 2 features or partial key | 1 feature or no key |
| 5 — land/water | Points + names both | Points only | Confuses blue/green |
| 6 — features | One of each + difference | One of each, no difference | Cannot sort |

**10–12 = secure overall; 7–9 = developing** (reteach lowest tasks with the
lesson demos, then re-check those tasks only); **below 7 = emerging** (revisit
the unit's practice sessions before Unit 03). This is a draft classroom
check, not a standardized or validated test. Full solutions, acceptable
responses, and reteach pointers: [answer-key.md](../answer-key.md) §UA.
