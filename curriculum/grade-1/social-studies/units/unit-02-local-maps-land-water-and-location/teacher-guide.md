# Unit 02 — Teacher Guide

Adult directions for all 16 sessions. The learner never needs to read this
file — read or paraphrase the lesson scripts aloud. Solutions live in
[answer-key.md](answer-key.md); never show that file to the learner.

## How to use this unit

- **Session shape (15–20 min):** 1-minute readiness check → explicit teaching
  (read or paraphrase the lesson; pause at bold words) → worked examples
  (think aloud; do not skip) → guided practice → independent practice →
  application → exit check (record secure/developing/emerging).
- **Recording:** keep one line per session per objective in a notebook. The
  exit checks are your assessment evidence — no separate gradebook needed.
- **Order matters more than the calendar:** if a session runs long, split it;
  never skip the worked examples or the exit check.
- **Preparation per session:** Session 2 — hide 5 soft objects. Session 3 —
  preview the illustration. Session 5 — draw 5 symbol cards. Session 7 — pick
  the real route. Session 8 — choose the walk route in advance. Session 9 —
  have a globe or world map ready. Sessions 13–14 — large paper.

that you could not do four weeks ago?" Scribe the answer on the learner's map.
Revisit it at the final review (Weeks 35–36).

## Misconception map (all six lessons)

1. **Left/right are fixed places** (L1) → re-anchor to the L-hand; note maps
   remove the confusion.
2. **A map is any drawing of a place** (L2) → "would a bird see that?" until
   the above view is automatic.
3. **Detailed pictures beat symbols; keys are optional** (L3) → rule: every
   symbol on the map must appear in the key.
4. **A route map shows everything** (L4) → "is it on the way?" + first/then/
   last narration.
5. **Blue means ocean only** (L5) → blue means *any* water; keep the agreement
   verbal.
6. **Sorting by material, not by making** (L6) → the one test question: "did
   people make it?"

## Reteach guidance

- **Objectives 1–2 weak:** replay L1's object game and L2's cup demo back to
  back; add the "be the bird" movement game daily for a week.
- **Objective 3 weak:** rebuild the 5-card match game with the learner drawing
  the cards; cover/uncover the key to prove its job.
- **Objective 4 weak:** co-draw: the adult draws one landmark, the learner
  draws the next; keep the key to 2 symbols until it is automatic.
- **Objective 5 weak:** stay on the illustration (river/pond) before returning
  to the globe; sort blue/green cards into piles.
- **Objective 6 weak:** reduce to two anchor items (house vs. river) and
  re-expand only when the test question is automatic.

## What "ready to move on" looks like

Ready for Unit 03 when objectives 1–4 are at least *developing* and the learner
points to land and water on a globe without a hint. If the key habit (every
symbol explained) is not secure, carry a 2-minute key check into Unit 03's
first two sessions rather than holding the learner back.

## Accessibility notes

- All checks accept oral, pointing, or drawing responses; scribe dictated
  labels; home-language answers count fully.
- Large-print, high-contrast symbol cards; textured shapes for low-vision
  learners; the color-a-map uses blue/green plus shape cues (wavy vs. solid)
  so color is never the only cue.
- Every lesson has a table variant and a floor-play movement variant — use
  whichever fits the learner's body that day.
- Hearing: face the learner during discussions; visual sentence frames
  ("First ___, then ___, last ___) support sequencing talk.
