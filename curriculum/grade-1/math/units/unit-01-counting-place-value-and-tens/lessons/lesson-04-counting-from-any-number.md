# Lesson 04 — Count from Any Number to 120

**Student goal:** I can start counting at any number (like 47 or 103) and
keep going to 120, and I can read and write the numbers I say.
**Time:** 20–25 minutes · **Unit:** [U01](../README.md) · **Session 13 of 16**
(first half of the combined core session)

## Materials

- A hundred chart (100–120 extended; adult-made or drawn — see teacher note)
- A small token or sticker to mark the starting square
- Number cards 1–120 for spot checks

## Readiness check (2 minutes)

Count by ones from 1 to 20 together. Then: "Start at 13 and count to 20."
If starting mid-sequence is hard, practice 10→20 and 20→30 starts before
going further.

## Teaching

We don't always start counting at 1. Sometimes we keep counting where
someone left off. The hundred chart shows the pattern: **each row goes up by
one, and each step down goes up by ten.**

> "Put your token on 47. Now count: 48, 49, 50, 51… Watch what happens at
> 49 to 50 — the tens change. Keep going: …58, 59, 60."
> "Now start at 103 and count to 112. After 109 comes 110 — that's eleven
> tens. After 119 comes 120 — twelve tens."

Trace the path on the chart with a finger as you count. Name the two moves:
**right = one more, down = ten more.**

**Key vocabulary:** *hundred chart*, *count on* (keep counting from a
starting number).

## Worked example 1 — from 58 to 71

Token on 58.

> "58. Count on: 59, 60 — the tens digit changed from 5 to 6 because we
> passed another ten. 61, 62, 63, 64, 65, 66, 67, 68, 69, 70, 71."
> "Write the start and the end: 58 → 71. Say each number as you trace it."

Then the learner counts alone from 58 while the adult listens for the
59→60 and 69→70 transitions.

**Reasoning to name aloud:** crossing a decade boundary changes the tens
digit — that's the signal that another ten has been completed.

## Worked example 2 — from 96 to 112 (crossing 100)

Token on 96.

> "96, 97, 98, 99 — and what comes after 99? **One hundred!** Nine tens and
> nine ones, then one more makes ten tens, which is one hundred."
> "101, 102 … keep going … 109, 110, 111, 112."
> "Write 112: one hundred, one ten, two ones."

**Reasoning to name aloud:** 100 is ten tens. The numbers 101–109 are "one
hundred and some ones" — the tens digit is 0 there, just like in the decade
numbers.

## Guided practice (adult stays close, hints allowed)

Do 4–6 short rounds.

1. Token on 23: count to 35. *Hint: "Trace each square as you say it."*
2. Token on 74: count to 82.
3. Token on 109: count to 120.
4. The adult says "start at 66, count six more" — the learner counts 67–72
   and writes 72.
5. Error analysis: the adult counts "98, 99, 100, 111…" Ask: "What did I do
   wrong?" (Expected: after 100 comes 101, not 111 — skipped the 101–110 row.)
6. Write the numbers 118, 119, 120 from dictation.

## Independent practice

The learner picks three start numbers (one in the 40s, one in the 80s, one
past 100), marks each on the chart, counts on 10, and writes the landing
number. The adult checks each landing square.

*Alternate response mode:* say the count aloud while the adult traces;
the learner taps the chart at each decade crossing.

## Application

Page numbers: open a book to page 87. "If we read 5 more pages, what page
will we reach?" (92.) "Start at 114, read 6 more?" (120.) Counting on is
how we track progress through anything numbered.

## Exit check

"Start at 89. Count to 101 out loud. Then write 101." Expected sequence:
89, 90, …, 99, 100, 101, written correctly. Record: secure / developing /
not yet.

## Supports

- **Language access:** count slowly; let the learner echo each number after
  the adult before counting alone.
- **Alternate response mode:** point-and-tap on the chart; adult writes
  dictated numerals.
- **Floor-play variant:** lay number cards 85–100 on the floor as a path;
  the learner hops one card per number starting from a called-out square.

## Extension

Start at 120 and count backward to 100. Or: "Start at 57. How many counts to
reach 70?" (13) — previews distance on the number line.

## Teacher note

**Likely misconceptions:** (1) freezing at decade crossings (49→50,
99→100) — pause and name the new ten aloud; (2) the "101–109" row confusion
("one hundred one" vs. "one hundred ten") — contrast 101 and 110 on the
chart; (3) hundred-chart orientation (rows vs. columns) — teach right = +1,
down = +10 as a fixed rule, and keep the chart the same orientation every
session.

**Hundred-chart note:** the unit chart runs 1–120 in 12 rows of 10. If
printing, print at a size where each cell fits a fingertip. Keep one chart
for the whole track — Unit 05 will reuse it.

**Answer-key reference:** [answer-key.md](../answer-key.md#lesson-04) has the
expected responses for the guided error-analysis round and exit check.
