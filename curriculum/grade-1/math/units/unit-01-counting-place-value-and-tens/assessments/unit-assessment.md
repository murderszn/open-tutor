# Unit Assessment — Unit 01: Counting, Place Value, and Tens

**Format:** five performance tasks, adult-observed; oral, pointing, drawing,
or manipulative responses all accepted, adult scribes. 20–25 minutes. Each
task maps to a unit objective in brackets. Scoring guidance and worked
solutions are in [answer-key.md](../answer-key.md#unit-assessment). This is
an educator-made check, not a standardized or validated test.

**Directions to the learner (read aloud):** "Show what you learned about
tens and ones. Use the straws, the picture, or your chart — whatever helps
you think."

## Task 1 — Bundle and count [Obj. 1]

The adult gives the learner 36 loose straws and a rubber band. "Bundle as
many tens as you can. How many bundles? How many loose ones? How many straws
in all?"

*Expected: 3 bundles, 6 loose ones, 36 straws; bundles tied only when ten
are counted in.*

## Task 2 — Count on and write [Obj. 2]

"Start at 88 and count to 101. Write the last three numbers you said."

*Expected sequence: 88, 89, 90, 91, 92, 93, 94, 95, 96, 97, 98, 99, 100,
101; written: 99, 100, 101.*

## Task 3 — Tens and ones [Obj. 3]

The adult shows the number card **57**. "Build this number with bundles and
loose straws. Tell me how many tens and how many ones. Now build **70** —
how is 70 different?"

*Expected: 5 bundles + 7 loose = 5 tens and 7 ones; 70 = 7 bundles and
0 loose ones — the ones digit is zero because there are no leftovers.*

## Task 4 — Compare with the picture [Obj. 4]

Show the generated illustration
[`assets/tens-and-ones-compare.png`](../assets/tens-and-ones-compare.png)
(or read its text alternative). "How many straws in the top row? How many
in the bottom row? Which row has more? Write the comparison with a symbol
and tell me why."

*Expected: top row = 34 (3 tens + 4 ones); bottom row = 25 (2 tens + 5
ones); 34 > 25 because 3 tens is more than 2 tens.*

## Task 5 — Explain your reasoning [Obj. 3, 4]

"Your friend says 29 is greater than 31 because 9 ones is more than 1 one.
Is your friend right? Explain using tens first."

*Expected: No — compare tens first: 2 tens < 3 tens, so 29 < 31. The ones
only matter when the tens are equal.*

## Scoring

| Points | Meaning |
|---|---|
| 9–10 | Secure on all four objectives — ready for Unit 02 |
| 7–8 | Developing — re-teach the missed task's objective (see teacher guide) and re-check within the week |
| 0–6 | Not yet — use flexible catch-up time before Unit 02; do not advance on shaky place value |

Award 2 points per task: 2 = correct with tens-first reasoning; 1 = correct
answer with prompting or weak reasoning; 0 = incorrect or no attempt.
