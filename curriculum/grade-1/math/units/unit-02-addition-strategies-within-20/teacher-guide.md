# Teacher Guide — Unit 02: Addition Strategies Within 20

Adult-facing guidance for the unit. Learner materials never include answer
keys; keep this file separate from the learner.

## How the unit fits

Unit 02 (track weeks 7–10) converts Unit 01's counting power into addition
strategy power. The four strategies arrive in a deliberate order: **count on**
(L1) is the fallback every later strategy is checked against; **turn-around**
(L2) makes counting on efficient and proves order never changes a total;
**make-ten** (L3) leverages the ten-structure built in Unit 01; **doubles**
(L4) anchor on facts most learners already half-know. Lesson 05 then
re-frames all of it through equations: the equal sign as balance, and the
missing addend as counting up. Unit 03 (subtraction) will re-use the
unknown-addend idea — "13 − 4" becomes "4 + ? = 13" — so Objectives 1 and 3
must be secure before moving on.

## Session-by-session notes

- **Sessions 1–4 (Week 7):** Keep sums within 15 while counting on
  stabilizes. The off-by-one hop error (counting the start number) is the
  unit's most common bug — catch it in Session 2's hop-count check, not in
  the quiz. Praise bigger-start choices explicitly; some learners need
  permission to not start at the left.
- **Sessions 5–8 (Week 8a):** The bowl-swap proof must be physical at
  least once — a learner who only hears "order doesn't matter" will not
  believe it. Watch for the "first number is in charge" belief; re-run the
  swap with their own counters.
- **Sessions 9–10 (Week 8b):** Make-ten only works if fill-to-ten is quick
  (Lesson 03 readiness check). If it isn't, drill fill-to-ten for two days
  before modeling the strategy. The generated illustration is a study
  object, not decoration — Session F's picture study is mandatory.
- **Sessions 11–12 (Week 9a):** Doubles must be cold before near-doubles
  (Bay-Williams/Kling progression, cited in the resource pack). Anchor on
  the *smaller* double — the larger-anchor route needs subtraction the
  learner doesn't have yet.
- **Sessions 13–16 (Week 9b–10):** The equal-sign lesson breaks the
  "answer goes here" habit. Use the balance gesture every time. Learners who
  judge equations from one side only need the two-side computation ritual
  (Session H's balance check chant).

## What "ready to move on" looks like

- Counts on from the bigger addend without recounting the start, sums to 20.
- Uses at least two of the four strategies by name and can say when each
  helps ("make-ten when one number is close to 10").
- Solves missing-addend equations within 20 by counting up.
- Judges true/false equations by comparing both sides; explains `=` as
  "is the same amount as."

## Re-teaching map

| Evidence | Re-teach with |
|---|---|
| Hop-count off-by-one | Session A, hop-count check; hand-over-start-number demo |
| Always starts at left addend | Lesson 02 bowl swap; "race the adult" (Session C) |
| Make-ten borrows the wrong amount | "How many empty boxes?" ritual; fill-to-ten drill |
| `=` means "write the answer" | Balance/seesaw demo; `9 = 4 + 5` and `6 = 6` cards |
| Judges equations one-sided | Session H sort with mandatory both-sides computation |
| Near-double anchored on larger double | Redirect to smaller anchor; rebuild with counters |

## Misconception watch (unit-wide)

1. Moving counters changes the total (make-ten) — always recount after
   moving; "moving is allowed, vanishing is not."
2. Turn-around only works for small numbers — true for all whole numbers;
   demonstrate with 9 + 12 later in the year, not now.
3. A near-double is "any close pair" — check: same addends, or one apart?
4. Doubles facts must be memorized before strategies — no: build them with
   ten frames and mirrors first; automaticity follows use.
