# Starter Lesson — Equal groups, arrays, and sharing

**Status:** draft supplement. **Time:** three 30-minute sessions. **Goal:** Represent multiplication as equal groups/arrays and connect a division sharing story to the same multiplication fact.

## Adult preparation and readiness

Use 24 counters, graph paper or a drawn grid, and pencil. Readiness: learner skip-counts by 2s or adds equal groups with objects. If not, use groups of 2 and count each counter. Accept models before written facts.

## Teach and model

Explain: “Multiplication counts equal groups. An array organizes the same groups into rows and columns.”

**Worked example 1:** 3 bags with 4 apples each: 4+4+4=12, so 3×4=12. Draw 3 rows of 4 dots.

**Worked example 2:** Share 12 counters equally among 3 plates. Each plate gets 4. The related fact is 12÷3=4, and 3×4=12 checks the result.

## Pacing and tasks

Session 1: adult models examples; guide tasks 1–2. Session 2: learner builds/draws tasks 3–4, with adult checking equal groups. Session 3: learner works tasks 5–6 and explains the exit check.

1. **Guided:** Draw 2 groups of 5 and write repeated addition.
2. **Guided:** Make an array with 3 rows of 2. Count total and write a multiplication sentence.
3. **Independent:** Show 4×3 as equal groups or an array.
4. **Independent:** Share 15 counters equally among 5 cups. How many in each?
5. **Adult-guided error check:** A drawing shows 3 rows with 4, 4, and 3 dots. Ask whether it shows 3 equal groups; repair it. A valid repair removes one from each 4-dot row, making 3+3+3, or adds one to the 3-dot row.
6. **Application:** There are 4 tables with 6 chairs each. How many chairs? Show a model.

**Answer checks:** 1) 5+5=10; 2) 3×2=6; 3) 12; 4) 3 each; 5) one row needs one more dot; 6) 24 chairs.

## Exit check and product

Solve “20 cards are shared among 4 players equally.” Expected: 5 each; check 4×5=20. Product: one array drawing, one sharing model, and an explanation of how multiplication checks division.

## Review rubric

| Criterion | 2 — shows skill | 1 — developing | 0 — not yet observed |
|---|---|---|---|
| Model | Shows equal groups or array | Model needs setup | Work with smaller groups |
| Fact | Matches model to multiplication/division sentence | Correct with counters | Rebuild with repeated addition |
| Explain | Uses related facts to check sharing | States result with prompt | Model the connection |

Use counters, tactile arrays, larger print, oral dictation, or fewer groups. Avoid small items for children who mouth objects. Let learner demonstrate with plates/cups or drawings. Common error: uneven groups are treated as equal. Fully offline; one lesson does not provide the whole multiplication and division progression.
