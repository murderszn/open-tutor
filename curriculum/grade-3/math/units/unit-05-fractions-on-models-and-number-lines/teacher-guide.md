## Ready to move on — what it looks like

- **After L1:** learner checks parts equal before naming any fraction,
  and says what the denominator counts ("how many equal parts in the
  whole") without prompting. If the learner names fractions from
  unequal parts, do not advance to a/b — re-fold Session A strips until
  the equal check is automatic.
- **After L2:** learner counts the whole's parts first (denominator),
  then the named parts (numerator), and counts by unit fractions aloud
  (1/8, 2/8, 3/8…). A bare fraction with the counts swapped is not
  ready.
- **After L3–L4:** learner counts intervals/jumps from 0, never tick
  marks, and places 1/b at the first tick after 0. If the learner still
  labels 0 as 1/b or counts 0 as a jump, re-teach with a counter hopped
  along the line before L5.
- **After L5:** learner proves equivalence on a strip or a number line
  of the same length and writes whole numbers as fractions (3 = 3/1)
  without prompting. If the learner judges fractions by the size of
  their numerals, re-lay shaded strips side by side before L6.
- **After L6:** learner names the reason for every comparison (same
  denominator → count the pieces; same numerator → compare the piece
  sizes) and checks that both fractions come from the same whole.
  Speed is never the criterion; a slow correct answer with a named
  reason passes, a fast bare symbol does not.
- **Unit readiness:** quiz 9–10, or assessment 14–16, with the project
  at 9+ rubric points. Below that, re-teach the missed objective's
  practice session, not the whole unit.

## Misconceptions and fixes

| Misconception | Fix |
|---|---|
| Naming any piece of a split whole a fraction, even when pieces are unequal | No fraction is written until parts are checked equal by folding, overlaying, or holding side by side (L1, Session H). |
| Swapping numerator and denominator (1 part of 4 → 4/1) | Anchor the denominator as "how many equal parts in the whole" every time; count the whole first (L1, L2). |
| Using the shaded count as the denominator (2 of 4 shaded → 2/3 or 2/2) | Two-step count in order: all equal parts first, then shaded parts; check by counting unit fractions aloud (L2). |
| Counting tick marks instead of intervals/jumps (0, 1/4, 2/4, 3/4, 1 → "5 parts") | Count the spaces between marks out loud from 0; hop a counter one jump per unit fraction (L3, L4). |
| Labeling 0 as 1/b, or starting the count at 1 | The tick at 0 means zero parts counted; 1/b is the end of the first part, the first tick *after* 0 (L3). |
| "Bigger numbers mean a bigger fraction" (2/4 > 1/2) | Shade both on strips of the same length, or mark both on number lines of the same length; let the matching length or point convince (L5). |
| Comparing denominators alone (1/8 > 1/2 "because 8 is bigger") | Lay unit pieces side by side in size order (1/2 > 1/3 > 1/4 > 1/6 > 1/8); fewer cuts, bigger pieces (L6). |
| Comparing fractions from different-size wholes | Insist both strips or both number lines start the same length before any comparison is recorded (L5, L6). |
| Writing a whole number as a fraction with the wrong denominator (3 = 1/3) | Rehearse "3 wholes, not cut, is 3/1" until the denominator-1 pattern is secure (L5). |

## Reteach paths

- **L1/L2 naming:** return to folding for one full session; use only
  denominators 2 and 4 until the equal check and the two-step count are
  each clean, then return to 3, 6, and 8.
- **L3/L4 number line:** keep a paper strip marked in the same
  denominator under the number line for a full session; match each fold
  to a tick mark. The strip is a tool, not cheating. Remove it only
  when the learner places fractions by counting jumps alone.
- **L5 equivalence:** do not teach a multiplication rule for
  equivalents. Stay with cutting: each piece cut in half doubles the
  count and halves the size. Use only 1/2 = 2/4 and 2/3 = 4/6 until
  those are secure.
- **L6 comparison:** if the learner falls back to comparing
  denominators, return to the unit-piece size order (1/2, 1/3, 1/4,
  1/6, 1/8) for a full session before any new comparison.
- **Project:** if the tray plan's fractions do not add up, re-count
  with strips before redrawing — the arithmetic is counting unit
  fractions (2/8 + 3/8 + 1/8 = 6/8), not a new operation.

## Differentiation

- **Support:** fraction strips for every item; adult-scribed fractions
  while the learner folds, shades, and speaks; denominators 2 and 4
  only for re-teach; the reproducible SVG number line for placement
  checks; answers may be spoken or pointed to, with the adult
  recording.
- **Extension:** L2's 3/4-vs-3/6 shaded-amount question; L5's "why
  2/3 has exactly one equivalent in this denominator set" (4/6) and
  the same for 1/3 (2/6); L6's four-fraction ordering with an equal
  pair (2/4 = 3/6); the project's "what if" questions.
- **Language access:** "how many equal parts in the whole" and "how
  many parts we are counting" as the two questions, said aloud before
  writing any fraction; pointing to the numerator and denominator as
  each is named.

## Notes on scope

- All fractions in this unit use denominators 2, 3, 4, 6, and 8 only,
  per the grade-3 3.NF footnote. Denominators 5, 7, 9, and 10 are
  deliberately not introduced; a learner who asks about them may fold
  a strip into fifths as an extension, but no lesson depends on it.
- Fraction addition and subtraction are not taught here. The only
  "adding" is counting unit fractions (3/8 + 5/8 = 8/8) as a check
  that parts make the whole. Formal fraction operations arrive in
  grade 4.
- Fractions greater than 1 appear only as counting past 1 on the
  number line (4/4 = 1, 8/8 = 1) and as whole numbers written as
  fractions (3/1, 6/1). Mixed numbers are not introduced.
- The brownie-tray illustration is an AI-generated picture, not a
  photograph and not data: it shows 8 equal pieces, 3 set aside, 5 in
  the tray. If the learner cannot see the image, the text-only
  alternative in Lesson 02 carries the same information.
- The project uses fictional bake-sale data. Real baking is optional,
  adult-supervised, and only with food every person involved can
  safely eat; check allergies first. Paper and play-dough complete
  every requirement.
