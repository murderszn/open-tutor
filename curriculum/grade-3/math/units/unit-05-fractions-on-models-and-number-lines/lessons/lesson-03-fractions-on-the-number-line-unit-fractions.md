# Lesson 03 — Fractions on the Number Line: Unit Fractions

 **Session:** 6 · **Time:** 30 minutes · **Goal:** I can split the number
line from 0 to 1 into b equal parts and locate the unit fraction 1/b at
the end of the first part.

**Materials:** paper number lines (0 to 1), pencils, ruler or straight
edge, fraction strips from Lessons 01–02 for comparing lengths.

**Retrieval warm-up (2 min, Lesson 02 bridge):** "Write 3/4. What does
the 4 tell us?" (The whole has 4 equal parts; each part is 1/4.) "What
does the 3 tell us?" (We count 3 parts of size 1/4.) "Count by unit
fractions of thirds to 3/3." (1/3, 2/3, 3/3 — the whole.) Today we put
those same unit fractions on a number line.

## Readiness check (3 min)

Ask aloud: "Point to 0 and to 1 on a number line. The part from 0 to 1
is the whole — one whole, like one strip." "If we split 0 to 1 into 4
equal parts, how long is each part?" (1/4.) "How many parts are there
between 0 and 1?" (4.) "What fraction is at the very first mark after
0?" (1/4 — the end of the first part.) If splitting into equal parts is
shaky, lay a paper strip marked in fourths under the number line and
match each fold to a tick mark before writing any fractions.

## Explicit teaching (8 min)

On a number line, the interval from **0 to 1 is the whole**. To show a
unit fraction **1/b**, split that interval into **b equal parts**. Each
part has length 1/b. The unit fraction 1/b sits at the **endpoint of the
first part** — the first tick mark after 0.

Count **intervals** (the spaces between tick marks), not tick marks.
There is one more tick mark than there are intervals, because 0 itself
is a tick mark. Start counting at 0, not at 1.

Here is 0 to 1 split into thirds. There are 3 equal intervals, and the
first tick after 0 is 1/3:

```
0          1/3         2/3          1
|-----------|-----------|-----------|
```

Here is 0 to 1 split into fourths. There are 4 equal intervals, and the
first tick after 0 is 1/4:

```
0      1/4      2/4      3/4       1
|--------|--------|--------|--------|
```

The number line works exactly like the paper strips from Lessons 01–02:
the whole is 0 to 1, each part is one unit fraction long, and counting
parts from 0 gives the fraction at each tick mark. 1/b is always the
first tick after 0, because it is the end of exactly one part.

## Worked example 1 — Locate 1/3

1. Read: locate **1/3** on a number line from 0 to 1. The denominator
   is 3, so split the interval from 0 to 1 into 3 equal parts.
2. Draw the number line. Mark 0 on the left and 1 on the right.
3. Split 0 to 1 into 3 equal parts: make 2 tick marks that cut the
   interval into 3 matching pieces. Check the parts: are the intervals
   all the same length? Yes. ✓
4. Count intervals from 0: the first interval ends at the first tick
   mark. That endpoint is **1/3** — one part of size 1/3.
5. Label it:

```
0          1/3         2/3          1
|-----------|-----------|-----------|
```

6. Check: 3 equal intervals fill the whole from 0 to 1, and 1/3 is the
   end of the first one. ✓
7. Common slip: counting the tick marks (0, 1/3, 2/3, 1 — four marks)
   and saying there are 4 parts. Count the intervals between the marks,
   not the marks: there are 3 intervals, so the parts are thirds.

## Worked example 2 — Locate 1/8

1. Read: locate **1/8** on a number line from 0 to 1. The denominator
   is 8, so split the interval from 0 to 1 into 8 equal parts.
2. Draw the number line. Mark 0 on the left and 1 on the right.
3. Split 0 to 1 into 8 equal parts: make 7 tick marks that cut the
   interval into 8 matching pieces. Check the parts: are the intervals
   all the same length? Yes. ✓ Each interval has length 1/8.
4. Count intervals from 0: the first interval ends at the first tick
   mark. That endpoint is **1/8**.
5. Label the first tick 1/8:

```
0   1/8   2/8   3/8   4/8   5/8   6/8   7/8    1
|-----|-----|-----|-----|-----|-----|-----|-----|
```

6. Check: 8 equal intervals fill the whole from 0 to 1, and 1/8 is the
   end of the first one. ✓
7. Common slip: starting the count at 1 instead of 0, or labeling the
   tick at 0 as 1/8. The tick at 0 means "zero parts counted" — 0/8,
   not 1/8. The first part ends at the first tick *after* 0.

## Guided practice (with hints)

Work through these together; the adult gives the hint, the learner does
the splitting, counting, and labeling.

1. On a number line from 0 to 1 split into **4 equal parts**, locate
   **1/4**. Label it.
   *(Hint: how many intervals are there? Count intervals from 0 — the
   first interval ends at 1/4.)*
2. On a number line from 0 to 1 split into **6 equal parts**, where is
   **1/6**? Label it.
   *(Hint: the denominator is 6, so there are 6 equal intervals. 1/6 is
   the end of the first one.)*
3. A number line from 0 to 1 is split into **2 equal parts**. Mark
   **1/2**. Where is it?
   *(Hint: 2 equal parts means one mark in the middle. That middle mark
   is the end of the first part.)*
4. Count the intervals: how many equal parts are there between 0 and 1
   on a number line marked in **eighths**?
   *(Hint: count the spaces between the tick marks, not the marks
   themselves. How many intervals fill the whole?)*
5. Error analysis: Jay marked **1/4 at the second tick** on a number
   line split into fourths. What did Jay do wrong? Where should 1/4
   be?
   *(Hint: count the intervals from 0 to Jay's mark. How many parts did
   he count? The second tick is the end of 2 parts, not 1.)*

## Independent practice

6. Draw a number line from 0 to 1. Split it into **3 equal parts**.
   Mark and label **1/3**.
7. Draw a number line from 0 to 1. Split it into **8 equal parts**.
   Mark and label **1/8**.
8. Draw a number line from 0 to 1. Split it into **6 equal parts**.
   Mark and label **1/6**.
9. A number line from 0 to 1 has **4 equal parts**. Which tick is 1/4
   — the first, second, or third tick after 0? Explain.
10. True or false: **"On a number line from 0 to 1 split into 4 equal
    parts, 1/4 is at the first tick mark after 0."** Explain your
    answer.
11. Error analysis: Kim counted the tick marks **0, 1/4, 2/4, 3/4, 1**
    on a fourths number line and said there are **5 parts**. What is
    wrong? How many equal parts are there really? Explain using
    intervals.

## Application

Draw a number line from 0 to 1. Split it into **4 equal parts** and
label the ticks **1/4, 2/4, 3/4, 1**. Then write one sentence explaining
why the first tick after 0 is 1/4 — use the words "interval," "equal
parts," and "first part" in your sentence. Check your work by counting
the intervals: there must be exactly 4, all the same length.

## Exit check

1. Mark **1/3** on a number line from 0 to 1 split into thirds. Label
   it.
2. Mark **1/6** on a number line from 0 to 1 split into sixths. Label
   it.

*Success criterion:* both exit items correct with the interval from 0 to
1 split into equal parts and 1/b at the first tick after 0 — not just a
memorized answer. If the learner counts tick marks instead of intervals,
count the spaces between the marks together before Session 7.

## Supports and extension

- **Language access:** let the learner say the location ("one third is
  the end of the first part") while the adult writes the label; the
  learner points to each interval as they count from 0.
- **Alternate response mode:** place fraction strips under a paper number
  line to match each fold to a tick mark, and answer orally; the adult
  records the written labels.
- **Extension:** on a number line from 0 to 1 split into thirds, locate
  **2/3** (the end of the second interval). On a number line split into
  fourths, locate **3/4** (the end of the third interval). Explain why
  2/3 is farther from 0 than 1/3: it counts two parts of size 1/3
  instead of one.

## Teacher note

The defining misconception in this lesson is **counting tick marks
instead of intervals** — seeing the marks 0, 1/4, 2/4, 3/4, 1 and
concluding there are 5 parts — and its twin, **starting the count at 1
instead of 0**, which shifts every label one part to the right. Both come
from treating the number line as a row of points rather than a length
split into equal intervals. The fix is physical: count the spaces between
the marks out loud from 0, and check with a paper strip that the first
interval's length matches one unit fraction. Answer key:
[answer-key.md](../answer-key.md#lesson-03).
