## Ready to move on — what it looks like

- **After L1:** learner names the hidden first question before
  computing, writes both steps with units, and never adds numbers of
  different kinds. If visible numbers are still added wholesale, do
  not advance — re-do Session A with counters for every story.
- **After L2:** learner writes one equation per step, uses a second
  letter for the middle answer, and proves unknowns by substitution.
  If the letter is treated as a label ("n means notebooks"), re-teach
  with number-only equations first, then reintroduce letters.
- **After L3–L4:** learner names the operation shape before computing
  and estimates before trusting an answer. If estimates are demanded
  to equal exact answers, re-teach L4's "neighborhood" language —
  estimates are checked for tens, not ones.
- **After L5:** learner explains a pattern with a property (equal
  addends, ten-minus-one, doubling), not just "that's the rule," and
  can produce a counterexample to a false pattern.
- **After L6:** learner sorts facts honestly into Know it / Strategy /
  Practice. A hidden Practice pile is the only failure mode today —
  it means Session 13 cannot target the real gaps.
- **Unit readiness:** quiz 9–10, or assessment 12–14, with the project
  at 9+ rubric points. Below that, re-teach the missed objective's
  practice session, not the whole unit.

## Misconceptions and fixes

| Misconception | Fix |
|---|---|
| Adding all visible numbers (3 + 3 + 5) | Name what each number counts; build groups before combining (L1). |
| Answering only the hidden question (9 packs, not 45 pencils) | Re-read the original question last, every time (L1). |
| Letter as label, not number | Solve the same problem with ? first, then replace ? with n (L2). |
| Adding before multiplying in combined equations | Parentheses change meaning; stepwise equations first (L2). |
| Picking operations from numbers, not the story | Act out the story; ask "sharing, grouping, joining, or removing?" (L3). |
| Using extra numbers | Read the question first; cross out decorations after (L3). |
| Estimate must equal the answer | Judge by tens/neighborhood; defend any honest rounding (L4). |
| Pattern as magic trick, no why | Demand the property: equal addends, ten-minus-one, doubling (L5). |
| False patterns from two examples | Require three examples plus a counterexample test (L5). |
| Claiming memory for slow-counted facts | Three-sessions-instant rule before a fact leaves Strategy (L6). |
| Bare numbers with no unit | No mark without the unit in practice; full sentence in project (all). |

## Reteach paths

- **L1/L3 confusion:** return to counters for one full session; use
  only totals under 40 and one operation pair (multiply-then-add)
  until step-naming is automatic, then reintroduce the other shapes.
- **L2 unknowns:** keep the multiplication chart open for a full
  session; the chart is a tool, not cheating. Remove it only when the
  learner finds unknowns without it.
- **L4 reasonableness:** estimate *before* computing for a whole
  session, and score the estimate separately from the exact answer,
  so estimating is never punished for being inexact.
- **L5 patterns:** build the pattern with counters (4 groups re-sorted
  into 2 equal groups) before writing any digit-sum rule.
- **L6 fluency gaps:** the Session 13 stations *are* the re-teach —
  assign the learner's own Practice pile, not a generic worksheet.

## Midyear note (Week 18)

This unit ends the first half of the track. Session 16's assessment
includes two cumulative items (rounding from Unit 01, division from
Unit 03) precisely so the adult can see whether Units 01–04 hold
together before Unit 05 (fractions) introduces a new representation.
If cumulative items fail while new items pass, the gap is retrieval,
not understanding — use Session 13-style stations in the flexible
weeks, not a full re-teach.
