# Teacher Guide — Unit 01: Place Value, Rounding, and Multi-Digit Operations

**For the guiding adult.** Sessions are 30 minutes, four per week, for a
grade-3 learner. Review the [answer key](answer-key.md) before each session.
Never show the learner the key; solutions live only here and in the key.

## Misconception notes (by lesson)

- **L1 — zero-place slip:** writing 59 for 509 or 460 for 4 flats + 6 ones.
  Fix: the recipe chant ("hundreds, tens, ones") said aloud on every build.
- **L2/L3 — neighbor skipping:** rounding 296 to 290 without naming 290/300.
  Fix: require naming both neighbors before any digit rule.
- **L2/L3 — halfway hesitation:** treating "5 rounds up" as a guess. Fix:
  anchor on the number line first; the digit rule is the shortcut, not the
  reason.
- **L4 — forgotten carry:** writing a two-digit column sum into one place.
  Fix: circle every carry; re-do one problem aloud.
- **L5 — subtract-smaller-from-larger:** e.g., 8 − 2 = 6 in the ones of
  742 − 358. Fix: the addition check is non-negotiable — it catches this
  every time.
- **L5 — zero chain panic:** in 500 − 274, ungrouping across two zeros. Fix:
  practice the single trade chain (5 hundreds → 4 hundreds + 10 tens → 9 tens
  + 10 ones) with blocks before the column work.
- **L6 — "add a zero" magic:** 4 × 70 = 2800. Fix: ask "28 of what?" until the
  learner says "tens."

## Reteach decision table

| Signal | Reteach | With |
|---|---|---|
| Exit check fails on zero-place items (S1) | 15 min: build/take-apart with 0 tens and 0 ones | Blocks, recipe chant |
| Halfway rounding wrong on S5/S8 exits | 15 min: number-line walks only — no digit rule | Number-line strip, counters |
| Carries dropped on S9/S10 | 15 min: expanded-form addition side-by-side with columns | Blocks for 10→1 bundling |
| Ungrouping errors on S11/S13 | 15 min: trade-chain builds, then column, then addition check | Blocks |
| Quiz < 20/27 (S15) | Delay the unit assessment; re-teach the two lowest sections | Corresponding lesson + practice |
| Quiz 20–23/27 | Proceed; use S16 morning for a 10-min warm-up on missed items | Quiz errors |

## Readiness bands (unit assessment, 50 pts)

- **44–50:** ready for Unit 02 (multiplication concepts). Keep the rounding
  warm-up habit each session.
- **36–43:** proceed, but open each Unit 02 session with a 5-minute rounding or
  regrouping warm-up for two weeks.
- **Below 36:** do not start Unit 02. Re-teach the two lowest-scoring sections
  using the table above, then re-administer the missed sections only.

## Accessibility and pacing notes

- All lessons include an oral/pointing response mode and an adult-scribed
  option; written output is never the only path to showing understanding.
- If a session runs long, cut independent practice (not the worked examples or
  the exit check) and roll the cut items into the next practice session.
- The project is deliberately two-part: estimation and exact computation stay
  separate so the estimate cannot be back-filled from the answer.

## What comes next

Unit 02 builds on tens-as-units thinking (Lesson 06) to develop multiplication
as equal groups and arrays. Keep the rounding warm-up at the start of each
Unit 02 session — estimation is the unit's gift to the rest of the year.
