# Practice Sessions — Unit 01

Each session is about 25–30 minutes. The adult reads the directions, watches
for the listed success criterion, and marks the key in
[answer-key.md](answer-key.md#practice-sessions). Every count below is exact —
re-solve if a total looks surprising.

## Session A: Build-a-number trays

**Follows Lesson 01.**

**Goal:** read, write, and expand three-digit numbers from block builds.
**Materials:** base-ten blocks, number cards.

1. Build **274** with flats, rods, and ones. Write the numeral, number name,
   and expanded form.
2. Build **805**. Write the numeral, number name, and expanded form.
3. The adult builds **4 flats, 7 rods, 2 ones** behind a screen, then reveals
   it. Write the numeral and number name.
4. Write the numeral for the recipe "six hundred thirty-nine," then build it to
   check.
5. Expanded-form puzzle: 300 + 50 + 8 = ? Write the numeral and number name.
6. Expanded-form puzzle: 900 + 4 = ? Write the numeral and number name.

*Success criterion:* all six correct, including both zero-place items (2, 6).

## Session B: Market rounding trays

**Follows Lesson 02.**

**Goal:** round to the nearest 10 fluently, including halfway cases.
**Materials:** the market illustration, digit cards.

Use the [market illustration](lessons/lesson-02-rounding-to-the-nearest-10.md)
context: the counts below are a new morning's harvest totals (fictional practice
data).

1. Peaches: **52** → nearest 10.
2. Apples: **67** → nearest 10.
3. Pears: **45** → nearest 10.
4. Plums: **91** → nearest 10.
5. Grapes: **78** → nearest 10.
6. Round-then-compare: which basket rounds to the **largest** ten? Which two
   baskets round to the **same** ten?

*Success criterion:* all six correct, with the halfway rule stated for item 3.

## Session C: Place-value war and rounding races

**Game sessions for Sessions 3 and 7.**

**Goal:** fast, confident reading of three-digit numbers and quick rounding.
**Materials:** digit cards 0–9 (two sets), paper.

**Place-value war (Session 3):** Shuffle digit cards. Each player draws three
cards and builds a three-digit number (cards may be arranged freely), then
reads it aloud and writes it in expanded form. Higher number wins the round.
Play 6 rounds. *Success criterion:* every number read and expanded correctly.

**Rounding races (Session 7):** The adult calls a number; both players race to
hold up the correct rounded ten (first to the nearest 10). Call list:
**38, 71, 95, 124, 266, 350, 418, 587, 690, 744.** Ties go to the player who
can name the halfway point. *Success criterion:* at least 8 of 10 correct with
the halfway point named on ties.

## Session D: Build, draw, label review

**Review session (Session 4).**

**Goal:** consolidate Lesson 01; re-teach any insecure diagnostic skill.
**Materials:** blocks, paper.

1. Build **509**, draw it, and label each part (flats/rods/ones). Write all
   three forms.
2. Build **360**, draw it, and label each part. Write all three forms.
3. The adult dictates: "seven hundred two," "four hundred sixty," "nine
   hundred ninety-nine." Write each numeral, then build one of them to check.
4. Re-teach slot: the adult picks the weakest skill from Sessions 1–2 (per the
   [teacher guide](teacher-guide.md) reteach table) and does 10 minutes of
   targeted practice.

*Success criterion:* items 1–3 all correct; the re-teach target is named in the
adult's notes.

## Session E: Add-and-check stations

**Follows Lesson 04.**

**Goal:** add within 1000 with regrouping; verify by estimation.
**Materials:** paper, blocks (optional).

Solve each, then estimate by rounding both addends to the nearest ten and
confirm the exact sum is reasonable.

1. **245 + 378**
2. **507 + 249**
3. **436 + 129**
4. **682 + 275**
5. **190 + 803**
6. **546 + 367**

*Success criterion:* all six exact sums correct, and each estimate within 20 of
the exact sum with the "reasonable / re-check" call made aloud.

## Session F: Subtract-and-verify trays

**Session 13.**

**Goal:** subtract within 1000 with ungrouping; verify with addition.
**Materials:** paper, blocks (optional).

Solve each, then check by adding the answer to the subtracted number.

1. **623 − 258**
2. **500 − 274**
3. **742 − 185**
4. **810 − 463**
5. **906 − 537**
6. Mixed fluency: round **648** to the nearest 10 and nearest 100; compute
   **7 × 60**; estimate **489 + 302** by rounding to the nearest hundred.

*Success criterion:* all six items correct, with every subtraction checked by
addition and the mixed-fluency set fully correct.
