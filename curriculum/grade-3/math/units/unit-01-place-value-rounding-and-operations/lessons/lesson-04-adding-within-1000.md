# Lesson 04 — Add Within 1000

**Session:** 9 · **Time:** 30 minutes · **Goal:** I can add two three-digit
numbers by regrouping with place-value strategies and the column algorithm.

**Materials:** base-ten blocks, paper and pencil.

## Readiness check (3 min)

Mental warm-up: 300 + 200 = ? (500.) 60 + 50 = ? (110 — "eleven tens.") If
adding tens past 100 is shaky, practice 40 + 70, 60 + 80 with rods first.

## Explicit teaching (8 min)

When we add three-digit numbers, we add **place by place** — ones with ones,
tens with tens, hundreds with hundreds. Sometimes a place makes **ten or more**,
and ten of one place bundles into **one of the next place**: 10 ones become
1 ten, 10 tens become 1 hundred. That bundling move is called **regrouping**.

Two ways to see the same math:

- **Expanded form:** split each number into hundreds + tens + ones, add each
  place, then put the pieces back together.
- **Column algorithm:** write the numbers stacked, add each column starting
  from the ones, and carry the regrouped ten into the next column.

Both are correct; the column method is just the expanded-form method written
tightly. Start from the **ones** — you cannot know whether to carry until you
add them.

## Worked example 1 — 245 + 378

**Expanded form:**
- Hundreds: 200 + 300 = 500
- Tens: 40 + 70 = 110 (eleven tens — that's 1 hundred and 1 ten)
- Ones: 5 + 8 = 13 (one ten and 3 ones)
- Put together: 500 + 110 + 13 = 623

**Column:**
```
  245
+ 378
-----
  623
```
Ones: 5 + 8 = 13 → write 3, carry 1 ten. Tens: 4 + 7 + 1 = 12 → write 2,
carry 1 hundred. Hundreds: 2 + 3 + 1 = 6. **245 + 378 = 623.**

## Worked example 2 — 507 + 249 (with a zero)

**Expanded form:**
- Hundreds: 500 + 200 = 700
- Tens: 0 + 40 = 40
- Ones: 7 + 9 = 16
- Put together: 700 + 40 + 16 = 756

**Column:**
```
  507
+ 249
-----
  756
```
Ones: 7 + 9 = 16 → write 6, carry 1. Tens: 0 + 4 + 1 = 5 → write 5. Hundreds:
5 + 2 = 7. **507 + 249 = 756.** The zero tens are easy — but you still add the
carried 1.

## Guided practice (with hints)

1. **324 + 156** *(Hint: any column make ten or more?)*
2. **436 + 285** *(Hint: add ones first; watch the tens.)*
3. **190 + 476** *(Hint: 90 + 70 is sixteen tens.)*
4. **508 + 362** *(Hint: zero in the tens place — don't skip the carry.)*
5. **745 + 198** *(Hint: 198 is almost 200 — you can also try 745 + 200 − 2.)*

## Application

Mia read **187** pages last week and **256** pages this week. How many pages
did she read in all? Write the addition and solve.

## Exit check

1. **456 + 278 = ?**
2. Estimate first: round both numbers to the nearest ten, then add the rounded
   numbers. Is your exact answer close to your estimate?

*Success criterion:* the exact sum is correct and the estimate is within a few
tens of it. If the learner forgets to add the carried digit, circle the carry
and re-do one problem aloud.

## Supports and extension

- **Language access:** the adult reads each column aloud ("five ones plus
  eight ones is thirteen ones"); the learner writes the digit and the carry.
- **Alternate response mode:** build both addends with blocks, physically
  bundle ten rods into a flat, then count.
- **Extension:** find two different pairs of three-digit numbers that both add
  to exactly 1000, and explain how the carries work in each. (e.g.,
  456 + 544; 275 + 725.)

## Teacher note

Watch for the **forgotten carry** (writing the full two-digit column sum in one
place) and **column drift** (adding ones to tens). Block-building the same
problem after a wrong written answer usually exposes the slip in one step.
