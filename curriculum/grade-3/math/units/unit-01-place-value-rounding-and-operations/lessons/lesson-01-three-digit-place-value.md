# Lesson 01 — Hundreds, Tens, Ones: Re-Anchoring Three-Digit Numbers

**Session:** 1 · **Time:** 30 minutes · **Goal:** I can build and take apart
three-digit numbers with hundred-flats, ten-rods, and one-cubes, and read and
write them as numerals, number names, and expanded form.

**Materials:** base-ten blocks (or paper flats, straw bundles of ten, one-cubes),
number cards 100–999, paper and pencil.

## Readiness check (3 min)

Ask aloud: "Show me 3 tens and 5 ones with your blocks. What number is that?"
(35.) "Ten tens bundled together make what?" (One hundred — a hundred-flat.)
If the learner cannot bundle 10 tens into 1 hundred confidently, spend the
session on that idea with repeated bundling before moving to three-digit
writing.

## Explicit teaching (8 min)

A three-digit number is a **bundle recipe**: some hundreds, some tens, some
ones. The **hundred-flat** is worth 100, the **ten-rod** is worth 10, and the
**one-cube** is worth 1. The three **digits** of a numeral tell us how many of
each we have — the leftmost digit counts the hundreds, the middle digit counts
the tens, the rightmost counts the ones.

We can write a number three ways:

- **Numeral:** 243 (the digits)
- **Number name:** two hundred forty-three (words)
- **Expanded form:** 200 + 40 + 3 (each digit's true value, added up)

Say the recipe out loud as you build: "2 hundreds, 4 tens, 3 ones — that is
243." Zero matters: 0 tens means "no ten-rods at all," but the 0 still holds its
place so the other digits keep their jobs.

## Worked example 1 — Build 243

1. Read the digits: 2 in the hundreds place, 4 in the tens place, 3 in the ones
   place.
2. Take 2 hundred-flats, 4 ten-rods, 3 one-cubes. Lay the flats left, rods
   middle, ones right — same order as the digits.
3. Numeral: 243. Number name: two hundred forty-three. Expanded form:
   200 + 40 + 3.
4. Check: 200 + 40 + 3 = 243. The recipe matches the numeral.

## Worked example 2 — Take apart 5 flats, 0 rods, 9 ones

1. Count: 5 hundreds, 0 tens, 9 ones.
2. Numeral: 509 (the 0 holds the tens place; do not drop it).
3. Number name: five hundred nine.
4. Expanded form: 500 + 9. Note we write 500 + 0 + 9 = 500 + 9; the zero-tens
   contribute nothing, but the 0 in the numeral keeps the 5 and 9 in the right
   places.
5. Common slip: writing 590 or 59. Say the recipe — "five hundred nine" —
   while pointing at each block to keep the places straight.

## Guided practice (with hints)

Work through these together; the adult gives the hint, the learner does the
writing.

1. Build **315** with blocks. Write the numeral, the number name, and the
   expanded form. *(Hint: say "three hundred fifteen" slowly and take one block
   kind per word-group.)*
2. Write the expanded form of **428**. *(Hint: cover the last two digits — what
   is the 4 worth?)*
3. Take apart **6 flats, 2 rods, 8 ones**. Write the numeral. *(Hint: one digit
   per block kind, in order.)*
4. Write the number name for **910**. *(Hint: the tens digit is 1 — say it
   first, then the zero.)*
5. Which build shows **504**? (a) 5 flats, 4 ones (b) 5 flats, 4 rods.
   *(Hint: 504 has 0 tens — where would 4 rods go?)*

## Independent practice

6. Write the expanded form of **762**.
7. Write the numeral for **"three hundred forty-eight"**.
8. Write the number name for **205**.
9. Describe, in words or with a quick sketch, how to build **891**.
10. Take apart **7 flats, 0 rods, 3 ones**. Write the numeral and the expanded
    form.
11. Error analysis: Sam built **4 flats and 6 ones** and wrote **460**. What
    did Sam mix up? What should the numeral be?

## Application

You may use only the digits **2, 5, 9** — each exactly once. Make the largest
three-digit number you can, then the smallest. Explain which digit you put in
the hundreds place each time, and why.

## Exit check

1. Write **637** in expanded form.
2. Take apart **3 flats, 8 rods, 1 one**. Write the numeral.

*Success criterion:* both exit items correct with the right place-value
reasoning. If the zero-tens item trips the learner, revisit Worked example 2
before Session 2.

## Supports and extension

- **Language access:** let the learner dictate the number name while the adult
  scribes, then the learner points to each digit as they read it back.
- **Alternate response mode:** build everything with blocks and answer
  orally; the adult records the written forms.
- **Extension:** build the number that is 100 more than 486 and the number that
  is 10 less than 486, then write both in expanded form. (586 = 500 + 80 + 6;
  476 = 400 + 70 + 6.)

## Teacher note

The classic grade-3 misconception is the **zero-place slip** (writing 59 for
509, or 460 for 4 flats + 6 ones). Learners who say numbers fluently but write
them wrong almost always skip saying the zero's place aloud. The fix is the
recipe chant — hundreds, tens, ones — said on every build until the zero holds
its place automatically. Answer key: [answer-key.md](../answer-key.md#lesson-01).
