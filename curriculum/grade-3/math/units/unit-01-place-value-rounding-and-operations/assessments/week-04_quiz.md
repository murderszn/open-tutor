# Formative Quiz — Unit 01 (Session 15)

**Time:** 20 minutes · **Points:** 27 · **Covers objectives 2, 3, 4, 5**

The adult reads each item aloud if needed; the learner writes the answers. This
quiz checks readiness for the unit assessment — score below 20 and re-teach per
the [teacher guide](../teacher-guide.md) before Session 16.

**1.** Round **47** to the nearest 10. (2 pts)

**2.** Round **385** to the nearest 100. (2 pts)

**3.** Round **562** to the nearest 10. (2 pts)

**4.** **436 + 285 = ?** Show the column work. (3 pts)

**5.** **700 − 346 = ?** Show the column work. (3 pts)

**6.** **6 × 40 = ?** Write the tens-as-units reasoning. (3 pts)

**7.** Estimate **298 + 512** by rounding both numbers to the nearest 100, then
write the estimate. (4 pts)

**8.** Ana says: "358 rounded to the nearest 100 is 300, because the tens digit
is 5 and I round down." Do you agree? Explain in one or two sentences. (4 pts)

**9.** The school collected **237** cans in October and **386** cans in
November. (a) Estimate the total by rounding each number to the nearest 100.
(b) Find the exact total. (4 pts: 2 for the estimate, 2 for the exact total)
