# Resource Pack — Unit 01: Fair Tests, Measurement, Data, and Explanations

**Goal (one sentence):** Give the guiding adult short, grade-3-appropriate
videos, references, and search routes that reinforce testable questions,
standard measurement, fair-test structure, and data displays.
**Age fit:** grade 3 (ages 8–9); the adult previews every video and
co-views with the learner.
