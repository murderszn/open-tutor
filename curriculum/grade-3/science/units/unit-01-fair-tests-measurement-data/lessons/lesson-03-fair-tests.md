# Lesson 03 — Fair Tests: Change One Thing

**Time:** 25–30 minutes · **Materials:** science journal, pencil, the
fair-test step cards (question → one change → keep-same list → 3 trials →
table → claim), toy car, book ramp, two surface cloths

**Goal (read to the learner):** Today you will learn the rule that makes a
test *fair* — change only **one thing** — and you will use it to judge two
test setups in a picture.

**Readiness check:** Adult asks, "Yesterday we measured carefully. Why do
scientists repeat a measurement instead of trusting one try?" Any answer
about checking or mistakes shows readiness. (Answer: one try could be a
fluke; repeats show a pattern.)

## Teaching (adult reads and models)

A test is **fair** when it changes only **one thing** and keeps everything
else the same. Scientists call the one changed thing the **variable** and
the things kept the same the **controls**. Then, whatever changes in the
result must be because of the one thing you changed.

Imagine the question: *"Does the surface change how far the toy car
rolls?"* A fair plan:

- **Change:** the surface — bare wood, then a towel.
- **Keep the same:** the same car, the same ramp, the same ramp height, the
  same release point, no pushing — release it the same way every time.
- **Repeat:** roll 3 times on each surface (**trials**), because one roll
  might be a lucky bounce.
- **Record:** every distance in a table, in centimeters, starting the ruler
  at 0 (Lesson 02's ritual).

If instead you rolled the car on the towel from a *low* ramp and on the bare
wood from a *high* ramp, you changed **two** things. If the car rolls
farther, you cannot tell whether it was the surface or the height. That test
is **unfair** — and an unfair test cannot answer its question.

**Worked example 1 — a fair plan, built out loud:**

> Adult: "Question: *Does ramp height change how far the car rolls?*
> The **one thing I change** is the ramp height: low, then high. What stays
> **the same**? The same car, the same ramp, the same surface, the same
> release point, no pushing. I roll **3 trials** at each height and write
> every distance in a table. Fair — one change, everything else the same."

**Worked example 2 — an unfair test, caught and fixed:**

> Adult: "Question: *Which ball bounces higher — the tennis ball or the
> rubber ball?* First I tried it wrong: I dropped the tennis ball from my
> shoulder and the rubber ball from my knee. Two changes — the ball AND the
> drop height. Unfair! So I fixed it: I drop **both** balls from my
> shoulder. Now only the ball changes. Fair."

Key idea to say plainly: **One change, everything else the same, repeated
trials. If you changed two things, you learned nothing.**

**Your task:** With the adult, decide for each station: fair or unfair?
Name the one change (if fair) or every extra change (if unfair).

- Left station: **fair** — the only change is the surface (bare wood vs.
  towel). Same height, same car, same release.
- Right station: **unfair** — three things change: the ramp height, the
  surface (bare vs. cloth), and the object (car vs. ball).

## Guided practice (adult leads, learner judges and fixes)

For each, the learner says fair or unfair, names the problem, and says how
to fix it.

1. "Does the car color change roll distance? I roll a red car and a blue
   car from the same height on the same ramp." *(fair — one change: color)*
2. "Which towel absorbs more? I pour one spoon of water on towel A and three
   spoons on towel B." *(unfair — water amount also changes; fix: same
   spoons of water on each)*
3. "Does ramp height matter? I roll the same car from a low ramp and a high
   ramp, same surface, no push, 3 trials each." *(fair)*
4. "Do plants need light? One plant by the window, one in the closet, both
   watered the same, same kind of plant." *(fair — one change: light)*
5. "Which ball rolls farther? A marble from a tall ramp and a basketball
   from a short ramp." *(unfair — ball AND height change; fix: same ramp
   height for both)*
6. "How many paper clips can a magnet pick up? I test the same magnet 3
   times and write each count." *(fair — and it changes nothing, which
   checks that the result repeats: repeated trials)*

## Independent practice

The learner picks a testable question from Lesson 01 and writes a fair-test
plan: the question, the **one change**, **two things to keep the same**,
and how many trials. Sentence frame: "My test is fair because I only change
___, and I keep ___ and ___ the same."

## Application

Revisit the unfair right-hand station in the picture. Draw or describe a
fixed version: change only **one** of its three differences and make the
other two match. (Any one of: same height, same surface, or same object —
with the other two equal — is an acceptable fair redesign.)

## Exit check

Prompt: "Your friend changed the ramp height AND pushed the car on the
second try. Is the test fair? Why not?" Accept: unfair — two things changed,
so we cannot tell which caused the result.

## Supports and extensions

- **Support:** Use the fair-test step cards as a checklist for every item.
  Let the learner sort "change" vs. "keep the same" word cards physically.
- **Extension:** The learner explains *why* 3 trials beat 1 trial using the
  word "pattern" — and names one failure point to watch for (car falls off
  the ramp; towel slips) and how to prevent it (3-5-ETS1-3's "consider
  failure points").

## Teacher note

**Likely misconception:** "fair" meaning "nice" or "equal turns." Re-anchor:
in science, fair means *only one thing changes*. Also watch for learners
who name a control but then change it mid-test — the step cards prevent
this. **Answer-key reference:** [answer-key.md](../answer-key.md)
(Lesson 03).
