# Teacher Guide — Unit 02: Balanced and Unbalanced Forces and Motion

**For the guiding adult.** Student materials never contain answers; all
solutions live in [answer-key.md](answer-key.md). This guide covers
session-by-session notes, the review game, re-check stations, readiness
signals, and reteach paths.

## Unit at a glance

- **Core idea:** Forces are pushes or pulls with direction and relative
  strength. Balanced (equal, opposite) → no change in motion. Unbalanced →
  motion changes (start, stop, speed up, slow down, change direction).
  Friction opposes motion. Motion patterns let us predict.
- **Standard honoring:** Every investigation and assessment item changes
  **one variable at a time** and compares force strength only as
  stronger/weaker — never numbers (3-PS2-1 boundary). Gravity appears only
  as "pulls objects down." No period/frequency vocabulary (3-PS2-2
  boundary).
- **Reused from Unit 01:** the fair-test routine (one change, rest same,
  3+ trials), the measure-from-zero ritual, labeled tables, and the
  claim-with-evidence-and-limitation frame.

## Session notes

- **Session 1 (Lesson 01):** Keep the push/pull demos on the *same*
  object so strength comparisons are fair. If the learner confuses object
  size with force strength, redo the gentle-vs-firm push on one car.
- **Session 3 (Lesson 02):** The book-on-table moment is the conceptual
  payoff — pause on it. Ask: "Is gravity still pulling *right now*?" before
  revealing the table's balancing push.
- **Session 5 (Lesson 03):** Use the generated image
  ([assets/tug-of-war-balanced-unbalanced.png](assets/tug-of-war-balanced-unbalanced.png))
  with its text-only alternative; let the learner do the
  identifying before you confirm. Stress the one-variable reading: the
  *number* of pullers changed between scenes.
- **Session 7 (Lesson 04):** The bowl-and-marble demo is the 3-PS2-2
  anchor. Count passes aloud together; let the learner own the prediction.
- **Session 8 — Review game: force-sort relay.** Prepare 8 scene cards
  (tug tie, one team winning, book on table, kicked ball, equal box
  pushes, car slowing on grass, swing mid-swing, marble in bowl). The
  learner sorts each into Balanced / Unbalanced / Pattern-predict piles,
  naming the reason. 6 of 8 with reasons = mastery signal.
- **Session 9 (Lesson 05):** Run the two-surface race yourself first to
  get clean demonstration values; record them as *your* observed data and
  label them as such if the learner copies them into practice.
- **Sessions 10–11 (Project):** Approve the written plan before any
  launch. Common plan flaw: changing push strength *and* release point —
  send it back for one variable. The adult demonstrates "gentle" and
  "firm" once and holds those definitions constant.
- **Session 14 (Showcase):** Each talk is 2 minutes: plan, claim with two
  data values, target-zone result, one redesign. Applaud the limitation —
  naming it is the Unit 01 skill carrying forward.
- **Session 15 — Investigation re-check stations.** Four quick stations:
  (1) predict-then-watch the marble pattern; (2) balanced or not? (book +
  finger-push); (3) friction ranking of three surfaces by touch; (4) the
  adult drops two different-weight balls from the same height — both land
  together; learner explains with "gravity pulls both down." 3 of 4
  correct with reasons = readiness signal. (Station 4 is observation
  only — the adult handles all drops.)

## Readiness and reteach

- **Ready for Unit 03:** quiz ≥ 7/10, assessment ≥ 20/24, project ≥ 13/15,
  and the learner can explain a tug-of-war tie *and* a win using
  "balanced/unbalanced."
- **If balanced vs. unbalanced is shaky:** replay the tug game with the
  learner calling "balanced/unbalanced" after every round; rebuild the
  equal-arrows vs. unequal-arrows drawings; re-sort the relay cards.
- **If motion-change vocabulary is shaky:** use the chant card (start,
  stop, speed up, slow down, turn around) with acted demos until naming
  is automatic.
- **If friction confuses:** return to the hands-rubbing demo and the
  two-surface race; keep language at "more/less friction," never numbers.
- **If predictions are guesses:** redo Lesson 04's count-and-predict with
  the learner writing the prediction *before* the second run; contrast
  with a true guess ("what color is the next car outside?") that has no
  pattern behind it.
- **Extension path:** the learner designs a second one-variable test
  (e.g., ramp height vs. distance — connecting back to Unit 01) or
  explores the PhET sim's friction setting with the adult.

## Common misconceptions (all lessons)

| Misconception | Correction move |
|---|---|
| Still object = no forces | Book on table: gravity pulls down *now*; the table pushes back |
| Stronger means bigger object | Compare two pushes on the *same* object |
| Prediction = guess | Prediction cites the observed pattern as evidence |
| Friction only on rough things | Smooth surfaces have *some* friction, just less |
| Motion change needs no force | "Something stopped/started it — find the unbalanced force" |
