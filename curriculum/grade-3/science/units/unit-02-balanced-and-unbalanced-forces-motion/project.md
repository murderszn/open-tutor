# Project — The Target-Zone Launch

**Type:** fair investigation (3-PS2-1) · **Time:** two 30-minute sessions
(plan + run), plus a showcase talk · **Adult role:** sets and checks every
ramp; supervises all launches; approves the plan before trials begin

## The challenge

Build a launcher (a book ramp at a fixed height) and find out: **does a
stronger launch push make the toy car roll farther?** Then use what you
learn to land the car inside a **target zone** taped on the floor — with
evidence, not luck.

## Materials

Toy car, short board or stiff cardboard ramp, books (adult sets the stack),
tape measure or ruler with centimeters, masking tape for the target zone,
two surface cloths (bare board and towel — reused from Lesson 05),
science journal, pencil. The adult keeps the ramp height and release point
identical for every trial.

## Steps

1. **Ask the testable question:** "Does a stronger launch push make the
   car roll farther?" Write it in the journal.
2. **Plan the fair test** (adult approves before any launch):
   - **Change (one variable):** push strength — *gentle* vs. *firm*. The
     adult demonstrates both strengths once so "gentle" and "firm" mean
     the same thing every trial.
   - **Keep the same (controls):** the same car, the same ramp, the same
     ramp height, the same release point, the same surface, no extra
     pushes after release.
   - **Repeat:** 3 trials at each push strength.
   - **Measure:** distance from the ramp's bottom edge to where the car
     stops, in centimeters, ruler starting at 0 (Unit 01's ritual).
3. **Record** every distance in a labeled table:

   | Push strength | Trial 1 (cm) | Trial 2 (cm) | Trial 3 (cm) |
   |---|---|---|---|
   | Gentle | | | |
   | Firm | | | |

4. **Run the trials.** The adult launches or directly supervises each
   launch. No aiming tricks — the car must roll straight off the ramp.
5. **Make a claim** using Unit 01's frame: "My claim is ___. My evidence
   is ___ and ___. One limitation is ___."
6. **Apply it:** tape a target zone on the floor (about 30 cm wide) at a
   distance the adult chooses. Using your evidence, choose *gentle* or
   *firm* and predict whether the car will land in the zone. Run 3
   prediction trials and record hits/misses.
7. **Showcase talk (2 minutes):** show the table, state the claim with two
   data values, report the target-zone hits, and name one redesign (e.g.,
   "a medium push," "a longer ramp run-up," "a smoother surface").

## Deliverables

- The approved plan (question, one variable, two or more controls, trial
  count).
- The completed data table with units.
- The written claim with two evidence values and one limitation.
- The target-zone prediction record (3 trials: hit or miss each).
- The 2-minute showcase talk.

## Rubric

| Criterion | 3 — Strong | 2 — Developing | 1 — Starting |
|---|---|---|---|
| Fair-test plan | One variable named; 2+ controls named; 3 trials planned | One variable named; 1 control named | Variable or controls missing |
| Data table | All 6+ trials recorded with cm units, labeled | Most trials recorded; units inconsistent | Table incomplete or unlabeled |
| Claim + evidence | Claim names the effect; cites 2 data values; names 1 limitation | Claim with 1 data value; limitation missing | Claim with no data |
| Target-zone prediction | Prediction stated before trials; hits/misses recorded for all 3 | Prediction after trials or partial record | No prediction or no record |
| Showcase talk | Explains plan, claim, and one redesign clearly | Covers plan and claim; redesign vague | Missing major parts |

**Scoring:** 13–15 = ready to move on; 10–12 = solid with one reteach
target (see teacher guide); below 10 = redo the investigation with adult
support, then re-score. Sample strong responses are in
[answer-key.md](answer-key.md#project-sample-responses).
