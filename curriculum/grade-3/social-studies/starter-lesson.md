# Starter Lesson — Read a map and ask a community question

**Status:** draft supplement. **Time:** three 30-minute sessions. **Goal:** Use a map key and compass rose, separate a map observation from an inference, and ask an evidence-seeking question about a fictional community need.

## Adult preparation and readiness

Use the fictional map and pencil. Do not ask for real addresses, routes, or personal needs. Readiness: learner understands a map key or can follow a finger-traced row/column.

```text
N ↑
┌──────────────┐
│ L     P     C│
│              │
│ S     M     H│
└──────────────┘
Key: L library; P park; C clinic; S school; M market; H homes
```

## Teach and model

Explain that a map gives selected information from above; a key explains symbols and a compass rose helps describe direction. Observation = what the map shows; inference = idea based on it.

**Worked example 1:** Observation: “The clinic is north of homes in this sketch.” Inference: “The clinic may be busy.” The map shows relative location, but it provides no evidence about how many people visit.

**Worked example 2:** Fictional note: “Several residents say the path to the clinic is hard to use after rain.” Evidence is that the note reports what some residents said; it does not prove every resident has the same experience.

## Pacing and tasks

Session 1: adult models map key/direction; guide tasks 1–2. Session 2: learner completes observation/inference tasks 3–4. Session 3: discuss the civic question, error-check, and produce recommendation.

1. **Guided:** Which symbol is west/left of homes? Which is north of homes?
2. **Guided:** Name what the map does not show (distance, street names, slope).
3. **Independent:** Label this sentence observation or inference: “The clinic is north of homes”; “The clinic is the busiest place.”
4. **Independent:** Ask one question that would help decide whether a path improvement is useful.
5. **Adult-guided error check:** Learner claims “everyone needs the path” from “several residents.” Explain the overgeneralization.
6. **Application:** Recommend what evidence to gather next and explain why.

**Answer checks:** 1) market west/left, clinic north; 2) any omitted feature; 3) first is directly observable in the map, second is an inference unsupported by the map; 4) e.g., how many people use it, when/what makes access difficult; 5) “several” is not “everyone”; 6) answers should seek more than one perspective or measure.

## Exit check and product

Learner states one observation, one question, and one next step. Product: annotated map and a short evidence plan.

## Review rubric

| Criterion | 2 — shows skill | 1 — developing | 0 — not yet observed |
|---|---|---|---|
| Map reading | Uses key and direction accurately | Correct with tracing | Revisit symbols and arrow |
| Source reasoning | Distinguishes observation and inference | Labels with prompt | Model a second example |
| Inquiry | Proposes a relevant question/evidence step | Names a concern only | Offer question stems |

Use tactile map pieces, large print, dictated answers, or adult read-aloud. The map and note are fictional; offline work is complete. Avoid treating a map as to scale or inferring residents' identities, accessibility status, or views beyond the source.
