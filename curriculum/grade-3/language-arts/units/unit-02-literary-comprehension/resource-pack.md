# Resource Pack — Unit 02: Literary Comprehension (Character and Theme)

**Goal:** Give the guiding adult vetted starting points for fable read-alouds,
theme/character teaching, and idiom work with third graders (ages 8–9).
**Core learning in this unit needs no account:** every required reading
passage is printed in the lessons themselves; external resources below are
supplementary.

## Web references (checked 2026-10-17 unless noted)

1. **Library of Congress — "Aesop for Children" interactive eBook**
   http://read.gov/aesop/about.html — **Verified 2026-10-17** (page opened;
   confirms the collection is adapted from *The Aesop for Children*,
   Rand McNally 1919, considered public domain in the US, with interactive
   illustrations). Adult-supervised read-alouds of additional fables;
   no account. Pair with Lesson 02/03 recount and message work. Note: the
   1919 language is denser than this unit's retellings — preview before
   assigning.
2. **Common Core State Standards — English Language Arts**
   https://www.thecorestandards.org/ELA-Literacy/ — Standards source cited
   in the track audit (issue #20 A00 crosswalk, `scope-and-sequence.md`
   §3); **not re-opened this run** — codes RL.3.1–3.10 and L.3.5.a are used
   exactly as cross-walked there. Adult reference only.
3. **`resources/language_arts_literary_terms.md`** (this repo) — adult
   vocabulary reference for *theme, point of view, moral*; **do not assign
   to the learner** (grade-fit note from the A00 audit).
4. **`resources/language_arts_great_books_and_stories.md`** (this repo) —
   teacher-side list of fable/folktale candidates; use only the
   public-domain Aesop entries, never the guide's summaries as learner text.
5. **ReadWorks** (readworks.org) — large free passage library with
   comprehension sets; **adult-side, teacher account required** — not the
   no-account route. Useful if the adult wants extra leveled fable passages
   beyond the unit. **Not verified this run** (listed as a search starting
   point, not a recommendation of specific content).
6. **Your local public library** — ask a children's librarian for
   single-author fable/folktale collections for the Week 10 compare/contrast
   session (RL.3.9). No link; the most reliable no-screen route.
