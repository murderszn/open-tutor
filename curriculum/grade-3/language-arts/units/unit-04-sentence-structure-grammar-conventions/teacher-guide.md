# Teacher Guide — Unit 04 (Adult Only)

This guide is for the guiding adult. It does not replace the
[answer key](answer-key.md), which holds every solution.

## How to teach this unit

- Teach one lesson, then practice, before moving on. Grammar terms
  stick when the learner uses them the same day, not when they are
  memorized in a list.
- Always start from the job, not the label: "What is this word
  doing?" comes before "What is it called?"
- Accept oral, pointing, card-sort, and written answers equally.
  The objective is the grammar decision, not handwriting volume.
- Sessions are 25–30 minutes. If a lesson runs long, split it: teach
  on day one, practice on day two, and shift the pacing table by one
  session rather than rushing.

## Lesson-by-lesson notes

### Lesson 01 — Parts of speech

- **Watch for:** calling every describing word an adjective. Use the
  test: describes a noun → adjective; tells how/when/where about a
  verb → adverb.
- **Watch for:** *-ly* = adverb, always. Counterexample: *lovely day*
  (*lovely* describes *day*, so it is an adjective).
- **Reteach:** sort the same ten words three times, faster each time,
  before re-testing.

### Lesson 02 — Plurals, verbs, agreement

- **Watch for:** "childs", "foots" (rule over-applied to exceptions).
  Praise the rule, then post the irregular list where the learner
  can see it.
- **Watch for:** "The dogs runs" (the *-s* feels plural). Drill pairs
  aloud: *dog runs / dogs run; she has / they have*.
- **Reteach:** build a personal irregular wall: *child/children,
  foot/feet, tooth/teeth, mouse/mice, man/men, woman/women, go/went,
  see/saw, eat/ate, run/ran, teach/taught, catch/caught*.

### Lesson 03 — Comparisons and conjunctions

- **Watch for:** "more taller" (double comparison). Rule: one marker
  only — *taller* or *more beautiful*, never both.
- **Watch for:** *-est* for two things. Return to the count test:
  two → comparative, three or more → superlative.
- **Reteach:** line up three objects and describe them aloud before
  writing anything.

### Lesson 04 — Sentence types, word choice, spoken vs. written

- **Watch for:** "longer = complex." Length is not the test; clause
  type is. A long simple sentence is still simple.
- **Watch for:** comma splices ("It was windy, we flew kites.").
  Fix by adding a conjunction or splitting the sentence.
- **Reteach:** build sentences from clause cards (independent cards
  one color, dependent cards another) until the learner can feel the
  difference between a clause that stands alone and one that waits.

### Lesson 05 — Titles, addresses, dialogue, possessives

- **Watch for:** capitalizing every title word. Chant: "First, last,
  and important — the rest stay small."
- **Watch for:** *it's* for possession. Test: "Can I replace it with
  *it is*? If yes, *it's*. If no, *its*."
- **Reteach:** punctuate the same dialogue three ways (tag first,
  quote first, tag in the middle) on three days.

### Lesson 06 — Spelling and dictionary

- **Watch for:** applying one suffix rule to every word. Order:
  look at the base word's ending first, then choose the rule.
- **Watch for:** guide-word guessing by first letter only. Model the
  letter-by-letter check (second letter, then third) every time until
  it is automatic.
- **Reteach:** the minimal pair *hoping / hopping* — one letter
  changes the meaning — then a five-word doubling drill.

## Session 15 — Midyear review and reteach

Session 15 is both Unit 04 reteach and a midyear revisit of Units
01–03. Spend about 15 minutes on the two weakest quiz skills
(re-answer two missed items correctly), then about 10 minutes on
one quick revisit from each earlier unit:

- **Unit 01 (word analysis):** read five multisyllable words aloud;
  name one prefix or suffix in each.
- **Unit 02 (literary comprehension):** retell a familiar story's
  central message in one sentence, naming one key detail.
- **Unit 03 (informational reading):** state the main idea of a
  three-sentence passage and point to one supporting detail.

Record what still needs work; it becomes the Unit 05 starting point.

## Scoring and next steps

- **Formative quiz (13 points):** 12–13 = ready for Unit 05;
  9–11 = reteach the missed skill in Session 15; below 9 = reteach
  two skills and re-quiz with the Practice Sets before the
  assessment.
- **Culminating assessment (40 points):** 36–40 = strong;
  28–35 = ready with one reteach note; below 28 = reteach the two
  weakest parts before Unit 05.
- **Project (40 points):** 32–40 with all three sentence types
  present = ready. Below 32 = reteach the weakest rubric row with
  the matching lesson before Unit 05.
- **Readiness for Unit 05 (narrative writing):** the learner can
  build and label the three sentence types, punctuate one line of
  dialogue, and explain one revision choice in a complete sentence.
  Spelling may still be developing; it is not a gate for Unit 05.

## Simplifications in this unit (say so, do not hide them)

- Conjunction lists are the grade-3 subset (*and, but, or, so*;
  *because, when, before, after, if, while*), not the full adult
  lists. The full FANBOYS set and relative pronouns arrive in later
  grades.
- Title capitalization follows the common school rule (first, last,
  and important words); professional style guides differ on small
  words such as *that* and *with*. The unit's examples avoid those
  edge cases.
- All addresses in lessons, practice, and assessment are fictional
  examples. No learner's real address is used anywhere in this unit.
