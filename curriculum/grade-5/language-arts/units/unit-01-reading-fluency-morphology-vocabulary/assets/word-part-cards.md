# Shared Grade-5 Word-Part Cards

**The shared cross-unit grade-5 card set, created once in U01.**
Later grade-5 units reference this file rather than recreating the
cards; if a later unit needs new cards, it extends this file.

These are deterministic text cards meant to be **printed or copied by
hand** onto index cards. One card per row: cut along the lines, fold
if you like. Front = the word part; back = meaning + hook word.

## Word-meaning strategy cards (4)

| Front | Back |
|---|---|
| Clue → Parts → Verify | 1. Name the context-clue type and guess. 2. Cross-check with prefix/root/suffix. 3. Confirm in a dictionary. Never skip to the dictionary first. |
| The meaning test | Cover the word part. Is the rest a real word? Does the part's meaning make sense inside the whole word? No to either → not that part. (*uncle* is not *un-* + *cle*.) |
| Dictionary entry map | Headword → part of speech → pronunciation → numbered senses (most common first). The *sentence* picks the number, not the dictionary's order. |
| Swap-and-check | A thesaurus synonym must fit the *sentence*, not just the dictionary. Read the full sentence aloud with the swap — if it sounds wrong, reject it. |
