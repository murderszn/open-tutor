# Unit 01 — Consolidated Practice Sets

Extra practice keyed to each lesson. The adult assigns what the learner
needs; nothing here is required in full. Every item is solved in the
[answer key](answer-key.md#practice-sets).

## Set A — Fluency (Lesson 01)

**A1. Phrasing marks.** Re-read "The Night of the Lanterns" (in
[Lesson 01](lessons/lesson-01-fluency-accuracy-rate-expression.md)) and
draw a slash (/) where your voice naturally pauses. Then read it again
following your slashes. Do your slashes land on punctuation and meaning
breaks?

**A2. Voice matching.** Read the mayor's two exclamations three ways:
as a whisper, as a command, as a plea. Which matches the story's mood?
Write one sentence explaining your choice.

**A3. Self-correction drill.** The adult reads a paragraph of the
passage with 3 planted errors (a swapped word, a skipped word, a
misread). Stop the adult at each error, name what went wrong, and
supply the fix.

## Set B — Prefixes (Lesson 02)

**B1. Disguise hunt.** Sort into in-/im-/il-/ir-: *incorrect,
immature, illogical, irresponsible, independent, impatient*. For each,
name the letter that forced the spelling.

**B2. Build and flip.** Build 4 words: *re-* + *build*; *dis-* +
*agree*; *over-* + *sleep*; *mis-* + *spell*. Then "flip" each meaning
back: what would the word mean *without* the prefix?

**B3. Fake-prefix patrol.** Which of these have a real prefix?
*unhappy, uncle, restart, restore, preview, previous.* For each fake,
explain why it fails the meaning test.

## Set C — Suffixes (Lesson 03)

**C1. Job change.** For *darkness, teacher, quickly, readable*: name
the base, the suffix, the new part of speech, and use each in a
sentence that proves the part of speech.

**C2. Spelling-move drill.** Add the suffix and apply the move:
*hope* + *-ful*; *carry* + *-ed*; *swim* + *-er*; *celebrate* +
*-tion*. Name the move used each time (drop e / double / y→i / none).

**C3. -able vs. -ible sort.** Sort into -able / -ible: *breakable,
visible, washable, terrible, comfortable, flexible*. Then write the
honest rule: is there a sound rule, or is this a memorize-and-verify
spelling?

## Set D — Roots (Lesson 04)

**D1. Root families.** For *dict-* and *port-*, list 4 words each from
the unit set or your reading. Write the assembled meaning of each.

**D2. Cross-root build.** Build one word for each meaning using the
eleven roots (bonus prefixes allowed): "see far" (*telescope* is taken
— find another); "write before"; "pull toward"; "say before." Verify
each with the meaning test.

## Set E — Context clues, dictionary, precise words (Lesson 05)

**E1. Mixed clue hunt.** "The **arid** desert, where rain almost never
falls, stretched for miles." / "She was **elated**, in fact she had
never been happier." Name each clue type and meaning.

**E2. Dictionary duel.** Look up **novel** (noun vs. adjective). Write
two sentences — one for each part of speech — and name the numbered
sense you used each time.

**E3. Precision rewrite.** Rewrite this paragraph replacing every vague
word (underlined) with a precise one, then defend two choices with the
swap-and-check: "The **big** storm made a **big** sound. She **walked**
to the window and **looked** out. 'That's **good**,' she **said**."
