# Unit 02 Resource Pack — Literary Theme, Perspective, and Character Development

**Summary:** A grade-5 literature unit on theme, character change, and
narrator point of view. All core learning is carried by the unit's two
original stories and taught lessons — no account, purchase, or outside
book is required. The resources below are adult-selected supplements:
verified pages the adult previewed, plus clearly labeled search links
for video. (Adult planning judgment; checked 2026-10-18.)

- `resources/language_arts_literary_terms.md` — teacher-side terminology
  reference (theme, point of view, characterization); never assigned to
  the learner (per the track audit).

## Web references (reputable; adult previews before assigning)

1. **ReadWriteThink — "Using Picture Books to Teach Characterization in
   Writing Workshop"** (lesson plan with the "Three Elements of
   Characterization" handout: appearance; actions/speech/behavior;
   interactions). Direct page verified 2026-10-18 (page opens; session
   plan, handouts, and NCTE standards listed):
   https://www.readwritethink.org/classroom-resources/lesson-plans/using-picture-books-teach
   — *Use:* Lesson 02's direct/indirect characterization teaching; the
   three-elements handout mirrors this unit's says/does/thinks framework.
2. **Maryland Thinkport — "Read Like This: Determining Theme in Literary
   Texts"** (Learn It module: track details, repetition, and symbols to
   infer theme). Content confirmed via search snippet 2026-10-18; adult
   should open and preview before assigning:
   https://ela.thinkport.org/mod4/learn-it.html
   — *Use:* Lesson 01 extension; the "look for repetition of details"
   hint reinforces the theme-evidence chart.
3. **EreadingWorksheets.com — Theme Lesson 2** (theme anchor-standard
   progression RL.1.2 → RL.11-12.2, with the grade-5 wording matching
   this unit's RL.5.2). Standard text confirmed via search snippet
   2026-10-18: https://ereadingworksheets.com/worksheets/reading/theme/theme-lesson-02/
   — *Use:* adult reference for the RL.5.2 standard wording; do not
   assign worksheets without previewing grade fit.
4. **Reading Rockets — comprehension topic hub** (research-based articles
   on teaching comprehension, including theme and point of view):
   https://www.readingrockets.org/topics/comprehension
   — *Use:* adult background; search within for "theme" lesson ideas.
   (Hub URL is the stable topics page; specific articles should be
   opened and previewed individually.)
5. **Library of Congress — Classroom Materials** (primary sources; useful
   when the unit's extension compares story themes to historical
   narratives): https://www.loc.gov/classroom-materials/
   — *Use:* extension only; not required for core objectives.
6. **Purdue OWL — Writing about Literature** (paragraph structure,
   quoting and citing): https://owl.purdue.edu/
   — *Use:* adult reference for Lesson 05's claim–evidence–explanation
   structure. (General OWL landing; navigate to the literature-writing
   section.)

**Free, no-account routes for every core objective:** the two original
stories + taught lessons (objectives 1–6); the ReadWriteThink lesson page
and Thinkport module open without accounts (objectives 1–3); Purdue OWL
is free without an account (objective 6); the project and assessments
use only unit materials.
