# Unit 02 Culminating Assessment — Theme, Perspective, and Character

**Track week 10** · Adult-held answer key and scoring guidance in
`answer-key.md` (§UA). You may re-read "The Broken Kite" and "The Quiet
Audition" during this assessment. Quote exactly when asked.

## Task 1 — Theme paragraph (objectives 1, 6)

Write a theme-analysis paragraph (6–10 sentences) on **one** of these
claims (choose):

- **A.** In "The Broken Kite," the theme is that asking for help takes
  courage.
- **B.** In "The Quiet Audition," the theme is that courage means trying
  again after freezing.

Requirements: state the claim in your own words · include **at least two
exact quotations** from the story · follow **every** quotation with an
explanation sentence ("this shows…") · draw details from **at least two
different parts** of the story (beginning/middle/end) · close by
restating the theme in new words.

## Task 2 — Character change (objectives 2, 4)

Choose **Sam** or **Maya**. (a) Name one trait at the beginning and one
trait at the end, each with a story detail. (b) Identify the **turning
point** — the moment the character changes course — and explain in 2–3
sentences how that moment connects the story's beginning to its ending
(how the parts fit together). (c) State the character's motive at the
turning point in one "because" sentence, and label it stated or inferred.

## Task 3 — Point of view (objective 3)

(a) "The Broken Kite" is third person; "The Crash, Told by Priya" is
first person. For **each** version, name one thing the narrator **can**
tell the reader and one thing the narrator **cannot** tell the reader.
(b) In 3–4 sentences, explain how Priya's point of view changes the
*meaning* of the crash scene compared with the third-person version.
Refer to at least one detail from each version.

## Task 4 — Comparing stories (objective 5)

Complete the comparison chart, then write a 4–6 sentence paragraph:

| | "The Broken Kite" | "The Quiet Audition" |
|---|---|---|
| The kind of courage shown | | |
| Who helps the main character, and how | | |
| What the ending proves about the theme | | |

Paragraph: state a **shared theme** that fits both stories, and explain
how the two stories prove it **differently**, using one detail from each
story.

## Scoring

Each task is scored 1–4 with the rubric in `teacher-guide.md`
("Unit assessment scoring"). Total 16. **13–16:** objectives secure —
move to U03. **9–12:** revise the lowest-scored task with the adult using
the answer key, then re-score. **Below 9:** reteach the two
lowest-scoring objectives with the teacher guide's reteach moves before
U03.

This is a curriculum-embedded assessment, not a standardized or validated
test.
