### Questions

**1.** Name all **six simple machines** from memory!

**2.** Review your Simple Machines Lab: Which machine did you build and test? What did you notice about the force you had to apply?

**3.** What is a **compound machine**? Give two examples of machines made by combining two or more simple machines together.

**4.** Welcome to **Python**! What does the following line of Python code do when you run it?
```python
print("Hello, my name is Learner!")
```

**5.** Look at this Python snippet:
```python
player_score = 10
player_score = player_score + 5
print(player_score)
```
What number will be printed on the screen?

**6.** In Python, what is the difference between a **string** and an **integer**?
- (a) `"50"` (String or Integer?)
- (b) `50` (String or Integer?)

**7.** **Diagram Challenge:** Choose a bicycle or a pair of scissors. Sketch it and label at least TWO simple machines hiding inside it! (e.g., wheel and axle, lever, wedge).

**8.** If you write `print(score)` without putting quotes around `score`, does Python print the word "score" or the value stored inside the variable?

## 🔑 Parent Answer Key (For Educator)

<details>
<summary>Click to expand Answer Key</summary>

1. **Six Simple Machines**:
   - 1. Inclined Plane
   - 2. Lever
   - 3. Pulley
   - 4. Wheel and Axle
   - 5. Wedge
   - 6. Screw

2. **Lab Reflection**:
   - Learner’s response should reference his actual project test (e.g., ramp incline or ruler lever balance) and note the force-distance trade-off.

3. **Compound Machine**:
   - A machine that combines two or more simple machines working together.
   - Examples: Scissors (two wedges + first-class lever); Bicycle (wheel and axle + levers + pedals/screws); Can opener (wheel and axle + lever + wedge).

4. **Python `print`**:
   - It outputs the text inside the quotation marks to the terminal console.

5. **Python Math**:
   - Outputs `15` ($10 + 5$).

6. **Data Types**:
   - String: Text wrapped in quotes.
   - Integer: Whole numerical value that can be used in arithmetic.
   - (a) String
   - (b) Integer

7. **Bicycle / Scissors Diagram**:
   - Scissors: Pivot screw (fulcrum), handles/blades (levers), sharp cutting edge (wedge).
   - Bicycle: Wheels/pedals (wheel and axle), hand brakes (levers), gears/chain (pulleys/wheel).

8. **Variable Output**:
   - It prints the **value stored inside the variable**. Putting quotes `print("score")` would literally print the word "score".
