# Project — The Mystery Materials Challenge

**Unit 02 · Sessions 11–12 (Week 9) · Investigation project**

## The challenge

You are the materials detective. The adult prepares **three sealed cups**
labeled only **X, Y, Z**, each holding a spoonful of a different white powder
chosen from: **baking soda, salt, sugar, flour, cornstarch**. (The adult keeps
the secret list.) Your job: **identify all three powders**, prove each
identification with **at least two properties**, and build particle models
showing each powder dry and one of them dissolved in water.

## Rules

- The full property toolkit from Lesson 03: color (hand lens), hardness,
  reflectivity, magnetic response, solubility. **No tasting, ever.**
- Tests must be fair: same spoonful size, same water amount, same stirring
  time for each powder (Unit 01 routine).
- One powder at a time; rinse or replace spoons and water cups between powders
  so tests don't contaminate each other.
- The two-property rule is the law: no identification from a single test.

## Steps

1. **Plan (Session 11, first half).** Write your test sequence: which property
   you test first, second, third — and *why that order*. (Smart detectives
   test the cheapest, least-destructive properties first: look, then magnet,
   then hardness, then solubility last.)
2. **Investigate (Session 11, second half).** Run the plan. Record every result
   in a property table — including surprises and failed tests. Honest
   "unclear" entries beat invented certainty.
3. **Model (Session 12, first half).** Draw particle models: each dry powder
   (particles packed, touching — a solid), and one powder stirred into water
   (particles spread among water's particles). Label what each model explains.
4. **Report (Session 12, second half).** Build the detective report (one page
   or poster):
   - The three identifications, each with **two cited properties**.
   - The particle models with captions.
   - One paragraph: *the hardest identification and how you solved it.*
   - One paragraph: *one test that gave an unclear result, and what you did
     about it.* (Real detectives report uncertainty.)

## Deliverables

1. Test plan (written before investigating).
2. Completed property table (all three powders × five properties).
3. Three particle-model drawings (dry) + one dissolved-model drawing.
4. Detective report (poster or page) with identifications, models, hard-case
   paragraph, and uncertainty paragraph.

## Rubric (20 points)

| Criterion | 4 — Strong | 3 — Solid | 2 — Developing | 1 — Starting |
|---|---|---|---|---|
| **Identifications** (4) | All 3 correct, each with ≥2 cited properties | All 3 correct, one cites only 1 property | 2 correct, or reasoning missing | 1 or fewer correct |
| **Fair testing** (4) | Same measures every time; contamination prevented; noted | Mostly consistent; minor lapse noted honestly | Inconsistent measures; not noted | Tests run carelessly |
| **Property table** (4) | Complete, organized, includes "unclear" where honest | Complete, minor gaps | Half complete or disorganized | Fragmentary |
| **Particle models** (4) | Dry + dissolved models correct, labeled, explain observations | Correct with weak labels | Arrangement errors (e.g., gas-like spread for a solid) | Missing or decorative |
| **Report honesty** (4) | Hard case + uncertainty paragraphs specific and reflective | Both present, one vague | One missing | Neither present |

**Scoring:** 18–20 exemplary · 14–17 proficient · 10–13 developing · below 10
reteach (see teacher guide). The rubric rewards honest uncertainty over lucky
guesses: a wrong identification with sound two-property reasoning and a clear
uncertainty note can still score 3 on Identifications at the adult's judgment.

## Safety

Adult prepares and labels all powders; previews for eye/skin safety. Powders
stay in cups; no blowing, no tasting, faces away from cups. Spills are swept,
not blown. Solubility water is discarded after the session, not drunk.

## Differentiation

- **Support:** the adult pre-fills the property table headings and the test
  plan's first step; the learner completes the rest. The report may be
  dictated.
- **Extension:** add a fourth unknown (the adult picks from the remaining two
  powders) *or* write a "detective's handbook" page: which single test rules
  out the most powders, and why? (Answer: solubility splits the list fastest
  — flour/cornstarch don't dissolve; salt/sugar/baking soda do.)
