# Project — The Ramp-Roll Fair Test

**Grade 5 Science · Unit 01** · Sessions 13–14 (launch), finished Session 16
Status: draft. The adult supervises every step and previews the procedure.

## The question

**Does raising the ramp make the ball roll farther?**

## Materials

- A smooth board, tray, or large book (the ramp) — about 60–100 cm long
- Books to raise one end (1 book = low ramp, 3 books = high ramp)
- One small ball (marble, table-tennis ball, or rubber ball)
- Tape (to mark the ramp base and the release point), a tape measure or long
  ruler (cm), notebook and pencil
- Safety: clear the rolling lane of people, pets, and breakables; the ball
  stays on the floor lane; the adult steadies tall book stacks.

## Steps

1. **Set up.** Tape-mark where the ramp meets the floor (the "start line"
   for measuring) and mark the ball's release point near the top of the ramp.
   These marks must not move between trials.
2. **Write the plan** (report parts 1–2): the testable question; the
   variable (ramp height: 1 book vs. 3 books); controls — same ball, same
   ramp board, same floor, same release mark, same measurer, same measuring
   tape; what is measured (roll distance in **cm**, from the start line to
   where the ball stops); 3 trials per height. Draw and label the setup
   model.
3. **Practice trials.** Run one trial at each height to rehearse the
   measuring routine: release (don't push) the ball from the mark, let it
   roll to a stop, measure from the start line to the ball's stopping point
   in cm. Adjust marks if needed.
4. **Real trials.** Low ramp: 3 trials, record each in the labeled data
   table. Then high ramp: 3 trials. If a trial is spoiled (ball hits a wall,
   someone bumps the ramp), note it, discard it, and re-run it.
5. **Convert.** Add a two-column table converting each distance from cm to m
   (divide by 100). Check each row backward.
6. **Graph.** Compute the average distance for each height. Draw a bar graph:
   title, x-axis (ramp height), y-axis "Average distance (cm)" with an even
   scale, two bars.
7. **Claim and evidence.** Write one honest claim the data support
   ("My evidence is ___") and one claim the data do NOT support.
8. **Revise the model.** Redraw the setup with a revised caption: what did
   the evidence change about your explanation of *why* the ball rolls
   farther (or not)?
9. **Finish the report.** Assemble all six parts in order. In Session 16,
   present the report: show the graph, read the claim, and explain the model
   revision in one minute.

## Deliverables

1. The labeled setup model drawing (before and revised versions).
2. The completed six-part investigation report (question, plan, data table,
   graph, claim/evidence, revised model).
3. The cm→m two-column conversion table.
4. A one-minute showcase talk (Session 16).

## Rubric

Scoring: 3 = strong, 2 = developing, 1 = starting. The adult scores with the
learner and notes one next step.

| Criterion | 3 — Strong | 2 — Developing | 1 — Starting |
|---|---|---|---|
| **Fair-test plan** | Variable named; ≥3 controls listed; measurement with units and trial count stated | Variable named; 1–2 controls; measurement stated without units or trial count | Variable missing or confused with the measurement; no controls |
| **Data quality** | All 6 trials recorded in a labeled table with units; spoiled trials noted and re-run | Table present but missing a label or unit; trials complete | Data incomplete or unlabeled; trials not repeated |
| **Graph** | Title, both axes labeled with units, even scale, averaged bars drawn to correct heights | Graph present with one element missing (title, unit, or even scale) | Graph missing or unreadable; no averaging |
| **Claim and evidence** | Honest claim tied to the data ("My evidence is ___"); correctly names an unsupported claim | Claim is vague or slightly overreaches the data | Claim contradicts the data or no evidence cited |
| **Report and model** | All six parts in order; revised model caption explains what the evidence changed | Report complete; revision is cosmetic (no explanation of what changed) | Report missing parts; no model revision |

**What "ready" looks like:** scores of 2 or better in every row, and the
claim stays inside the evidence. If the fair-test plan scores 1, re-teach
Lesson 03 with the ramp demo before the learner plans another investigation
— Units 02, 03, and 08 all depend on this routine.
