# Lesson 03 — Fair Tests

**Unit:** 01 — Models, Measurement, and Controlled Investigations · **Grade 5**
**Time:** ~40 minutes · **Session:** 7 of 16

## Goal

You will plan a **fair test**: change one **variable**, keep the rest as
**controls**, run at least three **trials**, and record data in a labeled
table.

## Materials

- Notebook, pencil; two-column table template (from Lesson 02)
- For the demo: a board or tray (ramp), books, a small ball, tape, a ruler
  or tape measure

## Readiness check (3 minutes)

The adult asks: "I want to know if a taller ramp makes a ball roll farther.
What is the **one thing** I would change? What must I **keep the same**?"
Expected: change the ramp height; keep the same ball, the same floor, the
same starting point, the same person measuring. If the learner names two or
three things to change, that's the lesson's starting point.

## Teaching

### Part A — One thing changes, the rest stays

A **fair test** answers a testable question by changing **only one thing**
(the **variable**) and keeping **everything else the same** (the
**controls**). If two things change at once, you can't tell which one caused
the result.

> Unfair: "I tested a tall ramp with a heavy ball and a short ramp with a
> light ball. The heavy ball went farther, so tall ramps are better." Wrong —
> the test changed *two* things (ramp height AND ball). The result proves
> nothing.

> Fair: same ball, same floor, same release point — only the ramp height
> changes. Now any difference in distance is evidence about ramp height.

**Worked example 1 — spot the unfair test.**
Question: "Does warm water dissolve sugar faster than cold water?"
Plan: "I'll stir the warm water but not the cold water, and I'll use a big
spoonful of sugar in the warm cup and a small spoonful in the cold cup."
*Thinking:* This changes three things — temperature, stirring, and amount of
sugar. Unfair. The fair version: same amount of sugar, same stirring (or no
stirring), same cup size — only the water temperature changes. Then the
dissolving time tells you about temperature.

**Worked example 2 — name the variable and controls.**
Question: "Do heavier balls roll farther than lighter balls on the same ramp?"
*Thinking:* The **variable** (the one thing changed) is the ball's mass —
heavy ball vs. light ball. The **controls** (kept the same): the same ramp at
the same height, the same floor, released from the same mark, measured the
same way. The thing **measured** is how far each ball rolls.

### Part B — Trials and tables

One try can be a fluke — the ball hits a bump, someone sneezes. Scientists
run **trials**: the same test repeated at least **three times**. Then they
look for the pattern across trials instead of trusting any single one.

Record every trial in a **labeled data table** — labels on every column,
units in the column heading.

**Worked example 3 — read a data table like a scientist.**
*Fictional practice data — not real observations.*

| Ramp height | Trial 1 (cm) | Trial 2 (cm) | Trial 3 (cm) |
|---|---|---|---|
| Low (1 book) | 82 | 85 | 84 |
| High (3 books) | 141 | 138 | 143 |

*Thinking:* The low-ramp distances cluster around 83–85 cm; the high-ramp
distances cluster around 138–143 cm. Every high-ramp trial beat every
low-ramp trial, so the pattern is strong: the higher ramp made the ball roll
farther *in this test*. The table lets you see the pattern — and the
repeated trials let you trust it.

**Worked example 4 — what counts as evidence.**
From the table above, which claim is supported?
a. "High ramps always make every ball roll farther." — Too big. This test
   used one ball on one floor; "always" and "every ball" go beyond the
   evidence.
b. "In this test, the ball rolled farther from the high ramp in all three
   trials." — Supported. It says exactly what the data show, no more.
Honest claims stay inside the evidence. Lesson 04 will turn this table into
a graph.

## Guided practice (with the adult)

1. **Fair or unfair?** For each plan, say fair or unfair and name the extra
   thing that changed (if any):
   a. "Which paper airplane design flies farther?" — same paper, same
      thrower, same throwing spot; only the design changes.
   b. "Which soil grows beans taller?" — different soils, but one pot is by
      the window and the other in a dark closet.
   c. "Does a longer pendulem string swing slower?" — same weight, same
      release angle; only the string length changes.
2. **Plan together.** Question: "Does the surface change how far the ball
   rolls?" Fill in: variable = ___, controls (list at least 3) = ___,
   measured = ___, trials = ___.
3. **Demo.** The adult runs the ramp demo once at low height while you
   measure the distance in cm. Record it in a labeled table. (You will run
   the full 3-trial version in the project.)

## Independent practice

Write or dictate your answers (8 tasks).

1. Question: "Do plants grow taller with more water?" Name the variable.
2. For the same question, name two controls.
3. A learner tests two fertilizers but also gives one plant more sunlight.
   Fair or unfair? Explain in one sentence.
4. Why do scientists run three trials instead of one? Give two reasons.
5. Question: "Which brand of paper towel absorbs the most water?" Name what
   is measured and the unit.
6. Label this table properly — what is missing?

   | | 1 | 2 | 3 |
   |---|---|---|---|
   | A | 12 | 14 | 13 |
   | B | 20 | 19 | 21 |

   *(No column labels, no units, rows A/B unexplained.)*
7. *Fictional practice data.* A learner tests whether a heavier ball rolls
   farther. Light ball: 90, 93, 91 cm. Heavy ball: 88, 92, 90 cm. What
   pattern do you see? Write one honest claim the data support.
8. **Error analysis.** "I tested once and the tall ramp won, so taller ramps
   always win." Name two problems with this conclusion.

## Application — design your own fair test

Pick a question from your question board (Lesson 01). Write a fair-test plan:
the testable question, the variable, at least three controls, what you will
measure (with units), and how many trials. The adult checks the plan for
safety before anything is tested. Keep this plan — Session 8 turns it into
practice data and a graph.

## Exit check

1. In your own words: what is the difference between a variable and a
   control?
2. A friend says "I don't need trials; my first try was perfect." What do
   you tell them?

## Supports

- **Reading/language access:** the sentence frames "When ___ changed, then
  ___ happened" and "I kept ___ the same so the test would be fair" are on
  the wall; the adult reads tasks aloud on request.
- **Alternate response mode:** act out fair vs. unfair with the ramp demo;
  dictate the plan while the adult writes.
- **Extension:** the project asks whether ramp *height* matters. Design a
  second fair test on the same setup that asks a *different* question (e.g.,
  ball mass, floor surface) — name its new variable and which old variable
  becomes a control.

## Teacher note

**Likely misconceptions:** (1) "Fair means everyone gets a turn" — re-anchor
to *one thing changes*. (2) Learners list the *measured* thing as the
variable ("the variable is how far it rolls") — the variable is what *you*
change; the measurement is the result. (3) "More trials = more different
things to try" — trials repeat the *same* conditions. **Answer key:**
[answer-key.md](../answer-key.md#lesson-03). **Next:** Lesson 04 (graphs and
models).
