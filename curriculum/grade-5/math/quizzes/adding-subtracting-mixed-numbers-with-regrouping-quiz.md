## 🔑 Parent Answer Key (Educator)

> [!NOTE]
> *This section is for Educator (educator) to quickly check Learner’s work, celebrate victories, and review any tricky steps together.*

**Question 1:**  
- **Target Answer & Key Steps:** $5\frac{2}{3}$

**Question 2:**  
- **Target Answer & Key Steps:** Common denominator 4: $1\frac{2}{4} + 2\frac{1}{4} = 3\frac{3}{4}$.

**Question 3:**  
- **Target Answer & Key Steps:** Common denominator 12: $3\frac{8}{12} + 1\frac{9}{12} = 4\frac{17}{12} = 5\frac{5}{12}$.

**Question 4:**  
- **Target Answer & Key Steps:** $2\frac{4}{6} = 2\frac{2}{3}$.

**Question 5:**  
- **Target Answer & Key Steps:** Regroup 5 as $4\frac{4}{4}$. $4\frac{4}{4} - 2\frac{1}{4} = 2\frac{3}{4}$.

**Question 6:**  
- **Target Answer & Key Steps:** Regroup $6\frac{1}{4} = 5\frac{5}{4}$. $5\frac{5}{4} - 2\frac{3}{4} = 3\frac{2}{4} = 3\frac{1}{2}$.

**Question 7:**  
- **Target Answer & Key Steps:** Common denominator 6: $4\frac{2}{6} - 1\frac{3}{6}$. Regroup $4\frac{2}{6} = 3\frac{8}{6}$. $3\frac{8}{6} - 1\frac{3}{6} = 2\frac{5}{6}$.

**Question 8:**  
- **Target Answer & Key Steps:** $2\frac{3}{6} + 1\frac{2}{6} = 3\frac{5}{6}$ cups.

**Question 9:**  
- **Target Answer & Key Steps:** $8 = 7\frac{8}{8}$. $7\frac{8}{8} - 3\frac{5}{8} = 4\frac{3}{8}\text{ feet}$.

**Question 10:**  
- **Target Answer & Key Steps:** Common denominator 10: $5\frac{4}{10} - 2\frac{7}{10} = 4\frac{14}{10} - 2\frac{7}{10} = 2\frac{7}{10}$.
