# Teacher Guide — Unit 04

Session-by-session teaching notes, misconception alerts, reteach
guidance, and readiness criteria. **This guide references**
[answer-key.md](answer-key.md) **by section — keys are never duplicated
here.** All keys were solved independently and reconciled against the
student files during writing.

## How to use this unit

- 16 sessions, ~40 minutes each, 4 per week (Weeks 15–18). Session types
  rotate: concept lesson → guided practice/game → review/quiz →
  project.
- Review every exit check and practice set the **same day**; the S08
  quiz and S15 assessment drive reteach decisions.
- Fluency is strategy-based: **no timed speed tests** anywhere in this
  unit.
- The adult may scribe, and learners may answer orally or by pointing
  — every lesson lists an alternate response mode.
- Grade the estimate separately from the exact answer in Lessons 04
  and the project: an estimate is evidence of thinking, not a rough
  draft.
- Week 18 closes this unit and bridges into the track's midyear review
  (R00 in issue #26): S16 returns the assessment and names each
  learner's highest-need objective from Units 01–04 for that review.

## Session-by-session notes

### S01 — Lesson 01: Equivalent fractions and common denominators (UO1)

- **Teach the bar before the multiplication.** If a learner adds to
  numerator and denominator, put the bars side by side and ask which
  shaded length matches.
- **Misconception:** renaming only one fraction; adding the same
  number to top and bottom (G3).
- **Ready to move on:** exit check correct with both fractions renamed
  to 12. Key: [answer-key.md](answer-key.md#lesson-01).

### S02 — Guided practice: Common-denominator race + Practice Set A (UO1)

- Let learners catch a deliberately wrong renaming — error-spotting
  transfers better than error-avoidance.
- **Reteach trigger:** if 2+ of the 5 Set A tasks miss the *denominator*
  (not the numerator), replay Lesson 01's bars before any more written
  work.

### S03 — Lesson 02: Adding with unlike denominators (UO2)

- **Do not teach "add tops, add bottoms" as a stage.** Bars first,
  renaming second, addition of numerators last — in that order, every
  time, until the learner can explain why denominators stay put.
- **Misconception:** 2/5 + 1/2 = 3/7. Fix with the benchmark test:
  the sum must exceed each addend.
- **Ready to move on:** exit check correct with renamed fractions
  written out. Key: [answer-key.md](answer-key.md#lesson-02).

### S04 — Fluency game: Fraction-strip build + Practice Set B (UO2)

- Insist on the renamed strip being laid out before the total is read
  — the build *is* the reasoning.
- **Reteach trigger:** if a learner builds with mixed piece sizes,
  return to Lesson 01, Worked Example 1.

### S05 — Lesson 03: Subtracting with unlike denominators (UO3)

- **Act out the subtraction** with strips: shade the start, cross out
  the renamed part, count what remains.
- **Misconception:** subtracting denominators, or subtracting in the
  wrong order. Fix: always check by adding back.
- **Ready to move on:** exit check correct with an add-back check
  named. Key: [answer-key.md](answer-key.md#lesson-03).

### S06 — Guided practice: Practice Set C + subtraction stations (UO3)

- Stations: (a) like-denominator warm-up, (b) rename-only, (c) full
  subtraction with add-back check. Learners rotate only after the
  adult initials each station.
- **Reteach trigger:** unsimplified answers (3/6 left as 3/6) in 2+
  items → a five-minute simplification routine before S07.

### S07 — Lesson 04: Mixed numbers, benchmarks, baking scene (UO3–UO4)

- **Teach regrouping as a trade, not a trick:** "one whole becomes
  four fourths" said aloud, with strips, before any written regrouping.
- **The picture is not data.** Say so out loud: the baking-scene
  illustration is a story prompt; the recipe amounts are in the text.
  Do not let learners count tray pieces for arithmetic.
- **Ready to move on:** exit check correct, with the regrouping step
  named for item 2. Key: [answer-key.md](answer-key.md#lesson-04).

### S08 — Week-04 formative quiz + reteach block (UO1–UO4)

- 12 items, same-day adult feedback. Record, per learner, which
  objective is insecure; set the reteach plan before Week 17.
- **Reteach rule:** a missed renaming item (1–2) means Lesson 01
  replay; missed mixed-number items (9–10) mean Lesson 04 regrouping
  replay with strips. Do not advance to Lesson 05 with a renaming gap
  unaddressed — Lesson 05's sharing work assumes renaming is secure.

### S09 — Lesson 05: A fraction is division (UO5)

- **Say the sentence every time:** "The first number is shared; the
  second number is how many share it." This one sentence prevents the
  1 ÷ 2 = 2/1 swap.
- **Misconception:** rounding a sharing answer to a whole number.
  The fraction is the exact answer; "between 3 and 4" only locates it.
- **Ready to move on:** exit check correct with between-numbers pairs
  stated. Key: [answer-key.md](answer-key.md#lesson-05).

### S10 — Fluency: Between-two-wholes bingo + Practice Set E (UO5)

- A bingo row counts only when every fraction and mixed number beside
  it is correct — speed without correctness scores nothing.

### S11 — Project session 1: Fraction Bakery menu card + computation sheet

- Approve each learner's ingredient pairs before they compute: pairs
  must have unlike denominators, and at least one pair must need
  regrouping or produce a sum over 1.
- **Reteach trigger:** a menu card whose items all share denominators
  is redesigned on the spot — it does not meet the brief.

### S12 — Project session 2: Tray/sharing plan + presentation rehearsal

- Check the sharing plan's multiplication check before rehearsal;
  a plan without a check is returned, not presented.

### S13 — Project presentations (all objectives)

- Each learner presents one computation and answers one peer
  "why did the denominators have to match?" question. Use the project
  rubric; record one strength and one next step per learner.

### S14 — Review stations (all objectives)

- Four stations: rename, add, subtract (with regrouping), share as
  division. Learners name their own strongest and weakest objective
  before the assessment.

### S15 — Culminating assessment (all objectives)

- 16 items, 30 points (scoring in the answer key). Adult scores the
  same day and writes a reteach list per objective.

### S16 — Feedback and bridge

- Return assessments; learners correct each missed item with the
  renaming step shown. Close by previewing Unit 05 (fraction
  multiplication): "Next unit, we multiply fractions — and the
  renaming habit from this unit will tell us when a common denominator
  is *not* needed." Name each learner's highest-need objective from
  Units 01–04 for the midyear review.

## Readiness and reteach summary

| If the learner… | Then… |
|---|---|
| Cannot rename to a common denominator (quiz items 1–2, assessment 1–2) | Replay Lesson 01 with bars; do not advance past S08 without a correct renaming exit check |
| Adds or subtracts denominators (quiz 12, assessment 15) | Benchmark intervention: prove the answer impossible with 0/1/2 comparisons, then rebuild with bars |
| Fails regrouping (quiz 10, assessment 10/12) | Replay Lesson 04's trade with strips; require the regrouped line to be written before subtracting |
| Swaps division roles (assessment 13–14) | Replay Lesson 05's sharing sentence with counters; require the division sentence before the fraction |
| Scores below half an objective's points on the assessment | Targeted reteach from that objective's lesson before Unit 05; record it in the midyear-review plan |

## Accessibility and safety notes

- All activities have an oral, pointing, or dictated response mode;
  written answers are never the only evidence.
- Fraction strips and paper bars are the default manipulative; no
  food handling is required. If the adult chooses a real baking
  follow-up, an adult supervises the oven and all food handling, and
  learners with food allergies use the paper version only.
- The generated illustration is labeled as a story prompt in its
  lesson and in `assets/README.md`; it is never presented as a
  measurement, a primary source, or evidence for a quantity.
