# Teacher Guide — Unit 05

Session-by-session teaching notes, misconception alerts, reteach
guidance, and readiness criteria. **This guide references**
[answer-key.md](answer-key.md) **by section — keys are never duplicated
here.** All keys were solved independently and reconciled against the
student files during writing.

## How to use this unit

- 16 sessions, ~40 minutes each, 4 per week (Weeks 19–22). Session types
  rotate: concept lesson → guided practice/game → review/quiz →
  project.
- Review every exit check and practice set the **same day**; the S08
  quiz and S15 assessment drive reteach decisions.
- Fluency is strategy-based: **no timed speed tests** anywhere in this
  unit.
- The adult may scribe, and learners may answer orally or by pointing
  — every lesson lists an alternate response mode.
- Grade the estimate/prediction separately from the exact answer in
  Lesson 03 and the project: a prediction is evidence of thinking,
  not a rough draft.
- Week 22 closes this unit and bridges into Unit 06 (measurement
  conversions and volume): S16 returns the assessment and names each
  learner's highest-need objective for that unit's fraction-arithmetic
  warm-ups.

## Session-by-session notes

### S01 — Lesson 01: A fraction times a whole number (UO1)

- **Teach the partition before the shortcut.** Say "split into b
  parts, take a" out loud for every example before writing
  (a × q) ÷ b.
- **Misconception:** multiplying the denominator by the whole number
  (G3: (3/4) × 8 = 3/32). Fix: the denominator counts the parts; use
  bars — 3/4 of 8 bars is 6 bars.
- **Ready to move on:** exit check correct with the split-and-take
  step shown. Key: [answer-key.md](answer-key.md#lesson-01).

### S02 — Guided practice: Partition relay + Practice Set A (UO1)

- Insist the partition is spoken before the answer is written — the
  game scores the reasoning, not just the number.
- **Reteach trigger:** if 2+ of the 5 Set A tasks miss the *numerator*
  (for example, answering (2/3) × 12 with 4 instead of 8), replay
  Lesson 01's bars before any more written work.

### S03 — Lesson 02: Fraction × fraction, area models (UO2)

- **Build the model before the rule.** Grid paper and two crayons
  first; (a × c)/(b × d) second. The garden picture is a story
  prompt — its plant counts are decorative and are never data.
- **Misconception:** adding denominators, or wanting a common
  denominator. Fix: count the tiles — the product's denominator is
  the total tile count (b × d).
- **Cancelling:** teach it only after the multiply-across rule is
  secure, and only as "divide a numerator and a denominator by the
  same factor." Never cancel two numerators.
- **Ready to move on:** exit check correct with the tiling count
  stated. Key: [answer-key.md](answer-key.md#lesson-02).

### S04 — Fluency game: Area-model match + Practice Set B (UO2)

- A mismatch is a teaching moment: re-draw the model together rather
  than marking it wrong and moving on.
- **Reteach trigger:** if 2+ of Set B tasks are unsimplified (for
  example, 10/30 instead of 1/3), replay the Lesson 02 cancelling
  step with small numbers before the quiz.

### S05 — Lesson 03: Scaling (UO3)

- **This is the unit's hinge lesson.** Do not rush it: the
  "greater than 1 grows, less than 1 shrinks" idea is what lets
  learners judge every later answer.
- **Misconception:** "multiplication always makes bigger" (G3). Fix
  with the partition: taking 1/2 of 8 keeps only half of it.
- **Misconception:** comparing the product to the fraction instead of
  to the other factor. Always ask: "Bigger or smaller than *which*
  number?"
- **Ready to move on:** exit check correct with the "without
  multiplying" reason stated. Key:
  [answer-key.md](answer-key.md#lesson-03).

### S06 — Guided practice: Scaling sort + Practice Set C (UO3)

- Sort first, compute second — the order is the point. If a learner
  computes first, cover the numbers and re-sort from the fraction's
  size next to 1.
- **Reteach trigger:** if a learner sorts (5/4) × 12 into "shrinks,"
  replay Worked Example 1 with fraction strips (5/4 of 12 is more
  than one whole 12).

### S07 — Lesson 04: Mixed numbers, real-world problems (UO4)

- **Convert first, every time.** The most common error is
  multiplying whole parts and fraction parts separately (G3:
  1 1/2 × 2 = 2 1/2). The fix is a written conversion line, never
  skipped.
- The legacy Fraction Feast doubling tasks (flour 2 1/2 × 2, water
  3/4 × 2) are the lesson's worked example — learners meet them
  again in the project with the models attached.
- **Ready to move on:** exit check correct with conversions shown.
  Key: [answer-key.md](answer-key.md#lesson-04).

### S08 — Review: Week-04 formative quiz (UO1–UO4)

- 12 items, same-day adult feedback, targeted reteach block. Record
  which objective is insecure for each learner; set the reteach plan
  before Week 21.
- **Reteach trigger:** UO1 or UO2 below 3 of 4 items → replay
  Lessons 01–02 with bars and grid paper in Week 21's first session
  before Lesson 05. UO3 below 3 of 4 → replay the scaling card and
  number line. Do not start the project until the quiz is reviewed.

### S09 — Lesson 05: Dividing unit fractions (UO5–UO6)

- **Name the question type first.** "Sharing" vs "servings" decides
  the operation's meaning and which number is the divisor. Keep the
  4 ÷ (1/2) vs (1/2) ÷ 4 pair visible all week.
- **Misconception:** multiplying instead of dividing (G3). Fix: ask
  the servings question out loud first — "how many thirds fit in 2?"
- **Do not teach "flip and multiply."** It is not the grade-5 method.
  The multiplication *check* (quotient × divisor = dividend) is the
  verification tool.
- **Ready to move on:** exit check correct with the multiplication
  check shown. Key: [answer-key.md](answer-key.md#lesson-05).

### S10 — Practice: How-many-servings game + Practice Sets D–E (UO4–UO6)

- The game scores naming the question type first — a right number
  with the wrong type scores nothing. That is deliberate: the type
  is the skill.
- **Reteach trigger:** if Set E shows swapped dividends/divisors on
  2+ items, replay Worked Example 3 with strips before the project.

### S11 — Project session 1: Fraction Feast (UO1–UO6)

- Learners produce the scaled recipe card, serving plan, and garden
  bed. Watch for the two classic slips: forgetting the flour
  conversion (Lesson 04) and swapping the lemonade divisions
  (Lesson 05).
- The cheese blend is Unit 04 addition — let learners show it as a
  labeled "from Unit 04" line rather than re-teaching it.

### S12 — Project session 2: Feast card and rehearsal (UO1–UO6)

- Every line gets a check (multiplication check or scaling
  prediction) before the card is finished. A line that fails its
  check is fixed now, not presented.
- Rehearsal is out loud: one computation, its model, its check.

### S13 — Project presentations (all objectives)

- Each learner presents one computation and answers one peer scaling
  question. Peer questions must be genuine ("why is the product
  smaller than the recipe amount?"), not "is that right?"

### S14 — Review stations (all objectives)

- Four stations: partition products, area models, scaling, unit
  fraction division. Adult feedback at each station. Learner names
  their own strongest and weakest objective before the assessment.

### S15 — Culminating assessment (all objectives)

- 15 items, 30 points. Adult scores with
  [answer-key.md](answer-key.md); reteach list written the same day.
- **Readiness signal:** 24+ points with the reasoning shown means
  ready for Unit 06. Below 18, or any objective with both its items
  missed, means reteach that objective before Unit 06's fraction
  warm-ups.

### S16 — Feedback and bridge (all objectives)

- Return assessments, correct each missed item with the model or
  check step shown, and name each learner's highest-need objective
  for Unit 06. Preview: Unit 06 converts measurements and packs
  volumes, and every conversion table reuses the fraction
  multiplication learned here.
