# Lesson 05 — Comparing and Ordering Decimals

**My goal:** I can compare and order decimals to thousandths by the meanings of
the digits in each place — and I know why "longer decimal" does not mean
"bigger number."

**Time:** about 40 minutes (5 readiness · 12 teaching · 8 guided · 12
independent · 3 exit).

**Materials:** place-value mat, digit cards, pencil and paper.

**Standards:** 5.NBT.A.3.b · **Unit objectives:** UO5

## Readiness check (5 minutes)

1. Which is greater: 7 tenths or 7 hundredths? Write both as decimals and
   explain which place makes the difference.
2. Write 0.65 and 0.605 on a place-value mat. Compare digit by digit from the
   left — which place decides which is greater?
3. True or false: 2.4 and 2.400 are equal. Justify with place values.

## Explicit teaching

### Compare place by place, from the left

Decimals are compared the way words are put in alphabetical order: start at
the leftmost place where they differ, and that place decides.

**Compare 0.65 and 0.605:**

1. Ones: 0 = 0. Tenths: 6 = 6. Still tied.
2. Hundredths: **5 vs 0**. 5 > 0, so **0.65 > 0.605**.
3. We stop — later places cannot overrule an earlier decision, because a whole
   hundredth is bigger than any number of thousandths (10 × 6/1000 = 6/100 <
   1/100… more precisely, the maximum thousandths contribution 9/1000 is still
   less than 1/100).

**The trap:** 0.605 "looks bigger" because it has more digits. But digits only
count where they sit. A 5 in the hundredths place beats any digit in the
thousandths place.

### Equalizing places makes it visible

Write both numbers to the same length by adding trailing zeros (which change
nothing — Lesson 02): 0.65 = 0.650. Now compare 0.650 and 0.605: thousandths
0 vs 5… wait, compare properly: tenths 6 = 6, hundredths 5 > 0. Same answer,
easier to see.

### Equivalent decimals

**2.4 = 2.400.** Expanded: 2 + 4/10 + 0/100 + 0/1000 = 2 + 4/10. Trailing zeros
add zero value, so we use **=** between them.

### Worked example 1 — ordering four decimals

Order from least to greatest: **0.34, 0.304, 0.43, 0.403**.

1. Compare **tenths** first: 3, 3, 4, 4. The 3-tenths numbers are smaller than
   the 4-tenths numbers.
2. Between 0.34 and 0.304: hundredths **4 vs 0** → 0.304 < 0.34.
3. Between 0.43 and 0.403: hundredths **3 vs 0** → 0.403 < 0.43.
4. Final order: **0.304 < 0.34 < 0.403 < 0.43**.

Check each link: 0.304 < 0.34 (0 < 4 in hundredths ✓); 0.34 < 0.403 (3 < 4 in
tenths ✓); 0.403 < 0.43 (0 < 3 in hundredths ✓).

### Worked example 2 — a race (smaller time wins)

Four sprinters' 100-meter times: Ana 10.42 s, Ben 10.318 s, Cara 10.5 s,
Dan 10.495 s. Fastest = **smallest** time.

1. Tenths: 4, 3, 5, 4 → Ben (3 tenths) is fastest: **10.318**.
2. Ana vs Dan: 10.42 vs 10.495 — tenths tie at 4; hundredths 2 vs 9 → Ana is
   faster: **10.42 < 10.495**.
3. Cara: 10.5 = 10.500; thousandths 0 vs Dan's 5 → **10.495 < 10.5**.
4. Finish order: **Ben (10.318), Ana (10.42), Dan (10.495), Cara (10.5)**.

## Guided practice (with hints)

**G1.** Compare with <, >, or =: **2.4 ___ 2.400**.
*Hint: write both in expanded form and see what the zeros add.*

**G2.** Compare with <, >, or =: **0.52 ___ 0.502**.
*Hint: go place by place from the decimal point; stop at the first
difference.*

**G3.** Order from least to greatest: **0.71, 0.701, 0.7**.
*Hint: equalize to three decimal places first (0.710, 0.701, 0.700), then read
left to right.*

**G4 — Error analysis.** Kofi says 0.512 > 0.9 "because 512 is bigger than 9."
Explain his mistake using place value, and write the correct comparison.
*Hint: which place decides first — tenths or thousandths?*

## Independent practice

**I1.** Compare with <, >, or =: **1.08 ___ 1.8**.

**I2.** Compare with <, >, or =: **3.06 ___ 3.60**.

**I3.** Order from greatest to least: **0.45, 0.405, 0.5, 0.455**.

**I4 — Explain your reasoning.** Mia ordered 0.6, 0.66, 0.606 from least to
greatest as 0.6 < 0.606 < 0.66. Is she correct? Justify each link with the
place value that decides it.

**I5 — Swim finals.** Four swimmers' 50-meter freestyle times: Ana 31.24 s,
Ben 31.208 s, Cara 31.3 s, Dan 31.29 s. List them from fastest (1st place) to
slowest (4th place), showing the place-by-place reasoning.

## Application task

**Comparison chain.** Choose any four decimals to thousandths (all different).
(a) Write them in order from least to greatest with < between each pair, like
a chain: ___ < ___ < ___ < ___. (b) Under each < sign, write the place value
that justifies that link (e.g., "tenths: 2 < 5"). (c) Trade chains with a
partner and verify each other's links.

## Exit check

Compare with <, >, or =: **0.75 ___ 0.705**. Write the place value that
decides it.

---

## Reading / language-access support

- Keep a posted sentence frame: "___ > ___ because the ___ place has ___ vs
  ___."
- Read comparison chains aloud: "0.304 is less than 0.34 is less than…"
- Home-language words for "greater/less than" may be used in explanations.

## Alternate response mode

- **Mat placement:** build both numbers on the place-value mat with digit
  cards and point to the deciding place instead of writing the explanation.
- **Oral chain:** speak the ordering with justifications; the adult scribes.
- **Sorting cards:** physically order number cards, then read the chain aloud.

## Extension

**Mystery number.** "I am a decimal to thousandths. I am greater than 0.45
and less than 0.46. My thousandths digit is twice my hundredths digit." Find
all possible numbers and explain why there are no others. Then make up your
own mystery-number riddle with at least three clues for a partner to solve.

## Teacher note

**Likely misconceptions:**
- "Longer decimal is bigger" (G4, I4) — the unit's signature trap; counter
  with the mat: a hundredths digit always outranks any thousandths digit.
- Comparing only the whole-number parts of the decimal digits (512 vs 9) —
  redirect to leftmost-differing-place.
- Writing chains without checking every link — require the justifying place
  under each < or >.
- Thinking 1.08 < 1.8 is "wrong because 8 > 08" — tenths decide: 0 < 8.
