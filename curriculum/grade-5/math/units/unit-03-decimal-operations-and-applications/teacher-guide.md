# Teacher Guide — Unit 03

Session-by-session teaching notes, misconception alerts, reteach guidance,
and readiness criteria. **This guide references** [answer-key.md](answer-key.md)
**by section — keys are never duplicated here.** All keys were solved
independently and reconciled against the student files during writing.

## How to use this unit

- 16 sessions, ~40 minutes each, 4 per week. Session types rotate: concept
  lesson → guided practice → fluency game → review.
- Review every exit check and practice set the **same day**; the S08 quiz
  and S15 assessment drive reteach decisions.
- Fluency is strategy-based: **no timed speed tests** anywhere in this unit.
- The adult may scribe, and learners may answer orally or by pointing —
  every lesson lists an alternate response mode.
- Grade the estimate separately from the exact answer in Week 13 (Lesson
  05): an estimate is evidence of thinking, not a rough draft.

## Session-by-session notes

### S01 — Lesson 01: Adding and subtracting decimals (UO1)

- **Teach the mat before the method.** If a learner lines up the right
  edge, do not correct the digits — put a tenths card on a hundredths
  card and ask, "Are these the same size?"
- **Misconception:** right-edge alignment; skipping regrouping across a
  zero (7.05 − 2.49). Fix: trade from the ones first, aloud, every time.
- **Ready to move on:** exit check correct with the regrouping step named.
  Key: [answer-key.md](answer-key.md#lesson-01).

### S02 — Guided practice: Place-value lineup game (UO1)

- Let learners catch the adult's deliberate lineup errors in Game 1 —
  error-spotting transfers better than error-avoidance.
- **Reteach trigger:** if 2+ of the 5 Set A tasks miss the *column*
  (not the arithmetic), replay the mat before any more written work.

### S03 — Lesson 02: Multiplying decimals (UO2)

- **Do not teach the place-counting shortcut first.** Grid first, then
  fractions, then the shortcut — in that order, every time, until the
  learner can explain the shortcut from the grid.
- **Misconception:** "0.3 × 0.4 = 1.2" (no hundredths reasoning) and
  dropping trailing zeros without understanding (0.20 vs 0.2).
- **Ready to move on:** exit check correct with a grid or fraction
  justification, not just the shortcut.

### S04 — Fluency game: Hundredths-grid race (UO2)

- Insist on the overlap count ("30 squares, so 0.30") — the count *is*
  the reasoning.
- **Reteach trigger:** if a team shades rows and columns but cannot say
  what the overlap means, return to Lesson 02 Worked Example 1.

### S05 — Lesson 03: Dividing decimals by whole numbers (UO3)

- **Act out the sharing** with play money before any written division.
  Dollars, then dimes, then pennies — the written method is just a
  record of that sharing.
- **Misconception:** the missing decimal point (6.3 ÷ 7 = 9) and stopping
  at a remainder (3 ÷ 4 = "0 R3"). Fix: "What place is this digit in?"
  and "Can we trade down one more place?"
- **Ready to move on:** exit check correct with a multiplication check.

### S06 — Guided practice: Division sharing stations (UO3)

- Every Set C answer must be checked by multiplying back before the
  session ends. A division answer without its check is unfinished work.
- **Reteach trigger:** correct digits but missing decimal point in 2+
  items → replay the money-sharing for that item only.

### S07 — Lesson 04: Money and measurement applications (UO4)

- **Require the sentence** "The question asks for ___" before any
  computation. Step-skipping (answering the total when change was asked)
  is the dominant error here, not arithmetic.
- The illustration activity: insist learners read all three prices aloud
  before computing. Learners who skip the reading invent prices.
- **Ready to move on:** exit check correct on both steps (total, then
  change).

### S08 — Week-04 formative quiz (UO1–UO4)

- Score the same day. Record, per learner, which objective is insecure:
  UO1 (items 1–2, 7, 11–12), UO2 (3–4, 8, 10), UO3 (5–6, 9), UO4 (7–9, 11).
- **Reteach block:** reteach only the weakest objective per learner
  before Week 13; do not re-teach the whole unit.

### S09 — Lesson 05: Choosing operations and reasonableness (UO4–UO5)

- **Estimate before computing, visibly.** If the estimate appears after
  the exact answer, it was not used — treat it as missing.
- Signal words are a starting hint, never a decision rule. Ask "What is
  happening in this story?" first.
- **Ready to move on:** exit check catches the 238 error by estimation
  and gives 23.8.

### S10 — Practice: Mixed-operation sprint (UO4–UO5)

- Set D answers without an estimate are incomplete, even when exact.
- **Reteach trigger:** exact answers right but estimates wild (e.g.
  estimating 6.25 + 3.4 as 100) → the learner is rounding the wrong
  place; reteach rounding to the nearest whole number (Unit 01).

### S11–S12 — Project sessions (UO1–UO5)

- Check the budget window early in S11: a plan over $50.00 wastes S12.
  The sample plan in the answer key is a teacher reference, not a list
  to hand out.
- **Honest remainders:** praise a team that reports leftover cents
  plainly; do not let a team fudge a division to look exact.
- Score with the project rubric; do not score the sample plan's list.

### S13 — Project presentations

- Each team presents one computation and answers one peer question.
  The peer question must be a "does that make sense?" question, not a
  repeat of the computation.
- Note any team whose presentation reveals a shaky objective — that
  learner gets a targeted station in S14.

### S14 — Review stations

- Four stations (add/subtract, multiply, divide, applications). Learners
  choose their weakest station first.
- End with each learner naming their strongest and weakest operation —
  that self-assessment goes on the assessment cover sheet.

### S15 — Culminating assessment (all objectives)

- 16 items; allow the full session. Score with
  [answer-key.md](answer-key.md#unit-assessment).
- **Readiness signals:** 13–16 correct with work shown → ready for
  Unit 04. 10–12 → targeted reteach on the missed objective, then a
  short re-check. Below 10 → reteach the flagged lesson(s) in full
  before Unit 04; do not advance on the strength of the project alone.

### S16 — Feedback and bridge

- Return assessments, correct each missed item with a place-value
  explanation (not just the right number), and preview Unit 04: the same
  decimal skills return when fractions need common denominators.
- File the reteach list with the unit record; the next unit's first
  session should re-check the weakest objective.

## Common misconceptions — quick reference

| Misconception | Where it appears | Fix |
|---|---|---|
| Right-edge alignment in addition/subtraction | Lesson 01, quiz Q12 | Place-value mat; "same size?" test |
| Subtracting smaller from larger per column | Lesson 01 G3 | Regroup aloud; check by adding back |
| Tenths × tenths = tenths | Lesson 02, quiz Q10 | Hundredths grid overlap count |
| Missing decimal point in a quotient | Lesson 03 G4 | "What place is this digit in?" |
| Stopping at a remainder instead of trading down | Lesson 03 | Trade to hundredths; 3 ÷ 4 = 0.75 |
| Answering the total when change was asked | Lesson 04, S07 | "The question asks for ___" sentence |
| Estimating after computing | Lesson 05, S10 | Grade the estimate separately |
