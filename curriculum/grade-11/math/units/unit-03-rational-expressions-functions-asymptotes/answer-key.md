# Answer Key — Unit 03: Rational Expressions, Functions, and Asymptotes

**For the guiding adult only. Do not place this file beside student
questions.** Every answer below was solved independently from the
student items and reconciled against them; where a lesson already
prints an answer in its guided practice, the key repeats it here so
the adult need not hunt through lessons. Restrictions are part of
every answer — an answer without them is incomplete.

## Lesson 01

- **Readiness:** 12/18 = 2/3; 12/0 undefined. Factors:
  `(x - 3)(x + 3)`, `x(x - 3)`, `(x - 2)(x + 2)`.
- **Guided:** 1. `x ≠ 1, -1`. 2. `(x - 1)/(x + 2)`, `x ≠ -1, -2`.
  3. `(x - 5)/(x - 5) = 1` only for `x ≠ 5`; at `x = 5` the original
  is undefined. 4. No — at `x = 0` the original is undefined, so
  the domain is `x ≠ 0`. 5. Denominator `(x - 1)^2`; `x ≠ 1`.
- **Independent:** 1. `(x - 4)/x`, `x ≠ 0, -4`. 2. `3(x + 2)/x`,
  `x ≠ 0, 2`. 3. `(x + 2)/(x - 1)`, `x ≠ -3, 1`. 4. False — a
  cancelled factor's zero survives as a restriction (Lesson 01,
  Modeled example 2). 5. `x + 3`, `x ≠ 3`; at `x = 3` the original
  is undefined while `x + 3` gives 6.
- **Application:** length `(x^2 - 9)/(x - 3) = x + 3`, `x ≠ 3`;
  in context `x > 3` (positive width and length).
- **Exit:** 1. `(x + 5)/x`, `x ≠ 0, 5`. 2. Before cancelling, from
  the original denominator. 3. No value; undefined (not 2).
- **Extension:** `(x^2 + 2x + 4)/(x + 2)`, `x ≠ 2, -2`.

## Lesson 02

- **Readiness:** 1/6 + 1/4 = 5/12. Division: quotient `x + 2`,
  remainder 3.
- **Guided:** 1. `x + 2`, `x ≠ -3, 2`. 2. `x + 3`, `x ≠ -1, 3`.
  3. `(x + 5)/((x - 1)(x + 1))`, `x ≠ 1, -1`. 4. `x - 2 +
  2/(x - 3)`, `x ≠ 3`; check `(x - 3)(x - 2) + 2 = x^2 - 5x + 8`.
  5. Flipping turns the divisor's numerator into a denominator,
  so its zeros become new restrictions.
- **Independent:** 1. `3x/((x + 2)(x - 1))`, `x ≠ -2, 1`.
  2. `(4x - 18)/((x + 3)(x - 3))`, `x ≠ 3, -3`.
  3. `x/(x + 3)`, `x ≠ -3, 3, -2`. 4. `x - 2`, `x ≠ -2, 2`.
  5. `3x - 1` (remainder 0), `x ≠ -2`; check
  `(x + 2)(3x - 1) = 3x^2 + 5x - 2`. 6. Error: denominators were
  added. Correct: `(2x + 1)/(x(x + 1))`, `x ≠ 0, -1`.
- **Application:** `(2x + 3)/(x(x + 3))` per hour, `x ≠ 0, -3`;
  in context `x > 0`.
- **Exit:** 1. `2x/(x^2 - 1)`, `x ≠ 1, -1`. 2. `x - 1 - 4/(x + 2)`,
  `x ≠ -2`; check `(x + 2)(x - 1) - 4 = x^2 + x - 6`.
  3. False — the divisor's numerator becomes a denominator.
- **Extension:** 1, for `x ≠ 1, -1` (the subtraction gives
  `2/(x^2 - 1)`; dividing by itself gives 1 wherever defined).

## Lesson 03

- **Readiness:** zero at `x = 1`; undefined at `x = -2`.
- **Illustration activity:** 1. The vertical dashed line — the
  function is undefined there, so no graph point lies on it and
  the branches cannot join across it. 2. A horizontal asymptote.
  3. The text alternative carries the same information.
- **Guided:** 1. Domain `x ≠ 2, -2`; hole `(-2, -1/4)`; vertical
  asymptote `x = 2`; no x-intercept; y-intercept `(0, -1/2)`.
  2. The input -2 is excluded, so its numerator zero is a hole,
  not an intercept. 3. Hole `(3, 6)`; no vertical asymptote.
  4. One answer: `x(x + 1)/((x - 1)(x + 1))` — hole
  `(-1, 1/2)`, asymptote `x = 1`, zero at 0; equivalents accepted.
  5. False — undefined at that input, so no point lies on the line.
- **Independent:** 1. `(x - 4)/(x - 2)`, `x ≠ 0, 2`; hole `(0, 2)`;
  vertical asymptote `x = 2`; x-intercept `(4, 0)`; no y-intercept
  (0 is excluded). 2. `2/x`, `x ≠ 0, -3`; hole `(-3, -2/3)`;
  vertical asymptote `x = 0`; no x-intercept; no y-intercept.
  3. `x + 1`, `x ≠ -1`; hole `(-1, 0)`; no vertical asymptote; no
  x-intercept (the only zero is excluded); y-intercept `(0, 1)`.
  4. One answer: `15(x - 2)/((x + 1)(x - 2))` — simplified
  `15/(x + 1)`, hole `(2, 5)`, asymptote `x = -1`, no x-intercept.
  5. `1/(x + 4)`, `x ≠ 4, -4`; hole `(4, 1/8)`; vertical
  asymptote `x = -4`. 6. The claims are both wrong: the function
  is `x + 1`, `x ≠ 1`, so `x = 1` is a hole at `(1, 2)`, and the
  x-intercept is `(-1, 0)`.
- **Application:** `A(n) = 18 + 2400/n`; algebraically `n ≠ 0`,
  in context `n` a positive whole number; `A(100) = 42`,
  `A(600) = 22`, approaching 18 dollars from above. The context
  graph is discrete points, so "asymptote" describes the
  formula's behaviour, not a line plotted points crowd against.
- **Exit:** 1. Hole `(3, 1/7)`; vertical asymptote `x = -4`; no
  x-intercept. 2. Cancel: a factor that leaves the denominator
  entirely gives a hole; one that remains gives an asymptote.
  3. No hole; `x = 2` is a vertical asymptote.
- **Extension:** `(x - 3)/(x - 2)`, `x ≠ 2`; vertical asymptote
  `x = 2` (the factor remains once in the denominator), zero at
  `x = 3`, y-intercept `(0, 3/2)`.

## Lesson 04

- **Readiness:** `3x^2` dominates.
- **Guided:** 1. (a) `y = 0` (`n < m`). (b) `y = 2` (`n = m`,
  4/2). (c) No horizontal asymptote; slant asymptote `y = x`
  (division: `x + x/(x^2 - 1)`). 2. Slant asymptote `y = x - 1`
  (quotient `x - 1`, remainder 3; check `(x - 2)(x - 1) + 3 =
  x^2 - 3x + 5`). 3. No crossing: `(x^2 - 4)/(x^2 - 1) = 1` gives
  `-4 = -1`, false. 4. Yes, crossing at `(2, 2)`:
  `(2x^2 + x)/(x^2 + 1) = 2` gives `x = 2`. 5. Vertical asymptote
  `x = -2`; horizontal asymptote `y = 1`; x-intercept `(1, 0)`;
  y-intercept `(0, -1/2)`; test points `f(-3) = -4`,
  `f(0) = -1/2`, `f(2) = 1/4`.
- **Independent:** 1. Vertical asymptote `x = 5`; horizontal
  asymptote `y = 3`; x-intercept `(-2/3, 0)`; y-intercept
  `(0, -2/5)`; end behaviour: approaches 3 from above on the
  right (`f - 3 = 17/(x - 5) > 0` for `x > 5`) and from below on
  the left. 2. Vertical asymptotes `x = 3, -3`; horizontal
  asymptote `y = 1`; no x-intercept; y-intercept `(0, -1/9)`;
  never crosses (`1 = -9` is false). 3. Slant asymptote `y = x +
  1` (remainder -4); vertical asymptote `x = -3`; y-intercept
  `(0, -1/3)`. 4. Slant asymptote `y = 2x - 3` (remainder 7);
  domain `x ≠ -1`. 5. No horizontal asymptote and no slant
  asymptote: the quotient is quadratic, so end behaviour follows
  a curve, not a line. 6. Error: degrees are 2 and 1, not equal,
  so the leading-coefficient ratio does not apply; division gives
  `x + 1 + 3/(x - 1)`, so the slant asymptote is `y = x + 1` and
  there is no horizontal asymptote.
- **Application:** horizontal asymptote `C = 0`; concentration
  eventually approaches zero. `C(0) = 0`, `C(2) = 10`,
  `C(10) = 400/104`, about 3.85 mg/L. Limit: a one-dose model; it
  says nothing about repeated doses and is not medical advice.
- **Exit:** 1. `y = 5/2`. 2. Slant asymptote `y = x - 2` — and
  since the division has remainder 0, `g(x) = x - 2` for
  `x ≠ -1`, with a hole at `(-1, -3)`. 3. Lower-degree terms
  become negligible compared with the leading term as
  `x` grows without bound.
- **Extension:** `x(x - 1)/(x + 1)`, `x ≠ 1, -1`; hole `(1, 0)`;
  vertical asymptote `x = -1`; slant asymptote `y = x - 2`
  (remainder `2/(x + 1)`; check `(x + 1)(x - 2) + 2 = x^2 - x`).

## Lesson 05

- **Readiness:** `x = 3`; check `3/(3 - 2) = 3`. Valid.
- **Guided:** 1. `x = 1/3`; check `2/(1/3) = 6`. Valid.
  2. `x = 0`; check `1/1 + 1/(-1) = 0`. Valid. 3. No solution:
  multiplying gives `2 = -1`, false — no candidate at all.
  4. `k = 240`; at 60 mph, `t = 4` hours (miles / (miles/hour)
  = hours). 5. `k = 120`; `L = 960` in the same load units.
- **Independent:** 1. `x = 5/2`; check `3/(3/2) = 2`. Valid.
  2. `x = -1`; check `-1 + 1/1 = 0`. Valid. 3. `x = 3`; check
  `6/4 = 6/4`. Genuine solution. 4. Simplify to `x + 3`,
  `x ≠ 3`; `x + 3 = 6` gives candidate `x = 3`, which is
  excluded — extraneous, so no solution. 5. Candidates
  `x = 3` and `x = -2`; -2 is nonviable (a negative time), so
  pipe A takes 3 hours and pipe B takes 6 hours; check
  `1/3 + 1/6 = 1/2`. 6. `k = 320`; `I(5) = 320/25 = 12.8`;
  as `d` grows, `I → 0` (horizontal asymptote `I = 0`).
- **Application:** equation `30/v + 30/(v - 4) = 4`, `v ≠ 0, 4`,
  in context `v > 4`; candidates about 17.26 and 1.74 mph; the
  second is nonviable (return speed would be negative); viable
  speeds about 17.3 mph out and 13.3 mph back; check
  `30/17.26 + 30/13.26 ≈ 4.00` hours.
- **Exit:** 1. `x = 2`; check `4/4 = 1`. Valid. 2. Candidate
  `x = 5` is excluded, so extraneous; no solution (the left side
  equals 1 wherever defined, never 2). 3. Only the original can
  distinguish genuine solutions from candidates created by
  multiplying.
- **Extension:** `x = 4/3`, not excluded; check: left side
  `3 + 6/7 = 27/7`, right side `3/(7/9) = 27/7`. Valid.

## Project — scoring guidance

Use the rubric in [project.md](project.md). The worked anchor
(`F = 2400`, `v = 18`) gives `A(100) = 42`, `A(600) = 22`,
horizontal asymptote `A = 18`, and the 10% level at the smallest
whole `n = 1,334` (from `2400/n ≤ 1.80`, i.e. `n ≥ 1333.33…`).
A learner with different `F` and `v` must show the same method:
both forms of `A(n)`, five computed values, a hand sketch with a
dashed `A = v` line checked against Desmos, the "never below `v`"
explanation from `F/n > 0`, the inequality step for the 10%
level, and two named model limits. A project with correct
arithmetic but no domain, no asymptote, or no model limits is
capped at 24/40, as the rubric states.
