# Practice — Unit 03: Rational Expressions, Functions, and Asymptotes

Work with pencil and paper; check every rational equation in its
original form, and state restrictions before simplifying. Full
worked answers are in [answer-key.md](answer-key.md), kept separate
from this student page. Sessions S2, S4, S7, S9, and S12 use these
sets in order; the review sessions return to the items marked with
a star.

## Practice Set A — Simplify and state the domain (Lesson 01; Session S2)

1. Simplify `(x^2 - 16)/(x^2 + 4x)`; state the domain.
2. Simplify `(3x^2 - 12)/(x^2 - 2x)`; state the domain.
3. Simplify `(x^2 + 5x + 6)/(x^2 + 2x - 3)`; state the domain.
4. Simplify `(x^2 - 10x + 25)/(x^2 - 25)`; state the domain.
5. Simplify `(2x^2 + 6x)/(x^2 - 9)`; state the domain.
6. True or false, with a reason: "After cancelling, the restrictions
   are just the zeros of the new denominator."
7. * A classmate simplified `(x^2 - 9)/(x - 3)` to `x + 3` and
   dropped the restriction. Write the correction: the full
   simplified form with its restriction, and one input value that
   shows why it matters.
8. Simplify `(x^3 - 27)/(x^2 - 9)`; state the domain. (Difference of
   cubes over difference of squares.)

## Practice Set B — Arithmetic and division (Lesson 02; Session S4)

1. Add: `2/(x + 2) + 1/(x - 1)`.
2. Subtract: `5/(x + 3) - 1/(x - 3)`.
3. Multiply and simplify: `(x^2 + 2x)/(x^2 - 9) * (x - 3)/(x + 2)`.
4. Divide and simplify: `(x^2 - 4x + 4)/(x + 2) ÷ (x - 2)/(x + 2)`.
5. Rewrite by division, and verify by multiplying back:
   `(3x^2 + 5x - 2)/(x + 2)`.
6. Rewrite by division, and verify by multiplying back:
   `(x^2 + 6x + 11)/(x + 3)`.
7. * Error analysis: a classmate wrote `1/x + 1/(x + 1) = 2/(2x + 1)`.
   Find the error, and give the correct sum with its domain.
8. Add and simplify fully: `1/(x - 2) + 2/(x + 2) - 1/(x^2 - 4)`.

## Practice Set C — Features from factored form (Lesson 03; Session S7)

For each function, give: domain, simplified form, hole(s) with
coordinates (if any), vertical asymptote(s), x-intercept(s),
y-intercept (or "none", with the reason).

1. `f(x) = (x^2 - 4x)/(x^2 - 2x)`
2. `f(x) = (2x + 6)/(x^2 + 3x)`
3. `f(x) = (x^2 + 2x + 1)/(x + 1)`
4. `f(x) = (x^2 - 5x + 6)/(x^2 - 4x + 4)`
5. * Write a rational function with a hole at `(2, 5)`, a vertical
   asymptote at `x = -1`, and no x-intercept. Justify each feature.
6. * For `f(x) = (x - 4)/(x^2 - 16)`, decide: hole or asymptote at
   `x = 4`? At `x = -4`? Give coordinates or the asymptote line.

## Practice Set D — Asymptotes, end behaviour, sketches (Lesson 04; Session S9)

1. For `f(x) = (3x + 2)/(x - 5)`, give the vertical asymptote,
   horizontal asymptote, intercepts, and end behaviour in words.
2. For `f(x) = (x^2 + 1)/(x^2 - 9)`, give both asymptotes, the
   intercepts, and say whether the graph crosses its horizontal
   asymptote (show the solving step).
3. Find the slant asymptote of `(x^2 + 4x - 1)/(x + 3)` and the
   vertical asymptote; then give the y-intercept.
4. Find the slant asymptote of `(2x^2 - x + 4)/(x + 1)` and state
   the domain.
5. Sketch by hand, then check with Desmos: `f(x) = (x - 1)/(x + 2)`.
   Mark domain, asymptotes, intercepts, and one test point per
   region. (Also the Lesson 04 guided task — repeated here as the
   session's sketch item.)
6. * A function has numerator degree 3 and denominator degree 1.
   Does it have a horizontal asymptote? A slant asymptote? Explain
   in one paragraph.
7. * Error analysis: a classmate wrote that `(x^2 + 2)/(x - 1)` has
   horizontal asymptote `y = 1` "because the leading coefficients
   are both 1." Correct the error.
8. Analyse fully, by hand and with a Desmos check:
   `f(x) = (2x - 4)/(x + 3)` — the function of the unit's exact SVG
   graph. Your feature list should match the SVG's labels.

## Practice Set E — Equations and variation (Lesson 05; Session S12)

Solve with restrictions stated first and checks shown in the
original equation. Classify each result as a genuine solution, an
extraneous solution, or no solution.

1. Solve `3/(x - 1) = 2`.
2. Solve `1/x + 1/(x + 2) = 0`.
3. Solve `(2x)/(x + 1) = (x + 3)/(x + 1)`.
4. Solve `(x^2 - 9)/(x - 3) = 6`. (Hint: simplify first, but keep
   the restriction.)
5. * Work-rate equation: pipe A fills a tank in `x` hours, pipe B
   in `x + 3` hours; together they fill it in 2 hours. Write and
   solve `1/x + 1/(x + 3) = 1/2`, reject any nonviable solution
   with a reason, and state the two times.
6. * Inverse variation: light intensity `I` varies inversely with
   the square of the distance `d` from the source: `I = k/d^2`.
   If `I = 80` (in given units) at `d = 2`, find `k`, then find `I`
   at `d = 5`, and say what happens to `I` as `d` grows large, in
   the language of Lesson 04.
7. Joint variation: `y` varies directly with `x` and inversely with
   `z`: `y = kx/z`. If `y = 12` when `x = 4` and `z = 3`, find `k`,
   then find `y` when `x = 10` and `z = 5`.
8. * A cyclist rides 30 miles out at speed `v` mph and returns at
   `v - 4` mph, taking 4 hours in total. Write the rational
   equation, solve it, and reject any nonviable speed with a
   reason. (Approximate answers to one decimal place are accepted;
   the unit check and the rejection reason are required.)
