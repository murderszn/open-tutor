# Teacher Guide — Unit 03: Rational Expressions, Functions, and Asymptotes

**For the guiding adult.** This guide is kept separate from student
materials. It states what "ready to move on" looks like, the
misconceptions to watch for, and what to re-teach when evidence
shows a gap. Full worked answers are in
[answer-key.md](answer-key.md).

## Session-by-session guidance

- **S1–S2 (Lesson 01, Set A):** insist on the order — restrictions
  first, from the original denominator, every time. If a learner
  writes a simplified form without restrictions, treat the item as
  incomplete, not as a presentation slip. The number-fraction
  analogy (12/18, 12/0) is the fastest repair for "cancelling
  terms" errors.
- **S3–S4 (Lesson 02, Set B):** the multiply-back check is
  mandatory for every long division. For addition, the most common
  error is adding denominators; the number counterexample
  (1/2 + 1/3 = 5/6, not 2/5) should be produced by the learner,
  not just told to them.
- **S6–S7 (Lesson 03, Set C):** use the four-row feature table
  (domain / zeros / asymptotes / holes) for every analysis. The
  hole/asymptote discrimination — "cancel first, then ask what
  remains in the denominator" — is the unit's central skill; drill
  it until it is automatic, because Lesson 04 and the assessment
  both assume it.
- **S8–S9 (Lesson 04, Set D):** require the degree comparison
  before any asymptote is written. The horizontal-asymptote
  crossing example (Lesson 04, guided task 4: the graph of
  `(2x^2 + x)/(x^2 + 1)` crosses `y = 2` at `(2, 2)`) should be
  worked, not skipped — it prevents the most durable
  over-generalisation in the unit.
- **S10 (Project Part 1):** approve the situation only when units
  divide correctly (dollars / items = dollars per item) and the
  domain is stated both algebraically and in context. Reject any
  real business's actual costs — this project uses invented,
  labelled assumptions.
- **S11–S12 (Lesson 05, Set E):** the first line of every solution
  must be "Restrictions: ___". A solution checked only in the
  multiplied equation is unfinished. Distinguish, in feedback,
  algebraic extraneous solutions (rejected because the original
  equation is undefined there) from context-nonviable solutions
  (which solve the equation but are impossible in context, like a
  negative time).
- **S13 (Reading):** the learner restates Paul's Online Notes'
  five-step graphing process in their own words and applies it to
  one new function. Copying the process verbatim does not meet
  the session's success criterion.
- **S14–S15 (Project Part 2, review):** the memo's 10% question is
  an inequality in `n` with `n > 0`, so the direction is preserved
  when dividing — if a learner flips it, re-teach inequality
  direction with positive multipliers before marking the memo.
- **S16–S20 (Workshop, gallery, quiz, assessment, flex):** see the
  reteach triggers below and the scoring guides in the quiz and
  assessment files.

## Readiness criteria (what "secure" means)

The learner is ready for Unit 04 when they can, without prompting:

1. Simplify a rational expression and state every restriction,
   including one that survives cancelling.
2. Add, subtract, multiply, and divide rational expressions, and
   rewrite one by long division with a multiply-back check.
3. Analyse a factored rational function: domain, zeros, holes with
   coordinates, vertical asymptotes, intercepts.
4. Determine horizontal and slant asymptotes from degrees and
   division, and describe end behaviour in words.
5. Solve a rational equation with a check in the original equation,
   and classify the result honestly (including "no solution").

## Misconceptions — what to watch, and the repair

| Misconception | Repair |
|---|---|
| Cancelling terms instead of factors | Number fractions first: 12/18, and why `(x + 3)/x` is not 3 |
| Restrictions dropped after cancelling | "Restrictions first" order, enforced for two weeks; log it in the answer-key record |
| Every denominator zero is an asymptote | "Cancel first, then ask what remains" — hole if the factor leaves the denominator entirely |
| A hole's input counted as an intercept | Excluded inputs cannot be intercepts; the hole's coordinates are an open circle, not a point on the graph |
| Horizontal asymptotes are never crossed | Worked crossing example `(2x^2 + x)/(x^2 + 1)` at `(2, 2)`; crossing is about finite `x`, approaching is about `x → ±∞` |
| Leading-coefficient ratio used regardless of degrees | Degree comparison first, every time; the ratio applies only when `n = m` |
| Slant asymptote claimed whenever `n > m` | Only `n = m + 1` gives a line; larger gaps give a curve as end behaviour, not an asymptote line |
| Checking in the multiplied equation | The check must be in the original; a candidate that "checks" after multiplying is the extraneous case |
| Extraneous reported as the answer | Final sentence must be "no solution" or "the solution is …" — never a bare candidate list |
| Context-nonviable treated as algebraically extraneous (or vice versa) | Name the rejection reason: "undefined in the original" vs. "impossible in context" |

## Re-teach triggers

- **Quiz below 21/30, or Part A of the assessment weak:** re-teach
  Lessons 01 and 03 with Practice Sets A and C (starred items
  first), then re-assess with one new factored function.
- **Part B weak:** re-teach Lesson 04's degree table with
  Practice Set D items 1–4 and 7; require the degree row to be
  pointed to before any asymptote is written.
- **Part C weak:** re-teach Lesson 05 with Practice Set E items
  1–4; require "Restrictions: ___" as the first line and the
  check in the original equation as the last line.
- **Project weak on units or domain:** return Part 1 for revision
  before Part 2 is marked; do not let a unit error ride through
  the whole project.
- **If the learner is not secure after Session 19:** use the
  track's flexible weeks (diagnostic/catch-up) before Unit 04.
  Do not start radical functions on top of insecure rational
  functions — Unit 04's extraneous-solution work assumes this
  unit's checking habit.
