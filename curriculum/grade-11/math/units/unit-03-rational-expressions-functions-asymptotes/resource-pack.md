# Resource Pack — Unit 03: Rational Expressions, Functions, and Asymptotes

## Summary

**Goal:** give the learner and the guiding adult free, no-account
routes to support simplifying rational expressions, rational
arithmetic and long division, graphing with zeros, asymptotes, and
holes, and solving rational equations with extraneous-solution
checks.
**Age fit:** grade 11 (about 16–17); all items are symbolic,
graphical, or adult-facing reference, with no reading required
below grade level.

## Web references

Checked 2026-10-22 unless noted. "Verified live" means the page
was opened and read on that date; where a page did not render, that
is stated rather than smoothed over.

1. **Paul's Online Math Notes (Lamar University) — Algebra,
   Section 4.8: Rational Functions**
   `https://tutorial.math.lamar.edu/Classes/Alg/GraphRationalFcns.aspx`
   *Why:* the unit's closest worked reference — definitions of
   vertical and horizontal asymptotes, the degree facts, and the
   five-step graphing process, with fully worked graphing examples
   (including `f(x) = 1/x`, `(3x + 6)/(x - 1)`, and a
   hole/asymptote example). Verified live 2026-10-22: page opened
   and read. Free, no account. Learner-facing with adult guidance.
2. **LibreTexts — Graphing Rational Functions (Cosumnes River
   College Corequisite Codex, Section 15.2)**
   `https://math.libretexts.org/Courses/Cosumnes_River_College/Corequisite_Codex/15%3A_Rational_Functions/15.02%3A_Graphing_Rational_Functions`
   *Why:* the hole theorem and the intercept theorem stated
   precisely, plus the caution that domain restrictions and holes
   are found from the *original* denominator before cancelling —
   the exact warning Lesson 01 and Lesson 03 teach. Found via web
   search 2026-10-22 and its key theorems read in the search result;
   the adult previews the full page before assigning. Free, no
   account. Learner-facing with adult guidance.
3. **Khan Academy — "Another rational function graph example"
   (Algebra II, graphs of rational functions)**
   `https://en.khanacademy.org/math/algebra-home/alg-rational-expr-eq-func/alg-graphs-of-rational-functions/v/another-rational-function-graph-example`
   *Why:* a worked graphing example (`y = 2x/(x + 1)`, horizontal
   asymptote `y = 2`, vertical asymptote `x = -1`) matching
   Lesson 04's method. Found via web search 2026-10-22; its
   transcript was read in the search result, but the page itself
   did **not** render in a text browser on 2026-10-22 (a client
   challenge page loaded instead), so the adult previews it in a
   real browser before assigning. Free; a Khan Academy account is
   optional for viewing.
4. **Desmos Graphing Calculator (free web calculator)**
