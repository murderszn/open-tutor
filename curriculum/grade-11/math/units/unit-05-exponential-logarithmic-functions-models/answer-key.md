## Lesson 01

- **Readiness:** 1. `3 · 2^4 = 48`; `3 · (1/2)^2 = 3/4`. 2. The
  first grows by equal differences; the second by equal factors.
  3. `b^0 = 1`, so the graph crosses the y-axis at `(0, a)`.
- **Guided:** 1. `a = 3`, `b = 1.5`, +50%, growth; `f(2) = 3 · 2.25 =
  6.75`. 2. `f(x) = 80 · (0.75)^x`; at step 2, `80 · 0.5625 = 45`.
  3. Table: `x = −1 → 8`, `0 → 4`, `1 → 2`, `2 → 1`; intercept
  `(0, 4)`, asymptote `y = 0`, range `y > 0`. 4. Rate 3%;
  `P(10) ≈ 1612.7`, so 1,613 animals to the nearest whole animal —
  a reporting choice, since the model is continuous. 5. False:
  `b^x > 0` always, so the graph approaches but never reaches 0.
- **Independent:** 1. Decay rate 20%; `h(3) = 250 · 0.512 = 128`;
  asymptote `y = 0`. 2. `5^(−x) = (1/5)^x` is the reflection of
  `5^x` across the y-axis (replace `x` by `−x`); `g` decays because
  its base `1/5` is between 0 and 1.
- **Applied (lily pond):** 1. Half on day 29, quarter on day 28.
  2. `C(30) = 2^0 = 1`; `C(29) = 2^(−1) = 1/2`; `C(28) = 2^(−2) =
  1/4`. 3. Day 25: `2^(−5) = 1/32`. Day 15 is wrong because halving
  works backward one day at a time from day 30, not by halving the
  day number.
- **Exit:** 1. Initial value 60, +12%. 2. No x-intercept: `1.12^x >
  0` always, so `60 · 1.12^x` is never 0.
- **Extension:** yearly factor `(1.02)^12 ≈ 1.268`, a 26.8% yearly rate.

## Lesson 02

- **Readiness:** 1. Differences 6, 6, 6. 2. Ratios 2, 2, 2.
  3. Second differences 2, 2 — constant, the quadratic signature.
- **Guided:** 1. Exponential, factor 1.5 (`y = 8 · 1.5^x`).
  2. Quadratic (second difference 2). 3. `[0, 2]`: `(9 − 1)/2 = 4`
  per unit; `[2, 4]`: `(81 − 9)/2 = 36` per unit — larger, because
  the function's values are larger later. 4. Over two or three
  points, a line and an exponential can both pass close to the
  points; only the difference/ratio test over several intervals
  distinguishes them. 5. Error: the differences are not constant
  (6, 12, 24); the ratios are constant at 2 — exponential, not linear.
- **Independent:** 1. Linear: $1,600 at year 20. Exponential:
  `1000 · 1.03^20 ≈ $1,806.11` — larger by about $206.
  2. (Open response; acceptable: exponential growth multiplies by a
  fixed factor each step, so its yearly increase grows with the
  quantity itself, while a linear increase stays fixed; the growing
  increase must eventually pass any fixed increase and keep widening
  the gap.)
- **Exit:** 1. Linear — differences constant at 6. 2. `(32 − 4)/3 =
  28/3 ≈ 9.33` per unit.

## Lesson 03

- **Readiness:** 1. `x = 5`; `x = −2`. 2. `f(0) = 1`, `f(3) = 8`;
  so `g(1) = 0`, `g(8) = 3`. 3. No input: `2^x > 0` always.
- **Guided:** 1. `log_6(36) = 2`; `2^6 = 64`. 2. `log_3(27) = 3`;
  `log_10(0.0001) = −4`; `log_8(1) = 0`; `log_2(√2) = 1/2`.
  3. Between 5 (`2^5 = 32`) and 6 (`2^6 = 64`); about 5.64.
  4. `4^x = 1024 → x = 5`; `log_9(x) = 2 → x = 81`. 5. False:
  the argument is negative (undefined), and `2^(−3) = 1/8`, not `−8`.
- **Independent:** 1. `log_b(1) = 0` because `b^0 = 1`;
  `log_b(b) = 1` because `b^1 = b`. 2. `g(1000) = 3`
  (`10^3 = 1000`); `g(0.01) = −2` (`10^(−2) = 0.01`).
- **Exit:** 1. `5^4 = 625`; verified: `5^4 = 625`. ✓
  2. No exponent makes `3^y = 0` (powers of 3 are positive), so
  `log_3(0)` is undefined.

## Lesson 04

- **Readiness:** 1. `2^7 = 128`; `2^3 = 8`. 2. `log_2(8) = 3`,
  `log_2(4) = 2`; sum 5; `log_2(32) = 5`. 3. `log(100) − log(10) =
  2 − 1 = 1` (also `log(100/10) = log(10) = 1`).
- **Guided:** 1. `log_3(27) + 2·log_3(x) = 3 + 2·log_3(x)`.
  2. `log_2(x·y^3)`. 3. By definition: `4^3 = 64`, so `log_4(64) =
  3`; by splitting: `log_4(16) + log_4(4) = 2 + 1 = 3`.
  4. `log_7(50) = ln(50)/ln(7) ≈ 3.9120/1.9459 ≈ 2.010`; check
  `7^2.010 ≈ 49.96` (rounding in the third decimal; exact value
  2.01038…). 5. Error: `log(10 + 10) = log(20) ≈ 1.301`, not
  `log(10) + log(10) = 2`; the sum computed `log(10 · 10)`.
- **Independent:** 1. `ln(3) + 4·ln(x) − (1/2)·ln(y)`, domain
  `x > 0`, `y > 0`. 2. (Open response; acceptable: `b^p + b^q`
  cannot be written as a single power `b^r` in general, so no
  logarithm identity can turn a sum inside into a sum outside.)
- **Exit:** 1. `log(x / y²)`. 2. `log_6(216) = 3` (`6^3 = 216`).

## Lesson 05

- **Readiness:** 1. `x = 7`. 2. `x = 243`. 3. The argument `x − 2`
  must be positive, so `x > 2`; any candidate at or below 2 is
  extraneous before it is even checked.
- **Guided:** 1. `t = 7`. 2. `x = 2`. 3. Domain `x > 1/2`;
  `x = 41`; check: `log_3(81) = 4`. ✓ 4. Domain `x > 1`;
  candidates `3` and `−2`; `3` checks (`log(3) + log(2) =
  log(6)`); `−2` is extraneous (domain). 5. `t = 15` hours.
- **Independent:** 1. Exact: `t = ln(2.5)/0.02`; about 45.81 years.
  2. (Open response; acceptable: the combined equation's domain is
  wider than the original's — combining hid the separate arguments
  — so a root of the combined equation may violate the original's
  domain, as `x = −2` did in Worked example 2.)
- **Exit:** 1. Exact: `x = log_2(100)`; about 6.64.
  2. Not extraneous: `log(0 + 1) = log(1) = 0` is defined; it must
  still satisfy the full equation to be accepted.

## Lesson 06

- **Readiness:** 1. Domain `x > 0`, x-intercept `(1, 0)`,
  asymptote `x = 0`. 2. The argument is `x − 1`, so the asymptote
  moves to `x = 1`; `+ 2` shifts the graph up 2. 3. `y = 150 ·
  1.5^x`.
- **Guided:** 1. Domain `x > −2`, asymptote `x = −2`,
  x-intercept `(1, 0)` (`log_3(x + 2) = 1 → x = 1`).
  2. Model about `200 · 1.3^t`; at `t = 5`, about `200 · 3.71293 ≈
  743`; limit: assumes the 30% rate continues unchanged.
  3. `a = 80`, `b = 2`; `y = 80 · 2^x`. 4. Residuals: `98 − 100 =
  −2`; `155 − 150 = +5`; `220 − 225 = −5` — small and scattered,
  a good fit. 5. False: a logarithmic function has a vertical
  asymptote, not a horizontal one.
- **Independent:** 1. `h` is `log_2(x)` shifted down 3;
  `k` is `log_2(x)` reflected across the x-axis (decreasing).
  2. Model `500 · 0.8^t`; `t = 6 → 500 · 0.262144 ≈ 131.07`,
  about 131; real decay may slow toward a floor or stop.
- **Exit:** 1. Domain `x > 4`, asymptote `x = 4`. 2. Residuals are
  negative (observed below predicted) at every point — a systematic
  bias, suggesting the model's initial value or rate is too high.
