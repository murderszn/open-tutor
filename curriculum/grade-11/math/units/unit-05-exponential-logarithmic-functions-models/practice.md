# Practice — Unit 05: Exponential and Logarithmic Functions and Models

Work each set after its lesson. Show every step; a bare answer earns
no credit in this unit, because the unit's skill *is* the reasoning.
Answers are in [answer-key.md](answer-key.md), for the guiding adult.

## Set A — Exponential functions (Lesson 01)

1. For `f(x) = 2 · 3^x`, state the initial value, base, percent rate,
   asymptote, and range. Evaluate `f(3)`.
2. Write the function for: starts at 1,200, grows 5% per step. Find
   the value after 4 steps.
3. A quantity decays by 15% per hour from 400. Write its function and
   find the value after 2 hours.
4. Sketch `y = 6 · (1/3)^x` from `x = −1, 0, 1, 2`. Label the
   intercept and asymptote.
5. True or false, with a reason: "`f(x) = 0.5^x` and `g(x) = 2^(−x)`
   are the same function."
6. A car worth $20,000 depreciates 12% per year. Write `V(t)` and
   estimate `V(5)` to the nearest dollar. State one limit of the model.

## Set B — Comparing growth (Lesson 02)

1. Classify each table (linear, quadratic, or exponential) and give
   the model:
   a. `x = 0, 1, 2, 3` → `y = 4, 10, 16, 22`.
   b. `x = 0, 1, 2, 3` → `y = 4, 12, 36, 108`.
   c. `x = 0, 1, 2, 3` → `y = 1, 4, 9, 16`.
2. Average rate of change of `f(x) = 2^x` on `[0, 3]` and on `[3, 6]`.
   Compare them and explain the difference in one sentence.
3. Two models for a fund: linear `L(t) = 500 + 25t` and exponential
   `E(t) = 500 · 1.05^t`. Evaluate both at `t = 20`. Which is larger,
   and does that surprise you given Lesson 02's crossover discussion?
4. Error analysis: "The outputs 3, 9, 27, 81 grow linearly because
   the differences 6, 18, 54 keep growing steadily." Correct it.

## Set C — Logarithms as inverses (Lesson 03)

1. Convert to logarithmic form: `7^3 = 343`; `10^(−2) = 0.01`.
2. Convert to exponential form: `log_4(256) = 4`; `log_2(1/32) = −5`.
3. Evaluate without a calculator: `log_5(125)`, `log_10(1,000,000)`,
   `log_3(1/27)`, `log_9(3)`.
4. Solve: `6^x = 216`; `log_8(x) = 2`; `log(x) = −1` (common log).
5. Estimate `log_3(100)` between two whole numbers, then approximate
   it with technology to two decimal places.

## Set D — Logarithm properties (Lesson 04)

1. Expand: `log_2(16x^4)` for `x > 0`; `log(x²y / 10)` for `x > 0`,
   `y > 0`.
2. Condense: `3·log(x) − log(y)`; `log_5(25) + log_5(x)`.
3. Evaluate `log_2(96)` by splitting `96 = 32 · 3` and using
   `log_2(3) ≈ 1.585`. Check by change of base.
4. Use change of base to evaluate `log_4(90)` to two decimal places.
5. Error analysis: a classmate condenses `log(a) + log(b)` as
   `log(a + b)`. Show a numerical counterexample that proves it wrong.

## Set E — Solving equations (Lesson 05)

1. Solve `4^(x−1) = 64`.
2. Solve `250 · (1.02)^t = 500`. Give the exact answer and an
   approximation to one decimal place. What does this answer mean
   in context (doubling time at 2%)?
3. Solve `log_5(x) + log_5(x − 4) = 2`. State the domain first and
   check every candidate.
4. Solve `200·e^(0.03t) = 600`. Give the exact answer and an
   approximation to two decimal places.
5. Solve `log_2(3x − 5) = 4`. Check the answer in the original equation.
6. A sample decays as `A(t) = 1200 · 0.75^t` (t in days). After how
   many days is the amount below 400 for the first time? Solve by
   logarithms and state whether the answer is a whole number of days
   or a threshold time, and why the distinction matters.

## Set F — Logarithmic graphs and modeling (Lesson 06)

1. For `f(x) = log_2(x − 3) + 1`, state the domain, asymptote,
   x-intercept, and one additional point. Sketch it.
2. For `g(x) = ln(x + 1)`, state the domain, asymptote, and
   x-intercept.
3. Fit by hand: points `(0, 50)` and `(2, 200)` on `y = a·b^x`. Write
   the model and predict at `x = 4`.
4. A dataset (fictional practice data): `t = 0, 1, 2, 3` →
   `y = 90, 117, 152, 198`. Test the ratios, write an approximate
   model, and compute the residual at `t = 2` for your model.
5. Two models predict a value of 80: Model A was fitted to data
   spanning `x = 0` to `10` and predicts at `x = 11`; Model B was
   fitted to data spanning `x = 0` to `3` and predicts at `x = 11`.
   Which prediction should be trusted more, and why?
