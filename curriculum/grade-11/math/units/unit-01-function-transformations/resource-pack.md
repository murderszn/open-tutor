## Parent-function library (Session S8 reading reference)

Copy this table into the function notebook; it is the reference for
the rest of the year.

| Parent `f(x)` | Domain | Range | Key features |
|---|---|---|---|
| `x` (identity) | all reals | all reals | odd; slope 1; through origin |
| `x²` (quadratic) | all reals | `[0, ∞)` | even; vertex (0,0) minimum; symmetric |
| `x³` (cubic) | all reals | all reals | odd; origin symmetry; through origin |
| `|x|` (absolute value) | all reals | `[0, ∞)` | even; V-shape; vertex (0,0) |
| `√x` (square root) | `[0, ∞)` | `[0, ∞)` | starts at (0,0); increasing, concave down |
| `1/x` (preview) | `x ≠ 0` | `y ≠ 0` | odd; two branches; Unit 03's subject — listed here only so transformations practiced now transfer later |
| `2ˣ` (preview) | all reals | `(0, ∞)` | through (0,1); growth; Unit 05's subject — same note as above |
