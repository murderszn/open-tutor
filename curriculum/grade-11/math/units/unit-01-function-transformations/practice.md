Student practice for Sessions S2, S4, S7, S12, S14. Work in the
notebook; the adult scores same-day. All solutions are in

## Practice Set A — the function concept (S2)

A1. For `f(x) = 2x² − 5`: compute `f(−3)`, `f(0)`, and `f(a + 1)`
   (leave the last unsimplified-then-simplified; show both steps).

A2. A parking meter charges $1.25 per hour or fraction thereof, up to
   4 hours. Write `M(h)` with its realistic domain (note the
   "fraction thereof" — what kind of function is this?) and interpret
   `M(2.5)`.

A3. Determine whether each relation is a function of `x`. Justify with
   the vertical line test or a counterexample point pair.
   a) `{(−1, 2), (0, 2), (1, 2), (2, 5)}`  b) `y² + x = 4`
   c) The graph of `y = |x − 3|`.

A4. For the graph through points (−3, 0), (−1, 4), (0, 5), (2, 5),
   (4, 1): state domain and range as sets, and decide whether it
   could be the graph of a function.

A5. Classify as even, odd, or neither. Show the `f(−x)` algebra.
   a) `f(x) = 4x⁶ − 2x² + 7`  b) `g(x) = x³ + 5x`  c) `h(x) = eˣ`
   (for c, compare `h(−x) = e⁻ˣ = 1/eˣ` with `h(x)` and `−h(x)`).

A6. (Retrieval) Solve `3(x − 2) + 5 = 2x + 1`, justifying each step.

A7. (Retrieval) Plot `y = −x + 3` for `x = 0, 1, 2, 3` and state its
   x- and y-intercepts.

## Practice Set B — vertical transformations (S4)

B1. Let `f(x) = x³`. For each, predict the transformation in words,
   then verify by evaluating at `x = −1, 0, 1, 2`:
   a) `g(x) = f(x) + 4`  b) `h(x) = −f(x)`  c) `k(x) = (1/2)f(x) − 1`.

B2. The vertex of `f(x) = 2(x − 3)² + 1` is `(3, 1)`. Describe the
   transformations of `y = x²` that produce `f`, in order, and verify
   the vertex by completing the square (show the steps).

B3. `f` passes through `(2, 5)`; `g(x) = af(x)` passes through
   `(2, −15)`. Find `a` and describe the transformation. Then give
   the image of the point `(2, 5)` under `g(x) = af(x) + 2` for the
   same `a`.

B4. Write the function whose graph is `y = √x` shifted up 3 and
   vertically compressed by factor `1/4`. State its domain and range.

B5. Explain why the graphs of `y = f(x) + k` and `y = f(x)` never
   intersect when `k ≠ 0`, but the graphs of `y = kf(x)` and
   `y = f(x)` always intersect at every x-intercept of `f`. (Two
   short arguments.)

B6. (Retrieval — Lesson 01) Is `f(x) = x⁴ − x` even, odd, or neither?
   Justify algebraically.

B7. (Retrieval — Lesson 01) A gym membership costs $40 sign-up plus
   $25/month. Write `C(m)`, state the realistic domain, and interpret
   `C(6) = 190`.

## Practice Set C — horizontal transformations (S7)

C1. From `f(x) = x²`, predict-then-verify (table at `x = −2, −1, 0,
   1, 2`):
   a) `g(x) = f(x − 3)` — which direction, and why?
   b) `h(x) = f(2x)` — stretch or compression, and why?
   c) `k(x) = f(−x)` — what symmetry does this reveal about `f`?

C2. Describe in order the transformations from `f(x) = |x|` to
   `g(x) = 3|−2(x + 4)| − 5`. (Factor the input expression first;
   then track the vertex `(0, 0)` through the whole chain.)

C3. A function `f` has domain `[−2, 6]`. State the domain of
   a) `g(x) = f(x + 5)`  b) `h(x) = f(3x)`  c) `k(x) = f(x) − 5`.
   Explain why (c)'s domain is unchanged but (a)'s and (b)'s move.

C4. Find `k` (show the matched pair and the verification):
   `f` has vertex `(2, −1)`; `g(x) = f(x + k)` has vertex `(−4, −1)`.

C5. Prove algebraically that `f(x) = x⁵ − 3x³ + x` is odd, and sketch
   what its graph must look like near the origin as a consequence
   (it passes through the origin — why must it?).

C6. (Retrieval — Lesson 02) Write the image of the point `(3, 7)`
   under `y = −2f(x) + 1`, and describe the transformation in words.

C7. (Retrieval — Lesson 01) Give the domain and range of
   `f(x) = √(x − 2)` and explain the restriction in one sentence.

## Practice Set D — composition (S12)

D1. A factory paints `p = 4t + 10` toys in `t` hours; each toy needs
   `c = 0.5p + 3` dollars of paint and labor… (check: units) —
   a) write cost as a function of hours; b) verify the units cancel;
   c) compute the cost for a 6-hour shift two ways (composite and
   stage-by-stage) and confirm they agree.

D2. For `f(x) = x² + 2x` and `g(x) = x − 4`: compute `(f∘g)(x)` and
   `(g∘f)(x)` in expanded form, evaluate both at `x = 1`, and write
   two sentences on why the results differ.

D3. Decompose each into an inner and an outer function, and verify by
   recomposing:
   a) `h(x) = (x³ + 1)⁴`  b) `k(x) = √(5 − 2x)`  c) `m(x) = 2^(3x−1)`
   (for c, an exponential is fine — name the stages).

D4. Find the intersection points of `y = x + 2` and `y = x² − 4x + 2`
   exactly; then state what equation the x-coordinates solve.

D5. Compute the average rate of change of `h(x) = (2x + 1)²` on the
   interval `[1, 4]`, and interpret it for the context "a square
   garden's area as its side length grows." (Units required.)

D6. (Retrieval — Lesson 03) Describe the transformations, in order,
   from `f(x) = x³` to `g(x) = −2(3x + 9)³ + 1`.

D7. (Retrieval — Lesson 02) If `f(−2) = 6`, what is `g(−2)` for
   `g(x) = 3f(x) − 4`? Show the substitution.

## Practice Set E — inverses (S14)

E1. Solve for `x`, justifying each step: a) `5x − 9 = 31`
   b) `(2/3)x + 4 = 10`.

E2. Find the inverse of each by swap-and-solve, and verify with both
   compositions:
   a) `f(x) = 7x + 3`  b) `g(x) = (x + 8)/4`  c) `h(x) = ∛(2x − 6)`.

E3. A car-sharing service charges `C(m) = 8 + 0.60m` dollars for `m`
   miles (`0 ≤ m ≤ 200`).
   a) Write `C⁻¹` and interpret it in a full sentence with units.
   b) State the domain and range of `C⁻¹` as intervals.
   c) Use `C⁻¹` to find how many miles $50 buys; verify by evaluating
   `C` at your answer.

E4. Determine whether each function is one-to-one on the given domain
   (horizontal line test or counterexample pair):
   a) `f(x) = 4 − x²`, domain all reals
   b) `g(x) = 4 − x²`, domain `x ≤ 0`
   c) `h(x) = 2x³ − 5`, domain all reals. If invertible, write the
   inverse.

E5. The graph of an invertible function `f` passes through `(1, 5)`,
   `(2, 9)`, `(3, 14)`. Write three points on the graph of `f⁻¹`
   and explain the coordinate swap.

E6. (Retrieval — Lesson 04) For `f(x) = √x`, `g(x) = x² − 3`: write
   `(f∘g)(x)` with its domain, and `(g∘f)(x)` with its domain.

E7. (Retrieval — Lesson 03) Is `f(x) = 2x⁴ + x² − 3` even, odd, or
   neither? One line of algebra.
