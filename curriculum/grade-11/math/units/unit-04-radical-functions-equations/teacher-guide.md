# Teacher Guide — Unit 04: Radical Functions and Equations

## How to use this guide

Student materials never contain answers. This guide and
[answer-key.md](answer-key.md) are the adult's copies: session
notes, misconception alerts, reteaching moves, and readiness
criteria. Keep them separate from the learner's pages.

## Session-by-session notes

- **S1 (Lesson 01).** Insist the index is spoken aloud on every
  conversion for the first week ("fourth root of sixteen" before
  writing `⁴√16`). The principal-root convention (`√16 = 4`, never
  `±4`) is the single fact that prevents half of Lesson 04's
  errors; test it orally before moving on.
- **S2 (Practice A).** A8 is the lesson's thesis in one item. If
  the learner still splits roots over sums, return to the numeric
  counterexample `√(9 + 16) = 5 ≠ 7` rather than to the rule.
- **S3 (Lesson 02).** Make the learner write the factored radicand
  form before reading any shift. `√(2x − 6)` started at 6 is the
  most common graphing error in the unit.
- **S4 (Practice B).** Check hand sketches against Desmos only
  after the domain, range, and starting point are written down;
  otherwise the tool does the thinking.
- **S5 (Review).** Error-analysis cards: one flawed simplification
  (`√72 = 8√9`? no — `√72 = 6√2`; a card might claim `√72 = 9√8`)
  and one flawed domain (`x > 3` for `√(x − 3)`). The learner
  corrects in writing, naming the rule broken.
- **S6 (Lesson 03).** Contrast drill: give a domain and ask which
  family it belongs to. "Domain all reals" must instantly say
  "cube root (or other odd index)", never "square root".
- **S7 (Practice C).** C5 (the inverse) is the Unit 01 payoff;
  if the learner cannot explain the restriction difference, revisit
  the one-to-one test before Lesson 04.
- **S8 (Lesson 04).** Teach the check as a mathematical step, not
  housekeeping. Require the check line on every problem, including
  the ones that "obviously" work — the habit must be automatic
  before two-radical equations arrive.
- **S9 (Practice D).** D4 (no solution) and D7 (error analysis)
  are the discriminating items. A learner who reports {2, 5} on D7
  has not yet internalized the check.
- **S10 (Project studio 1).** Approve the route and the quantity
  definitions in writing. For Route 1, verify the support is stable
  and the swing path is clear; for Route 3, verify the memo plan
  labels the data as fictional practice data.
- **S11 (Lesson 05).** Number the two squaring steps in the margin.
  The exit check (a solvable two-radical equation) separates
  learners who can run the procedure from those who only watched it.
- **S12 (Practice E).** E5 (no solution) tests whether the learner
  trusts algebra over hope: a negative discriminant ends the
  problem, and "no solution" is a complete answer.
- **S13 (Lesson 06).** The two tests have a fixed order: increments
  first (shape), residuals second (fit). A model defense that cites
  only small residuals is incomplete.
- **S14 (Practice F + studio 2).** F5 is a writing sample: collect
  it. The project memo draft should be complete except for the
  final prediction check.
- **S15 (Review).** Retrieval mix: one item per lesson, plus one
  Unit 02 item (polynomial zero) and one Unit 03 item (rational
  restriction). Anything below half marks becomes a Week 18
  reteach target.
- **S16 (Synthesis).** Mixed error-analysis plus one connection
  per earlier unit, in the learner's own words. Accept any true
  connection (for example: "Unit 01 transformations move root
  graphs the same way they moved quadratics").
- **S17 (Gallery).** The adult critiques one thing per project:
  the weakest rubric row. The learner logs the critique and the
  fix, or logs a reasoned disagreement.
- **S18 (Quiz + reteach).** Score the Week-17 quiz; reteach from
  the lowest-scoring objective the same session if possible.
- **S19 (Assessment).** Parts A–C in one sitting; Part C is the
  midyear retrieval evidence, not a throwaway.
- **S20 (Flex).** Catch-up first, extension second, Unit 05 preview
  only if Parts A and C meet the readiness bar in the assessment
  scoring summary.

## Misconceptions and reteaching

| Misconception | Reteach move |
|---|---|
| `√16 = ±4` | `√` means the principal (nonnegative) root; `±` appears only when *solving* `x² = 16`. Drill: evaluate vs. solve, side by side. |
| Splitting roots over sums | Numeric counterexample `√(9+16) = 5 ≠ 3+4`; product rule only. |
| Reading `h` from an unfactored radicand | Always factor first: `√(2x − 6) = √(2(x − 3))`. |
| Excluding the starting point from the domain | `√0 = 0` is defined; domain uses `≥`, not `>`. |
| Reporting unchecked candidates as solutions | No solution set without a check line; make the check a graded step. |
| "Extraneous" means "I made an arithmetic mistake" | Show Lesson 04 Example 1 with flawless arithmetic: the fake answer is structural, produced by squaring. |
| Cube-root equations can also make fakes | Cubing is one-to-one; the check still runs, but it guards arithmetic, not sign. |
| Choosing a model by how the dots look | Increments first, residuals second, words last — in that order, every time. |
| Calculator-precision answers | Round to the tool: hundredths for a hand stopwatch, exact form otherwise. |

## Readiness criteria

- **Ready for Unit 05** if the unit assessment scores Part A 18+
  and Part C 6+, and the project memo defends a model with both
  tests. Proceed to exponential and logarithmic functions.
- **Reteach radical equations** if Part A items A4–A5 are weak:
  replay Lesson 04 with the ISOLATE–POWER–CHECK checklist,
  then re-administer Practice Set D.
- **Reteach root graphs** if A2–A3 are weak: replay Lessons 02–03
  with the factored-form-first rule and Desmos checks after, not
  before, the hand work.
- **Reteach model selection** if Part B is weak: replay Lesson 06
  with the learner's own project data, so the two tests are applied
  to numbers they own.
- **Cumulative gaps (Part C)** point back to Units 01–03, not to
  this unit: use those units' practice sets for targeted repair
  during the track's flexible weeks.

## Project notes (adult)

- Route 1 safety: stable support, small angles, clear swing path,
  adult present. A weight that detaches ends the experiment for
  the day; the learner switches to Route 2 or 3 and says so in the
  memo.
- Route 3 honesty: a memo presenting the provided data as the
  learner's own measurements loses the memo points and must be
  rewritten. This is a data-ethics lesson, not a gotcha.
- Accept any five lengths spanning roughly 0.2–1.0 m. The rubric
  scores method and reasoning, not agreement with 2.0066; a
  measurement that disagrees by more than ~0.1 s should be
  discussed, not hidden.
