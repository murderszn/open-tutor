# Resource Pack — Unit 04: Radical Functions and Equations

**Goal:** support a Grade 11 learner's work with radical notation,
root graphs, radical equations, and root models, with free
no-account routes for every core objective. Videos supplement the
lessons; they never replace the check step or the domain argument.

## Focused queries

1. `square root function domain range transformations graph`
2. `cube root function graph domain all real numbers`
3. `solving radical equations extraneous solutions checking`
4. `pendulum period square root length formula`
5. `rational exponents radical form simplify`
6. `fitting square root model residuals data`
