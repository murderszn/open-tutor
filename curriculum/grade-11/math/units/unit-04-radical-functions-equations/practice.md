# Practice — Unit 04: Radical Functions and Equations

Work in order; each set follows its lesson. Keep exact radical form
until a context asks for a decimal, and check every equation
solution in the original equation. Solutions and reasoning are in
[answer-key.md](answer-key.md); do not open it until you have
attempted the set.

## Practice Set A

A1. Evaluate `81^(3/4)`.
A2. Evaluate `(-32)^(1/5)`.
A3. Write `√(x^3)` in exponent form (assume `x > 0`).
A4. Simplify `√48`.
A5. Simplify `∛40`.
A6. Simplify `√(x^7)` for `x > 0`.
A7. Simplify `2√12 + √27`.
A8. Rationalize the denominator of `6/√2`, and in one sentence
explain why `√(25 + 144)` is not `5 + 12` (give both values).

## Practice Set B

B1. State the domain, range, and starting point of
`f(x) = √(x − 4) + 1`.
B2. Graph `g(x) = −√x + 3` by hand (use `x = 0, 1, 4, 9`) and state
its domain, range, and whether it is increasing or decreasing.
B3. State the domain and starting point of `f(x) = √(3x − 12)`.
(Hint: factor the radicand before reading the shift.)
B4. True or false, with a reason: "The domain of `√(x + 1)` is
`x > −1`."
B5. Find both intercepts of `f(x) = √(x + 9) − 5`.
B6. Describe, in transformation words, how `h(x) = 2√(x − 1) − 3`
is obtained from `√x`, and state its domain and range.
B7. Which function starts at `(−2, 5)`? (a) `√(x − 2) + 5`,
(b) `√(x + 2) + 5`, (c) `√(x + 2) − 5`. Explain the choice.
B8. Error analysis: a classmate graphed `√(2x + 4)` starting at
`x = −4`. What did they miss, and where does the graph really
start?

## Practice Set C

C1. State the domain, range, and center of
`f(x) = ∛(x − 5) − 2`.
C2. Give five plotted points for `p(x) = ∛x + 1`, using perfect
cubes, and sketch the curve.
C3. Show with a number that `∛x` is an odd function.
C4. State the center, domain, and range of `f(x) = −∛(x + 2)`,
and say whether it is increasing or decreasing.
C5. Write the inverse of `y = x^3 + 1`, and explain why no domain
restriction was needed.
C6. Which has the larger domain, `√x` or `∛x`? Explain using the
parity (even/odd) of the index.
C7. Find both intercepts of `f(x) = ∛(x + 8) − 3`.
C8. Error analysis: a classmate wrote "∛(−27) has no real value."
Correct them with the value and the reason.

## Practice Set D

D1. Solve `√(x − 3) = 5`.
D2. Solve `√(2x + 5) = x − 1`. Find both candidates, check both,
and name any extraneous solution with its reason.
D3. Solve `√(x + 10) = x − 2`.
D4. Solve `√(4x − 3) = x + 2`, or show there is no real solution.
D5. An object falls `h` meters in `t = √(2h/9.8)` seconds. How
long does it take to fall 19.6 meters?
D6. In your own words, explain why squaring both sides of an
equation can create a solution that the original equation does
not have.
D7. Error analysis: a student solved `√(x − 1) = 3 − x`, squared
to get candidates 2 and 5, and reported the solution set {2, 5}.
Check both candidates and give the correct solution set.
D8. Solve `3√(x − 1) = 12`.

## Practice Set E

E1. Solve `∛(3x − 2) = 2`.
E2. Solve `√(x + 5) − √(x − 2) = 1`.
E3. A pendulum of length 1.44 m has what period? Use
`T = 2π√(L/9.8)` and round to hundredths of a second.
E4. What pendulum length gives a period of 1.5 seconds? Use
`T = 2π√(L/9.8)` and round to hundredths of a meter.
E5. Solve `√(2x + 7) − √x = 1`, or show there is no real solution.
E6. A cube's volume is 216 cm³, then 1000 cm³. Find both edge
lengths. By what factor does the edge grow when the volume grows
from 27 cm³ to 81 cm³?
E7. How long does an object take to fall 122.5 meters?
(Use `t = √(2h/9.8)`.)
E8. Explain why a cube-root equation still gets a check even
though cubing cannot create extraneous solutions.

## Practice Set F

F1. Outputs for equally spaced inputs are 10, 14, 16.5, 18.5.
Compute the increments and say which family (linear, root, or
exponential) they suggest, and why.
F2. A model predicts 2.8, 4.0, 5.2 for actual values 3.0, 4.1, 5.0.
Compute the residuals and say whether they show a pattern.
F3. A pendulum dataset gives the point `L = 0.49` m, `T = 1.40` s.
Estimate `a` in `T = a√L` from this point, then predict `T` at
`L = 0.64` m.
F4. Fictional practice data: `L = 0.2, 0.4, 0.8` m with
`T = 0.90, 1.27, 1.79` s. Fit a line through the first and last
points, predict `T` at `L = 0.4` m, compute the residual, and say
whether the line or a square-root model fits better, and why.
F5. Write a two-to-three-sentence defense of the square-root model
for the F4 data, using both the increment argument and the
residual argument.
F6. A tank drains by the fictional practice model
`V(t) = 80 − 10√t` liters, `t` in minutes. When is the tank
empty, and what is the domain in context? Explain the upper bound.
