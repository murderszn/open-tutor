# Answer Key — Unit 04: Radical Functions and Equations

**Adult only.** Every practice, lesson guided-practice, quiz,
assessment, and project item is solved here. Where an answer is a
judgment (a model defense, a memo), the key gives the reasoning a
full-marks response must contain and the variations that are
acceptable.

## Lesson 01

1. `x^(2/5)`.
2. `8^(2/3)`: cube root of 8 is 2; squared is 4.
3. `√200 = √(100 · 2) = 10√2`.
4. `∛(16x^4) = ∛(8x^3 · 2x) = 2x∛(2x)` for `x > 0`.

## Lesson 02

1. `√(2x − 6) = √(2(x − 3))`: domain `x ≥ 3`, range `y ≥ 0`,
   starting point `(3, 0)`.
2. `k(x) = 3√x − 4`: domain `x ≥ 0`, range `y ≥ −4`; points
   `(0, −4)`, `(1, −1)`, `(4, 2)`, `(9, 5)`.
3. Correction: the domain is `x ≥ 5`, not `x > 5`, because
   `√0 = 0` is a real value — the starting point itself is included.

## Lesson 03

1. `h(x) = ∛(x + 3) − 2`: center `(−3, −2)`; domain and range all
   reals; points `(−3, −2)`, `(−2, −1)`, `(−4, −3)`, `(5, 0)`,
   `(−11, −4)`.
2. True. `x = 0` is always in a cube-root function's domain, so
   `f(0)` is always defined.
3. `x^3` is one-to-one over all reals, so its inverse is a
   function with no restriction. `x^2` sends both 3 and −3 to 9,
   so it must be restricted (to `x ≥ 0`) before it has an inverse
   function.

## Lesson 04

1. `√(x + 7) = 5` gives `x + 7 = 25`, so `x = 18`. Check: `√25 = 5`. ✓
2. `√(5x − 4) = x − 2`: squaring gives `5x − 4 = x^2 − 4x + 4`,
   so `x^2 − 9x + 8 = 0`, candidates 1 and 8. Check `x = 1`:
   `√1 = 1` vs `−1` ✗ — extraneous (squaring erased the sign).
   Check `x = 8`: `√36 = 6` vs `6` ✓. Solution set: {8}.
3. The equation `√(x − 2) = −4` has no solution: a principal
   square root is never negative. Squaring gives `x = 18`, but
   `√16 = 4 ≠ −4`, so 18 is extraneous and the solution set is empty.

2. `∛(x + 10) = 4` gives `x + 10 = 64`, so `x = 54`. Check:
   `∛64 = 4`. ✓. No candidate is rejectable: cubing is one-to-one.
3. `T = 2π√(0.64/9.8) = 2π(0.25555) ≈ 1.6056`, so **1.61 s** to

## Practice Set C

## Practice Set D

D2. Candidates `2 ± 2√2`. `2 + 2√2 ≈ 4.828`: `√(2x + 5) ≈ 3.828`,

   gives `≈ 1.828` vs `≈ −1.828` ✗ — extraneous. Solution set:
   {`2 + 2√2`}.
D3. Candidates 6 and −1. `x = 6`: `√16 = 4`, `6 − 2 = 4` ✓.
   `x = −1`: `√9 = 3` vs `−3` ✗ — extraneous. Solution set: {6}.
D4. `√(4x − 3) = x + 2` squares to `4x − 3 = x^2 + 4x + 4`, so
   `x^2 + 7 = 0` — no real solution. Solution set: empty.
D5. `t = √(2 · 19.6/9.8) = √4 = 2` seconds.
D6. Acceptable reasoning: squaring erases sign, so `a = b` and
   `a = −b` both square to `a^2 = b^2`; a candidate satisfying
   the squared equation may satisfy only the negated version of

   exposes it.

## Practice Set E

E2. `√(x + 5) = 1 + √(x − 2)`; squaring gives

   Check: `√16 − √9 = 4 − 3 = 1` ✓. Solution set: {11}.
E3. `T = 2π√(1.44/9.8) = 2π(0.38333) ≈ 2.4086`, so **2.41 s**.
E4. `1.5 = 2π√(L/9.8)` gives `L = 9.8 · (1.5/(2π))^2 ≈ 0.5585`,
   so **0.56 m**.
E5. `√(2x + 7) = 1 + √x`; squaring gives `x + 6 = 2√x`;
   squaring again gives `x^2 + 8x + 36 = 0`, discriminant
   `64 − 144 < 0`. No real solution.
E6. Edges: `∛216 = 6` cm; `∛1000 = 10` cm. Volume 27 → 81 cm³:
   edge `3 → ∛81 = 3∛3 ≈ 4.33` cm, a factor of `∛3 ≈ 1.44`.
E7. `t = √(2 · 122.5/9.8) = √25 = 5` seconds.
E8. Acceptable reasoning: cubing is one-to-one, so it cannot

## Practice Set F

F1. Increments: 4, 2.5, 2 — shrinking. That suggests a root
   family (flattening growth), not linear (constant) or
   exponential (growing).
F2. Residuals: `+0.2, +0.1, −0.2`. Mixed signs, no pattern, small:
   an acceptable fit.
F3. `a = 1.40/√0.49 = 1.40/0.70 = 2.00`. Prediction at
   `L = 0.64`: `2.00 · 0.80 = 1.60` s.
F4. Line through (0.2, 0.90) and (0.8, 1.79): slope
   `(1.79 − 0.90)/0.60 ≈ 1.4833`; prediction at `L = 0.4`:
   `0.90 + 1.4833 · 0.2 ≈ 1.20` s. Actual 1.27 s, residual
   `+0.07`. The line under-predicts the middle — the
   curve-above-line pattern — so the square-root model fits better.
F5. Full marks for a defense containing both: (a) the increments
   (rates) shrink as `L` grows, matching a root's flattening, not
   a line's constancy; (b) the line's residuals are systematically
   positive in the middle, while the root model's residuals are
   near zero with no pattern.
F6. `80 − 10√t = 0` gives `√t = 8`, so `t = 64` minutes. Domain
   in context: `0 ≤ t ≤ 64`. The upper bound is imposed by the
   context (a tank cannot hold a negative volume), not by the
   equation, which would keep decreasing past empty.

## Project — sample solution (Route 3 data)

Estimates of `a` in `T = a√L`: from `L = 0.20, T = 0.90`,
`a = 0.90/√0.20 ≈ 2.01`; from `L = 1.00, T = 2.01`, `a = 2.01`.
Both agree with the theoretical `a = 2π/√9.8 ≈ 2.0066`. Residuals
with `a ≈ 2.0066`, rounded to hundredths: 0.00 at every point
(predictions 0.90, 1.19, 1.49, 1.74, 2.01). Line through the first
and last points: slope `(2.01 − 0.90)/0.80 = 1.3875`, equation
`T = 1.3875L + 0.6225`; predictions 1.11, 1.39, 1.66 at
`L = 0.35, 0.55, 0.75` against actual 1.19, 1.49, 1.74 —
residuals `+0.08, +0.10, +0.08`, all positive in the middle: the
systematic misfit of a line on root-shaped data. Prediction at
`L = 0.50`: `2.0066 · √0.50 ≈ 1.42` s. Full marks require the
memo to label Route 3 data as fictional practice data, to state
the domain (`L > 0`) and the small-angle condition, and to defend
the model with both the increment argument and the residual
argument.
