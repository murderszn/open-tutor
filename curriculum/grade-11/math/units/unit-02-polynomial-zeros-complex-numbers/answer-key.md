## Lesson 01 — Complex numbers

**Readiness:** 1. `x² = 25` → `x = ±5`; `x² = −25` has no real
solution (no real square is negative). 2. `6x − 4`; `2x² + x − 3`
(FOIL: `2x² − 2x + 3x − 3`).

**Guided practice:**
1. `7i`; `7 − 4i`.
2. `5 + 2i`.
3. `6 − i + 2 − 5i = 8 − 6i`.
4. `(1 + 4i)(2 − 3i) = 2 − 3i + 8i − 12i² = 2 + 5i + 12 = 14 + 5i`.
5. `30 ÷ 4` remainder `2` → `i² = −1`.

**Independent practice:**
1. `−5 + 9i`.
2. `0` — the numbers are additive inverses; real and imaginary parts
   both cancel.
3. `6 − 8i`.
4. `6i − 15i² = 6i + 15 = 15 + 6i`.
5. `25 − 20i + 4i² = 21 − 20i`.
6. `103 ÷ 4` remainder `3` → `i³ = −i`.
7. Sample: `(3 + 4i)(3 − 4i) = 9 + 16 = 25`. Accept any correct pair
   (e.g., `5 · 5`, `(5i)(−5i) = 25`).
8. Finished: `6 − i − 2i² = 6 − i + 2 = 8 − i`. Skipped step: the
   `i² = −1` replacement.

**Application:** `(x + 2i)(x + 3i) = x² + 5xi + 6i² = (x² − 6) + 5xi`.
Real part `x² − 6` (square meters); imaginary part `5x` — the sum of
the cross terms. Accept: the real part combines the "real × real"
and "imaginary × imaginary" products; the imaginary part combines the
mixed products.

**Exit:** `i² = −1` gives solutions to `x² = −(positive)` (e.g., `x =
±5i` for `x² = −25`). Example: `(1 + i)² = 1 + 2i + i²` must become
`2i`; stopping leaves non-standard form.

## Lesson 02 — Quadratics with complex solutions

**Readiness:** 1. `(x + 2)² = −9` — stuck at the negative square
root over the reals. 2. `6`; `13`. Pattern: sum is real, product is
real (`a² + b²`).

**Guided practice:**
1. `(x + 1)² = −4` → `x = −1 ± 2i`.
2. `x = (4 ± √(−16))/2 = (4 ± 4i)/2 = 2 ± 2i`.
3. Discriminant `144 − 180 = −36 < 0` → nonreal pair; `x = (12 ±
   6i)/6 = 2 ± i`.
4. `4 + 7i`; `−2 − i`; `−9i`; `6`.
5. Numerator `(2 + 3i)(4 + i) = 8 + 14i + 3i² = 5 + 14i`;
   denominator `17` → `5/17 + (14/17)i`.

**Independent practice:**
1. `(x + 3)² = −16` → `x = −3 ± 4i`. Verify `x = −3 + 4i`:
   `x² = 9 − 24i + 16i² = −7 − 24i`; `6x = −18 + 24i`; sum `+ 25`:
   `(−7 − 18 + 25) + (−24i + 24i) = 0` ✓.
2. Discriminant `16 − 80 = −64`; `x = (4 ± 8i)/8 = 1/2 ± i`.
3. (a) disc `−16` → nonreal; `x = 5 ± 2i`. (b) disc `0` → `x = −2`
   (repeated real). (c) disc `−36` → nonreal; `x = 1 ± 3i`.
4. (a) `x(x − 3)(x + 3)`: zeros `0, 3, −3`. (b) `x²(x² + 4)`:
   zeros `0` (multiplicity 2), `±2i`.
5. FOIL: `36 − 12i + 12i − i²·(−1)`… carefully: `(6 + i)(6 − i) = 36
   − 6i + 6i − i² = 36 + 1 = 37`. Shortcut: `6² + 1² = 37`. ✓
6. `8i(1 − 2i)/5 = (8i − 16i²)/5 = (16 + 8i)/5 = 16/5 + (8/5)i`.
7. `(x + 3i)(x − 3i) = x² + 9` ✓.
8. Accept: the parabola's equation has two *complex* solutions; the
   graph only shows *real* `(x, y)` points; "no x-intercept" and
   "has (complex) solutions" are compatible.

**Application:** `−5t² + 30t + 2 = 0` → `t = (30 ± √940)/10 = 3 ±
√9.4 ≈ 6.07` or `≈ −0.07` seconds. Physical: `t ≈ 6.07` s (landing);
`t ≈ −0.07` s rejected (before launch). `−5t² + 30t − 60 = 0` →
`t² − 6t + 12 = 0` → `t = 3 ± √3 i`. One sentence: the algebra is
valid but no clock reads `3 + √3 i` seconds, so this model has no
physical launch moment.

**Exit:** conjugate of `−3 + 8i` is `−3 − 8i`. `(a + bi)(a − bi) =
a² − abi + abi − b²i² = a² + b²`, real because the cross terms cancel
and `i² = −1`.

## Lesson 03 — Polynomial structure

**Readiness:** 1. `x(x − 2)(x + 2)`; `(x − 2)(x + 2)(x² + 4)` (two
rounds: `x⁴ − 16 = (x² − 4)(x² + 4)`). 2. `p(2) = 8 − 8 − 10 + 6 =
−4`.

**Guided practice:**
1. `x²(x + 5) + 2(x + 5) = (x² + 2)(x + 5)`.
2. `(x − 2)(x² + 2x + 4)`; quadratic zeros `x = −1 ± √3 i`, so
   `(x − (−1 + √3 i))(x − (−1 − √3 i))`.
3. `p(1) = 1 + 4 − 3 − 2 = 0` — remainder `0` (so `(x − 1)` is a
   factor).
4. `p(2) = 8 − 12 + 4 = 0` → yes, `(x − 2)` is a factor.
5. `(x + y)⁴ = x⁴ + 4x³y + 6x²y² + 4xy³ + y⁴` (Pascal row 1–4–6–4–1).

**Independent practice:**
1. `x²(2x − 3) − 4(2x − 3) = (x² − 4)(2x − 3) = (x − 2)(x + 2)(2x −
   3)`.
2. `(3x + 4)(9x² − 12x + 16)`.
3. `p(−1) = −3 − 1 − 2 − 5 = −11`. Remainder `−11`.
4. `p(1) = 0` → `(x − 1)`; quotient `x² − 5x + 6 = (x − 2)(x − 3)`;
   full: `(x − 1)(x − 2)(x − 3)`. Multiply-back verified in the
   lesson.
5. `(x² − 9)(x² + 9) = (x − 3)(x + 3)(x² + 9)`; over ℂ add `(x −
   3i)(x + 3i)`. Structures: difference of squares, twice.
6. Both sides expand to `x⁴ + 2x²y² + y⁴`; `x = 3, y = 2` gives
   `169 = 25 + 144` → triple `(5, 12, 13)` ✓.
7. Not complete: `x² − 1` factors further → `(x − 1)(x + 1)(x − 2)`.
   "Complete" = no factor can be broken down further over the
   numbers in use.

**Application:** `V(x) = x(100 − 40x + 4x²) = 4x³ − 40x² + 100x =
x(10 − 2x)²`. Zeros: `x = 0`, `x = 5` (multiplicity 2). Physical:
`0 < x < 5` inches. `x = 0`: no cut, no box. `x = 5`: side `10 −
2·5 = 0` — the sheet vanishes. Units: `x` in inches, `V` in cubic
inches.

**Exit:** `p(−3) = −27 + 18 + 15 − 6 = 0` → yes, `(x + 3)` is a
factor.

## Practice Set D

1. `p(−1) = 0` → `(x + 1)(x + 3)(x − 2)`; zeros `−1, −3, 2`.
2. Divide by `(x − 3)(x + 1) = x² − 2x − 3`: quotient `x² − 4 = (x −

   crosses at both (odd multiplicities; flattens at `x = 2`).

   triple zero; or one simple + one double (crosses once, touches
   once).
7. The bound allows at most 2; `y = x(x − 1)(x + 1)` has zeros `0,
   ±1` and exactly 2 turning points at `x = ±1/√3`.

## Lesson 04 — Zeros and graphs

**Readiness:** 1. `(x − 3)(x − 2)(x + 2)`; zeros `3, 2, −2`. 2. As `x
→ +∞`, `f → −∞`; as `x → −∞`, `f → +∞` (leading term `−x³`).

**Guided practice:**
1. `x(x − 2)²`: zeros `0`, `2` (multiplicity 2 — touches, doesn't
   cross).
2. `±2, ±2i` — the conjugate pair is `2i, −2i`.
3. Down on both ends; at most 3 turning points.
4. Zeros `−1` (mult. 2, touches), `2` (crosses); degree 3, `+1`
   leading → down-left, up-right; ≤ 2 turning points; y-intercept
   `(0, −2)`.
5. Accept: the waterline is the real axis; each light above has a
   mirror twin below, just as `2 + 3i`'s zero forces `2 − 3i`.

**Independent practice:**
1. `(x − 2)(x + 2)(x − 1)`: zeros `2, −2, 1`.
2. `(x − 1)(x + 1)(x − 2)(x + 2)`: zeros `±1, ±2` (no complex zeros
   here — all four are real).
3. `2, −1, 3 + i, 3 − i`, plus one more real zero `r`.
4. Zeros `1, −3, 4`; degree 3, `−1` leading → up-left, down-right;
   ≤ 2 turning points; y-intercept `(0, −12)`.
5. `x²(x − 2i)(x + 2i)`: zeros `0` (mult. 2), `±2i`. Only `x = 0`
   is real, so the graph touches the axis just once.
6. The bound is 2, not 4. Zeros `0, ±√3`; derivative `3x² − 3`
   vanishes at `x = ±1` — exactly 2 turning points.
7. (Enrichment) The quadratic formula gives `x = (−b ± √(b² −
   4ac))/2a`: two values always — distinct reals (discriminant >
   0), one repeated real (`= 0`), or a conjugate pair (`< 0`).
   Exactly two counting multiplicity.

**Application:** `P(2) = −8 + 32 − 10 − 14 = 0` → `(t − 2)` is a
factor. Dividing: `P(t) = −(t − 2)(t − 7)(t + 1)`. Zeros: `2, 7,
−1`. On `[0, 10]`, `P(t) > 0` exactly when `2 < t < 7` — profitable
in months ~3–7. Units: thousands of dollars per month. Past `t =
10` the cubic dives to `−∞`; no fitted polynomial should be trusted
outside its domain.

**Exit:** `x(x − 1)(x² − 2x − 2)`; zeros `0, 1, 1 ± √3`. Degree 4,
`+1` leading → up on both ends; at most 3 turning points.

## Lesson 05 — Intersections

**Readiness:** 1. `x = 3, −1`; the x-coordinates of the intersection
points `(3, 9)` and `(−1, 1)`. 2. Crossings near `x = −2` and `x = 1`
(exact: `−2`, and `1` double).

**Guided practice:**
1. `x² − 2x = x(x − 2) = 0` → `x = 0, 2`; points `(0, −1)`, `(2,
   3)`.
2. `x = 3, −2`; points `(3, 5)`, `(−2, 0)` — Desmos shows the same
   crossings.
3. `x² + x + 6 = 0`, discriminant `−23` → no real solution; the
   parabola floats entirely above the line.
4. `x ≈ −1.86, −0.25, 2.11`. Verify one: `(−1.86)³ ≈ −6.43`,
   `4(−1.86) + 1 = −6.44` ✓ (to two decimals).

**Independent practice:**
1. `x = 1, 3`; points `(1, 2)`, `(3, 18)`.
2. `x = 0, 3, −1`; points `(0, 0)`, `(3, 9)`, `(−1, −3)`.
3. `x² − 40x + 200 = 0` → `x = 20 ± 10√2 ≈ 34.14` or `≈ 5.86`
   units. Plan around `≈ 5.86` units — the first break-even, the
   reachable milestone (the second requires ~6× the volume).
4. `u = x²`: `u = (3 ± √5)/2` → `x ≈ ±1.618, ±0.618`. Verify `x ≈
   1.618`: `(1.618)⁴ ≈ 6.854`; `3(1.618)² − 1 ≈ 6.854` ✓.
5. Lost solution: `x = 0`. Dividing by `x` assumes `x ≠ 0`. Correct:
   `x(x − 4) = 0` → points `(0, 0)`, `(4, 16)`.
6. Accept: the test is cheap and can give exact factors; skip it when
   the equation clearly has no rational candidate (e.g., after one
   quick mental test fails) or when only an approximation is needed.

**Application:** a) `0.05w² + 1.5w − 8 = 0` → `w² + 30w − 160 = 0`
→ `w = (−30 + √1540)/2 ≈ 4.62` lb (the negative root `≈ −34.62`
lb is rejected — negative weight). b) 10 lb: S `$23.00`, T `$35.00`
→ S cheaper. 30 lb: S `$53.00`, T `$135.00` → S cheaper. c) T's
quadratic term dominates for large `w` (end behavior `→ +∞`
faster than S's line), so the dimensional-weight surcharge makes T
progressively more expensive.

**Exit:** `x² + 3x = x(x + 3) = 0` → `x = 0, −3`; points `(0, 6)`,
`(−3, 0)`. Geometrically: the solutions are the x-coordinates where
the two graphs meet.
