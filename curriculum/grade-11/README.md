# Grade 11 — Independent Curriculum Track

This folder is an anonymous, grade-specific track in the public OpenTutor curriculum library.

**Contents:** The mathematics track's audit and scope-and-sequence are a
validated draft in unmerged draft PR #117 (issue #50); the science track's
audit and scope-and-sequence are a validated draft in unmerged draft PR #118
(issue #51); the language arts track's audit and scope-and-sequence are a
validated draft in this run's draft PR (issue #52). The eight units and the
review package of each subject are planned, not yet written. The social
studies track is planned (issue #53) and has no folder yet. No subject track
is complete. All materials still require educator review.

**Do not refer a learner to another grade's track.** Each track is
self-contained for one learner at a time; a guiding adult adapts pacing,
materials, and supports. Keep completed learner work, names, photos, schedules,
and grades in private storage — never in this public repository.

See also: [curriculum index](../README.md).
