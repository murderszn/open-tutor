# Resource Pack — Unit 04: Language, Rhetoric, Syntax, and Stylistic Analysis

**Goal:** Give a grade-11 learner (and guiding adult) free, no-account
routes to every core objective: syntax as style, word choice and
connotation, figurative language and tone, contested usage, and the
stylistic analysis essay. **Age fit:** high-school grade 11; the adult
previews every link for advertising, comments, and suitability before
the learner opens it. Checked 2026-11-03 unless noted. "Verified" =
the source page's text and publisher were confirmed on that date; the
adult opens each page before assigning and confirms quotations against
the edition used. "Search link" = a clearly labeled preferred-channel
search the adult runs and previews (no invented titles, runtimes, or
captions).
