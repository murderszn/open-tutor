## Lesson 01 (items 1.1–1.10)

**1.1.** 60.0 cm × (1 m / 100 cm) = **0.600 m**.

**1.2.** Three significant figures. The trailing zero after the
decimal point is significant — it claims the length was read to the
nearest 0.01 m.

figures; the decimal point makes the trailing zero significant).

**1.4.** (m/s)² / (m/s²) = (m²/s²) ÷ (m/s²) = **m**. The 2 is exact
and carries no units. Units check passes.

**1.5.** 2.50 × 10⁵ mg × (1 g / 1000 mg) × (1 kg / 1000 g) =

*less* precision than the data supports, which is honest; it would be
a problem only if it claimed *more* (e.g., 5.860 m/s).

**1.9.** 5.00 L × (1 m³ / 1000 L) = **0.00500 m³** = 5.00 × 10⁻³ m³.

## Lesson 04 (items 4.1–4.9)

**4.1.** Slope = (15.0 − 6.0) m / (5.0 − 2.0) s = 9.0/3.0 =
**3.0 m/s**. The slope of an x–t graph is the velocity.

**4.2.** Area = ½ × 4.0 s × 20.0 m/s = **40 m**. The area under a v–t
graph is the displacement.

**4.3.** a) v = Δx/Δt = 10.0 m / 2.0 s = **5.0 m/s** between every
pair of points — constant velocity (uniform motion).
b) x(8.0 s) = **40.0 m**, assuming the velocity stays 5.0 m/s
(straight-line extrapolation of uniform motion).

**4.4.** a) a = (0 − (25.0 m/s)²) / (2 × 75.0 m) = −625/150 =
**−4.17 m/s²** (negative = opposite the direction of motion).
b) t = (0 − 25.0 m/s) / (−4.1667 m/s²) = **6.00 s**.

**4.5.** a) Δv = area = 3.00 m/s² × 4.00 s = **12.0 m/s**.
b) Δx = 0 + ½(3.00)(4.00)² = **24.0 m**. Check via average velocity:
½(0 + 12.0)(4.00) = **24.0 m** ✓.

**4.6.** a) t = √(2 × 20.0 / 9.80) = √4.08163 = **2.02 s**.
b) v = 0 + (−9.80)(2.0204) = **−19.8 m/s** (19.8 m/s downward).
c) Wrong because time scales with the *square root* of height, not
height itself. t(40.0 m) = √(80.0/9.80) = √8.16327 = **2.86 s**, not
4.04 s (= 2 × 2.02 s).

**4.7.** a) v² = v₀² + 2aΔx (chosen because time is neither given nor
asked): a = (85.0 m/s)² / (2 × 900 m) = 7225/1800 = **4.01 m/s²**.
b) 4.50 > 4.01 m/s² — yes, with margin **0.49 m/s²**. At 4.50 m/s²
liftoff needs Δx = 7225/(2 × 4.50) = 803 m, leaving **97 m** of
spare runway.
c) Any one: air resistance, thrust that isn't constant, headwind/
tailwind, runway slope, rolling friction.

**4.8.** Horizontal v–t segment = **constant velocity** (zero
acceleration). Downward-sloping segment = velocity decreasing =
**negative acceleration**.

**4.9.** A straight line starting at +v₀ (t = 0), sloping downward,
crossing v = 0 at the top of flight, and reaching −v₀ on return. The
slope is constant at **−9.80 m/s²** the whole time.

constant downward acceleration from gravity.
b) No — the flight time is still set by the *vertical* motion; a small
initial downward v_y₀ only shortens the fall slightly (handled by the
full y-equation, not the v_y₀ = 0 shortcut).

**5.5.** Fastest **just before landing**: the markers are farthest
apart there, and equal time intervals with larger spacing mean larger
speed. By independence of motion, v_x stays constant while |v_y| grows
under gravity, so total speed √(v_x² + v_y²) is largest at landing.

**5.6.** t = √(2 × 2.50 / 9.80) = √0.510204 = **0.714 s**;

b) Lower the launch speed or lower the launch height (or add a slight

measured mean ± uncertainty band overlaps the predicted value (or:
percent difference is small — a few percent — and the miss is
explained by named, directional error sources).

**5.10.** Gravity's pull (∝ m) and inertia (∝ m) cancel in a = F/m,
so the kinematic prediction contains no mass term. The Launch Lab
tests this by firing a different-mass ball at the same settings and
checking that it lands at the same range.

## Project (P1–P6) — acceptable responses

**P1.** Acceptable: any single testable question linking launch
conditions to range, e.g. "Does R = v_x·√(2y₀/9.80) predict the
measured landing distance of a horizontally launched ball?" Must be
answerable with the planned data.

**P2.** Acceptable: independent = launch height and/or launch speed
(the set conditions); dependent = horizontal range; controlled =
launch angle (0°), ball type/mass, release method, landing surface,
still air. One misidentified variable = Developing per rubric.

**P3.** Acceptable: table with columns labeled *with units* (trial,
y₀ (m), v_x trial (m/s), range trial (m)), all trials recorded.
Sample: y₀ readings 1.20, 1.21, 1.19 m; five ranges 2.90, 2.95,
2.88, 2.93, 2.91 m.

**P4.** Acceptable: prediction computed *before* launching with units
shown canceling and three significant figures, e.g. t = √(2 ×
1.20/9.80) = 0.495 s; R = 6.00 m/s × 0.495 s = **2.97 m**; uncertainty
carried from the y₀/v_x measurements.

**P5.** Acceptable: with the sample data — measured mean = 14.57/5 =
**2.91 m**, range = 0.07 m → ±0.04 m; percent difference =
|2.91 − 2.97|/2.97 × 100% = **2.0%**; honest comparison (prediction
inside/near the measured band); ≥2 specific directional error sources,
e.g. "launch angle slightly above 0° would lengthen the range;
timing error in the speed run would shift v_x and the prediction the
same direction." Generic "human error" alone = Developing.

**P6.** Acceptable: conclusion follows the evidence ("the prediction
matched within 2%, consistent with the equation, given the error
sources"); mass check stated (different-mass ball lands at the same
range within uncertainty — mass does not affect the trajectory); one
concrete improvement (e.g., "use a photogate for v_x" or "fix the
launcher angle with a level").
