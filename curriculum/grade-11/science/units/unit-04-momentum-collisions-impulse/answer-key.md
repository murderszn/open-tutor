# Answer Key — Unit 04 (Adults Only)

**Adults only. Every numbered item in the lessons, practice sets,
quiz, and assessment is solved here, independently of the lesson
text. If a student answer differs, check the sign first, then the
system, then the arithmetic — in that order.**

## Lesson 01 — Momentum

- **1.1.** The bowling ball: at the same speed, the larger mass
  carries the larger momentum, so it is harder to stop.
- **1.2.** It doubles: momentum is proportional to velocity at fixed
  mass.
- **1.3.** `p = (2.5)(+4.0) = +10 kg·m/s`.
- **1.4.** `p = (0.20)(−8.0) = −1.6 kg·m/s`.
- **1.5.** Runner: `(80)(6.0) = 480 kg·m/s`. Ball: `(0.50)(40) =
  20 kg·m/s`. The runner is harder to stop, by a factor of
  `480 / 20 = 24`.
- **1.6.** `p = (3.0)(−2.5) = −7.5 kg·m/s`.
- **1.7.** `v = p / m = 60 / 4.0 = +15 m/s` (to the right).
- **1.8.** The error is in the second factor: velocity is a vector,
  so momentum is a vector. Two objects at the same speed in opposite
  directions have momenta of equal size but opposite sign; they are
  not the same momentum, and in a total they partly cancel.
- **1.9.** Cyclist: `(75)(8.0) = 600 kg·m/s`. That is about
  `1/30` of the car's 18,000 kg·m/s (600 / 18,000 = 1/30). Stopping
  the cyclist is a roughly thirty-times-smaller momentum-change job.
- **1.10.** `p = (0.80)(+5.0) = +4.0 kg·m/s`. Convention: right is
  positive.
- **Extension.** Any pair with `mv = 3.0`, e.g. 1.0 kg at 3.0 m/s,
  or 0.30 kg at 10 m/s. Equal momentum does not imply equal kinetic
  energy, because KE depends on `v²`: the 0.060 kg ball at 50 m/s
  has KE 75 J, while the 0.50 kg ball at 6.0 m/s has KE 9.0 J, at the
  same momentum 3.0 kg·m/s.

## Lesson 02 — Impulse

- **2.1.** The foam pad: the longer stop feels softer. (Qualitative;
  Lesson 05 quantifies it.)
- **2.2.** `Δp = (1.0)(4.0 − 0) = +4.0 kg·m/s`.
- **2.3.** `J = (120)(0.050) = 6.0 N·s`; `Δv = 6.0 / 0.50 = 12 m/s`
  (final speed 12 m/s from rest).
- **2.4.** `J = (30)(0.20) = 6.0 N·s`; `Δv = 6.0 / 1.5 = 4.0 m/s`.
- **2.5.** `Δp = (0.20)(−8.0 − 10) = (0.20)(−18) = −3.6 kg·m/s`.
  The wall's impulse on the ball is −3.6 N·s.
- **2.6.** `Δp = (1.2)(−1.0 − 3.0) = (1.2)(−4.0) = −4.8 N·s`.
- **2.7.** `Δp = (0.30)(0 − 12) = −3.6 kg·m/s`; magnitude of
  average force `= 3.6 / 0.060 = 60 N`.
- **2.8.** Push A: `(200)(0.020) = 4.0 N·s`. Push B: `(40)(0.10) =
  4.0 N·s`. Equal impulses, so equal final speeds for identical
  masses — the force–time trade-off.
- **2.9.** (a) `Δp = (60)(0 − 12) = −720 kg·m/s` (magnitude 720).
  (b) Rigid: `720 / 0.020 = 36,000 N`. Airbag: `720 / 0.20 =
  3,600 N`. (c) The longer stop reduces the force by a factor of 10.
- **2.10.** `1 N = 1 kg·m/s²`, so `1 N·s = 1 kg·m/s² × s =
  1 kg·m/s`. Impulse equals change in momentum.
- **Extension.** Area: two triangles `2 × ½(0.10)(40) = 4.0 N·s`
  plus rectangle `(0.20)(40) = 8.0 N·s`, total `12 N·s`.
  `Δv = 12 / 3.0 = 4.0 m/s`.

## Lesson 03 — Conservation

- **3.1.** Slower: the same momentum is carried by more mass after
  sticking, so the common speed must fall.
- **3.2.** Accept any correct statement of: the sum of the objects'
  momenta is the same before and after the interaction.
- **3.3 (image task).** Before: `(2.0)(+3.0) + (3.0)(0) =
  +6.0 kg·m/s`. After: `(5.0)v′ = 6.0`, so `v′ = +1.2 m/s`
  (joined carts move right at 1.2 m/s).
- **3.4.** Before: `(3.0)(+2.0) + (2.0)(−1.0) = 6.0 − 2.0 =
  +4.0`. After: `(5.0)v′ = 4.0`, so `v′ = +0.80 m/s`.
- **3.5.** Total before is zero, so `50(−2.8) + 70v = 0`, giving
  `v = +2.0 m/s` (the 70 kg skater moves right at 2.0 m/s).
- **3.6.** Total before is zero, so `2.0(+3.0) + 2.0v = 0`, giving
  `v = −3.0 m/s`. The momenta (+6.0 and −6.0) sum to zero, as before.
- **3.7.** Before: `(0.80)(+5.0) + (0.40)(−2.0) = 4.0 − 0.80 =
  +3.2`. After: `(1.2)v′ = 3.2`, so `v′ = +2.7 m/s` (2.67 rounded
  to two significant figures).
- **3.8.** Before: `(5.0)(1.2) = 6.0`. After: `(8.0)v′ = 6.0`, so
  `v′ = +0.75 m/s`.
- **3.9.** Arithmetic cause: a sign error — e.g. treating a
  left-moving velocity as positive — inflates the after total.
  Check: every velocity's sign against the right-positive
  convention. Physics cause: an external impulse during the
  collision (a hand pushing, friction over a long contact) changed
  the system's momentum. Check: was the system truly isolated, and
  was the contact brief?
- **3.10 (simulation prediction).** Before: `(1.0)(2.0) = 2.0`.
  After: `(2.0)v′ = 2.0`, so `v′ = +1.0 m/s`. (Session S7 tests this.)
- **3.11.** Before: `(1.0)(6.0) = 6.0`. After: `(3.0)v′ = 6.0`,
  so `v′ = +2.0 m/s`. Condition: conservation applies to a system
  with no net external force.
- **Extension.** Case 1: `(2.0)(3.0) / 6.0 = 1.0 m/s`. Case 2:
  before `6.0 − 4.0 = 2.0`, after `(6.0)v′ = 2.0`, so
  `v′ = +0.33 m/s`. The second case is slower because the
  opposing momentum of the heavier cart cancelled part of the total.

## Lesson 04 — Elastic vs. inelastic

- **4.1.** Smaller: sticking together means one common velocity,
  and the kinetic energy of the joined mass is less than the sum of
  the separate kinetic energies (shown numerically in Example 2).
- **4.2.** The "so" is false: momentum conservation and kinetic
  energy conservation are separate laws with separate conditions.
  Momentum is conserved in every isolated collision; kinetic energy
  only in elastic ones.
- **4.3.** Momentum before: `(2.0)(2.0) = 4.0`. After:
  `(2.0)(0.67) + (1.0)(2.67) = 1.34 + 2.67 = 4.01` ✓ (rounding).
  KE before: `½(2.0)(2.0)² = 4.0 J`. After:
  `½(2.0)(0.67)² + ½(1.0)(2.67)² = 0.45 + 3.56 = 4.01 J` ✓
  (rounding). Both match: elastic (consistent).
- **4.4.** Before: `(3.0)(4.0) + (3.0)(−2.0) = 12 − 6 = 6.0`.
  After: `(6.0)v′ = 6.0`, so `v′ = +1.0 m/s`. KE before:
  `½(3)(16) + ½(3)(4) = 24 + 6 = 30 J`. KE after:
  `½(6)(1.0)² = 3.0 J`. Lost: `27 J`.
- **4.5.** Accept: momentum is (approximately) conserved because
  the collision is brief and external impulses are small, but the
  collision is inelastic because kinetic energy was transformed
  into deformation energy (bent metal), sound, and heat — the
  two-quantity test fails on energy while passing on momentum.
- **4.6.** Equal masses exchange velocities: after, the first cart
  moves at −2.0 m/s and the second at +2.0 m/s. KE before:
  `½(1.5)(4) + ½(1.5)(4) = 6.0 J`; after: the same, 6.0 J. Elastic.
- **4.7.** Before: `(4.0)(1.5) = 6.0`. After: `(6.0)v′ = 6.0`,
  so `v′ = +1.0 m/s`. KE before: `½(4.0)(1.5)² = 4.5 J`. KE
  after: `½(6.0)(1.0)² = 3.0 J`. Lost: `1.5 J`.
- **4.8.** The error is conserving the wrong quantity: kinetic
  energy is not conserved when objects stick. Momentum conservation
  is the reliable law here; the "missing" kinetic energy became
  deformation energy, heat, and sound.
- **4.9.** KE before in both cases: `½(1.0)(3.0)² = 4.5 J`.
  Elasticity 100%: velocities exchange — first ball 0, second
  3.0 m/s; KE after 4.5 J; lost 0 J. Elasticity 0%: common velocity
  `(3.0)/(2.0) = 1.5 m/s`; KE after `½(2.0)(1.5)² = 2.25 J`;
  lost `2.25 J`.
- **4.10.** Accept: momentum is conserved in every collision of an
  isolated system; kinetic energy is conserved only in an elastic
  collision.
- **Extension.** Formulas give `v₁′ = [(3−1)(2.0)]/4 = 1.0 m/s`
  and `v₂′ = [2(3)(2.0)]/4 = 3.0 m/s`. Momentum: before 6.0,
  after `3.0 + 3.0 = 6.0` ✓. KE: before 6.0 J, after
  `1.5 + 4.5 = 6.0 J` ✓.

## Lesson 05 — Safety

- **5.1.** Let the hands move back: the longer stop feels softer
  (smaller average force for the same momentum change).
- **5.2.** Momentum change: the same (both stop from the same
  speed). Force: not the same — the barrels extend the stopping
  time, so the average force is smaller.
- **5.3.** `Δp = (0.50)(0 − 8.0) = −4.0 kg·m/s` (magnitude 4.0).
  Wall: `4.0 / 0.0050 = 800 N`. Pad: `4.0 / 0.050 = 80 N`.
- **5.4.** Force falls by a factor of 5 (inverse proportion at
  fixed `Δp`).
- **5.5.** A: `6.0 / 0.030 = 200 N`. B: `6.0 / 0.12 = 50 N`.
  On force alone, B is better. A could still win overall if B is
  too large, too heavy, or single-use where reuse matters — any
  one stated trade-off is acceptable.
- **5.6.** `Δp = (70)(0 − 10) = −700 kg·m/s` (magnitude 700).
  Dashboard: `700 / 0.025 = 28,000 N`. Belt and airbag:
  `700 / 0.25 = 2,800 N`.
- **5.7.** `Δp = (1,000)(0 − 15) = −15,000 kg·m/s` (magnitude
  15,000). 0.10 s: `150,000 N`. 0.50 s: `30,000 N`.
- **5.8.** Correction: the momentum change is the same in both
  cases (full stop from the same speed); what changes is the
  stopping time, and therefore the average force. Separately,
  spreading the force over a larger area reduces pressure, which
  also reduces injury — that is an area effect, not an impulse
  effect.
- **5.9.** Accept a draft with: two named materials and a
  time-based prediction; constraints stated (≤0.50 kg total,
  ≤30 cm); and the hard-stop prediction: impact speed 5.4 m/s,
  momentum `1.1 kg·m/s`, hard-stop average force about 110 N
  (1.08 / 0.010 = 108 N).
- **5.10.** Accept: extending the time reduces the average force
  because `F_avg = Δp / Δt` — same numerator, larger denominator.
- **Extension.** Triangular peak `= 2 × average = 2 × 3,600 =
  7,200 N`. A design judged only on average force could still fail
  if its peak exceeds the damage threshold, which is why the
  project uses a damage criterion rather than a single computed
  number.

## Lesson 06 — Tool choice

- **6.1.** Stopping time → impulse (`J = Δp`). Stopping distance
  → work–energy (`W = ΔKE`), because work is force times distance.
- **6.2.** Impulse–momentum (needs force and time, or a velocity
  change) and work–energy (needs force and distance, or speeds and
  heights). Accept equivalent answers.
- **6.3.** `Δp = (0.20)(−5.0 − 5.0) = −2.0 kg·m/s`. KE before:
  `½(0.20)(25) = 2.5 J`; after: `½(0.20)(25) = 2.5 J`; change
  zero. Impulse is nonzero because velocity (a vector) reversed,
  while kinetic energy depends on speed squared and is unchanged.
- **6.4.** (a) Common velocity: `(2.0)(5.0) / 5.0 = 2.0 m/s`.
  (b) KE after collision: `½(5.0)(2.0)² = 10 J`; distance
  `= 10 / 5.0 = 2.0 m`.
- **6.5.** Accept: in the rocket-plus-exhaust system there is no
  net external force, so total momentum stays constant; exhaust
  gains backward momentum, so the rocket must gain equal forward
  momentum. Nothing external pushes the rocket.
- **6.6.** (a) `Δp = −4.0 kg·m/s`; time `= 4.0 / 20 = 0.20 s`.
  (b) KE `= ½(1.0)(16) = 8.0 J`; distance `= 8.0 / 20 = 0.40 m`.
  Check: average speed `2.0 m/s × 0.20 s = 0.40 m` ✓.
- **6.7.** Common velocity: `(3.0)(2.0) / 4.0 = 1.5 m/s`
  (momentum tool). KE before: `½(3.0)(4.0) = 6.0 J`; after:
  `½(4.0)(2.25) = 4.5 J`; lost `1.5 J` (energy test).
- **6.8.** The learner conserved kinetic energy, which fails for a
  sticky collision. Momentum conservation is the reliable law;
  the "missing" kinetic energy became deformation energy, heat,
  and sound.
- **6.9.** (a) Work–energy, `W = Fd = ΔKE`; check with impulse if
  the time is also known. (b) Impulse–momentum, `J = FΔt = Δp`;
  check with energy if the distance is known. (c) Conservation of
  momentum, `m₁v₁ + m₂v₂ = m₁v₁′ + m₂v₂′`; check with the energy
  test. (d) Work–energy / energy conservation, `mgh = ½mv²`;
  check with kinematics. (e) Impulse–momentum,
  `F_avg = Δp / Δt`; check against a damage criterion, not energy
  alone.
- **6.10.** Accept: "time → impulse–momentum, because impulse is
  force times time"; "distance → work–energy, because work is
  force times distance."
- **Extension.** Simplified model: `v = 20 m/s` forward, as
  computed in the lesson. It overstates a real rocket because the
  rocket's mass decreases as exhaust leaves and because all
  velocities must be measured in one consistent frame; the
  direction of the conclusion is still correct.
