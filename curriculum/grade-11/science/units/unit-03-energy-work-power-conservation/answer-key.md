# Answer Key — Unit 03 (adults only)

Every item below was solved independently of the lesson text
and reconciled with it. Where a lesson's guided practice and
the practice sets share numbers, the working is shown once
and the result cross-checked, not copied. `g = 9.80 m/s²`.

## Lesson 01 — Work

**Guided practice.** 1. `W = (40 N)(6.0 m) = 240 J`. 2.
`W = (80 N)(10 m)(cos 60°) = (80)(10)(0.500) = 400 J`. 3. `0 J`
— no displacement, so no energy is transferred, however hard
the hold feels. 4. `W = (19.6 N)(3.0 m) = 58.8 J ≈ 59 J`,
positive (force along the displacement). 5. Push:
`(50 N)(3.0 m) = +150 J`; friction: `−(30 N)(3.0 m) = −90 J`;
net: `150 − 90 = +60 J`.

**Independent practice.** 1. `(25 N)(12 m) = 300 J`. 2.
`(200 N)(8.0 m)(cos 45°) = (200)(8.0)(0.707) = 1131 J ≈
1.1 × 10³ J`. 3. `0 J` — the normal force is perpendicular
to the horizontal motion (`cos 90° = 0`). 4. Push:
`(90 N)(6.0 m) = 540 J`; friction: `−(40 N)(6.0 m) = −240 J`;
net: `300 J`. 5. Gravity: `−(5.0 kg)(9.80 m/s²)(2.0 m) =
−98 J`; lifting force: `+98 J`; net: `0 J` — consistent with
constant velocity (`ΔKE = 0`, Lesson 02).

**Applied task (work audit).** Accept any action with all four
forces named: weight (zero work for horizontal motion —
perpendicular), normal force (zero work — perpendicular),
applied force (positive work — along the motion), friction
(negative work — opposing). Deduct for a missing force or for
an "effort" argument used in place of displacement.

**Exit check.** 1. `150 J`. 2. False — holding still gives
zero displacement, so zero physics work; the tiredness is
energy burned inside the muscles, not transferred to the box.
3. `0 J`, because `cos 90° = 0`.

## Lesson 02 — Kinetic energy and the work–energy theorem

**Guided practice.** 1. `KE = ½(0.50)(8.0)² = 16 J`. 2.
`100 = ½(5.0)v²` → `v² = 40` → `v = 6.3 m/s`. 3. `KE =
½(800)(15)² = 90,000 J`; `d = 90,000 / 4500 = 20 m`. 4.
`KE_i = ½(2.0)(4.0)² = 16 J`; `KE_f = ½(2.0)(10)² = 100 J`;
`ΔKE = 84 J`. 5. Correction: the factor is **4**, not 2 —
e.g., a 2.0 kg ball at 2.0 m/s has KE 4.0 J; at 4.0 m/s it has
16 J.

**Independent practice.** 1. `KE = ½(4.0)(3.0)² = 18 J`. 2.
`KE_i = ½(1.0)(6.0)² = 18 J`; `KE_f = 18 − 10 = 8.0 J`;
`v = √(2 × 8.0 / 1.0) = 4.0 m/s`. 3. `KE = ½(60)(10)² =
3000 J`; `d = 3000 / 300 = 10 m`. 4. Wrong — stopping
distance scales with `v²`, so doubling speed quadruples
stopping distance, not doubles it.

**Applied task (crash-energy comparison).** (a) Car B carries
`4×` the kinetic energy (`30² / 15² = 4`). (b) Its stopping
distance is `4×` longer (same braking force, `W = Fd`).
(c) Accept any two sentences that follow from the ×4 scaling
and mention that crash energy, not just speed, is what the
brakes and the body must absorb.

**Exit check.** 1. `24 J`. 2. `v = √(2 × 90 / 5.0) =
6.0 m/s`. 3. False — tripling speed multiplies KE by **9**.

**Extension.** `62.5 m` at 25 m/s; `250 m` at 50 m/s (×4).

## Lesson 03 — Gravitational potential energy

**Guided practice.** 1. `(10)(9.80)(5.0) = 490 J`. 2.
`(0.20)(9.80)(2.0) = 3.92 J ≈ 3.9 J`. 3. `(70)(9.80)(300) =
205,800 J ≈ 2.1 × 10⁵ J`; no, the path does not matter —
gravity is conservative, only the height change counts. 4.
`PE = (3.0)(9.80)(−2.0) = −58.8 J ≈ −59 J` below the datum;
rising to the datum changes it by `+59 J`.

**Independent practice.** 1. `(3.0)(9.80)(4.0) = 117.6 J ≈
118 J`. 2. `(600)(9.80)(20) = 117,600 J ≈ 1.2 × 10⁵ J`. 3.
Accept any correction that says: PE values are relative to a
chosen datum, so below-datum values are legitimately negative;
only *changes* are datum-independent. 4. Ratio `2:1`
(`50 m : 25 m`).

**Applied task (PE bank).** A: `(5.0)(9.80)(10) = 490 J`;
B: `(10)(9.80)(4.0) = 392 J`. A stores more, by `98 J`. The
sentence must say stored energy is the product `mgh` — mass
alone does not decide it.

**Exit check.** 1. `98 J`. 2. False — the datum changes the
labels, never the change. 3. `150 J` — same height change,
same PE gain, path-independent.

**Extension.** `h = 28.8 / (0.40 × 9.80) = 7.3 m`.

## Lesson 04 — Elastic potential energy and conservation

**Image activity (skater, 60 kg, 3.0 m).** (a)
`PE = (60)(9.80)(3.0) = 1764 J ≈ 1.8 × 10³ J`. (b)
`½(60)v² = 1764` → `v = √58.8 = 7.7 m/s`. (c) At 1.5 m:
`PE = 882 J`; `KE = 1764 − 882 = 882 J`;
`v = √(2 × 882 / 60) = √29.4 = 5.4 m/s`.

**Guided practice.** 1. `PE = ½(100)(0.20)² = 2.0 J`. 2.
`v = √(2 × 9.80 × 4.0) = √78.4 = 8.9 m/s`. 3.
`v = √(2 × 9.80 × 1.2) = √23.52 = 4.8 m/s` (mass cancels).
4. `KE = 200 − 120 = 80 J`; `h = 120 / (2.0 × 9.80) = 6.1 m`.

**Independent practice.** 1. `v = √(2 × 9.80 × 3.2) =
√62.72 = 7.9 m/s`. 2. `EPE = ½(50)(0.10)² = 0.25 J`;
`v = √(2 × 0.25 / 0.10) = √5 = 2.2 m/s`. 3.
`v = √(2 × 9.80 × 20) = √392 = 19.8 m/s ≈ 20 m/s`. 4.
Correction: doubling height multiplies impact speed by
`√2 ≈ 1.41`, not 2, because `v = √(2gh)`.

**Applied task (playground slide).** (a) `v = √(2 × 9.80 ×
2.0) = 6.3 m/s`. (b) Lower — friction converted some
mechanical energy to thermal energy. (c) Accept any two
sentences naming friction and thermal energy as the
destination.

**Exit check.** 1. `½(400)(0.050)² = 0.50 J`. 2.
`v = √98 = 9.9 m/s`. 3. False — speed goes as the square root
of height, so half the height gives `v / √2`, not `v / 2`.

**Extension.** `KE = 9.6 J`; `h = 9.6 / (0.30 × 9.80) = 3.3 m`.

## Lesson 05 — Nonconservative forces and efficiency

**Guided practice.** 1. `100 − 70 = 30 J`. 2. `6.0 / 60 =
10%`. 3. `1250 / 5000 = 25%`; wasted `5000 − 1250 = 3750 J`.
4. Initial PE: `(5.0)(9.80)(2.0) = 98 J`; final KE:
`½(5.0)(5.0)² = 62.5 J`; thermal: `98 − 62.5 = 35.5 J ≈
36 J` (positive, as expected — 5.0 m/s is below the
frictionless 6.3 m/s).

**Independent practice.** 1. `1200 − 900 = 300 J`. 2.
`1500 / 2000 = 75%`. 3. A is more efficient (75% vs. 60%);
B delivers more useful energy (1800 J vs. 1500 J). 4. Accept
any correction naming thermal energy (warmer slide, clothes,
air) as the destination, with warmer surfaces as evidence.

**Applied task (home audit).** No single ranking is required;
check that each conversion names input, useful output, and a
wasted form (thermal, plus sound/light where honest), that no
conversion is claimed at 100%, and that each ranking has a
reason.

**Exit check.** 1. `40 J`. 2. `125 / 500 = 25%`. 3. False —
100% efficiency is impossible; some energy always becomes
thermal.

**Extension.** `KE = ½(1500)(20)² = 300,000 J = 3.0 × 10⁵ J`,
all of it thermal.

## Lesson 06 — Power and budgets

**Guided practice.** 1. `1000 / 20 = 50 W`. 2. `W =
(20)(9.80)(5.0) = 980 J`; `P = 980 / 2.5 = 392 W ≈ 390 W`. 3.
`P = (1200 N)(25 m/s) = 30,000 W = 30 kW`. 4. The faster
climber uses more power, by a factor of **2** (same work,
half the time).

**Independent practice.** 1. `W = (70)(9.80)(3.0) = 2058 J`;
`P = 2058 / 5.0 = 411.6 W ≈ 410 W`. 2. `500 × 10 = 5000 J`.
3. Thermal: `500 − 300 − 0 = 200 J`; the system is closed,
so the total is constant and the unknown component is the
total minus the known ones. 4. Correction: the 100 W motor
does `100 × 60 = 6000 J`; the 1000 W motor does `1000 × 1 =
1000 J` — the *less* powerful motor does more work here,
because it runs longer.

**Applied task (project budget).** Check: columns for input,
kinetic, useful output, thermal, and total; rows for start, a
middle instant, and end; the unknown column expressed as
"total − (known components)" before it is typed as a formula.

**Exit check.** 1. `200 W`. 2. `200 W`. 3. Thermal:
`900 − 400 − 300 = 200 J`, from the closed-system balance.

**Extension.** Rectangle area: `(40 N)(5.0 m) = 200 J`.

## Project — simulation alternative dataset (fictional practice data)

For the PhET route, a worked account to check against (not
data the learner measured): a 50 kg skater at a ramp top
2.0 m above the bottom. Total energy: `(50)(9.80)(2.0) =

`√(2 × 980 / 50) = √39.2 = 6.3 m/s`. Friction run — bottom

learner's own numbers will differ; the accounting rules must

## Unit assessment

**Task 1 (work).** Applied work: `(150 N)(10 m)(cos 60°) =
750 J`. Friction work: `−(40 N)(10 m) = −400 J`. Net work:
`750 − 400 = 350 J`. (3 pts: one per value; sign errors lose
the value's point.)

**Task 2 (work–energy theorem).** `KE_i = ½(2.0)(3.0)² =
9.0 J`; `KE_f = 9.0 + 40 = 49 J`; `v = √(2 × 49 / 2.0) =
7.0 m/s`. (3 pts.)

**Task 3 (conservation).** PE at 8.0 m: `(0.60)(9.80)(8.0) =
47.04 J ≈ 47 J`. Speed at ground: `v = √(2 × 9.80 × 8.0) =
√156.8 = 12.5 m/s`. At 4.0 m: `KE = (0.60)(9.80)(4.0) =
23.52 J`; `v = √(2 × 23.52 / 0.60) = √78.4 = 8.9 m/s`.
(4 pts: PE, ground speed, mid KE, mid speed.)

**Task 4 (spring).** `EPE = ½(250)(0.12)² = 1.8 J`. Launch
speed: `v = √(2 × 1.8 / 0.050) = √72 = 8.5 m/s`. (3 pts.)

**Task 5 (nonconservative).** PE: `(3.0)(9.80)(1.2) =
35.28 J ≈ 35 J`. KE: `½(3.0)(2.0)² = 6.0 J`. Lost:
`35.28 − 6.0 = 29.28 J ≈ 29 J`. Efficiency: `6.0 / 35.28 =
17%`. (4 pts.)

**Task 6 (power).** `W = (25)(9.80)(10) = 2450 J`;
`P = 2450 / 5.0 = 490 W`. (2 pts.)

**Task 7 (budget table, HS-PS3-1).** Mid instant thermal:
`800 − 500 − 200 = 100 J`. End instant thermal:
`800 − 300 − 0 = 500 J`. Explanation: the cart system is
closed, so the total stays 800 J and the unknown component is
the total minus the known ones; friction converted 500 J
altogether by the end. (4 pts: two values, balance rule,
conclusion.)

**Task 8 (open response).** Accept any answer that: (a)
predicts the smooth ramp's cart arrives faster (or both arrive
at the same speed if frictionless — mass cancels), using
energy accounting; (b) explains the rough ramp's shortfall as
mechanical energy converted to thermal energy, with the
accounting `W_nc = ΔE_mech`; (c) corrects the flawed claim
(e.g., "heavier falls faster" — in the frictionless case the
mass cancels from `mgh = ½mv²`; with friction the result
depends on the friction force, not on weight alone). (5 pts:
prediction, accounting, correction, each with reasoning.)
