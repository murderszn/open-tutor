## Set B — Source-kind sorting and inference drills (Sessions 4, 10)

**B1.** Classify each by kind (map / traveler's account / artifact / coin /
chronicle / secondary interpretation / modern reconstruction). Then name
one thing it CAN and one thing it CANNOT tell us.

a. A 12th-century brass astrolabe found in a shipwreck.
b. A museum's 30-minute film showing "a day in medieval Baghdad."
c. Ibn Battuta's *Rihla* describing the markets he visited. *(Real work,
   named as a kind — adult previews any excerpt.)*
d. A gold coin stamped with the name of a Mali ruler, found in a
   Moroccan market town.
e. A 2026 textbook chapter titled "The Indian Ocean World."
f. Al-Idrisi's world map, made in 1154 for Roger II of Sicily.

**B2.** For item (d): infer the coin's likely place of *minting* versus
place of *finding*, and explain in two sentences what the gap between
those places proves — and what it does not prove.

**B3.** Inference drill. For each, state the inference AND the clue it
rests on:

a. A chronicle entry lists three caravan gifts to a town's well-repair
   before mentioning a royal wedding. → Infer the writer's priorities.
b. A traveler's account describes market prices in exact numbers but never
   names the city's ruler. → Infer what the writer cared about.
c. A map labels Christian cities with crosses and all other cities with
   dots. → Infer the mapmaker's viewpoint.

**B4.** Run the five evaluation tests (origin, authority, structure,
context, corroborative value) on **one** item from B1 — your choice.
End with a two-sentence verdict.

## Set C — Map-construction studio (Session 6)

*Rebuilt from the track's legacy city-planning design lab
(`curriculum/grade-7/social-studies/assignments/city-planning-design-lab.md`),
per the A00 audit: the original scaffold (naming, zoning, location
reasoning) is kept; map instruction (scale, key, grid), corridor
placement, and a rubric are added. The original file is unchanged.*

**C1. Design a medieval trade town.** On graph or plain paper, draw a
map of a fictional oasis town on ONE trade corridor (your choice from
Lesson 03). Your map MUST include:

- a title naming the town and its corridor;
- a key/legend explaining every symbol;
- a compass rose;
- a scale bar (state what it equals);
- a grid (lettered columns, numbered rows);
- at least five features: a water source, a market, an inn for travelers
  (caravanserai), a town gate, and one feature of your choice;
- the corridor route passing through or near the town (dashed for
  overland, wavy for sea — label which corridor it is).

**C2. Location reasoning.** Below the map, answer in 3–5 sentences: *Why
did you put the market where you did? Why is the inn near the gate (or
not)?* Every placement reason must reference water, defense, trade, or
travel distance — not "it looked nice."

**C3. Evidence claims.** Write two claims your map PROVES (cite the map
tool: grid, scale bar, key) and two things your map CANNOT show.

**Studio rubric** (adult scores; each row 0–3):

| Criterion | 3 — strong | 2 — developing | 1 — starting | 0 — missing |
|---|---|---|---|---|
| Map tools | All six tools present and correct (title, key, compass rose, scale bar, grid, symbols) | Five tools present; minor error in one | Two or fewer tools missing or wrong | Map unreadable as a map |
| Scale honesty | Scale bar matches grid; a measured distance is stated correctly | Scale bar present; one measuring error | Scale bar decorative (doesn't match) | No scale bar |
| Location reasoning | Every placement tied to water/defense/trade/distance | Most placements reasoned; one "looked nice" | Reasons are decorative only | No reasoning written |
| Corridor fit | Town sits on the named corridor; route symbol matches kind (dashed/wavy) | Corridor named; route symbol wrong or vague | Corridor named but town disconnected from it | No corridor |

**Score guide:** 10–12 = portfolio-ready; 7–9 = revise one row with the
adult; below 7 = rebuild with the adult modeling one placement decision.

## Set D — Corridor practice + "where in the modern world?" (Session 7)

**D1.** On the corridor schematic, trace each corridor with a finger and
copy this table into your notebook, filling the middle column from the
schematic:

| Corridor | Cities in order (from schematic) | One good it carried |
|---|---|---|
| Silk Road (overland) | | |
| Mediterranean (sea) | | |
| Indian Ocean (monsoon) | | |
| Trans-Saharan (caravan) | | |

**D2. Where in the modern world?** Using
[`resources/un_countries.csv`](../../../../../resources/un_countries.csv)
(columns: `name_common`, `capital`, `region`, `subregion`), match each
medieval city to the modern country containing its site. Write
city → country, and note any case where the medieval name differs from
the modern city name.

Cities: Chang'an, Samarkand, Baghdad, Constantinople, Venice, Alexandria,
Aden, Hormuz, Calicut, Malacca, Sijilmasa, Timbuktu, Gao.

*Adult note: the CSV has no medieval names; the learner matches by known
modern equivalents (e.g., Chang'an → Xi'an, China; Constantinople →
Istanbul, Türkiye). The point is continuity of place, not CSV lookup
speed — the adult confirms the six trickiest.*

**D3.** Choose one corridor. In four sentences, explain why its *physical
geography* shaped how people traveled it (desert, sea winds, mountains,
or straits — pick what fits). This is D2.Geo thinking: environment shapes
movement.
