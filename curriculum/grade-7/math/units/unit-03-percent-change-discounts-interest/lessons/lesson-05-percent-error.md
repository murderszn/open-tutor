# Lesson 05 — Percent Error

**Goal:** You will compute percent error as |estimate − actual| /
actual and explain why the denominator is the actual value.
**Time:** 45 minutes · **Materials:** paper, pencil, calculator for checking only
**Unit:** [Unit 03](../README.md) · **Objective 5** · **Standard 7.RP.A.3**

## Readiness check (3 min)

1. Compute |50 − 40|.
2. Compute 10 ÷ 40 as a percent.
3. A guess of 60 for an actual value of 75: how far off is the guess,
   in absolute terms?

## Teaching

An **estimate** is a guess or a measurement; the **actual value** is
the true value. The **percent error** says how big the mistake is
*relative to the truth*:

> percent error = |estimate − actual| ÷ actual × 100%

The absolute value bars mean "ignore the sign of the difference" — an
overestimate and an underestimate of the same size have the same
percent error. The denominator is the **actual** value because the
error is measured against the truth, not against the guess. Using the
estimate as the denominator is the classic mistake of this lesson.

**Worked example 1.** You estimate a rope is 50 meters long. It is
actually 40 meters. What is the percent error?

|50 − 40| = 10. Percent error = 10 ÷ 40 × 100% = **25%**.
If you divided by the estimate (10 ÷ 50), you would get 20% — wrong
base. The truth is 40, so the error is measured against 40.

**Worked example 2.** A scientist measures a wire as 98 cm. Its actual
length is 100 cm. What is the percent error?

|98 − 100| = 2. Percent error = 2 ÷ 100 × 100% = **2%**. A small error
against a large actual value is a small percent error — that is the
point of the measure.

**Worked example 3.** A student estimates 120 people will attend a
fair. Actually 150 attend. What is the percent error?

|120 − 150| = 30. Percent error = 30 ÷ 150 × 100% = **20%**.
Reason check: 30 is one-fifth of 150, and one-fifth is 20%. ✓

## Guided practice (with hints)

**G1.** Estimate 60, actual 75. Find the percent error.
*Hint: difference 15, denominator 75.*

**G2.** A measured length is 49 cm; the actual length is 50 cm. Find
the percent error.
*Hint: difference 1, denominator 50.*

**G3.** Estimate 200, actual 160. Find the percent error.
*Hint: difference 40, denominator 160 — not 200.*

## Independent practice

**I1.** Estimate 30, actual 36. Find the percent error.
**I2.** A measured mass is 297 g; the actual mass is 300 g. Find the
percent error.
**I3.** Estimate 88, actual 80. Find the percent error.
**I4.** Two guesses for an actual value of 200: one guess is 180, the
other is 220. Find both percent errors. What do you notice?

## Applied task

A reporter estimates a crowd of 450 people. The actual crowd is 500.
(a) What is the percent error? (b) The reporter's editor says "you
were off by 50 out of 450, so about 11%." Is the editor right? Explain
which denominator is correct and why, in one or two sentences.

## Exit check

Estimate 55, actual 50. What is the percent error? Show the difference
and the denominator.
