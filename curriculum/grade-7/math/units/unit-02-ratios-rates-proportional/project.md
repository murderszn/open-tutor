# Project — Best-Value Pantry Investigation

**Unit 02 · Sessions 11 and 13** (45 minutes each; submitted with the
Session 16 assessment)
**Objectives 1–3** · Rebuilds the legacy
`assignments/proportional-relationships-shop.md` with keys and a rubric

## The task

You are the family's value detective. Stores *want* you to compare
sticker prices; mathematicians compare **unit rates**. Your job: find
out whether bigger really means better value — and whether any store's
pricing is actually proportional.

## Materials

Grocery flyers, pantry labels, or a notebook of prices copied from a
real shelf (copy numbers only — no photos of people, no store names
required); paper; pencil; calculator for checking only.

## Steps

**Part 1 — Collect (Session 11, ~30 min + 15 min computing)**

1. Choose **3 products** (real or pretend; e.g., rice, peanut butter,
   dish soap). For each product, record **2–3 package sizes** with
   their weights/volumes and prices. You need at least 8 size-price
   pairs total.
2. For every pair, compute the **unit rate** (price per unit) with
   correct units. Show each division.
3. Rank the sizes of each product from best to worst value.

**Part 2 — Test and report (Session 13)**

4. **Proportionality test:** for each product, test whether price is
   proportional to size (equivalent y ÷ x across its sizes, or
   equivalent ratios). Give a verdict per product with the test shown.
5. Write **3 comparison statements** using ratio language (e.g., "The
   5-lb bag costs $1.40 per pound, while the 2-lb bag costs $1.70 per
   pound, so the larger bag saves $0.30 per pound").
6. **Design a deal:** invent a new size for one product and set a price
   that (a) keeps the product's pricing proportional if it was
   proportional, or (b) undercuts the current best unit rate by at
   least 5% if it was not. Show the math.
7. Write a **4–6 sentence conclusion**: is "bigger is better value"
   always true? When does proportionality hold in store pricing, and
   when does it break? Cite your own numbers.

## Deliverables

1. Data table: product, size, price, unit rate (with units), value rank.
2. Proportionality verdicts with the y ÷ x test shown for each product.
3. Three ratio-language comparison statements.
4. The designed deal with supporting computation.
5. Written conclusion (4–6 sentences).

## Rubric (20 points)

| Criterion | 4 — Strong | 3 — Proficient | 2 — Developing | 1 — Beginning |
|---|---|---|---|---|
| Unit-rate computation (4) | All ≥8 unit rates correct, units on every answer, divisions shown | All correct; minor unit omissions | Most correct; some division work missing | Many errors or no work shown |
| Value ranking (3) | Rankings follow the unit rates exactly for all 3 products | Rankings correct; one ordering slip | Rankings match sticker prices, not unit rates | No coherent ranking |
| Proportionality test (5) | y ÷ x tested on every size of every product; correct verdicts with reasons | Tests shown; one verdict wrong | Test attempted on some products only | No test, or "goes up together" reasoning |
| Comparison statements (3) | 3 statements, correct ratio language, accurate numbers | 3 statements; minor number slip | Fewer than 3, or vague ("better deal") | Missing |
| Designed deal (3) | Price computed correctly for the stated goal; math shown | Correct idea; arithmetic slip | Deal stated without supporting math | Missing |
| Conclusion (2) | 4–6 sentences, answers both questions, cites own numbers | Addresses the questions; thin evidence | One question answered | Missing or off-topic |

**Scoring:** 18–20 exemplary · 14–17 proficient · 10–13 developing ·
below 10 revisit Sessions 5–6 with the adult before the unit assessment.

## Adult notes

- The "designed deal" (step 6) is the hardest; if the learner is stuck,
  do one together: for a proportional product with k = $1.50/lb, a new
  6-lb size must cost 6 × 1.50 = $9.00 to stay proportional.
- Common error: ranking by sticker price. Point back to Lesson 02's
  apple stand — the image activity exists for exactly this moment.
- A sample solution sketch (not a full key — learner data varies) is in
  [teacher-guide.md](teacher-guide.md#project-sample-sketch).
