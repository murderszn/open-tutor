# Teacher Guide — Unit 02: Ratios, Rates, and Proportional Relationships

For the guiding adult. Student materials never contain answers; all
solutions are in [answer-key.md](answer-key.md).

## Pacing notes

- **Sessions 1–4 (Week 7):** unit rates. Do not rush complex fractions —
  Lesson 01's reciprocal method is the same division learners know, but
  the stacked-fraction look causes panic. Cover one worked example with
  your own numbers before assigning guided practice.
- **Sessions 5–8 (Week 8):** the proportionality test. This is the
  unit's conceptual core. Spend Session 8's clinic on the two classic
  errors below; have the learner say verdicts *aloud* with reasons.
- **Sessions 9–12 (Week 9):** k and y = kx. The equation is new notation
  for an old idea (the unit rate); keep saying "k is the per-one value."
- **Sessions 13–16 (Week 10):** project finish, review, quiz,
  assessment. Collect the project with the Session 16 assessment.

## Misconception clinic

1. **"Going up together means proportional."** Counter with the gym fee
   (Lesson 03, I3) and the parking garage (assessment B2): both increase
   steadily, neither is proportional. The test is *equivalent ratios*,
   not *increasing together*.
2. **"A straight line means proportional."** Counter with the taxi graph
   (Lesson 04, Worked example 2): straight, but misses the origin
   because of the flat fee. Both parts of the graph test are required.
3. **Dividing in the wrong order.** The sentence frame "___ per ___"
   must come *before* the division; the quantity after "per" is the
   divisor. (Lesson 01, I6.)
4. **Dropping units.** Require units on every answer from Session 1;
   a bare "4" earns no credit on the assessment.
5. **"A rate exists, therefore proportional."** The exit check of
   Lesson 06 ($0.65/mile + $12 base) exists to kill this: a per-unit
   rate can coexist with a non-proportional relationship.
6. **Cross-multiplying without testing.** Lesson 06, I6 (workers/hours):
   proportions only apply *after* the proportionality test passes.

## Differentiation

- **Support:** double number lines for every unit-rate problem in Week 7;
  pre-printed coordinate grids for Lessons 04–05; the text-only data
  table instead of the image activity; dictate-and-scribe for the
  project conclusion.
- **Extension:** Lesson 06's inverse-proportion enrichment (h = 24/w);
  Lesson 05's slope-preview task; design-a-deal with a percentage
  target in the project rubric's top band.
- **Language access:** the unit's vocabulary is small and repeated —
  keep a running word wall (ratio, rate, unit rate, proportional,
  constant of proportionality, origin). Every lesson restates new terms
  in context.

## Reteach triggers

- If the Week-10 quiz Q4/Q5 table tests are wrong, re-teach Lesson 03
  with two new tables before the unit assessment — do not proceed to
  Unit 03's percent work on a shaky test.
- If Q7/Q8 (k and y = kx) are wrong but the tests are right, the gap is
  notation, not concept: re-do Lesson 05's G1–G3 orally.
- If Q9/D1 value rankings follow sticker prices, re-do the Lesson 02
  image activity with the learner's own grocery numbers.

## Project sample sketch

(For the adult's eyes only — learner data will differ.) Example: rice
2-lb $3.20 ($1.60/lb), 5-lb $7.25 ($1.45/lb); peanut butter 16-oz $2.80
($0.175/oz), 28-oz $4.48 ($0.16/oz); dish soap 19-oz $3.99 ($0.21/oz),
50-oz $9.50 ($0.19/oz). Proportionality: rice 3.20/2 = 1.60 vs 7.25/5 =
1.45 → not proportional (bulk discount); same pattern for the others.
Designed deal: new 10-lb rice bag at the 5-lb unit rate → 10 × 1.45 =
$14.50 keeps the (non-proportional) best rate; or undercut by 5%:
1.45 × 0.95 = $1.3775/lb → 10 lb at $13.78 (round to $13.75).

## Readiness for Unit 03

Unit 03 (percent) assumes: fluent unit rates, a reliable
proportionality test, and y = kx with k-as-unit-rate. If the unit
assessment Part B or C scores below proficient, spend a Week-10-style
review session on Lessons 03–05 before starting percent — percent
*is* proportional reasoning with k = the percent rate.
