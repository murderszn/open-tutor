# Lesson 02 — Adding Rational Numbers

**Goal (student-readable):** I can add integers and other rational numbers
using a number-line diagram, and I can explain the sign rules with
opposite-quantities stories.
**Time:** 45 minutes · **Materials:** number line, paper, pencil.

## Readiness check (5 min)

Compute on your number line: (a) 4 + 3; (b) −4 + (−3). Say each answer as
a sentence: "Start at ___, move ___ units ___, land on ___." (Answers:
7; −7.) If the two answers feel like mirror images, you already see the
pattern this lesson names.

## Teaching

Addition on the number line is a **journey**: start at the first number
(p), then move a distance of |q| — right if q is positive, left if q is
negative. So p + q is the point you land on.

**Opposite quantities combine to 0.** A $5 deposit and a $5 withdrawal, a
3-degree rise and a 3-degree fall — each pair sums to 0. That is why
n + (−n) = 0 for every n: the number and its opposite cancel.

**Sign rules (with reasons, not just rules).** Adding two positives: move
right twice — the sum is positive and larger than either addend:
5 + 3 = 8. Adding two negatives: move left twice — the sum is negative:
(−5) + (−3) = −8. Adding numbers with different signs: the moves fight.
Start at 5, move 8 left: 5 + (−8) = −3. The result takes the sign of the
number with the larger absolute value, because the longer journey wins:
|−8| = 8 beats |5| = 5, so the answer is negative.

**Fractions and decimals work the same way.** The number line doesn't care
about the form. (−1/2) + (−1/4): start at −1/2, move 1/4 left, land at
−3/4. 2.5 + (−1.8): start at 2.5, move 1.8 left, land at 0.7. When
denominators differ, find a common denominator first — exactly as in
grade 6 — then let the signs decide the direction.

**Properties as strategies.** Because addition is commutative and
associative, you can regroup to make opposites cancel first: in
(−7) + 4 + 7, pair (−7) + 7 = 0 and 4 remains. Always scan for canceling
opposites before grinding — it is faster and less error-prone.

## Worked examples

**Example 1.** (−9) + 4.

Start at −9. Add 4 → move 4 right. −9 → −8 → −7 → −6 → −5. **Answer: −5.**
Reason check: the signs differ; |−9| = 9 > |4| = 4, so the negative wins;
9 − 4 = 5, so −5. Both methods agree.

**Example 2.** (−2/3) + 5/6.

Common denominator 6: −2/3 = −4/6. Now (−4/6) + 5/6: start at −4/6, move
5/6 right, land at 1/6. **Answer: 1/6.** Reason check: 5/6 > 4/6, so the
positive wins; 5/6 − 4/6 = 1/6. ✓.

**Example 3.** A checking account has −$42 (overdrawn by $42). A $60
paycheck deposit arrives. New balance?

(−42) + 60. Signs differ; 60 > 42, so positive wins; 60 − 42 = 18.
**New balance: $18.** Story check: the deposit first cancels the $42 debt
(opposite quantities → 0), leaving $18. ✓

## Guided practice (with hints)

1. Use the number line: (a) −6 + 2; (b) −6 + (−2); (c) 6 + (−2).
   *(Hint: say the journey aloud — "start, move, land.")*
2. (−11) + 11 + (−4). *(Hint: scan for opposites first.)*
3. (a) 3/4 + (−1/2); (b) −2.5 + 1.2. *(Hint: common denominator for (a);
   line up decimal points for (b).)*
4. A football team gains 8 yards, then loses 13 yards. Net gain or loss?
   Write the addition and the net result.
5. Explain in your own words why (−5) + 5 = 0, using a real situation.

## Independent practice

6. Compute: (a) −15 + 9; (b) 15 + (−9); (c) −15 + (−9); (d) 15 + 9.
   What pattern do you notice in the absolute values of the answers?
7. Compute: (a) −7/8 + 3/8; (b) 5/6 + (−2/3); (c) −1.4 + (−3.6);
   (d) 0.9 + (−2.25).
8. Fill the missing addend: (a) −8 + __ = −3; (b) __ + (−6) = 2;
   (c) 5/4 + __ = 1/2.
9. **Error analysis.** Sam says (−12) + 7 = −19 "because you add 12 + 7 and
   keep the negative." What did Sam do wrong, and what is the correct
   answer with a number-line reason?
10. The temperature was −6°C at dawn and rose 11°C by noon. What was the
    noon temperature? Show the addition and a reason check.

## Application

**Debt diary.** You owe a friend $25 (balance −25). Over three days: you
pay back $10, borrow another $8, then pay back $12. Write one addition
expression for the final balance and compute it. Is the debt fully repaid?
*(Model: −25 + 10 + (−8) + 12.)*

## Exit check

1. (−4) + (−9) = ? Explain with a journey sentence.
2. Without computing exactly, is (−13/7) + (5/7) positive or negative?
   How do you know?

## Supports and extensions

- **Reading/language access:** keep a "journey sentence" frame posted:
  "Start at ___, move ___ units ___, land on ___."
- **Alternate response mode:** use two colors of counters (red = negative,
  blue = positive); opposite pairs cancel and are removed.
- **Extension:** Find two different pairs of rational numbers (one using
  fractions, one using decimals) that sum to exactly −1, and prove with a
  number-line sketch that no other sign combination could work.

## Teacher note — likely misconceptions

- "Two negatives make a positive" gets over-applied to *addition*:
  (−5) + (−3) = −8, not 8. The "positive" version is true only for
  multiplication/division (Lesson 04) — preview the distinction but don't
  teach it yet.
- Learners sometimes add absolute values and then guess the sign. Insist on
  the journey sentence until the sign choice is justified by the longer
  move, not by a memorized rule.
