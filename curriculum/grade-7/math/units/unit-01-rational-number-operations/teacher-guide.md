# Teacher Guide — Unit 01: Rational Number Operations

**For the adult.** This guide holds the teaching judgment: what to watch
for, when to reteach, and what comes next. Keep it separate from the
learner — solutions live in [answer-key.md](answer-key.md).

## Readiness signals (end of unit)

The learner is ready for Unit 02 when they can, without prompting:

- Rewrite any subtraction as adding the opposite and say *why* the rewrite
  is valid (the "undo" idea), not just the rule.
- Predict a product/quotient's sign before computing digits, and justify
  the sign with the rules or the distributive-property argument.
- Convert p/q to a decimal by long division and predict terminating vs.
  repeating from the denominator's prime factors.
- Write one planned expression for a multi-step story, estimate first,
  and catch their own sign errors with the estimate.

## Reteach table

| If the learner… | Revisit | Targeted follow-up |
|---|---|---|
| Compares negatives by digit size (−7 > −3) | L1 | Daily 5-minute number-line ordering warm-ups for a week; floor-tape number line |
| Says (−5) + (−3) = 8 | L2 | Counter model: two red piles combine into a bigger red pile; journey sentences aloud |
| Writes −8 − (−3) = −11 | L3 | Red/blue rewrite drill: circle both signs, rewrite, then compute; 10 items/day until automatic |
| Says (−4)(−5) = −20 | L4 | Rebuild the (−1)(−1) distributive argument together; sign-rule chant card |
| Stops long division early (5/6 = 0.83) | L5 | Remainder-tracking template: "same remainder → same digits"; verify 0.83 × 6 ≠ 5 |
| Drops units or mixes °F/°C mid-problem | L6, project | Require units in every solution line; one-scale rule posted |
| Divides the mean by the wrong count | L6 | "How many numbers?" asked aloud before every mean; number-line sign reason |

## Misconception notes (by lesson)

- **L1:** Zero's opposite is 0 — say it; learners guess "there is none."
  |−5| = 5, never −5: absolute value is a distance.
- **L2:** "Two negatives make a positive" is *false for addition*;
  quarantine that phrase to multiplication/division (L4).
- **L3:** The double-sign rewrite must flip *both* the operation and the
  second number's sign. Partial flips (5 − −3 → 5 + −3) are the most common
  written error — have the learner read the rewrite aloud.
- **L4:** (−a)² = a² but −a² = −(a²). Division by zero is undefined —
  don't let "0 ÷ 0 = 0" slide.
- **L5:** 0.9̄ = 1 (state as a fact for now; proof waits for grade 8).
  22/7 is a repeating rational *approximation* of π, not π.
- **L6:** Distance traveled vs. displacement: absolute values for (b)-type
  questions. Estimation flags errors; it never proves an answer.

## Pacing notes

- Sessions 2, 4, 6, 9, 13 draw from [practice.md](practice.md); assign by
  objective, not in order — match the bank to the week's gaps.
- Session 7's misconception clinic works best as a *discussion*, not a
  worksheet: put one error-analysis item on a board and let the learner
  teach it back.
- The Temperature Ledger needs the adult only for data collection and
  completeness checks. If a week of real data is impractical, Dataset B is
  a full substitute — say so without apology; the reasoning is identical.

## What comes next (Unit 02)

Unit 02 (ratios, rates, proportional relationships) reuses this unit's
complex fractions for unit rates from fractional ratios, and its
estimation habit for checking proportionality claims. If complex fractions
are still shaky after Session 9, spend Session 13's practice time there
rather than on new enrichment — Unit 02 assumes them.

## Scoring the assessments

Use [answer-key.md](answer-key.md): every quiz item, assessment task, and
practice item is solved with reasoning notes. Partial-credit guidance is
in the quiz and assessment headers. For open-response items (e.g.,
assessment Task 3b, Task 5c), accept any wording that names the
distributive property and the forced conclusion, or that gives a correct
estimation bound — samples are in the key.
