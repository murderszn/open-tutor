**For the adult only.** Every item below was solved independently and
reconciled with its lesson, practice, quiz, assessment, or project
statement. Accept equivalent forms (e.g., −1/2 for −4/8) and any correct

## Lesson 01

**Readiness:** 7 and −7; both are 7 units from 0.

**Guided practice.** 1. Points at −10, −4, −1, 0, 3 in that left-to-right
order. 2. −12; 5; 0; 23. 3. 14; 14; 0; 3.5. 4. (a) −7 < −2; (b) −1.5 < 0;
(c) |−6| = 6 > |4| = 4, so >; (d) −(3) = −3, so =. 5. −8°C is colder;
|−8 − (−2)| = |−6| = 6 degrees colder.

**Independent practice.** 6. 7, 4, 0, −2, −6, −11. 7. (a) True: |−5| = 5 >
4. (b) True: −(−9) = 9. (c) True. (d) False: −12 = −12, so −12 < −12 is
false. 8. Integers, e.g., −3, 0, 2; non-integers, e.g., −3.5, −0.25, 2.9
(any three in range accepted). 9. The −18 ft diver is deeper; deeper by
|−18 − (−9)| = 9 ft. 10. Vertical line: −18 near the bottom, 0 (freezing)
above it, 20 off-scale marked with an arrow above 10.

**Application.** Ordered: −200 < −50 < 0 < +800 < +1500. Submarine–fish
distance: |(−200) − (−50)| = |−150| = 150 m.

**Exit check.** 1. |−13| = 13: "13 units from zero." 2. −4 > −6; on the
line −4 sits right of −6.

## Lesson 05

**Readiness:** (a) 0.5; (b) 0.25; (c) 0.3333….

**Guided practice.** 1. (a) 5/8 = 0.625, terminating (8 = 2³); (b) 4/9 =
0.4̄, repeating (9 = 3²); (c) 11/25 = 0.44, terminating (25 = 5²). 2. (a)
−0.6̄; (b) −0.35; (c) 13/6 = 2.16̄ (remainder 4 repeats). 3. As decimals:
2/3 = 0.6̄, 0.6, 0.6̄, 3/5 = 0.6 — ordered: 0.6 = 3/5 < 2/3 = 0.6̄. 4.
4(5/6) = 20/6 = 10/3 = 3.3̄ cups — repeating, so no exact terminating
decimal. 5. Sample: "7 is prime but isn't 2 or 5, so after reducing, the
denominator still has a factor 7; remainders can only be 1–6, so one must
repeat and the digits cycle."

**Independent practice.** 6. (a) 0.175; (b) −0.916̄ (remainder 8 repeats);
(c) 0.4̄5̄ (remainder 6 repeats → 45 block); (d) −0.36. 7. (a) True.
(b) True (e.g., 0.375 = 375/1000). (c) False: 22/7 = 3.1̄4̄2̄8̄5̄7̄
repeats; π never repeats. 8. Any three strictly between 0.333… and 0.34,
e.g., 167/500 = 0.334, 67/200 = 0.335, 337/1000 = 0.337. 9. Alex dropped
the infinite 3s: 5/6 = 0.83̄, not 0.83. Over 4 batches the error is
10/3 − 3.32 = 0.0133… = 1/75 cup — small but real, and it grows with more
batches. 10. −4/15 = −0.26̄; |−4/15 − 0.26̄| = |−8/15| = 8/15 = 0.53̄.
It tells you the two numbers are opposites (0.26̄ = 4/15), so the distance
between them is twice the number.

**Application.** Sixteenths: denominators are powers of 2 → always
terminate (e.g., 1/16 = 0.0625). Millimeters of a centimeter: tenths →
always terminate. Both terminate because the denominators' prime factors
are only 2s and 5s; sixteenths need up to 4 decimal places, tenths only 1.

**Exit check.** 1. −5/12 = −0.416̄ (remainder 8 repeats). 2. Disagree: 13
is prime but not 2 or 5, so 2/13 must repeat (repetend up to 12 digits).

**Ledger.** Daily swings (High − Low): D1: 3 − (−4) = 7; D2: −1 − (−8) =

**Graph notes.** Vertical number line from −14 to 8; highs as dots, lows
as crosses; zero line labeled "freezing (0°C)"; highs connected. The plot
shows the mid-week dip (Days 2–4 below zero) and the Day 5–6 recovery.

**Conclusion sample.** "The week cooled then recovered: the mean high was
