# Lesson 05 — Equations of the Form p(x + q) = r

**Goal:** You will solve word problems leading to equations of
the form p(x + q) = r, using both the distribute-first and the
divide-first methods, and compare them with an arithmetic
solution.
**Time:** 45 minutes · **Materials:** paper, pencil, calculator for checking only
**Unit:** [Unit 04](../README.md) · **Objective 3** · **Standard 7.EE.B.4.a**

## Readiness check (3 min)

1. Expand 2(x + 3).
2. Solve 2x + 6 = 14 (the expanded form of the equation above).
3. If 2 times something equals 14, what is that something?

## Teaching

In p(x + q) = r, the unknown sits inside parentheses with q,
and the whole group is multiplied by p. There are two correct
routes, and a good problem-solver knows both and picks the
easier one for the numbers in front of them.

**Divide-first:** divide both sides by p first, so the group
(x + q) stands alone; then undo the + q. This is fastest when
r ÷ p is a clean number.
**Distribute-first:** expand p(x + q) into px + pq, then solve
the px + q' = r equation from Lesson 04. This is safest when
r ÷ p is messy, or when you want the expanded form for another
step.

Both routes must give the same answer — if they do not, one
route has an arithmetic slip. That cross-check is the point of
learning both.

**Worked example 1.** Solve 2(x + 3) = 14.

Divide-first: (x + 3) = 14 ÷ 2 = 7, so x = **4**.
Distribute-first: 2x + 6 = 14; 2x = 8; x = 4. ✓
Check: 2(4 + 3) = 2 × 7 = 14. ✓
Arithmetic solution: 14 ÷ 2 = 7; 7 − 3 = 4.

**Worked example 2.** Solve 5(x − 2) = 35.

Divide-first: x − 2 = 35 ÷ 5 = 7, so x = **9**.
Distribute-first: 5x − 10 = 35; 5x = 45; x = 9. ✓
Check: 5(9 − 2) = 5 × 7 = 35. ✓

**Worked example 3.** Solve (1/2)(x + 6) = 5.

Divide-first means multiply both sides by 2 (the inverse of
× 1/2): x + 6 = 10, so x = **4**.
Distribute-first: (1/2)x + 3 = 5; (1/2)x = 2; x = 4. ✓
Check: (1/2)(4 + 6) = (1/2) × 10 = 5. ✓
Here divide-first is one step shorter — and it avoids
fraction coefficients entirely.

## Guided practice (with hints)

**G1.** Solve 3(x + 4) = 21 both ways.
*Hint: divide-first gives x + 4 = 7.*

**G2.** Solve 4(x − 5) = 12 both ways.
*Hint: distribute-first gives 4x − 20 = 12.*

**G3.** Solve −2(x + 1) = 10, and check by substitution.
*Hint: dividing by −2 flips the sign of the group.*

## Independent practice

**I1.** Solve 2(x − 7) = 18.
**I2.** Solve 6(x + 2) = 30.
**I3.** Solve (1/3)(x − 3) = 4.
**I4.** Solve −3(x − 4) = 21.

## Applied task

Three gift bags each contain x marbles plus 4 bonus marbles,
for 45 marbles in total. Write the equation, solve it both
ways, and check it. Then write a one-sentence arithmetic
solution: "45 divided by 3 is ___, minus 4 is ___." Explain
why the arithmetic sentence matches the divide-first route.

## Exit check

Solve 2(x + 5) = 26 both ways. Which route was shorter for
these numbers, and why?

## Supports and extension

- **Reading/language access:** circle the group (x + q) in
  the equation before choosing a route.
- **Alternate response mode:** use tiles to show p equal
  groups before writing either route.
- **Extension:** solve 3(2x − 1) = 21 two ways (note: this
  group contains 2x, not x — distribute-first is natural
  here). Explain why divide-first still works: 2x − 1 = 7,
  so 2x = 8, x = 4. (Full solution in the key.)

## Teacher note

Likely misconceptions: distributing p to x but not to q
(2(x + 3) → 2x + 3); dividing only one side by p; sign errors
with a negative p. Answers: see [answer key](../answer-key.md),
Lesson 05.
