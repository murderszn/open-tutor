## Lesson 01 — Expand and combine

- Readiness: (1) 27 both ways; (2) 7x; (3) 3 both ways — a
  fraction and its decimal are the same number.
- G1: 4x − 12. G2: 7x + 2. G3: −2x − 3.
- I1: 10x − 5. I2: 7x + 5. I3: x + 8. I4: x + 5.
- Applied: perimeter = 2(2x + 3) + 2(x − 1) = 4x + 6 + 2x − 2
  = **6x + 4**. For x = 5: length 13, width 4, perimeter
  2(13) + 2(4) = 34; 6 × 5 + 4 = 34. ✓
- Exit: 3x + 2. Check x = 3: 3(3 + 2/3) = 11; 3 × 3 + 2 = 11. ✓
- Extension: 2(3x − 1) − 3(x + 4) = 6x − 2 − 3x − 12 = **3x − 14**.
  The x-coefficient is 6 − 3 = 3.

## Lesson 02 — Factor and rewrite

- Readiness: (1) 12x + 18; (2) 6; (3) 0.05; a + 0.05a = 1.05a.
- G1: 4(2x − 3). G2: 1.1y — a 10% increase.
  G3: 2a + 9 (no further factoring: GCF of 2a and 9 is 1).
- I1: 5(3x + 2). I2: 0.75p — a 25% decrease.
  I3: 8x − 4 = 4(2x − 1). I4: 3x + 6 — the form shows three
  groups of (x + 2), or a starting value of 6 growing by 3
  per unit of x.
- Applied: 3(n + 1.50) expands to 3n + 4.50, so the two prices
  are always equal. For n = 6.50: 3 × 6.50 + 4.50 = 24.00;
  3 × 8.00 = 24.00. ✓ Use the expanded form to compute, the
  factored form to see the three identical sets.
- Exit: 3(3x + 2). Check x = 4: 36 + 6 = 42; 3 × 14 = 42. ✓
- Extension: (3/4)x + 3/2 = (3/4)(x + 2), because (3/4) × 2 =
  3/2. The GCF is 3/4: it divides both (3/4)x and 3/2.

## Lesson 05 — Equations p(x + q) = r

- Readiness: (1) 2x + 6; (2) x = 4; (3) 7.
- G1: x = **3** (divide: x + 4 = 7; distribute: 3x + 12 = 21).
  G2: x = **8** (divide: x − 5 = 3; distribute: 4x − 20 = 12).
  G3: x = **−6** (−2 × (−5) = 10 ✓).
- I1: x = **16**. I2: x = **3**. I3: x = **15**
  ((1/3) × 12 = 4 ✓). I4: x = **−3** (−3 × (−7) = 21 ✓).
- Applied: 3(x + 4) = 45 → x = **11 marbles**
  (3 × 15 = 45 ✓). Arithmetic: 45 ÷ 3 = 15; 15 − 4 = 11 —
  exactly the divide-first route in words.
- Exit: x = **8** both ways (divide: x + 5 = 13;
  distribute: 2x + 10 = 26). Divide-first was shorter here
  because 26 ÷ 2 = 13 is clean.
- Extension: 3(2x − 1) = 21. Divide-first: 2x − 1 = 7 →
  2x = 8 → x = **4**. Distribute-first: 6x − 3 = 21 →
  6x = 24 → x = 4. ✓ Divide-first still works because the
  group (2x − 1) is treated as one quantity first.

## Lesson 06 — Inequalities and graphs

- Readiness: (1) true; false. (2) open circle at 4, arrow
  right. (3) x = 4; with > it becomes x > 4, a whole ray.
- G1: x < **8** — open circle at 8, arrow left.
  G2: x ≥ **4** — closed circle at 4, arrow right.
  G3: x < **−3** — open circle at −3, arrow left (flip).
- I1: x < **4** — open circle at 4, arrow left.
  I2: x ≥ **7** — closed circle at 7, arrow right.
  I3: x < **−5** — open circle at −5, arrow left (flip).
  I4: x ≤ **6** — closed circle at 6, arrow left.
- Applied: 12 + 8g ≤ 60 → 8g ≤ 48 → g ≤ **6 games at most**.
  Whole-number reading: g = 6 gives $60 exactly; g = 7 gives
  $68, over budget. The inequality allows decimals, but you
  cannot buy part of a game.
- Exit: −4x < 20 → x > **−5** (flip). Open circle at −5,
  arrow right. Checks: x = 0 gives 0 < 20 ✓ (a solution);
  x = −6 gives 24 < 20 ✗ (not a solution).
- Extension: −2(x + 3) > 10. Divide-first: x + 3 < −5
  (flip) → x < **−8**. Distribute-first: −2x − 6 > 10 →
  −2x > 16 → x < −8 (flip at the division). Graph: open
  circle at −8, arrow left.

## Project sample (Budget Challenge)

Budget $200. Base plan: 4 games at $25 and 2 books at $20:
expression 4(25) + 2(20) = 100 + 40 = **$140**.
Exact-spend equation with $20 extras: 140 + 20n = 200 →
20n = 60 → n = **3**; check 140 + 60 = 200. ✓
Inequalities: (a) 140 + 20n ≤ 200 → n ≤ 3, so at most 3
extras; (b) with a $10 fee, 140 + 20n + 10 ≤ 200 → n ≤ 2.5,
so at most 2 extras once the fee is included. Graph (a):
closed circle at 3, arrow left (n counts extras). A learner
plan with different numbers earns full marks when its algebra
matches its totals the same way.
