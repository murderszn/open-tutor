# Teacher Guide — Unit 04: Expressions, Equations, and Inequalities

**Unit:** [Unit 04](README.md) · **Track weeks:** 15–18 · **Standards 7.EE.A.1–2, 7.EE.B.3–4**

## Pacing notes

- **Week 15 (Sessions 1–4):** Lesson 01's sign discipline is
  the unit's load-bearing habit — do not let learners skip
  the substitution check, because Lessons 04–06 all depend on
  it. Lesson 02's rewriting (a + 0.05a = 1.05a) is a return
  to Unit 03, not new content; spend the time on factoring
  with a GCF that is not obvious (Session 4, P8).
- **Week 16 (Sessions 5–8):** Lesson 03 is deliberately
  calculator-free in method: the estimate comes first, or it
  does not count as a reason check. Lesson 04's balance-scale
  image works best if the adult covers the caption first and
  asks "what does level mean?" before any numbers appear.
- **Week 17 (Sessions 9–12):** Lesson 05 should feel like a
  choice, not a second topic: for each problem, ask which
  route is shorter *for these numbers* and why. Lesson 06's
  flip rule needs the 3 < 5 → −3 > −5 demonstration on the
  board, not just the rule stated.
- **Week 18 (Sessions 13–16):** Session 13 is the whole
  project in one session — learners who pick round numbers
  (like the key's sample) finish; learners who pick awkward
  prices will need the finishing time before Session 16.
  Session 14 is retrieval, not re-teaching. If the quiz
  (Session 15) shows a class-wide flip error, reteach Lesson
  06's test-value check before the assessment rather than
  after it.

## Misconception clinic

| What learners say | The error | The repair |
|---|---|---|
| "3(2x + 1/2) = 6x + 1/2" | Distributes to the first term only | Multiply the outside number by *every* inside term; check with x = 2 |
| "−(x − 5) = −x − 5" | Forgets distributing −1 flips both signs | −(x − 5) = −x + 5; test x = 0: −(−5) = 5 |
| "12x + 18 = 2(6x + 9), done" | Factors out a non-greatest factor | Keep factoring until the GCF is out: 6(2x + 3) |
| "1.05a means increase by 105%" | Misreads the multiplier | 1.05a = a + 0.05a: a 5% increase, not 105% |
| "2(x + 3) = 2x + 3" | Distributes to x only | The 2 multiplies the whole group: 2x + 6 |
| Divides before removing q in px + q = r | Wrong undo order for that route | Either undo in reverse order, or divide-first only for p(x + q) = r |
| "−2x > 10 → x > −5" | Forgets the flip rule | Multiplying/dividing by a negative reverses order; test x = 0 exposes it |
| "x ≤ 6.7, so 6.7 games" | Decimal answer for whole objects | The inequality allows decimals; the story counts whole games, so at most 6 |
| Closed circle for > or < | Circle convention swapped | Open = boundary excluded; closed = boundary included |

## Reteach triggers

- **Expression items (quiz Q1–Q3, assessment Q1–Q3) below
  70%:** return to Lessons 01–02; drill "expand, then check
  with x = 2" as a spoken routine before any factoring.
- **Equation items (quiz Q5–Q6, Q9; assessment Q6–Q7, Q10)
  below 70%:** return to Lessons 04–05; require the
  substitution check written out, not done mentally.
- **Inequality items (quiz Q7–Q8, Q10; assessment Q8–Q9,
  Q11–Q12) below 70%:** return to Lesson 06; require a
  boundary test and one inside/outside test value for every
  item until the flip rule is automatic.
- **Project rubric below 14/20:** the usual cause is totals
  that do not match the algebra — have the learner recompute
  the base plan from the item list before revising any
  inequality.

## Readiness and next steps

- **Ready for Unit 05** when the learner solves px + q = r
  and p(x + q) = r fluently with checks, and graphs an
  inequality with the correct circle and direction: Unit 05
  uses equations for unknown angles, and the same undoing
  sequence applies.
- **Not yet ready:** if the flip rule or the substitution
  check is still unreliable, use Week 19 (midyear review)
  for targeted reteach on objectives 3–4 before Unit 05's
  angle equations.
- **Extension path:** learners who finish early can take the
  Lesson 05 extension (a group containing 2x) and the Lesson
  06 extension (a negative coefficient outside parentheses)
  as the bridge to multi-step inequalities with grouping.
