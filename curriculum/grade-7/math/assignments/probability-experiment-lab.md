# Probability Experiment Lab - Learner

Shared spec: Shared reference(use the selected grade’s private workspace)

## Learner Checklist

- [ ] Choose or design a chance experiment with at least 3 possible outcomes.
- [ ] List the full sample space.
- [ ] Predict the theoretical probability for each outcome.
- [ ] Run at least 50 trials and record every result.
- [ ] Calculate experimental probability for each outcome.
- [ ] Make a bar graph or line plot.
- [ ] Write an 8-10 sentence conclusion comparing theory to results.
