# Learner — Geometry Scale Drawing Studio (Grade 7)

## Goal
Use scale factor, area, and perimeter in a design task.

## Tasks
1. Draw a bedroom, studio, or game-room layout to scale (example: 1 cm = 1 ft).
2. Label side lengths and compute perimeter.
3. Break shape into rectangles/triangles and estimate area.
4. Write a short note: one change that improves the layout and why.
