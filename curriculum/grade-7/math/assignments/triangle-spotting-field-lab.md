# Triangle Spotting Field Lab - Learner

Shared spec: Shared reference(use the selected grade’s private workspace)

## Learner Checklist

- [ ] Find at least 8 real-world triangles.
- [ ] Include at least 2 side-length types: equilateral, isosceles, or scalene.
- [ ] Include at least 2 angle types: acute, right, or obtuse.
- [ ] Photograph or sketch each triangle without private information in the image.
- [ ] Estimate or measure side lengths for each example.
- [ ] Classify each triangle by side length and by angle.
- [ ] Explain the evidence for each classification.
- [ ] Write an 8-10 sentence reflection about where triangles appear and why they are useful.

## Resource Pack

Use the Resource Pack in the shared spec for videos, web references, and quick-open searches. Start with Khan Academy's classifying triangles video, then use the Britannica triangle reference to check definitions.
