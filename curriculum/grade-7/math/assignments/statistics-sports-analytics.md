# Grade 7 — Statistics Comparison

**Blank reusable assignment.**

## Goal and Instructions

Use an educator-provided anonymous or fictional 10-value dataset. Calculate mean, median, mode, and range. Compare the first five and last five values. Graph the data and write a conclusion that distinguishes an observed pattern from its possible causes.
