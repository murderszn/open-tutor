# Learner — Proportional Relationships Shop (Grade 7)

## Goal
Use ratios, unit rates, and percent to compare deals.

## Tasks
1. Pick 3 products (real or pretend) with different package sizes and prices.
2. Find the unit price for each and rank best to worst value.
3. Write 3 comparison statements using ratio language.
4. Add one percent discount (10%, 15%, or 20%) and recalculate final price.
