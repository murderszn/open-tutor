## Web references (verified 2026-10-12 via search-result verification; open and preview before assigning)

1. **Common Core State Standards — English Language Arts**
   [thecorestandards.org/ELA-Literacy](https://www.thecorestandards.org/ELA-Literacy/)
   — the unit's reference framework; grade-7 codes/descriptions verified
   against the published standards during the track A00 audit (2026-10-05).
   Free, no account. *(Standards reference for the adult.)*
2. **Aesop's Fables (V. S. Vernon Jones translation), Project Gutenberg
   #11339**, via the University of Pennsylvania Online Books Page:
   [onlinebooks.library.upenn.edu/webbin/gutbook/lookup?num=11339](https://onlinebooks.library.upenn.edu/webbin/gutbook/lookup?num=11339)
   — public-domain full text; free, no account. *(Project Option B reading.)*
3. **ReadWriteThink — "Choose Your Own Adventure: A Hypertext Writing
   Experience"**
   [readwritethink.org/classroom-resources/lesson-plans/choose-your-adventure-hypertext](https://www.readwritethink.org/classroom-resources/lesson-plans/choose-your-adventure-hypertext)
   — NCTE/ILA lesson built on adventure-story elements (setting, character,
   plot, conflict); useful adult background for element-interaction
   teaching. Free. *(Adult planning for Lessons 05–06.)*
4. **Story Elements Graphic Organizer (PDF)**
   [schools.archmil.org/…/6StoryElementsGraphicOrganizer.pdf](https://schools.archmil.org/CentersofExcellence/DOCsPDFs/Learning-Support-Teams/2013-LST/6StoryElementsGraphicOrganizer.pdf)
   — printable organizer covering theme, setting, character, point of view,
   conflict, and plot stages; free direct download, no account. *(Learner
   alternative to the hand-drawn interaction map.)*
5. **The Literacy Loft — teaching story elements guide**
   [theliteracyloft.com/2025/10/the-ultimate-guide-to-teaching-story-elements-in-grades-3-5-and-beyond-with-confidence](https://theliteracyloft.com/2025/10/the-ultimate-guide-to-teaching-story-elements-in-grades-3-5-and-beyond-with-confidence/)
   — teacher-facing guide on explicit story-element instruction (character,
   setting, plot, conflict, theme). Free article. *(Adult background.)*
