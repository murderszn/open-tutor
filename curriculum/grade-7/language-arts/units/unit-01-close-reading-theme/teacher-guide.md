# Teacher Guide — Unit 01: Close Reading, Theme, and Interacting Story Elements

Guidance for the adult leading this unit. Student materials never include
answer keys; this guide and [answer-key.md](answer-key.md) stay with the
adult.

## How the unit fits together

- **Sessions 1–4 (RL.7.1)** build the foundation: several-pieces citation
  (L1), then inference-vs-fact with defended alternatives (L2). Do not rush
  — every later lesson stands on "point to the page."
- **Sessions 5–8 (RL.7.2)** add theme: topic→statement with the three tests
  (L3), then objective summary with the opinion-word purge (L4). L.7.6
  academic verbs enter in L3 and are required from Session 6 on.
- **Sessions 9–12 (RL.7.3)** add interaction: setting→choice→plot chains
  with the removal test (L5, using the generated illustration), then the
  full interaction map with theme as the system's output (L6).
- **Sessions 13–16** apply everything: the dossier project, the formative
  quiz (revised legacy quiz, passage-anchored), the new-passage assessment,
  and portfolio theme statements.

## Common misconceptions and responses

| Misconception | What you'll see | Response |
|---|---|---|
| One citation = "several pieces" | Same quote reused, or one detail cited three ways | Require distinct paragraph numbers; "spread your evidence across the story" |
| Inference stated as fact | "The text says Mara feels relieved" | Make them highlight: is the feeling-word on the page? Label stated/inferred every time |
| Topic as theme | "The theme is courage" | The verb test: "say it in a sentence that makes a claim about life" |
| Plot summary as theme | "Mara climbs the tower in the storm" | The travel test: "would this sentence be true of *any* story? It must be — remove the names" |
| Theme proved from the ending alone | Trace lists three end-details | Require one detail per stage; the beginning *plants*, the middle *tests* |
| Summary as review | "I liked…", "the best part…" | Somebody–Wanted–But–So frame; ban opinion words structurally, not by willpower |
| Setting as inventory | "The setting is stormy, dark, cold" (then stops) | Require the arrow: "…which *forces* ___ to ___" |
| Theme as a sixth box | Theme drawn equal to character/setting | Re-draw: theme is the banner, the *output* of the arrows |
| Unlabeled map arrows | Twelve arrows, no mechanisms | "An unlabeled arrow is decoration" — model two labeled arrows, then hand back |

## Re-teaching map

| If the learner struggles with… | Revisit | With |
|---|---|---|
| Finding distinct citations | L1 guided practice | Re-read one paragraph at a time; highlight-then-claim |
| Stated vs. inferred | L2 guided practice | The sort game (Practice B) with the answer key's ten statements |
| Theme statements failing tests | L3 guided practice | Repair the four workshop statements (Practice C) before writing new ones |
| Opinion words in summaries | L4 guided practice | The contaminant hunt (Practice D); keep the banned-word list visible |
| Setting→choice chains | L5 worked examples | The chain frame; draw three boxes before writing |
| Interaction maps | L6 guided practice | Build one arrow together; prompt "does it push back?" per pair |
| Quiz score below 18/30 | Missed element's lesson + practice | Re-take the quiz with the *assessment* passage after re-teaching |
| Assessment below 24/37 | Full re-teaching map above | Reassess with an adult-chosen alternate passage, not the same one |

## Readiness criteria

The learner is ready for **U02** (literary perspective, figurative
language, poetry) when: every major claim they make about a story is
followed by a citation without prompting; they can write a theme statement
passing all three tests and trace its development; their summaries are
opinion-free on the first draft; and they can build one labeled
setting→choice→plot chain independently. Portfolio theme statements
(Session 16) are the evidence — file them.

## Leading the discussions (Sessions 4, 8, 12)

- **Session 4 (inference duel):** the point is not winning but *steel-manning*
  — after arguing, each side must state the opponent's best point fairly.
  Praise alternative-naming more than correct answers.
- **Session 8 (summary repair):** keep it light; contaminated summaries are
  funny. The humor makes the opinion-word hunt memorable.
- **Session 12 (project launch):** resist choosing the text for the learner.
  Ask: "which text gives you the most to *prove*?" Fables are short but
  dense; myths are rich but long — both are legitimate.

## On the legacy quiz revision

The formative quiz revises
`quizzes/literary-terms-story-elements-narrative-devices-quiz.md` per the
A00 audit decision: the original ten items tested guide recall
(definitions, "give a real example from a movie you know"); the revision
keeps the story-elements coverage (plot stages, conflict types, setting's
four parts, static/dynamic, direct/indirect characterization, theme vs.
topic, POV-adjacent inference work) but anchors every item to the read
passage and adds theme-development and element-interaction items the
original lacked. The original file is left untouched in `quizzes/`; its
answer-key gap is filled here, in the unit's teacher materials.

## Text selection for the project (Options B and C)

- **Fables:** the [resource pack](resource-pack.md) links a public-domain
  Aesop text. Preview the chosen fable: under ~400 words, clear
  setup→choice→consequence arc ("The Tortoise and the Hare," "The Boy Who
  Cried Wolf," "The Ant and the Grasshopper" all qualify).
- **Myths:** use the great-books guide's mythology table for your own
  summary; tell it in your own words at grades 6–8 reading level. Icarus
  and King Midas trace theme development cleanly (warning → choice →
  consequence).
- Never assign a linked title unpreviewed (audit boundary).

## Notes on the generated illustration

`assets/storm-lighthouse-setting.png` is an **AI-generated illustration**,
not a photograph or a primary source — say so to the learner. It depicts an
imagined storm-night lighthouse matching the anchor story's setting and is
used only for the Lesson 05 setting-analysis activity, which also provides
a full text alternative. Factual review: no false measurements, labels, or
geographic claims are embedded in the activity; the image carries no text.
See [assets/README.md](assets/README.md) for the generation record.
