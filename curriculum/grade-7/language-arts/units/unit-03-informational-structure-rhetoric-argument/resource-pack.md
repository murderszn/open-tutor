# Resource Pack — Unit 03: Informational Structure, Rhetoric, and Argument Evaluation

**Goal in one sentence:** give a grade-7 learner and guiding adult
reliable background and practice routes for central ideas, text
structure, author's position, argument evaluation, and two-author
comparison — at grade level, free, and without an account for core
learning.

**Age fit:** grade 7 (ages ~12–13). Articles in this unit are original
and rights-clean; external items below are adult-previewed background,
not assigned reading. Videos supplement the lessons; they never replace
them.

## Internal references and datasets

- No external dataset is required for this unit. All numbers in
  Articles A and B and the Lesson 05 argument passage are a **fictional
  practice dataset** created for analysis practice: shaded sidewalk
  88°F vs. sunny sidewalk 104°F; air above 90°F vs. 96°F; planting
  about $300 per tree, care about $50 per tree per year; one block's
  root repairs $8,000. Learners must never cite these as real-world
  facts; the project sources note exists for exactly this distinction.
- Real-world background figures, when the project extension needs one,
  come from references 2 and 3 above — never from the fictional
  articles.
