# Learner — Context Clues Vocabulary Lab (Grade 7 LA)

## Goal
Use context clues to determine meaning and tone.

## Tasks
1. Select a reading passage (book/article/chapter).
2. Choose 8 unfamiliar or strong vocabulary words.
3. Guess meaning from context before looking up definitions.
4. Compare your guess to dictionary meaning.
5. Write one original sentence for each word.
