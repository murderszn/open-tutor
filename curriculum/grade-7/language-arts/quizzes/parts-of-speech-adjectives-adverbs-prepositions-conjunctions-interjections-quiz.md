# Grade 7 Language Arts — Parts of Speech — Adjectives, Adverbs, Prepositions, Conjunctions & Interjections Quiz

**Topic:** Parts of Speech — Adjectives, Adverbs, Prepositions, Conjunctions & Interjections

**Assignment:** Read the **Adjective**, **Adverb**, **Preposition**, **Conjunction**, **Interjection**, and **Quick Summary Table** sections in the [Parts of Speech](../../../../resources/language_arts_parts_of_speech.md) guide.

Please answer the following 10 questions based on your reading.

---

**1.** What is an adjective? List the four questions adjectives answer, and give two example sentences where an adjective is used.

**2.** What are the three articles in English? Which is definite and which are indefinite? Give an example sentence using each.

**3.** Explain the three degrees of comparison for adjectives. Write an example with the word *fast* at all three degrees.

**4.** What is an adverb? Name the five questions adverbs can answer (How? When? etc.) and give one example adverb for each.

**5.** Many adverbs are formed by adding *-ly* to an adjective — but not all *-ly* words are adverbs, and not all adverbs end in *-ly*. Give one example of each exception.

**6.** What is a preposition? Write three prepositional phrases using three different prepositions, and explain what relationship each one shows (location, time, direction, etc.).

**7.** What is a coordinating conjunction? Name all seven using the FANBOYS mnemonic and write a sentence using one.

**8.** What is a subordinating conjunction? Give three examples and write one sentence using a subordinating conjunction.

**9.** What is a correlative conjunction? Give two examples of pairs and write a sentence using one pair.

**10.** What is an interjection? Give four examples — two that express strong emotion (using !) and two that express mild emotion (using ,). Write a complete sentence for one of them.
