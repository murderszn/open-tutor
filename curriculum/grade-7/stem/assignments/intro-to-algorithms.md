# Grade 7 — Algorithm and Flowchart Design

## Goal
Design an algorithm that validates a user-entered number and categorizes it as below range, in range, or above range.

## Requirements
- Define input, output, and at least three test cases.
- Write numbered pseudocode with a decision branch for invalid input.
- Draw a flowchart and implement the algorithm in Python or JavaScript.
- Test boundary values and document one bug fix.

**Product:** Pseudocode, flowchart, runnable code, and an independent test log. Do not compare with another grade's track.
