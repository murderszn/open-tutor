# Thermodynamics Cooling Lab - Learner

Shared spec: Shared reference(use the selected grade’s private workspace)

## Learner Checklist

- [ ] Read the Big Idea, Four Laws, and Heat Transfer sections in `[Shared reference](../../../../resources/thermodynamics_laws.md)`.
- [ ] Set up a safe warm-water cooling test.
- [ ] Record temperature every 2 minutes for at least 12 minutes.
- [ ] Make a temperature-over-time graph.
- [ ] Identify the system and surroundings.
- [ ] Explain where heat moved and which heat-transfer modes were involved.
- [ ] Run one comparison test that changes only one variable.
- [ ] Write an 8-10 sentence conclusion connecting the data to the first and second laws of thermodynamics.

## Resource Pack

Use the Resource Pack in the shared spec. Start with the local thermodynamics guide, then use Khan Academy or PhET if you need a clearer model of energy transfer.

Submit the data table, graph, setup photo or sketch, comparison test, and conclusion.

## Safety
An educator must approve the setup. Use small, light objects on a stable low surface, keep people clear of moving objects, and stop if anything is unsafe. Use warm—not hot—water; no flames, lasers, pressurized containers, sharp tools, or mains electricity. Substitute provided data or diagrams when equipment or supervision is unavailable. Keep observations and identifying images private.
