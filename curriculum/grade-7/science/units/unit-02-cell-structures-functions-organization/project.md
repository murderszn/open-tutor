# Project — The Organization Model

**Unit 02 project (Sessions 11 and 13; submitted at Session 16).**
Build a layered model that traces one example from a single cell all
the way to the whole organism — and explain how the cell-level parts
make the whole thing work.

## The task

Choose **one** of the two tracks:

- **Track H (human):** neuron → nervous tissue → brain → nervous
  system → human. *Or* muscle cell → muscle tissue → heart →
  circulatory system → human. *Or* red blood cell → blood tissue →
  heart → circulatory system → human.
- **Track P (plant):** root hair cell → absorptive tissue → root →
  root system → plant. *Or* mesophyll cell → leaf tissue → leaf →
  shoot system → plant. *Or* guard cells → leaf surface tissue →
  leaf → shoot system → plant.

Then build the model:

1. **Five labeled layers** (cell → tissue → organ → organ system →
   organism), one per row or panel, each with: the level name, your
   example's name at that level, and 2–3 labels of key structures.
   Use paper, cardstock, or a digital drawing tool — neat and
   readable, not fancy.
2. **Cell layer detail:** reuse and extend your Unit 01 labeled cell
   diagram for the cell in your trace. Add the Lesson 01
   "if-missing" annotations: for at least four structures, state
   what the whole cell could not do without it.
3. **"What this level adds" captions:** under each layer, write one
   sentence naming what that level can do that the level below
   cannot.
4. **Whole-system explanation (one paragraph):** argue that your
   example is a system of interacting parts. Cite at least two
   interactions (e.g., guard cells controlling gas flow for
   mesophyll photosynthesis; the heart depending on nervous tissue
   to coordinate beats). End with one sentence naming a limit of
   your model — something real that it does not show.
5. **Oral or written walkthrough (3 minutes):** present the model to
   the adult, tracing bottom to top without reading the captions
   word for word.

## Materials

Paper/cardstock or a digital drawing tool, pencils/markers, scissors,
glue/tape, ruler; your Unit 01 cell diagrams; this unit's lessons and
the [organization-levels diagram](assets/organization-levels.svg)
(schematic reference — your model must be your own work, not a copy).

## Deliverables (what you turn in)

- [ ] The five-layer model (physical or digital file/printout)
- [ ] Cell-layer "if-missing" annotations (≥4 structures)
- [ ] "What this level adds" captions (all five levels)
- [ ] Whole-system explanation paragraph (with ≥2 interactions and
      one model limit)
- [ ] 3-minute walkthrough (adult initials and date when done)

## Rubric (scoring guidance for the adult)

| Criterion | 3 — Proficient | 2 — Developing | 1 — Beginning |
|---|---|---|---|
| Levels in order (30%) | All five levels present, in correct order, each labeled with the level name and the example | Four levels correct, or one level mislabeled | Levels missing or out of order; examples do not match levels |
| Structure-function detail (30%) | Cell layer shows ≥4 structures with correct "if-missing" whole-cell consequences; captions name each level's added capability | Structures labeled but consequences vague ("the cell would die"); some captions generic | Structures unlabeled or consequences incorrect; captions missing |
| Systems argument (25%) | Paragraph cites ≥2 real interactions between parts/levels and names one honest model limit | One interaction cited, or limit missing | No interactions cited; paragraph restates labels |
| Presentation (15%) | Walkthrough traces bottom-to-top fluently, answers one adult follow-up question | Walkthrough reads captions; struggles with follow-up | Cannot trace the model without heavy prompting |

**Scoring:** 12 = exemplary; 9–11 = proficient (unit objective met);
6–8 = developing (revise the flagged criterion and resubmit that
part); below 6 = reteach Lessons 01–04, then rebuild. Keep the model
and the adult's scored rubric in private storage — never in this
repository.

## Milestones

- **Session 11 (launch):** choose a track; sketch the five layers;
  draft the "what this level adds" captions; start the cell-layer
  annotations.
- **Session 13 (workshop):** finish all layers and captions; write
  the whole-system paragraph; rehearse the walkthrough.
- **Session 16:** submit the model with the unit assessment.

## What success looks like

A proficient model makes the *interactions* visible, not just the
labels: the adult can point at any two adjacent layers and hear *why*
the upper one needs the lower one. The paragraph reads like a small
scientific argument, not a parts list — and the named model limit
shows the learner knows what the model cannot prove.
