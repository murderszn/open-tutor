# Lesson 02 — Measurement, Units, and the Lab Notebook

**Goal (student-readable):** I can measure with SI units, always write
the unit, tell accuracy from precision, and build a labeled data table.
**Time:** 45–50 minutes · **Materials:** metric ruler, kitchen or
spring scale, thermometer, notebook, pencil.

## Readiness check (5 min)

Write "the desk is 120 long." What is wrong with this measurement?
(Answer: no unit — 120 what? Centimeters? Inches? Without the unit,
the number is meaningless.) Rewrite it correctly two ways: with a
metric unit and with a US customary unit.

## Teaching

Scientists everywhere use the **SI system** (metric): meters for
length, kilograms for mass, seconds for time, degrees Celsius for
temperature, liters for volume. Two reasons: the units scale by tens
(1 meter = 100 centimeters = 1,000 millimeters, so conversions are
just moving the decimal point), and everyone on Earth uses the same
system, so a measurement made in Tokyo is instantly understood in
Chicago.

Three rules for every measurement you ever record:

1. **Always write the unit.** "12.5" means nothing. "12.5 cm" is a
   measurement.
2. **Match the tool to the job.** A ruler marked in millimeters can
   report to the nearest millimeter; guessing thousandths of a
   millimeter from it is pretending to a precision you do not have.
3. **Repeat and record every trial.** Real measurements vary a little.
   Three trials of the same thing are worth more than one.

**Accuracy vs. precision.** Imagine throwing darts:

- **Accurate** = close to the true value (near the bullseye).
- **Precise** = close to each other (tight cluster), whether or not
  they hit the bullseye.

You can be precise but not accurate (tight cluster off-center — your
tool may be miscalibrated). You can be accurate but not precise (darts
scattered around the bullseye — the average is right, but each throw
is sloppy). Good science wants both: repeated measurements that
cluster tightly *around the true value*.

A **data table** organizes measurements so anyone can read them. Every
data table needs: a title, labeled columns (quantity + unit in the
header), one row per trial or object, and the trials numbered. Example:

| Trial | Length of pencil (cm) |
|---|---|
| 1 | 14.8 |
| 2 | 14.9 |
| 3 | 14.8 |

**Your lab notebook** is where all of this lives: date each entry,
record the question you are investigating, write the procedure in
steps, tape in or draw the data table, and end with a conclusion that
answers the question using the numbers. Messy-but-complete beats
neat-but-empty — but make it readable enough that someone else could
repeat your work.

## Worked examples

**Example 1.** A learner measures a book's width three times: 21.3 cm,
21.2 cm, 21.4 cm. The true width (measured with a calibrated tool) is
21.3 cm. Are the measurements accurate? Precise? Explain.

**Precise** — the three values cluster within 0.2 cm of each other.
**Accurate** — they center on the true value, 21.3 cm. Reason check:
precision asks "do the trials agree with each other?"; accuracy asks
"do they agree with the truth?" Here the answer to both is yes.

**Example 2.** Convert 2.5 km to meters and centimeters.

2.5 km × 1,000 m/km = **2,500 m**. Then 2,500 m × 100 cm/m =
**250,000 cm**. Reason check: kilo- means thousand, centi- means
hundredth of a meter, so going km → m → cm makes the number get
bigger twice. A common error is moving the decimal the wrong way —
ask "should the number get bigger or smaller?" before computing.

**Example 3.** Fix this data table (three defects):

| | length |
|---|---|
| first | 12 |
| second | 12.1 |

Defects: (1) no title; (2) the column header has no unit; (3) trials
are not numbered ("first/second" is not a standard label; and a
three-trial set is missing its third row). Fixed version:

| Trial | Length of leaf (cm) |
|---|---|
| 1 | 12.0 |
| 2 | 12.1 |
| 3 | (to be measured) |

## Guided practice (with hints)

1. Write the SI unit for: (a) length, (b) mass, (c) time,
   (d) temperature.
2. Convert: (a) 6.5 km to meters; (b) 72 cm to meters.
   *(Hint: km → m multiplies by 1,000; cm → m divides by 100.)*
3. A target's bullseye is 10 cm across. Arrows land at 9.8, 10.1,
   and 9.9 cm from center. Accurate? Precise? Explain in one sentence
   each.
4. A thermometer reads 20°C, 25°C, and 21°C for the same room
   (true temperature 21°C). Accurate? Precise? Explain.
   *(Hint: check clustering first, then closeness to 21.)*

## Independent practice

5. Measure the same book's length three times to the nearest
   millimeter. Record in a titled, labeled data table. Are your
   trials precise? (You cannot judge accuracy without a true value —
   say so.)
6. Convert 3.0 hours to seconds. Show the multiplication.
7. Error analysis: "I measured 4.521 cm with a ruler marked only in
   centimeters." What is wrong, and what should the learner report
   instead?

## Application

Measure three different classroom objects (each three times), record
all nine measurements in one data table with a title and units, and
write two sentences: which object was easiest to measure precisely,
and why?

## Exit check

In your own words, explain the difference between accuracy and
precision, using the three book-width measurements from Example 1.

## Supports, extensions, and teacher note

- **Reading/language access:** word bank on the notebook page —
  *accurate, precise, trial, data table, unit*.
- **Alternate response mode:** the learner may dictate measurements
  while the adult writes, then the learner checks each unit is present.
- **Extension:** time a 30-second event with a stopwatch five times;
  compute the range (max − min) and discuss what the range says about
  precision.
- **Teacher note — likely misconception:** learners merge the two
  words into "exactness." Keep the dartboard image alive all unit:
  *cluster = precision; bullseye = accuracy.*
