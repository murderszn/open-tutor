# Resource Pack — Unit 03: Photosynthesis, Respiration, and Matter–Energy Flow

**Summary (adult planning judgment):** Grade 7 learners meeting
photosynthesis, cellular respiration, and ecosystem matter–energy
flow do best when short videos *supplement* — never replace — the
paper equation-builder, the seedlings CER activity, the carbon-atom
tracing, and the food-web model project. The resources below support
the unit's six objectives: the photosynthesis equation, matter
tracing from air, cellular respiration, the photosynthesis–
respiration system, the food-web model, and the closing CER
explanation. All external links were checked 2026-10-25 unless
marked as open search links. At least one free, no-account route
supports every core objective.

## Web references (reputable, free, no account for reading)

1. **Verified 2026-10-25 (opened):** Britannica —
   [Photosynthesis](https://www.britannica.com/science/photosynthesis)
   — definition, formula 6CO₂ + 6H₂O → C₆H₁₂O₆ + 6O₂, chlorophyll
   and chloroplast roles, why photosynthesis matters. Supports
   Objectives 1–2 (Lessons 01–02). Free to read; page updated
   2026-10-14.
2. **Verified 2026-10-25 (opened):** Wikipedia —
   [Photosynthesis](https://en.wikipedia.org/wiki/Photosynthesis)
   — oxygenic photosynthesis, chloroplasts, sugar storage, and the
   link to cellular respiration. Supports Objectives 1–3. Adult
   previews: a long general reference; assign sections, not the
   whole article.
3. **Search-result reference (not opened in full, adult checks
   before assigning):** NSTA NGSS topic listing —
   [MS Matter and Energy in Organisms and Ecosystems](https://my.nsta.org/ngss/DisplayStandard?view=topic&id=30)
   — official wording for MS-LS1-6, MS-LS1-7, MS-LS2-3 with
   clarification statements and assessment boundaries. Supports
   the unit's standards notes; educator reference, not a learner
   assignment.
4. **Search-result reference (not opened in full, adult checks
   before assigning):** OpenSciEd —
   [7.4 Matter Cycling & Photosynthesis](https://openscied.org/instructional-materials/7-4-matter-cycling-photosynthesis/)
   — a Grade 7 instructional unit on the same expectations,
   useful for the adult's background and for extension activities.
   Supports Objectives 1, 4, 6.
5. **Verified via the track crosswalk (2026-10-05, re-checked
   2026-10-25):** NGSS middle-school life-science performance
   expectations, via the track scope-and-sequence crosswalk —
   codes MS-LS1-6, MS-LS1-7, MS-LS2-3. Educator reference.
