# 💻 Computer Science Basics

This guide introduces fundamental concepts of how computers process information and how we give them instructions (coding).

## 1. How Computers Work
At their core, computers only understand two states: **ON (1)** and **OFF (0)**. This is called binary. Everything a computer does—from playing a video game to writing an essay—is eventually translated into billions of 1s and 0s.
- **Hardware**: The physical parts you can touch (CPU, RAM, Hard Drive, Keyboard).
- **Software**: The invisible instructions and code that tell the hardware what to do (Apps, Operating Systems, Video Games).

## 2. What is an Algorithm?
An **algorithm** is simply a step-by-step set of instructions to solve a problem or complete a task.
- *Real-World Example*: A recipe for baking a cake is an algorithm. If you follow the steps exactly, you get a cake.
- *Computer Example*: The steps a search engine takes to find the best website for your search query.

### Inputs, Outputs, and Chaining
Algorithms don't just happen in a vacuum. They take something in, process it, and give something back.
- **Input**: What goes into the algorithm (e.g., the ingredients for your cake, or the words you typed into a search engine).
- **Output**: What comes out of the algorithm (e.g., the baked cake, or the list of website results).
- **Chaining**: Because the output of one algorithm can become the input for the next, programmers connect (or "chain") small algorithms together to build highly complex systems. For example, the output of a "Calculate Score" algorithm might be the input for an "Update Leaderboard" algorithm.

## 3. Core Coding Concepts
When we write code, we use specific concepts to build our algorithms.

### Variables (Memory)
A **variable** is a container that stores a piece of information so the computer can remember it later.
- *Think of it like:* A labeled box. If I have a box labeled "Score" and put the number 10 inside, `Score = 10`.

### Conditionals (Making Decisions)
Computers use **if/then** statements to make decisions based on changing information.
- *Example*: **IF** the player presses the jump button, **THEN** the character jumps. **ELSE**, the character stands still.

### Loops (Repeating Actions)
A **loop** tells the computer to repeat a set of instructions over and over until a certain condition is met.
- *Example*: Keep dealing cards **UNTIL** every player has 5 cards.

## 4. Flowcharts
Before writing complex code, programmers often draw **flowcharts** to plan their algorithms visually.
- **Oval**: Start / End
- **Rectangle**: Process / Action
- **Diamond**: Decision (Yes/No Question)
- **Arrows**: Show the direction of the flow.
