# K–8 Reference Sources

These primary sources inform the planning language and should be checked alongside the family's state or local requirements. OpenTutor's grade profiles are paraphrased examples, not a full mapping to any source.

## Core reference frameworks

- [Common Core State Standards: Mathematics](https://corestandards.org/mathematics-standards/) — grade-level math content and mathematical practices. States choose whether and how to adopt these standards.
- [Common Core State Standards: English Language Arts & Literacy](https://corestandards.org/english-language-arts-standards/) — reading, writing, speaking/listening, language, and content-area literacy expectations.
- [Next Generation Science Standards](https://www.nextgenscience.org/standards) — searchable K–12 performance expectations organized around science/engineering practices, disciplinary core ideas, and crosscutting concepts. NGSS is one reference; state adoption varies.
- [NCSS C3 Framework](https://www.socialstudies.org/standards/c3) — social studies inquiry arc: questions, disciplinary concepts/tools, evidence, and communication/action. It is a framework rather than an exhaustive grade-by-grade content list.
- [IES What Works Clearinghouse: Foundational Skills to Support Reading for Understanding in K–3](https://ies.ed.gov/ncee/wwc/PracticeGuide/21/) — evidence-graded recommendations for academic language, sound awareness linked to letters, decoding/word analysis, and daily connected-text reading.

## Use and attribution

The plans summarize broad expectations in original wording. They do not reproduce standards tables. Check the linked source for exact language, updates, jurisdiction-specific adoption, and implementation guidance. The IES guide supports literacy planning, but it is not a complete phonics curriculum or a substitute for a teacher's assessment and instructional judgment.
