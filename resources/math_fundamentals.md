# 🔢 Math Fundamentals — Grades 4–7

A student-friendly reference covering core math topics used across Advanced learner and Core learner’s assignments: place value, fractions, ratios, probability, and geometry.

## Place Value

Place value tells us what a digit is worth based on its position.

```
123,456
  |    ← ones
  |     ← tens
  |      ← hundreds
  |       ← thousands
  |        ← ten-thousands
  |         ← hundred-thousands
```

In decimals, the pattern continues after the decimal point: tenths, hundredths, thousandths.

**Quick check:**
- In 52.8, what place value is the 5?
- In 52.8, what place value is the 8?

## Fractions

A fraction has a **numerator** (top) and **denominator** (bottom).

- `1/2` = one half
- `3/4` = three quarters

To add fractions with the same denominator: keep the denominator, add the numerators.
```
1/4 + 2/4 = 3/4
```

To add different denominators, find a common denominator first:
```
1/2 + 1/3
→ 3/6 + 2/6 = 5/6
```

To multiply: multiply tops and bottoms.
```
1/2 × 2/3 = 2/6 = 1/3
```

To divide: flip the second fraction (reciprocal) and multiply.
```
1/2 ÷ 3/4 = 1/2 × 4/3 = 4/6 = 2/3
```

## Ratios & Unit Rates

A **ratio** compares two amounts: `a:b`.

A **unit rate** is a ratio with a denominator of 1.

If 3 apples cost $1.50, the unit rate is:
```
$1.50 ÷ 3 = $0.50 per apple
```

Rate formula: `rate = cost ÷ quantity`

## Percent & Decimals

```
50% = 0.50 = 1/2
25% = 0.25 = 1/4
75% = 0.75 = 3/4
10% = 0.10 = 1/10
```

## Probability

`P(event) = number of favorable outcomes ÷ total possible outcomes`

Example: Rolling a 4 on a standard die.
```
P(4) = 1 ÷ 6 = 1/6 ≈ 16.7%
```

## Geometry Basics

| Shape | Area Formula | Perimeter Formula |
|-------|--------------|-------------------|
| Rectangle | `length × width` | `2l + 2w` |
| Triangle | `1/2 × base × height` | `a + b + c` |
| Circle | `π × r²` | `2πr` |

## Common Conversions

Length:
```
1 foot = 12 inches
1 yard = 3 feet
1 mile = 5,280 feet
```

Weight:
```
1 pound = 16 ounces
1 ton = 2,000 pounds
```

Volume:
```
1 gallon = 4 quarts
1 quart = 2 pints
1 pint = 2 cups
1 cup = 8 fluid ounces
```
