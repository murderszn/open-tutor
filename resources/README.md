## Datasets

Column names carry units; treat values as labeled snapshots, not live
data — re-check dated facts (populations, officeholders, prices)
before teaching.

- [periodic_table_elements.csv](periodic_table_elements.csv) — atomic number, symbol, name, atomic mass (u), group/period
- [solar_system_planets.csv](solar_system_planets.csv) — distances in million km, orbital periods in days, diameters in km, surface gravity in m/s²
- [un_countries.csv](un_countries.csv) — country reference table
- [un_countries.json](un_countries.json) — machine-readable twin of `un_countries.csv`; prefer the CSV for learner-facing sorts
- [us_presidents.csv](us_presidents.csv) — presidents in order with terms
- [us_states.csv](us_states.csv) — `population_approx` ≈ 2020 Census figures; areas in sq mi / sq km; `subregion` uses the Census Bureau's four regions (Northeast, Midwest, South, West)
