# Semester Curriculum Resource Library

This is the shared, parent-reviewed resource shelf for Advanced learner’s 8th-grade semester, Core learner’s 5th-grade semester, and Early learner’s kindergarten semester. Each quiz and project links back here and also includes a topic-specific video search.

> **Family viewing note:** Preview videos before assigning them. YouTube search results and advertisements can change. Prefer the named educational channel in each search link, turn on captions when helpful, and use the web reference when a distraction-free option is better.

## How to Use This Library

1. Open the matching student and subject shelf below.
2. Start with the first linked course, collection, or primary-source set.
3. Use the topic-specific links inside the assignment for the exact week’s concept.
4. After watching or reading, explain one idea aloud or solve one example before starting the graded work.

## Curation Notes

- Sources favor official documentation, government and museum collections, established educational nonprofits, and the OpenTutor preferred-channel list.
- Some linked sites offer optional accounts; the listed core material is free to access.
- Video availability, advertisements, and suggested-video panels can change. Parent preview remains part of the assignment routine.
- Generated subject banners are decorative learning maps, not answer keys. Students should use labeled diagrams from the linked authoritative sources when precision matters.
